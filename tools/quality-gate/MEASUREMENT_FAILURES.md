# 측정 실패를 난이도 실패로 둔갑시키지 않기

- 2026-11-01: 기존 Stage31 native smoke의 승선 목표에 구형 `y=1860`이 남아 있었다. 현재 저작된 갑판은 `y=3366`이다. 정상 목표의 좌표를 현재 스테이지에서 읽고, 없으면 명시적으로 실패한다. 이동 정책의 실패를 지형/난이도 결함으로 결론 내리지 않는다.
- 31장 native 비교에서 획득45SP 중29~30SP 미사용 파티는13R 전멸, 획득SP 전부 사용 파티는17R에34적을 정리했지만2명 사망·승선 미완료·시뮬레이션 예산 소진이다. 둘 다 합격이 아니다. 이전 정책의 결과를 수정된 정책의 결과로 재사용하지 않는다.
- 두 native 파티 모두 합성 장 진입 프로필이며 인간 승률 자료가 아니다. 화면에 표시돼야 공격 가능한 예고 등은 실제 브라우저에서 별도로 확인한다. 단위시험/정적 배치/물리 안정성 통과가 완주·미술·정량 기준을 대신하지 않는다.
- 입력 실패·미사용 성장·정책 경로 오류·실제 게임 결함을 분리한다. 손실/timeout/오류 시행도 보존하고, 후보·정책·프로필 버전을 명시한다.
- 40장14적 후보는 물리 배치 검사는 통과했지만 피날레 규모에 미달하여 폐기했다. 최신 제작 목표42명(보스1·중간보스2 포함),18–20R은 사전 설계이며 아직 실측 통과가 아니다. 원본v3와의 차이를 숨기지 않는다.
- 35장 실제 폭4608인데 출구 대사에 구형 x6500/화면6980이 남아 있었다. 현재 저작된 완료/출구 좌표를 우선하고 구형 지도 fallback만 보존했다. 위치·가시성·숨김·구형 지도 조건의 production-event fixture는 통과했으며, 정상 완주/브라우저 검수와 구분한다.
