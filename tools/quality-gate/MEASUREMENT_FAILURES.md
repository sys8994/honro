# 측정 실패를 난이도 실패로 둔갑시키지 않기

- 2026-11-01: 기존 Stage31 native smoke의 승선 목표에 구형 `y=1860`이 남아 있었다. 현재 저작된 갑판은 `y=3366`이다. 정상 목표의 좌표를 현재 스테이지에서 읽고, 없으면 명시적으로 실패한다. 이동 정책의 실패를 지형/난이도 결함으로 결론 내리지 않는다.
- 31장 native 비교에서 획득45SP 중29~30SP 미사용 파티는13R 전멸, 획득SP 전부 사용 파티는17R에34적을 정리했지만2명 사망·승선 미완료·시뮬레이션 예산 소진이다. 둘 다 합격이 아니다. 이전 정책의 결과를 수정된 정책의 결과로 재사용하지 않는다.
- 두 native 파티 모두 합성 장 진입 프로필이며 인간 승률 자료가 아니다. 화면에 표시돼야 공격 가능한 예고 등은 실제 브라우저에서 별도로 확인한다. 단위시험/정적 배치/물리 안정성 통과가 완주·미술·정량 기준을 대신하지 않는다.
- 입력 실패·미사용 성장·정책 경로 오류·실제 게임 결함을 분리한다. 손실/timeout/오류 시행도 보존하고, 후보·정책·프로필 버전을 명시한다.
- 40장14적 후보는 물리 배치 검사는 통과했지만 피날레 규모에 미달하여 폐기했다. 최신 제작 목표42명(보스1·중간보스2 포함),18–20R은 사전 설계이며 아직 실측 통과가 아니다. 원본v3와의 차이를 숨기지 않는다.
- 35장 실제 폭4608인데 출구 대사에 구형 x6500/화면6980이 남아 있었다. 현재 저작된 완료/출구 좌표를 우선하고 구형 지도 fallback만 보존했다. 위치·가시성·숨김·구형 지도 조건의 production-event fixture는 통과했으며, 정상 완주/브라우저 검수와 구분한다.
- 기예 이름이나 발사체 생성만으로 결박을 검수하지 않는다. HSH01은 투과탄이고 HSH02도 기존에는 실제 결박 처리가 없었다. 새 결박형 중간보스에만 명중 시 native bound=1을 적용하고, 실제 발사체 명중·다음 턴 이동예산 감소·자기 행동 뒤 해제·다음 턴 복원을 검증한다. 일반 수의귀나 NPC는 이 변경의 대상이 아니다.
- 최초 퇴각점만 검사하면 두 번째 주기의 제자리 이동을 놓친다. 저작된 지지점과 원래 생성 지점 사이에서 현재 위치와 다른 목적지를 고르고 두 번째 주기도 검사한다.
- Workshop 기본 생성의 행동 상한과 공식 캠페인 이관 결과는 다를 수 있다. 실제 origin=campaign으로 생성해 확인한다.36장 상한2에는 명시적인 action-budget revision을 붙여 기존 보정이3으로 바꾸지 못하게 한다.
- 39장 포격은 화면에 표식이 잠깐 보인 사실만으로 발사하지 않는다. 물/월드 clipping이 끝난 뒤 실제 표식·라벨을 그리고, 가려짐·대화·숨김을 배제한다. 표시 뒤 제공된 아군 행동의 완료와 다음 팀 경계를 모두 확인한다. 진행 중 충전은 새 대응 기회로 세지 않는다.
- 포탄의 예측을 표적 도달 시각에 끊으면 빗나간 뒤 안전지대로 날아가는 경로를 놓친다. 실제 힘 적분·고정 지형 충돌·본래 수명/월드 이탈까지 검사하고, 움직일 수 있는 유닛은 정지 장애물로 가정하지 않는다. 안전지대 전체와 주민 몸/폭발 반경을 보호한다. 임의의 표적 시각 폭발이나 주민 무적을 추가하지 않는다.
- 지도 변경은 이미 정산된 승리를 재시작시키면 안 된다. 현재 시도의 정산 표식 또는 이미 다음 장으로 간 구형 기록은 오래된 화면 snapshot만 비우고 진행을 보존한다. 이전 방문의 cleared만 있는 새 재플레이 승리/아웃로는 정산 완료로 오인하지 않고 그대로 이어간다.
- 4막 보고서를 저장한 직후 1–30장만 허용하는 정리 코드가31–40장을 지우고 있었다. 실제4막 결과 저장·다시 불러오기 검사를 추가했다. 브라우저 완주 검사는 결과창 확인 뒤의 최종 localStorage까지 별도로 보존해야 다음 장의 정상 이어하기 근거로 쓸 수 있다.
