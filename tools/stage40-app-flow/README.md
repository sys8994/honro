새 독립 Chromium 저장소에 저장소의 QA 체크포인트 원문을 UI 가져오기한다. SHA256 2c8e5d95e1e956059da5ae0b74a02641beed0bccf0932568194b108fec3a8141. 원본은 기존 측정 프로필이며 자연1~39 완주나 사용자의 현재 저장이 아니다.
