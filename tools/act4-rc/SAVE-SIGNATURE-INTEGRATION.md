Common source `b59957592` integrates only `6963180f94358eae9afdac9af544ae8216f79fb6` and its focused test. Each official Act 4 compact save still serializes the current provider and live placement asset and compares their full serialized strings. A cached FNV signature is reused only if the newly serialized provider text matches the cached text exactly; a cache entry is added only after a live asset also exactly matches that provider. Modified live/custom assets remain inline; restore still verifies signatures independently. The cache contains string keys/text/signatures, has a 9,000,000 UTF-16-code-unit cap including keys, and holds no provider-object references. This is not an identity-only trust cache; cache size is not a device-memory measurement.
