# 혼로 6막 9·10장 시각 후보와 실측 근거

6막 개정에 맞춰 이미 플레이한 실제 네 영웅의 최신 신체·프로필을 사용했습니다. 두 장 모두 변경은 **원래 장 한정 시각 후보**입니다. 충돌, 기예, 피격 크기, 접지, 보상, 원경 및 저장은 바꾸지 않았습니다. 아래 모듈은 해당 장의 정식 런타임에 아직 결선하지 않았으며 이 브랜치에서 배포하지 않습니다.

## 9장, 무명사 외부

- 같은 카메라의 실제 게임 엔진 12개 전후 화면에서, 하얀 다중 경계 대신 어두운 접촉 경계를 쓰고 실제 암체 안층과 묻힌 석단을 보강했습니다. 새 발판은 없습니다. 동쪽 접촉선의 밝기 상위 10% 기준이 PC 177.8→98.8, 모바일 175.1→98.9였습니다.
- 원래 수의귀 리그는 한기가 느껴지는 남색과 연보라, 장승은 잿빛 고목·구릿빛으로 나눴습니다. 증원 직후 실제 이동 중일 때 변화가 크게 보이고, 자리를 잡으면 색을 가라앉힙니다. 일반 몬스터의 전역 팔레트는 변경하지 않습니다. 실루엣·접지 12개 쌍 픽셀 일치. 근거와 예외는 JSON에 기록했습니다.
- 이 스코프는 새로운 타입과 행동 구현을 대체하지 않습니다. 기존 모션 상태를 관측하는 시각 코드만 있습니다.

## 10장, 산문 앞 후일담

- 비충돌 장식 띠와 이 장에서만 과도하던 밝은 스트로크를 제거한 A안에, 암반 층리 5개와 산문 기단 6개(합 96정점)를 기존 실루엣 안에 보강한 B안을 선택합니다. 담허의 걷기·발바닥·카메라가 같은 PC/모바일 16개 비교를 확인했습니다.
- 장 중간의 모션/접지와 카드형 엔딩은 별도입니다. 카드 원본의 모바일 구도, 실제 두 탭 저장 중복 방지 및 세이브 재개 검수 범위는 본 후보에 포함되지 않습니다.

## 상태

실제 레이아웃·규칙이 가짜로 쉬워지지 않는 것과 보기 좋은 것은 별도로 판정합니다. 같은 위치의 전후 렌더 비교는 근거이지, 최종 사용자의 미술 판정, 전체 프로그램 브라우저 완주, 정식 캠페인 합격을 대신하지 않습니다.
