## 공통 출고 조건

같은 정상 프로필에서 5막 엔딩부터 네 사람이 실제로 6막을 끝내고 저장을 복원하는 PC·모바일 앱 증거, 승인된 시안에 준하는 후반 압도감, 초·중·후기 적 반복 문제 거부, 앱을 새로 열었을 때 장·파티·장비·골목 좌표의 올바른 경로, 1~5막 저장·진행/원본 회귀 없음. 여러 고정 시드와 서로 다른 전술을 확인하고, 전후 수치와 대표 스크린샷이 함께 있어야 합니다.

공식 격리 브라우저 근거: 5막 끝→6막 1장 run 45426735626, 6막 1→3장 strict 지형 run 45429906923. 두 독립 케이스로, 정식 캠페인 5막부터 6막 끝까지 한 번에 끝났다는 의미가 아닙니다.
