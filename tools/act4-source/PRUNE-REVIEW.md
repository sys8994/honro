# 미사용 4막 자산 경량화 후보

원본 48c4c4…는 90,192,828바이트, 자산 286개다. 전체 40장 설정과 현재 runtime/map 코드, 유지 자산의 내부 참조를 추적하고 이전 저장용 act4compat 제공자를 보존했다. Python 사전 후보는 190개/31,733,190바이트를 제외해 58,459,638바이트, 자산96개였다. 새 미술을 단순화하거나 노드를 없앤 것이 아니라 사용하지 않는 이전 자산만 제외한 수치다.

로컬 비교에서 전체40장 컴파일 결과가 변경 전후 동일했고 31장 설계 지문도 같았다. 공유 도구 prune-unused.mjs는 실제 로드된 프로젝트와 입력 원본이 일치하는지 확인한 뒤 동일 검사를 수행한다. 아직 운영 원본에 설치하거나 배포하지 않았다. 이전 저장 호환과 실제 빌드 확인 뒤에만 반영한다. 원본 이력 강제 삭제는 하지 않는다.
