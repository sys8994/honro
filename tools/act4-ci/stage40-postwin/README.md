# 6턴 승리 뒤 재로드 비교 진단

입력은41280269841 실행에서 정상 전투→호송→승리→쉼터 이동 직후 실제 localStorage를 읽어 보존한 기록이다. 새로 만든 완료 상태가 아니다. 전체6턴·적4명 처치·아군4/주민4생존·필수11대사·13/11/2 집계·낙수0회까지 실제로 진행됐다. 같은 실행의 승리 후 재로드에서 profile projection 불일치가 발생했으나 기존 검사기가 before/after 필드를 저장하지 않아 원인은 아직 미확인이다. 그 실행은 전체 검수 실패로 유지한다.
