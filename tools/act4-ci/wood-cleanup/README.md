# 38장 목재 경계 정리

아직 배포하지 않은 비교 후보다. 원래 BODY의 바위 경로·흰 문자 표식·보행면·충돌·적·주민·이벤트는 그대로 둔다.

## 폐기한 방법
- 별도 목재 추적 겹을 제거하면 계단형 테두리는 없어지고 약1.14MB 줄지만 목재의 갈색·매듭·접합 표현까지 줄어든다. 실제 게임 비교41278550491을 확인한 뒤 채택하지 않았다. `359661be`는 미배포 후보로만 보존한다.
- 흰 바탕색만 바꾸는 방법은 픽셀 계단형 내부 경계를 남겼다. 원래 경로를 복제해 갈색을 덧칠하는 방법도 잔여 경계·중복 렌더 비용 때문에 폐기했다.

## 새 후보
기존 목재12개 색 경로와 알파 마스크를 그대로 추출해 실제 Inkscape1.4 path-simplify를 적용했다. threshold0.0003/0.0006/default를 각각 원본에서 비교했으며0.0006 후보를 선택했다. default는 곡선 변화가 커서 제외했다. 목재 난간·보·못/매듭·접합을 실제 확대 이미지에서 확인했으며 각 색 경로의 subpath 개수는 모두 유지됐다. 이것만으로 작은 디테일 보존이 자동 승인되는 것은 아니다.

1200×1163 native render 확대 구간 비교: 선택 후보의 실루엣 최대 차이2.236 raster px =0.663 source units, RGB MAE1.010/255. 이 수치는 래스터 관측값이지 해석적 곡선 오차 상한이 아니다. 접촉면 주변의 검사 띠 MAE7.379/255도 별도로 남긴다. 색 단순화 수치로 형상 합격을 대신하지 않는다. 바탕의 불필요한 흰색은 기존 목재 그림자색으로 교정했으므로 이 의도적 색 수정도 비교 수치에 포함되어 있다.

압축 SVG는 실제 Inkscape 출력 원본458,046B를 보존한다. prepare.py는 소스 해시를 확인하고 같은 색 경로/마스크만 연결한다. 각 compound는 기존 엔진 규격에 맞게 순서만 분할하고 한 번의 fill로 유지한다. 보호할 바위/문자 경로 및 모든 게임 지형·배치는 exact equality로 확인한다. 실제 게임 정상/확대 비교를 거친 뒤 채택한다.

## 진행 중인 저장 보존
동일ID의 자산을 덮어쓰면 revision5 진행 중 저장의 서명과 달라져 복원되지 않는다. 미술 수정만으로 전 장을 초기화하지 않는다. 새 입장용 자산ID를 분리하고,기존 `approved38:body`는 원문 그대로 보존한다. 38장 metadata의 `retainedArtAssetIds`를 통해 기존 dependency-closure 로더가 원본 공급자도 읽는다. 숨긴 가짜 배치나 충돌 사물은 추가하지 않는다. 진행 중 저장은 기존 그림으로 계속하고 새 입장부터 정리한 그림을 쓴다.

보존본 때문에 월드 원본 총량은 늘 수 있다. 3.68→3.00MB는 새 활성 자산의 크기이며 전체 저장소 감소로 표현하지 않는다. 공통 경로 문자열은 기존 전송 pool이 공유하므로 실제 신규 장 전송량을 별도로 측정한다. 실제 구버전 UI 저장의 재개·재로드·HP/좌표/지형 동일성을 확인한 뒤 발행한다.

## 확인 결과 — 2026-11-01
- 정상/1.3배 실제 게임 비교41279187575에서 계단형 목재 경계 완화,갈색 재질·기둥/난간/접합/매듭 보존을 직접 확인했다. 별도로 동쪽 상부 목재를 native renderer로 확인했다. 원래 바위와 문자 경로는 바꾸지 않았다.
- 저장 호환 실행41279902381은 정상 UI로 만든 이전38장 저장을 새 자산 빌드에 가져와 재개하고 다시 재로드했다. HP·좌표·라운드·충돌 지형과 원본 BODY 해시 `68043259188b4c37c47d8977ed6f33de865121e90c93dd3a98b340da8e82f265`가 유지됐다. 새 입장은 새ID/새그림을 사용했다. 오류0,지도/막 초기화 없음.
- 엄격한 production build 통과. 신규 활성 BODY3,678,528→2,999,803B. 호환 원본을 포함한 월드 전체는58,499,879→61,499,742B이며 감소가 아니다. 기존 문자열 pool 적용 후38장 자산 묶음은 비압축6,520,024→6,973,611B로453,587B 증가했다. 기존 저장을 버리지 않는 데 드는 보존 비용을 숨기지 않는다.
- 런타임/충돌/전투 변경이 아니므로 새 전체38장 완주로 기록하지 않는다. 이전 상·하부 실제 완주 검증과 이번 미술/저장 검증은 구분한다.
