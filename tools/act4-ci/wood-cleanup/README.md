# 38장 목재 중복 추적 겹 정리

검토 후보이며 아직 배포하지 않았다. 기본 BODY의 원래 Inkscape 추적 경로와 문자 표식은 그대로 둔다. 그 위의 별도 timber 추적 겹은 원래 기둥/난간과 같은 구조를 다시 그리면서 픽셀 계단형 경계와 밝은 테두리를 만들었다.

진단에서 흰 바탕색만 바꾸면 계단형 내부 경계가 그대로 남았다. 원래 경로를 복제해 갈색을 덧칠하는 실험도 경계·렌더 비용 문제를 남겼다. 두 방식은 폐기했다. 후보는 중복 겹과 그 겹에만 쓰는 clip 두 개를 제거한다. 원래 단일 추적 그림의 풍화된 목재색과 매끈한 경계를 보존하며 경로를 새로 그리지 않는다. 바위·흰 표식·보행면·충돌·적·주민·이벤트는 수정하지 않는다.

자산 약3.68MB→2.54MB. 색·외곽은 미술 겹 제거에 따라 바뀌므로 raw→최적화 오차 수치로 포장하지 않는다. 기존 지형과 발판의 접촉, 정상/확대 화면, 원래 표식 유지, 같은 세계의 다른 자산 무변경을 실제로 확인한 뒤 채택한다.
