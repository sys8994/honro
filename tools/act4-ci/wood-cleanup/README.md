# 38장 목재 경계 정리

아직 배포하지 않은 비교 후보다. 원래 BODY의 바위 경로·흰 문자 표식·보행면·충돌·적·주민·이벤트는 그대로 둔다.

## 폐기한 방법
- 별도 목재 추적 겹을 제거하면 계단형 테두리는 없어지고 약1.14MB 줄지만 목재의 갈색·매듭·접합 표현까지 줄어든다. 실제 게임 비교41278550491을 확인한 뒤 채택하지 않았다. `359661be`는 미배포 후보로만 보존한다.
- 흰 바탕색만 바꾸는 방법은 픽셀 계단형 내부 경계를 남겼다. 원래 경로를 복제해 갈색을 덧칠하는 방법도 잔여 경계·중복 렌더 비용 때문에 폐기했다.

## 새 후보
기존 목재12개 색 경로와 알파 마스크를 그대로 추출해 실제 Inkscape1.4 path-simplify를 적용했다. threshold0.0003/0.0006/default를 각각 원본에서 비교했으며0.0006 후보를 선택했다. default는 곡선 변화가 커서 제외했다. 목재 난간·보·못/매듭·접합을 실제 확대 이미지에서 확인했으며 각 색 경로의 subpath 개수는 모두 유지됐다. 이것만으로 작은 디테일 보존이 자동 승인되는 것은 아니다.

1200×1163 native render 확대 구간 비교: 선택 후보의 실루엣 최대 차이2.236 raster px =0.663 source units, RGB MAE1.010/255. 이 수치는 래스터 관측값이지 해석적 곡선 오차 상한이 아니다. 접촉면 주변의 검사 띠 MAE7.379/255도 별도로 남긴다. 색 단순화 수치로 형상 합격을 대신하지 않는다. 바탕의 불필요한 흰색은 기존 목재 그림자색으로 교정했으므로 이 의도적 색 수정도 비교 수치에 포함되어 있다.

압축 SVG는 실제 Inkscape 출력 원본458,046B를 보존한다. prepare.py는 소스 해시를 확인하고 같은 색 경로/마스크만 연결한다. 각 compound는 기존 엔진 규격에 맞게 순서만 분할하고 한 번의 fill로 유지한다. 보호할 바위/문자 경로 및 모든 게임 지형·배치는 exact equality로 확인한다. 실제 게임 정상/확대 비교를 거친 뒤 채택한다.
