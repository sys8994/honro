# 직접 수정 후 GitHub CI 검증

- 이 경로는 작성된 스크립트를 GitHub Actions에서 실행한다. Codex 작업을 생성하거나 재개하지 않는다.
- ff30007a57341e6fc9dcf16c59af0970b92f1a41: 실행 41257873385에서 고정 의존성 설치, 타입, 관련 모델, 접지/보행 경사 구분, 기존 배포 가드, 기본 진입, 34장 저장 복원·물 복귀·재진입 검증이 통과했다. 4막 전체 합격이나 master 배포를 뜻하지 않는다.
- 31장 전체 플레이는 기존 입장 프로필을 초기 주입한 독립 세션이다. 앞선 30장을 자연 진행한 증거가 아니다. 전투 중 위치·HP·완료 플래그는 수정하지 않는다.
- 전투 계획에 런타임 탄도 예측을 읽으므로 도구 보조 플레이로 보고한다. 사람의 클리어 확률로 환산하지 않는다.
- 승선은 실제 동행 선택·이동·점프·하강·상호작용 입력으로만 검증한다. 이동 실패와 전투 난이도 실패를 별도 로그로 구분한다. 시간/라운드 초과는 실패이며 강제 승리로 넘기지 않는다.
- 자동 결과가 성공해도 그림의 미술 검수 통과로 취급하지 않는다. 실제 출력 스크린샷을 직접 확인한 뒤 관찰 근거를 기록한다.
- 저장 스냅샷은 압축하고 대표 화면만 남긴다. 전체 프로젝트 초안은 CI 산출물에 넣지 않는다.

31장 직접 CI 첫 전체 플레이(41258727310)는 실패다. 20라운드 뒤 적 3명(총 421 HP)이 남고 설오는 10라운드에 사망했다. 40회 발사의 각도 오차 >3° 및 위력 오차 >0.05는 각각 0회였다. 반면 7라운드 설오가 x3117→4784로 단독 전진했고 9라운드에는 x5919에서 집중 피해를 받았다. 낮은 HP만으로 반복 방어한 입력이 18회였다. 따라서 조작 오류/난이도 초과로 단정하지 않고, 안전 사격이 있을 때 반복 방어하지 않는 전술과 원거리 동행의 단독 선행 제한을 별도 비교한다. 적 수·체력·피해 및 맵은 그대로 둔다. 이후 파티 사망 시 해당 4인 생존 검증은 즉시 실패로 보존해 무의미한 반복 시간을 줄인다.
