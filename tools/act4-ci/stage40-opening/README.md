# 40장 첫 교전의 입력·전술 진단

기존15턴 완주의 첫 전투11턴에는 친군 오폭,동쪽에 휘겸만 보낸 전술,선반에서 떨어지는 S06,재이동이 포함되어 있었다. 이를 적 HP가 높다는 이유로 단정하지 않는다.

이번 진단은 기존 보존40장 기록을 실제 UI로 가져오고 전투 처음부터 재시작한다. 플레이어 성장·장비·적 HP·배치·지형·승리조건은 바꾸지 않는다. 준비된 캠페인 기록이며 자연1–39 연속 플레이는 아니다. 담허와 휘겸이 동쪽 사선을 확보하고 설오와 소단은 서쪽 적을 우선 대응한다. 기존31장 검증에서 사용한 읽기 전용 궤적/친군 위험 예측과 실제 키·게이지 입력을 사용한다. 낙하를 유발했던 S06은 이 전술에서 선택하지 않는다.

4적 교전 종료만 검사한다. 참고 목표는4턴 이내,진단 관측은 최대8턴이며 전체 호송 완주 또는20턴 게임 합격으로 바꾸어 부르지 않는다. 조작 오차·낙하·방어·행동별 HP를 남겨 입력/전술/적 수치의 원인을 구분한다. 결과를 본 뒤 필요한 부분만 수정한다.

41278792070은 동일한 적/장비로 첫 교전을6턴·12발사·아군/주민 전원 생존으로 끝냈다. 참고4턴에는 미달이다. 이전11턴과 비교해 HP/배치 수정 없이 전술 차이만으로 크게 단축됐다. 첫 설오 발사의 실제 게이지는83.3%,계획77.0%여서 빗나갔다. 또한 이동 시도7회 제한이 이동력을 남긴 채 턴을 소비했고,상부 궁수의 x만 쫓아 아래쪽에서 왕복하는 입력 문제가 있었다. 이 결과를 적 수치 문제로 단정하지 않는다.

후속 정책은 실제 지형의 동쪽 계단과 합류 지점을 따라 상부 사선으로 올라가며,남은 이동력을 쓰고,1,500거리 밖의 불안정한 장거리 사격 대신 접근한다. 결과 종료 시 실제 저장 원문을 압축 보존한다. 실측 기록 없이 재구성한 완료 세이브는 만들지 않는다.
