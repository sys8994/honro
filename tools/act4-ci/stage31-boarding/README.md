실제로 34명을 처치한 13라운드 직후의 localStorage 읽기 스냅샷이다. 원래 프로필의 앞선 캠페인 완료는 합성 입장 조건이므로 1~30장 자연 진행으로 주장하지 않는다. 네 동행은 아직 배에 올라 있지 않다. inputs.json은 같은 실제 실행의 interactive-key/hold/wait 기록을 E 승선 입력까지 추출했다. 이후 전투/목표 상태를 강제로 바꾸지 않고 실제 UI 가져오기·계속·키 입력으로만 검사한다.
