# 40장42명 후보 실제 입력 진단

기존에 보존한40장 항해 기록을 정상 UI로 가져온 뒤 맵 revision에 따른 정상 재시작으로 신규 편성에 진입한다. 이전39장까지의 성장·장비·사건 증거를 그대로 사용하며 HP/좌표/처치/승리 상태를 주입하지 않는다. 원래 프로필의 준비 수준도 결과 해석에 포함한다. 새1–39장 연속 완주나 일반 플레이어 성공률 표본으로 부르지 않는다.

목표:42명/1주요/2중간보스 실제 진입, 정상 입력으로 전투→귀환→정산→같은 컨텍스트 재로드. 읽기 전용 탄도 예측과 키·충전 입력은 도구 보조 정책이며 인간 난이도 추정이 아니다. 만조/보스 상태/아군·주민/이동 지지면과 실패 저장을 보존한다.

20라운드 초과는 통과하지 않는다.24라운드 또는40분 관측 상한은 실패 자료를 남기기 위한 자원 한도이며 실패를 숨기는 중단 규칙이 아니다. 기존4명용8라운드 테스트/동쪽 선반 특례를 사용하지 않는다. 하단 귀환은 출항 계단→선착장→진입 계단→해안 순으로 실제 이동한다. 전체 경로 성공은 아직 미확인이다.

후속 입력 정책 교정: 좁은 아래점프 진입 지점을550ms 고정 보행으로 지나치지 않도록 남은 거리로 입력 시간을 제한한다. 사격 후보는 x거리 상위4체가 아니라 실제 거리 내 보이는 후보를 검토한다. 공격 전 미관측 경고의 표적을 실제 미니맵 입력으로 확인한다. 귀환은 한 영웅씩 보내며 다른 영웅의 이동을 방어로 버리지 않고, 매 아군 턴 가능한 생존 동행 모두를 이동한다. 주민4명은 전원 생존 필수이며 영웅 사망과게임패배를 혼동하지 않는다. 진행 중 이전 정책 실행은 별도 진단 자료로 보존하며 새 정책 결과로 바꾸지 않는다.

첫 실제진단41354740770:25R 관측 종료,41발사,42명 중11명 처치,아군3명 사망,주민4명 생존,주요보스 미교전. 실패 보존.1R 설오가 앞쪽 적을 지나2340까지 전진했고 담허가 아래층을 노리며 동행이 분산됐다. 소단은 남은 적31명 상태에서 반복 공격했다. 이 결과만으로 게임 난이도 과다를 확정하지 않는다.

동일 HP/공격/장비의 후속 정책은 휘겸을 먼저 움직이고 같은 지지면 위협을 우선한다. 앞 적을 지나쳐2660을 향해 걷지 않으며, 근접 동료220범위라는 일괄사격금지 대신 기존 실제 탄도·친군피해 판정을 사용한다. 휘겸의 응수세도 조건부로 사용한다. 수치 밸런스 조정 전 이 비교를 분리한다. 첫 진단에서 만조는5–6R로 보스 교전 전에 지나갔으므로 해당 기믹 문제도 별도로 수정·재검증한다.
