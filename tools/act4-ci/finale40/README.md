# 40장42명 후보 실제 입력 진단

기존에 보존한40장 항해 기록을 정상 UI로 가져온 뒤 맵 revision에 따른 정상 재시작으로 신규 편성에 진입한다. 이전39장까지의 성장·장비·사건 증거를 그대로 사용하며 HP/좌표/처치/승리 상태를 주입하지 않는다. 원래 프로필의 준비 수준도 결과 해석에 포함한다. 새1–39장 연속 완주나 일반 플레이어 성공률 표본으로 부르지 않는다.

목표:42명/1주요/2중간보스 실제 진입, 정상 입력으로 전투→귀환→정산→같은 컨텍스트 재로드. 읽기 전용 탄도 예측과 키·충전 입력은 도구 보조 정책이며 인간 난이도 추정이 아니다. 만조/보스 상태/아군·주민/이동 지지면과 실패 저장을 보존한다.

20라운드 초과는 통과하지 않는다.24라운드 또는40분 관측 상한은 실패 자료를 남기기 위한 자원 한도이며 실패를 숨기는 중단 규칙이 아니다. 기존4명용8라운드 테스트/동쪽 선반 특례를 사용하지 않는다. 하단 귀환은 출항 계단→선착장→진입 계단→해안 순으로 실제 이동한다. 전체 경로 성공은 아직 미확인이다.
