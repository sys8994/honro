# 38장 발판 접합 검토 후보

기존 수정 시도의 문제는 새 바위를 native covered terrain에 등록하지 않아 기본 충돌 그림과 벡터 그림이 겹친 것이다. 이 후보는 기존 지형·기믹을 삭제하지 않고 해당 등록만 올바르게 연결한다. 바위 자체의 새 그림은 생성하지 않았다.

출처: 159b3b615b7e5cae93fd872fb6488e36660d05e5의 stage38-shoulder-organic/04-final.svg 및 stage38-shoulder-covered-candidate.py. 이전 미등록/뒤쪽 레이어 후보는 시각 검수 실패 이력이 있다. 여기 포함한 SVG의 SHA-256은 prepare.py에서 검사한다.

이전 별도 물리 진단에서 왼쪽 접근 두 번 점프로 올라갈 수 있었다. 오른쪽에 있던 이전 저장 위치에서의 접근과 자연스러운 접합, 새 정상 입장 플레이는 아직 합격하지 않았다. 기존 저장을 임의 이동/변경하는 마이그레이션은 하지 않는다.

현재 통합 원본(48c4c4…)에 적용한 후보는 bb68162f…이다. CI의 이전/이후 화면은 실제 게임의 카메라만 이동해 캡처한다. 캡처 성공은 미술 합격이나 플레이 성공이 아니다. 직접 이미지 검수 후 통과/실패를 별도로 적는다.
