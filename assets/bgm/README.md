# 혼로 배경음

음원 파일명은 `코드_장소_곡명.mp3` 형식이다. 곡 코드와 표시 제목, 장소, 음원 해시는 [곡 목록](../../shared/data/bgm.json)에 있다. [장별 악곡표](../../shared/data/bgm-stages.json)는 1막 1장부터 6막 10장까지 통산 장 번호 1–60을 쓴다. 게임 우하단에는 실제 재생 중인 파일의 곡명이 표시된다.

| 장소 | 코드와 곡명 |
|---|---|
| 메인 | 01 혼로 |
| 연목 | 11 고갯마루 · 12 물그늘 · 13 그림자밟기 · 14 살풀이 |
| 동굴·잠운사 | 21 돌문 · 22 산울림 · 23 숨은 물길 · 24 넋전 |
| 강변 읍성 | 31 저잣거리 · 32 먹자국 · 33 빗장 |
| 해안·저문골 | 41 뱃노래 · 42 밀물 · 43 빈 고샅 |
| 산성·귀림 | 51 봉홧불 · 52 꽃상여 |
| 하늘우물 | 53 두레박 · 54 물이 하늘로 간다 |
| 무명사 | 61 산문 · 62 빈 종터 · 63 뒤집힌 처마 · 64 이승 저승 · 65 파계 |
| 마지막 전투·천도 | 66 가름진 · 67 길닦음 |
| 엔딩 | 99 마중 |

## 재생

- 장에 들어가거나 재도전하면 시작곡(E)을 처음부터 재생한다. 곡이 끝나면 F 목록에서 E 바로 다음 곡으로 넘어가고, 목록 끝에서는 처음으로 돌아간다. 한 곡만 있는 천도 장에서는 같은 곡을 반복한다.
- 1막 10장은 소단의 바깥 주박이 깨지면 14를 반복한다. 6막 8장은 대도사 등장부터 대도사와 술법 유지점이 모두 쓰러져 전투가 끝날 때까지 65를 반복하고, 이후 장의 목록으로 복귀한다.
- 타이틀·휴식터·여정·오프닝과 1–5막 엔딩은 01을 사용한다. 6막 마지막 장의 천도는 67, 엔딩 스틸컷은 첫 컷부터 별도 파일 99를 사용한다. 스틸컷이 더 길면 곡을 반복하고 마지막 화면에서 페이드아웃한다.
- 곡을 하나씩 스트리밍한다. 같은 장의 ESC·대화·결과창·설정·훈련 재구성은 곡을 넘기지 않는다. 첫 재생 25ms 램프, 곡 교체 420ms 크로스페이드, 탭 숨김 정지, 배경음·효과음 독립 설정과 묵종 감쇠를 유지한다. 6막 스틸컷은 기존 전용 재생기가 화면 전환과 마지막 페이드를 맞춘다.

## 음원·엑셀 갱신

사용자가 지정한 원본 폴더 안의 MP3와 엑셀을 코드로 대조한다. 새 음원의 표지·텍스트 태그와 인코더 표식을 지우고 실제 음악 프레임을 보존한다. 파일명 끝의 제목과 곡 목록의 제목을 맞추고 정리된 파일의 Git blob을 기록한다. 01과 99는 내용이 같아도 서로 다른 역할과 경로를 유지한다.

엑셀의 막·장으로 통산 번호를 계산하고 E·F·G를 순서대로 대조한다. 바뀐 음원, 제목, 장별 행만 수정한다. G의 발동 조건이 달라지면 해당 게임 이벤트와 연결하고, 빌드한 게임에서 진입·곡 끝·이벤트 전후를 확인한다.
