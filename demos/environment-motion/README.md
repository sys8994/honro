# 계곡의 숨 · 환경 모션 독립 시안

실행 경로: `demos/environment-motion/index.html`. 저장소 루트에서 `python3 -m http.server 8000` 후 `http://localhost:8000/demos/environment-motion/`을 연다. 빌드·설치·외부 라이브러리는 필요 없다. 게임 코드·엔트리·캠페인·저장에는 연결하지 않는다.

정지 WebP 한 장 위에 작은 투명 Canvas 8개를 배치한다. 나무·바위·기둥·강둑·원경·안개는 정지 이미지다. 수면·폭포의 정지 원화 위에 같은 위치의 작은 물 표현만 갱신한다. 화로와 기둥에는 원래 불·천이 없어 이중 형상이 생기지 않는다.

| 효과 | 방법 | 작업량 상한 / 원본 좌표 크기 |
| --- | --- | --- |
| 수면 | 반사 crop을 시작 시 캐시하고, 물 안쪽 고정 마스크에서 3px 가로 띠를 최대 약 2px 옮김 | 61개 띠, 반짝임 8개 / 1062×182 |
| 폭포 | 고정된 좁은 물줄기 마스크에 세로 질감 두 장을 순환 이동 | 질감 64×192, 작은 물보라 7개 / 104×218 |
| 불 | 유기적 곡면 3개와 작은 내부 밝기 변화, 캐시된 광원 alpha 변화 | 불티 10개, 광원 캐시 140×140 / 200×146 |
| 깃발 | 시작 시 만든 해진 천 질감을 세로 12개 띠로 분할, 고정부 변위 0에서 끝으로 증가 | 정적 질감 144×164 / 양쪽 바람 공간 340×220 |
| 풀 | 뿌리가 고정된 곡선, 공통 바람에 군락별 위상 차이 | 4군락×9줄기 / 145×105, 135×105, 145×130, 105×90 |

수면·폭포의 흐름과 불은 무풍에서도 지속한다. 깃발·풀은 무풍에서 정지하며, 깃발·풀·불티는 같은 부호의 바람을 사용한다. 슬라이더는 -1..1이다. 효과별 끄기는 마지막 프레임을 보존한다. 전체 정지와 재개, 크기 변경에서도 마지막 시간과 바람을 보존하며 숨겨진 동안의 시간을 따라잡지 않는다.

RAF 루프는 30fps 상한과 deltaTime을 사용한다. 화면 밖(`IntersectionObserver`), 숨긴 문서(`visibilitychange`), 전체 정지, 효과 5개 모두 끄기에서 RAF를 취소한다. `prefers-reduced-motion`이면 기본 정지하며 명시적인 전체 재생은 허용한다. DPR은 최대 1.5, 실제 표시 크기로 Canvas를 축소한다. 전체 배경 재그리기·pixel readback·화면 전체 filter/blur·프레임별 노이즈·유체 시뮬레이션은 없다.

## 비용과 실측

- 요청 파일: WebP 282,404 bytes(275.8 KiB), HTML/CSS/JS 합계 19,884 bytes(19.4 KiB). 폰트·런타임 외부 요청 없음. 배경 생성은 1회이며 실행 중 생성 서비스 호출이나 별도 서버 연산은 없다.
- 원화 1672×941 디코드 RGBA 환산 약 6.0 MiB. 준비 캐시 합계 248,788px, RGBA 환산 약 0.95 MiB. 브라우저의 추가 복사·GPU 메모리는 별도다.
- 최대 표시 폭 1440px·DPR 1.5일 때 Canvas 합계 약 64만px 이하, RGBA 환산 약 2.5 MiB 이하. 실제 갱신 면적은 마스크가 더 좁으며 아래 수치는 투명 여백을 포함한 전체 Canvas 크기의 합이다.

2026-10-18, Linux x86_64 / AMD EPYC 9V74 / Headless Chromium 154.0.8037.57, 효과 5개 활성, 바람 +0.35. `performance.now()`로 효과 그리기 호출만 측정했다.

| 실행 조건 | 표본 | CPU 평균 / p95 | Canvas 합계 |
| --- | --- | --- | --- |
| 데스크톱 1440×1040, DPR 1 | 126 프레임 | 0.331 / 0.400 ms | 253,144px |
| 모바일 크기 390×844, DPR 3 → 1.5 제한 | 77 프레임 | 0.292 / 0.500 ms | 39,779px |

데스크톱은 화면 녹화 중 측정했다. 모바일은 같은 데스크톱 CPU의 viewport 에뮬레이션으로 실제 휴대폰 성능 측정이 아니다. GPU·브라우저 합성·최초 이미지 디코드 비용은 포함하지 않는다. 페이지의 접힌 성능 패널은 최근 최대 180개 실제 표본의 CPU 평균/p95, 활성 효과 수, Canvas 픽셀 수만 표시한다. 시간 계측 오버헤드와 환경에 따라 수치는 달라진다.

## 확인과 제약

- 데스크톱 및 모바일 세로/가로에서 가로 넘침 없음, 효과별 정지 프레임 보존, 전체 정지, 양방향 바람, 무풍에서 물·불 지속과 천·풀 정지를 확인했다. 효과 Canvas 영역 밖 두 화면의 픽셀은 동일했다. 콘솔 오류 0.
- 화면 밖 일시정지는 실제 IntersectionObserver 알림으로 확인했다. Headless 환경의 탭 가림을 재현하지 못해 문서 숨김은 `document.hidden`을 임시 대체한 `visibilitychange` 분기 확인이다. 실제 모바일 백그라운드/복귀는 미확인이다.
- 검증 자료: `_local/reports/environment-motion/browser-results.json`, `desktop.png`, `mobile.png`, `mobile-landscape.png`, `environment-motion-5s.mp4` (Git 제외). 게임 빌드·전체 verify는 실행하지 않았다.
- 배경은 이번 시안용 ImageGen 정지 원화를 WebP로 변환했다. 지정된 Library 숲·동굴 참고 이미지는 다운로드 오류 후 재시도하지 않았다. 승인된 과거 게임 그림이나 인체·묵종 에셋은 사용하지 않았다.
- 조명은 화로 주변의 작은 광원만 바뀐다. 실제 동적 그림자·물리 천·유체 효과는 구현하지 않았다. 통합 시에는 게임 카메라 좌표와 자산 마스크를 연결하는 별도 작업이 필요하다.

이 브랜치는 검토용이다. master 병합과 Pages 발행은 부모 담당자의 확인 이후 진행한다.
