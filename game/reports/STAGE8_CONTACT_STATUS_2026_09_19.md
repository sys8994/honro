# 닫힌 장례문 끼임과 행동 상태 안내 — 2026-09-19

실행 파일은 [HONRO.html](../../HONRO.html)이다. 새 파일을 열고 **이어하기**를 선택하면 고체 안에 끼인 저장 위치를 복구한다. 처음부터 스테이지를 다시 시작할 필요는 없다.

## 재현한 원인

사용자는 장례문 중간에서 설오와 담허만 이동·공격이 안 되고 다른 동료는 가능했다고 확인했다. 같은 증상을 실제 지형의 밀침으로 재현했다. 사용자 저장이나 정확한 입력 이력은 받지 않았으므로 제보 당시 상태 자체를 분석한 것으로 표현하지 않는다.

기존 충돌 탐침의 가장 낮은 지점은 발 위 5였다. x=7020의 `earth-shoulder-5` 턱에 발끝이 먼저 닿으면 몸 탐침들은 위를 지나가지만 발은 고체로 들어갈 수 있었다. 이어서 고체 내부에 겹친 `spine-5`를 착지면으로 선택했다. 몸은 멈췄지만 노출 지면에 서 있지 않아 발사가 거절되고, 보행도 고체 침투 방지에 막혔다.

| 항목 | 수정 전 재현 |
|---|---|
| 시작 위치 | `(6736.5, 1722)` |
| 밀침 속도 | `(350, -250)` |
| 최초 침투 | 1/120초 갱신의 98번째 단계, 발 깊이 약 4.4 |
| 정지 위치 | `(7293.16, 1703.91)` |
| 해당 x의 노출 지면 | `y ≈ 1645.12` |
| 결과 | 속도 0이지만 `grounded=false`, 이동·발사 불가 |

발끝의 연속 경로를 벽과 검사하고, 묻힌 착지면을 제외했다. 벽에 멈출 때에는 반대 방향으로 빠져나올 수 있도록 기존 몸 탐침 너비만큼 여유를 둔다. 정상 점프·낙하·충격 피해 규칙은 유지한다.

로드 시에는 발이 고체 안에 있는 살아 있는 이동 유닛만 가까운 유효 지면으로 옮긴다. 이전 접촉 보정을 받은 뒤 다시 끼인 저장도 처리한다. 체력·기력·XP·턴·이동력·행동 여부·상태이상을 초기화하지 않는다. 진행 중인 몸체 기예/운반과 유효한 공중 좌표는 유지한다.

## 상태와 행동 제한 표시

- 하단 동행 칩: **기절 / 결박 / 저주 / 완료**를 지속 표시한다. 작은 화면에서도 상태명이 잘리지 않도록 상태가 있을 때 우선 표시한다.
- 기절한 동료 클릭: 이번 턴에 행동할 수 없는 이유를 안내한다. 행동 권한은 그대로 유지한다.
- 하단 설명: 현재 인물의 상태 효과·기간과 기력 부족, 재사용 대기, 공중 이동, 이동력 소진, 공격/턴 처리 상태를 구분한다.
- 기절은 `stunnedRound`로 현재 턴의 행동 상실을 기억한다. 소비된 `stun=0`을 정상 상태로 오인하지 않는다. 결박은 이동 제한이며 공격 금지로 표시하지 않는다.
- 적·동맹 정보 카드도 같은 상태 설명을 사용한다. 예전 저장에서 이미 소비되어 원인이 없어진 기절은 추정하지 않는다.
