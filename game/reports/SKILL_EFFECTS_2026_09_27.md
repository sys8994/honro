# 허공터 연속 사용·파문·번개 후속 개선

2026-09-27. 사용자 후속 요청 5개를 반영했다. 원호파와 팔괘파의 형태는 최초 개편 명세보다 이번 요청을 우선한다. 사용자가 말한 ‘팔각궤’는 현재 게임의 팔괘파(M15)에 대응한다.

## 원인과 공통 구현

허공터의 기존 `resetPractice()`는 기력과 행동권만 복구했으며 비기 재사용 대기는 남겼다. `finishRedesign()`도 허공터에 이탈보의 후속 이동 제한을 적용했다. 수련 종료 경로에서 이 상태들을 정리하고, 캠페인의 재사용 대기·이탈보는 그대로 유지했다. 진행 중인 투사체나 소환 행동까지 취소하지는 않는다.

예상 도형과 실제 파문이 모두 두꺼운 선이었고, 효과 수명이 전투 배속에 따라 짧아졌다. 공통 `geometryPaths()`를 사용하되 표현을 분리했다. 새 파문·명중·번개 효과만 실제 화면 시간으로 수명을 계산하므로 4배속에서도 0.8~0.9초 보이고 일시정지에서는 멈춘다. 피해나 전투 진행 시간을 늦추지는 않는다.

원호파는 원의 중심을 목표 지점에 두고 유닛을 통과하도록 설정되어 있었다. 첫 적/지형 충돌을 사용하고 원의 중심을 반지름만큼 뒤로 이동해 원호 자체가 충돌 지점에 닿도록 바꿨다. 팔괘파의 외곽도 원의 반경 판정에서 팔각형 선분 판정으로 바꿨다. 뇌호·천뢰호는 두 점을 잇는 `inkLine`을 실제 꺾임과 분기를 가진 `lightningBolt`로 교체했다. 시각적 흔들림에는 전투 RNG를 사용하지 않는다.

주요 파일: `shared/engine/src/engine.ts`, `skillMechanics.ts`, `skillVisuals.ts`, `art.ts`, `skillLore.ts`, `skillRedesignData.ts`, `progression.ts`, `types.ts`, `shared/runtime/renderer.js`. 게임·Workshop은 같은 소스로 빌드한다. 생성 HTML은 직접 편집하지 않았다.

## 저장과 검증 범위

저장 스키마·skillRevision 변경이나 성장 초기화는 없다. 캠페인 XP·배분·진행·기존 적의 LA/LM 기예를 보존한다. 이전 버전에서 이미 비행 중이던 원호파의 `phaseMode=all`도 다음 실제 스텝에서 해제하여 새 접촉 동작을 적용한다. 원호파의 효과 설명과 팔괘파의 외곽 설명도 변경된 실제 동작에 맞췄다.

통제된 전투 fixture와 실제 빌드의 입력·그리기를 검사한 결과이며 전 캠페인의 정상 육성·수동 완주를 뜻하지 않는다. 예상 궤적은 조준 당시 전장 기준이고 이후 적의 이동을 확정하지 않는다. 스크린샷의 표현은 Chrome headless에서 확인했으며 실기기별 디스플레이·GPU 체감까지 평가한 것은 아니다. 이전 [7개 후속 개선 보고서](SKILL_POLISH_2026_09_27.md)의 파문 표현은 이번 변경으로 갱신되었다.

최종 게임/Workshop 성능은 각 6조건 모두 기준을 통과했다. 12조건의 관측 렌더 호출률은 54.53~56.52Hz, 평균 렌더 비용은 0.531~1.588ms이며 예열 뒤 캐시 재생성은 0이다. [게임](../../reports/performance-game.json) · [Workshop](../../reports/performance-editor.json).
