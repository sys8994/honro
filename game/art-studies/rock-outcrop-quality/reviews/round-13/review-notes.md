# 독립 암반 미술 연구 — 13차 부모 재검수 후보

**상태: 재검수 후보. 최종 미술 합격·작업 완료로 확정하지 않았다.** 7차는 부모 검수에서 불합격했고, 8–13차에서 형상을 다시 저작하고 실제 Chromium PNG를 열어 검수했다. 원본 7차와 판정은 `reviews/round-7/review-notes.md`, `reviews/final-assembly.png`에 보존한다. 최신 전체 화면은 **`reviews/round-13/assembly-normal-and-30pct.png`**다.

## 부모 지적에 대한 교정

| 지적 | 이번 변경 | 실제 픽셀 확인 |
|---|---|---|
| 세 모듈이 같은 사선 판석/박리 배열을 공유 | 기존 BEDS/공통 윤곽 생성기를 폐기. A·B·C의 큰 암면·밝은 면·그림자 면을 별도 좌표로 저작 | 정상/30%에서 수평 턱, 수직 함몰, 사선 매몰 사면을 구분 가능 |
| 같은 세 돌 퇴적 주머니 | 공통 주머니 삭제. A는 침식턱, B는 함몰 하단의 단일 흙 퇴적, C는 오른쪽 사면의 크기·형태가 다른 각석 | 동일한 주머니가 세 모듈을 따라 반복되지 않음 |
| 얇고 매끈한 갈색 테두리 | 폭을 가진 토양 상면, 아래로 덮이는 흙 혀, 상면을 뚫은 돌, 암면에 걸린 피복 | 토양-암면 경계에서 앞뒤 가림 확인 |
| 같은 세 가닥 풀 | A의 낮은 소군집, B의 한 절리 주변, C의 더 넓은 비대칭 군집을 별도 저작 | 식생의 위치·폭이 다름. 모든 판석에 식생을 붙이지 않음 |
| 선 같은 접촉틈/동일 명암 | 폭이 변화하는 undercut/공동/매몰 면을 채워진 Path로 저작. B의 공동 안에도 어두운 암면과 돌출 턱 추가 | 선 대신 면으로 깊이 표현. 광원은 위/왼쪽으로 통일 |
| 축소에서 벽지 같은 반복 | 구조 방향 자체를 다르게 만들고, A에는 수직으로 남은 침식 핵, B에는 넓은 우측 덩어리, C에는 하단 횡방향 낙석 추가 | 30% 조합에서도 서로 다른 구조로 남음 |

미술상 남는 판단점: 아직 사실적인 원화보다 각진 벡터 양식이 강하다. B의 큰 함몰이 동굴 입구로 읽히는지, A의 수평 층리가 과하게 정렬되어 보이는지, C의 판석 리듬이 충분히 자연스러운지는 **부모의 실제 픽셀 재검수에서 확인할 항목**이다. 크기/path 수나 캡처 횟수로 합격을 대신하지 않는다.

`gzip.compress(..., mtime=0)` 측정. 크기/path 예산을 먼저 정하지 않았다. 7차 반복 생성 패턴을 폐기하면서 구조가 달라졌고 경로 수도 달라졌다. 모두 순수 SVG. XML 파싱 성공, image/base64 없음, 래스터 내장·노이즈 필터 없음.

저작: `python author.py 13`. 좌표 소스는 `author.py`, `surface_planes.py`, `finish.py`, `weathering.py`. 검수: 이 폴더에서 `python -m http.server 8732 --bind 127.0.0.1`, 다른 셸에서 `python capture.py 13`. Python Playwright와 `/usr/bin/chromium` 사용. deviceScaleFactor=1, img CSS 720×460, 작은 패널 transform=0.3. H 표식은 에셋 바깥의 검수 HTML에만 있다.

변경은 이 디렉터리 내부만. 런타임·게임 데이터·빌드·기존 에셋·master·Pages는 변경하지 않았다. 브랜치 `art/rock-outcrop-quality-20261020`.

이 추가 작업에서 권한 거부·실행 불명·남은 캡처 차단은 없다. 최초 작업의 CDN 다운로드 HTTP403 및 file:// 차단은 이전 기록에 있으며, 설치된 Chromium+로컬 HTTP 검수로 캡처가 가능했다.
