# 암반 교정 — 16차 재검수 후보

**최종 미술 pass 및 공개 배포는 보류 상태다.** 부모가 13차에서 확인한 “B의 고리형 동굴”과 “균일한 밝은 facet 띠”를 교정했다. 14·15·16차를 각각 렌더링하고 실제 PNG를 열어 확인했다. 13차 에셋/캡처는 `reviews/round-13/`에 보존되어 있으며 주 작업의 preview 통합 여부를 이 작업에서 변경하지 않았다.

## 이번 교정

- **B:** 기존 상부 고리·안쪽 고리·빈 중앙을 불투명 암반 면으로 덮어 교체했다. 중앙 오른쪽으로 치우친 폭이 다른 절리를 남기고, 위 왼쪽에서 내려온 토양과 오른쪽 아래의 넓은 퇴적물이 절리 일부를 가리게 했다. 내부에 밝은 면이 닫힌 고리를 만드는 구성을 제거했다.
- **A/B/C:** 선택한 16개 주 암면의 밝은 영역을 별도 Path로 재저작했다. 일부는 넓은 마모면, 일부는 좁게 남은 입술, 일부는 중간에서 끊기는 면으로 변경했다. 단순 불투명도나 색 변경만으로 띠를 가린 것이 아니다.
- **국소 가림:** A·C 일부 암면을 얇은 흙 퇴적면으로 가렸다. 14차의 둥글고 떠 보이는 흙 덩어리는 15차에서 얇게 줄이고 지지 턱에 맞췄다. 16차에서는 B 상단의 이중 테두리와 C 상부 흙 덩어리를 정리했다.
- **범위:** viewBox 720×460과 세 모듈의 구성 역할·파일 이름을 유지했다. 런타임, preview 통합 코드, 게임 데이터, 빌드, 기존 에셋, master, Pages는 수정하지 않았다.
