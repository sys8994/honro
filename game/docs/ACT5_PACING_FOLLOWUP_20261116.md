## 원인과 검증 범위

- 4장 기준판은 양쪽 발판에서 어느 한 지정 무리를 처치하면 실제 동행의 통과 위치 없이 합류 목표가 열렸다. 상로 직접 표본에서 첫 수목귀를 제압하자 다음 뿌리의 수의귀가 HP 1,106인 상태로 합류턱을 가리켰다. 10장 14R 기준 재실행에서는 조망·낮은 석교·문턱귀 목표가 모두 5R에 시작했다.
- 6장 20R 중 일부는 이전 입력 정책의 밧줄 거리 판정으로 생겼다. 밧줄에 충분히 가까워지기 전에 현 목표 옆 전위를 계속 공격했다. 밧줄까지 실제로 걸어가는 정책으로 기준판을 다시 돌리니 주경로 12R, 견제 경로 11R이었다. 이 보정과 동쪽 왕복 밧줄의 효과를 구분한다.
- 8장 기준판의 14R과 22R은 처치 세 기 차이만으로 해석할 수 없다. 첫 진목 도달부터 6R과 11R이었고, 두 번째 진목 전에 접근과 공격 선택도 달랐다.
- 구판 9장 출구는 실행 데이터에서 두 동행, 마지막 생존자 한 명의 예외다. 그 인원·위치·판정은 이어 사용한다. 밧줄과 새 편성은 해당 장의 신규 전투에 적용한다.
- 표준 난도, 장 입장 XP(25레벨), 합법 SP와 능력치 12회, 정식 장착 기예, 네 동행, 소모품 미사용의 별도 Chromium 전투다. 입력 정책 완주는 구·신판에 같은 기본 규칙을 사용했다. 10장 회복·돌파는 회생진목/회풍참을 장착한 별도 합법 전술이다. 아래 직접 입력·혼합 표본과 이전 사용자 직접 플레이는 별도 기록이다.

## 직접 입력과 타격 근거

- 4장 위 뿌리는 공개판과 후보에서 같은 시작을 잡았다. 실제 Ctrl+D로 네 명이 상층에 올라갔고 같은 수의귀에 휘겸 S02 직격 984, 등불에 설오 A03 직격 293+91, 담허 M13 직격 385를 관측했다. 후보는 수목귀와 첫 길목을 넘긴 뒤 R3에 표식이 x415→x679로 바뀌었다. 새 길목의 수의귀에 소단 O02로 HP 1,106→363, 산개에 휘겸 S03 직격 923을 확인했다. 위 길을 확보하자 R4에 합류턱 목표가 생겼고 아래 골 적이 남았다. 직접 표본은 R5 합류턱의 수의귀를 담허 기파로 마무리하고 공통 고갯길 목표와 증원 예고가 나오는 데까지다.
- 10장 자연스럽게 예고가 발생한 11R부터 직접 입력했다. 휘겸이 실제 키로 돌진선 끝 x818→872(1024폭 시안 기준)로 나가자 그 돌진의 추가 피격이 없었다. 다음 턴 설오 A07을 각도 키·충전 후 발사해 빈틈에 실제 직격 1,905+238, 문턱귀 HP 2,539→396을 관측했다. 이 구간 전후의 정산 통계는 입력 정책 표본 쪽에 기록했다.
- 1장 호송 중 소단 D·F 이후 도식이 같은 R에 전진했다. 2장 Ctrl+D로 성책 발판에 올라 소단 O05로 군북을 한 발에 부쉈다(243+212). 증원 없이 세 명을 대피시켰고 정산을 복원했다. 3장의 정상 흐름에서 소단의 분리 버튼으로 3→4단계가 진행됐다. 별도 준비 상태에서 가까운 수의귀가 막는 안내와 제압으로 버튼을 여는 동작도 확인했다.
- 6장 담허는 서쪽에서 아래 석단으로 내려갔다가 원래 층으로 돌아왔다(y1932→2640→1932). 새 동쪽 밧줄은 실제 E 입력으로 중간 턱 y3128→윗절벽 y1948, HP 유지, 이동도 150 사용이다. 8장 준비 상태에서는 소단 섭혼부로 살아 있는 도구 옆 제기귀를 제어해 E로 회수했다. 9장의 실제 평사는 하강 구역과 역류 구역에서 각각 아래와 위로 휘었다. 회풍참 추락은 기존 징검길 y4880에서 복귀했다.
- 직격과 주변 피해 차이는 초기 편성 변경 전후 근거로 사용했다. 예를 들어 2장 보조 입력의 ‘직접 겨냥 또는 적이 피해를 가함’ ID가 19→24기였고, 1장은 최종 같은 정책에서 피해 교환 29기 중 7기는 주변 피해만 받았다. 3장은 30기 중 29기가 직접 겨냥되거나 피해를 가했다. 7장의 24기 피해 교환을 새 개편 성과로 합산하지 않는다.
- 위쪽·아래쪽 4장과 10장 두 전술의 전체 완주는 Chromium 동작·조준 정책이다. 직접 키와 버튼은 위에 기록한 구간이다. 전 장을 처음부터 정산까지 사람이 직접 입력한 표본은 없다. 준비 상태 검사에 사용한 위치·피해 고정은 정량 표본에서 제외했다.

## 저장과 출시

기존 전투 객체의 배치·목표·좌표·HP·성장을 새 값으로 덮지 않는다. 구판 v5 2·4·6·8·9·10장의 격리 세션을 실제 이어하기로 복원했다. 6장은 기억 행사 직후의 바뀐 목표와 기존 30개 밧줄이 그대로였고, 새로 입장한 v6의 32개와 구분됐다. 이전 v4 세션도 6장에서 복원됐다. 해당 장의 명시적 재시도는 새 편성을 사용한다.
