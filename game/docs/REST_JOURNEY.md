# 길 위의 쉼터와 여정첩

## 개정 방향

전투 사이의 기본 화면을 현재 지역의 쉼터로 바꾼다. 이전 장소에서 들어오는 왼쪽 길, 머무는 동행과 모닥불, 다음 장소로 이어지는 오른쪽 길이 한 풍경 안에 이어진다. 자유 이동이나 새 아이템 체계는 추가하지 않는다.

- **모닥불:** 합류한 모든 동행의 기존 능력치·기예·장착 화면을 연다. 특정 인물에게 메뉴 기능을 맡기지 않는다.
- **오른쪽 이정표:** 실제 다음 장소의 이름과 ‘진입’을 표시한다.
- **필수 대화:** 쉼터 도착 시 먼저 자동 시작한다. 기존 첫 길의 대화와 각 장의 인터루드에 있던 설명을 설오의 말로 전달한다. 별도의 전투 전 삽화·서술 화면은 사용하지 않는다. 진행 위치를 저장하며 도중 재개한다.
- **선택 대화:** 필수 대화 뒤 동행을 눌러 듣는다. 아직 합류하지 않은 동행은 보이지 않는다. 이야기를 진행하거나 보상을 얻기 위한 의무 대화가 아니다.
- **여정첩:** 보조 메뉴다. 지상·지하의 지리와 지역 → 장소 → 사건을 구분한다. 현재 위치와 이미 지나온 길을 구별하며 지난 전투를 다시 방문한다.
- **허공터:** 별도의 작은 맥락 메뉴로 유지한다.

## 진행과 저장

새로운 길의 진입, 저장된 전투의 이어서 걷기, 과거 장소 다시 걷기를 구별한다. 단 하나의 진행 중 전투를 다른 전투로 바꿀 때는 이름을 보여 주고 확인한다. 취소는 저장과 화면을 보존한다. 성장·기예·장착 선택과 전투 스냅샷의 기존 분리 계약은 그대로 유지한다. 쉼터 방문은 체력·기력·아이템·경험치를 지급하지 않는다.

각 장의 기존 서술 문단 전체를 쉼터 필수 대화로 옮긴다. 전투의 목표 안내, 카메라 초점이 있는 인물 대화, 현장 사건과 마무리 대화는 기존 전투 트리거를 유지한다. 쉼터에서 전달한 설명을 진입 때 반복하지 않는다. 쉼터를 생략하는 긴급 연결에서는 같은 설명을 전장 위 일반 대화로 전한다. 기존 저장의 진행 중 서술도 별도 삽화 화면 대신 일반 대화로 이어진다. 최초 대사 표시와 읽기 재개는 안정적인 식별자로 저장한다. 완료한 전투를 다시 걸어도 첫 완료 보상을 반복하지 않는다.

현재 20개 장소를 데이터로 관리하고 뒤에 확장할 수 있게 한다. 장소·지역명은 이미 쓰인 이름을 사용한다. 급한 장면은 선택적으로 쉼터를 생략한다. 특히 18 → 19는 같은 묵종 공간의 연속 사건이다. 모든 보스 전투 앞뒤를 일괄 생략하지 않는다. 10장 이후 소단의 합류를 쉼터에서도 반영한다.

## 화면과 접근성

어두운 한국화·수묵담채 계열의 순수 SVG 풍경을 사용한다. 낮은 대비의 큰 산세와 안개, 접지된 나무와 바위, 작은 불빛으로 쉬는 분위기를 만든다. 선택 영역은 실제 버튼이며 키보드·터치로도 접근한다. 좁은 세로 화면에서는 길과 동행 조작을 잘라내지 않고 읽기 순서로 재배치한다. 필수 대화 중 배경 조작을 막고 종료 뒤 선택 영역으로 돌아온다.

## 잔잔한 대기 움직임

네 동행은 전투와 동일한 공통 리그의 idle을 서로 다른 위상으로 재생하며, 고정된 발·클릭 영역 위에서 호흡과 작은 체중 이동을 보인다. v010 네 전신의 전 주기 벡터 경계에 맞춘 공통 canvas 배율 2.21을 사용해 설오 머리·휘겸 갓·담허 지팡이·소단 전신에 여백을 남긴다. 기존 2.5에서의 일괄 프레이밍 조정이며 에셋의 체형·키·인게임 표시 배율은 바꾸지 않는다. 쉼터 전신 표시는 11.6% 작아진다. canvas backing 높이만 늘리는 상단 padding은 현재 flex/object-fit 중앙 배치에서 표시 배율이나 발 위치를 바꾼다. 같은 전신 크기까지 보존하려면 overflow wrapper와 반응형 letterbox 위치 계산을 추가해야 하므로, 이번에는 DOM·발·클릭 배치를 유지하는 측정 기반 공통 fit을 택했다. 모닥불은 불꽃 세 층·불티 세 개·주변 광량을 서로 다른 리듬으로 변화시킨다. 수관·등롱·안개·구름·물결은 기존 SVG 경로의 transform/opacity만 움직이며 카메라 시차나 새 물리는 만들지 않는다.

기존 앱 프레임만 사용하고 별도 rAF/리스너/타이머를 추가하지 않는다. 최대 24Hz, 700px 이하에서 20Hz로 갱신하며 프레임 시간은 60ms로 제한한다. 숨긴 탭은 정지하고 다시 보일 때 건너뛴 시간을 따라잡지 않는다. 동작 줄이기를 켜면 정지 포즈로 그린 뒤 갱신을 멈춘다. 쉼터 이탈은 DOM 참조를 해제하고 선택 대화 이후의 재생성은 시간과 기존 포커스 복귀를 유지한다. 이 표시 시계는 전투 엔진과 저장 프로필에 접근하지 않는다.

## 검증 기준

실제 App의 클릭·저장·불러오기 계약, 최초/반복 도착, 대사 중 재개, 미합류 비노출, 10 → 11 합류, 긴급 연속 진입, 여정첩 선택과 현재 위치의 분리, 전투 교체 확인/취소, 지난 전투 보상, 모닥불 선택의 보존을 회귀 검사한다. Native Canvas/SVG 화면 검수는 브라우저 실제 입력 검수와 구분한다. 두 생성 HTML은 동일 소스로 빌드하며 공개 배포는 별도 단계다.


## 검증 결과 · 2026-10-06

- 통합 오프라인 묶음 45개 통과. 마지막 UI 경계 수정 뒤 쉼터·충전 집중 검사와 두 HTML 빌드를 다시 통과했다.
- 쉼터 14개 시나리오 안에서 20장 설명 전체의 이관·재개·중복 방지, 저장 교체 취소, 결과 화면을 닫은 긴급 연결, 과거 전투 재시도의 복귀 경로를 확인했다.
- 모닥불 저장 51개·성장 예산 14개 회귀 통과. 소단 충전은 실탄 1,008개, 실제 입력 처리 126회와 중단·변경 입력을 확인했다.
- 실제 SVG·동행 벡터를 사용하는 Native 화면 21개를 검토했다. 지하 물길·법당은 열린 밤하늘 대신 동굴 안으로 표현하며 세로·울트라와이드 구도를 포함한다.
- 실제 브라우저 CSS·키보드·터치·성능, 수정된 공개 빌드의 정상 플레이, 최종 미술 승인은 아직 별도 검증 대상이다. 공개 배포는 수행하지 않았다.
