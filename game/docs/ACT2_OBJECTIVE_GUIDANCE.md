# 2막 목표 가독성 보완

2026-10-05. 11–20장의 승인된 공간·그림을 유지하고 현재 행동 안내 두 곳만 보완한다.

## 방어 범위와 중단 이유

기존 안내는 “표시된 범위 안에서 유지”를 요구했지만, 실제 화면에는 목표 중심의 32단위 타원만 있었다. 실제 판정은 발 좌표 기준 반경 680 안의 유효한 동행과 반경 260 안의 적을 구별한다.

- 실선 원은 현재 방어 목표의 `radius`, 점선 원은 `contestRadius`를 그대로 쓴다. 경사에서도 발 좌표 기준의 원이며 지형을 평평하게 가정하지 않는다.
- 필요한 인물, 현재 누적 턴, 방어 중/범위 밖/적 진입 상태를 표시한다. 색과 함께 실선·점선과 글자를 사용한다.
- 화면 배율과 무관하게 선과 글자는 읽을 수 있는 픽셀 크기를 유지한다. 좁은 화면에서는 안내 상자를 화면 안에 제한한다.
- 계산은 읽기 전용이다. 실제 진행·중단·증원·유효 인물 판정은 기존 `HonroAct2.tick` 그대로이며, 가이드와 그 판정의 일치 여부를 검사한다.
- Stage View의 편집용 전체 지도와 기예 미리보기에는 전투 안내를 추가하지 않는다. Playtest는 실제 전투 화면과 같은 경로를 사용한다.

## 사격할 고정점

여섯 파괴 목표는 작고 어두운 매달린 물건으로 보였고 현재 목표 표시가 실제 충돌 형상의 왼쪽 끝을 가리켰다.

- 현재 순서의 파괴 목표에만 실제 충돌 폴리곤의 윤곽선과 고정 픽셀 크기의 모서리 표식을 그린다.
- 설오가 필요한 표적은 이름과 사격 표식을 표시한다. 다른 목표는 공격하여 파괴할 수 있음을 표시한다.
- 목표 카메라·화살표의 가로 초점은 실제 대상의 중앙을 사용한다.
- 파괴하면 표식은 바로 사라지고, 미래 목표와 묵종 본체는 강조하지 않는다. 콜라이더 크기·위치·내구도·피해·필요 인물은 변경하지 않는다.

## 범위와 보존

변경 소스는 `shared/runtime/act2-art.js`와 `shared/runtime/act2.js`의 표시 데이터다. 맵·미션 단계·완료 판정·밸런스·저장 형식·SVG 그림·18/19 공유 공간과 첫 막은 변경하지 않는다. 두 배포 HTML은 공통 소스에서 다시 빌드한다.

## 재현과 검증

- `npm run test:act2:guidance`: 12개 방어 목표의 실제 반경·인물·엄격한 경계·소환/사망/전향·적 진입 판정을 실제 엔진과 비교한다. 여섯 파괴 목표의 충돌 윤곽·중앙 초점·파괴 후 제거, 좁은 화면, 편집/미리보기 제외와 렌더 중 전투 데이터 불변성도 검사한다.
- `npm run capture:act2:guidance -- after`: 실제 공통 `HonroMaps + Engine + HonroScene`의 격리 상태 화면을 Native Canvas로 만든다. 18장 유지/이탈/적 진입, 19장 경사면, 15/18장 사격 목표를 가로 1440×960과 세로 390×844로 촬영한다.
- 전후 비교 시 `HONRO_GUIDANCE_BASELINE`은 기존 체크아웃의 루트를 지정한다. 이 옵션은 두 표시 소스를 기준 버전으로 읽어 같은 촬영 상태를 만든다. 일반 검사에서는 사용하지 않는다.
- Native Canvas의 CJK fallback 차이를 줄이기 위해 촬영용으로 설치된 한국어 글꼴을 지정한다. 다른 환경에서는 `HONRO_KOREAN_FONT`에 로컬 글꼴 경로를 줄 수 있다. 제품의 글꼴 설정을 바꾸지 않는다.
- `npm run verify:offline`: 빌드·타입·기존 오프라인 회귀와 위 가이드 검사를 포함한다.

현재 전투 지형·배치 fingerprint는 기존 10장 정상 엔진 완주 기록과 일치한다. 이번 화면은 현재 목표를 구성한 격리 fixture이며 정상 전투를 다시 완주한 결과로 세지 않는다. 실제 브라우저 DOM/HUD 배치·키보드/터치·Game/Workshop/Playtest 입력과 브라우저 성능은 접근 제한으로 미검증이다. Native Canvas를 브라우저 통과로 기록하지 않는다.
