# 6장 지형 미술 인계 — 비배포 스켈레톤

## 상태와 목적

`tools/stage6-prototype/author.mjs`의 복제 맵 스켈레톤을 작업 기준으로 삼는다. 이는 실험 기준이 고정된 후보이지 최종 게임플레이·저장 합격 지형이 아니다. production build 경로에 연결하지 않는다. 목표는 현재의 큰 반복 삼각 암면을 비대칭의 연결된 계곡 지질로 바꾸고, 서·중·동 세 끊어진 교판의 실제 상면과 지면에 닿은 교각을 명확하게 읽히게 하는 것이다. 새 그림은 충돌·배우 크기·카메라·퀘스트를 결정하지 않는다.

## 고정 지리와 플레이

- Play Bounds는 기존 6600×3800. 새 연속 하부 지면의 x/y 절점은 author.mjs `nodes`가 단일 원본이다: (0,1770), (550,1870), (1250,2050), (1700,2220), (1950,2240), (2350,2550), (3000,3170), (3500,3300), (4100,3270), (4700,3090), (5350,2800), (6600,2450). y는 아래로 증가한다. 범위 밖 단일 확장 지형도 author 함수가 보존한다.
- 하부는 시작→교각귀(x3230 부근)→운반대(x4100)→북문(x6380)의 필수 보행·호송로다. x3385–4100의 얕은 물 후보는 수면 y3270, 실제 컴파일 최대 깊이 약29.5다. 지면의 실제 앞 경계를 가리거나 물을 더 깊은 함정처럼 그리지 않는다.
- 기존 실제 상부 지지선: 서교판 (1320,1980)→(1680,1880)→(2070,1870)→(2350,1900), 중교판 (2810,1810)→(3150,1830)→(3480,1860), 동교판 (4200,1910)→(4650,1970)→(5150,2080)→(5650,2210). 각 선 사이 빈 틈은 실제 단절이며 연결된 새 발판으로 그리지 않는다. 서교판은 진입·엄호 후 서쪽으로 돌아 하부로 내려가는 선택 경로다.
- 현재 비대칭 형상 비교 도면: [skeleton.png](stage-review/stage06-bridge/geography-prototype/skeleton.png). 수치/좌표는 파일 원본을 우선한다. 두 래스터 컨셉 이미지는 스타일 참고만 하며 대칭 그릇형·균등 기둥 반복을 채택하지 않는다.

## 기존 연결과 새 원본

- 현행 authoring은 `shared/build.mjs` → `tools/map-forge/stage6-positioning.mjs` → `tools/act1-vector-production/apply-stage6-candidate.mjs`, BODY 출력은 `shared/data/act1/stage06-body-candidate.json`, 기하 참조는 `tools/act1-vector-production/stage06-body-source.json`이다. 기존 BODY는 옛 지면 해시에 묶여 있으므로 새 지면을 옛 그림에 늘려 맞추거나 source lock을 우회하지 않는다.
- 새 산출물은 층별 편집 가능한 Inkscape SVG 원본(최소 BODY/표면/교각별 의미 분리), 레퍼런스와 사용한 색/접지 기준, `tools/vector-production/import-svg.py`를 거친 비충돌 runtime JSON 및 원본→출력 비교다. 전체 스테이지 이미지 자동 추적을 기본 방식으로 삼지 않는다. 상세 `game/docs/VECTOR_AUTHORING_SOP.md`와 `game/docs/MAP_ART_PIPELINE.md`를 따른다.
- 지면 선 아래에 BODY를 넣고 기존 단일 terrain-domain을 재사용한다. 별도 충돌 폴리곤·더미 바닥·시각으로만 보이는 플레이 발판은 추가하지 않는다. 교각 바닥은 그 x의 새 실제 지면에 닿아야 하며, 각각 다른 길이·비틀림·파손을 가진다. 양쪽 사면의 경사와 암층, 틈과 바위는 비대칭으로 구성한다. 원경 산과 대기는 기존 공통 renderer를 사용한다.

## 필수 확인과 인계

회색 박스 지형의 좌표가 이후 바뀌면 미술을 먼저 고정하지 않는다. 각 단계에서 ① 전체 스켈레톤/배치 ② 실제 게임 카메라의 서교판·교각귀/운반대·동쪽 출구 접지/시인성 ③ 모바일 및 줌/카메라 이동을 서로 다른 실제 화면으로 점검한다. 상부 보행면, 배우 발과 전면 가림, 교각 밑 접지, 수면/지면 경계와 장식의 루트가 충돌과 맞아야 한다. 원본/최종 실제 픽셀 비교와 변경 동작의 정상 입력 플레이를 남긴다. 정량 통과·정적 스케치나 생성 이미지 자체를 미술/게임성 승인으로 기록하지 않는다.

결과 보고에는 편집 SVG와 생성 JSON 위치, 원본 hash·생성 방법, 각 화면과 실제 지지면 확인, 남은 충돌/시각 불일치를 포함한다. 승인 전 master/Pages에 배포하지 않는다.
