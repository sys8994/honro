# 3막 장소 재구성

2026-10-07 사용자 승인: 24장 뒤 A(휘겸·담허)/B(설오·소단) 조사, 25·26 별도 장소, 27 좌우 화재 조치 뒤 중앙 합류. 기존 21 성문·22 다층 기록고의 지형은 이 생성기에서 변경하지 않는다.

## 소스와 적용

`tools/map-forge/act3-location-rebuild.mjs`의 `applyAct3Locations(g, input)`은 호출자가 건네는 최신 프로젝트를 복제하고 23–30만 재작성한다. 1–22는 전체 stage 객체 불변을 검사한다. 기존 캠페인 파일 전체를 다른 브랜치 위에 복사하지 않는다. `HonroObjectiveRevision.author`가 있으면 23–30 범위만 정규화한다.

새 프로젝트에 `design.act3.locationRevision=1`을 저장한다. 그 뒤 production 전체 재생성도 새 장소 생성기로 되돌아오며, 21–22의 최신 caller 계약을 보존한다. 진행 중 battle은 재생성하지 않는다.

## 장소

- 23: 성벽 아래 실제 흙/석조 천장, 두 수로와 석조 아치 다리, 높이가 다른 하역구와 선택 점검로. 짐꾼 보행면 위에 선택 점검로의 밑면이 걸리지 않도록 몸 크기로 검증한다.
- 24: 낮은 폐가, 가문의 대청과 사당, 경사진 후원. 토지문서 뒤 두 조사길이 분리된다.
- 25: 낮은 재실에서 비탈을 내려가 묘역 아래 석실로 진입. 지표 둔덕, 완만하게 높이가 바뀌는 흙천장, 옹벽, 넓은 기록함 방과 옆 굴 출구. 높은 기단 위에 건물을 다시 얹지 않는다. 묘주·유해 발굴·새 범인 설정을 추가하지 않는다.
- 26: 성 밖 열린 하천 공방. 가마·주조함·탄 들보·금속 더미·물가 작업대를 구분하고, 선택 고지에는 실제 교면과 접지 지주를 둔다.
- 27: 서쪽 낮은 회랑과 동쪽 높은 수로에서 네 명이 동시에 시작한다. 각자 제어장치 앞에서 불탄 출입문을 해제한 뒤 중앙 뜰에 실제로 걸어 모인다. 거대한 검은 기둥 대신 낮은 문루, 탄 널문과 들보를 같은 충돌 다각형으로 그린다.
- 28: 도시 전각 대신 성 밖 절개된 길과 바람 많은 돌둑, 파발 기록막.
- 29: 밤 수문 아래 봉인 창고, 깊은 물 위 점검교와 머리 위 수문 누각.
- 30: 모래톱·소나무·작은 하역정자·나룻배가 있는 넓은 강변. 도시 윤곽은 먼 배경 한 층이다.

23/25의 후면 석벽은 실제 다리·배우보다 먼저 그린다. 후면 벽이 실제 교면을 덮으면 충돌 검사는 통과해도 배우가 허공에 떠 보이므로 미술 검사 실패다. 지형에는 기존 공통 외곽선이 적용된다. 장소 천장은 재질별 공통 지형색을 사용하며 2막 동굴 전용 회색 줄무늬로 덮지 않는다.

## 현재 검증과 경계

- `tests/act3-location-contracts.mjs`: 최신 입력의1–22 불변, 재생성 반복 일치, canonical round-trip, 8장 실제 출전명단·적/정예·행동상한, 전원 몸 접지/물 경계 복구. 27 네 인물 각각 자기 제어장치까지 닫힌 상태로 접근, 닫힌 차단문이 정상 경로를 막음, 열린 뒤 중앙까지 무피해 이동.
- `tests/act3-location-traversal.mjs`: 실제 2/4인 필수/선택 경로와 23·27 짐꾼 walk-only. 이동도는 검사 입력마다 보충하므로 정상 플레이 완주라고 부르지 않는다.
- `tests/act3-location-shots.mjs`: 39개 군집마다 지원된 가까운 위치에서 팀에 있는 인물의 기본탄을 실제 발사해 예측/명중 일치. 25는 담허 기본탄, 그 외는 설오 기본화살. 전체 적별 공략·기력 밸런스 검사와 구분한다.
- `capture-act3-production.mjs --location-focus --game-follow`은 공통 Scene을 쓰며 와이드, 장소400px, 실제 follow400px, 27 양측/화재 출입구를 별도로 기록한다.

정상24→27 무휴식 연속 전투·저장·씬, 통합 브라우저/성능, 부모 미술 검토와 실제 Pages 검증이 끝나기 전에는 최종 완료로 표시하지 않는다.

## 통합 실행 계약

`test:act3:locations`는 현재 정본을 입력으로 생성·왕복 저장·실체 경로·사격·양쪽 소등을 검사한다. 재생성은 전30장이 참조하는 자산을 모아 미참조 `a3-*`만 제외한다.1–22장 사용 자산과 기존 비3막 자산을 보존하며 진행 중 저장의 내장 지형은 변경하지 않는다.
