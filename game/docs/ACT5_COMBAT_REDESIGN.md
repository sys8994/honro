# 5막 전투·난도 개편 기준

사용자 표기 5막 1~10장, 내부 ID 41~50. 인계 ZIP의 5막 기획 v1.0의 사건 순서와 라운드 목표를 유지한다. 이전 40장 기준 v3의 5막 행은 참고안이다. 책정한 수치, 실제 편성, 실제 플레이에서 관측한 결과를 구분한다.

## 1~4막과 비교

기준 소스는 master 4a6042ba8와 5막 초도 프리뷰 0c0f86102다. 동일 런타임에서 각 장의 시작 전투를 생성해 집계했다. 살아 있는 전투원만 초기 적으로 세고 구조물·아군·이벤트 대기는 제외했다. 행동 상한의 막간 표는 전투 생성 시 설정값이다. 1~4막과 5막 초도는 엔진이 시작될 때 일반 캠페인 6 미만 설정에 +1 보정을 적용할 수 있다. 5막 개편값은 이 보정을 반영해 5~7기로 직접 설정한다. 둘 다 유효 행동을 한 적의 실측 수와 구분한다.

## 수치의 의미와 검수

- 4막과 같은 성장대의 보통 난도를 기준으로 일반 적은 기준 평사 **2.55~2.70발**, 기준 피격 강도 **참조 HP의 11.1~12.5%**로 설정했다. 각각 기본 HP·공격 산정 입력이다. 스킬·방어·형기혼·거리·받은 총 피해에 따라 실측은 달라진다. 정예는 4.5~6.3발, 장무율은 보스 기준 12발에서 계산한다. 6·7장은 기존 기획대로 정예 없이 좁은 공간과 진목 목표로 압박을 만든다.
- 5막의 전투 난도는 일반 적 머릿수로 환산하지 않는다. 4막과 같은 정책·비슷한 성장에서 필수 경로상 전열·원거리·지원 역할이 실제로 행동하는지, 클리어 라운드, 영웅 HP 손실, 무력화와 보호 대상 피해, 적의 유효 공격·이동, 증원 경고·첫 행동을 비교한다. 24~32% 피해 목표는 적이 활동하는 라운드의 실제 아군 HP 손실을 그 라운드 시작 파티 최대 HP 합으로 나눈다. 시간·설정 차이를 표시하고 반복 표본이 확보될 때만 클리어율을 집계한다.
- 전장을 모두 청소하거나 총 라운드 하한까지 기다려야 승리하는 규칙을 두지 않는다. 근거리 전열, 고지의 궁수, 공중 등불·박쥐, 속박·돌진 역할이 각 장의 길목에 미치는 영향을 실제로 확인한다. 적 턴 행동 상한을 채우는 데 시간이 많이 들어가면 행동 수만 늘리지 않고 지형·사선·AI 실효성을 대조한다.
- 증원은 원인이 되는 목표·장무율의 약화·시험 진 상태에 연결한다. 이미 존재하는 편성의 유한 예비 기록을 빈 자리에서 출전시키며, 출전을 기다리는 필수 무리는 퀘스트가 건너뛰지 않는다. 자동 저장에는 이미 등장한 증원과 출전을 기다리는 증원 상태가 함께 남는다.
- 기존 저장은 저장 안의 목표·부대·높이를 그대로 사용한다. 개편 전투는 새 진입과 정식 재도전에 적용된다. 1~4막 지형·전투 수치와 호환 revision은 그대로 둔다.
