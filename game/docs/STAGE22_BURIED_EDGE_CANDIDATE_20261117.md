# 22장 매립 기초 접합 후보

공개 기준선에서 관측한 두 사각면은 범위 잘림이나 handoff strip 누락이 아니라 `stage22-vertical-art.mjs`가 저작한 매립 기초 두 색면이다. 소스 주석도 깊이 묻힌 조용한 기초라는 의도를 명시한다. 실제 지층은 y30600까지 이어진다. 이 기초를 삭제하거나 건축 벽면·창호를 새로 그리지 않는다.

## 최소 변경
- `v22-art-built-buried-west-foundation`: 원본 (0,5660)~(1590,6600), 색 #354d48 유지.
- `v22-art-built-buried-east-foundation`: 원본 (1610,4940)~(4810,6620), 색 #304a47 유지.
- 두 plane에만 side 140 / bottom 260의 매립 경계 합성 메타데이터를 저작 소스와 campaign에 동일하게 추가한다.
- 22장·두 ID·비 Workshop 조건만 device-space isolated mask로 그린다. 원본 상부 중앙은 불투명하게 유지하며 주변 지층과 합성한다. 다른 plane은 기존 그리기 경로를 사용한다.
- 기존 14장 바닥 closure rim 수정은 보존한다. 통합 manifest에서 해당 runtime의 예상 SHA는 이번 의도된 변경으로 갱신하며 이전 SHA와 사유를 남긴다.

## 검증과 한계
전체 campaign에서 두 메타데이터 외 값 불변, 점·색·접지·물리 보존, 저작 재생성·멱등성, alpha/조건 범위를 검사한다. Native portrait 극단 팬/중앙 5뷰와 desktop 좌하단 1뷰를 전후 비교한다. 직접 확인에서 직사각 하단/측면 접합은 완화되고 상부 방·기단은 유지된다. 이는 의도된 건축 전체의 재평가나 공개 UI 최종 합격을 뜻하지 않는다.

일회성 독립 Chromium canvas 검사는 process socket 권한으로 브라우저 시작에 실패해 미실행이다. 보안 비활성화나 기존 세션 접근을 하지 않았다. Native 결과를 실제 브라우저 오류로 단정하지 않는다. 이 장의 원인은 저작 source 도형과 관측 화면 위치의 일치로 구분했다. 공개 Game·실기기·동적 상태는 미검수이고 사용자 저장/기존 전투는 접근하지 않았다. 원격 후보/CI와 master/Pages 배포를 구분한다.

검증 결과: 위 소스/마스크 검사는 통과했으며, 새 경로를 제거하면 이전 runtime 바이트와 일치한다. 기존 14장 회귀는 251개 표면을 확인해 의도한 폐합선 한 개만 제외했다. 6뷰 물리 SHA256은 `72c9eee3b861ce2cdf65e617dcf692ab0504882ce6d9f6405cfe8b8d20d80141`로 동일하다. 공식 CI 결과는 별도 확인한다.
