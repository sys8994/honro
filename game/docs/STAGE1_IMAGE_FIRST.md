# 1장 · 승인 절제 원화의 독립 원경/투명 근경

2026-10-19 최신 사용자 정정 이후의 검수본이다. 이전 고밀도 통합 원화는 미술 기준에서 제외한다. 부모가 전달한 `1537b8dd01cd8de03b2e86abab6c6e64473d860c`의 무손실 WebP 원본 3개를 직접 픽셀 확인했다. 원본은 `game/docs/art-references/quiet-layered-20261019/`에 보존한다. 합성 `honro-layered-concept.webp`는 밝기/분위기 비교용이며 runtime에 등록하지 않는다. 실제 표시에는 `honro-independent-far.webp`와 `honro-quiet-near-transparent.webp`만 사용한다. 별도 이미지 생성, 새 풀/바위/미세무늬 추가, 원화의 형태 변경은 하지 않았다.

## 레이어와 캐시

`shared/runtime/quiet-layered-art.js`는 원경과 근경을 서로 다른 좌표/캐시로 다룬다. 원경은 `act1BackdropFrame`의 화면/aspect cover와 기존 약한 가로/더 작은 세로 카메라 시차를 재사용한다. 그림의 큰 월드 사각형으로 원경을 늘이지 않는다. 화면 밖 여유와 연속 제한도 기존 계약을 사용한다. 원경 톤 canvas는 두 장이 공유할 한 개다.

근경은 원본 1672×941 그대로, 하나의 균등 art-to-world 변환(1장 2배)으로 WORLD의 structural-back에 그린다. 지형 polygon의 재질 마스크, 반복 타일, strip warp, 밑면 fade를 쓰지 않는다. 기존 월드 캐시를 사용한다. 승인 합성의 차분한 밝기에 맞춘 brightness만 원경 .68/근경 .62로 각 source canvas에서 1회 적용한다. 채도/대비 강화, 패턴/디테일 생성, 프레임 filter, 나무 모션/새 RAF는 없다. 정상 1장은 `quietFar`와 `stage1QuietNear` 두 개만 요청/디코딩한다.

## 그림 안의 실제 접촉

`tools/map-forge/stage1-image-first.mjs`가 새 원화의 밝은 흙길 폭 안쪽에서 보행선을 다시 읽었다. 큰 토양 polygon은 물리 내부로만 존재하고 미술 클립으로 쓰지 않는다. 흙길 앞/뒤의 그려진 top plane을 그대로 보존한다. 지면은 점프 없이 출구까지 이어지며, 전경은 원화 아래까지 이어지는 큰 암반/흙/개울이다.

고목에는 실제 보이는 뿌리와 굵은 자연 가지 한 곳만 접촉을 둔다. 그림에 없는 구형 서쪽 가지 발판은 삭제했다. 원본 `pine-branch-east` ID와 HP340은 유지하고, 원본 뿌리 ID/내구도도 유지한다. 뿌리→자연 가지, 큰 중앙 바위 상면은 표준 점프로 접근한다. 뒤쪽 바위의 상면은 one-way여서 앞쪽 넓은 흙길을 보이지 않는 벽/천장으로 막지 않는다. collision debug는 기존 실제 물리 접촉선이며 기본 꺼짐이다.

자연 가지 파괴 시 독립 전체 장면 이미지로 교체하지 않는다. 정상 원화는 그대로이며, 해당 가지/그 가지의 잎에 한정한 원화 좌표 알파 제거 canvas를 한 번 캐시한다. 물리 polygon은 그 마스크에 사용하지 않는다. 새 배경 픽셀이나 다른 파괴 원화를 생성하지 않고 뒤의 독립 원경이 보인다.

원본 4체와 런타임 추가 4체의 HP/XP/수는 유지한다. 고목 가지의 까마귀, 중앙 바위/개울 서쪽 접근, 동쪽 접근, 고개의 작은 군집과 빈 연결 구간을 둔다. 유한 cart 증원의 총수와 기존 사건 ID/대사/퀘스트 의미를 유지하고 진입점만 새 그림에 맞춘다. 기존 물/접촉 파문/날씨 구현은 유지하며 새 얕은 개울 위치에만 연결한다.

1장의 campaign map revision만 1→2로 올린다. 예전 진행 중 1장 전투는 같은 장 입구에서 다시 시작하며 성장/SP/장착/완료 기록은 기존 정책으로 보존한다. 2장/3장 이후 revision과 공용 `HonroStage1LocationArt` API는 이 변경에서 유지한다.

## 실제 확인 범위

빌드, 고립된 설오 기본 무점프 보행/출구, 뿌리→가지 표준 점프/가지 보행, 큰 바위 표준 점프, 기존 revision/discard 성장·장착·진척 보존을 확인했다. 실제 Chromium에서는 합법적인 첫 보행 뒤 일반 화면과 같은 위치 debug 한 쌍, 줌아웃 한 장을 확인했다. 90개 정지 프레임에서 source tone filter는 최초 2회 그대로이고 원화 요청은 원경/근경 두 개뿐이다. 정상 전투 완주, 전체 장/스킬 검사는 하지 않았다.

화면과 결과는 `_local/reports/stage1-quiet-layered/`에 보존한다. Library 다중 저장은 1회 시도했으나 네트워크 오류로 실패했으므로 저장 성공으로 기록하지 않는다. 이 브랜치는 부모의 시안/실제 화면 비교 전 master 병합/배포하지 않는다.
