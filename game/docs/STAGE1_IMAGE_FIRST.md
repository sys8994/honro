# 1장 이미지 우선 장소 저작

2026-10-19. 기존 맵의 실루엣·좌표·충돌 마스크를 이미지 생성 입력으로 쓰지 않고, 승인 원본 3장의 회화·지면 깊이·사람 비례와 이야기 기능에서 독립적인 새 송림 장소를 먼저 생성했다. 원본은 `art/image-first-references-20261019`의 `e21ef6b8f282090617e1e6498bf2c4e2cc0b1dec`이며 `game/docs/art-references/image-first-20261019/`에 보존한다. 새 원화에는 캐릭터·적·UI가 없다.

`tools/map-forge/stage1-image-first.mjs`는 새 그림의 1536×1024 픽셀에서 읽은 길 내부·돌·뿌리·가지 접촉점을 3.2배의 단일 변환으로 저작한다. 길은 뒤쪽 산의 외곽선이 아닌 폭 있는 흙길 내부에 놓인다. 앞쪽 암반·흙·개울은 그림 아래까지 이어진다. 2D 물리는 그대로이며, 기본 점프로 뿌리와 양쪽 가지에 접근한다. 기존 가지 ID/내구도, 적 원본/보상, 이벤트 ID/대사/기능, 출구 목표를 유지한다. 구형 장식 나무/풀/문/바위 생성은 이 장에서만 제거하고, 실제 엄폐석 두 개는 그림과 맞는 별도 충돌로 저작했다.

`shared/runtime/stage1-image-first-art.js`는 `stage1ImageFirst.revision === 1`인 캠페인 1장만 선택한다. 완성된 고유 장소 원화를 단일 균등 배율로 그린다. 지형 폴리곤에 이미지를 잘라 넣거나, 띠로 변형하거나, 재질을 반복하지 않는다. 최초에는 정상 원화 한 개만 요청/디코딩하고 파괴 상태는 필요할 때 요청한다. 요청하는 이미지 총수는 정상/서쪽/동쪽 3개로 유한하다. 공유 월드 래스터 캐시를 사용하며 프레임 재질 필터와 새 RAF/모션이 없다. 새 장면의 카메라는 원화의 실재 범위 안에서 줌/이동한다. 줌아웃과 세로 화면용 하늘·앞쪽 지면은 별도로 원화에 확장했다.

현재 한계: 원경까지 들어 있는 단일 장소 그림이다. 공유 원경 및 독립 깊이 시차는 아직 적용하지 않았다. 이번 검수 수정에서는 이 이유로 전체 원화를 다시 생성하지 않는다.

파괴 이미지 제작/합성: 정상 원화만을 참조하여 낮은 좌/우 가지를 각각 제거한 상태 이미지를 생성했다. 독립 생성본을 그대로 전체 교체하면 가지 밖 픽셀도 달라졌다(가지 영역 밖 RGB 채널 평균 절대 차 약 9.5~10.3/255). 따라서 정상 원화는 모든 상태에서 유지하고, 서쪽 `[275,375,245,100]`, 동쪽 `[540,365,320,110]`의 고정 원화 좌표에서만 제거 이미지를 부분 레이어로 사용한다. 가장자리 6px 알파를 한 번 캐시한다. 양쪽 파괴도 두 부분 레이어를 합성하므로 나머지 하늘·산·지면·물·나무 몸통의 위치나 그림을 전체 교체하지 않는다. `place-both-broken.webp`는 제작 비교용 보존 소스이며 runtime에서 요청하지 않는다.

초기 편성 보정: 원본 4체와 런타임 추가 4체의 수/능력은 그대로다. 서쪽 개울 접근의 산개 2체, 고목 양쪽 가지의 까마귀 2체, 동쪽 개울 접근의 산개 2체, 고개 사슴 2체로 배치한다. 고목은 지상 사격과 가지 상승 사격을 고를 수 있는 전술 자리다. `cart`의 기존 유한 증원 총수는 유지하고 서쪽 개울/동쪽 뒤편의 두 진입점으로 나눈다. `stage1-image-first-roster.js`는 신규 전투의 추가 편성 위치에만 적용되며 저장된 적 위치를 재배치하지 않는다.

기존 전도성 물·접촉 파문·날씨 구현은 보존한다. 개울 위치만 새 그림에 맞추고, 불투명한 수면 카드가 원화를 덮지 않도록 기존 수면 패스의 투명도를 이 장에 한해 낮춘다. 충돌 디버그는 기존 실제 물리 외곽선이며 기본 꺼짐이다.

기존 `HonroStage1LocationArt`의 공용 함수와 2~30장 저작/렌더러는 수정하지 않는다. 새로운 지형이므로 캠페인 1장 revision만 1로 올린다. 같은 revision 저장은 그대로 유지하고, 이전 revision의 진행 중 전투만 폐기한다. 성장/기예/장착/완료 기록 보존 정책은 기존 코드를 사용한다.

확인 범위: 빌드, 실제 Chromium의 1장 일반/동일 위치 충돌선/줌아웃/모바일 렌더, 1장 설오의 고립된 기본 이동·점프로 출구 및 두 가지 접근, 실제 revision/discard의 성장·장착·기록 보존, 정지 화면 90프레임의 캐시 안정성. 전체 전투 완주·30장 순회·스킬 검증은 실시하지 않았다. 화면/수치 기록은 `_local/reports/stage1-image-first/`에 둔다. 검수 전 master 병합 및 배포하지 않는다.
