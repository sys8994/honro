# 혼로 환경 미술 SOP v0.1

상태: 2026-10-19 사용자 승인 방식. 초기 운영판이며 모든 미술 문제가 해결됐다는 뜻은 아니다.

## 목표
한국식 다크 판타지의 자연스러운 지형과 명료한 2D 포격 공간을 함께 만든다. 반복적인 미세질감은 허용하지 않는다. 그림을 기존 벡터 실루엣에 씌우지 않는다.

## 1. 입력과 우선순위
- 프롬프트 1: 전체 미술 원칙, 미세질감 억제, 좌우/실제 높이의 2D 공간, 레이어 분리. 최우선이다.
- 프롬프트 2: 지역별 재질·색·식생·건축·조명. 한 지역의 공통 표현을 유지한다.
- 프롬프트 3: 개별 장의 크기, 종횡비, 이동 거리, 수직 낙차, 전투 구간, 주/선택 동선, 사건/목표, 이전·다음 장과의 연결.
- 세 블록을 하나의 생성 요청에 결합한다. 자연어 우선순위이며 도구에 없는 수치 가중치를 설정했다고 주장하지 않는다.
- 지역별 레퍼런스는 깨끗한 승인 원본 하나 이하를 사용한다. 이전 장의 파생 결과를 다음 장의 참고로 연쇄 재사용하지 않는다. 레퍼런스의 질감과 구도 복제 여부도 확인한다.

## 2. 규모는 게임 설계에서 결정
맵 크기와 종횡비는 장의 핵심 개성이다. 공통 3:1/16:9 규칙을 두지 않는다.
이미지 픽셀 수나 기본 출력 비율 때문에 기존 진행 거리·높이·전투 구간을 축소하지 않는다.
기존 코드에서는 사건, 목적, 경로의 역할, 규모와 동료/적 전투 구성을 추출한다. 기존 좌표·실루엣은 그림의 본보기로 전달하지 않는다.
이번 적용 목표:
- 1장: 약 6000×2700, 긴 접근과 고지로 오르는 진행.
- 2장: 약 6200×4700, 고지 사격과 아래 호위로의 큰 낙차.
- 3장: 약 7000×2800, 긴 나루·운송 구간과 창고 높이 선택.
- 4장: 약 5600×3200, 방어 분지와 상하 이동.
- 5장: 약 6400×4200, 긴 접근/사격 지대와 거대한 폭포.
이는 초기 설계 목표이며 이미지 비율을 찌그러뜨리지 않는다. 균일 배율과 월드 여백으로 조정하고 결과 수치를 기록한다.

## 3. 미술·공간 규칙
- 거의 사이드뷰. 지면 윗면은 얕게만 보이고 화면 Y는 실제 높이를 뜻한다.
- 화면 깊이 방향으로 돌아가는 플레이 길이나 호수 앞뒤의 전투 차선을 만들지 않는다.
- 높이가 큰 장식만으로 수직 다이나믹을 대체하지 않는다. 오르기→사격→내려가기→우회/합류가 가능한 전략 경로를 만든다.
- 일반 전략 경로는 정상 점프/이동으로 접근 가능해야 한다. 특수 능력이 필요한 보상 퍼즐만 의도적으로 예외로 둔다.
- 바위·흙·물의 자연스러운 큰 형태를 사용한다. 단면 지층, 반복 텍스처 띠, 단색 지하 덩어리, 허공에 뜬 뿌리를 피한다.
- 나무·건물·발판의 접지와 인물 대비 크기를 맞춘다. 가까운 장식을 원경처럼 흐리게 만들지 않는다.
- 원경은 독립 자산이며 대비·채도·디테일을 낮춘다. 모든 여백을 채우지 않는다.
- 강한 지형 윤곽선을 평상시 덧그리지 않는다. 실제 충돌 윤곽은 기존 디버그 토글로 확인한다.

## 4. 기본 생성 + 표면 재채색
기본 구도 이미지를 만든 다음 필요한 경우 별도 재채색 단계로 잔질감을 제거한다.
재채색은 이미지 모델에 기존 구도를 입력해 큰 색면 중심으로 다시 그리는 과정이다. 결정론적 노이즈 필터도, 픽셀 단위 지형 보존도 아니다.
- 바위: 큰 2~4개 명암 면과 소수의 주요 균열.
- 흙길: 연속적인 큰 색면. 잔자갈·입자 무늬 제거.
- 수풀: 묶인 실루엣과 몇 개의 명암 덩어리. 잎/풀잎 반복선 제거.
- 건물: 구조 기둥·지붕 형태는 살리고 나뭇결/돌결 미세패턴 제거.
- 물: 큰 반사대와 흐름 덩어리. 작은 잔물결 자수처럼 채우지 않는다.
- 채색은 차분한 셀/매트 일러스트 쪽으로 이동할 수 있다. 변경된 화풍은 결과로 확인한다.
- 흐림, 축소, 어두운 필터로 결함을 숨겨 통과시키지 않는다.
- 재채색 이후 지형 윤곽이 바뀔 수 있으므로 최종 이미지에서 충돌 접촉면을 다시 측정한다.

## 5. 레이어와 모션
원경 / 근경 지형 / 필요한 중경 장식 / 움직일 요소를 구분한다.
물 표면·폭포·불·깃발·일부 풀만 효과 대비 비용이 좋은 모션을 준다. 모든 나무를 움직일 필요는 없다.
폭포는 기본 절벽 이미지에 물줄기를 완전히 굳혀 넣지 않는다. 열린/닫힌 물길과 화살 저항 영역이 같은 좌표를 사용하도록 별도 모션 레이어로 둔다.
매 프레임 전체 대형 이미지 필터·재생성 금지. 정적 색 보정/캐시는 변경 시에만 계산한다. 장 진입 시 필요한 자산만 로딩한다.

## 6. 실제 맵 반영
최종 그림의 지면 윗면 안쪽에 충돌 접촉 경로를 맞춘다. 외곽 픽셀 전체를 복잡한 폴리곤으로 추적하지 않는다.
발판/지붕은 해당 기존 one-way 규칙을 유지한다. 단순 고체 벽으로 바꾸지 않는다.
퀘스트·이벤트·목표 ID, 캠페인 진척과 캐릭터 성장 데이터를 보존한다.
지형 개편 시 진행 중인 해당 전투는 revision으로 무효화해도 된다. 이를 이유로 낡은 전투 지형을 계속 보존하지 않는다.
적의 종류별 수·전체 밀도와 전투 역할을 보존하며 새 지형에 재배치한다. 동일한 두 마리 묶음/등간격 반복을 피하고 공중 적의 지형 겹침과 사격/접근 가능성을 확인한다.

## 7. 장별 필수 사항
- 1→2장: 1장의 높은 오른쪽 출구가 2장의 왼쪽 고지로 이어진다.
- 2장: 설오는 처음부터 고지에 있으며 아래 상여차 길이 좌우로 연결된다. 독립된 낮은 왼쪽 봉우리가 아니다.
- 3장: 나루와 창고 사이 실제 이동 공간, 정상 접근 가능한 지붕/고지.
- 4장: 성문 방어 목표와 기존 방어 턴/패배 조건 유지.
- 5장: 깊은 호수 앞길/건너편 접근로 없음. 주박은 폭포 뒤이며 축지진목으로도 직접 도착할 수 없다. 담허의 의식으로 물길이 열리고 설오가 사격한다. 닫힌 물길에서 화살은 고체 벽처럼 튕기지 않고 급감속해 아래로 떨어진다. 휘겸은 등장하지 않는 기존 전개 유지.

## 8. 최소 검수와 배포
미술: 전체 구도와 실제 게임 배율의 대표 바위/수풀/건축 한 구간 확인. 잔질감, 시점, 접지, 크기, 레이어 혼입이 있으면 해당 부분만 수정한다.
게임: 빌드/실행, 수정한 장의 주요 이동·목표 도달·필수 기믹만 확인한다. 무관한 스킬 검사, 전체 verify, 대량 검사, 별도 검수자 금지.
수정 단위마다 브랜치와 무관하게 커밋·원격 푸시한다. 최종 master와 기존 Pages에 배포하고 배포 SHA 및 직접 화면을 확인한다.
기록: 프롬프트 버전, 참조 이미지, 원본/재채색본 구분, 최종 자산 경로, 월드 크기/균일 변환, 커밋, 필요한 검사 결과.
