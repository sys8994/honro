# 물건 살피기·획득 표현 정리 — 2026-11-02

전투/휴식터의 ‘보상’ 진입점과 누적 숫자 배지를 없애고 장비 보유품 옆의 ‘물건 살피기’로 통일했다. 선택창은 기록된 장 번호·장소와 ‘가져갈 물건 / 챙긴다 / 나중에’만 사용하며, 발견 장소·이전 소유자를 지어내지 않는다. 하나 챙기면 다음 선택을 강제로 열지 않고 원래 화면으로 돌아간다. 수치·효과·선택 원장·저장 schema·액션 ID는 유지한다. App/상태 집중 검사와 별도 UI 소스 오버레이 브라우저 검사를 사용한다. 오버레이는 정상 production 빌드 증거가 아니다. 정상 빌드는 Stage31의 전체 runtime digest 변경으로 기존 Engine probe 증거가 만료되어 차단되며, 해당 gate/증거는 이 수정에서 변경하지 않는다.
