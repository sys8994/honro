# 혼로: 휴식터·여정첩·초상화·설정 개선안

2026-10-22. 상태: 이동/여정첩 조작은 구현 중. 지도 원화, 초상화 리페인트, 설정창 전체 재구성은 **기획안**이며 아직 적용하거나 확정하지 않았다.

## 1. 확정된 이동 계약

- 휴식터를 중심으로 전투와 여정첩을 오간다. 정지 메뉴의 여정첩 진입을 휴식터 이동으로 바꾼다.
- 진행 중 전투를 버리는 이동은 먼저 확인한다. 취소 시 메모리와 저장 모두 변경하지 않는다.
- 여정첩의 장소 선택은 이동이 아니다. 선택한 장소 정보와 하단 CTA를 표시한다.
- 휴식터가 있으면 휴식터 진입, 없으면 직접 스테이지 진입이다. 유무는 실제 콘텐츠 데이터와 흐름으로 판정한다.
- 휴식터/여정첩의 명시적 스테이지 진입은 새 전투다. 영구 성장·장착·동료·클리어·해금은 보존한다. 인트로 Continue의 기존 재개 의미를 무관하게 제거하지 않는다.
- 막 탭은 1막~6막까지 수용한다. 다음 막 지도는 이전 막 클리어 뒤에만 노출한다. 미구현 막은 준비 중이며 플레이 가능한 척하지 않는다.
- 막은 정식 캠페인의 act 기준이다. surface/underground 지리 layer와 같지 않다. 특히 11·12장과 13장 이후를 같은 2막 안에서 보존한다.
- 엔딩 pending/seen, 컷별 저장, 다음 막 제목과 쉼터 전환 및 중복 보상 방지를 유지한다.

## 2. 여정첩 미술 제안

권장: 큰 수묵 지형 이미지 + 벡터 경로/지명/선택/완료 표식.

이미지는 분위기와 큰 지형 덩어리만 담당한다. 글자, 노드, 진행선, 클릭 영역을 구워 넣지 않는다. 기존 좌표를 먼저 고정하고 그에 맞춰 원화를 기획한다. 미세한 종이 노이즈를 덧씌워 품질을 대신하지 않는다.

- 1막: 산길·나루·마을·폭포가 연결되는 산수 여정도.
- 2막: 지상 접근부에서 지하 물길로 내려가는 절개형 구성.
- 3막: 성벽·수로·관아·공방·나루의 관계가 읽히는 평면 구성.
- 4~6막: 확장 규격만 마련. 미확정 지명/지도를 제작하지 않는다.

먹회색·청록의 절제된 면과 작은 주홍 표식. 금색은 선택/주요 CTA에 한정한다. 지역명 중복과 여러 겹의 선택 광채를 없앤다. 지명은 실제 텍스트로, 작은 화면에서도 안정된 크기로 유지한다. 팬/핀치는 유지하되 버튼 행을 추가하지 않는다.

후속 미술 제작을 선택하면 동일한 1막 구도로 개선 벡터와 혼합형 두 시안을 비교하는 것이 효율적이다. 이번에 전체 지도 원화 제작을 승인받은 것으로 취급하지 않는다.

## 3. 대화 초상화 제안

기존 인물 디자인을 새로 발명하지 않고 후보의 얼굴·배색·핵심 실루엣을 보존한다.

- 설오: 후기 정리본의 회녹색 옷, 활, 얼굴 존재감을 기준으로 한다. 무조건 평범한 얼굴로 되돌리지 않는다.
- 담허: 짧게 묶은 회색 머리, 늙었지만 깨어 있는 눈빛, 먹갈색/상아색 의상. 수염·피부의 반복 질감은 추가 정리한다.
- 휘겸: 거의 정면인 검은 갓, 성숙한 얼굴, 검붉은 옷깃. 기존 고밀도 표면 묘사를 설오·담허와 같은 큰 면으로 정리해야 한다.
- 소단: 잿빛/빛바랜 보라 옷, 낮게 묶은 머리, 방울의 정체성을 보존한다. 장신구와 반복 무늬를 줄이고 수동적이거나 겁먹은 소녀처럼 만들지 않는다.

반신 투명 마스터를 보존하고 대화 UI는 가슴 위를 사용한다. 캔버스 크기보다 얼굴 크기·눈높이·광원·명암 밀도를 맞춘다. 갓 때문에 휘겸 얼굴이 작아지면 안 된다. 1인 1기본 표정부터 시작하고 실제 장면이 필요할 때만 표정을 늘린다. 원본 노이즈와 실제 UI 식별성, 밝고 어두운 배경에서 alpha 가장자리를 각각 검수한다.

반복 NPC는 같은 그림체의 흉상 1장, 단역은 절제된 직업/연령별 풀을 검토한다. 핵심 이름 있는 인물에게 같은 얼굴을 무분별하게 재사용하지 않는다. 인간 보스는 대화 초상과 첫 등장 연출을 구분한다. 거대·사물형 보스는 종/가면/핵 등 식별 부위를 사용하며, 말하지 않는 존재에 억지로 초상화를 만들지 않는다. 정체불명 존재의 얼굴을 먼저 공개하지 않는다.

## 4. 정지/설정 제안

정지 메뉴의 최종 제안은 계속하기 / 다시 시작 / 설정 / 휴식터로 가기 네 항목이다. 구간 재시도가 있으면 다시 시작 아래에서 선택하게 하고 상시 버튼을 늘리지 않는다.

설정은 소리 / 화면 / 플레이 / 기록 관리 네 범주로 분리한다.

- 소리: 효과음과 배경음악의 켜기/끄기 및 음량을 같은 행에 둔다.
- 화면: 전체화면, 화면 방향, 미니맵.
- 플레이: 난이도, 아군/적 행동 속도, 조작 안내.
- 기록 관리: 내보내기/가져오기. 새 여정은 별도 위험 영역 및 명시적 확인.
- 디버그는 일반 옵션과 섞지 않는다. 활성 상태의 표시 및 종료 접근은 숨기지 않는다.

현재 값 즉시 반영은 유지하고 저장 버튼을 새로 만들지 않는다. 뒤로는 바로 위 화면으로 돌아가며 정지 중 설정 이동은 전투를 재개하지 않는다. 이번 구현 범위는 이동 계약과 여정첩 조작이고, 설정 전체 재설계는 아직 제안이다.
