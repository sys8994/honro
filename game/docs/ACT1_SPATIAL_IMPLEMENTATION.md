# 1막 장소·SVG 개편

2026-10-05. 새로 진입하는 1–10장 전체에 적용하는 야외 장소 개편이다. 2막의 넓은 명암면, 접지, 공간별 구성, 실제 지형에 붙은 경계 표현을 공통 Canvas에 적용하되, 1막의 숲·나루·성문·폭포·나무다리·뿌리마을·제례 공간을 유지한다.

## 장별 조사와 수정

| 장 | 조사한 문제 | 적용한 장소 구성 |
|---|---|---|
| 1 연목 고갯길 | 가는 기둥과 우산 모양 소나무, 고갯길 아래 넓은 단색 면 | 불균등한 솔숲, 수레터 여백, 개울 뒤 암반, 동쪽 능선. 큰 가지의 실제 전투 높이와 물길 유지 |
| 2 상여 위의 높은 길 | 세로 절벽이 같은 색 면으로 붙고 하부 행렬과 상부 엄호턱의 장소 구분이 약함 | 위쪽 숲 어깨, 내려가는 절개, 분지 물길, 맞은편 돌기둥. 높은 설오/아래 상여의 관계 유지 |
| 3 나루의 남은 장부 | 작은 창고와 화물 소품이 긴 강가에서 분리되어 보임 | 나루 작업 처마, 침수된 부두, 진흙 수로와 큰 창고 마당. 기존 물·부두·장부 위치 유지 |
| 4 문 밖에 남은 사람들 | 성문·담·집·망루가 독립된 장난감 크기처럼 놓임 | 이어진 성문과 담, 피난 안뜰, 불탄 집 터, 동쪽 망루 바위. 두 진입로 유지 |
| 5 폭포 틈의 한 발 | 노출 돌턱이 공중 판으로 읽히고 절벽 덩어리가 약함 | 실제 돌턱 뒤의 큰 화강암 벽, 상단 숲과 물줄기 틈, 아래 얕은 소. 결박/폭포 지붕과 발사 공간 유지 |
| 6 끊어진 나무다리 | 교각과 긴 상판 사이 빈 공간이 넓고 운반대의 장소성이 약함 | 양쪽 목조 교대, 부러진 상판의 열린 지지대, 다리 밑 운반 쉼터와 북문 숲. 하부 호송로 유지 |
| 7 살아 있는 사람을 꺼내는 법 | 거목보다 얇은 경사로와 반복 계단이 지배함 | 큰 고목 줄기·뿌리 거처, 낮은 집/중간 피난집/윗사당. 세 주민 높이와 열린 통로 유지 |
| 8 돌아오는 빈 상여 | 긴 길 위에 작은 창고·문·상여 소품만 있음 | 서쪽 장례창고, 무너진 제례문과 빈 회랑, 동쪽 상여터, 두 결박마당의 암반 기반 |
| 9 바람 없는 마당 | 서쪽·중앙·동쪽이 같은 공중 판과 작은 표식으로 보임 | 받이진 사이의 빈 우물마당, 무너진 회랑, 동쪽 제당. 지면 경로와 높은 사격 선택지 구분 |
| 10 놓지 못한 밤 | 작은 제당이 계단 발판 위에 떠 있고 양쪽 회랑이 약함 | 중앙 열린 제당과 넓은 암반 기초, 서·동 회랑, 외문과 당산 숲. 보스·의식·받이진 위치 유지 |

## 한 지도, 한 렌더러

- `tools/environment/act1-scene-composition.mjs`가 1막의 장별 풍경을 재현한다.
- `shared/assets/environment/act1-scene-*.svg`는 이름 있는 그룹과 넓은 색면으로 작성한 순수 SVG다.
- `tools/environment/build-act1-art.mjs`가 기존 공통 SVG compiler로 편집 가능한 `asset.vector`를 등록한다.
- `shared/runtime/act1-spatial-art.js`는 실제 compiled polygon 내부의 암면과 보행 가장자리를 그린다. 별도 충돌이나 물리 루프를 만들지 않는다.
- 경사지 소나무는 다중 나무의 평평한 뿌리선을 공유하지 않고 한 그루씩 실제 지면에 붙인다. 넓은 수관의 곡선은 유지한다.
- 후방 암반은 장별로 지정한 실제 지지 지형에 붙고, 가는 목조 지지대는 열려 있는 비충돌 뒷배경이다. 시각적 계단을 새 이동 기능으로 취급하지 않는다.
- 원래 landmark record와 필요한 충돌을 보존하되, 3장 서쪽 바위의 낮은 이음새는 그림과 collider를 함께 12단위 올려 수정했다. 새 그림으로 교체한 비충돌 landmark만 새 장의 렌더 단계에서 숨긴다. 존재하지 않는 사물이나 충돌/상호작용 사물을 숨기는 metadata는 map validator가 거절한다.
- Game·Stage View·Playtest는 `shared/build.mjs`의 동일 bundle을 사용한다.

## 승인된 원경의 보존

기존 1–5장 `act1-far.svg`, 6–10장 `act1-gorge.svg`의 모든 산 윤곽과 나무·구름·달 기하는 보존한다. Native SVG backend에서 검은 도형으로 보이던 `use`와 gradient ellipse를 동등한 명시적 path/group으로 정규화했다. `tests/fixtures/act1-backdrop-geometry.json`은 정규화된 전체 기하의 해시를 고정한다. 브라우저에서 같은 문제가 발생했다고 주장하지 않는다.

## 저장·편집 호환성

새 장의 `design.act1Scene.version=1`만 새 미술을 사용한다. 진행 중인 옛 Battle에는 새 지형·그림 metadata를 덮어쓰지 않는다. 프로필과 저장 schema는 바꾸지 않는다. 모든 원본 미션, 파티 합류, 적/동료 수치와 기예, 물의 전도, 파괴 가능 물체를 별도 계약 검사로 확인한다.

## 검증

검증 결과와 한계는 [1막 공간 검증](ACT1_SPATIAL_VALIDATION.md)에 기록한다. Native Canvas는 production compiler/Engine/HonroScene을 사용하지만 브라우저 HUD·입력·성능 검사 또는 사람의 플레이 검수를 대신하지 않는다.
