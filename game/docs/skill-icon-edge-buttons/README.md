# 스킬 아이콘 가장자리 채움 개선

진행 상태: 구현 및 3회 집중 검수 완료. 소스 커밋 후 별도 전체 검수 예정.

- 기준 소스: `0a9acf40396452e2f424cd9731f8f91f3478da03` (착수 시 원격 master와 같음).
- 작업 브랜치: `feat/skill-icon-edge-buttons`.
- 범위: 전투 HUD의 네 스킬 버튼, 모닥불 출전 슬롯·기예 트리·상시 기예·궁극기·장착 비교·스킬 상세, 허공터 선택 카드와 상세에 공통으로 쓰는 `skill-art` / `skill-stamp`.
- 원인: HUD 이미지 32~36px 고정 및 스탬프 안의 32px 이미지가 별도 타일을 만들고, 스탬프와 이미지에 둥근 모서리가 중첩됨.
- 보존: 원본 이미지 84개, 이름·단축키·MP·잠금/선택/불가/포커스·벡터 폴백, 기존 버튼/조이스틱/발사 조작 크기와 동선.
- 제외: 보고서 기능, 공통 설정 디자인, master 병합, Pages 배포. 부모 검수 후 통합 예정.
- 첨부 화면 두 개의 Library ID는 전달받았으나 이 실행 환경에 Library 읽기/다운로드 도구가 노출되지 않아 직접 열지 못함. 실제 저장소 빌드 화면으로 검수함.

최종 소스 SHA, 3회 집중 픽셀 검수 및 별도 전체 검수, 검사 결과와 실제 JPG 증거는 완료 시 아래에 갱신한다.

## 집중 검수 기록

1. 여백·프레임: 실제 Chromium에서 최초 111개, 허공터 사용처 보완 후 114개 확인 통과. 네 동행의 트리와 상시 기예, 출전 슬롯, 84개 상세 헤더, 장착 비교/목록, HUD의 사각 프레임과 내부 채움을 측정하고 JPG를 직접 열어 확인했다. 상세의 비기 표식이 줄바꿈되지 않도록 조정했다. 추가로 허공터의 `i` 래퍼도 이미지로 가득 채우고 액티브·상시 선택과 카드 모서리 보존을 확인했으며 세 JPG를 직접 열었다.
2. 상태·가독성: 15개 확인 통과. 선택의 밝은 테두리/이름, 기력 부족 점선과 비용, 재사용 회수, 실제 파진연격 후속 검술 제한의 disabled, 잠금/수련 불가, 빈 슬롯, 키보드 포커스/숫자 선택/Enter, 터치 선택, 실제 404의 SVG 폴백을 확인하고 JPG를 직접 열었다.
3. 반응형 조작: 45개 확인 통과. 390×844, 844×390, 360×800, 1280×900에서 기준 CSS와 버튼/전장/조이스틱/도약/하강/방어/발사 영역의 좌표·크기가 모두 동일했다. 실제 Chromium 터치 입력으로 조이스틱 잡기/해제, 발사 충전/해제와 스킬 선택, 상세 스크롤/닫기를 확인했다. 390·844·360 화면과 가로 상세 JPG를 직접 열었다.

원본 WebP 84개(총 504,894바이트)는 기준 소스의 각 파일과 바이트 단위로 모두 같으며, [개별 SHA-256](evidence/asset-byte-audit.json)을 보존했다. 이미지 생성/원본 편집/자르기는 하지 않았다. HUD는 기존 52×45 등 약간 직사각형인 조작 영역에 원본 전체를 맞춰 표시하므로 해당 비율만 CSS로 조정한다. 수련/상세 스탬프는 정사각형이다.

## 검사 진행 결과

통과: build, game typecheck, 84개 이미지/메타데이터/strict manifest 검사, camp-skill-ux, training-layout, portrait-framing, web-split, 위 3회 실제 Chromium 검사.

기존 실패: ui-buttons(설정의 이전 단일 화면 계약), combat-action-layout(파일 뒷부분 전체를 검사하는 정규식), passive-status-layout(이전 미디어 쿼리 계약), character-info(기존 선택 유닛 기대값), camp-stat-formatting(기존 반올림 기대값). 다섯 검사를 별도 기준 소스 worktree에서도 실행해 같은 실패를 재현했다. 저장소 경로를 정규화하면 다섯 실패의 전체 출력이 각각 완전히 같다. [명령별 결과](evidence/regression-results.json)와 변경 후/기준 소스 원문 로그를 함께 남긴다. 기존 검사 코드는 수정하지 않았다.

미실행: 전체 npm run verify, 전 30장 완주, 성능 검사, 실물 휴대폰 및 Safari. 이번 CSS 범위에 필요한 검사만 수행한다. Pages는 부모 담당이므로 이번 브랜치에서는 배포하지 않는다.
