# 1막 화면 깊이·가독성 규칙 · 2026-10-01

## 미술 기준

메트로폴리탄 미술관의 [한국 미술 교육 자료, 〈기러기 내려앉은 강가〉 설명과 관찰 지침](https://resources.metmuseum.org/resources/metpublications/pdf/The_Arts_of_Korea_A_Resource_for_Educators.pdf#page=106)은 안개로 거리를 암시하고, 선명한 전경 윤곽과 부드러운 원경 형태를 대비해 보라고 안내한다. 게임에서는 그 원리를 옮겨 멀리 있는 숲을 저채도·낮은 불투명도로 물리고, 실제 충돌 지형·나루 발판·바위는 더 밝고 끊기지 않는 윤곽으로 구분한다. 원화를 복제하거나 특정 나무 형태를 그대로 따르지 않는다.

## 좌표와 거리

3·4장의 하늘·구름·밤숲은 화면 좌표의 캐시된 원경이고, 충돌 지형·붙박이 건물·오브젝트는 월드 좌표다. 월드 좌표 계층의 `distance=0`은 카메라 줌에 1:1로 반응한다. 원경 계층의 `distance`는 시각 깊이이며 물리·저장 데이터와 무관하다.

| 계층 | distance | 표현 |
|---|---:|---|
| 달 | ∞ | 크기와 화면 위치 고정 |
| 구름 | 24 | 거의 고정 |
| 먼 숲 | 1.9 | 가장 옅고 작게 움직임 |
| 중간 숲 | 0.95 | 중간 명도·움직임 |
| 가까운 원경 숲 | 0.48 | 숲 중에서는 가장 크고 선명함 |
| 지형·발판·바위·세계 내 장식 | 0 | 화면의 실제 줌에 따라 변화 |

기준 줌 `0.66`에서 원경 크기 계수는 1이다. `size = 1 + (zoom / 0.66 - 1) / (1 + distance)`를 쓴다. 따라서 줌아웃하면 나무도 작아지되 세계의 캐릭터보다 완만하게 변한다. 수평 시차는 `cameraX × 0.055 / (1 + distance × 0.22)`이고, 달의 무한 거리에서는 0이다. 원경 캐시 키에는 줌을 포함하고 3·4장만 카메라 위치를 40월드 단위로 묶어 지속적인 이동 중의 재구성을 제한한다. 화면 크기 자체는 캐시 예산을 유지한다.

소나무 수관과 달리 잎이 없는 가지가 실루엣으로 읽히도록 3장에는 일부 앙상한 나무, 불탄 마을인 4장에는 더 많은 앙상한 나무를 섞었다. 줄기·가지는 회갈색, 잎은 탁한 청회녹색으로 분리했다. 먼 숲의 불투명도는 0.43, 중간 숲은 0.57, 가까운 원경은 0.69다. 월드 `back` 장식은 0.32, 지형 구조 뒤의 장식은 0.72, `mid`는 0.86, `prop`은 0.96, `front`는 1이다. 가까운 `rock` 오브젝트는 `prop`에서도 1이다. 이 값은 화면의 시각 계층용이며 오브젝트의 상호작용 속성이나 충돌을 바꾸지 않는다.

## 확인 범위

`python -X utf8 tests/stage36-place-browser.py --stage34`는 같은 장면의 넓은 줌(0.22)과 보통 줌(0.66)을 저장하고, 줌 변경 시 원경 캐시 키 갱신, 불투명도 계층, Game/Stage View 비교, Workshop Playtest, 물 애니메이션의 캐시 분리를 검사한다. 화면은 `_local/reports/stage34-water-forest/`에 둔다. 공통 렌더러를 바꾼 뒤에는 `tests/migration.mjs`와 `tests/integration.py`를 함께 실행한다. 5·6장의 원경은 이번 라운드에서 설계를 바꾸지 않았다.
