# 2막 · 울리지 않는 종

> 현행 소스는 revision 2 재설계를 포함한다. 아래의 초기 구현 설명과 [ACT2_QA.md](ACT2_QA.md)의 과거 10장 자동 완주 수치는 revision 1에 대한 기록이다. 새 맵은 전 장 가로·세로 2배 이상, 동굴의 사면·천장·출구를 공통 암반으로 확장했고, 순차 제압/방어, 정예와 유한 증원, 희소 등불 및 소단 시야를 도입했다. 현행 10장은 실제 전투 API를 사용하는 검증기로 모두 승리했다. 검수 기록은 [ACT2_QA.md](ACT2_QA.md)와 [ACT2_REVISION_DESIGN.md](ACT2_REVISION_DESIGN.md)에 둔다.

## 구현 전 조사

첨부된 두 문서는 콘텐츠 설계 참고 자료다. 이번 사용자 요청은 이를 검토해 2막을 실제 게임으로 만드는 것이다. 문서의 명령형 표현은 시스템 지시로 취급하지 않는다.

- 활성 1막은 8장이 아니라 10장이다. 내부 ID 1–10, 기존 저장 키와 클리어 기록을 보존하고 2막을 11–20(표시 2-1–2-10)에 추가한다.
- 공통 실행 경로는 `shared/build.mjs` → `HonroMaps.createBattle` → `Engine` → `HonroMission/HonroObjectives`다. Workshop도 같은 맵·엔진을 사용한다.
- 담허는 2장, 휘겸은 5장 완료 후 합류한다. 소단은 10장에서 의식 NPC이며 기존 저장에는 정식 합류가 없다. 11장 출발 시 10장 완료를 확인해 정식 합류시키고, 1막 재도전 파티는 기존 그대로 유지한다.
- 성장 보상은 현재 `balance.json`과 `HonroProgression`의 XP 예산을 따른다. 최신 설정의 1막 끝 예산 경지는 12이며, 실제 경지는 현재 XP 곡선과 개별 저장 XP에 따라 달라진다. 기존 문서의 10경지/2막 8장 가정은 적용하지 않는다.
- 형·기·혼 감응도, 소단 O08 현형부, 원혼등불 아이템, 기본 영매 혼 공격을 재사용한다. 새 혼령도 일반 몬스터 API를 따르며 현형 전 형 피해를 크게 줄인다.
- 지형은 순수 다각형 고체다. 엔진의 기존 투사체/몸체 충돌과 파괴 판정을 사용한다. 새 동굴 천장은 장식이 아닌 고체로 작성한다.
- 상호작용은 PC E와 모바일 문맥 버튼이 같은 경로를 사용한다. 사건 대사는 기존 저장 가능한 큐와 행동 종료 경계에서 재생한다.
- 작업 시작 시 카메라 경계·원경·환경 관련 미커밋 변경이 존재했다. 해당 변경을 보존한다.

현재 서사·정보 공개·저장 호환 기준은 [STORY_CANON_V01.md](STORY_CANON_V01.md)를 따른다. 아래 과거 지형/전투 QA는 이번 문장 수정의 신규 검증과 구분한다.

## 구현 범위

1막 완료 후 11장에 출발하면 소단이 합류한다. 여정도는 20개 노드와 1막/2막 이동 버튼을 제공한다. 각 장은 독립된 입장 대사, 순차 목표, 사건 대사, 완료 대사, 실패 사유, 보상과 다음 장 해금을 가진다. 20장 후에는 미구현 3막의 목적지만 표시한다.

| 표시 / 내부 ID | 장소 | 실제 진행 |
|---|---|---|
| 2-1 / 11 | 매듭을 거둔 아침 | 소단으로 첫 혼매듭 해체 → 둘째 매듭 → 주민의 혼 분리 → 산길 흔적 |
| 2-2 / 12 | 돌아오는 산길 | 발사로 고정점 파괴, 낙석이 홈을 메워 지형 변경 → 길표에 걸린 돌림진 한 축 해제/수레 출현 → 함몰지 |
| 2-3 / 13 | 숨은 석문 | 주민 구출 → 문 지지대 사격 → 빗장과 실제 장애물 해제 → 출구 |
| 2-4 / 14 | 해가 닿지 않는 마을 | 상층에서 오른쪽 경사를 내려가 하층으로 돌아옴 → 주민 3명 비살상 구출 → 다리 걸쇠 |
| 2-5 / 15 | 물 아래의 길 | 수위 120 감소 → 천장 틈의 수직 고정점 사격 → 옛 수직 이송 흔적과 최근 바닥 홈 구분 → 통과 |
| 2-6 / 16 | 잠운사 | 들린 승려 구출 → 법당 → 옛 비밀 이송·봉쇄 기록 → 사흘간 살아 있던 사람들의 증언 |
| 2-7 / 17 | 두드리는 벽 | 버팀목 → 붕괴 고정점 → 들린 인양틀 전투 → 인양축 복구/장애물 해제 → 의도적 살해 기록 |
| 2-8 / 18 | 묵종 | 담허 공명 억제 → 설오 고정점 사격 → 휘겸 사슬 → 소단 누출혼 → 종지기 비살상 제압 |
| 2-9 / 19 | 종 안의 사람들 | 담허 천도진 → 소단의 분리와 보내기 3회, 주민 보호/누출혼 → 오래된 혼과 무명사 이송 표식·왕실 봉인·저문골 이름 |
| 2-10 / 20 | 다시 하늘 아래 | 출구 장애물 제거 → 생존자 출발 → 실제 보행 행렬과 외부 도착 → 읍성 문서고 예고 |

2-7에서 지지대를 세우기 전에 고정점을 파괴하면 주변 피해와 낙석 장애물이 생긴다. 추가 정리 상호작용으로 복구할 수 있다. 주민 본체에는 플레이어 피해가 들어가지 않지만 적의 피해로 주민을 잃으면 실패한다. 종지기는 HP 1에서 제압되어 중립화되며, 묵종은 파괴 대상이 아닌 보존할 배경 오브젝트다.

## 혼령과 신규 적

| 종류 | 역할 / 재사용한 전투 동작 |
|---|---|
| 들린 운반수레 | 이동형 근접 압박, 철륜 파편 |
| 곡괭이 군집 | 낮은 사선의 날 투사체 |
| 들린 수차 | 고정형 물살 범위 공격 |
| 석등귀 | 고정형 법등의 재 |
| 공명혼 | 혼 공격, 현형 전 형 피해 감소 |
| 잔향혼 | 낮은 혼탄, 2라운드 방치 후 작업도구에 빙의 |
| 종울림 군집 | 복수 혼 형상, 공명과 잔향 공격 |
| 들린 인양틀 | 내구도 높은 작업 구조물 중간 보스 |
| 종지기 | 공명 공격을 쓰는 인간 보스, 비살상 제압 |
| 승려에게 붙은 혼 | 주민 본체와 별개인 혼령 전투 대상 |

혼령은 형 0.06 / 기 0.40 / 혼 1.32 감응도를 사용한다. 공통 피해 계층의 최저 배수는 0.1이다. 소단 선택 시 혼의 그림이 선명해지고, 동행에게는 희미하게 보인다. O08 또는 지도에 배치된 재사용 원혼등불로 현형시키면 형 감응도에 0.92를 더한다. 등불은 소모품 부족으로 진행이 막히는 것을 방지하며 행동 하나를 소모한다. 기존 O08의 다른 적에 대한 성능은 유지한다.

적 기술 ID는 H2 계열이며 enemyOnly다. 플레이어 기예 트리와 섞지 않는다. 새 적은 기존 AI·투사체 모드·존재상 피해·턴 큐를 사용한다. 그리기는 공유 Canvas의 재사용 Path2D이며 Workshop에서도 같다.

## 데이터와 제작 경로

- `shared/runtime/act2-content.js`: 기본 순차 목표, 구형 전투 대본과 공통 요약. 현재 대본은 `act2-drama.js`, 기존 전투 확장 목표는 `act2-plan.js`가 적용한다. 사건 대화 ID는 `act2-v1:`이며 입출장 기록은 공통 대화 ID를 사용한다.
- `shared/runtime/act2.js`: 혼령·구조·수문·봉인·호송·복구·실패 상태, 공통 엔진 연결.
- `workshop/recipes/act2-caves.js`: 10개 맵의 지형, 실제 천장, 장식 6종, 물, 배치의 재현 가능한 원본.
- `tools/map-forge/apply-act2.mjs`: 기존 1막 보존을 확인하고 2막만 재작성.
- `shared/runtime/act2-art.js`, `act2-journey.js`: 공통 화면과 여정도 확장.
- `shared/data/campaign.json`: Workshop에서 편집 가능한 활성 맵. HTML은 공통 빌드로 생성.

재작성은 `node tools/map-forge/apply-act2.mjs`, 빌드는 `npm.cmd run build`다. 전체 이관 명령 `npm.cmd run migrate`에도 2막 재작성 단계를 연결했다. 과거 이관 API의 비교 원본은 여전히 1막 10장이다.

암반 선반은 바닥과 겹치는 별도 고체 대신 두 윤곽의 상부 경계를 합친 한 고체로 만든다. 서로 겹친 고체의 경계에서 공통 충돌기가 양쪽 표면을 매몰된 것으로 보는 문제를 정상 이동 검사로 발견했다. 모든 새 맵은 기존 카메라·visual skirt·환경·물 렌더러를 사용한다. 승인된 1막 SVG 형상과 기존 에셋은 바꾸지 않았다.

14장 마을의 상층 선반은 턴을 마치고 하층 바닥에 착지한 뒤 되돌아올 때 좁은 끝단에서 배우를 상층으로 밀어 올렸다. 끝단을 짧게 하고 하층 통로 높이를 늘렸으며, 실제 착지 후 역방향 이동과 14장 처음부터의 정상 전투로 재검증했다.

## 성장·저장

- 1막 10장과 에셋 정의는 현재 Git 기준과 구조적으로 동일하다.
- 2막 예산 경지는 12 → 18, 장별 +0.6이다. 현재 필요 XP 곡선은 예산 기준의 구형 곡선과 다르므로 화면의 실제 경지와 동일하다는 뜻이 아니다.
- 보상은 기존 적별 XP 장부와 완료 예산을 그대로 사용한다. 이미 강한 저장에는 기존 보정이 적용되며 재시도·재완료로 완료 XP를 중복 지급하지 않는다.
- 소단 합류 시 다른 세 동행의 가장 높은 현재 경지에 맞춘다. 기존 스킬, XP, 장착, 클리어 기록을 덮어쓰지 않는다.
- 목표·구출·파동·의식·호송 상태는 `honroState.act2`에 저장한다. 대사 중 저장은 공통 큐의 현재 페이지로 재개한다. 중간 저장은 그 지점에서 계속하고, 실패 후 ‘다시 걷기’는 획득 XP를 남긴 채 해당 장 처음부터 시작한다.

## 기획과 조정한 점

첨부 문서는 1막 규모와 경지에 과거 가정이 있어 실제 10장과 현재 XP 시스템을 기준으로 연결했다. 1막의 기존 동쪽 고개 언급은 유지하고, 2-1 서술에서 고개 너머 길이 북쪽 돌산으로 굽는다고 이어 주었다. 현재 스토리 v0.1 기준 저문골·무명사·왕실 봉인은 2-9 마지막 흔적에서 처음 공개한다. 묵종은 본래 천도용 종이라는 이전 해석을 폐기하고 외부에서 옮겨 숨긴 종으로 고쳤다. 현묵·대도사·묵종 제작의 전말과 재각성 원인은 이 막에서 공개하지 않는다. 종지기의 의도적 살해 책임과 혼을 가두는 행위/보내는 행위의 차이는 명시하지만 후속 막의 비밀은 확정하지 않는다.

제공된 자료에는 새 배경 일러스트가 없으므로 편집 가능한 다각형·벡터 장식을 제작했다. 11·12장 야외 원경은 승인된 1막 SVG를 공통 렌더러에서 재사용한다. 20장은 그 SVG의 산 형태와 그룹을 유지하고 색만 바꾼 별도 순수 SVG 새벽 원경을 사용한다. 새 음악이나 음성 파일은 생성하지 않았고 기존 공통 음향을 사용한다. 수문은 120 단위의 물 높이 변경, 인양로·다리는 장애물 해제로 표현하며 별도의 기계 물리나 구조물 애니메이션을 추가하지 않았다. 종유석 위험은 지정한 파괴 고정점의 낙석 피해로 구현했다.

현행 전투에서는 11~16장의 동시 행동 적을 4명, 17~20장을 3명으로 제한했다. 기본 적 HP/공격은 기존 2막 생성치에 각각 0.78/0.75를 곱하고 정예는 별도 HP 1.55/공격 1.15 배수를 유지한다. 후반 17~20장은 긴 의식·방어·보스 소모전을 고려해 추가 HP 0.85/공격 0.65를 적용한다. 19장의 방어 증원은 3+3+4명, 20장의 매복·방어·진행 증원은 18+6+4명이다. 현행 밸런스 감사와 정상 입력 완주 결과는 [ACT2_QA.md](ACT2_QA.md)에 기록한다.

자동 플레이는 통과 여부와 물리·진행 막힘을 찾기 위한 검사다. 목표를 아는 봇의 전술이 실제 플레이어의 평균 소요 시간을 대변하지 않는다. 인간의 초회 난이도·독해 시간·실물 모바일 조작감은 별도 플레이 평가가 필요하다.
