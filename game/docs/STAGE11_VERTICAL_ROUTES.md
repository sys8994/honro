# 2막 1장: 기존 compact 지형의 상·하층 추가

2026-11-09, 기준 master `be573beeb`. 첨부된 북쪽 집결 화면과 현행 compact B-open 6200×3200 맵을 기준으로 한다. 원본 16000×12000 협곡으로 되돌리지 않는다.

## 변경

- 북쪽 고개 x4500–5940에 소나무 상단 우회로를 추가했다. 진입 기본 점프 높이 약 141, 꼭대기는 y1430으로 기존 고개보다 약 250 높다. 아래 주동선은 그대로 통과할 수 있다. 서쪽 가장자리에서 아래 적에 사격하거나 위쪽 비행 적과 같은 고도에서 교전할 수 있고, 어느 지점에서나 기존 하강 조작으로 돌아간다.
- 중앙 골 x2730–3247.5에 낮은 돌발판을 추가했다. 주 돌목 아래·골 바닥 위의 중간층이며, 기본 점프 약 123으로 진입한다. 위층을 향한 사격과 바닥 복귀를 선택할 수 있다.
- 기존 소나무와 돌목의 네이티브 벡터 자산을 그대로 재사용했다. 지형과 그림에 동일한 이동/배율을 적용했다. 신규 래스터·임의 폴리곤 미술을 만들지 않았다.
- 원래 5개 지형, 9개 미술 배치, 맵 크기, 적, 사건, 목표, 환경, 진입/집결 조건을 보존했다. 기존 진행 중 세이브에는 지형을 강제 삽입하지 않는다. 새 진입/재시도에서 추가 지형이 반영된다.
- 재현 함수는 `tools/map-forge/stage11-vertical-routes.mjs`. 패키지 재생성에도 연결했다. 상호작용 수정 파일은 변경하지 않았다.

## 확인 범위

- `node tests/stage11-vertical-routes.mjs`: 네 캐릭터 × 두 경로, 기본 점프/이동/턴 대기/하강 8회 통과. 지형 접촉·머리 여유 확인. 상태 JSON 직렬화 후 Engine 복원에서도 지형/좌표 보존 및 무피해 바닥 착지. 북쪽은 2턴, 중앙 골은 1턴의 격리 이동이다.
- 같은 검사에서 별도의 격리 전투 두 장면: 북쪽 가장자리→아래 표적, 중앙 낮은 발판→위 돌목 표적에 실제 예측/발사/탄도 계산으로 각각 피해 확인. 이는 정상 전체 교전 승리나 난도 측정이 아니다.
- `node tests/stage11-compact-lazy-author.mjs`: 실제 제작/컴파일 경계, 다른 장 보존, 원본 불일치 차단 및 미술 fallback 통과.
- `node --expose-gc --max-old-space-size=1200 tools/environment/capture-stage11-vertical-routes.mjs vertical-routes`: 공통 Engine/Scene의 전체, 북쪽 보행 배율, 중앙 골, 390×844 세로 화면 직접 확인. 상·하층 접촉선과 기존 바닥을 구분할 수 있다. 실제 브라우저/HUD 입력 검수와는 다르다.
- 원래 지형/미술/유닛/이벤트/목표/환경/경계와 기준 커밋을 직접 대조해 보존을 확인했다.

## 남은 통합 확인

상호작용 담당의 변경과 함께 최종 빌드, 실제 브라우저 짧은 키 입력/저장 이어하기, master 및 기존 Pages 배포/공개 동작을 확인해야 한다. 이 문서만으로 이를 완료했다고 주장하지 않는다. 전체 캠페인 완주, 재미/미술의 사용자 승인을 주장하지 않는다.
