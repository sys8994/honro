# BGM 표시 제목 — 2026-10-22

사용자의 새 첨부 파일명에서 대괄호 분류 뒤의 곡명을 표시 제목으로 사용한다. main은 혼로, battle 1–6은 장막 너머의 음 / 하늘의 그림자 / 산 자와 남은 자 / 불길의 춤 / 암막 / 불완전한 의식이다. battle 6의 여분 `]`는 오타로 제거했다. 기존 추천 제목은 더 이상 사용하지 않는다. MP3 ID3나 음량을 편집하지 않는다.

파일·막별 매핑·예상 blob과 실제 검증 범위는 [현행 BGM 목록](../../assets/bgm/README.md)에 있다. [청취 페이지](../../tools/bgm-title-review.html)는 같은 JSON의 7개 제목과 경로를 읽고 preload=none으로 곡별 사용자 재생만 요청한다. 한 곡을 재생하면 다른 곡을 정지한다. battle 5/6의 바이트가 아직 없으므로 해당 두 링크/재생은 완료 상태가 아니다.

기존 5곡의 실제 해시·메타데이터·전체 decode는 `_local/reports/bgm-assets.json`에서 확인한다. 전체 7곡 청취·악기/선율 판단·새 Game/Workshop 빌드 검수를 완료한 것으로 해석하지 않는다. 과거 5곡 신호 분석과 당시 검수는 Git 이력 및 2026-10-21 evidence의 역사 기록이다.
