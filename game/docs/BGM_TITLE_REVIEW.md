## 분석 근거와 청취 한계

음악을 직접 듣고 악기·선율·조성·정서를 판단하지 못했다. 실제 MP3 디코딩과 브라우저 재생은 확인했으며 청취 검수와 구분한다. 모든 파일은48kHz stereo MP3, ID3 lyrics-eng는 [Instrumental]이다. 이 태그만으로 보컬 부재를 검증한 것은 아니다.

FFmpeg로 전곡을22,050Hz mono float PCM으로 디코딩했다. 1초 RMS의 -50dBFS 이상 구간 중앙값/10–90백분위, 처음·중간·마지막10초 레벨, Hann2048/hop1024 magnitude spectral centroid를 계산했다. RMS는 LUFS/체감 음량이 아니고 centroid만으로 음악적 밝음·악기·감정을 단정할 수 없다. 분석 때문에 원본 파일을 변환하지 않았다.

원시 메타데이터·분석·SHA256은 [bgm-inventory.json](evidence/intro-bar-bgm-2026-10-21/bgm-inventory.json), 실제 재생/실패회복 검사는 [bgm-checks.json](evidence/intro-bar-bgm-2026-10-21/bgm-checks.json)이다. 개발용 직접 진입한1·10·21장의 검사이며 전체 캠페인 플레이 검증은 아니다. ended 이벤트로 곡 끝을 단축했다. 실제5곡의 승인 제목을 모두 확인했고 실패05→02, 설정 음소거/음량·쉼터01 복귀를 확인했다.

최초 추천 초안은 승인 제목으로 대체했다. 신호 분석은 제목 선정의 보조 자료이며 직접 청취를 대신하지 않는다.
