# 14장 수직 마을 미술 검토

## 완료 기준과 현재 상태

게임의 실제 충돌·상면·배우 위치·사선은 검증된 상태로 동결한다. 전경 바위가 배경과 구분되면서 집 기단·접촉 그림자가 실제 절벽에 붙어 읽혀야 한다. 큰 공간의 낮은 장소 밀도와 큰 평면만 반복되는 깊이 표현은 아직 보완 사항이다. 정상자원 완주가 미술 승인을 대신하지 않는다.

## 보존한 반려 시안

33개 미술 요소·11주거 묶음과 비대칭 실제 암반 밑면을 Native 전후16컷으로 확인했다. 기본68경로/전신/목교/탄도는 보존됐으나 F 돌턱 받침이 후면 암벽에 가려지고 하부 안개가 잘린 띠로 보였다. F 받침은 요소순서로 교정해 별도 정상줌 렌더에서 목재 기둥·버팀대가 다시 보이는 것을 확인했다.

C 한 구역의 첫 표면 시안(`6de2339e…`)은 실제 collision polygon 안의19path만 사용하고 다른29장·반복생성·Path2D/환경검사를 통과했지만 시각적으로 반려했다. 둥근 어깨와 매끈한 굴테, 전면 S자 면이 돌보다 천/고무·추상 무늬로 읽혔고 주변 회색과 올리브 재질이 갈라졌다. 이를 다른 구역으로 확대하지 않는다. 해당 source-only checkpoint는 복구용이며 canonical과 배포 HTML에는 활성화하지 않았다.

## 기존 미술을 재사용하는 기준

새 무늬를 계속 만드는 대신 기존11·12·16 실제 production Scene을 같은1440×960/scale0.5로 비교했다.

- 11장 의식터 암벽(7350,6930): 서로 붙은 큰 돌 단위, 밝은 윗면/앞면/그늘 측면과 하부면. `stage11-landscape-art.js`의 ROCK_BLOCKS/rockBlock이 C의 주 기준이다.
- 12장 북측 채석장(7360,3900): 넓은 차가운 암면, 굵은 절리와 가는 모서리 빛의 일정한 방향. `stage12-quarry-art.js`의 panels/seams를 보조 기준으로 쓴다.
- 16장 법당 경사/기단(4400,4700): canonical `terrainPlanes`와 건물 석축 접촉을 참고한다. 기본 ROOM_ART와는 다르다.

기존 큰 바위 그림을 단순히 후면에 붙이지 않고 C 실제 지지면·외곽 안에서 전경 암석면이 이어지게 한다. 그 접점과 배우/집의 접지가 정상줌에서 읽힌 뒤 상·하층으로 확대한다. 주변 암반과 같은 차가운 재질 범위를 유지한다.

## 재현

`tests/stage14-vertical-native-art.mjs`의 기본 실행은 전후16컷이다. `HONRO_NATIVE_VIEW`와 `HONRO_NATIVE_OUT`으로 단일 검토컷을 별도 출력할 수 있다. `tools/capture-vertical-style-references.mjs`는 명시적 stage/x/y 입력만 사용해 기존 stage를 같은0.5배율로 캡처하며 각 PNG와 project/runtime 해시, 상태불변을 기록한다. 모두 Native Canvas이고 브라우저 검수와 구분한다.
