# 허공터 배치 · 2026-10-10

연습장은 캠페인의 교전 진행을 강제하는 곳이 아니라 같은 기예를 여러 조건에서 비교하는 공간이다. 새 진입/명시적 리셋만 새 배치를 만든다. 영웅/기예 변경, 캠페인 저장, 적 사망·복구 정책은 기존 경로를 유지한다.

이전 5600×2300 / 적 12체 / 정예 1체에서 6000×2300 / 적 20체 / 정예 1체로 조정했다. 지형 종류는 추가하지 않고 시작 평지와 중앙 마당을 넓혔다. 행동 상한은 2, 일반 HP는 130–265, 정예 HP는 3400으로 유지한다. 무한 증원/자동 부활은 없다.

- 시작 x340, 첫 표적 x800. x0–650은 정비·진목 배치와 조준 준비 공간이다.
- 근접 3체: x800–1010의 같은 평지. 검기 접근과 짧은 사격을 비교한다.
- 중앙 6체: x2550–3000. 3체씩 모인 두 덩어리로 범위 공격과 단일 대상의 차이를 확인한다. 기존 높은 발판은 위로 돌아 쏘는 선택을 유지한다.
- 공중 4체: 중앙 양옆의 서로 다른 높이. 고각/직사와 공중 표적을 비교한다.
- 물가 4체: x4100/4190과 x4510/4610의 두 쌍. 물 반응과 건너편 사격, 다리 위 설치를 비교한다.
- 정밀 2체: x5640/5860. 동쪽 경사와 평지에서 거리·고각을 조절한다.
- 정예 1체: x3290. 넓어진 능선 끝, 기존 폭발통 옆이되 밀집 표적과 떨어져 있다. 정예의 기존 전용 기술과 내구를 유지한다.

수치는 이번 구현값이며 사용자 확정 목표 숫자가 아니다. 높은 지형/물/파괴 발판/폭발통의 기존 종류와 진입·리셋 UI는 그대로다. 공유 world.js 생성기를 사용하고 캠페인 JSON/Workshop 편집 맵을 바꾸지 않는다.

## 재현·검증 범위

`npm run test:training-layout`은 새 전장의 구성, 실제 8초 신체 물리, 접지/HP/프로필 불변, 적 행동 상한, 각 구역의 실제 예측/발사, 중앙 다중 명중을 확인한다. 발사 검사는 영웅의 사격 지점과 기예를 통제한 격리 실험이며 정상 입력 완주가 아니다.

`npm run capture:training-layout`은 d00c7bb와 현재 world.js를 같은 Native Canvas Scene/카메라로 캡처한다. 증거는 `_local/reports/training-layout/`에 생성한다. Native 이미지는 실제 브라우저·성능·Pages 검증을 대신하지 않는다. 캠페인 전용 encounter manifest의 stage 1–30에 허공터를 캠페인 장으로 거짓 등록하지 않는다. 브라우저 허공터 진입/반복 리셋/영웅 전환 및 게시본 검증은 최종 통합 검수에서 별도로 수행한다.
