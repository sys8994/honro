# 2막 재설계 · 구현 및 검증 기록

2026-10-03 현행 결과: 11~20장 10개 맵은 실제 전투 입력으로 전부 승리했다. 초기 정예 보정을 Game/Stage View 공통 컴파일에 넣어 화면·전투 수치를 일치시켰고, 동적 목표 라벨을 제외한 월드 화소 통합 67조건이 통과했다. 11~16장의 동시 적 행동 상한은 4, 17~20장은 3이며 밸런스 감사가 통과한다. 14장은 상층 끝에 착지한 뒤 하층으로 되돌아갈 때의 좁은 충돌 지형을 고쳐 75라운드/340행동으로 처음부터 완주했다. 동굴 원경 암벽·외곽 지층·좁아지는 출구와 19장 오래된 혼의 표식을 보강하고, 20장은 승인된 원경 형태를 유지한 순수 SVG 새벽 팔레트로 바꿨다. 상태 fixture 10장, 개편 조건 82개, 물리 이동 10장, 실제 브라우저 17묶음과 동굴 경계 화소 14곳이 통과했다. 과거 51/57라운드 승리는 검증기가 체력을 직접 더한 오류 때문에 폐기했다. 현행 장별 측정값과 그 한계는 [ACT2_QA.md](ACT2_QA.md)에 둔다. 아래 턴 범위는 실제 봇 완주 뒤 재보정한 계획값이다.

이번 화면 재수정 후 전체 `npm.cmd run verify`는 세 번 모두 기존 몬스터/조준 화면의 변동성 있는 프레임 예산에서 중단됐다. 기준을 낮추지 않고 각 검사를 단독 재측정했으며, 2막 전용 검사와 두 HTML의 순차 성능 18조건씩은 별도로 통과했다(최저 58.04/59.63Hz, 평균 렌더 최댓값 2.764/2.642ms, 브라우저 예외·예열 후 캐시 재생성 0). 단일 전체 검사 성공으로 표기하지 않는다. 실행별 수치와 자동 플레이의 한계는 [ACT2_QA.md](ACT2_QA.md)에 둔다.

기준 버전은 `e4ff5ec`이다. 이전 구현은 정상 이동 검사에 통과했지만 작은 단선 동선, 상호작용 위주의 승리 조건, 동굴 바깥의 야외 skirt, 비어 있는 배경과 부족한 서사로 사용자 요구를 만족하지 못했다. 이전 QA의 통과를 이번 개편의 완료 근거로 사용하지 않는다.

## 완료 판정 기준

1. 동굴 13–19장의 천장·좌우·아래가 같은 암반으로 이어지고 지정한 입구와 출구만 열린다. 게임·Workshop·Playtest, 최소 줌과 일반 줌, 가로·세로 화면, 네 경계를 실제로 검수한다. 시각 연장은 물리에 넣지 않는다.
2. 11–20장 각각 기존 가로·세로의 2배 이상. 지형을 그대로 확대하지 않고 교전 구역·경사·평탄한 건축 터·발판을 다시 작성한다. 기준 수치는 `tests/fixtures/act2-v1-baseline.json`에 고정한다.
3. 상호작용만으로 진행할 수 없게 제압·방어·구조·사격·호송을 연결한다. 지정 적과 필수 증원을 남긴 채 승리하지 못하며, 방어는 실제 라운드와 범위 내 생존·적 점거 여부로 진행한다. 장별 적 수·정예·증원·이동 거리·예상 턴수와 실제 정상 조작 결과를 대조한다.
4. 원혼등불은 18장 1개, 19장 2개만 둔다. 지역 반경 내 현형이며 다른 장에는 없다. 미현형 원혼은 소단만 식별하고 다른 동행에게는 약한 공기 떨림만 남긴다. 클릭·정보 카드·체력·상태·미니맵·피해 요약으로 위치/정체를 노출하지 않으며 피격 판정은 유지한다.
5. 장소별 건물·작업 도구·물길·살림·제의 흔적과 접지된 후경을 보강한다. 화면 반복 검수에서 나온 문제를 수정하며 노드 수나 스크린샷 개수를 미술 승인으로 대신하지 않는다.
6. 입장 대사는 8개 이내, 나머지는 구조·발견·전투 뒤에 나누어 전달한다. 석공과 아들, 승려의 증언, 종지기의 고의와 책임, 희생자의 이름, 생존자 귀환을 연결한다. 대사 큐·기록·저장 재개·정보 공개 순서를 검사한다.

위 여섯 항목과 전체 회귀·성능 검사까지 증명하기 전에는 완료 상태가 아니다.

## 구현과 저장

- `act2-plan.js`: 장별 크기, 제압 대상, 방어 시간, 유한 증원, 희소 등불, 예상 턴 범위.
- `act2-drama.js`: 개편 대사와 사건 장면. `act2-content.js`의 기존 목표는 옛 전투 호환용으로 유지한다.
- `act2.js`: 제압·점거 방어·파동·현형·보호·호송. 현재 목표와 완료 조건을 공유한다.
- `act2-caves.js`: 새 동선·천장·입출구·건축 터·벡터 자산·후경 지지면의 재현 가능한 원본.
- `cave-enclosure.js`: 실제 암반과 외부 시각 연장이 동일한 월드 좌표 gradient를 사용한다. 경계 밖 암반은 충돌에 추가하지 않는다.

새 전투는 `honroAct2Revision:2`와 목표 목록을 전투 안에 저장한다. revision 1의 기존 전투는 기존 목표와 저장 지형에서 계속한다. 재시도/새 진입에만 개편 맵이 적용된다. Workshop 사용자가 직접 작성한 맵을 강제로 다시 생성하지 않는다.

## 초기·중간 검수 기록 (역사)

- 화면 1차: 바깥 색 연결은 개선됐지만 천장에서 입구까지 직각 절단, 같은 장식 반복, 건물의 경사 매몰을 발견.
- 화면 2차: 입구 아치·얇은 발판·장소별 배치로 수정. 동굴 배경이 계속 비어 보여 공통 `scenicPurpose()`를 조사했고 2막을 허용하지 않는 장 번호 조건을 발견.
- 화면 3차: L2/L3의 실제 지지면·후경과 건축 터를 추가하고 묵종·암주 형상을 보강. 미술 전체 합격은 아직 선언하지 않았다.
- `node tests/act2-revision.mjs`: 53건 통과. 크기·노드·적·등불·진행 우회 방지·방어 시간/점거·지역 현형·피격·옛 목표·레시피 결정성 검사다. 완주나 미술 검수를 대신하지 않는다.
- `tests/act2-revision-browser.py iteration-1/2/3`: 각 16개 결과 묶음, 게임 10장·네 경계 화면·모바일 두 방향·영체 클릭·Workshop 5장, 브라우저 예외 없음. 실제 Playtest와 저장 재개 심화 검사는 아직 남아 있다.
- 1막 migration 및 환경 구조 검사를 한 차례 통과했다. 이후 수정이 계속되고 있으므로 최종 회귀는 다시 필요하다.
- 첫 정상 행동 봇에서 동료 오폭과 회복 반복을 관찰했다. 무조건 기본기만 쓰던 봇에 실제 장착 기예·진영 간격·우호 피해 회피를 반영하고 제한 실행으로 병목을 조사 중이다. 아직 개편판 10장 완주는 확인되지 않았다.

출력은 `_local/reports/act2-revision/`에 보관한다. 과거 `_local/reports/act2/`의 revision 1 완주 기록과 섞어 성공을 주장하지 않는다. 기존 `test:act2`의 고정 좌표와 순차 상호작용 fixture도 개편 목표에 맞춘 갱신이 필요하다.

## 2026-10-03 커밋 시점 검증

사용자의 커밋·원격 master 푸시 요청으로 현재 진행본을 보존한다. 재설계 완료나 전체 검사 통과를 의미하지 않는다.

- 장식용 `rock_large`의 충돌이 바닥과 겹쳐 지지면을 무효화하던 원인을 확인했다. 새 장식용 `act2:rock-bank`는 그림을 유지하고 충돌을 제거했다. 마을 상층 선반 끝과 평탄한 건축 터의 윤곽도 조정했다.
- `tests/act2-traversal.mjs`: 10개 장 통과. 적·문을 제외하고 이동 예산을 보충하는 물리 경로 검사이며 전투 완주 증거가 아니다. 경유점 높이의 엄밀한 확인은 추가 검증 대상이다.
- 최신 빌드 후 `tests/act2-revision.mjs` 53건, `tests/migration.mjs` 1막 10개 장 통과. `tests/act2-revision-browser.py prepush`는 16개 결과 묶음과 브라우저 오류 0건을 기록했다. 게임 14장 입구와 Workshop 18장 화면을 직접 확인했다. 환경 목록도 재생성하고 `--check`를 통과했다.
- `npm.cmd run verify`: 빌드·타입 검사 및 선행 검사 이후 `game/tests/balance-report.mjs`에서 exit 1. 13–20장의 동시 적 행동 상한 5–6명이 현재 허용 기준을 초과한다. 실제 난이도 검증 없이 허용 기준을 완화하지 않았다. 이후 전체 회귀·성능 단계는 실행되지 않았다.
- 별도 `tests/integration.py`: 11장의 Game/Stage View 화면 일치 검사에서 66픽셀 차이(비율 0.0001273, 허용 0.0001 미만)로 exit 1. 원인 분석과 남은 통합 검사가 필요하다.
- 제한 정상 행동 봇은 11장 100행동·22라운드에서 `knot-east`에 머물렀다. 개편판 완주로 계산하지 않는다. 봇의 재사용 대기 판정·보고서 경로 정리, 전투 완주·난이도 보정, 최종 미술·저장/Playtest 검증은 남아 있다.

이번 로그는 `_local/logs/act2-revision-prepush-verify.log`, `_local/logs/act2-revision-prepush-integration.log`, 화면은 `_local/reports/act2-revision/prepush/`에 있다.
