# 네 동행 캐릭터 제작·검수 기준

현재 설오·담허·휘겸·소단은 캐릭터 시트의 얼굴을 반영한 v008이다. v007에서 약 2배로 늘렸던 노드를 다시 늘리는 작업이 아니다. **v007 앵커 수의 ±5% 안에서 얼굴 형태와 이목구비 배치를 다시 작성**한다. 몬스터의 3배 예산과 구분한다.

## 제작 입력과 좌표 기준

- 실제 입력은 사용자가 제공한 `260916_설오_캐릭터시트.png`, `260916_담허_캐릭터시트.png`, `260916_휘겸_캐릭터시트.png`, `260916_소단_캐릭터시트.png`다. `tools/party-forge/references/`에 원본 그대로 보관한다. 제작용 PNG는 게임 HTML에 넣지 않는다.
- `references.json`에 각 PNG의 SHA-256·크기·얼굴 crop·게임 얼굴 crop·형태 지침을 기록한다. 생성기가 파일 해시를 검사한다. 휘겸의 초상은 왼쪽을 향하므로 제작과 비교에서 함께 반전한다.
- `portrait-shapes.mjs`는 **원본 PNG의 픽셀 좌표**로 얼굴 윤곽, 귀, 머리, 눈썹, 두 눈, 코, 입, 수염을 작성한다. 이름 있는 경로와 `part`가 파트 마스크다. 제한된 수의 곡선으로 직접 작성하며 자동 추적의 작은 조각이나 중복선을 가져오지 않는다.
- 캐릭터마다 한 개의 균일 배율과 평행 이동으로 게임 좌표에 옮긴다. 눈·입을 따로 임의 조정하거나 얼굴 가로/세로를 다르게 늘리지 않는다. `portraitMaps`의 원본/게임 기준점·배율·반전·이목구비 기준점이 rig JSON의 `face.authoringMap`에 남는다.
- 몸은 고정 v006 원본 `shared/assets/party.v006.runtime.js`에서 v007의 복식·모션 개선을 재현한다. 직전 비교 원본은 `tests/fixtures/party-v007.runtime.js`이며 SHA는 `references.json`에 고정한다. 과거 compact 설오 시안은 사용하지 않는다.
- viewBox `[-100,-140,880,680]`, 발 기준 설오 `[240,479]`/나머지 `[240,480]`, 기준 높이 415/415/425/399를 유지한다. 가려진 관절은 기존 pivot/parent·IK 길이를 따른다. v007의 리그·동작·무기 제약과 동일함을 검사한다.

## 앵커와 용량 예산

| 인물 | v007 → v008 앵커 | 변화 | 곡선 제어점 | 경로 / 색상 |
|---|---:|---:|---:|---:|
| 설오 | 514 → 512 | −0.4% | 71 | 92 / 18 |
| 담허 | 517 → 541 | +4.6% | 69 | 90 / 17 |
| 휘겸 | 458 → 480 | +4.8% | 53 | 93 / 20 |
| 소단 | 497 → 511 | +2.8% | 93 | 94 / 21 |

M/L/Q/C의 명시된 끝점을 윤곽·내부 경로 모두에서 집계한다. Q/C 제어점과 닫기 Z는 합산하지 않는다. 생성 시 v007 대비 **0.95~1.05배**를 강제한다. 휘겸은 얼굴에 예산을 배분하며 팔 보호구·옷단의 중복 장식선 두 개를 정리했다. 렌더러가 계산하는 활시위·화살은 고정 에셋 수에서 제외한다.

v008 에셋 런타임은 82,549 bytes, v007 79,117 bytes 대비 +3,432 bytes(+4.34%)다. 공통 리그 런타임은 17,540 bytes로 동일하다. `metrics.json`에 캐릭터별 raw/optimized SVG·rig/animation bytes·LOD 경로 수·제작 소스 SHA를 남긴다. PNG 참조와 이전 원본은 공방 전용이다.

## 형태와 팔레트

- 설오: 길게 갈라지는 앞머리·높은 묶음머리, 가는 턱, 낮은 눈꺼풀과 얇은 입. 코가 외곽에서 튀어나오는 옛 측면 다각형을 없앤다. 겉옷은 어두운 회록색, 하의는 시트의 어두운 색으로 맞춘다.
- 담허: 회색 관자와 짧은 상투, 무거운 눈꺼풀, 짧은 콧수염·턱수염. 예전 긴 흰 수염을 재사용하지 않는다. 먹빛 겉옷과 회색 안감·밝은 옷깃을 구분한다.
- 휘겸: 갓 아래 두 눈, 넓은 턱, 짧은 수염, 뺨의 흉터. 갓과 머리의 틈을 닫고 갓끈은 눈·입을 피한다. 남색 무복을 유지한다.
- 소단: 둥근 머리 덩어리, 긴 앞머리와 낮은 쪽머리, 작은 눈·코·입, 부드러운 턱. 턱 아래를 검은 머리로 가리지 않고 목과 귀를 연결한다. 상아색 겉옷에 **옷깃 안쪽·치마·소매/신발의 연보라색 포인트**를 복원한다. 붉은 머리끈을 유지한다.

피부는 바탕/그늘/따뜻한 면, 머리는 바탕/큰 밝은 면, 눈과 입은 제한된 선과 면으로 구분한다. 작은 눈에 과도한 흰자·반사광을 추가하지 않는다. 텍스처 필터와 래스터 삽입은 없다.

## 작성·런타임·모션

`recipes.mjs`가 v006을 복제해 v007 몸·모션을 만들고, `sheet-faces.mjs`가 기존 머리/목/머리꼬리를 시트 경로로 교체하고 색상을 적용한다. `build.mjs`는 SVG·rig JSON·animation JSON·런타임을 `shared/assets/party/`에 생성한다. 생성 SVG와 두 HTML만 직접 수정하지 않는다.

`shared/runtime/party-rig.js`의 머리 pivot `[240,143]`, 머리의 회전·이동만 허용하는 구조를 유지한다. 몸통의 비균일 늘어남/전단을 얼굴에 적용하지 않는다. v007에서 줄인 이동 발 들기·설오/휘겸 몸통과 옷자락 흔들림도 유지한다. 새 얼굴을 붙이기 위해 팔 길이·접지·무기 연결·동작 시간을 바꾸지 않는다.

`rebuild-game-adapter.mjs`는 엔진의 이동·충전·발사·피격·점프를 읽는다. 물리 좌표·충돌 크기·전투 수치·세이브는 미술 작업에서 바꾸지 않는다. 엔진 점프를 시각 root 이동으로 중복 적용하지 않는다. Game·Stage View·Playtest는 `shared/build.mjs`의 동일한 에셋·공통 렌더러를 쓰며 캠페인 적 소단에도 적용된다.

화면 높이 80px/160px 기준의 3단계 LOD를 유지한다. 주요 윤곽·눈·입은 남기고 작은 귀선·주름·봉제선을 생략한다. SVG는 상세 경로를 보존한다.

## 시각 검토와 반복

첫 비교 뒤 원본 좌표로 다시 작성하고, 연결부와 축소·모션 검토를 거쳐 네 번째 수정본까지 진행했다. `_local/reports/party-forge/iterations/`에 단계별 비교를 보관한다. 자동 검사 통과를 얼굴의 시각적 완성으로 판정하지 않는다.

1. **시트/벡터 직접 비교**에서 머리 덩어리, 귀·턱 길이, 눈 간격과 높이, 코·입, 수염/머리카락을 본다. v007/현재 전신·얼굴도 비교한다.
2. 256/128/96/64px, 밝은/어두운 배경, 좌우, 단색 실루엣을 확인한다. 64px에서는 표정보다 머리·갓·리본·도구의 식별을 본다.
3. idle/attack/move/jump_fall/hit 스크럽과 6시점 도감에서 얼굴 비율·목 틈·모자 연결·손/무기·발 접지·루프 경계를 본다.
4. 4인 × 5동작 × 101시점의 유한 행렬·머리 비율·관절 연결·팔 도달·대기 발 고정·루프와 양방향 조준 시위를 검사한다. PNG 해시/crop, 두 눈과 입의 얼굴 내부 위치, v007 리그/동작/제약 보존도 검사한다.
5. 두 HTML의 실제 발사 버튼 누름/뗌, 엔진 피해·점프를 확인한다. 세 화면 픽셀 일치·렌더링 상태 불변·편집 프로젝트 보존을 검사하고 실제 화면을 연다.
6. 다른 브라우저 부하 없이 전체 `npm run verify`를 실행한다. 구조적 통과와 직접 본 미술 평가를 구분한다.

```powershell
npm.cmd run build
npm.cmd run test:party
# _local/reports/party-forge/index.html 열기
npm.cmd run verify
```

공방에서 인물·동작·시점·방향·배경·실루엣·관절을 바꾸고 제작 소스 해시가 붙은 메모를 저장할 수 있다. `references.png`는 시트/현재, `faces.png`와 `comparison.png`는 v007/현재, `*-sizes.png`는 실제 픽셀 크기다. `browser.json`은 53개 구조/연결 검사, `VISUAL_REVIEW.md`는 관찰과 수정 이력이다. 보고서는 `_local/reports/party-forge/`, 과거 원본은 `_local/archive/party-v007/`에 둔다.

별도 정면 얼굴·립싱크·다양한 표정 세트·천 물리 시뮬레이션은 제공하지 않는다. 64px에서 세밀한 표정까지 읽는 것을 목표로 하지 않는다. 모든 실기기와 캠페인 모든 프레임을 수동 검수했다는 의미도 아니다.
