# 필수 사건으로 전달하는 단서

선택 원문 목록·읽기 버튼·기록 메뉴와 선택해서 읽으라는 안내를 없앤다. 대화는 이전 / 대화 넘기기 / 다음으로 제어한다. 이미 저장된 원문 필드는 삭제하거나 진행 조건으로 사용하지 않는다. 내부 스토리 기준서와 원본 자료는 보존한다.

| 장 | 플레이어가 하는 일·보는 변화 | 필수로 이해하는 사실 |
|---|---|---|
| 3 | 움막 기록함을 확보하고 동행과 행선지를 확인 | 마을 사람 열셋·아이 둘, 연목 주막에서 북문으로 이동 |
| 16 | 노승 구조·위협 제거 후 증언, 법당 개방 뒤 이송 기록 확보 | 사흘 두드림·종지기의 인양축 제거·작업굴 확인, 칠십 년 전 이송과 최근 사건 구분 |
| 17 | 실제 인양축 복구와 보호5턴, 작업대 일지 확보 | 문 잠금·축 제거와 사흘째 두드림 중단 |
| 19 | 기존 유품·천도 의식을 마친 자리로 소단이 다가가 확인 | 남은 혼은 옷차림부터 최근 희생자와 다르며, 표식은 무명사·잠운사·왕실·저문골을 연결 |
| 22 | 두 기록함을 각각 꺼내고 운반, 기존2턴 대조 유지 | 사술 제압 보고와 농가·아이·노인 호적의 모순. 학살 확정은 여기서 하지 않음 |
| 23 | 살아 있는 짐꾼의 운송 묶음을 풀고 호송 | 저문골의 시신·생활 금속이 무명사로 향함 |
| 24 | 사당을 열고 두 조사팀이 실제 입구 확인 | 보호지·기록실·공방·관아 뒤뜰 물길 관계 |
| 25 | 다섯 도착지의 생활 물품과 번호 관찰 | 같은 가족의 물품이 운송로 곳곳에 남음 |
| 26 | 숨은 기록실을 열고 조사 자료 확보, 주민 구조·자료 인계 | 조직적 저항 없이 대도사가 주민 전원 살해. 금속량 대응과 유골 처리의 미해명 부분 |
| 27 | 실제 첫 진목·네 도착지 이동·가족 명세 확보 | 물품 번호와 이름의 연결, 현장 길의 어긋남 |
| 28 | 수문·차단막 조작과 두 팀 합류, 구조한 기록의 작은 묶음을 현장에 놓고 대조 | 승인·현장 살해·사후 은폐의 세 책임 구분 |
| 29 | 기존2턴 봉인 해체를 보호하고 남은 자료 확보 | 비빙의·타종 후 어그러짐, 현묵의 보호 의도와 현재 행방 미상. 저편 정체·최종 진실은 공개하지 않음 |
| 30 | 나루에 실제 도착해 강 방향·막힌 길을 기존 이송 기록과 대조, 기존3턴 방어·집결 | 운송로 연결과 아직 남은 고향 사람들·최근 타종의 의문 |

작은 닫힌 소품의 운반·대조는 기존 Story의 직렬 cue와 저장 cursor를 사용한다. 소품에는 문서 본문을 월드에 쓰지 않는다. 렌더러는 상태를 읽기만 하며 목표/보상/전투 시간을 변경하지 않는다. 이동은 기존 엔진의 충돌·지지면 검사로 진행하고, 막힌 이동은 통과시키거나 순간이동하지 않는다. 이미 든 자료는 대조 때 다른 층의 인물에게 순간이동시키지 않는다.

검수는 `tests/required-story.mjs`, `tests/required-story-browser.py`, `tests/dialogue-controls-audio.mjs` 및 신규 exact runtime/campaign delta로 한다. 현재 브라우저 증거는 22장의 실제 두 상호작용·장면 Continue, 나머지 주요 장의 격리 이벤트 표본, desktop/mobile·Workshop·휴식터·디버그 제어다. 정상 자원 전체 캠페인 완주와 동일하지 않다. 최종 master 통합·공개 배포와 추가 장면 검수는 Stage17 P0 선배포 및 다음 단일 발행자 순서 뒤 진행한다.
