# 2막 지형 통합 검수

기존 지도 크기·충돌·배치·서사·카메라를 보존하고, 원경과 분리한 측면 근거리 벡터 재질만 적용한다. 기본 적용은 명시적 목록이며 미검수 파일을 자동 탐색하지 않는다.

- 캐릭터 높이92 유지. 캐릭터 축소로 맵 비율을 보정하지 않는다.
- SVG 감소는 불변 Inkscape RAW 합계 대비다. 개별 부품30%를 강제하지 않는다.
- 정상1×/2× 시각 오차 허용값은 그대로 유지한다. 실패한 접촉선은 원본 경로를 보존한다.
- 12장 시안 생성 프롬프트 원문은 일부 복구 불가. 재구성 설명을 원문으로 표시하지 않으며 전체 출처 기록 완료라고 주장하지 않는다.
- 15장 배수 후 드러나는 발판, 기계·서사 물체는 정적 그림에 합치지 않는다.
- 기본 훅은 Stage13 stoneFinish 다음, 서사 author 이전에 적용한다. 원본 훅 검수와 서사 적용 후 물리 검수는 분리한다.
- 브라우저 검수는 명시된 장 해금 fixture를 사용한 실제 UI 진입·이동·점프·저장 복구·화면 크기 검수다. 연속 캠페인이나 전투 클리어 검수가 아니다.
- 게임플레이 정량 검수의 실패·미측정 항목은 별도로 유지한다. 미술 통합 성공을 스테이지 전체 승인으로 승격하지 않는다.

단계: 원본 스켈레톤 → 측면 근거리 시안 → Inkscape 추적 → 보호 영역 최적화 → 실제 크기 시각 검수 → 원본/서사 기하 비교 → 새 빌드 검증 → 브라우저/저장 검수 → 게임플레이 검수 → 배포 확인.
