- 캐릭터 높이92 유지. 캐릭터 축소로 맵 비율을 보정하지 않는다.

- 정상1×/2× 시각 오차 허용값은 그대로 유지한다. 실패한 접촉선은 원본 경로를 보존한다.
- 12장 시안 생성 프롬프트 원문은 일부 복구 불가. 재구성 설명을 원문으로 표시하지 않으며 전체 출처 기록 완료라고 주장하지 않는다.
- 15장 배수 후 드러나는 발판, 기계·서사 물체는 정적 그림에 합치지 않는다.
- 기본 훅은 Stage13 stoneFinish 다음, 서사 author 이전에 적용한다. 원본 훅 검수와 서사 적용 후 물리 검수는 분리한다.
- 브라우저 검수는 명시된 장 해금 fixture를 사용한 실제 UI 진입·이동·점프·저장 복구·화면 크기 검수다. 연속 캠페인이나 전투 클리어 검수가 아니다.
- 게임플레이 정량 검수의 실패·미측정 항목은 별도로 유지한다. 미술 통합 성공을 스테이지 전체 승인으로 승격하지 않는다.

- 18장 V1은 수치상 오차 검수에 통과했지만 넓은 평행 띠 무늬 때문에 미술 검수에서 반려했다. 원본 크기는 유지하고 국소 시안을 재생성한 V2만 적용한다.

- 19장 독립 검수에서 공유18장 재질의 합법 천장 카메라 경계선이 발견되어18장은 통합 활성 목록에서 제외했다. 수정 후18/19 양쪽 가장자리 재검수 없이 다음 단계로 넘기지 않는다.

## 실행 환경 재발 방지

임시 worktree 정리 전 파일 변경 여부뿐 아니라 node_modules 등 공유 symlink의 역참조를 확인한다.2026-11-03 야간에 clean한 옛 배포 worktree를 정리하면서 Stage5의 공유 의존성 경로가 끊겼다. 저장소 코드·증거는 보존했고 retained collector 의존성으로 symlink를 복구했다. 이때 발생한 startup import 실패를 게임 실패로 집계하지 않는다. 공유 의존성은 유지되는 독립 경로에 두며 실제 heavy 렌더에만 짧게 락을 걸고 대기·추적·패키징까지 락을 점유하지 않는다.
