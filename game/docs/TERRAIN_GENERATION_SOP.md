기본 저작 절차는 [벡터 제작 SOP](VECTOR_AUTHORING_SOP.md), 장 통합은 [스테이지 제작 SOP](STAGE_PRODUCTION_SOP.md)를 함께 적용한다.

## 맵 끝 환경 연결 기준

2026-11-02 사용자 확인: 2장 좌우 확장 지질 처리의 느낌과 방식을 이후 제작의 기준 사례로 채택한다. 이는 해당 검수 이미지의 미술 방향 승인이지 브라우저·저장·게임플레이·배포 검사 면제는 아니다.

- **맵 끝도 같은 장소의 연속이다.** 플레이 지형만 섬처럼 놓거나, 좌우·하단을 큰 단색 벽으로 메우지 않는다. 본 지형의 암석 층·큰 명암면·색 계열이 비플레이 영역까지 자연스럽게 이어져야 한다.
- 현재 world domain과 실제 카메라 허용 범위를 먼저 읽고 시안의 확장 범위를 정한다. Play Bounds 밖을 숨기려고 카메라를 제한하거나 캐릭터를 줄이지 않는다. 별도 충돌 dummy/skirt를 만들지 않는다.
- 외곽도 **스켈레톤 가이드 → 이미지 시안 → Inkscape 추적 → 보호 오차 안의 최적화**로 제작한다. 반복 암석 타일이나 임의 코드 폴리곤으로 대체하지 않는다. 원경 이미지는 계속 별도다.
- 외곽은 플레이 영역보다 차분하게 그리되, 색 하나로 비워 두지 않는다. 거대한 단색 면, 과밀한 잡티, 같은 바위의 격자 반복을 모두 피한다.
- 플레이 영역 경계가 미술의 직사각형 절단선이 되면 안 된다. 같은 연속 지질을 뒤 절벽·지반 기초에 사용하고, 본체의 불투명 밑색이 확장 그림을 다시 가리지 않는지 확인한다. 밝은 암석 면도 캔버스 하단에서 일자로 끊기지 않도록 자연스러운 형태로 끝낸다.
- 비플레이 절벽 안에 실제 길처럼 보이는 보행선·테두리를 남기지 않는다. 실제 발판과 보행면의 가독성은 유지한다. 렌더 표시 교정과 물리 지형 변경을 구분한다.
- **필수 화면:** 기본 배율, 최소 줌 전체보기, 허용되는 좌우 최대 pan, 모바일. 형식 변환·용량 검사만으로 연결 미술을 합격 처리하지 않는다. 진짜 연결부를 크게 보고 색면 단절·틈·떠 있는 외곽·가짜 통로를 확인한다.

기준 사례: [2장 연속 지질 기준 사례](https://github.com/sys8994/honro/tree/ad1780c4bbaf35a6ffc950195243792bf459d8f4/art/act1-near-vector-candidates/stage02-continuous-v2). 맵 4300×3300은 유지하고 시안의 시각 범위만 x=-4000~8300, y=0~4500으로 넓혔다. 이 수치를 다른 장에 복사하지 말고 각 장의 원본 지형·카메라에서 다시 계산한다.
