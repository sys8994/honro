# 6막 10장 「다시 흐르는 길」: 출처 확인 전 지형·정서 카드

## 범위와 의도
확인된 기획 목차에서 10장은 외부의 종결부입니다. 9장의 「마지막 마당」에서 내외부 붕괴와 압박이 최고조에 이른 뒤, 10장은 동선과 시선이 다시 이어지는 사실을 먼저 보여 줍니다. 귀환 인원·특정 인물의 상태·대사·클리어 조건·보상·다음 이동을 사용자 기획 원문 없이 확정하지 않습니다. 이 장이 정식 전투인지 독립 에필로그인지도 보류합니다.

## 서로 다른 가설
- **A. 땅이 다시 이어지는 쪽**: 7,200×4,100 WU 일차 구상. 서쪽에서 낮게 굽은 산기슭에 닿고, 중간에 경사진 길과 돌아나온 높은 옛 석단이 갈라졌다가, 동쪽 잔존 석축의 평소 출구 앞에 이어집니다. 두 길은 조망·높이·실제 재진입이 달라야 합니다. 법칙이 정상이라 단조롭다고 보이지 않도록 자연적인 수직 굴곡과 땅이 만드는 화면 여백을 살립니다.
- **B. 경계에 남은 흔적을 돌아오는 쪽**: 가깝게는 뿌리와 절리로 이어진 언덕길, 멀게는 높지 않은 산열이 예전의 어긋남을 가만히 되새기게 합니다. 6-2 또는 6-7의 위치를 정확히 되짚을 필요가 원본에서 확인되는 경우에만 해당 좌표와 정식 카메라를 인용합니다. 확인되지 않으면 비슷한 상징을 같은 장소라고 부르지 않습니다.

## 우선 검증
A를 첫 안으로 둡니다. 실루엣은 새 게임에서 이전 장보다 눈에 띄게 잔잔하되 지형의 길·높이·여백 밀도는 보존합니다. 오후 회색에만 매이지 않고 절제된 새벽빛이나 회청색 희미한 부드러움을 PC·모바일 원경에 각각 검토합니다. 원경과 전경은 분리하며, 저층 여백에 원경 가짜 발판을 놓지 않습니다.
1. 전체 지형 축소 및 상하좌우 외곽 확대에서 목표를 모르는 사람도 출구 쪽 지형이 어디로 이어지는지 읽혀야 합니다.
2. 동선 실험에서 정상 걷기·일반 점프, 두 갈래의 독립 지형과 합류, 다른 높이 조망이 확인되어야 합니다. 서사를 위해 반드시 걷거나 싸워야 한다는 가정을 넣지 않습니다.
3. 후경에서만 잔존 붕괴와 약한 흐름 변화는 시험 가능하지만, 6-4·6-6과 같은 탄도 역전 상태를 10장에 자동으로 붙이지 않습니다. PC/모바일 동작 감소도 같은 방향이 읽혀야 합니다.
4. B가 원본에 맞으면 연결되는 장소의 실제 근거를 먼저 고정하고 카메라·대사·저장에 영향이 없는 부분만 교체합니다.
