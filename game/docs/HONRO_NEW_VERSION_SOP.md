# 혼로 새 버전 40장 제작 SOP — 작업 초안

## 우선순위와 기준선
- 사용자의 최신 지시와 승인된 스토리·세계관·취향이 우선이다. 1~40장을 빠짐없이 새 기준으로 다시 기획하고 시안부터 지형·게임플레이 구현·실제 플레이·정량 및 시각 검수·배포까지 진행한다. 사용자가 중단하지 않는 한 멈추지 않는다.
- 2026-11-06 확인 당시 기존 master 기준 커밋은 3e56b3427c33f50cdafb386a9854af46368d7a78이다. 이 커밋은 기존 소스의 식별자이며 별도 스냅샷/태그를 만들었다거나 현재 공개 페이지가 같은 SHA임을 뜻하지 않는다. 기존 v3 설계 파일과 이전 결과를 훼손하지 않고 보존한다. 기존 버전과 새 버전의 코드·기준·증거·배포 상태를 구분한다.
- 코덱스는 사용·재개하지 않는다. 막히면 원인을 밝히고 허용된 다른 방식을 찾으며 독립 작업을 계속한다. 접근 제한이나 승인 정책은 우회하지 않는다. 사용자 승인 대기를 이유 없이 새로 만들지 않는다.

## 1. 40장 공통 및 개별 정량 기획
- 장별 기존 원문·현재 구현·최신 사용자 지시·스토리/승패 조건·동행/지형·전투 역할·검수 근거를 먼저 대조한다. 원본과 개정안·현재값·실측값을 한 칸에 섞지 않는다.
- 각 장에 분량(턴·시간), 난도(정상 전략별 성공률·피해·적 실효 행동), 적 총예산·필수교전·일반/정예/중간/주요보스·공격 예고/대응, 맵 가로·세로·면적·종횡비·실제 활용구역, 유효 고저차·경로·점프·하강, 기믹·승패·화면 품질과 측정 방법을 정한다. 비전투·호송 등에는 해당 유형의 지표를 적용한다. 각 수치에 사용자 원칙과 해당 장의 이야기·전투/동선상의 근거를 남긴다. 기존 값을 유지해도 이유를 명시한다.
- 전 장을 나란히 비교해 난도는 장별 강약과 국소 편차를 두고 전반적으로 우상향한다. 패턴·협공·보스·목표 압박을 보며 턴/HP만 늘려 난도를 만들지 않는다. 평균 턴은 완만히 오르되 기존 v3의 20턴 상한은 기존 설계안으로 기록하고, 사용자가 허용한 예외는 사유와 실제 측정을 남긴다.
- 맵 크기는 초반 완만한 증가 후 비교적 일찍 수렴·포화하고 대부분 적정 편차 범위에 둔다. 스토리·지형·전투상 필요한 장만 큰 예외로 둔다. 가로·세로·면적과 기존 종횡비를 함께 정량 확인하며 수직형/복합형의 필요한 고도와 실제 이동을 함께 검토한다. 미검증 숫자를 확정값이나 통과 기준으로 가장하지 않는다.
- 전원 생존을 임의로 요구하지 않는다. 특정 장의 명시적 필수 생존 조건만 적용한다. 측정·설계 미완료 또는 근거 없는 예외는 통과가 아니다.

## 2. 스테이지별 지형 50%
1. [10점] 원경/지형, 기획·정량 목표·기존 지형 및 스토리와 연결 확인.
2. [10점] 플레이 동선·전투 스켈레톤과 원경·지형을 구분한 시안 제작 및 기획/레퍼런스 대조.
3. [10점] 공통/장별 플레이 지형을 Inkscape로 벡터화하고 필수 형상 보존 최적화. 원경은 이미지 레이어이며 충돌 지형과 분리.
4. [10점] 지형·충돌·발판·이동·카메라를 게임에 반영하고 필수 목표/저장 호환을 확인.
5. [10점] 전체 구조·접합, 보행 배율/가독성, 확대·축소·모바일 및 상태 변화 세 차례의 서로 다른 시각·지형 검수와 수정 후 재검수.

## 3. 스테이지별 게임플레이 50%
1. [10점] 장별 적·정예·중간/주요보스·기믹·동선·퀘스트·전술을 새 정량 기준과 이야기 맥락에 맞춰 설계.
2. [10점] 적·행동·전투·기믹·대사와 상태 전이를 구현하고 변경된 핵심 기능 확인.
3. [10점] 정상 성장·정상 입력으로 시작부터 종료까지 실제 플레이, 지형·스토리·승패·저장/복원 확인. 테스트 fixture와 실제 플레이를 구분.
4. [10점] 장에 맞는 여러 전략을 시험해 사전에 정한 목표 대비 실제 턴·성공률·피해·적 행동·전투/수직 이동 및 필요 지표를 측정. 재미와 반복/지루함은 실제 플레이 화면과 흐름을 별도 검토. 결함과 조작 문제를 구분하고 수정·재검수.
5. [10점] 최종 소스의 지형·게임플레이 종합 회귀, 필요한 빌드, master 통합과 기존 Pages 배포·공개 동작 확인. 최종 소스가 바뀌면 영향받는 항목은 다시 검증.

각 단계의 점수는 해당 단계가 확인된 경우에만 부여한다. 진행 중은 단계를 명시하고 임의의 완료 점수로 환산하지 않는다. 필요한 stage-specific 검수가 불가/실패/미측정이면 해당 점수는 미완료다. 한 장의 단계 점수 합은 0~100%, 지형과 게임플레이는 각각 최대 50%. 40개 장을 동일 비중으로 전체 진행률 = 40장 진행률 합 / 40으로 산출한다. 한 장 100%=전체 2.5%이며 실제 최신 기준의 원격 배포와 공개 확인까지 끝나기 전에는 해당 장을 100%로 표시하지 않는다. 공유 기획·SOP는 별도로 상태를 표시하고 장별 점수를 허위로 가산하지 않는다.

## 4. 작업 루프와 보고
- 40개 장 공통 기준을 먼저 만들고, 단계별 담당·파일 충돌을 분리해 가능한 작업을 병렬 처리한다. 각 변경 단위는 보존·커밋·원격 push하고, 통합/배포는 충돌 없이 관리한다.
- 매 30분 전체 %와 장별 지형·게임플레이의 확인된 단계, 완료/진행/실패/미측정, 차단 원인·해결 시도·재개 결과를 보고한다. 변동이 없다면 없다고 말한다. 각 장의 중요한 결과와 스크린샷은 그때그때 보고한다.
- 누적 실패는 감추지 않고 조작/게임 결함을 분리한다. 완료 여부·정량값·예외·시안·실제 게임·공개판을 혼동하거나 미검증 수치를 사실처럼 말하지 않는다.
