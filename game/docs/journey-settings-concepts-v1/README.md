# 여정첩 이미지 및 설정 UI 시안 — 2026-10-22

상태: 사용자 검토용 시안. 게임 런타임·master·Pages에는 미적용. 초상화는 사용자 요청으로 보류하며 기존 후보는 채택하지 않는다.

## 지도 설계

- 1막: 가로 3:2, 녹색 산촌·나루·폭포·북문 주변 군집·계단으로 연결된 두 마당.
- 2막: 세로 2:3, 지상11/12와 지하13~20을 절개도로 통합. 잠운사는 지하이며18/19는 거대 종 하나를 공유.20은 입구와 다른 출구.
- 3막: 정방형, 황토/석회/먹색 지붕/청록수로. 지상 하역장과 지하25/27 집하장 구별.24에서 두 조사 동선이 나뉘어28에서 합류. 실제 진행은25→26→27 순서이며 자유 분기 아님.
- 각 막 정확히10개 stage pin. 지도에 부착한 번호·텍스트·동선은 별도 SVG UI이며 원화에 포함하지 않는다.
- 모든 지점이 보이는 제작 검토용이다. 실제 적용에는 미방문 안개/해금 규칙과 모바일 확대·이동·고정 화면 크기의 터치 영역이 필요하다.
- 장소 관계를 우선한 제안 배치다. canonical terrain의 실제 축척이나 고정 방위라고 주장하지 않는다. 3막 점선은 조사 관계의 도식이며 도로의 정밀 좌표가 아니다.
- 휴식 없는 직접 진입은2,10,19,25,26,27,28. stage-map.json과 지도 하단 목록에 기록한다.

## 미술 과정 및 검토

부모가 내장 이미지 생성으로3장 제작했다. 첫 원화는 지리 요건에 비해 미세 묘사가 많아 전체 재페인트로 지붕/암반/수목을 큰 면 중심으로 정리했다. 이후 정확한 장 이름·10개 pin을 별도 UI에 연결했다. 초기 직선 진행선은 지형을 가로질러 실제 길로 오인될 수 있어 제거하고,3막의 지상/지하 조사 관계만 가는 도식으로 남겼다.

실제 픽셀 검토:1)장소·개수·공유 종·지하 사찰/집하장,2)막별 색/비율/밀도 및 첫 버전 대비 정리,3)표시 글자·번호·겹침·원화 분리. 마지막 전체3장을 확인했다. 이는 시안 품질 검토이지 게임에 적용된 실제 화면 검수나 전체 캠페인 검수가 아니다.

원화 full-resolution PNG와 라벨 포함 PNG를 사용자에게 전달했다. 저장소의 WebP는 가벼운 검토용 축소본이며 출시용 최종 자산이 아니다. 초기/재페인트 프롬프트를 보존한다.

## 설정 시안

정지 4행동(계속하기 / 설정 / 다시 걷기 / 휴식터), 설정 4범주(소리 / 화면 / 플레이 / 기록·관리), 소리 상세, 기록·관리 상세, 별도 흐름도 5장이다. 390×844 설계의 두 배 크기 벡터 시안이며 실제 게임 스크린샷이 아니다.

- 상세의 뒤로는 설정 첫 화면으로 간다. 설정의 ×는 진입점으로 복귀한다. 전투에서 들어왔다면 정지 메뉴다. 정지 ×와 계속하기는 전투를 재개한다. 배경 탭은 무동작이다.
- 설정은 기존처럼 즉시 반영·저장한다. 별도 적용 버튼은 없다. 효과음 55%, BGM 65%는 시안 표시값이며 실제는 저장값을 사용한다. 5% 단위를 유지한다.
- 화면에는 전체화면 실행, 방향 자동/가로/세로, 미니맵을 둔다. 브라우저 지원 제한을 안내한다.
- 플레이에는 기존 난이도명을 유지한다. 시안에 임의 명칭을 추가하지 않는다. 우리/적 행동 속도는 각각 1/1.25/1.5/2/3/4이고, 현재 전투의 목표·조작 안내를 둔다. 난이도는 현재 전투에 즉시 적용된다.
- 기록 파일 내보내기/가져오기와 주의 영역의 새 여정/검수 모드를 구분한다. 가져오기와 초기화 전 확인을 제안한다. 취소/파일 오류는 상태를 보존하고 전투를 재개하지 않는다.
- 검수 모드는 현재 전투를 멈추고 휴식터로 이동하는 기존 규칙을 보존한다. 디버그 중 가져오기/새 여정을 숨기고, 내보내기는 일반 기록을 사용한다. 임베디드 제약도 보존한다.
- 다시 걷기는 조건부 구간 재시작과 전투 처음부터를 다음 단계에서 구분하며 기존 자원·체크포인트 규칙을 유지한다.
- 터치 영역은 44px 이상, 목록 행은 65px, 닫기는 같은 위치다. 긴 내용은 본문만 스크롤한다. 계정/클라우드 저장/단축키 설정 등 미구현 기능을 추가하지 않는다.

이 설계의 생산 적용은 사용자 피드백 후 별도 작업이다.
