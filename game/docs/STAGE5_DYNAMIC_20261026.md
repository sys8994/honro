# Stage 5 노송 잔교 구현

승인된 B3 벡터 시안의 상부 암반·노송 발판과 하부 물길·왼쪽 입구 동굴을 실제 지형으로 저작한다. 시안 좌표에 y+1000을 적용한다. 폭6400, 시작(200,2420), 높은 잔교(3150,1497), 물길진(3460,2670), 주박목(5450,1330)이다. 기본 활2600·장거리 활3400·궁극3500의 현재 사거리는 보존한다.

`tools/map-forge/stage5-dynamic-geometry.json`은 승인 원본이다. `stage5-dynamic-art.json`은 승인 SVG에서 추출한 벡터 형상이다. 나무의 굵은 재질 선은 공통 장식 렌더 정책에 맞춰 저작 시 채워진 리본으로 변환한다. 얇은 윤곽선을 되살리는 전역 렌더 변경은 없다. 실제 나무 착지면과 동굴 천장·오른쪽 벽은 별도 canonical terrain이며, 벡터 그림에서 충돌을 추론하지 않는다. 오른쪽 원본의 맵 밖 x6650은 Play Bounds 경계6400으로 투영한 뒤 공통 terrain-domain 확장을 적용한다.

초기 적12·유한 사슴 증원6·행동 상한·전투 수치·참가 동행·임무 완료 조건은 보존하고 역할 군집을 새 길에 배치한다. 증원은 하부 실제 지형을 추적한다. 물길진 유지, 주박목 파괴, 완료된 적 페이즈2회라는 기존 계약을 유지한다. 서사 개편은 하지 않는다. 지도 revision5는 호환되지 않는 진행 중 Stage5 전투만 재시작하며 성장·SP·장비·완료 기록과 사용자 Workshop 지도는 보존한다.

## 집중 확인 현황

- 생성기 재실행은 동일하다. 적용 스크립트는 다른29장 불변을 확인한다.
- 명시된 입구 점프와 발판 연결로 상부 진단 이동 통과: 5회 점프, 피해0. 하부 동굴 진단 이동도 피해0으로 통과했다. 이 검사는 고립 몸체와 이동 예산 갱신을 사용하는 물리 진단이며 정상 전투 완주 증거가 아니다.
- 초기 탄도 검사에서 시작·낮은 발판·중간 발판의 A01 타격은 없었고 높은 잔교 A01 실발사로101 피해를 확인했다. 이후 닫힌 낙수의 고각 우회와 열린 낙수의 좁은 사선을 발견하여 동일한 렌더/유체 형상을 수정 중이다. 최종 물줄기에서 잔교 x3080/3150/3220/3290의 A01 실발사는 각각133 피해를 줬다. 닫힌 낙수·시작·낮은 자리·중간 자리 A01, 낮은 자리 A14, 동굴 M01/M06은 명시된 탄도 탐색에서 목표를 맞히지 못했다. 중간 나무 가지 A14의 합법적인 단축 사선은 유지한다.
- 1차 전체 구조: `pass1/stage-5-overview.png`. 상하 동선과 높은 주박목의 위치를 확인했다.
- 2차 재질/가독성: `pass2/stage-5-tree-detail.png`, `pass2/stage-5-cave-detail.png`. 공통 장식 정책 때문에 빠졌던 굵은 나뭇가지/버팀대를 채워진 재질로 복원했고 공중에 남았던 휴식 표식을 높은 잔교에 접지했다.

위 증거의 루트는 Git 제외된 `_local/reports/stage5-dynamic-20261026/`이다. 생산 HonroScene/Engine의 native Canvas 캡처이며 브라우저 HUD/실제 입력 확인과 구분한다. 3차 모바일/상태 변화는 `pass3/stage-5-mobile-tree.png`, `pass3/stage-5-mobile-cave.png`, `pass3/stage-5-high-shot.png`에서 가지 착지면·동굴 입구·열린 낙수의 실제 사격창을 확인했다. Alt 하강은 세 발판 모두 통과했으며 중간 가지의 다음 착지면은 약97 아래 처마여서 임의100 낙하 검사 임계값을20으로 바로잡았다. revision4→5의 구전투 재시작, 성장/현재 전투/Workshop 보존, 물 상태 반복 적용도 통과했다. 최종 종합, 필요한 빌드와 짧은 정상 입력은 진행 중이다. master/Pages는 부모 검토 전 보류한다.
