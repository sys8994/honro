# 몬스터 체급 개편 구현 — 2026-11-18

기획: [MONSTER_SCALE_PLAN](planning/monster-scale-20261118/MONSTER_SCALE_PLAN.md). 사용자 승인("추천한대로 다 진행"), 장승 3.8m로 변경.

## 적용 범위
- `shared/runtime/monster-scale.js`(모델), `monster-scale-art.js`(표시), `shared/engine/src/monsterPatterns.ts`(큰 어둠 구역·2라운드 축소)만 수정했다. 장 데이터·충돌·이벤트·revision은 바꾸지 않았다.
- 캠페인 신규 전투에만 `b.honroMonsterScaleRevision=1`을 기록한다. 이전 전투 스냅샷·사용자 지도는 기존 몸을 유지한다. `G.HONRO_MONSTER_SCALE_DISABLED=true`로 전체, `HonroMonsterScale.OFF_STAGES`로 장별 해제한다.
- 키(`u.h`)를 바꾸면 그림·피격 직사각형이 함께 커진다. 폭(`r`)은 배율^0.6, 상한 46(일반)/52(거대)/60~64(중간 보스).
- HP는 표의 배율만큼, 맞춤 단계가 줄면 비례해 덜 올린다. 대형 보행속도·이동력 0.8~0.9배. XP는 변경 없음.

## 맞춤 검사
- 머리 위 여유(일방 발판 제외)와 `validTerrainContactPose`로 목표 크기를 검사하고, 실패하면 100→85→70→55→40% 단계로 줄인다. 모두 실패하면 원래 몸을 유지하고 `b.honroMonsterScaleLog`에 남긴다.
- 목표물(상여 결박 등) 바로 옆의 일반 적은 시작 시 원래 크기를 유지하고, 전투 중 목표물 옆으로 걸어오면 원래 몸으로 돌아갔다가 벗어나면 다시 커진다(사선 보존).
- 성장·팽창도 같은 검사를 거치며 줄어들 때는 바로 줄인다. 이후 생성되는 증원·5막 예비 병력도 생성 경로와 미션 틱에서 같은 규칙을 적용한다.

## 기믹
- 3장 나루장승: 머리 위 132px는 일방 징검돌이었다. 실제 자리는 하늘이 트인 저지대라 이전 없이 6.5m가 들어간다. 기획의 이전안은 필요 없어 장 데이터를 바꾸지 않았다.
- 큰 어둠(46장 우물 바닥): 이동하지 않는다. 피격되거나 영웅이 그림자 구역(반폭 380/480/580px) 안에서 행동을 마치면 자라고, 조용한 2라운드 뒤 한 단계 줄어든다. 예고 후 내려치기는 구역 안에만 닿는다. 구역 밖 영웅으로는 깨어나지 않으며 승리 조건이 아니다.
- 2막 16장 잠운사 지하 동굴 안쪽 어둠에 큰 어둠 실루엣을 표시만 한다(사용자 지정: 2막 동굴·3막 지하 후보 중 선정, 처음 둔 1막 5장 폭포 웅덩이에서 이동).
- XL 이상 몸은 처음 깨어날 때 1.5초 카메라를 맞추고, 확대된 지상 적에게 단색 접지 그림자를 그린다.

## 미결·사용자 결정
- 큰 어둠 처치 보상: 장비 원장은 장·막별로 설계된 항목만 지급한다. 처치 사실만 `b.honroEquipmentFacts.greatDarkness`에 기록했다. 지급 아이템(기존 항목 또는 신규 설계·아이콘)은 사용자가 결정해야 한다.
- 큰 어둠 전용 그림: 현재 기존 `eoduksini3` 리그를 임시로 쓴다. 전용 키 큰 그림의 제작 방식은 사용자가 결정해야 한다.
- 40장 선착장 포격귀(중간 보스)는 선착장 아래라 공간이 부족해 원래 크기를 유지한다.

- 브라우저 1~50장 신규 진입(이야기 난이도, 목표물 보존 규칙 반영): 확대·단계 축소·공간 부족·목표물 옆 유지 수는 장별로 `honroMonsterScaleLog`에 남는다. 최종 집계 1,196명 중 약 410명 확대, 22명 공간 부족 유지, 18명 목표물 옆 유지. 지형 자세 오류 0, 페이지 오류 0(31·39·40장은 로딩 대기 연장 후 재측정).
- 성장·팽창 동기화: 어둑시니 152→239→291, 그슨대 110→245→110, 큰 어둠 606→788(구역 행동 성장)·16m 화면 확인.

- 1막 기본 봇(기존 대비): 6장 승리 17→18라운드. 3·1장은 기존과 같은 봇 한계로 미결. 8장은 기존 12라운드에 첫 결박을 끊었으나 개편 후 봇이 커진 장승(s8-7)을 먼저 처치한 뒤 결박 위에 겹쳐 서서 발사하지 않는 봇 고착(18라운드 이후 위치 고정, 결박 HP 230)으로 미결. s8-7만 원래 크기로 두면 기존과 같아 진행 순서 차이로 판단한다. 사람 플레이 확인이 필요하다.
