# 변경 구간의 교전 확인

## 범위

지형·동선·적 배치·정예·증원·활성화·행동 선택을 바꾸면 이 문서의 해당 기준과 [캠페인 적 배치 기준](ENCOUNTER_PLACEMENT.md)을 참고한다. 바꾼 구간의 이동·교전·퀘스트 진행만 확인한다. 배경/장식만 바꾸면 결과 이미지와 필요한 모션·가독성을 확인하며 전투 검사를 추가하지 않는다. 문서만 바꾸면 문구·링크만 확인한다.

## 설계 기준

혼로는 발사만큼 이동, 좋은 위치 선점, 다양한 동행과 기예 활용이 중요한 포격 RPG다.

- 장소·지형에 맞게 전위·사수·지원·정예의 역할 군집을 둔다. 길 전체를 등간격 적이나 작은 난수 오차로 채우지 않는다.
- 실제 걸을 수 있는 높이와 층, 차폐·사선, 우회·퇴로가 선택을 만드는지 본다. 그림 속 발판은 이동 경로가 아니다.
- 군집 사이 여백은 접근 선택·재정비·위협 예고·퇴로를 위한 것이다. 멀리 고립되어 영향을 못 주는 적을 의도된 여백으로 설명하지 않는다.
- 초기 병력·정예·유한 증원·동시 생존 상한·실제 행동 상한을 구별한다. 모든 장에 같은 군집 반경·정예 비율·첫 행동 라운드·피해량을 강제하지 않는다.
- 기존 봉인·구조·호송·방어 사건에 맞는 반응을 만든다. 승인되지 않은 목표·서사·승리조건·파티 분할을 추가하지 않는다.

## 필요한 확인

1. 수정한 구간에 진입해 이동과 해당 퀘스트가 진행되는지 짧게 확인한다. 기존 검사나 계산으로 확인 가능한 항목은 재사용하며 대량 신규 테스트를 만들지 않는다.
2. 배치/행동을 바꾼 군집·파동은 실제 지지면과 사선에서 의도한 역할을 하는지 본다. 제자리 대기·표적 없는 발사·도달하지 못한 추격은 실효 행동이 아니다. 피해 외에 제압·회피·경로/위치 변경·기예/동행 선택·목표 방어 압력도 실제 영향이다. 모든 파동에 피해를 강제하지 않는다.
3. 증원 생성 조건을 바꿨다면 해당 예고·입장·첫 행동을 확인한다. 점유 대기/대체 입구, 중복 방지, 취소·Continue는 그 로직에 영향을 준 경우에만 확인한다. 이동한 보스/NPC의 현재 전장과 입구가 연결되는지 본다.
4. 저장/스키마/진행 경계를 바꿨다면 관련 옛 저장과 신규 진입을 선별 확인한다. 기존 전투의 지형·배치·HP·목표·성장을 보존한다.
5. 확인한 동작·결과·관련 결함·미확인 범위를 짧게 보고한다. Native 진단, 실제 브라우저, 준비 세이브, 정상 연속 플레이를 구분한다. 확인하지 않은 전체 캠페인이나 성능을 통과로 표현하지 않는다.

알려진 수정 범위의 무기능 군집/파동이나 진행 불가가 있으면 해결 전까지 그 항목은 미완료다. 무관한 장의 미확인 항목이나 형식상 증거 누락 때문에 작은 수정 전체를 차단하지 않는다. 총원·완주·테스트 개수·해시만으로 미관과 재미를 승인하지 않는다.

### 관련 결함을 고칠 때 참고할 기존 사례

- `stage8-first-seal`: 서쪽 산개 3체가 R8에 나타나 R12에 처음 행동했지만 총 7행동이 제자리였고 피해 교환·플레이어 대상 행동이 없었다.
- `stage8-low-health`: 보스가 중앙으로 이동한 뒤 동쪽 산개 2체가 옛 뒤쪽 입구에 나타나 약 2,000 거리에서 전투를 마쳤다.

이 사례는 과거 관측이며 현재 수정본의 실패 판정이 아니다. 해당 결함을 고칠 때만 같은 파동의 현재 경로·사선·실효 행동을 비교한다.

## 선택형 관측 도구

기존 `npm run encounter:review -- help`, `tests/encounter-evidence-gate.mjs`와 [조건부 파동 도구 계약](ENCOUNTER_CONDITIONAL_DISPOSITIONS.md)은 상세 관측 자료를 정리하거나 도구 자체를 수정할 때 재사용할 수 있다. manifest 작성·해시 묶음·전 장 inventory·별도 검수자·증거 gate 통과는 일반 수정의 필수 절차가 아니다. 도구를 선택하면 그 도구의 입력 계약을 지키며 합성 fixture 성공을 실제 맵 합격으로 표시하지 않는다.

`npm run test:encounter-evidence`는 관측 도구 자체의 회귀 검사다. 배치·디자인·문서 수정마다 실행하지 않는다. 기존 테스트와 도구는 보존한다. [복원된 review-job](RECOVERED_REVIEW.md)도 선택형 도구이며 별도 전체 검수나 발행 승인 의무를 만들지 않는다.
