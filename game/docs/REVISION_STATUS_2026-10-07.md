## 검증 해석

현재 화면에는 엔진 소모품 명령이 노출되어 있지 않다. 과거 개별 장 입력봇과 초기 분할 진단의 해당 명령 사용은 엔진 진단으로만 보존하며, UI 가능 완주나 난도 합격으로 해석하지 않는다. 소모품 필드는 저장 호환상 유지한다.

새 연속 진단은 준비된24장 한 번의 입장 뒤 실제 App 결과 전환으로25→26→27을 이었다. 이동·기술·상호작용·App 방어만 사용했고 체력/좌표/목표/가방을 강제로 바꾸지 않았다. 공통 저체력 방어 정책에서28/38/23/24라운드에 각 장을 마쳤다. 이는 DOM/Canvas 대역의 입력봇 증거이며 브라우저 연속 완주·모든 난이도·사람의 재미 판정을 대신하지 않는다. 실패한 앞선 시도도 보존한다.
