# 설오·휘겸 기본 공격 음향 라우팅 진단

조사 기준은 `9ed5e01d892e75b003b4009d41cb56e538784f9e`와 그 커밋의 기존 생성물 `game.37e461ef6104b3e5.js`다. 이 브랜치는 진단 문서와 재현 검사만 추가한다. 제품 코드·음원·DOM·빌드·master·Pages를 변경하지 않는다. 다음 음원 후보와 중첩 조정은 별도 승인 후 진행한다.

## 관측

실제 App의 허공터 진입과 기본 장착/선택, 키보드 충전·해제, Engine 이벤트, Chromium의 실제 AudioBufferSource.start/stop을 추적했다. 명중·지형 충돌은 살아 있는 연습 전투에 준비했고 치사/비치사를 분리했다. 충전1.25초 표본이며 저장소의9ed 빌드를 로컬 HTTP로 실행했다. 사용자의 공개 플레이를 녹음하거나 실기기로 청취한 검사가 아니다.

| 구간 | 설오 기본 A01 | 휘겸 기본 S00 | 자산 노드 gain |
| --- | --- | --- | --- |
| 충전 attack | bow_charge.mp3 | qi_charge.mp3 | 1 × 충전 그룹 |
| 충전 loop | bow_charge_loop.wav | qi_charge_loop.wav | 0→1 × 충전 그룹 |
| 발사/휘두름 | bow_release.mp3 | sword_swing.mp3 | .80 / .75 |
| 명중 | bow_hit.mp3 | sword_hit.mp3 | .75 / .75 |
| 일반 지형 충돌 | arrow_block.mp3 | 별도 지형음 없음 | .45 / 없음 |

충전 그룹 gain은.22→.40이며1.25초 표본에서 약.306이었다. 여기에 사용자 master 볼륨이 별도로 곱해진다(첫 조사에서는.55). 충전rate는1, 물리 단발음rate는 고정 순서1/.98/1.02/.99/1.01이다. 실제 시작에서1/.98/1.02를 확인했다. 휘겸 S00은 launch 이벤트 자체로는 소리를 내지 않고 실제 stroke에서 sword_swing을 낸다. 일반 지형은 평참의 타격 대상이 아니며, 별도 authored melee 대상 계약은 이번 검사 범위 밖이다.

- 기본 장착은 A01/S00 그대로이며 미분류로 떨어지지 않았다. 활/검의 launch/hit 파일·AudioBuffer 객체·디코드 PCM SHA256은 서로 달랐다. 요청한 served MP3 바이트와 v2 원본도 대조한다.
- 휘겸의 **qi 충전 공유는 실제 동작**이다. 담허·소단과 같은 qi_charge/qi_charge_loop를 쓴다. 이번 표본에서 qi_launch가 무기 발사를 대신 재생하지는 않았다.
- 치사 명중에서는 두 무기 모두 공통 구 procedural **down**(.57초)이 타격과 동시에 재생됐다. 비치사 명중에는 없었다. down은 개별 감쇠 노드 없이 master에 직접 연결되어 암묵 배율1이고 타격의 개별gain은.75다. 이 수치는 **서로 다른 파일의 체감 음량 비교가 아니다**. 파형·스펙트럼·마스터 출력 처리까지 다르므로 down이 더 크게 들린다고 단정하지 않는다.
- 휘겸의 실제 명중에서는 sword_hit와 sword_swing이 같은 실행 창에 겹쳤다. 치사 명중에는 down까지3겹이다. 이는 관측된 중첩이며 이번 브랜치는 이를 제거하지 않는다.
- 구 arrow/sword/hit procedural 공격음이 approved 무기음을 대신 재생하거나 덮는 경로는 A01/S00 표본에서 없었다. 공통 down만 별도로 관측됐다. 모든 스킬/장면에 일반화하지 않는다.

## 재현

기존 의존성/Chromium이 있는 환경에서 `python tests/weapon-sfx-routing-browser.py`를 실행한다. 기존 빌드를 사용하며 새 빌드나 전체 캠페인 검사는 필요 없다. 테스트는 A01/S00 각각 발사·치사 명중·비치사 명중·일반 지형8표본에서 기본 선택, 실제 자산/gain/rate, 공통 down의 치사 경계, 검 타격/휘두름 중첩, 버퍼/PCM 분리, served 원본 바이트를 확인한다. 현행 중첩을 **관측 기준**으로 보존하는 검사이며 향후 개선의 목표 동작으로 강제하는 정책은 아니다. 승인된 소리/중첩 변경 때 기대값도 함께 검토해야 한다.

결과 JSON은 `_local/reports/weapon-sfx-routing-20261023/routing.json`에 기록하고 Git에는 넣지 않는다. 이전 첫 관측은 `_local/reports/skill-sfx-routing-20261023/{routing,routing-nonlethal}.json`에 남겼다. 읽기/재현 범위이므로 빌드·주관적 청취·실기기 Android/Safari·공개 배포는 수행하지 않는다.

이번 보존 검사 실행은8표본·64개 확인을 통과했고 브라우저 예외는0개였다. 이는 위 라우팅 관측의 재현 결과이며 청취 품질 승인이나 수정 배포 완료가 아니다.
