# 혼로 스토리 v0.1 반영 계약

기준: 사용자 제공 `HONRO_스토리_기획_v0.1.pdf` 26쪽 전문(메인 스토리 기준안·2막 수정안·3막 러프 기획). 기존 공간·전투·퀘스트와 저장 구조를 유지하며 문장과 공개 순서만 정비한다.

## 활성 원본과 호환성

- 1막: `shared/runtime/story-content.js`.
- 2막: `act2-content.js`의 기본 대본·목표·요약 위에 `act2-drama.js`가 현재 대본을 적용하고 `act2-plan.js`가 기존 전투 목표를 확장한다. 구형 전투도 같은 공개 범위의 기본 문장을 사용한다.
- 쉼터: `journey-content.js`의 필수 도착 설명은 전체 서술과 일치시킨다. 선택 대화는 이미 확인한 사실만 다루며 필수 사건의 대체 수단으로 사용하지 않는다.
- `act1-v6:`, `act2-v1:`, `act2-r2-*`, `rest-interlude-v1-*`, `rest-optional-v1-*` ID와 사건 키는 유지한다. 이미 저장된 대화 큐·페이지와 전투 상태를 소급해서 바꾸지 않는다.
- 기존 sign 상호작용은 길표의 진 한 축을 푸는 행동으로 설명한다. 새 이동 반복 기믹이나 진법 시스템을 추가하지 않는다.

## 1막과 2막 초반

- 1막은 들림 급증과 정체를 모르는 종소리만 남긴다. 나무꾼이 산에 절이 없다고 전지적으로 확정하지 않으며 저문골·무명사·대도사·현묵은 공개하지 않는다.
- 2-1: 연목 주민과 옛 지도에는 북쪽 깊은 산의 절·동굴 정보가 없다. 홍만의 장부는 북문 뒤부터 비어 있다. 장부에 고갯길이 적혀 있었다는 기존 불일치를 제거한다.
- 2-2 「돌아오는 산길」: 같은 바위·마른 소나무·돌탑을 반복해서 지난다. 담허가 돌림진과 자신이 배운 법의 닮음을 알아보고 기존 sign 사건에서 한 축을 푼다. 현묵의 이름은 아직 모른다.
- 2-3 「숨은 석문」: 진 너머 함몰지·하늘빛이 드는 석문 공간을 처음 발견한다. 주민은 세대를 이어 살았고 대종 타종과 바깥길 개설의 금기만 전한다.

## 검증 상태

초반 문장 수정 단위: `node tests/journey-content.mjs` 통과. 전체 서사·저장 회귀, 활성 지도 표시 문장 동기화와 최종 빌드·배포 검수는 중후반 수정 단위와 통합 검사에서 수행한다. 이 문서는 이 상태를 전체 QA 완료로 표시하지 않는다.
