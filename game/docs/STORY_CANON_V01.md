# 혼로 스토리 v0.1 반영 계약

기준: 사용자 제공 `HONRO_스토리_기획_v0.1.pdf` 26쪽 전문(메인 스토리 기준안·2막 수정안·3막 러프 기획). 기존 공간·전투·퀘스트와 저장 구조를 유지하며 문장과 공개 순서만 정비한다.

## 활성 원본과 호환성

- 1막: `shared/runtime/story-content.js`.
- 2막: `act2-content.js`의 기본 대본·목표·요약 위에 `act2-drama.js`가 현재 대본을 적용하고 `act2-plan.js`가 기존 전투 목표를 확장한다. 구형 전투도 같은 공개 범위의 기본 문장을 사용한다.
- 쉼터: `journey-content.js`의 필수 도착 설명은 전체 서술과 일치시킨다. 선택 대화는 이미 확인한 사실만 다루며 필수 사건의 대체 수단으로 사용하지 않는다.
- `act1-v6:`, `act2-v1:`, `act2-r2-*`, `rest-interlude-v1-*`, `rest-optional-v1-*` ID와 사건 키는 유지한다. 이미 저장된 전투 대화 payload·큐·페이지와 전투 상태를 소급해서 바꾸지 않는다. 쉼터는 기존부터 ID·index만 저장하므로 같은 ID·문단 수·페이지를 유지하며 수정된 현재 문장을 표시한다. 옛 쉼터 문구 자체를 보존하는 저장 형식 변경은 하지 않는다.
- 기존 sign 상호작용은 길표의 진 한 축을 푸는 행동으로 설명한다. 새 이동 반복 기믹이나 진법 시스템을 추가하지 않는다.

## 1막과 2막 초반

- 1막은 들림 급증과 정체를 모르는 종소리만 남긴다. 나무꾼이 산에 절이 없다고 전지적으로 확정하지 않으며 저문골·무명사·대도사·현묵은 공개하지 않는다.
- 2-1: 연목 주민과 옛 지도에는 북쪽 깊은 산의 절·동굴 정보가 없다. 홍만의 장부는 북문 뒤부터 비어 있다. 장부에 고갯길이 적혀 있었다는 기존 불일치를 제거한다.
- 2-2 「돌아오는 산길」: 같은 바위·마른 소나무·돌탑을 반복해서 지난다. 담허가 돌림진과 자신이 배운 법의 닮음을 알아보고 기존 sign 사건에서 한 축을 푼다. 현묵의 이름은 아직 모른다.
- 2-3 「숨은 석문」: 진 너머 함몰지·하늘빛이 드는 석문 공간을 처음 발견한다. 주민은 세대를 이어 살았고 대종 타종과 바깥길 개설의 금기만 전한다.

## 2막 중후반과 공개 한계

- 2-4: 주민은 종의 기원을 모르고 “절보다 종이 먼저”라는 구전과 최근 몇 해의 자발적 타종만 전한다.
- 2-5: 막힌 상부 수직공과 녹슨 대형 인양 고정구는 오래전 외부 이송의 흔적이다. 새 정 자국의 원형 홈과 밖에서 끊은 손잡이는 최근 종지기 사건의 흔적이다. 두 시대를 구분한다.
- 2-6: 칠십 년도 더 된 “대종 일 좌” 이송 기록, 출처 봉인·삭제, 타종 금지, 상부 인양로와 바깥길 폐쇄, 산길 진 유지 기록을 발견한다. 담허는 자신의 법과 표식의 닮음을 말하되 아직 누구의 일인지 단정하지 않는다. 희생자가 사흘간 살아 있었다는 현재 증언은 따로 남긴다.
- 2-7~8: 종지기는 정확한 과거를 모른 채 불완전한 경고를 해석했다. 최근 석공·주민·젊은 승려를 가두고 구조를 방해한 고의와 책임, 그릇의 과포화와 연목 유출은 유지한다. 오래전 제작자의 전모를 아는 대사로 만들지 않는다.
- 2-9: 현재 희생자를 보낸 뒤 더 오래된 복식의 혼이 남는다. 무명사→잠운사 이송 표식, 왕실 봉인, 저문골 지명을 기존 old-soul 발견에서 확인한다. 이전 갑옷·깃대 단서는 제거해 저문골을 군사 집단으로 오인시키지 않는다. 오래된 혼을 모두 보냈다고 단정하지 않는다.
- 2-10: 과포화에 따른 연목 들림 급증은 수습했다. 최근 자발적 타종의 원인은 미해결이다. 이 규모의 왕실 관련 운송·봉쇄 장부를 찾으러 큰 읍성 문서고로 향한다. 다음 막 표시는 「지워진 기록」이며 아직 playable 상태로 바꾸지 않는다.
- 1·2막에 현묵 악역설, 담허의 확정된 죽음, 대도사의 정체·목적, 저문골 학살과 종 제작법, 무명사 내부의 전말을 삽입하지 않는다. 저문골의 정체·휘겸 가문의 연결은 후속 막에서 기록으로 밝혀야 한다.

## 고정한 검증

- `npm run test:story-canon`: 20장 비문장 규칙·퀘스트 순서·ID·전투 수치, 전체 지도 지형·AI·유닛·에셋·초기 상태의 원래 해시, 필수 쉼터 페이지 수와 정보 공개 경계를 검사한다. 지도에서 바꾼 것은 제목·설명·표시 라벨뿐이다.
- 같은 명령의 App 회귀 17사례는 기존 12·16·19·20장 대화/대기 큐의 export→import→Continue, localStorage 재개, 12·13장 쉼터의 모든 중단 페이지, 선택 대화 3개를 확인한다. DOM·Canvas·storage는 대역이며 실제 App/저장/이야기 경로를 사용한다.
- 공간 계약 fixture의 서사 필드와 표시 라벨은 새 대본에 맞춰 갱신하되 변경 전 비문장 필드를 비교한 뒤 갱신했다. 새 `story-canon-v01-baseline.json`은 수정 전 d2e7b22의 게임플레이/지도 해시와 옛 대화 payload를 별도로 고정한다. 실제 이전 저장 fixture는 수정하지 않았다.
