# 스테이지 제작 SOP v1.0

장 개편은 아래 순서로 진행한다. 각 단계의 검수는 해당 변경의 짧은 확인이다. 전 장 재플레이·전체 verify·모든 스킬 검사·별도 검수자를 기본 절차로 추가하지 않는다. 복잡한 맵이나 다중 경로 자체가 목표가 아니며 상황에 맞는 규모와 구성을 정한다. 사용자 최신 지시와 승인된 변경 범위가 우선한다.

## 0. 장별 설계 카드

스토리의 전후 연결, 승리조건/실패조건, 현재 참가 동행, 전투의 핵심 질문, 맵 크기/종횡비/수직성, 주요 장소/랜드마크, 반드시 보존할 ID·이벤트·기믹, 이번 변경 범위를 먼저 기록한다. 기존 기획을 보존하는 항목과 새로 설계하는 항목을 구분한다.

## 1. 플레이 지형과 동선

solid·one-way·물·위험·공중 공간과 사격각·엄폐·높이차를 함께 구성한다. 시작→필수 이벤트→목표→출구를 실제 이동능력으로 연결하며 일반 전략 경로는 접근 가능하게 한다. 기예 퍼즐 경로는 의도·보상·대체 경로 필요 여부를 명시한다. 밟는 지붕은 one-way다. 수직 포격의 높이는 화면 Y이며 원근상의 앞뒤 길과 혼동하지 않는다. 초기 아군 위치는 이 단계에서 임시 배치한다.

검수는 바뀐 길의 연결, 낭떠러지/경사 접점, 필수 사격선만 확인한다.

## 2. 공통 미술 구성

공유 assetId·재질·조합을 사용하고 원경·근접 장식·플레이 지형·전경을 분리한다. 접지, 인물 대비 크기, 한옥 구조, 광원, 여백, 미세 반복 없음으로 형태를 확인한다. 원경은 독립 이미지, 근경은 공통 벡터로 제작한다. 복사한 장별 패스를 만들지 않는다. 줌아웃 외곽도 같은 지형 세계로 연속되게 한다.

검수는 정상 화면과 넓은 시야의 실제 렌더 이미지로 해당 변경의 형태·재질·접합·가독성을 확인한다. 빌드 성공·오류 없음·성능 결과와 미술 판정을 별도로 기록한다. 적용되는 미술 기준에 하나라도 실패하면 수정 후 해당 항목을 다시 검토하기 전까지 미술 완료·출시로 판정하지 않는다. 현재 벡터 미술 교정의 구체적인 차단 조건과 대표 화면 범위는 [맵 미술 제작 기준](MAP_ART_PIPELINE.md#현재-벡터-미술-교정의-출시-차단-조건)을 따른다.

## 3. 아군/NPC 초기 배치

계획한 동선·스토리 상황·공간 점유에 맞춰 초기 위치를 확정한다. 시야와 이동 시작이 막히지 않는지 확인하고 NPC 역할/주인공 리그, 동행 도착 조건 등 현행 기획을 보존한다.

## 4. 적 배치

적마다 지형과 목표를 활용할 역할을 정하고 총수·밀도·정예·증원 예산을 기록한다. 등간격·항상 두 마리 쌍·좌우 복사를 피하고 장소 의미에 맞는 비대칭 군집과 여백을 둔다. 공중 적은 지형 밖의 여유 공간에 놓으며 공격이 불가능하면 접근/재위치가 가능해야 한다. 총원만으로 완료를 판정하지 않는다.

검수는 끼임·고립·즉시 부당 피격·행동 없는 배치와 필요한 교전 한 번만 확인한다.

## 5. 이벤트 상태 전이

trigger(위치/턴/처치/상호작용)→조건→결과→완료/실패→다음 상태를 연결한다. 증원의 유한성, 중복 발화, 대화 중 정지, 턴 조건 off-by-one, 완료 모달/출구 연결을 변경 범위에서 확인한다. 대사가 약속하는 행동과 보상은 실제 이벤트에 있어야 한다.

## 6. 대사·씬

화자·청자·주어·목적어·행동 주체를 명확히 하고 필수 정보를 선택 읽기에 숨기지 않는다. 사건은 이동·행동·환경 변화와 짧은 대사로 전달하며 긴 설명으로 대신하지 않는다. 다음 장의 시작 위치와 합류/퇴장 동기를 연결한다. 초상화는 해당 인물 또는 없음으로 한다. 새로 바꾼 대사·씬만 확인한다.

## 7. 통합·배포

수정한 장의 시작→바뀐 핵심 동작→완료 연결을 최소 확인하고 장별 완료·미실행·임시 유지 항목을 기록한다. 필요한 코드 빌드와 기본 실행을 하되 수정 영역 밖의 전수 검증은 하지 않는다. 실제 관련 결함을 발견하면 해당 단계로 돌아가 수정한다. 커밋·원격 push·master 반영·Pages 배포/공개 동작 확인은 서로 다른 상태로 보고한다.

재료·에셋·렌더 연결만 바꾸는 작업에서 단계 1/3/4/5/6을 모두 재작성하거나 재플레이하지 않는다. 기존 계획의 보존을 확인하고 이번 변경 여부와 최소 확인 결과만 남긴다. 불필요한 새 이벤트·적 배치·대사를 만들지 않는다.

## 현재 1~3막 30장 공통 에셋 연결에 적용

단계 0의 30행 적용표를 작성한다. 각 장의 기존 크기·구성·승패 조건·퀘스트·참가 동행·초기 배치·적 편성·저장 ID·이벤트·기믹은 보존 대상으로 기록한다. 단계 1~6 각각의 이번 변경 여부와 최소 확인 결과를 짧게 표시한다. 충돌 다각형·천장·오버행·개별 one-way 발판을 유지하며 모든 장소를 동일한 숲으로 덮지 않는다. 기존 스토리·랜드마크·퀘스트 대상·묵종·폭포·공간왜곡을 유지하고 아직 공통화하지 않은 특수 표현은 임시 유지로 표에 남긴다.

이미지 지형 제거로 숨겨졌던 길/발판/주요 요소가 빠지면 관련 단계에서 보완한다. 최초 적용은 공통 벡터/재질의 렌더 연결이며 스테이지 전체 재설계 완료나 미술 합격을 뜻하지 않는다. 공통 라이브러리의 후속 개선은 같은 참조를 통해 전체 장에 반영한다.

최초 공통 에셋 연결의 검증 범위는 정식 빌드 1회와 30장의 활성·에셋 참조 누락·런타임 오류를 확인하는 가벼운 스모크 1회였다. 대표 플레이는 1장 입장/이동/발판, 5장 폭포/타겟, 18장 묵종, 25 또는 27장 지하/천장, 30장 출구다. 이는 미술 합격 근거가 아니며 현재 교정에는 위 미술 차단 조건을 적용한다. 전체 스킬·전체 verify·별도 검수자는 실행하지 않는다.
