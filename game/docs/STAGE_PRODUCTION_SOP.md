# 스테이지 제작 SOP v1.2

장 개편은 아래 순서로 진행한다. 각 단계의 검수는 변경 범위에 맞춘다. 장 개편은 아래 집중 미술 검수 3회와 최종 종합 검수를 포함하며, 렌더 연결만의 최소 검사를 개편 완료 기준으로 사용하지 않는다. 전 장 재플레이·전체 verify·모든 스킬 검사·별도 검수자를 기본 절차로 추가하지 않는다. 복잡한 맵이나 다중 경로 자체가 목표가 아니며 상황에 맞는 규모와 구성을 정한다. 사용자 최신 지시와 승인된 변경 범위가 우선한다.

## 벡터 저작 기본 경로

2026-10-28 확정된 [벡터 제작 SOP](VECTOR_AUTHORING_SOP.md)를 함께 따른다. 단계 1의 실제 플레이 스켈레톤을 먼저 고정하고 단계 2에서는 레이어/자산별 시안을 실제 Inkscape로 벡터화·정리한다. 전체 장 이미지 추적과 임의 코드 폴리곤 그림을 정식 제작 기본값으로 삼지 않는다. 공통 자산과 장 고유 지형, 미술 원본과 충돌 원본, 편집 원본과 배포 산출물을 구분한다.

## 0. 장별 설계 카드

스토리의 전후 연결, 승리조건/실패조건, 현재 참가 동행, 전투의 핵심 질문, 맵 크기/종횡비/수직성, 주요 장소/랜드마크, 반드시 보존할 ID·이벤트·기믹, 이번 변경 범위를 먼저 기록한다. 기존 기획을 보존하는 항목과 새로 설계하는 항목을 구분한다.

## 1. 플레이 지형과 동선

solid·one-way·물·위험·공중 공간과 사격각·엄폐·높이차를 함께 구성한다. 시작→필수 이벤트→목표→출구를 실제 이동능력으로 연결하며 일반 전략 경로는 접근 가능하게 한다. 기예 퍼즐 경로는 의도·보상·대체 경로 필요 여부를 명시한다. 밟는 지붕은 one-way다. 수직 포격의 높이는 화면 Y이며 원근상의 앞뒤 길과 혼동하지 않는다. 초기 아군 위치는 이 단계에서 임시 배치한다.

검수는 바뀐 길의 연결, 낭떠러지/경사 접점, 필수 사격선만 확인한다.

## 2. 공통 미술 구성

공유 assetId·재질·조합을 사용하고 원경·근접 장식·플레이 지형·전경을 분리한다. 접지, 인물 대비 크기, 한옥 구조, 광원, 여백, 미세 반복 없음으로 형태를 확인한다. 원경은 독립 이미지, 근경은 공통 벡터로 제작한다. 복사한 장별 패스를 만들지 않는다. 줌아웃 외곽도 같은 지형 세계로 연속되게 한다.

근경의 뒤쪽 지표 폭·보행면·앞 경사면은 하나의 연결된 장소로 설계하고 캐릭터 충돌면과 구분한다. 전체 근경을 충돌 폴리곤으로 잘라내지 않는다. 필요한 가림만 렌더 순서로 처리한다. 임의 삼각 분할·같은 돌의 격자 복제·거대한 단색 면으로 빈 곳을 채우지 않는다. 미술 완성도와 런타임 연결 완료를 구분한다.

## 3. 아군/NPC 초기 배치

계획한 동선·스토리 상황·공간 점유에 맞춰 초기 위치를 확정한다. 시야와 이동 시작이 막히지 않는지 확인하고 NPC 역할/주인공 리그, 동행 도착 조건 등 현행 기획을 보존한다.

## 4. 적 배치

적마다 지형과 목표를 활용할 역할을 정하고 총수·밀도·정예·증원 예산을 기록한다. 등간격·항상 두 마리 쌍·좌우 복사를 피하고 장소 의미에 맞는 비대칭 군집과 여백을 둔다. 공중 적은 지형 밖의 여유 공간에 놓으며 공격이 불가능하면 접근/재위치가 가능해야 한다. 총원만으로 완료를 판정하지 않는다.

검수는 끼임·고립·즉시 부당 피격·행동 없는 배치와 필요한 교전 한 번만 확인한다.

## 5. 이벤트 상태 전이

trigger(위치/턴/처치/상호작용)→조건→결과→완료/실패→다음 상태를 연결한다. 증원의 유한성, 중복 발화, 대화 중 정지, 턴 조건 off-by-one, 완료 모달/출구 연결을 변경 범위에서 확인한다. 대사가 약속하는 행동과 보상은 실제 이벤트에 있어야 한다.

## 6. 대사·씬

화자·청자·주어·목적어·행동 주체를 명확히 하고 필수 정보를 선택 읽기에 숨기지 않는다. 사건은 이동·행동·환경 변화와 짧은 대사로 전달하며 긴 설명으로 대신하지 않는다. 다음 장의 시작 위치와 합류/퇴장 동기를 연결한다. 초상화는 해당 인물 또는 없음으로 한다. 새로 바꾼 대사·씬만 확인한다.

## 7. 집중 미술 검수와 최종 종합

장 개편은 실제 런타임 캡처를 직접 열어 최소 3회의 서로 다른 집중 검수를 수행한다.

1. 전체 형태·동선 연속성·지지 구조: overview에서 지형·가지·지붕·암반이 연결된 장소인지, 외곽까지 완결되는지 확인한다.
2. 디테일·가독성·전경/원경 구분: 일반 플레이 거리에서 재질의 중간 크기 형태, 접지, 캐릭터·조준선·상호작용 대상의 식별을 확인한다.
3. 일반/확대/최대축소/모바일 및 이동·기믹 전후: 다른 화면비와 카메라 위치, 변화한 상태에서 잘림·공백·가림·오인·충돌 불일치를 확인한다.

문제는 수정 후 재촬영한다. 같은 화면 반복으로 횟수를 채우지 않으며 세 번은 자동 합격 기준이 아니다. 이후 최종 소스로 별도의 종합 검수를 실시하여 앞선 수정의 회귀, 이야기·공간·전투·미술의 결합을 확인한다. 최종 소스가 바뀌면 영향받는 증거와 종합 판정을 갱신한다.

검수 기록에는 소스 SHA(미커밋이면 변경 내용), 화면 경로·카메라/화면비·상태, 직접 본 문제·수정·재확인·남은 한계를 남긴다. 실제 보지 않은 이미지, 실패, 미실행을 통과로 쓰거나 부모/사용자 승인을 만들어내지 않는다. 기존 검사나 manifest gate가 있으면 우회하지 않으며 회수 요구를 이 문서와 일치시킨다. 이를 위해 불필요한 대형 gate 시스템을 새로 만들지는 않는다.

## 8. 관련 플레이·결과 보고·배포

수정 장의 시작→바뀐 이동/사격/핵심 기믹→승패·출구 연결을 실제 플레이로 확인한다. 위치 선점의 보상, 분산·합류·회귀·수직 동선, 캐릭터 고유 스킬의 물리 특성과 장소 이벤트는 해당 장의 설계 카드에 맞춰 평가하며 모든 장에 복잡한 구조를 강제하지 않는다. solid/one-way/위험/천장과 그림의 일치, 접근 불능·고립·불필요한 벽도 확인한다.

필요한 빌드와 변경 관련 검사를 실행한다. 지형이 바뀐 장은 map revision으로 구전투만 폐기하고 성장·SP·장착·캠페인 진척을 보존한다. 장별 완료·부분 구현·미실행·임시 유지 항목을 구분한다. 최신 사용자 지시(2026-10-21)에 따라 내부 검수 통과 후 master/Pages에 반영하고 실제 스크린샷과 결과를 보고한다. 장별 사용자 승인 답변은 기다리지 않고 사용자가 중단할 때까지 다음 장을 순차 진행한다. 핵심 스토리·기획 변경이 필요하면 먼저 보고한다. 작업 브랜치의 수정 단위 커밋·원격 push는 계속한다.

내부 검수 후 최신 master와 타인 변경을 보존해 반영하고 정확한 SHA로 빌드·Pages 배포·공개 동작을 확인한다. 커밋·push·master 반영·배포 성공·공개 검증은 서로 다른 상태로 보고한다. 접근 거부를 우회하거나 로컬 검증을 공개 배포 검증으로 부르지 않는다.

## 재료·렌더 연결만의 제한된 작업

단계 0에서 보존할 장별 데이터와 변경 범위를 기록하고 단계 1~6의 변경 여부와 최소 확인 결과를 남긴다. 기존 승패·스토리·참가 동행·ID·이벤트·기믹·충돌·발판·랜드마크를 보존하며 불필요한 새 기획을 만들지 않는다. 필요한 빌드와 활성·에셋 참조·오류 확인 및 변경된 화면/동작만 검사한다. 공통 렌더러 연결 완료와 전 장 개편·미술 합격은 별개다. 전 30장 연결 작업의 과거 대표 스모크 기록은 장별 재설계의 검수 증거를 대신하지 않는다.
