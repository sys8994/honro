## 공통 Scene 연결

현재 기존 `HonroAct2SpatialArt.terrain`은 CURRENT-solid clip과 `terrainPlanes`를 이미 구현하지만 `art-dark.js`의 호출 경계는 원래11–20장이다. 새22에는 공통 renderer 함수에 접근하는 좁은 opt-in이 필요하다.

- 전체 `HonroAct2SpatialArt.active` 범위를 넓히거나 stage를14로 위장하지 않는다.
- 일반22/진행 중 구22/다른29장의 terrain과 배경 경계는 유지한다.
- 판문도 같은 clip을 써 열리면 해당 미술이 함께 사라져야 한다.
- 이 호출 경계는 공통 통합 담당이 소유한다. 전용 Native 테스트가 production Scene의 실제 dispatch를 확인한다. 테스트에서 함수를 강제로 교체해 미술을 그리지 않는다.

Native 미술 검토 전에는 돌 면의 크기/조명/회랑-석축 접점과 가짜 발판 오인 가능성을 확정하지 않는다. 독립 검수자는 전후 실제 PNG에서 배우·판문·작업점·도약 틈·사선을 확인한다. 자동 author 통과, screenshot 생성 성공, 전투 시뮬레이터 완료만으로 장소감과 가독성에 합격을 주지 않는다. 실제 브라우저·정상자원 완주·전 군집/파동 영향·전체회귀·master/Pages 직접 검수는 별도다.
