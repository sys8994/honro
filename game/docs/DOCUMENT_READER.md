# 현장 문서와 읽기 화면

홍만 장부의 `shared/runtime/story.js` → `documentView(node,d,meta,text)`를 모든 `kind:document`에 공용한다. CSS는 `game/src/presentation.css`. 원문은 `story-content.js`·`act2-drama.js`·`act3-content.js` 및 현재 narrative content가 제공한다. UI가 별도의 사건이나 목표를 생성하지 않는다.

월드 경로 `story-act23-art.js.evidence/draw`는 완료 여부에 따른 기존 노출 조건과 좌표를 유지하고, 문서 원문을 Canvas에 쓰지 않는다. 큰 종이판 대신 폭42·높이19 월드 단위의 닫힌 묶음을 그린다. 모든 경로가 Game/Stage View/Playtest에 공유된다. 23/25장의 생활도구, 15장 흔적, 19장 공양물은 제거하지 않는다. 이전 전투 저장에서도 기존 마커를 그대로 해석한다.

## 읽기·진행 계약

- 지도는 획득한 원문의 행을 경로 목록으로 읽고, 장부는 제본 여백, 메모는 작은 폭과 문서 제목 구획을 사용한다. 다른 장소/사건을 추가하지 않는다.
- 17–20px 본문, 명조 계열, 종이색과 먹색 명암, 큰 글씨26px, 독립 본문 스크롤을 제공한다. 모바일 가로 화면에서도 닫기와 이동 버튼은 고정된 별도 행에 있다.
- 닫기/ESC는 해당 문서 다음 대사로 이동한다. 이전은 현재 대사 묶음 안에서만 읽는다. 기존 대화 넘기기는 기존 finish 정책을 유지하고 획득을 재실행하지 않는다. 지난 기록의 뒤로/ESC는 문서 위치를 유지한다.
- `app.dialogue`와 `scene.storyFrozen`을 기존대로 사용한다. 새 전투 업데이트 루프를 만들지 않는다. 문서 중 `canInput`은 false이며 전투가 멈춘다.
- 기존 `honroStory`가 줄 위치·원문을 저장한다. 큰 글씨와 스크롤은 일시적인 보기 설정이다. 목표 완료는 기존 interaction 경로에서 한 번만 수행한다. 30장 배·증원 트리거와 27장 명세/검은 틈, ordered steps, flag 및 storyId를 변경하지 않는다.

## 검수

`node tests/act23-evidence-art.mjs`는30장 전체 inventory, 원문 비노출, 작은 묶음, 무변이·19장 공양물 보존을 검사한다. `python tests/document-reader-browser.py`는 실제 Chromium Game/Workshop, desktop/mobile/가로회전,16종 문서 폭, 실제30장 상호작용, 전투 정지, 저장/Continue, 중복 거부, 이전/닫기/ESC/Tab/지난 기록, 터치 스크롤을 검사한다. 이동 위치를 둔 controlled fixture이며 전30장 정상 완주를 의미하지 않는다.

전후 PNG와 JSON은 `_local/reports/document-reader/`. 첨부 Library 원본은 이 실행환경의 지원 전송 및1회 재시도가 실패했으므로 원본 픽셀 확인을 주장하지 않는다. 부모의 원본 확인과 별도로 동일30장 baseline HTML을 실제 재현해 전후 화면을 확인했다. 원본 파일·사용자 저장은 수정하지 않았다.
