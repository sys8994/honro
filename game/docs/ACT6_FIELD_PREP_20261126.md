# 6막 전열 정비

정비는 선택입니다. 배운 기예와 소유한 장비만 바꿀 수 있습니다. 상점, 수련, 회복, 기예 초기화, 소모·발동 기록 초기화는 없으며 이미 다른 동행이 장착한 공용품은 뺏을 수 없습니다.

| 시점 | 정비 가능 인물 | 보존되는 조건 |
| --- | --- | --- |
| 2장 종터, 의식 시작 전 | 종터에 선 네 사람 | 기존 6막 2장 절차와 3장 저장·인계 |
| 5장 빈 종터 첫 공세 전 | 설오, 휘겸 | 담허는 안에 남고 소단은 혼줄을 붙듦. 장착한 호혼령은 기존 별도 버튼으로만 사용 |
| 7장 완료 직후, 8장 문턱을 넘기 전 | 육신으로 만난 네 사람 | 이미 맡은 곽진의 후위, 네 사람의 발 위치, 출구, 피해와 성장 상태 |
| 9장 패배 뒤, 같은 장을 다시 걷기 전 | 9장에 진입할 당시의 네 사람 | 첫 진입과 곽진 발견 직전에는 정비 UI 없음. 실패한 전투 상태를 복사하지 않음 |

5장은 첫 이동, 발사, 차례가 지난 뒤에는 메뉴를 닫습니다. 8장 장 경계는 정비한 네 사람을 인계하고, 진행 중인 7장 상태를 처음부터 다시 여는 경우는 기존 정책이 적용됩니다. 9장 재도전의 정비안은 같은 탭의 연속 재시도에서 유지되며 새로고침하면 이전 입장 기록으로 돌아갑니다. 정상 캠페인과 별도 장 경계 저장은 정비 버튼을 누른 시점에 덮어쓰지 않습니다.

검수: `node --test tests/act6-field-prep.mjs`와 이미 빌드한 게임에서 `python tests/act6-field-prep-browser.py --build <저장소> --chromium <실행파일> --stage 55|57|59`. 브라우저 검수는 격리 저장과 위치/엔진 입력을 보조자로 사용하는 대상 장 검수이며 캠페인 정주행은 아닙니다.
