# 1~20장 지형·동선 후속 대조

기준은 `de286f94`다. 이미 배포한 공중 적 보완을 반복하지 않고, SOP 단계 0의 장별 의도와 단계 1의 실제 지형·기본 이동 연결을 대조했다. 이번 범위에서 추가 지형 변경이 필요한 결함을 확정하지 못했으므로 활성 지형·동선·적·사건·대사는 보존한다. 공통 미술과 21~30장 데이터도 수정하지 않는다. 이는 모든 장의 전투·길 찾기·미술을 새로 합격시킨다는 뜻이 아니다.

## 실제 최소 확인과 실패 해석

검사는 현재 실제 Engine의 `move/jump/wait/tick`을 사용했다. 설오는 해당 장 실제 시작 위치에서 출발하고 SP03 없는 기본 점프를 사용한다. 이동량을 강제로 계속 채우지 않고 소진하면 실제 wait/턴 경계를 거친다. 적과 다른 배우를 제거한 지형 격리이며, 정상 전투·구조·호송 완료 증거가 아니다.

- 6장: 서쪽 잔해 1 → 잔해 2 → 서쪽 상판 → 파손 틈 → 가운데 상판. 도약 4회·wait 2회, 피해·유효 지지면 오류 0. 처음의 자동 waypoint 시도는 잔해 2에서 상판으로 오르기 전 도약을 생략해 아래 길로 걸어 내려갔다. 같은 지도에서 x1560의 실제 잔해 끝에서 도약하니 연결됐다. 이 자동 경로 실패를 지형 접근 불가로 기록하거나, 통과시키기 위해 지형을 고치지 않았다.
- 20장: 실제 시작 위치부터 `hero-side-perch`로 오르고 서쪽 지면으로 복귀한 뒤 `last-pass-shot-shelf`에 올라 다시 지면으로 복귀. 각 사격턱 기본 점프 1회, 전체 피해·유효 지지면 오류 0. 첫 사격턱은 지면보다 약 214 높지만 현재 기본 점프로 닿았다. 발판 수만을 이유로 추가 계단을 만들지 않는다.
- 4장: 불탄 회랑을 파괴 상태로 둔 격리 fixture에서 동쪽 낮은 돌턱 → 중간 발판 → 감시대. 기본 점프 3회, 피해·지지면 오류 0. 회랑 파괴를 실제 전투로 벌어들인 시험은 아니다.
- 10장: 실제 시작에서 중앙 접근 → 고목 네 단계 → 상단 의식 발판. 기본 점프 4회, 피해·지지면 오류 0.

6·20장은 기존 생성 번들의 실제 Chromium Scene으로 보존 화면을 확인했다. pageerror 0이었다. Native Canvas 캡처는 adapter의 `InvalidArg: Value is not undefined`로 실패해 Chromium으로 대체했다. 공통 미술의 보강 여부를 여기서 재판정하지 않는다. 20장 사격턱의 단순한 직사각 표시나 6장 근경 지지물의 표현은 현재 그림의 한계로 보이지만, 실제 이동 경로의 고립·높이 부족과는 구분해 공통 미술 담당 영역으로 남긴다.

검사 로그는 `_local/reports/stages1-20-terrain/`에 있다. Git으로 보존한 두 화면은 [6장 교량 위·아래](../../review/stages1-20-terrain/stage6-bridge-levels-preserved.png), [20장 쉼터 사격턱](../../review/stages1-20-terrain/stage20-rest-overwatch-preserved.png)이다. 이번에 지형이 바뀌지 않아 전후가 서로 다른 화면을 만들지 않았다.

활성 맵·이벤트·대사·campaign map revision·저장 경계·공통 미술·21~30장·생성 번들은 변경하지 않는다. 문서와 보존 화면만 발행하므로 기존 정식 빌드를 다시 생성하지 않는다. 전체 verify·20장 플레이 순회·기예/전투 재검사는 실행하지 않았다. 미실행 영역의 재미·난이도·모든 우회길 접근성을 통과로 주장하지 않는다.
