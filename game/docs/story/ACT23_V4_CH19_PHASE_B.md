# 19장 검토 원고 결합

`v4-reviewed/HONRO-CH19-reviewed-final.json` 확정 33행의 ID·화자/채널·조건·문구를 그대로 `shared/data/reviewed/act23-v4-ch19.json`에 옮기고 내부 판본 `revision:1`만 추가했다. 원본의 `implementation_verified:false`는 원고 출처 메타데이터이며 실행 검수 완료로 바꾸지 않았다. 장면·선택대화·저널에 새 문장을 쓰지 않았다.

## 실행 계약

- Phase A, Phase B의 19장 명시 허용 및 정확한 33행 자료가 함께 있어야 활성화된다. map revision은 519다. 일반판·Phase A 단독은 기존 동작을 유지한다.
- 기존 `mourner-brother`, `mourner-sister`, `objective`를 중립 주민 세 명으로 사용한다. 중복 군중을 만들지 않는다. 실제 접지 상태에서 물건을 내리는 시간·몸짓·이동하는 물건을 관찰한 후 도착/도입을 연다. 망치·밥그릇·작은 물건은 이후에도 남는다.
- 적·증원·옛 전투 이벤트는 0이다. 설오·휘겸은 실제 NPC이며, 담허는 `route` 완료 뒤 NPC가 된다. 기존 프로필의 동행·성장·장착을 삭제하지 않는다. 물리 tick보다 앞서 이 전환을 적용해 담허의 다음 대사가 역할 전환을 앞서지 않는다.
- `separate-1..3`의 병렬 자유 순서와 기존 자동 `send-*` 후속을 보존한다. 2번 만남에는 두 형상이 실제 겹쳐 있고 그 상태에 접근했을 때만 MID.04를 허용한다. 다른 두 만남부터 처리할 수 있다. 보내기 버튼을 다시 누를 필요가 없다.
- 각 혼의 실제 이동·퇴장과 해당 분리 완료를 모두 확인한 뒤에만 마지막 두드림 종료/MID.07/첫 저널을 연다. 실제 혼이 남아 있는 시점만 선택대화를 허용한다.
- `old-soul`에서 실제 접지한 관찰자의 위치와 0.8초 관찰을 확인하고 무명사·왕실 봉인·저문골 세 표식을 각각 저장한다. 기존 이송 흔적 물리 영수증도 함께 있어야 EVIDENCE/POPUP/두 번째 저널을 연다. 현재 확인 가능한 표식만 말하며 제작기원·저문골의 사건을 단정하지 않는다.
- 완료 대화 후 주민들은 기존 Engine 보행으로 후방 안전길까지 돌아간다. 실제 보행 거리·접지·도착을 완료 조건으로 사용한다. 장면 카메라는 물건·두 혼·고리/받침·후방 이동을 가리킨다. 예전 고정 유품/묶인 옛 혼 tableau는 이 내부 판에서 표시하지 않는다. 비전투 혼의 이름은 승인된 `EDGE.RUNTIME.STAGE19.SPIRIT_LABEL.1`을 사용한다.
- 실제 완료한 같은 run에만 `history.stages[19].reviewed19`에 퇴장·표식·출연 생존자 증거를 남긴다. 옛 클리어 기록을 새 목격으로 합성하지 않는다. 사용자 후속 범위에 따라 물건을 놓은 살아 있는 주민이 손을 입가로 들어 부르는 짧은 동작과 연결된 혼의 시각 반응을 실행한다. 새 이름·대사·음성은 추가하지 않는다. 대사/모달 없이 실제 시간이 진행되고 접지한 관찰자가 근처에서 지형에 가리지 않고 본 세 만남의 영수증이 모두 있어야 `familyWitness:true`가 된다. 단순 옛 클리어 또는 불완전 영수증은 20장 선택대화/막종료 첫 행의 근거가 되지 않는다.

## 확인과 한계

`node tests/act23-v4-reviewed19.mjs` 통과. 실제 App·Story·Engine에서 정확한 33행, 실제 NPC 역할 전환, 자유 순서 3→1→2, 자동 퇴장, 장면 중간 저장/재개, 세 흔적 관찰, 주민 후방 보행, 저널 중복 방지, 옛 클리어/기본판 격리를 확인했다. 이전 장 클리어와 동행의 접근 위치는 명시적 fixture다. 주민의 귀환 좌표는 직접 완료 위치로 지정하지 않고 Engine 보행으로 확인했다. 이 검사는 실제 Canvas/음향·정상 전투 완주·미술 집중 검수·공개 배포의 증거가 아니다.

담당 범위는 이 장별 runtime/data/test와 이 문서다. 공통 결합 계층·번들·빌드·master/Pages 반영은 부모 담당이다. 이 문서에서 원격 저장·배포 을 완료했다고 주장하지 않는다.
