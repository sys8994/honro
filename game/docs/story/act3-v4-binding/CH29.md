# 29장 조기처치와 수문 회수

기존 실제 차폐·낙하 안전 행동 기회·명령 부하 단계·유한 증원·조기처치 보상을 유지한다. 보스가 죽으면 도입·명령·전진 발화는 각 행 직전에 취소한다. 단계3은 성공 필수 조건이 아니다. 화면 밖 조기 낙사로 죽은 보스에게 지연 발화를 부여하지 않는다.

실제 화면 안 사망 순간만 짧은 마지막 발화 대상이다. 그 실제 자리의 빈 갑주 잔해와 기울어진 군기를 paint하며, 보스의 몸/HP/전투 상태를 복원하지 않는다. 동일 저장의 사망 커서를 보존한다. 실제 보스전 시작 snapshot을 보존해 패배 안내의 시작 상태 복원이 실제 retry와 일치한다. 적·차폐·아이템·턴은 시작으로 되돌리고 성장/XP ledger와 이미 끝난 대사의 once는 보존한다. 수문 회수·진목의 실제 짧은 손짓·A/B 출구는 선택 화자의 대사 완료를 요구하지 않는다. 담허가 죽어도 나루 길은 열리며, 현묵 문하 식별이 없으면 해당 저널은 기록하지 않는다.

production App/Engine 검사에서 죽은 담허·한 생존 영웅·화면 밖 조기처치·미입장 예비병 취소·실제 수문 조작/손짓/B handoff를 확인했다. Chromium은 실제 화면 안 hurt에 의한 사망·빈 갑주/기울어진 군기·사망 커서 저장을 확인했다. 적 처치/영웅 위치는 fixture이며 정상 보스 전투 완주가 아니다.

보류: `A3.S29.THRUST_WARNING.01`의 실제 창 공격 예고가 현재 PhaseA에 없다. 현재 보스는 `possessedGuard`의 S09 반월검기이며 `meleeFollow='windup'` 같은 존재하지 않는 상태를 증거로 쓰지 않는다. 승인 문구는 보존하고 발동하지 않는다. 새 창 공격 물리나 대체 원고의 별도 결정이 필요하다. Sodan의 실제 공격 접근 경고와 정상 단계3 전진 문구는 조건을 연결했지만 해당 정상 전투 분기의 실제 입력 검증은 아직 미실행이다.
