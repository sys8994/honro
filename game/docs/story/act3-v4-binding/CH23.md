# 23장 검수 원고 연결

기존 짐꾼의 실제 walk/integrateBody 호송을 유지하고, 다음 엄폐 구간의 적이 남아 있으면 이동을 멈춘다. 실제 이동 거리·접지·dock-exit 도착·위협 해소를 함께 확인하며 저장한 좌표와 이동 예산을 이어 쓴다. 생활금속·시신운반 흔적·반복 마을 표찰은 실제 운반구 옆 관찰로 기록한다. 표찰, 수레 가문 문장, 21장 빈 갑주와 같은 군기는 서로 다른 조형이다. 군기는 21장 갑주 렌더러의 동일 문양 경로를 재사용한다.

살아 있는 짐꾼의 핵심 증언은 휘겸·설오의 선택 발화 생존과 분리했다. 모든 발화가 무효인 사건은 cancelled로 남고 물리 구조 사실을 대체하지 않는다. 선택대화는 실제 전투 전 시야와 각 화자의 파티 출연을 확인한다.

`tests/act23-v4-reviewed23.mjs`는 production App/Engine의 전체 짐꾼 이동, 적 접근 정지/재개, 중간 저장, 실제 도착, 죽은 질문자 뒤 살아 있는 짐꾼 증언을 검사한다. 적 처치·영웅 안내 위치·선행 장 기록은 fixture다. `tools/testing/act23-v4-reviewed23-24-browser.py`는 Chromium에서 실제 E/Enter, Canvas, localStorage 재개와 모바일 화면을 확인한다. 정상 전투 완주·Pages 확인은 포함하지 않는다.
