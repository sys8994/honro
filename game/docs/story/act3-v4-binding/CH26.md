# 26장 지상 구조와 짧은 증언

소단의 실제 현장 혼 분리와 기존 주민의 native 보행·접지·지역 위협 해소를 유지한다. 증언은 주민의 실제 안전 도착 뒤 기존 구조 동선의 가문 물건/짧은 글을 가까운 휘겸이 확인할 때 열린다. 문고리·금속·제련 도구와 군대 표식은 분류대 실제 관찰로 기록하며 지하팀에 미리 공유하지 않는다. 새 문서 수집 목표는 없다.

두 문장 문서는 승인된 휘겸의 인용 대사 안에 한 번만 표시한다. 실제 DOM의 `data-reviewed-document-row`가 문서 ID·원문 메타데이터를 보존하며 인용문을 별도 클릭이나 이중 낭독으로 만들지 않는다. 전체 저널은 실제 관아 연기까지 관찰한 뒤 기록한다.

기존 지붕이 실제 피격되어 흔들리는 경우에만 붕괴 경고를 허용한다. 추가한 작은 탁자는 실물 상판 충돌과 아래의 빈 지지 공간을 갖는다. NPC의 실제 혼 분리 전 위험과 분리 뒤 구조/증언을 구분했다. 일반 접근 적만으로 붕괴를 선언하지 않는다. 새 위험 피해나 보상을 만들지 않았다.

`tests/act23-v4-reviewed26-30.mjs`의26 항목과 Chromium `act23-v4-reviewed25-30-browser.py`가 실제 NPC 보행, 혼 분리, 저장된 구조/인용 커서, 문서 한 번 표시와390px 화면을 확인한다. 적 처치·영웅 안내 위치·선행 증거는 fixture이며 정상 전투 완주 검증은 아니다. 실제 지붕 피격→경고→탁자 공간의 전체 전투 입력은 아직 미실행이다.
