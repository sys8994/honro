# 28장 실제 재합류와 기록함

기존 화재 차단·물길 개방은 자유 순서이며12번째 적 턴 종료 전이라는 마감을 유지한다. 실제 네 사람의 접지와 집결을 확인한 뒤 한 번의 재합류 proof를 남긴다. 재합류 전 필수 인물 상실은 실제 실패다. 재합류가 이미 성립한 뒤 선택 화자의 사망은 기록함 확보를 잠그지 않는다.

기존 실제 부상자·곽진 호송과 안전 도착을 그대로 사용한다. 기록함은 기존 한 상호작용으로 얻고, 이를 살아 있는 곽진 곁으로 실제 가져간 뒤 승인된 네 문서와 조건을 만족한 화자 문답을 재생한다. 휘겸이 죽었더라도 살아 있는 동행이 문서 UI로 핵심 사실을 확인할 수 있다. 곽진에게2880px 떨어진 기록함 자리에서 말하게 하지 않는다.

문답 뒤 현재 병사·곽진·주민은 native walk로 실제 출발한다. 이때 이미 끝난 안전지대 escort mover를 종료해 병사가 같은 목표로 되돌아가는 경쟁 이동을 막는다. 안전경계 안 첫75px만 진행하고, 실제 출발40px 전에는 최종 저널을 기록하지 않는다. 병사와 주민의 몸 충돌 및 기존 라운드 예산은 유지된다. 곽진 상실은 실제 실패다.

production App/Engine focused 검사는 두 장치·실제 네 사람 집결·호송 중 저장·휘겸 사망·한 기록함·살아 있는 곽진 문답·현재 호송 출발과 저널 지연을 통과했다. 영웅 위치/적 처치/선행 증거는 fixture다. 이 장의 실제 Chromium 전체 조작은 아직 미실행이다. 실제12번째 적 종료로 실패한 뒤 안내를 표시하고 정상 retry가 두 입구·네 사람·두 장치·자원을 시작 상태로 복원하는 검사도 통과했다. 마감/대화 정지 자체는 기존 City의12적턴 구현을 유지하며 별도 전체 전투를 통과했다고 주장하지 않는다.
