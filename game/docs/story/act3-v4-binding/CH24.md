# 24장 검수 원고 연결

23장 수레와 저택·사당은 같은 세 꽃잎 가문 문장이다. 마을 표찰과 구별한다. 공방 안 주민은 실제 지지면과 생존 상태를 가진 비전투 장면 인물이며, 닫힌 문 위 창살 뒤에서 가까운 동행에게 구조 요청을 한다. 그 요청과 실제 수로 혼의 이동을 확인한 뒤 소단의 감지 발화를 허용한다.

두 출입로 안전과 네 사람의 실제 집결 뒤 분할 대화를 시작한다. 이후 실제 네 영웅의 walk/integrateBody 이동과 두 쌍의 각 앵커 접지를 확인한 뒤 출발 proof·저널·안내를 기록한다. 대화 확인만으로 분할 도착을 인정하지 않는다. 분할에 필요한 동행이 없으면 실제 실패로 처리하며 조용한 영구 대기를 만들지 않는다. 기존 split v2 무휴식·자원 연속을 유지한다.

`tests/act23-v4-reviewed24.mjs`는 실제 분할 이동 비용·양쪽 도착·중간 저장·생명/기력 연속과 지식/생존 가드를 검사한다. 적 처치·초기 집결 위치·선행 기록은 fixture다. Chromium 검사에서 실제 키 입력·저장 재개·문 안 주민과 두 앵커·390px 화면을 확인했다. 정상 전투 완주·Pages 확인은 포함하지 않는다.
