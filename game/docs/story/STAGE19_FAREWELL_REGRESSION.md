## 어떻게 사라졌나

- `shared/data/narrative-current.json`의 `stages.19`에 원문54행이 지금도 정상적으로 남아 있다: 도입3+퇴장2+사건49. 파일 삭제가 아니다.
- `shared/runtime/act23-v4.js`의 `content()`가 `story:[]`, `outro:[]`, `beats:{}`를 반환한다. 기존 가족 장면은 활성 본문에서 제외된다. 새 `completeStep()`은 예전 가족 `beats`를 재생하지 않는다.
- `shared/runtime/act23-v4-reviewed-chapters.js`도 기존 도입/퇴장과 여정 대사 대신 검토 원고 경로를 사용한다.
- `shared/data/reviewed/act23-v4-ch19.json`의33행은 대사18,도착1,팝업1,선택대화6,목표3,저널2,동적표현2다.33행 전부가 플레이 중 필수 대사는 아니다. 필수 대사/도착/팝업은20행이며, 각 가족의 개별 문답을 대체하지 않는다.
- `act23-v4-reviewed19.js`의 `separated`/`departure` 사건은 장 전체에서 한 번씩만 발생한다. 각 가족의 대화 대신 호명 몸짓0.7초/혼의 응답0.35초를 관찰한 영수증을 남긴다. `act23-v4-act3.js`는 각 `send-*`를1초 뒤 완료한다.

원문에서 빠진 핵심은 형의 망치/다 하지 못한 약속12행, 언니를 부르는 평소의 호칭과 응답12행, 이름 없는 혼 곁에 남는 휘겸11행이다. 예를 들어 “잠꾸러기…….” 뒤의 “응. 나 일어났어.”와 “……잘 가, 언니.”라는 실제 응답/작별 순서가 현재 필수 본문에는 없다.0.7초 몸짓을 목격했다는 기능적 증거가 이 감정 장면의 보존을 증명하지 않는다.

## 왜 검수에서 걸러지지 않았나

v4 기획은 반복 보내기 클릭을 합치고,짧은2~3회 상호작용과 검토 원고만 노출하도록 지시했다. 원고의 “새 이름·관계·생전 사건을 발명하지 않음”과 새33행 고정 계약은 이미 있던 가족의 기억·호응을 보존하는 대조와 분리되지 않았다.

당시 `ACT23_V4_CH19_PHASE_B.md`와 `tests/act23-v4-reviewed19.mjs`/브라우저 검사는 새33행의 정확성,적0,NPC전환,물건 내리기,퇴장,표식,저장 재개,주민 귀환을 확인했다. 기존54행과 가족별35행의 서사 기능을 대조하는 검사는 없었다. 선행 클리어·접근 위치가 fixture였고 정상 연속 플레이/실제 체감 분량은 미검증이라고 당시 문서에도 적혀 있다. 기능 조건 통과를 기존 장의 감정적 해소 보존으로 확대 해석하면 안 된다.

자료에 있는 “부모 최종판단/승인후보/확정33행”은 저장된 제작 출처의 표현이다. 사용자가 가족 대사 제거를 승인했다는 직접 근거는 이번 조사에서 확인하지 못했다. 사용자의 이번 반려가 현재 판단이다.

## 후속 복구에 적용할 기준

54행 원문을 보존하고 가족별 만남→응답→작별의 여섯 장면을 복구 대상으로 삼는다. 반복 클릭을 줄이는 것과 대화 삭제를 분리한다. 현행18장 사건·20장 연결·역할 전환·진행 저장을 함께 확인해야 하므로 옛 런타임 전체를 되돌리지 않는다. 시간을 늘리기 위한 적/이동/대기 추가로 대사 손실을 대신하지 않는다.19장 기능과 대사는 이번 파일 정리에서 변경하지 않았다.
