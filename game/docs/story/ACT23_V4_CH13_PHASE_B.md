# 13장 검토 원고 결합

`v4-review/HONRO-CH13-parent-final.json`의 확정 35행을 그대로 보존하고 내부 판본 번호 1만 추가했다. 장별 결합 파일은 `shared/runtime/act23-v4-reviewed13.js`, 원고 자료는 `shared/data/reviewed/act23-v4-ch13.json`이다. 새 대사를 작성하지 않았다.

## 적용과 보존

- Phase A와 `HONRO_ACT23_V4_PHASE_B_STAGES`의 13장 선택, 35행 검토 자료가 함께 있어야 실행한다. 장 map revision은 513이다. 일반판과 Phase A 단독에는 이 원고가 노출되지 않는다.
- 기존 `13.extract → 13.escort → 13.release → gate → 13.party-pass` 진행, 소단의 분리 상호작용, 실제 Engine 기반 석공 이동, 문 위 작업 발판, 안쪽 빗장, 네 사람의 통과 조건을 사용한다. 기존 A/B 진입 위치를 보존한다.
- 초기 적 총수는 보존한다. 공통 진입에서 기존 적 한 명의 위치만 석공 아래 접근 구간으로 옮긴다. A/B의 기존 해당 적 위치는 그대로 적용한다. 기존 구조/문 목표에 연결된 밀도 증원 반응은 두 원혼 진입과 중복되지 않도록 이 장 내부판에서만 제거한다.
- NPC 지도 표시 이름은 구조 전 `???`이며, 실제 분리와 발 지지·안전 동선 확인 뒤 `석공`으로 바뀐다. 확정 대사의 석공 화자명은 원고 그대로다.

## 사건 근거

- 실제 밧줄·혈흔·팔과 붙은 혼 연결을 그린다. 기존 하부 적이 Engine.walk로 35 이상 접근한 관측과 살아 있는 붙은 혼이 있어야 도착 서술을 연다.
- BRANCH.01/02는 저장된 A/B 경로뿐 아니라 발화자의 실제 높이도 확인한다. A는 석공보다 위, B는 석공보다 아래에 있어야 한다. B의 기존 출현 위치는 석공보다 위이므로 BRANCH.02를 즉시 표시하지 않으며, 휘겸이 실제 아래쪽으로 접근한 후 표시한다. 경로 기록이 없을 때만 공통 BRANCH.03을 사용한다.
- 현장 발견과 소단의 실제 접근 뒤 INTRO를 연다. 높은 사격 대사는 설오가 기존 `forecourt-shot-ledge`에 접지한 때만, 아래 방어 대사는 살아 있는 적의 실제 하부 접근 기록이 있을 때만 표시한다.
- 보호 대상 조준 팝업은 Engine.predict의 실제 표적이 `resident-1`인 경우에만 예약한다. 소단의 첫 분리 상호작용은 MID.03을 열고, 그 대화가 끝난 다음 상호작용부터 기존 분리를 실행한다.
- 분리 후 MID.04는 붙은 혼의 실제 제거, 구조자의 발 지지, 현재 위치에서 안전자리까지의 연속 지지면을 확인한다. 해당 대사가 끝나기 전에는 호송 tick을 진행하지 않는다.
- 가족 소식은 실제 200 이상 걸어 안전자리에 도착하고 주변 위협이 사라진 뒤 표시한다. 이어 석공의 inspect 자세와 실제 걸쇠 회전 0.7초를 실행한 다음 MID.09를 연다. 그 전에는 대기 확정 상호작용을 완료할 수 없다.
- 설오가 실제 닫힌 문 앞에 접지해야 MID.10을 표시한다. 석공의 0.5초 point 자세와 보이는 안쪽 빗장 위치를 근거로 MID.11을 연다. 빗장 상호작용의 기존 안쪽 판정은 그대로 적용하므로 문 밖에서 조작할 수 없다.
- 이후 아래쪽 동굴 바닥에 정확히 두 원혼을 한 번만 생성한다. 두 유닛이 실제 Engine.walk로 오르막을 95 이상 이동하고 높이도 각각 20 이상 올라온 뒤에만 MID.12를 표시한다. 생성 ID·시작점·이동 거리·상승량을 저장하여 재개 시 중복 생성하지 않는다.
- COMPLETE와 저널은 석공의 접지·안전자리 유지, 실제 안쪽 빗장 개방, 네 동행의 문 통과, 걸쇠 장면과 두 원혼 장면 완료를 모두 확인한다. 저널은 확정 한 행을 한 번만 저장한다. 석공 사망·추락으로 기존 실패가 발생하면 FAIL.01의 정확한 UI 문구를 사용한다.
- 선택 대화 9행과 목표 UI 3행은 원고 그대로 사용한다. 공통 결합 계층이 선택 화자의 실제 출연·생존과 ID·문구를 다시 확인한다.
