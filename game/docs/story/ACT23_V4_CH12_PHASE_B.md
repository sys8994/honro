부모 확정28개 ID를 `shared/data/reviewed/act23-v4-ch12.json`에 그대로 보존했다. 본문은 임의 수정하지 않는다. 11장과 독립된 내부 gate `HONRO_ACT23_V4_PHASE_A=1 HONRO_ACT23_V4_PHASE_B_STAGES=12`만 연결하며 기본/Phase A 단독 빌드는 payload가 없다. current/compat catalogue와1막·성장은 그대로다.

## 사실·순서·저장

첫 길표 통과 뒤의 대사만 E01에 열고, 기존 길표→기존 하부 checkpoint→길표 실제 왕복 거리1000 이상과 동일 구도를 두 번째 확인한 뒤에만 돌림진 발견을 말한다. 정지·시간 경과로 반복을 완료하지 않는다. 기존 A/B 출구와13장 진입 위치를 유지하며, 대본의 upper/lower 의미는 A/B와 대응한다. 내부 기억의 route12는 upper/lower, 기존 handoff는 A/B를 유지한다.

반복 구도에는 기존 길표 바위와 공통 rooted-pine 에셋을 같은 지지면에 연결했다. 처음과 반복 장면의 카메라가 같은 좌표를 가리킨다. 실제 경고면과 아군의 offered/ended 행동 기회 뒤 유한 원혼2체가 입장하고, 원본 보행40 이상으로 진목에 접근한 뒤 누출을 말한다. 기존 초기38체 편성·먼 선택 경로는 제거하지 않았다. 그2체만 조정의 필수 위협이며 중복 생성하지 않는다.

담허가 실제 가까이 접지해 조작을 요청하고0.8초 조정한다. 근접 적이 있으면 진척을 유지한 채 멈추며 승인된 popup을 표시한다. 담허가 자리를 옮기거나 다른 동행을 선택하면 조정을 진행시키지 않는다. 이후 조정 대사·두 경로 확인이 끝나야 실제 출구로 route를 확정한다. 선택하지 않은 분기 대사는 재생하지 않는다. 내리막의 비전투 혼 움직임과 출구 도착 뒤에만 완료 대사·저널을 표시한다.

화자 생존·정확한 ID/본문·revision1을 매 표시 때 검사한다. 선택 대화4개는 진입 직후에도 반복 경험을 선취하지 않는 확정본이다. MID07은 설오가 실제 사선을 확인했을 때만, popup은 실제 조정 방해 때만 재생한다. 모든28행이 무조건 한 실행에 나오는 구성은 아니다.

12장 candidate212 진행만 revision512의 안전 시작으로 바뀐다. 성장/SP/장착/완료·보상 원장은 보존한다. 같은512의 왕복 중간 좌표·조정 진척·새 원혼 ID·선택 분기·대사 커서는 재개한다. UI 목표/경로/상호작용의 기계 ID 노출은 검수된 해당 목표/선택 문구로 대체한다.
