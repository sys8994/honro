# 14장 검토 원고 결합

이 결합은 `v4-review/HONRO-CH14-parent-final.json`의 확정 29행을 그대로 사용한다. `shared/data/reviewed/act23-v4-ch14.json`은 행 ID·화자/채널·조건·문구를 보존하고 내부 판본 번호 1만 추가한다. COMPLETE.01의 ‘내가 숨어 있던 집’과 KNIGHT_1의 존대 표현은 부모 최종판을 따른다. 새 대사를 쓰지 않았다.

## 적용 계약

- Phase A와 14장 Phase B가 함께 켜지고 29행 검토 자료가 주입된 내부 판에서만 실행한다. 장 map revision은 514다. 일반판과 Phase A 단독에는 이 원고가 노출되지 않는다.
- 도착은 서술만 표시한다. 집 근처의 실제 동행 접근 뒤 길찬이 첫 사람 목소리로 말한다. 석공 구조 완료의 근거인 13장 클리어 또는 구조·전원 통과 이력이 없으면 아버지 소식 대화를 열지 않는다.
- 아버지 소식 대화가 끝나기 전에 집 문을 열 수 없다. 기존 적이 실제로 집 쪽으로 움직인 관측이 있을 때 MID.01을 표시한다. 접근 전에 적을 이미 처치했다면 현재에 맞지 않는 접근 문구를 생략하고 좁은 길 확인과 확보 대화를 진행한다.
- 집 앞 위협 완료와 MID.03 뒤에만 문을 연다. 문 개방 직후 MID.04–05를 마칠 때까지 기존 물리 씬의 종·홀림 tick을 막는다.
- 실제 길찬의 홀림 이동 거리, 경고 지점, 담허의 현장 접근을 확인한 뒤 MID.06–08을 연다. 해당 대화가 끝나기 전에는 소단의 기존 분리 상호작용을 실행할 수 없다. 분리 후 MID.09–11을 끝낸 다음 기존 Engine 기반 은신처 이동을 계속한다.
- COMPLETE.01–03과 저널은 길찬의 실제 분리·은신처 도착·지형 접지·주변 이송로 위협 제거를 모두 확인한다. 단순 `honroV4Safe` 플래그만으로 완료하지 않는다. 저널은 정확한 원고로 한 번만 저장한다.
- 선택 ARCHER_0·KNIGHT_1은 E02 대화가 열리기 전, OCCULTIST_0은 집 앞 위협 완료 전에만 허용한다. 공통 결합 계층이 실제 출연·생존 화자를 다시 확인한다.

## 확인과 한계

`node tests/act23-v4-reviewed14.mjs`는 실제 App·Story·Engine과 통제한 적 처치/접지 위치를 사용한다. 원고 29행 일치, 첫 목소리, 문 개방·종 선후, 적의 실제 접근, 길찬의 실제 홀림/분리/호송, 중간 저장 대화 커서, 선택 시점, 저널 중복 방지, 실패 문구 및 내부 플래그를 검사한다. 이 검사는 정상 전투 완주·브라우저/음향·미술 검수의 증거가 아니다.

2026-10-27 담당 범위의 위 집중 검사와 두 JS/MJS 파일의 `node --check`를 통과했다. 테스트는 은신처 이동 중 길찬의 위치를 직접 지정하지 않고 Engine의 실제 이동·점프·접지를 사용한다. 동행 리더 위치와 라운드 경계는 통제된 입력이다.

이 파일의 담당 범위는 장별 원고·씬 연결뿐이다. 공통 번들/리뷰 결합 계층, 기존 Phase A 지형·적 편성·증원·실패 재시도 정책, 빌드 및 배포는 각각 해당 담당 범위를 따른다. 특히 기존 재시도 정책을 문 개방 직전 체크포인트로 새로 구현했다는 주장을 하지 않는다.

## 실제 브라우저 검수 범위

`tools/testing/act23-v4-reviewed14-browser.py`는 부모가 빌드한 비공개 후보의 Chromium DOM·Canvas·Enter 조작·localStorage를 사용한다. 전투 처치와 동행 위치는 선언된 fixture다. 길찬의 홀림·분리·짧은 은신처 이동은 기존 Engine의 실제 상태와 이동으로 확인한다. 지형·충돌·적 편성·아군 위치의 새 설계는 이 작업 범위가 아니다.

집 앞 도착/첫 목소리, 소식 전달·문 개방·종의 선후, 중간 대화 저장/복구, 길찬 분리·접지된 은신처 도착 및 완료 대화의 복구, 선택 대화 다섯 행의 실제 UI·KNIGHT_1 중간 커서 복구·E02/E03 선택 시점 가드를 확인한다. 증거는 `_local/reports/act23-v4/reviewed14-browser/`의 PNG와 `capture.json`에 남긴다. 일반 전투 완주·공개 배포·실제 오디오 장치 검수와는 구분한다.

첫 캡처의 직접 검수에서 MID.06 카메라가 말하는 소단을 따라 길찬의 실제 이동을 화면 밖에 놓는 결함을 발견했다. 장별 `camera` 계약을 추가해 집 대화는 길찬·집, 홀림/경고는 실제 길찬·경고 지점, 분리/완료는 길찬·은신처를 대상으로 삼는다. 대사는 바꾸지 않고 공통 카메라의 읽기 공간·모바일 응답을 재사용한다. 부모가 이 소스로 다시 빌드한 `http://127.0.0.1:8768/HONRO.html` 비공개 후보에서 2026-10-27 재검사했다. 장별 런타임 SHA-256은 `108479e4bb04c14e65f999cad472628a7b993c2ded02cb77bf030fad31c5bb01`이다. 이는 미커밋 14장 결합·카메라 수정 소스의 검수이며 공개 배포 확인이 아니다.

최종 Chromium 스크립트는 통과했고 page error는 0개다. 대사/안내/선택 대화 25개 고유 행의 DOM 표시, 두 목표의 실제 HUD 텍스트, 정확한 저널 한 번 저장을 확인했다. 실패 문구는 앞의 Node 집중 검사 범위다. 길찬의 실제 홀림 누적 이동은 약 443.97, 은신처 이동은 약 706.97이며 최종 위치 `(2717.45, 2300)`에서 지형 접지가 참이고 혼 분리가 완료됐다. 동행의 리더 위치와 라운드 경계는 fixture이며 길찬을 목적지에 배치하지 않았다.
