# 11장 원고·실제 사건 연결 후보

부모 전달26문구를 그대로 `shared/data/reviewed/act23-v4-ch11.json`에 저장했다. 원고의 ID/화자/본문을 바꾸거나 새 문구를 만들지 않았다. `COMPLETE.05`는 부모가 채택한 Gemini 최종 단문이다. 원문 검수6파일과12–15장 부모 전달 최종 JSON,검수 경과/오대상14장 폐기 상태는 `v4-review/`에 보존한다. 최신 부모 판정상11–15장 올바른 대상 응답은 ID별 대조되어 확정됐다. Library 검수 증거 ZIP은 지원 전송2회가 모두 download failed로 종료됐고, 실제 파일·README·manifest를 확보/검증하지 못했다. 여기 보존한 자료는 부모 메시지의 실제 본문이다. 이 커밋의 실제 연결은11장만이다.

## 빌드·판본·저장

`HONRO_ACT23_V4_PHASE_A=1 HONRO_ACT23_V4_PHASE_B_CH11=1 npm run build`의 별도 내부 worktree만 활성화한다. 기본 build와 Phase A 단독 build는 원고 payload=null/검수 gate=false다. current/compat/legacy catalogue와 raw campaign은 보존한다. Stage11만 이 gate에서 map revision412를 사용한다. 구211/내부411 진행은 기존 성장/SP/장착/완료/기지급 원장 보존 경로로 안전 시작한다. 같은412의 배우·대사 본문/안정 rowId/커서·scene slot은 그대로 재개한다.12장 이후 기계 revision은 유지한다.

ID·화자·본문·reviewedStage11/revision1을 검증하며 임의 reviewedV4 옵션만으로 원고를 허용하지 않는다. catalogueRevision===1과 독립된 판본이다. 장면 종료 acknowledgment도 저장하므로 종료 직후 재접속이 대사를 반복시키지 않는다. 공통 첫 혼령의 기존 승인 본문/관측·기예 조건/queue·Continue를 보존한다. 실패 alias는 다른 장에 확대하지 않았다.

## 검사와 한계

- `tests/act23-v4-reviewed11.mjs`: 원본 App/Engine/Story,본문/ID·순서·가드·원고 중 저장 재개·실제 낮은 화살 충돌/높은 화살 명중·혼 분리/이동·대응 기회 뒤2체 입장·집결·종/잔혼/저널·실패·휴식 커서·구 진행 성장 보존. DOM·Canvas와 일부 전투/영웅 위치는 fixture다.
- `tests/act23-v4-ch11-physical.mjs`: 네 동행이 원본 walk/jump/중력으로 사격 자리와 상여틀 위를 실제 통과한다. 전투를 제거한 동선 fixture다.
- `tests/act23-v4-common.mjs`: 공통 첫 혼령 queue/저장/Continue 보존.
- `tools/testing/act23-v4-reviewed11-browser.py`: 실제 Chromium DOM/Canvas/키 입력/localStorage,대사 순서와 중간 재개,상여틀·차폐·혼 진입/잔혼·목표 UI·여정첩·휴식 대화. 원시 결과는 현재 cloud의 `_local/reports/act23-v4/reviewed11-*`이며 다른 환경의 경로 존재를 보장하지 않는다. 실제 실행 결과와 최종 소스의 화면을 확인한 뒤 성공 범위를 보고한다.

정상 난이도11장 전투·동선 전체 수동 완주,실기기 청취/터치를 검사한 것은 아니다. 12–15장 확정 원고 연결은 후속 범위이며16장 이후 미전달 원고는 적용하지 않는다. master·Pages 반영은 보류한다.

최종 내부 build/Chromium 검사는 통과했고 pageerror0이다. 전체 구조에서는 기존 지형 접지와 암반 연결을, 일반 거리에서는 상여틀 차폐/배우 식별을, 상태·모바일에서는 실제 새 원혼2체와 대사창 겹침을 직접 확인했다. 최종 소스 종합 화면에서 이전 분리 기둥을 연결된 암반으로 교정한 결과와 여정첩 본문 가독성을 재확인했다. 모델 검사9묶음/네 동행 원본 이동4경로도 통과했다. 화면은 이 cloud의 `_local/reports/act23-v4/reviewed11-browser/`에 있으며 전투 처치·일부 위치는 명시적 fixture다.

후속 감사 P1: 원래 shoulder 밖 사체에서 support를 고정해 혼 생성이 막히던 것을 실제 Engine 지지면 선택으로 수정했다. `tests/act23-v4-reviewed11-recovery.mjs`는 원본 이동/도약으로 act2-floor에 도달하고 실제 impulse로 밀린 뒤 처치·저장 재개·안전 배치·단일 생성을 확인한다. 같은 revision412의 기존 교착 저장도 복구한다. 정상 UI 도달성이 없던 휴식 선택 P2는 독립 감사에서 철회되어 제품 결함/정책 변경으로 기록하지 않는다.
