# 6막 2장 설계 카드 / 세 곳의 바깥자리
2026-11-24 / 초안. 원본 ZIP 바이트와 대조되기 전 확정 목표·세부 좌표·수치·대사로 사용하지 않는다. 디자인만, 공개 캠페인 변경 없음.

## 확인된 뼈대
- 6-2는 **무명사 외부**. 세 진목 설치 위치를 확보하는 외부 준비 장이며, 담허의 혼 분리가 경계다. 이후 6-3에서 담허가 단독으로 법당 안의 불가능한 거리를 겪는다. 6-2에서 최종 가름진 성공이나 외부 최종 방어전을 미리 일으키지 않는다.
- 5막 끝의 무명사 산문은 동트기 전에 암벽·석교·옛 종자리를 살피기로 한다. 세 장소는 시각/지리 복선이지만, 원본 ZIP을 확인하기 전에는 세 설치점과 1:1 대응으로 확정하지 않는다. 종터에 묵종은 없다.
- 이전 공간 기획의 이상 현상: 사용 가능한 석교와 능선길 위 여러 고도에서 망자가 현실에 없는 길을 따라간다. 망자의 길은 휘겸이 건너는 발판도, 전원 지워야 할 전투 목표도 아니다.

## 6-1과 달라지는 플레이·화면 가설
- 6-1이 멀리 끊긴 지형을 바라보게 했다면, 6-2는 정상적인 석교/석축과 불가능한 거리·높이의 원경 행렬이 가까이 어긋나 보인다. 물리 전환은 6-4가 중심이므로 아직 전역 중력 반전이 아니다.
- 세 설치 위치의 각 기능이 화면과 플레이에서 달라야 한다. 후보: 높은 엄폐 없는 관측점(사선), 석교 끝 좁은 이동점(타이밍), 암벽 기슭에 매달린 낮은 접근점(우회와 복귀). 세 임무가 같은 연속 버튼/파괴 반복처럼 보이면 반려. 먼저 짚이는 길이 하나 있고 상·하 우회가 선택되는 구조로, 순서 자유 여부는 원본과 정상 입력 검수로 결정한다.
- 비전투 망자의 행렬은 별도 원경/대기 층. 설치를 위협하는 실제 적은 각 위치의 지형적 이점과 역할로 묶고 그 사이를 비운다. 무한 적이나 섬멸 판정을 추가하지 않는다. 정상 이동을 막는 길이면 새로운 특수기 의무를 만들기 전에 뼈대를 바꾼다.

## 검증할 경계
- 진입·설치 부분 완료 각각에서 저장/이어하기; 각 상태의 목표 문구와 다음 위치 안내; 선택 가능한 설치 순서 각각; 이탈·미달·실패 후 재진입에서 중복 설치/중복 보상·플래그 오염 없음.
- 실제 사용한 외부 파티/담허·아군 장착과 성장/다음 내부 장의 발동 계약을 확인한다. 판정 우회로 담허를 미리 분리하거나 기존 50장 산문 세이브를 바꾸지 않는다. 6-3의 별도 씬은 대사·연출/새 전투 시작/되돌리기에서 같은 순서여야 한다.
- [6막 SOP](ACT6_PRODUCTION_SOP_20261124.md)의 G0–G7 전체 적용. 현재 설치점·이벤트·엔진 이동·아트 합격 0. 원본 세부가 미확인된 상태에서도 레이어와 경로 가설 검증은 진행 가능하다.
