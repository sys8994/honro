## 조사한 성장 계약 (수치 변경 없음)

- 상한 30, 다음 레벨 XP `round((180 + 90*(L-1)^1.65)*1.5)`, 누적 상한 372,860. 누적 XP는 경지 2/3/5/10/15/20/25/30에 270/675/2,466/17,184/54,133/121,237/225,393/372,860이다.
- SP 총량 `3 + (경지-1)*2`. 기본기는 무료 1랭크, 기예와 능력치 수련은 같은 SP를 사용한다. 새 합류 시 기존 `autoTrain`과 장착 정리를 유지한다.

전투 XP는 총 예산의 40% 반올림이다. 적별 표시 예산은 `round(전투예산 * 적 가중치 / 전체 가중치)`, 최소 1이며, 실제 지급은 장부 상한으로 제한된다. 기본 가중치는 박쥐 .68, 까마귀 .78, 등불 .80, 혼/인간 1, 그림자 1.15, 짐승 1.25, 수문 1.6, 곡귀 1.45, 정예 ×1.25, 중간보스 3.2, 보스 5다. 유한 증원도 전체 분모에 포함된다.

현재 신규 장은 기여도 v4: 실제 적 HP 예산·지원·목표 기여를 정산하며 지원 점수 ×1.25, 정규 동행 공통 몫 20%, 개인 기여 80%, 낮은 레벨 보정 최대 25%다. 지원·환경 귀속과 예산 보존은 기존 정책이다. 과거 장은 v3 공유 정책을 유지한다. 재도전은 적 HP 기여 상한·지급액·목표 토큰을 저장해 중복 지급을 막고, 완료 장은 XP를 다시 지급하지 않는다. 단순히 재도전 횟수를 늘려 XP를 파밍할 수 없다. 분할 조사의 잔여 보상은 합류 시 한 번 정산된다.

## 레벨업 정책

기존 활성 전투 경로는 `applyHero(..., full=true)`로 살아 있는 동행의 HP·기력·이동력을 **새 최대치까지 전회복**했다. 부모의 후속 지시에 따라 이를 유지하며 30%로 낮추거나 추가 회복을 중첩하지 않는다. 최대치 증가분은 새 최대치 전회복에 포함된다. 사망 또는 HP 0인 동행은 능력치·경지만 갱신하고 HP 0, 기존 기력(새 상한 내)을 유지한다. 행동 완료·턴·쿨다운을 초기화하지 않는다.

전투 v3/v4, 코어 fallback, 일반 완료, 분할 합류 정산은 실제 `grantXP` 결과가 레벨 상승일 때만 같은 처리를 쓴다. 같은 flush의 여러 적과 여러 분할 정산 장부는 먼저 지급액을 모아 캐릭터당 한 번 적용한다. 상한·0 XP·레벨 미상승에는 회복/연출이 없다. 로드·스탯 재계산·합류 보정은 레벨업 이벤트를 만들지 않는다. 과거 stale XP 복구의 기존 최대치 증가분 처리는 보존하며, 로드로 전회복을 주지 않는다.

생존 동행은 1.35초 동안 캐릭터 위치를 따라가는 먹빛/금빛 인장과 청록 파문, 화면 배율과 독립된 `레벨업 · 경지 이전 → 이후 (+N)`을 표시한다. 화면/저장에는 강제 SP 창·전투 정지·카메라 이동이 추가되지 않는다. 연출은 Scene의 임시 Map에만 있고 저장되지 않는다. reduced-motion에서는 상승 이동을 생략한다. 회복은 시스템 회복으로 상처 원장에서 차감되며 힐러/지원 기여 XP를 만들지 않는다. 완료 보고서의 전투/클리어/합류 XP 분류는 별도로 유지한다.

## 최초 합류 정책

기존 담허는 2장 완료 뒤 고정 경지 3, 휘겸은 5장 완료 후 6장 진입에서 고정 경지 6, 소단은 10장 완료 뒤 기존 세 동행 최고 경지였다. 로드의 `repairRecruits`도 과거 고정 하한까지 올려 XP 인상 이후 새 정책을 다시 덮었다.

최초 합류 시 `profile.recruited`에 있는 기존 정규 직업의 경지 평균을 내림한다. 대상 자신·소환체·게스트 NPC·미합류 직업은 제외한다. 프로필/진행 전투의 이미 획득한 XP 중 큰 값을 사용한다. 그 정수 경지 시작 XP로 맞추되 대상의 기존 XP가 더 높으면 보존한다. 재합류/로드에서는 기존 XP 동기화만 하고 고정 합류 하한을 다시 강제하지 않는다. SP는 XP에서 도출하며 기존 랭크·수련·장착·성장 기록을 삭제하지 않는다.

`joinLevel(stage)`는 역사적 보상 앵커 및 NPC 전투 보정 전용으로 그대로 유지했다. `partyJoinLevel(profile, cls, battle)`이 영구 신규 동행의 별도 정책이다. 따라서 모든 장의 보상 총량과 NPC용 담허/휘겸 전투 레벨은 변하지 않는다.
