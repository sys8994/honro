# Stage5 하부 지형과 조우 교정

B3의 높은 주박목·노송 발판·왼쪽 동굴 구도와 보행면, 나무 one-way/Alt 하강, 천장/우벽, 물길진→주박목→적 종료2회 계약을 보존한다. Stage5 밖 지도·이야기·성장·사거리·전투 엔진을 변경하지 않는다.

## 확인한 원인과 지형 처리

B3 바닥은 y3700에서 닫혔지만 stage.height는4300이었다. terrainDomain.extend는 닫힌 바닥이 simulation bottom에 닿아야 아래로 확장한다. 따라서 옆으로만 늘어난 유한 판 아래에 배경이 드러났다. domain이 활성화된 현재 전투는 legacy terrainSkirt도 생략하므로 보완되지 않았다. 이전 검수는 일반 카메라와 나무 상세 위주라 세로 최저 줌/아래 팬의 이 결함을 놓쳤다.

canonical valley-floor의 매몰된 바닥을 안정된 simulation bottom까지 연결해 공통 terrainDomain.author가 동일 암반을 world bottom까지 확장한다. 실제 노출된 보행 경계는 그대로다. 공통 materialLandmarks의 Stage5 전용 opt-in은 하부 벡터의 underpaint/clip을 같은 world polygon에 연결하고 큰 암면과 깊이 음영을 이어 그린다. 우측 절벽의 재질 면도 domain 경계까지 연속된다. 별도 dummy collider·사각형 덮개·새 raster 배경은 없다. 상부 유한 돌턱은 하부 길을 막는 충돌로 채우지 않고, 실제 능선/하부 지표에서 유도한 L1 structural-back 암벽으로 지지한다. legacy 전투와 다른 장은 이 재질 분기에 들어오지 않는다.

## 새 조우

초기9체, 기존 종/기술 생성기 사용, 상한 유지. 같은 HP/기술을 가진 옛 runtimeTemplate을 위치만 바꾸지 않는다. 각 신규 진입은 공통 종별 factory와 현재 난도·피해·존재 방어를 사용한다. 아래 좌표는 엔진 월드 좌표다.

| 군집 | 종·위치 | 활성 구역 | 역할 |
|---|---|---|---|
| 낮은 입구 | 산개920/2580, 멧돼지1090/2620, 원혼1460/2787 | 하부 x500~1600,y2450~2910 | 근접 전위·짧은 돌진·나무 아래 원거리 지원 |
| 상부 안부 | 사수1540/1997, 까마귀1690/1680 | 상부 x820~1820,y1860~2380 | 능선 사격과 높이차 사선 |
| 노송 | 사수2710/1682 | x1990~2990,y1470~2050 | 중간 가지에서 상승 경로 압박 |
| 동굴 | 산개2870/2680, 원혼3140/2675, 수의귀3510/2670 | x2570~3570,y2440~2860 | 입구 전위·낮은 통로 지원·의식 자리 주박 |

의식이 시작되면 하부 증원을 예고하고 다음 라운드부터 산개2+원혼2가 실제 낮은 물길의2690/2410 부근에서 진입한다. 동행이 입구를 점유하면420 서쪽 대체 입구 또는 점유 대기를 사용한다. 공통 multi-spawn의 전원 사전 예약으로 부분 생성/중복을 막고 하부 지지면과 담허 추격을 유지한다. 나무 상승 구간의 별도 예고 후에는 중간 가지 위 실제 비행 여유를 검사한 까마귀2가 들어온다. 각 반응은 한 번뿐이며 추가 무한 증원/HP 보정은 없다. 기존 임무의 유한 종료 반응은 보존한다.

구역 활성은 거리만으로 다른 층까지 깨우는 대신 저작한 공간을 사용하고, 피격/교전 경계는 유지한다. 유한 반응의 표적은 하부 담허/상부 설오로 정하며 실제 이동·사격·행동 상한을 우회하지 않는다. 지도 revision6은 호환되지 않는 Stage5 구전투만 다시 시작하고 성장·SP·장비·완료 기록·Workshop을 보존한다.

## 집중 검증 기록

검증 루트: Git 제외 `_local/reports/stage5-foundation-20261026/`.

- 수정 전 최신 master의 동일720×1412/최저 줌 재현: `before/stage-5-portrait-min.png`.
- 1차 전체/아래/좌우 연결: `pass1/`. 하부 하늘 공백 제거를 확인했고 우측 재질의 직각 종단을 발견했다.
- 2차 암면/우측 재질/가로·데스크톱: `pass2/`. 공통 world polygon에 재질을 연결해 종단을 제거하고 매몰 기반암을 큰 면으로 분할했다. Native Canvas이며 실제 HUD 입력 검증과 구분한다.
- 상부5점프와 하부 동굴 진단 경로는 통과했다. 고립 몸체/이동 예산 갱신을 쓰는 물리 진단으로 정상 진입 완주를 주장하지 않는다.
- 초기 정상 자원 입력은6행동/3적 페이즈로 제한했다(`entry-input/trace.json`). 실제 입구 점프·사격과 산개/멧돼지/원혼/까마귀의 피해 교환을 기록했다. 과거 진입 도우미의 동행 XP 동일 강제는 최신 모집 규칙과 달라 중단했으며 현재 보상/모집 결과(설오1868,담허1643)를 그대로 사용했다. 성장 코드는 변경하지 않았다.
- 동굴 의식/중간 가지의 준비 위치에서3적 페이즈 역할 확인과 유한 증원, 마지막 화면/빌드는 진행 중이다. 준비 위치 주입을 정상 진입 경로로 표현하지 않는다.

사용자 원본 스크린샷은 지원된 소비 환경 materialization 최초/1회 재시도가 모두 다운로드 오류로 끝나 로컬 파일이 없었다. 원본 픽셀 검수는 완료로 기록하지 않으며, 저장소의 수정 전 정확한 재현을 별도로 남긴다. 스크린샷을 Library에 새 업로드하지 않는다. master 통합과 Pages 상태 조율은 부모가 먼저 순서를 결정한다.
