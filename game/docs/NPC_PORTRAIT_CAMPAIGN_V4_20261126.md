# 혼로 대사 초상화 v4 적용 기록
기준 소스: `29793bee12a199e53bd8c0509ced68b827e09e1e`. 실제 막별 대사 소비 경로와 새로 증설된 대사를 확인했다. 초상만 바뀌며 대사 문장, 얼굴·이름 공개 규칙, 서사 영수증, 전투, 맵 및 다른 화자의 화풍은 변경하지 않는다.

## 적용 범위
- 1막: 이미 연결된 기존 승인 초상을 유지한다. 얼굴이 없도록 설계된 서술·안내는 유지한다.
- 2막: 유헌의 기존 승인 종지기 초상을 실제 낭독 행에 연결한다. 18장·19장 생존자는 서로 다른 새 초상이다. 19장 주민 1/2와 동생을 잃은 형/언니를 잃은 동생은 각각 같은 배우의 기존 초상을 유지한다. 가족의 혼 셋은 작별 장면에만, 읍성 피란민은 20장 소식 장면에만 보인다.
- 3막: 21·28·30장 곽진, 24장 공방 주민, 29장 한태록, 30장 나루 사공에 새 초상. 24장 공방 주민 대사는 지상 배우가 실제 받아들여진 행에 한한다. 26장 구조 주민은 이전 승인 초상을 유지한다. 27장 정체 미공개 목소리는 얼굴을 넣지 않는다.
- 4막: 32장 고향 사람, 38·39·40장 도식 대사에 적용한다. 39장 도식은 최신 확장 행을 대조해 포함했다. 이미 붙어 있던 연실은 유지한다.
- 5막: 41·44·45장 도식, 42·43장 곽진, 43장 장무율, 46장 기억/두 번째 진목의 현묵을 연결한다. 현묵이 현재 살아 있는 배우인 것처럼 등록하지 않는다.
- 6막: 57장 외부 진지의 곽진은 앞 장과 같은 얼굴. 58장 대도사는 새 전투 외형의 갈라진 관, 낡은 붉은 관끈, 누런 금실, 건조한 긴 얼굴과 회색 수염을 초상에 유지한다. 등장·두 번째·세 번째 국면 대사만 추가 연결한다. 언급·추모에 올라오는 박문돌·이만복에는 자동으로 얼굴을 붙이지 않는다.

## 자산과 보존
WebP 15개(각 768×1152, 투명 알파)는 `shared/assets/portraits/npc-campaign-v4/`에 둔다. `game/config/npc-portraits.json`에 제작 원본 SHA-256, 배포 파생 SHA-256과 프레이밍을 기록한다. 14종 원본은 기존 전달본 `HONRO-초상화-전수조사와-후보-15종.zip`의 원본을 보존하고, 대도사 새 원본은 별도의 승인 검토용 `daedosa.png`로 보존한다. 예전 사각관·보라 겉옷의 대도사 후보는 설치하지 않는다. 원본 재보존 경로는 제작 담당자 인계 기록에 남긴다. 기존 승인 원본 및 재사용 PNG·WebP를 덮어쓰지 않는다.

초상 선택은 실제 행(막4의 `act4PreviewRow` 포함), 장면·화자, 검증된 배우 순서이며 이름 유사성이나 직업으로 교체하지 않는다. 기존 lazy load/decode, 한 자산 단위 재사용, 정해진 이미지 실패 중립 처리를 그대로 사용한다. 웹 생성물은 소스 빌드로만 생성한다.

## 검증
`node tests/npc-portrait-campaign-v4.mjs`: 신규 행 80개, 5막의 화자 발화 50개 연결, 6막 장면 4개, 투명 자산 15종의 파일과 SHA 검증 및 이름 기반 오매핑 차단. `tests/npc-portrait-campaign-browser.py`는 6막 8장 기둥→문턱 실제 대면과 유헌/주민1/2 등 실제 앱 대사창의 디코딩된 초상, 표시 이름, 양쪽 조작 버튼의 위치, 모바일·PC 광학 구성을 분리해서 검사한다. 브라우저에서 재연한 특정 행과 라이브 전투 도달은 구분하며 전 캠페인 연속 플레이를 주장하지 않는다.
