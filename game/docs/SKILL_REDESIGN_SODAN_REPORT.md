# 소단 기예 개편 결과

소단의 기본기는 기력 0의 혼령탄으로 분리했다. 혼행·주박·초혼은 각각 다섯 기예이며 마지막 칸은 만혼귀결·지박부·반향령이다. 기존 투과령·역천령·황천창·회귀망령, 쇠망부·증오부, 배회령·등불귀의 핵심 투사체와 효과는 그대로 사용한다. 새 현형·섭혼·지박·잔혼은 전장 그래픽과 컴팩트한 상태 아이콘에도 표시한다.

새 주박은 현형·섭혼·지박을 담당한다. 현형 상태에는 `manifested`, `revealSpiritToParty`, `formDamageTakenBonus`를 남긴다. 섭혼은 일반 적의 편과 전투 스탯을 잠시 바꾸며 정해진 실제 행동 횟수를 마친 뒤 `min(포획 시 체력 비율, 현재 비율)`로 돌아온다. 지박 대상이 죽으면 최대 네 기의 고정 지박령이 짧은 범위 피해·둔화를 남긴다. 영안은 소단 기본 속성으로 부여하며, 아직 등장하지 않은 은신 혼령을 위한 판별 함수를 둔다.

초혼령은 소단 행동 종료 직후 자기 소환령만 한 번 행동하고 아군 팀 종료에는 중복 행동하지 않는다. 등불귀는 낮은 랭크에서 한 대상, 높은 랭크에서 최대 두 대상을 노린다. 호혼령은 방호와 향후 혼 성향/저항을 위한 수치를 준다. 먹귀는 제한 반경의 적 탄을 끌어당겨 흡수하고 임계치에서 터진다. 반향령은 소단이 혼행을 발사할 때 확정된 같은 월드 목표를 각자의 원점에서 겨누며 75/150/225ms 간격으로 준동시 발사한다. 주박·초혼은 반향하지 않는다.

만혼귀결은 대표탄이 실제로 닿은 자리를 귀결점으로 삼는다. 각 원점에서 10~14기의 혼령이 지형을 통과하며 곡선으로 모이고 경로·도착점에 피해를 준다. 조준 중에는 원점마다 대표 예상 궤적 하나만 그린다. 부적·혼매듭·희미한 혼령을 쓰고 새 효과에서 거대한 룬이나 Canvas `filter`는 사용하지 않는다.

## 기획안-현행 코드 충돌 및 처리

| 기획 항목 | 현행 코드와 처리 | 남은 한계 |
| --- | --- | --- |
| 계통별 궁극기 셋 | 기존 트리는 계통당 다섯 칸과 별도 공통 `O99` 하나였다. 기존 칸을 재사용하고 혼행만 `O16`을 추가했다. 세 끝 기예를 SP 8까지 성장하는 `capstone`으로 두고 `O99`는 장착·해금에서 제외했다. | 구 저장의 비행 중 `O99`만 숨긴 이전 정의로 해소한다. |
| 형/기/혼 피해와 영안 | 속성 피해 체계나 은신 혼령형 적이 아직 없다. 현형·영안·호혼령 수치를 저장 가능한 hook으로 추가하고 현재 전투 수치를 강제로 재분류하지 않았다. | 추후 적 타입·속성 피해가 생기면 이 hook을 연결해야 한다. |
| 소환령 행동 순서 | 기존 `summonTurn`은 아군 전체 턴 뒤였다. 같은 저장형 단계를 소단 직후에도 실행하고 `summonActionRound`로 그 라운드의 중복 행동을 막았다. | 소단이 없는 옛 진행은 팀 종료의 기존 경로를 유지한다. |
| 기존 스킬 ID와 저장 | `O08`~`O10`, `O13`~`O15`의 뜻이 바뀌었다. 옛 탄·NPC 스킬은 `LO*` 정의로 마무리하고, 바뀐 투자와 `O99` 투자는 SP로 환급한다. XP·통계·`O02`~`O07` 투자는 보존한다. | 진행 중인 옛 소단 행동의 장착 구성은 새 기예로 자동 치환하지 않고 기본기와 보존 기예만 남긴다. |

## 검증

- `node tests/sodan-redesign.mjs`: 기존 아홉 기예, 신규 주박·초혼·만혼귀결, 섭혼 전 랭크 표, 다섯 패시브 대표 상황, 반향 제한·목표·지속·한도, 상태 저장과 구 기록 환급.
- `python -X utf8 tests/sodan-redesign-browser.py`: Game과 Workshop에서 주박→배회령→반향령 3체→혼령탄→만혼귀결 순서의 짧은 전투. 20개 표적·56개 귀결 혼령·80프레임 렌더 구간은 반복 실행에서 약 145~190ms였다. 화면은 `_local/reports/sodan-redesign/`에 저장했다.
- `npm.cmd --prefix game run typecheck`, `node tests/migration.mjs`, `python -X utf8 tests/integration.py` 통과. 마이그레이션 검사는 새 혼령탄 수치가 10장 소단 보스 템플릿의 공격력 두 필드만 달리 계산하는 것을 명시적으로 고정하고, 지형·단계·유닛의 나머지 데이터는 모두 비교한다. 활성 캠페인의 기존 보스 수치는 보존했다.
- `node tests/finale-update.mjs` 통과. 기존 시험의 10장 최소 클리어 라운드 기대값을 현재 게임 규칙인 15라운드와 맞췄다.
- 새 스킬의 전투·시연·저장 경로는 두 HTML이 같은 번들을 사용한다. 다른 브라우저 부하 없이 성능을 순차 측정한다.

전체 `verify`는 기존 전 기능·전 화면을 반복하므로 사용자 요청에 따라 이번 수정과 직접 관련된 검사만 했다. 실제 캠페인 10개 스테이지 전체 완주와 실기기 모바일 발열은 대표 검사 범위에 넣지 않았다.
