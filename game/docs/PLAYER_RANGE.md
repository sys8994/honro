# 플레이어 발사 사거리

사거리 기준과 캘리브레이션 값의 원본은 `shared/engine/src/playerRange.ts`의 `PLAYER_RANGE_TUNING`이다. 무풍, 같은 높이의 평지, 몸 높이92, 조율0.5, 사용 기예 경지1, 상시 기예0, 최대 충전의 본탄·표식 중심을 기준으로 한다. 화면 픽셀·폭발 반경·후속탄의 총 외연과 구분한다. 50%는 최대 발사속도의 절반이며 고정된 일반 발사 설정이 아니다.

일반 탄은 실제 감쇠·중력·생성 오프셋·1/120초 충돌을 넣어 발사속도를 맞췄다. 설오의 새 플레이어 발사는 중앙 설정에서 조율에 따른 속도 ±2%를 반영한다. 기존 1.26−0.14×조율 배율을 다시 중첩하지 않는다. NPC·적·구형 전용 기예의 속도와 피해는 유지한다. 거리 피해는 여전히 생성점부터1800에서 상한이며 정심은 비행거리를 늘리지 않는다.

## 유한 비행과 후속 효과

소단 혼령탄·황천창·회귀망령의 새 발사는 최초 시전자 위치와 유한 시간/거리 예산을 기록한다. 먼저 닿은 지형·유닛 충돌 규칙을 유지하고, 예산이 끝나면 공중 효과를 낸다. 자탄의 age가0이 되더라도 flightAge/flightRange는 상속한다. 반향령은 독립 발사이므로 자신의 발사 위치에서 같은 예산을 받으며 시전자에게 반경으로 묶이지 않는다. 일반 소환령의 다턴 이동 예산도 바꾸지 않는다.

회귀망령은 기존28% 출항 관통 피해를 유지한다. 지형이 먼저면 기존95% 귀환 폭발을 유지한다. 공중 종결이면 기존95%를 공중38%와 귀환57%로 나눈다. 표식 대상의30% 가산·기존 폭발 감쇠는 유지하며, 공중 폭발을 기록한 저장 상태는 다시 폭발시키지 않는다. 귀환은 실제 경로를 되짚는다.

등불귀의 플레이어 소환체는1100 안의 대상(+대상 몸체)을 선택하고, 탄은 독립 발사점부터1200/1.2초 안에서 추적한다. 범위 밖에는 발사하지 않는다. 기존 NPC 소환과 이미 날아가는 탄은 종전 예산을 유지한다.

휘겸 돌격의 새 발사는 경신에 따른 거리 성장을 선형 예산에 맞추고 수평1500에서 추진을 끝낸다. 그 뒤 중력과 몸체 충돌로 실제 낙하·착지를 이어간다. 검기 성장도 속도 배율의 제곱으로 늘지 않게 한다. 검술의 기존 근접 범위는 유지한다. 강궁 충돌 속력·곡사 낙차 피해 계수에는 새 발사속도와 예전 기준의 비율을 기록해 사거리 조정이 중복 피해 하향으로 작용하지 않도록 정규화한다. 기본 피해를 올리지 않는다.

## 저장과 검증

새 필드는 투사체별 선택 정보다. 저장 프로필·SP·장비·완료 기록·캠페인 map revision을 올리거나 전투를 리셋하지 않는다. 변경 전 비행 탄은 새 예산을 주입하지 않으며, 기존 전투에서 다음에 발사하는 탄부터 조정한다. 소단 조준선은 기존 힘 적분·충돌 예측에 실제 발사와 같은 최초 예산을 공유해 공중 종결점/귀환 시작점을 계산한다. 조준 중 battle 복제·가상 발사·소환·피해는 실행하지 않는다. collect=false는 경로 배열을 수집하지 않으며, 예산이 없는 부적/씨앗은 기존 간소 적분 간격을 유지한다. 구속의 BODY 속도0.72배는 캘리브레이션 이후 적용한다.

집중 검사: `node tests/player-range.mjs`, `node tests/returning-wraith-fall.mjs`, `npm --prefix game run typecheck`. 일회성 전후56항목 표·조율/최대 성장 민감도·Stage5 정상 사격점·Chromium 공중 효과 증거는 `_local/reports/player-range/`에 둔다. 각도 전역5도/근방0.25도 탐색의 근사값이며, 임의 바람·표적 유도·수동 선회·모든 캠페인 완주를 보장하는 표가 아니다. 거리 예산은 STEP 경계에서 판정하므로 비행 한 substep(통상8 미만)의 오차가 있을 수 있다.
