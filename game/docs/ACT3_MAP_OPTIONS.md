# 3막 고밀도 도시·건축 전장 제안

**전투 전제 변경(2026-10-07):** 이 역사 초안의 인간 회수조 직접 전투·비살상 대안은 더 이상 현재 구현 기준이 아니다. 사용자가 선택한 인근 읍성의 들림과 죽은 육신에 남은 악귀, 살아 있는 피신·구조 주민의 구분은 [현재 런타임 계약](ACT3_RUNTIME_CONTRACT.md#regional-fiend-revision-2026-10-07)을 따른다. 아래 공간 검토의 기록은 보존한다.

**최종 콘셉트와 지도는 미승인이다.** 첫 세 후보는 건물 밀도가 부족해 채택되지 않았다. 1안의 높낮이만 출발점으로 삼고, 훨씬 많은 건물을 실제 게임 지형으로 쓰는 한 방향을 새로 제안한다. 이전 문서와 도식은 [첫 비교안 역사 자료](ACT3_MAP_OPTIONS_V01.md)에 보존한다. 이전 그림의 건물 수·치수·추천 표시는 현 설계 기준이 아니다.

이 문서는 검수용 사양이다. 운영 캠페인·런타임·에셋 등록부·HTML 빌드 입력을 변경하지 않으며, 아래 좌표와 수치는 프로토타입 검증 전 시작값이다.

## 기준과 새 방향

- 출처: 사용자 제공 `HONRO_스토리_기획_v0.1.pdf` 26쪽 전문. 17–23쪽의 3막 사건과 23–26쪽의 공개·유보·설계 원칙을 따른다. 이전 막과의 연결은 [스토리 반영 계약](STORY_CANON_V01.md)을 따른다.
- **강과 수로를 낀 거대 읍성권의 겹겹 건축 전장.** 상점·주택·관창·문루·회랑·담장·관아·큰 기록고가 포격각, 이동 층, 엄호 위치와 진행 경로를 만든다.
- 건물 몇 채를 긴 평지에 띄엄띄엄 놓고 뒤에 수십 동을 그리는 방식은 배제한다. 실제 플레이 전면에도 건축 밀도를 확보한다.
- 도시의 뒤편은 건물군으로 만든다. 별도의 먼 성벽·지붕군·강 맞은편 창고들이 장소와 규모를 설명한다. 모든 배경을 숲과 산으로 처리하지 않는다.
- 물은 여러 갈래의 경로 분리, 석교·목교·회랑 연결, 교대 엄호, 한 번의 수문 개방과 하역길 전환에 쓰인다. 유체 시뮬레이션이나 전체 구조물의 물리 붕괴를 전제하지 않는다.
- 궁궐 같은 규모감은 큰 관아·왕실 방계 저택의 전각과 담장 구성으로 검토한다. 수도·실제 왕궁·왕의 현재 거처를 임의로 확정하지 않는다.
- 다채로운 기믹·목표·역동적 지형·뚜렷한 배경 전환이 최우선이다. 그에 맞춰 사건 순서를 바꿀 수 있지만 저문골 → 묵종 → 무명사의 인과와 정보 공개 경계는 유지한다.

## 확장 지리와 실제 플레이 크기를 구분

건물이 많다는 이유로 이동거리나 층간 높이를 무작정 늘리지 않는다. 앞선 논의의 10,400×4,600 / 9,200×6,200 같은 큰 수치는 확정 Play Bounds가 아니며, 아래 시작값으로 대체한다.

| 항목 | 밀집 수로 도시 프로토타입 | 거대 기록고 절개 프로토타입 |
|---|---|---|
| Play Bounds 시작값 | 약 7,600×3,500 | 약 6,200×3,400 |
| 주 이동면 | 지상·하역로 y≈2,600 | 하층 y≈2,500 / 중층 2,080 / 상층 1,660 |
| 선택 엄호 높이 | 지붕 y≈2,050–2,250 | 각 층의 작은 서가 회랑·서쪽 상층 |
| 실체 밀도 | 실제 건물 9동 + 고정 교량 3곳 | 단일 대건물 내부 12개 건축·충돌 구획 |
| 배경 밀도 | 30–40동 규모의 서로 다른 군집 | 외부 진입부의 도시군 + 실내 뒤벽·서가·기둥군 |
| 필수 이동 | 마른 도로와 고정 다리를 통한 순방향 진행 | 두 계단 구간과 중층 연결교를 통한 3층 접근 |

- `terrainBounds`는 공통 v6 지형 정책으로 별도 확장한다. 확장된 바깥 세계를 이동 목표나 전투 공간으로 세지 않는다. [TERRAIN_DOMAIN](TERRAIN_DOMAIN.md), [CAMERA_BOUNDS](CAMERA_BOUNDS.md)를 따른다.
- 캐릭터 크기를 맞추려고 늘이거나 줄이지 않는다. 실제 배치된 네 동행의 `h/r/maxMove/jumpCost`와 이동·도약 궤적을 먼저 읽고 맵을 조정한다. 엔진 생성 기본값 `h=72`가 모든 최종 배치의 측정값을 대신하지 않는다.
- 기록고 층간 420은 약 5–6개 인물 높이를 출발점으로 삼는 가설이다. 한 층을 2–3개 중간 쉼면으로 나누며, 단일 상승 120–180, 쉼면 폭 180–260, 경사 0.4–0.65부터 검증한다. 엔진 보행 상한 1.35를 계단 설계 목표로 쓰지 않는다.
- 계단은 실제 지지면을 갖는다. 낮은 계단 무늬 뒤에 수직 벽을 숨기거나 필요한 이동을 그림으로만 연결하지 않는다. 필수 경로는 특수 이동 기예 없이 네 동행 모두 통과할 수 있어야 한다.
- 구간별 누적 이동거리와 가장 작은 실제 `maxMove`를 비교해 이동만으로 필요한 턴 수를 보고한다. 약 600–1,000 이동마다 엄호·문간·목표·전투 위치를 두되, 최종 간격은 실제 이동량으로 조정한다.

## 대표 A: 밀집 수로 도시

### 전면 건축과 경로

9동은 서문, 상점, 복층 주택, 수문 관리채, 대형 관창, 감시채, 작업창고, 동쪽 관창, 출구 문간으로 구성한다. 폭은 대략 350–800부터 배치하되 모든 건물에 지붕·처마·문간·층바닥·담장 중 하나 이상의 실제 충돌/이동/사격 역할을 부여한다. 이름만 다른 배경 장식을 활성 건물로 세지 않는다.

- 두 수로 폭은 각각 약 550–700. 첫 수로는 석교와 교대 엄호, 두 번째는 목교와 하역장 경계로 다른 전투를 만든다.
- 세 번째 고정 연결교는 지붕/회랑 사이에 놓아 아래 골목과 위 엄호 길을 연결한다. 필수 지상 호송 경로와 구별한다.
- 지상 길은 여러 건물의 열린 문간과 처마 아래를 지나고, 수로에서 다시 하늘이 열린다. 지붕은 최대 두 주요 높이로 읽히게 한다.
- 높이가 다른 지붕 사이는 기존 도약 또는 짧은 계단·연결교로 접근한다. 닿지 않는 장식 지붕에는 적·목표·필수 아이템을 배치하지 않는다.

### 진행·승리·장면 변화

진입 골목 확보 → 수문 관리채 접근과 개방 → 수로의 고정 두 상태 수위 변화로 짧은 하역 우회길 개방 → 장부함 운반자 엄호 → 관창 출구 도착. NPC는 마른 순방향 지상길과 고정 다리로 이동하며, 지붕을 오르거나 뒤로 돌아오는 새 경로 엔진을 요구하지 않는다.

수문은 기존 `act2.js`의 단회 개방·수위 하강 개념을 분리해 재사용하는 후보다. 프로토타입에서 상태 전환까지 구현하지 않았다면 **기본 수로·다리 충돌만 검증**, **수문 진행 미구현**을 구분한다. 물을 바닥 그림으로만 두고 기믹 완성으로 보고하지 않는다.

이 장의 정보는 시신·생활 금속의 무명사 운송과 회수조의 첫 개입이다. 종 제작법이나 최종 목적은 밝히지 않는다.

## 대표 B: 거대 기록고 절개 실내

한 건물의 여러 층과 방을 실제로 드나드는 전장이다. 외벽과 지붕을 크게 그리고 내부 바닥만 비워 놓는 방식은 피한다. 12개 구획은 하층 진입문·분류실·서가동·보존실, 두 계단실, 중층 회랑·연결교·열람대, 상층 문서실·서쪽 엄호실·출구 발코니처럼 서로 역할이 다른 공간이다. 단일 건물을 억지로 12동이라고 세지 않는다.

### 층과 필수 접근 경로

- 하층: x≈1,000–5,900, y≈2,500. 짧은 처마 진입 뒤 분류실과 서가 사이를 통과한다.
- 서쪽 계단: x≈1,900–2,600에서 중간 쉼면을 거쳐 y≈2,080까지 올라간다.
- 중층: x≈2,600–3,200의 회랑, x≈3,200–3,900의 고정 연결교. 아래가 열린 중정/채광정으로 층간 사격 구간을 만든다.
- 동쪽 계단: x≈4,000–4,700에서 y≈1,660으로 올라간다.
- 상층: x≈5,000–5,650의 문서실과 보호 대상, 이후 출구 발코니. 서쪽 상층은 선택 엄호 경로다.
- 통로의 유효 머리 공간은 실제 가장 큰 동행을 기준으로 확보한다. 대개 3.5–5개 인물 높이부터 검토하고, 구조재 두께와 머리/무기 가림을 함께 확인한다.
- 채광정은 모든 층을 하나의 긴 곡사로 무력화하지 않도록 짧은 회랑 끝·층바닥·서가 차폐를 조합한다. 완전히 막힌 천장 복도와 열린 중정이 번갈아야 한다.

### 진행·승리·장면 변화

하층 문간의 봉쇄 표적 개방 → 중층에서 소각용 지정 표적 무력화 → 위층 서리가 기록을 정리하는 동안 보호 → 발코니 출구 확보. 보호 NPC는 상층에 머무르며 수직 호송하지 않는다. 정밀파괴·진입·거점 보호·탈출의 단계는 기존 시스템 조합으로 설계한다.

소각은 국소 표적의 상태와 보호 진행으로 표현한다. 실제 불 확산이나 전체 건물 붕괴를 필수 조건으로 추가하지 않는다. 빛은 종이창·채광정·층 사이의 밝은 틈에서 들어와, 암반 천장의 동굴과 다른 실내를 만든다. 이 장에서는 이름 삭제와 조사 요구 이후 가문 몰락을 밝히고, 대도사의 목적·현재 상태는 유보한다.

## 대표 C: 대형 관아·방계 저택 권역 — 후속 검토

11개 전각·문간·회랑을 여러 마당과 두 물길 주위에 배치한다. 외문·행랑·객당·중문·수로 회랑·대전각·동회랑·내문·사당·기록채·정원 누정이 실제 이동·충돌·사선에 관여한다. 대전각 하나와 배경 집들로 대신하지 않는다.

문장과 보호지 확인 → 기록채에서 무명사 주조 연결 → 회수조 침입과 입구 봉쇄 → 정원 옆문 탈출로 이어진다. 궁궐 규모감은 많은 전각, 넓은 처마, 층을 잇는 회랑으로 만들고 실제 왕궁이나 수도 설정을 추가하지 않는다. 이번 우선 프로토타입 두 장에는 포함하지 않으며, A/B의 실제 밀도·이동 결과를 보고 상세 치수를 정한다.

## 겹친 건물과 가독성의 공존

- **충돌/이동층:** 지붕, 층바닥, 담장, 교대, 필수 계단은 한 좌표계의 canonical polygon. 장식 뒤에 보이지 않는 벽을 두지 않는다.
- **건물 뒤면:** 실내 벽·서가·기둥은 동행 뒤에 그린다. 전면은 측면 절개로 열고, 이미 승인되지 않은 실시간 자동 벽 숨김 시스템을 필수로 요구하지 않는다.
- **가까운 장식:** 표적·조준선·보호 대상 앞을 덮지 않는다. 큰 처마는 실루엣으로 사선을 막는 높이를 명확히 보여준다.
- **배경 도시군:** 지지면에 붙은 거리별 군집을 사용한다. 앞의 건물보다 낮은 대비·채도로 분리하고, 크기와 형태가 다른 군집 사이에 하늘·물의 틈을 남긴다. 건물 수만 늘린 단일 반복 띠로 밀도를 대신하지 않는다.
- **모바일 검수:** 전체 조감 캡처뿐 아니라 390×844와 844×390의 실제 일반 확대 화면이 필요하다. 현재 배우, 다음 쉼면/문간, 사선을 막는 처마가 함께 읽히는지 확인한다. 최소 줌의 기존 actor 식별 규칙을 바꾸지 않고 가까운 전투 화면을 별도로 검토한다.

## 10장 흐름의 새 적용 제안

순서는 아직 미확정이며 원안 두 폐가 장의 통합도 검수 대상이다.

1. 성밖 강변 접근: 도시의 지붕군을 멀리 보고, 수레 통로 개방·주민 구조로 진입한다.
2. 성문·밀집 장터: 문루·차양·복층 점포 사이에서 경로 개방과 대피 보호를 한다.
3. 관아 기록고 별동: 거대한 본관으로 이어질 규모를 보여주고, 종이창·서가 실내에서 공식 보고와 호적을 비교한다.
4. 수로·관창: 대표 A. 여러 건물과 물길·다리를 실제 엄호/운반 전장으로 사용한다.
5. 외곽 방계 저택: 대표 C. 여러 전각·정원·기록채를 거쳐 발견 후 바뀐 퇴로로 탈출한다.
6. 불탄 공방: 지붕이 무너진 큰 작업장과 가마·창고를 지나 유족 구조·핵심 장치 제압을 한다.
7. 거대 기록고 본관: 대표 B. 3층 내부·서가·연결교·채광정에서 소각 저지와 기록 보호를 한다.
8. 북문 외청·관아 석축: 대문·회랑·성벽 진입로를 돌파하고 승인·현장 학살·은폐의 책임을 구분한다.

**3막 확정 공개:** 저문골의 무고함과 휘겸 선조의 보호지, 대도사의 보고에 따른 제압 승인과 현장 학살, 고위층의 사후 은폐, 시신·생활 금속의 무명사 이송과 대종 주조·잠운사 이송, 선조의 조사와 가문 몰락, 현묵의 제자 계통, 무명사의 어그러짐, 일반 빙의가 아닌 대도사.
