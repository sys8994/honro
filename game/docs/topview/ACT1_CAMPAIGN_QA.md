# 혼로 탑뷰 1막 · 아침 인계

**연목 고갯길에서 동쪽 외문까지 열 장이 이어진다.** 첫 장의 오프닝·조작·저장에 이어 아홉 전장과 장간 쉼터, 1막 엔딩을 구현했다. 새 여정에서 얻은 2장 저장을 한 번 불러온 뒤 같은 탭에서 2~10장을 이겼다. 소단까지 네 사람이 외문으로 나온 뒤 기존 스틸 세 장을 넘겼고, 타이틀에서 열 장의 클리어 기록이 남았다. [플레이](https://sys8994.github.io/honro/) · [아홉 전장 비교](evidence/act1-campaign/contact.webp) · [수치와 승패 조건](evidence/act1-campaign/verification.json)

1장은 PC와 터치 입력으로 각각 직접 공략해 2장을 열었다. 2~10장 연속 경로에서는 적 턴과 물리 시간을 가속하고, 엔진의 걷기·사선 예측·발사·방어·상호작용을 사용했다. 쉼터에서는 번 SP를 기존 자동 배분 규칙으로 썼다. 별도의 새 브라우저 프로필로는 아홉 장 모두 키보드 또는 터치 스틱 이동, HUD 발사, 페이지 새로고침, 타이틀 이어하기를 실제 입력으로 확인했다. 이 개별 입력 검사에서는 장 잠금만 미리 풀었다.

## 검수 중 찾아서 바꾼 부분

- 이전 1장 데모를 실제로 이긴 저장은 쉼터를 1장에 고정해 두었다. 이 저장으로 확장판의 타이틀 이어가기를 눌러 1장이 다시 열린 것을 재현했다. 이전 데모의 완료 상태일 때 원래의 1→2 직접 전환을 복원했다. 같은 원본 저장으로 상여길이 열렸고 1장 클리어·일지·경험치는 그대로였다.
- 2장의 늦은 비행 증원이 옛 횡스크롤 공역을 검사해 상여가 끝에서 기다리는 문제가 있었다. 원래의 절벽·분지에 탑뷰 공역을 등록하고 날짐승의 몸 전체가 들어갈 자리를 검사한다. 정상 경로에서 마지막 전투와 도착을 모두 확인했다.
- 3·6장 상판은 양 끝점·폭을 공유해 그리기와 걸음이 맞는다. 6장 초기 시안은 목표와 실제 보행면이 283단위 떨어져 있었다. 연결부를 고친 뒤 운반대를 호위해 장을 마쳤다. 뒤 검수에서는 양쪽 절단부에 드러난 장선과 낡은 판재의 가로 결을 더했다. [목교 이전](evidence/act1-campaign/06-before.webp) · [목교 보정 후](evidence/act1-campaign/06.webp)
- 5장의 초판 낙수는 물 위에서 직선들이 갑자기 시작해 굽이가 읽히지 않았다. 고정된 바윗턱, 가는 물줄기, 하류 포말을 붙였다. 진을 사용하면 물의 흐름과 사격 환경장이 함께 바뀐다. [낙수 이전](evidence/act1-campaign/05-before.webp) · [낙수 보정 후](evidence/act1-campaign/05.webp)
- 8장 증원은 원본의 웨이브별 출구에 산개·까마귀·혼불 몸이 동시에 들어갈 자리를 마련했다. 점유한 출구에서는 분대가 보류됐다. 정상 저장에서 첫 결박 뒤 서쪽 증원이 3라운드에 나왔다. 내려오는 길을 비워 준 두 번째 공략에서는 22라운드 하강 완료, 23라운드 까마귀, 28라운드 낮은 체력 증원, 30라운드 승리를 기록했다. [라운드·출구 기록](evidence/act1-campaign/verification.json)
- 쉬운 시도만 남기지 않았다. 초반 5장은 훈련 없이 노출된 사격점에 머물러 8라운드에 패배했다. 7장은 아군이 사선을 가린 동안 주민을 잃었다. 10장은 영웅 셋이 먼저 외문에 도착한 뒤 소단이 사망해 17라운드에 패배했다. 다시 시도할 때에는 훈련·자리·호위 행동을 바꿨다.

## 자산과 수정 파일

- **집·나루·의식터**에 민가, 창고, 부러진 교각, 망루, 우물, 제단, 결박주, 돌계단, 화물, 운반대, 상여, 당목 12종을 제작했다. 여기에 목책, 돌축대, 장례 깃천, 작은 종걸이 네 종을 장의 필요에 맞게 배치했다. 처마·수관은 발보다 앞에서 겹치며, 깃천은 걸음을 막지 않는다. [배치·치수](../../../topview/tools/compile-act1.py) · [원본 그림](../../../topview/assets/source/act1)
- **물과 숲 아래의 깊이**에 계곡 원경 판화와 낙수 턱·포말·목재결·부러진 장선 4종을 더했다. 전장당 고정 바닥·수변·교량과 다리 아래 그림자를 타일로 굽고, 물결·낙수·배우·전경은 게임에서 합성한다. [지형 저작](../../../topview/editable/act1/fields.py) · [베이크](../../../topview/tools/bake-campaign.py)
- **배우**는 담허·휘겸·소단의 자세별 방향 시트 3벌, 상두꾼·무녀·주민 남녀·들린 사람·조객·그림자·등불·장승·나루장승·교각귀·빈 상여 12종을 추가했다. 설오와 동물, 기존 소나무·바위·석등·수레는 1장의 원화를 이어 썼다. 동행은 서로 다른 대기·보행·시전 그림을 쓴다. 일부 주민과 원혼은 한 실루엣에 방향 반전과 자세 변형을 쓴다. [배우 등록](../../../topview/src/actors.mjs) · [제작 도구](../../../topview/tools/pack-campaign-art.py)
- 플레이 동작은 `topview/src`, 원본 캠페인과 맞닿는 사건은 `shared/runtime`, 아홉 장 지도는 `topview/data`, 정적 전달본은 `topview/generated`와 `topview/assets/terrain/act1-*`에 있다. [전체 파일 목록](evidence/act1-campaign/changed-files.tsv) · [원본 대응·제작 백로그](ACT1_CAMPAIGN.md) · [갱신한 제작 SOP](PRODUCTION_SOP.md)

## 재현

아래 명령은 저장소 루트와 별도 테스트 프로필을 사용한다. 먼저 `npm run build` 후 `python -m http.server 8000`으로 실행한다. `CHROMIUM` 환경변수로 테스트 브라우저 실행 파일을 고를 수 있다. 정상 체크포인트에는 1장 승리와 2장 입장 상태가 들어있다.

```sh
node --test topview/tests/*.test.mjs
python topview/tests/play_chapter.py --base http://localhost:8000/ --out /tmp/honro-first --save-checkpoint /tmp/honro-2.json
python topview/tests/simulate_campaign.py --base http://localhost:8000/ --checkpoint /tmp/honro-2.json --out /tmp/honro-campaign
python topview/tests/simulate_campaign.py --clear-courtyard --base http://localhost:8000/ --checkpoint /tmp/honro-campaign/chapter-8.json --out /tmp/honro-bier
python topview/tests/campaign_field.py --base http://localhost:8000/ --out /tmp/honro-input
python topview/tests/campaign_field.py --base http://localhost:8000/HONRO.html --mobile --out /tmp/honro-input
python topview/tests/campaign_field.py --base http://localhost:8000/ --missions --out /tmp/honro-gates
python topview/tests/campaign_field.py --base http://localhost:8000/ --art --out /tmp/honro-cameras
python topview/tests/campaign_field.py --base http://localhost:8000/ --frames --chapters 5 8 --out /tmp/honro-frames
```

77개 장별 상태 검사는 필수 접근, 목표·실패·원본 승리, 다음 장이나 기존 막 엔딩으로의 전환을 다뤘다. 2~8장은 쉼터·다음 장, 9장은 10장 직접 전환이다. 원본 엔딩의 이미지 ID는 `act1-release`, `act1-2`, `act1-3`이다. [개별 판정](evidence/act1-campaign/verification.json)

5장 폭포와 8장 상여를 단독 Chromium 창 1,180×700에서 각각 150프레임 관측했다. 기본 배율 1.70과 가장 넓은 1.19에서 네 표본 모두 프레임 간격 중앙값 16.7ms, 95백분위 16.8ms였다. 이는 조준 중의 화면 표본이며 여러 투사체의 동시 피격이나 휴대전화 성능 측정은 별도다. 독립 배포 복사본은 1,084개 파일, 114.9MiB로 패키징했다. 플레이 중에는 해당 장·인접 타일을 필요할 때 읽는다.

## 남은 품질 범위와 피드백

요청한 아홉 장 가운데 미착수인 장은 없다. 사람의 실제 터치로 열 장을 연속 공략하는 출시 전 검수, 여러 숙련도·난이도·휴대전화의 체감 비교는 남았다. 첫 사용자 피드백은 **5장에서 담허의 진에서 설오의 사격점으로 눈이 자연스럽게 가는지**, **8장에서 하강로를 막은 배우를 알아보는지**, **10장에서 세 영웅과 소단의 대피 속도 차이가 납득되는지** 순으로 받는 것이 좋다. 그 결과에 따라 목표 안내와 지역 구도를 먼저 손볼 수 있다. 원본 복구 기준과 프로필 분리는 [포크 계약](FORK_CONTRACT.md)에 기록했다.
