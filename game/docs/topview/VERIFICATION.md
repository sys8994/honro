## 재현

[제작 SOP](PRODUCTION_SOP.md)의 명령으로 새 빈 폴더를 패키징해 HTTP로 제공한다. Python Playwright와 Chromium이 필요하다. 기본 Chromium 경로는 `/usr/bin/chromium`이며 `CHROMIUM` 환경변수로 바꿀 수 있다.

```sh
python3 topview/tests/play_chapter.py --base http://127.0.0.1:8000/ --out /tmp/yeonmok-pc
python3 topview/tests/play_chapter.py --mobile --base http://127.0.0.1:8000/ --out /tmp/yeonmok-touch
python3 topview/tests/play_chapter.py --mobile --viewport 390x844 --base http://127.0.0.1:8000/ --out /tmp/yeonmok-portrait
python3 topview/tests/play_defeat.py --base http://127.0.0.1:8000/ --out /tmp/yeonmok-loss
python3 topview/tests/check_field.py --base http://127.0.0.1:8000/ --out /tmp/yeonmok-field
python3 topview/tests/check_field.py --base http://127.0.0.1:8000/ --edited-map /tmp/edited-yeonmok.json --out /tmp/yeonmok-edited
python3 topview/tests/sample_render.py --base http://127.0.0.1:8000/ --out /tmp/yeonmok-render
```

**제작 중 해결한 오류.** 원본 이벤트가 드러내는 나무꾼을 렌더러가 찾지 못해 배우 이미지와 현장 좌표를 연결했다. 원본의 일반 인구 한도 8은 기존 시작 적 12기보다 작아 수레 증원이 등장하지 못했다. 이 장의 실제 초기 편성과 일회성 증원 수로 한도 16을 계산한다. 적 행동 수 제한은 원래 규칙을 따른다. 터치 자동화의 초기 버튼 대기 4.5초는 동시 실행 중 이미 도입 대사가 열렸는데도 시간 초과를 냈다. 앱의 이동·사격·시간 규칙을 그대로 두고 입력 검수기의 기다림만 18초로 조정해 같은 처음부터 다시 실행했다.
