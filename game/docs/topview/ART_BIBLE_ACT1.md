적용 대상은 탑뷰 1막 1장의 일반 전장과 같은 배우를 쓰는 동작 보기다. 이 판의 기준선은 `3472c70448ffff42f113d26e22b933af6d4430a0`이다. 제작 순서는 전장 촬영, 치수 확정, 기준선 실측 대조, 제작, 같은 시점 재촬영으로 고정한다. 아래 미터는 이 게임의 연출 설계값이다.

## 한 대의 카메라

평행투영 카메라를 지면 위 30°에 두고 수평축을 지도의 두 건축축에 대해 각각 45° 돌린다. 오른쪽 아래와 왼쪽 아래로 향하는 지면축의 화면 기울기는 +½, −½이다. 수직선은 화면 수직이고 뒤쪽 기둥도 앞쪽 기둥과 같은 길이다. 지면의 정사각형은 폭 대 높이 2:1 마름모, 수원과 외곽을 담는 화면 영역은 직사각형이다.

줌 1의 기준은 옆으로 펼친 지면 1m당 40 지도 픽셀이다. 건축 좌표 (X,Y,Z)m를 `x=28.284(X−Y), y=14.142(X+Y)−34.641Z`로 투영한다. 원형 발판의 단축은 장축의 ½이다. Tiled 바닥은 96×48 마름모다. 전투 저장에 쓰는 180단위 섹터와 래스터 주소 64×44는 이 마름모와 별개의 주소계다. 기존 주소는 바닥 위에 그대로 대응시키고, 새 미술의 높이·깊이는 위 미터 변환으로 정한다. 실제 CSS 픽셀은 지도 픽셀에 카메라 줌을 곱한다. 기본 줌 1.70에서 0.70~1.50배를 허용한다. 화면보다 작은 지도 가장자리에서는 빈 공간이 나오지 않는 최소 배율을 적용한다.

## 빛·접지·전투 가독성

- 해는 화면 좌상단이다. 윗면은 따뜻한 회황색, 멀어지는 면은 회녹색, 발밑은 찬 먹색으로 통일한다. 투영된 그림자는 오른쪽 아래로 떨어지며 수직 높이 1px당 약 (+0.46,+0.23)px가 기준이다. 지붕 아래와 처마 받침은 더 어둡다. 시간대 그레이딩은 전장의 공통 마지막 단계다.
- 8비트 sRGB 밝기 Y′는 0.2126R+0.7152G+0.0722B로 잰다. 시간대 적용 전의 외곽 수관은 95백분위 Y′≤119, 장식 채널 차 p95≤55, 바닥의 질감 밝기 p95≤148을 쓴다. 유닛에는 작은 밝은 얼굴·어깨 또는 갈기와 어두운 핵심 윤곽을 남긴다. 실전에서는 몸의 안쪽과 바로 바깥 2~5픽셀 띠를 비교해 윤곽 표본의 중간 국소 명도차 16 이상을 목표로 한다. 풀과 털이 같은 계열이어도 실루엣이 읽혀야 한다.
- 인간의 앵커는 가까운 발의 접지선과 양발 사이 중심, 네발짐승은 가까운 발들의 지지선이다. 그림자 중심은 그 중심의 2px 이내다. 접지 AO는 사람 반경 7~10×2~4px, 땅짐승은 몸길이를 따라 길게, 부유체는 좀 더 넓고 옅게 둔다. 지면 표식은 발·목적지의 지면 좌표를 사용한다. 전장 피격 원은 그리지 않는다. 지붕·수관과 겹친 실루엣만 가림 윤곽을 받는다.
- 최저 줌에서 설오의 키 ≥65 CSS px, 날개폭 ≥38 CSS px가 목표다. 적을 가리키면 같은 몸의 실제 알파를 따라 밝은 윤곽을 표시한다. 표시는 캐릭터·적·통로/엄폐·장식 순으로 주의를 끌어야 한다. 기본 구도에서 수관이 설오의 얼굴을 덮지 않아야 한다.
- 길은 이어지는 다져진 흙·작은 바퀴 자국, 풀은 짧고 낮은 녹색 덩어리, 바위는 단단한 윗면, 물은 짙은 청록과 얕은 둔덕으로 읽는다. 강물 위를 가로지르는 길은 교량의 상판에서만 연결한다. 다리 양쪽은 다져진 진입로와 받침돌을 갖는다.
- 대기 목표는 가까운 신발 고정, 설오 정수리의 전체 진폭 ≤1 지도 px, 어깨·팔의 상대 이동 약 0.3~1.1px다. 산개의 기존 가슴 호흡은 비교 기준이다. 조류는 날개가 몸통과 독립해 움직인다. 감소된 모션 설정에서는 지정한 중립 프레임을 유지한다.

## 다음 장의 제작 순서

1. 일반 진입점으로 전장에 들어가 인물·양쪽 교두보·숲·문을 같은 뷰포트와 줌으로 촬영한다. 편집기의 장식 목록, 사건으로 나오는 배우, 실제 칠해진 픽셀과 충돌 원천을 대조한다.
2. 위 표에서 그룹별 치수와 기준점을 고른다. 다른 시대·체급이면 새로운 행에 미터와 변경 사유를 먼저 쓴다. 새 그림의 요청에는 정사영, 좌상단 광원, 표면 상한, 발·문·차축·상판 기준점을 함께 넣는다.
3. 차이가 큰 문·교량은 치수대로 원형을 제작하고 나머지는 기준 표시 크기에 등록한다. 불투명 영역을 재고 얼굴·발·활 손을 확대 검토한다. 방위별로 제각각 축소해 실루엣을 통과시키지 않는다.
4. 실제 엔진의 전경 가림·그림자·시간대까지 합성해 기본/최소 배율, PC와 터치에서 재촬영한다. 배우를 추가로 모아 찍은 치수 검사용 장면과 일반 플레이를 구분한다.
5. 기준선·수정값·판정·잔여 한계, 재현 명령, 같은 카메라 전후 그림을 남긴다. 대사, 입장, 발점, 조준, 피격과 일반 저장 경로는 영향받은 범위에서 확인한다.
