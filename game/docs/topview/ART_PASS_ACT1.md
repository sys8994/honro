## 조작과 실제 확인 범위

- Shift 방향키 회전은 초당 약 160°에서 39.6°로 줄었다. 0.1초 동안 약 4° 돌아가고, 키를 누르는 동안 발점과 이동력이 유지된다. Shift 클릭은 겨눈 지점으로 바로 향한다. 60Hz와 120Hz 계산을 비교했다.
- 기본 카메라에서 허용한 줌은 0.70~1.50배다. PC 휠과 터치 핀치로 실제 1.19~2.55 범위에 닿았다. 3개 화면 크기, 2개 줌, 8개 방향에서 화면 가장자리를 확인했다. 이전보다 줌아웃 시 전장이 덜 넓게 보이도록 기본값을 1.40에서 1.70으로 정했다. [터치·카메라 측정](evidence/art-bible/field.json)
- PC에서 전장을 끌면 화면이 고정되고, 창의 네 가장자리에 마우스를 두거나 미니맵을 클릭·드래그하면 카메라가 움직인다. 들린 산개의 몸 위에 윤곽이 나타나고 클릭하면 원래의 정보 창이 열렸다. 설오를 클릭하면 선택됐다. 나무꾼의 사건 뒤에는 그 곁의 빈 땅을 눌러 이동했다. [마우스 검사](evidence/art-bible/pointer.json) · [원래 몬스터 정보 창](evidence/art-bible/monster-inspection.jpg)
- 1180px 화면에서 발사는 88px, 이동 잠금과 방어는 각각 42px다. 844px에서는 74/36, 390·320px에서는 64/32다. 각 버튼 중앙이 자기 입력을 받으며 기예와 포각 표기가 겹치지 않았다. [발사·이동 잠금·방어](evidence/art-bible/action-buttons.png)
- 일반 보행으로 소나무와 사당의 뒤·아래·앞을 통과했다. 산개의 검증된 호흡을 유지했고, 설오의 대기에서는 머리와 밑창이 같은 높이에 남았다. [가림 측정](evidence/art-bible/occlusion.json) · [설오 발 복원 기록](VERIFICATION.md#설오의-발과-대기-호흡)
- PC와 터치 Chromium에서 원래 오프닝·쉼터로 들어가 활의 예측과 실탄 명중을 대조하고, 일반 이어하기와 수레·증원·나무꾼·능선 사건, 6라운드 도착, 정산·타이틀·야영지를 확인했다. 이전 저장 이름에 넣은 격리 표식도 두 경로에서 보존됐다. 모바일 결과는 브라우저의 터치 에뮬레이션이다. 실물 기기의 프레임 속도와 테스트 밖의 화면비는 미측정이다. [PC 기록](evidence/art-bible/desktop.json) · [터치 기록](evidence/art-bible/touch.json)

공개 Pages는 구현 커밋의 시트, 지도, 핵심 렌더러, HTML과 네이티브 모듈의 바이트가 일치한 뒤 루트와 `HONRO.html`에서 각각 1장 진입과 보행을 확인했다. [공개판 확인](https://github.com/sys8994/honro/actions/runs/46154250951)

## 재현

저장소 루트에서 의존성을 설치한 뒤 제작한다. Blender는 구조물 재제작 시에만 필요하다. 아래 브라우저 명령에는 Playwright와 Chromium이 필요하다.

```sh
python -m pip install -r topview/tools/requirements.txt
blender -b -t 3 --python-exit-code 1 -P topview/tools/render-structures.py
python topview/tools/pack-poses.py
python topview/tools/compile-map.py
npm run build
node --test topview/tests/*.test.mjs
python -m http.server 8000
```

```sh
python topview/tests/check_art.py --base http://localhost:8000/ --out /tmp/yeonmok-art --views
python topview/tests/check_pointer.py --base http://localhost:8000/ --out /tmp/yeonmok-pointer
python topview/tests/check_field.py --base http://localhost:8000/ --out /tmp/yeonmok-field
python topview/tests/check_overhang.py --base http://localhost:8000/ --out /tmp/yeonmok-depth
python topview/tests/play_chapter.py --base http://localhost:8000/ --out /tmp/yeonmok-play
python topview/tests/play_chapter.py --base http://localhost:8000/HONRO.html --mobile --out /tmp/yeonmok-play
```

기준판 비교는 `3472c704`를 다른 포트로 열고 `check_art.py`에 그 주소와 `--original --views`를 준다. 화면 검수에서는 수정한 지도에 생성물과 일반 게임 진입점이 함께 있는지 먼저 확인한다.
