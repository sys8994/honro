# 연목 고갯길의 석교와 데스크톱 조작

일반 저장에서 5턴 석교 위의 설오와 같은 편성(배우 총 17명)을 불러왔다. 화면은 1920×936, 카메라는 지도 (918, 766), 줌은 2.55다. [수정 전](evidence/bridge-render/before-bridge.webp) · [수정 후](evidence/bridge-render/after-bridge.webp) · [실행 중인 강물과 그림자](evidence/bridge-render/current.webp)

| 조건 | 기존판 평균 프레임 간격 | 수정판 평균 프레임 간격 |
| --- | ---: | ---: |
| 정지 | 24.4 ms | 17.3 ms |
| 석교 주변 일정 경로 카메라 이동 | 26.5 ms | 18.7 ms |
| 실제 버튼으로 활 충전 | 29.2 ms | 19.6 ms |

Linux 헤드리스 Chromium 한 탭에서 각 판 두 번, 정지와 패닝 각 100프레임, 충전 60프레임씩 측정했다. 새 판 정지 p95는 두 번 모두 16.8 ms, 패닝은 16.8·33.4 ms, 충전은 두 번 모두 33.4 ms다. 별도 125% 배율에서는 같은 260프레임 동안 기존 미니맵이 너비·높이를 각각 78회 재할당했고 새 판은 0회였다. 개별 사용자 PC와 휴대전화 실기기 FPS는 미측정이다. [시행별 값과 경로 좌표](evidence/bridge-render/samples.json)

- **조작** 왼쪽 드래그와 미니맵 드래그는 카메라를 옮긴다. 오른쪽 클릭은 보행, 짧은 왼쪽 클릭은 적 정보·동행 선택, Shift+왼쪽 클릭은 제자리 조준이다. 화면 가장자리에 마우스를 세워도 카메라는 고정된다. 터치 스틱, 탭 보행, 두 손가락 핀치와 이동 잠금을 유지한다.
- **그림자** 두 다리·지형 소품 83개의 투영과 접지 음영을 정적 타일에 저장했다. 설오·몬스터는 그 위에 실시간 그림자를 드리운다. 같은 프레임 조건에서 특정 배우의 그림자만 껐을 때 발점 주변 픽셀이 설오 54%, 가까운 멧돼지 94% 달라졌다. 수관과 처마의 앞뒤 가림은 별도로 보행 검수했다.
- **물결** 기존 강물 표본에서는 약 0.5초 사이 RGB 한 채널이 5 이상 바뀐 픽셀이 0.23%였다. 새 판에서 84.69%가 바뀌었고 같은 시각 마른 땅과 다리 상판의 대조 영역은 0%였다. 움직임 줄이기를 켜면 세 영역이 모두 0%였다.
- **확대** 원본 이미지에서 지도 지면을 2.5배 밀도로 구웠다. 건물과 두 교량은 같은 치수·카메라에서 3배 밀도로 다시 렌더링했다. 설오는 기존 원화를 더 높은 해상도로 그리며, 동물 자세는 144×128에서 216×192 셀로 다시 추출했다. 실제 원화의 작은 세부가 최종 확대의 한계다.
- **비용** 지형과 물을 브라우저 합성층에 보존하고 가림 윤곽을 재사용한다. 정적 지형의 같은 반경에서 걸을 수 있는 칸 사이의 충돌 결과는 재사용하되, 시작점·목표·경로 단축은 매번 실제 지형에 검사한다. 기록한 다섯 쌍의 경로에서 모든 중간 지점이 기존과 일치했다.

재현할 때는 타이틀로 들어가 석교 중앙(지도 928, 792)으로 이동하고 방어로 5턴까지 진행한다. 같은 일반 저장을 두 빌드의 격리된 브라우저에서 열어 비교한다. 픽셀 측정은 화면 x=845~1069, y=93~219의 강과, 오른쪽의 마른 땅, 상판 중간을 사용했다.

```sh
npm run build
node --test topview/tests/*.test.mjs
python topview/tests/check_pointer.py --base http://localhost:18835/ --out /tmp/honro-pointer
python topview/tests/check_field.py --base http://localhost:18835/ --out /tmp/honro-touch
python topview/tests/play_chapter.py --base http://localhost:18835/ --out /tmp/honro-chapter
```
