# 혼로 초상 변형 시스템 v1

2026-10-23. 사용자 요청: 현재 모든 캐릭터 대사에 의도한 초상 종류를 명시하고, 이미지는 점진적으로 확장한다. 기획/이미지/대사 판정은 부모가 담당하고 Codex는 최소 구현·검사만 한다.

## 단일 데이터 계약
- 현재 튜플 [화자, 텍스트, metadata]와 rowId를 보존한다. metadata.portraitExpression 하나만 사용한다. 두 번째 portraitType/mood/pose 선택 필드를 추가하지 않는다.
- 값은 base, emotion.*, action.*, scene.*. 분류·한국어 이름·시각적 설명·사용 조건은 변형 카탈로그에 둔다. 감정×포즈 모든 조합을 생성하지 않는다.
- 대본의 의도와 제작된 에셋 목록을 분리한다. 알려진 미제작 변형은 정상이며 해당 인물 base로 표시하고 미제작 보고서에 남긴다. 모르는 ID/오타는 새 공식 대본 검사를 실패시킨다.
- 인물 해석은 현재 행/장면/배우 매핑을 그대로 사용한다. 공용 주민 템플릿 재사용은 동일인 설정이 아니다. 다른 인물·동일 클래스의 얼굴을 추정하여 대체하지 않는다.
- 서술/기록/안내/정체 미공개 얼굴 없는 장면은 제외 사유를 명시하고 기존 숨김 정책을 보존한다. 소단의 적대/동료 시기와 의상·소품·부상 선공개를 금한다.
- 고정723행 외에 구조 주민/활성 영웅 동적 대사를 포함한다. 실제 화자 치환 후에도 종류와 정체가 보존되어야 한다.
- 저장/불러오기·사용자 제작 데이터에 필드가 없으면 base로 정규화한다. 옛 저장 대사/큐/커서/행 ID를 덮어쓰지 않는다. 새 공식 데이터에는 생략을 허용하지 않는다.

## 에셋 및 제작량
- 주연 각8종 전후: 기본1, 표정4, 행동2, 중요 장면1. 실제 대사 수요로 조정하며 인물마다 똑같은 감정 세트를 강제하지 않는다.
- 주요 NPC3종, 일반 주민 템플릿2종, 종지기3종 출발. 한 줄 단역은 기본1로 충분하면 늘리지 않는다. 비인간 무대 오브젝트에 불필요한 사람 얼굴을 만들지 않는다.
- 신규 종류는 카탈로그 등록→대사 지정→미제작 집계→원본 독립 생성→3회 집중 미술검수+종합→런타임 파일 등록→실제 대화 검수 순서다.
- 이미지별 identityMaster/source SHA/상태/가용 장면/framing/한국어 설명을 기록한다. 기본 승인 이미지를 정체 참조로 하며 변형에서 다음 변형을 반복 편집하지 않는다.
- 눈·머리 크기, 복장, 화풍, 얼굴/옷 묘사 밀도를 유지한다. 모공·직물결·미세 노이즈 금지. 캐릭터의 평범함과 개성을 유지한다.
- 기본은 단일 완성 투명 이미지. 얼굴·몸 분리 런타임 합성은 이번 범위 아님. 새 이미지를 등록하면 대사 코드 수정 없이 해당 태그에 연결된다.

## 선택·오류·성능
- 정확한 변형→동일 인물 승인 base→해당 인물의 기존 명시적 얼굴 없음 처리. 이번 시스템에 구 벡터 초상 대체 경로를 새로 넣지 않는다. 기존 주인공 네트워크 실패 벡터 경로도 변형 이미지 경로에서는 기본 이미지/중립 상태로 통일한다. 세계 속 벡터 캐릭터는 그대로다.
- 미제작과 네트워크 실패를 구분한다. 등록되지 않은 이미지 URL을 추측하며404를 만들지 않는다. 실패는 유한 재시도, 대사/다음 버튼은 비차단. 다른 인물의 이전 얼굴이 남으면 실패다.
- 초기 타이틀에서 전체 변형 요청 금지. 현재 장면/다음 몇 행만 비동기 준비, 이미 요청한 URL+revision을 재사용한다. 동일 이미지/크롭이면 다시 그리지 않는다. 변형 변경은 이미지 완료 후 교체하되 발화자 변경이면 이전 얼굴 즉시 제거한다.
- 배포용 후보 512×768/768×1152 WebP를 실제 대화 크기로 비교하여 선정한다. 원본 PNG는 제작용으로 보존하되 초기 배포 다운로드 대상이 아니다. 화질/용량은 측정 전 보장하지 않는다.
- 디코딩 캐시 개수뿐 아니라 예상 RGBA bytes로 제한하고 최근 사용/현재 화면/다음 대사 보호를 명확히 한다. 초기 제안 모바일16MiB/큰 화면32MiB, 브라우저 전체 메모리 상한 보장이 아니다. 기존 로더를 확장하고 새 병렬 로더를 만들지 않는다.
