# 3막 한국 읍성·포구 미술 기준

## 의도와 범위

사용자는 3막의 건축과 도시가 한국의 옛 건축·도시 풍경으로 읽히도록 공식 레퍼런스를 검색해 반영하라고 요청했다. 한두 지붕 끝을 고치는 대신 민가·관아·사고·성문·수문이 서로 다른 규모와 구조를 갖도록 한다. 조선의 특정 연도나 실제 도시를 그대로 재현하는 프로젝트는 아니며, 확인한 건축 어휘를 혼로의 한국 판타지에 맞게 재구성한다.

곡선 처마·기와·격자창은 여러 동아시아 건축에서 공유한다. 그것만으로 국적을 판단하지 않는다. 이번 작업의 기준은 한국의 특정 유산 사진에 실제로 보이는 건물 비례, 칸 구성, 지붕 종류의 위계, 석축·담장·마당과 건물의 관계다. 공식 사진은 참고 열람에만 사용하고 게임 에셋이나 결과물에 복제·트레이싱·삽입하지 않는다. 새 그림은 편집 가능한 원본 코드/SVG다.

## 새 벡터 모듈

`tools/environment/korean-town-art.mjs`는 기존 `hall`과 독립된 새 제작 모듈이다. 현재는 새 한국식 민가/가게/관아/서고/창고/단층 누각과 낮은 담장·대문의 원본 벡터를 제공한다. 길게 잡힌 용마루와 수직 방향 기와 골, 억제된 처마선, 작은 칸 단위 창호, 중앙 마루, 흙벽·자연석 기단, 낮은 초가를 유형별로 나눈다. 기존 바둑판 같은 지붕 가로띠는 사용하지 않는다.

지붕 그림과 제안 지붕 고체는 같은 샘플 윤곽에서 생성한다. 아직 미승인 맵에 몰래 적용하거나 기존 높은 지붕 고체를 남긴 채 낮은 그림만 입히지 않는다. 전경 건물의 실제 높이/지붕 변경은 해당 동선·탄도와 함께 검수한다. 비충돌 후경은 뿌리를 보이는 담·마당/강둑 지지면에 붙인다.

## 변경·검수 순서

1. 대표 21·22·23장에서 민가 저층 / 관아 석축 / 사고 누형의 위계를 먼저 확인한다.
2. 필수 길·호송·목표 위치는 우선 보존한다. 필요한 선택 지붕길의 높이·접근 계단 변경은 목록과 이유를 남긴다.
3. 변경한 collision과 그림의 일치, 4인 필수/선택 길, 탄도, 물과 목표 접지를 다시 검사한다.
4. 같은 카메라 전후 및 400px 화면에서 사람이 먼저 읽히는지, 과대 기둥/공중 건물/가짜 보행층이 남지 않았는지 확인한다.
5. 부모의 최종 화면 리뷰가 끝나기 전에는 3막을 master/Pages에 활성화하지 않는다.

## 대표 지도의 공간 계약

`tools/map-forge/apply-korean-town-review.mjs`는 정본을 읽고 검토용 복제본만 출력한다. 공유 `HonroMaps.finalize`를 마지막에 적용한다. 1–20장의 객체, 24–30장, 21–23장의 필수 길·지형 원본·물·목표·마커를 비교해 보존한다. 실제 요소 지붕은 미술 윤곽과 함께 바뀌므로, 생성된 `collision-change-list.json`에 요소 변경 사유와 compiled collider의 이전/이후 world vertices를 별도로 기록한다.

- 21: 낮은 장터와 관아 익랑 사이에 높은 석축 성문을 두고 기존 성벽 오름길과 y=1960 보행면을 유지한다. 문루는 단층이다. 낮아진 지붕과 성벽 계단이 겹치지 않게 진입부 민가를 물린다.
- 22: 실제 세 보관층은 유지한다. 판문 아래·작은 창 위의 칸 구성과 수평 책갑/궤로 바꾼다. 과도하게 솟았던 두 지붕만 낮추며, 세 층 규모는 역사 복원이 아닌 게임 내 판타지 확장이다.
- 23: 기존 필수 부두·수문·호송길을 유지한다. 과거의 빈 상층 누각과 연결되지 않는 계단을 걷어낸다. 단층 수문 누각은 기존 석교 상판에 놓이고, 짧은 지붕 보수길 받침은 실제 아래 지붕/교량에 접지한다. 실제 상층 놀이는 한 곳의 누형 관창에 모은다. 세 보관층은 y=2730/2470/2210이며, 260 간격을 두 실제 계단으로 연결한다. 관창 옆은 무리하게 집을 끼우지 않고 하역 마당으로 비운다.

열린 관창 계단·회랑은 기존 명시 의미인 `oneWay=true`를 사용한다. 건물 지붕도 아래에서 통과하고 위에 착지하는 `oneWay=true` 발판이다. 검토한 ID만 적용하며 실제 닫힌 지면·천장은 고체로 유지한다. 별도 추정 기반 collision role은 도입하지 않는다.

## 검토 증거의 범위

`HONRO_PROJECT_FILE`을 지정하면 공간·물/스폰·탄도 검사를 정본을 덮어쓰지 않고 같은 검토 후보에 실행할 수 있다. `capture-act3-production.mjs --game-follow`는 같은 수동 landmark 카메라와 함께 실제 App 초기 배율 및 Scene follow 구도의 400px/가로 화면을 기록한다. 카메라만 따라가며 전투 상태가 바뀌지 않는지 검사한다. Native Canvas 장면은 실제 공통 엔진/렌더러 출력이지만 브라우저 HUD 입력·정상 전투 완료·실측 성능 증거는 아니다.

첫 배치 검사에서는 관창 상층 4인 경로, 22장 전체 경로, 21장 필수 길과 21–23장 탄도가 통과했다. 동시에 낮은 처마가 기존 경사로의 머리 공간을 침범하는 문제가 검출됐다. 관련 건물 폭/위치와 지붕 계단 시작점을 수정하고 재검사하며, 최초 실패를 최종 통과로 간주하지 않는다.

### 대표 3장 집중 검사 결과 (2026-10-07 03:05 UTC)

검토 소스 `1f461fb`의 21–23장 필수/선택 경로 28건은 실제 엔진의 4인 보행·기본 점프로 모두 0피해 통과했다. 23장 운반인은 walk-only로 0피해 통과했다. 물/스폰/재시도 35검사, 목표/일반 차선의 실제 화살과 처마 차단 9검사, 수문과 짧은 받침/관창 바닥 접점 검사가 통과했다. 최초 실패한 경사로 머리 간섭은 건물 폭·위치를 정리하고, 아래가 열린 새 목재 접근 계단을 명시 `oneWay=true`로 저작해 해결했다. 기존 필수 석교·경사로 자체는 변경하지 않았다.

같은 소스의 실제 Native 10뷰에서 전투 상태 불변을 확인했다. 지도 SHA256은 `fcb5b4f64d30a4330f9b42b880b0030673d78c3f299fa7c3a7fd9812961d0759`, 런타임 묶음은 `c233e09cd0b6f6e2a685f68d0ec3db2935fc958bee093558a24db472dd948079`다. 이전/이후 compiled collider 변경은 21장 12개, 22장 4개, 23장 29개이며 좌표 목록을 생성 보고서에 보관했다. 이후 입구의 별도 구형 서가 두 종류도 수평 포갑으로 통일하는 비충돌 미술 수정을 추가했다.

부모의 대표 화면 리뷰 후에만 최신 통합 정본을 입력으로 연결한다. 24–30장의 한국 건축 어휘 확장과 통합 브라우저/전투 검수는 별도 진행 중이며, 이 결과를 전체 3막 완료로 해석하지 않는다.
