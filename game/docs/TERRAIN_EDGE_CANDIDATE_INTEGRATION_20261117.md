# 기존 지형 외곽 후보 통합 검증

기준 master7d238d20, 통합 base af1c7364. 기존3/7/12/14/15 후보 위에2/4/5/6/8/9/10 수정과11검사·기록을 선별 통합한다. 신규 장의 그림을 바꾸는 단계가 아니다. 실행 소스/검사48개를 원격 후보blob SHA와 대조해 일치시킨다. 이전 브랜치의 생성 HTML/web 파일은 통합하지 않고 공식 CI에서 새로 빌드한다.

## 충돌 처리

기존15장 상단원본무늬끝의 의도불명 항목은 그대로다. 전체 조사에서 새로 발견한21~40 결함과 기타미술검토 항목도 이통합으로해결되지않는다. 공개 Game·실기기·동적상태 미검수는유지한다. 통합브랜치는 master/Pages배포가 아니며 최종검수이전 공개반영하지않는다. 사용자저장과기존전투는접근하지않는다.

## 첫 통합 CI와 기존 검사 가정의 구분
CI 44062241372에서 원본 48개 동일성, 범위·접합·수목, 최적화 등록, 공식 패키지 재생산은 통과했다. 기존 `act1-local-art-save.mjs`는 3장에 압축 table이 없다는 assertion에서 실패하여 빌드는 미실행이었다. 기준선 be99eb99와 현재 profile-store 및 해당 테스트는 byte 동일하며, 기준선 3/7장 `act1-site` 자산은 기존 codec에서 table이 아닌 inline 보존 대상이다. 기준선 자산을 두 번 배치한 독립 전투에서도 table 없음·동일 객체 반환·복원 성공이 재현된다. 저장 손상 회귀로 판정하지 않으며 기존 검사는 수정하지 않는다.

통합 CI는 새 `terrain-edge-save-roundtrip.mjs`로 실제 1~16장 전체의 입력 불변, JSON 직렬화 후 정확한 자산/전투 복원, provider 없는 복원, 기존 inline 복원을 검사한다. 3/7장에는 기존 codec대로 inline 보존을 명시적으로 확인한다. 이 검사는 로컬 통과했고 기존 Act2 codec의 13개 malformed 거부·독립 저장 모형도 통과했다. 실제 브라우저 저장 용량이나 사용자 저장 접근 검사는 아니다. 후속 CI와 공식 빌드 결과는 별도 확인한다.

### 기존 검출력 보존
`terrain-edge-act1-save-compat.mjs`는 기존 Act1 테스트 파일을 수정하지 않고 읽어, 정확히 한 table assertion만 3/7장의 현행 inline 조건으로 교체해 전체 나머지 코드를 실행한다. 치환 지점이 정확히 한 개가 아니면 실패한다. 다른 장의 table 필수 조건, 변형 자산·캐시, provider 독립성, 11개 malformed 원자적 거부, migration·export/import, 합성 quota·archive 보존 검사를 그대로 실행해 로컬 통과했다. 원래 파일 자체의 직접 실행 실패는 미해결 기존 테스트 가정으로 남으며 이를 전체 기존 suite 통과라고 부르지 않는다. CI는 별도 기준선 codec/발행 자산 재현도 실행한다. 이 조치는 생산 저장 codec을 변경하거나 사용자 저장을 읽지 않는다.
