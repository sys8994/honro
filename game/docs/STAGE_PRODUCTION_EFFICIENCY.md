## 이번 2막 1장의 빠른 수정

- 새 그림·미세 장식·새 보스를 추가하지 않고 이미 만든 아홉 에셋을 재사용한다.
- 선택한 BODY 접합과 흰 테두리 교정, 다섯 화면 노출용 foundation을 실제 package에 연결한다.
- 기본 새 진입은6200×3200, 초기17+필수 유한3 편성으로 연결한다. packer도 이 편성을 기본값으로 삼아 실수로24기 후보로 돌아가지 않게 한다.
- 원문·승패·네 동행 조건·기하를 그대로 두며 진행 중인 기존 전투는 유지한다. 중간보스 제안의 미구현을 구현 완료로 표시하지 않는다.
- 저장 경계/부분 로딩 확인, 필요한 두 HTML build, 상여 주변의 짧은 실제 UI 입력과 저장/Continue만 확인한다. 과거 모델/이동 근거는 적용 범위를 확인해 재사용한다.
- 전체 브라우저 완주·사람의 재미 평가·보편적 성공률을 이번 짧은 확인으로 새로 주장하지 않는다.

## 현재 명령

`npm run build`는 공통 Game·Workshop·Playtest 산출물을 생성한다. Stage31 자체의 검토/발행은 `npm run check:stage31-release` 또는 `npm run build:stage31-reviewed`를 명시적으로 사용한다. 검사 구현과 기존 결과를 삭제하거나 stale 결과의 hash만 갱신하지 않는다.

제작 기준의 단일 원문은 [장 제작 SOP](STAGE_PRODUCTION_SOP.md), [벡터 SOP](VECTOR_AUTHORING_SOP.md), [새 버전 SOP](HONRO_NEW_VERSION_SOP.md)다. 이 문서가 별도의 추가 gate나 체크리스트를 만들지는 않는다.
