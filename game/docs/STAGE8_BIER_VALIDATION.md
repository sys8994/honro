## v7 후보 수용과 남은 범위

2026-10-09 부모 검수에서 v6의 위 고지/가운데 포켓/아래 굴 관계를 수용했고 v7의 작은 봉인 막대, 상여집 규모와 통행 가독성을 확인했다. 큰 실루엣과 장식 확장은 여기서 마친다. 넓은 암면의 단순함과 하부 전후면 색 대비가 약한 점은 알려진 미술 한계로 남기며, 이후 미술 수정은 실제 플레이 카메라의 인물/통로 가림에 한정한다.

현재 후보는 경로·실탄 검수 뒤 정상 전투 검수 중이다. 영웅의 단차 이탈에 보스용 exact grounded 전신 직사각형 검사를 적용하면0.27px 발밑 전이나 지지면 교대도 막힘으로 기록되는 진단 한계가 나왔다. 원래 직사각형 결과를 숨기지 않고 머리/몸통 관통과 엔진의 합법 발 접촉을 분리해 판정하며, 실제 접촉 결함만 국소 교정한다. 일부 처마와 엄폐 모서리는 실제 머리/어깨 충돌이므로 수정 대상이다. 보스의 안전 이동 전신 검사는 완화하지 않는다. A02의 얇은 목재가 실제 암반에 겹쳐 관통 이득이 사라진 사선 결함도 국소 배치 수정 후 다시 실탄 검사한다.
