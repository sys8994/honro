# 3막 지형 개편 후속 작업

기준: master `240ff6ebcdfe960b5a9363f4ffdbd28ae4bcf274`. 2026-10-17 사용자가 3막 전체 개선을 계속하도록 지시했다. 이전 10장 통합·배포는 제작 완료나 미술 승인과 다르다. 현재 제작 데이터를 공통 런타임으로 렌더링해 아래 개선점을 확인했다.

## 장별 수정 범위

- 1장: 장터·관아에 접근 가능한 짧은 지붕/처마 순환 경로. 건축물에 붙은 발판과 하중을 받치는 구조, 배수로와 지표 아래 큰 재질면.
- 2장: 기존 수직 경로 유지. 암산 위에 흩어진 작은 집 대신 층대를 받치는 석축과 연결된 기록고 건축의 깊이.
- 3장: 호송 저지대·지붕 경로 유지. 운하, 관창, 하역장의 장소감과 흙비탈/석축/목재 재질 구분.
- 4장: 종택·사당 접근과 분할 이벤트 유지. 지붕 우회로, 담장·정원·수경 공간과 건축물 기단 보강.
- 5장: 실제 축지 발사창과 경로 유지. 수문축·정비회랑의 중량감과 물때, 완만한 물길 이상 현상.
- 6장: 증언·귀환·두 동행 완료 조건 유지. 무너진 작업장과 피난처의 연결된 지형, 지상/상층의 짧은 선택 경로.
- 7장: 실제 이동/축지/설오 추락 씬 유지. 어긋난 회랑·반사·위로 휘는 물길로 비물리적 배면 공간을 크게 읽히게.
- 8장: 합류·문·증거 이벤트 유지. 관아 마당 양쪽의 짧은 처마 경로와 화재/방화수 공간 차별화.
- 9장: 상하 선택 경로 유지. 수문 석축, 정비 통로, 물가와 배면 강변의 깊이; 반복 벽돌 도식 축소.
- 10장: 호송·나루·상하 경로 유지. 실제 지표에 붙은 강변 암반·퇴적층, 선창과 배의 구조, 원거리 강변.

## 보존과 진행 방식

각 장을 별도 저작/확인/커밋 단위로 진행한다. 이미 개선한 플레이 구조를 불필요하게 다시 만들지 않는다. 지붕은 one-way 발판이다. 배경에는 충돌이나 선명한 가짜 발판 테두리를 추가하지 않는다. 실제 플레이 표면·캐릭터·조준선과 배경의 대비를 구분한다.

저장 스냅샷, 이벤트/목표/적 ID, 추가 적 편성, 두 동행 도착 조건을 보존한다. 변경된 동선만 일반 이동·점프·아래로 점프로 확인한다. 미술만 수정한 장은 게임플레이 데이터 보존과 결과 화면을 확인한다. 전체 verify나 무관한 스킬 검사는 실행하지 않는다.

공통 데이터와 생성물은 한 담당자가 통합한다. 원격 최신 변경을 보존하고 완성 단위마다 원격 브랜치에 저장한다. 실제 수정 화면을 장별로 전달하고 master/기존 Pages에 반영한다. 계획 작성·렌더 성공·배포 성공을 미술 승인으로 기록하지 않는다.
