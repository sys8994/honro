# 캐릭터 기준 환경 비율 교정
사용자 승인: 2026-10-19 12:58 UTC, 전체 스테이지와 휴식터.
현재 계획/원본 전달 단계. 구현 완료나 배포 완료가 아니다.

## 문제와 공통 규칙
단일 대표 그림 1774×887을 6000×3000으로 확대해 캐릭터 대비 모든 사물이 커졌다. 전체 맵 길이와 개별 사물 크기를 분리한다. 캐릭터 렌더 높이 H를 실제 코드에서 측정한다. 캐릭터·점프·사거리·충돌 크기는 유지한다. 일반 돌은 대체로 0.2–0.8H, 수풀은 0.3–1H, 보행 가능한 일반 문은 약 1.3–1.6H를 출발점으로 삼되 실제 미술과 기능에 맞춘다. 거대 절벽·묵종·주술 고목은 의도적 예외다. 이 값은 강제 일괄 배율이 아니다.

30개 장과 휴식터 모두 적용 대상으로 기록한다. 아직 교정된 장은 0개다. 1장부터 정상 게임 배율에서 캐릭터와 함께 확인하고 순차 적용한다. 기존 장의 폭·높이와 종횡비, 수직 전투 구도, 주요 사건·퀘스트·도착 조건을 추출하여 보존한다. 기존 벡터 모양을 그림의 레퍼런스로 사용하지 않는다.
2장은 높은 왼쪽 시작과 아래 상여차 길, 5장은 폭포 뒤 타깃과 접근 불가능한 호수, 10장은 의도적 대형 주술 고목을 지킨다. 휴식터는 건물 문/창·사람·모닥불·상호작용 거리부터 맞춘다.
원경은 독립, 근경에 맞닿는 나무는 원경처럼 흐리지 않는다. 단순 반복/반전 타일로 맵을 채우지 않는다. 새 지형 접촉선과 그림의 발 디딤점을 맞춘다. 적은 동일 개체수·밀도를 유지하면서 자연스러운 비등간격 배치, 지형 끼임 금지.

## 1장 첫 구현
시작 숲길 / 승인 balanced 고목 / 높은 출구의 세 고유 구간으로 약 6000 world를 구성한다. 각 구간 약 2200 world 및 작은 접합부를 검토하며 H 실측과 그림 접촉선에 따라 조정한다. 승인 balanced는 중간 한 번만 사용한다. source scale 3.38 배를 그대로 반복하지 않는다.
새 start/exit는 부모가 생성한 원본이며 아직 잔질감 보정 전이다. 생성 모델 입력은 각 prompt 파일에 그대로 저장한다. 코드 보정은 사용자 승인된 방식으로, 원본/alpha/주요 형태를 보존하며 별도 파일로 만든다.

## 보정 구현 지시
기존 승인 mild/balanced 방식: RGB 0..1, Gaussian sigma 2.2 가이드. alpha 유효 영역을 가중치로 사용한 joint bilateral, mild 반경 8 / 색 sigma .08 / 강도 .65. strong 반경 12 / 색 sigma .10 / 강도 .90. 넓은 명암 경계(gray Gaussian sigma 1.8 gradient .012–.047, 3px dilation 후 sigma .7)는 보호. balanced=.85*mild+.15*strong. 수관 녹색 근사 마스크 HSV H38–105(0..255), S>38, sigma3을 이용해 원본을 .35만큼 복원한다. 이는 의미 분할이 아닌 색상 근사이므로 나무 형태 훼손 여부를 눈으로 확인한다. alpha는 비트 단위 유지. 전체 블러/형태 단순화 금지. 기존 코드가 저장소에 있으면 재사용하며 없으면 이 동일 범위로 구현한다.
