# 21–30장 목표 기준 배치 교정

기준 master: `1fb64610be98f9d6b4e7c273d08fc64b80c9d886`. 장별 실제 목표·질문·참가 동행·보존 근거·확인 범위는 `review/shared-vector-campaign/stage-cards.json`의 21–30행이다. 오래된 content 문구보다 실제 컴파일된 `honroAct3Steps`와 장별 활성 컨트롤러를 우선했다.

기존 지형은 모두 필요한 연결을 이미 가지고 있어 재저작하지 않았다. 21장 장터 지붕, 22장 하층 계단, 23장 창고 지붕, 24장 정원 회랑, 25/27장 전망 복귀길, 26장 작업다락, 28장 동쪽 처마, 29장 상층 퇴로, 30장 나루 계단을 장마다 한 경로씩 격리 이동으로 확인했다. 25/27장은 첫 실제 M09 연결과 두 동행 도착을 추가 확인했다. 지형을 바꾸지 않았으므로 map revision·저장 재시작 정책은 변경하지 않았다.

초기 수는 21장부터 `26/30/40/26/15/18/15/20/27/40`, 정예는 `5/7/10/6/3/4/3/5/7/10`으로 유지했다. 종류·ID·원본 전력/XP 예산·유한 증원 정의·행동 상한도 보존했다. 등간격 전위와 반복 사격쌍을 비대칭 역할 간격으로 교정하고, 21장 장터 처마 및 23장 동쪽 경사, 24장 종택 충돌면에 겹친 등불귀를 열린 사격 공간으로 옮겼다. 다른 층을 보거나 기본 공격이 닿는 격리 명중은 정상 전투 완주나 모든 적의 접근 검증을 뜻하지 않는다.

25/26/27장 출구의 `allHeroes:true`, 실제 두 동행 팀과 도착 조건을 유지했다. 27장 추락 씬은 재생하지 않았으며 trigger·지형·컨트롤러를 그대로 보존했다. 23장 운반자 호송은 그대로다. 30장은 활성 데이터에 별도 호송 NPC가 없으며 기록 대조→3턴 나루 방어→생존 동행 전원 집결이 현재 목표다. 배의 점유 대기/내려앉기 컨트롤러는 변경하지 않았다.

원본 저작은 `act3-place-encounters-20261017.mjs`, `apply-stage22-vertical.mjs`, `stage23-density-roster.mjs`, `stage30-density-roster.mjs`가 소유한다. `authorPlaceEncounters(p,s)` 또는 `authorStage22PlaceEncounters(p,s)`는 지정 장만 적용하며, 23/30장은 `applyPlaceEncounters({library:p.library,stages:[s]})`로 지정 장만 복원할 수 있다. 부모 통합 시 전체 campaign 파일로 다른 장을 덮는 대신 현재 프로젝트에 이 저작 함수를 적용한다. 생성 HTML/배포 자산·master 통합은 부모 담당이다.

Native 캡처·격리 이동/실탄·초기 몸/비행 여유 결과는 `_local/reports/act3-stage-rework-20261020/stageNN/`에 둔다. 브라우저·정상 완주·전체 verify·별도 검수자·공개 배포는 미실행이다. 게임 AI·공통 미술 registry/runtime·휴식터·로더는 수정하지 않았다.
