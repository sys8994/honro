# 클리어 보고서 1차 기획

상태: 2026-10-22 사용자 요청에 대한 기획. 구현·통계 수집은 시작하지 않았다. 기준 master f37530094b3f83d33991162243b7a2722c8fd8f9.

## 화면

기존 클리어 모달의 보상을 유지하고 전투 시간 / 진행 턴 / 적 처치 / 아군 전투 불능을 2×2 요약으로 보여준다. 상세 보고서는 보조 버튼, 다음은 주버튼이다. 보고서를 읽지 않고 진행할 수 있다.

상세는 모바일 전면 패널: 장·난이도와 팀 합계 → 실제 참전 동행별 행 → 선택한 동행의 기예별 내역. 동행별 가한 피해·처치·받은 피해·유효 회복, 기예별 사용 횟수·피해·처치·회복을 제공한다. 동행 순서는 파티 순서를 기본으로 하며 MVP나 모호한 종합 기여 점수는 만들지 않는다. 지원 역할을 단순 피해로 서열화하지 않는다.

상세를 닫으면 클리어 모달로 돌아간다. 상세 열기/닫기는 다음 장 진행이나 보상 재지급을 호출하지 않는다. 장마다 최근 완료 보고서를 로컬에 보존하고 완료한 여정첩 장소에서 다시 볼 수 있도록 제안한다.

10/20/30장 첫 완료는 현재 일반 결과 모달을 건너뛰고 막 엔딩으로 들어간다. 승리 확정 때 보고서를 저장하되 기존 엔딩·다음 막 제목의 여운을 깨지 않도록 휴식터 도착 후 방금 장 보고서에 접근하는 안을 추천한다. 엔딩 흐름을 몰래 재설계하지 않는다.

## 집계 규칙

- 활성 전투의 실제 경과 시간. 입장/중간 대사, 설정·정지, 백그라운드, 로딩을 제외한다. 배속을 곱한 시뮬레이션 dt가 아니라 실제 시간을 사용한다.
- 진행 턴은 기존 round와 일치시킨다. 캐릭터 행동 횟수, 발사 횟수, 투사체 수, 피격 횟수는 서로 구분한다. 천뢰호 한 번으로 열 적을 맞혀도 사용 횟수는 한 번이다.
- 피해는 실제 감소한 HP만 집계하고 초과 피해를 제외한다. 보호막 흡수는 별도 필드이며 회복과 섞지 않는다.
- 회복은 실제 증가한 HP만 집계한다. 최대 HP 초과분과 성장·장 전환 HP 보정은 제외한다. 본인 회복은 포함한다.
- 처치는 적 개체의 최종 전투 불능 확정 한 번이다. 부활·불굴·단계 전환을 최종 처치로 오인하지 않는다. 목표물·소환물 파괴는 별도 분류한다.
- 지속 피해·설치물·소환 공격은 원래 동행과 기예를 보존해 귀속한다. 원본 기예가 없는 경로는 계측부터 보완하고 임의 추정하지 않는다.
- 환경 처치, 동맹 NPC, 아군 오사는 분리한다. 최대 피해 기여자에게 주는 XP 처치 규칙을 전투 기록에 그대로 재사용하지 않는다.
- 피해 분담/전이의 재귀 경로를 감사한다. 정상 다중 타격은 각각 집계하되 같은 HP 감소 이벤트가 이중 집계되지 않아야 한다.

## 시도·저장

Continue는 같은 시도, 전투 처음부터/명시적 재전투는 새 시도다. 이전 실패 시도의 수치를 성공 보고서에 섞지 않는다.

구간 재도전은 별도 예외다. 권장안은 최종 클리어 경로의 전투 수치를 체크포인트와 함께 되돌리면서 실제 활성 소요 시간과 구간 재도전 수를 유지하는 것이다. 이 범위를 보고서에 명시해야 하며 구현 전 계약을 고정한다.

3막 분할 조사에서는 각 장의 실제 참가자만 표시한다. 25/27장 설오·담허,26장 휘겸·소단,28장 전원은 현행V2 기준이다. 구V1 저장과 재전투를 구분한다. 불참 인물을 0점 행으로 추가하거나25~28의 XP 묶음 지급을 한 장 전투통계로 오인하지 않는다.

현재 전투에는 집계 누계를 저장하고 승리 시 불변 스냅샷으로 확정한다. 저장 부작용을 매 타격 localStorage 쓰기로 구현하지 않는다. 현재 자동저장 경로와 재접속을 사용한다. debug/허공터/사용자 맵은 일반 캠페인 기록과 분리한다.

옛 저장에는 없는 기록을 0으로 표시하지 않는다. 기록 없음 또는 부분 기록을 명시한다. 보고서에는 스키마/게임 버전, 장, 난이도, 시도 식별자를 보존해 이후 비교의 의미를 지킨다.

## 현재 구현과의 차이

heroes.damage/kills는 성장 누적값이다. contribution-xp는 상한·HP 진행도 최고치·중복 보상 제한이 있는 XP 장부다. b.events는 최근30개 문자열이므로 상세 통계를 복원할 수 없다. 별도 시도별 계측이 필요하다.

주요 확인 위치: shared/runtime/main.js의 outcome/Continue/defend, shared/engine/src/engine.ts의 hurt/recover, contribution.ts, shared/runtime/contribution-xp.js, progression.js, stake-crossing.js, split-campaign.js, act-endings.js.
