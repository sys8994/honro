# 6막 지형에서 정식 캠페인으로 옮기는 순서

## 완료한 좁은 검수

- 10개 장의 실제 지형, 전경, 시각·충돌 영역을 공통 컴파일러에서 처리했습니다. 독립 매니페스트 전체·지연 로딩 10/10은 같은 데이터의 두 경로를 대조한 값입니다. 정식 게임 메뉴에서 연속 입장했다는 뜻이 아닙니다.
- 엄격한 편집기 검증은 6/10입니다. 6-1·2는 일부 외곽 투영, 식별자, 자산 참조가 빠져 있습니다. 6-5·6은 원본 L0 벡터에 그러한 참조값이 없고 해당 편집기가 L0를 받지 않습니다. 레이어를 바꾸거나 가상의 참조를 넣지 않았습니다.
- 멀티 패킷 결합에서 고유한 이름이 아닌 자산 9종이 확인됐습니다. 1·2장, 7·8장, 9·10장의 현행 자산 18개가 해당합니다. 각 장에 귀속된 실제 내용이 다르므로 공유 본체로 중복 제거하면 안 됩니다.
- 6-6 패킷의 적 없는 시작에서 엔진 기본 규칙이 목표 미달을 승리로 처리하는 현상을 재현했습니다. 독립 시험에서만 가름진 가동, 실제 귀환, 출구가 모두 있을 때 완료되도록 수정했고, 신호가 없으면 끝에 도달해도 완료되지 않습니다.

## 지형 → 게임 패키지 계약

1. 같은 저작 버전의 편집 SVG, 렌더 메쉬, 플레이/전체 충돌, 앵커와 카메라 경계를 묶습니다. 보이는 장식을 충돌화하지 않습니다.
2. 실제 자산 전체(앵커/바운드/렌더/콜라이더) 해시가 일치하고 출처가 하나일 때만 공유합니다. 그 외에는 제작 입력 파일을 보존하면서 내보내기에서 명시적인 장 소유 키에 연결합니다. 기존 충돌·기예·유닛 ID는 바꾸지 않습니다. 역변환하면 벡터와 배치가 원본과 같아야 합니다.
3. 동일 컴파일 원본에서 전체/지연 로드, 자산 참조, 실제 접지 및 픽셀을 검사합니다. 파일이 없을 때 다른 장의 자산 키로 보완하는 경로는 거부합니다.
4. 원경은 별도로 원본/포맷/크기/앵커/시차/PC 및 모바일 구도를 기록합니다. 가려지거나 플레이 길로 오인되면 원경 구도나 역할을 조정합니다. 플레이 지형이나 판정을 바꾸지 않습니다.
5. 목표·아군·적·레벨·진입·장 종료가 기획과 맞을 때만 연결합니다. 빈 맵 승리, 로드 완료, 강제 플래그를 정식 클리어 수치로 올리지 않습니다. 기존 장비·정상 성장 프로필과 실제 목표 경로로 연결합니다.
6. 51–60이 준비되지 않으면 숨깁니다. 메뉴·이어하기·선로딩에 같은 진입 판정을 적용하고, 1–50 데이터와 기존 진행 기록 보존, 6막 신규 보고서 보존, 실제 브라우저 플레이를 확인합니다.
