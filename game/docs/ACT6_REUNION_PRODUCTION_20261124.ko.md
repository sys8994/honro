# 혼로 6막 개정판: 길을 남긴 사람들
기준 2026-11-24. 기존 기획안의 6-1~6을 보존하고, 사용자 승인에 따라 6-7 후반~6-10의 출전·사건·지형을 아래 한 줄기로 다시 엽니다. 이 문서는 구현 기준입니다. 현재 장별 시험 결과나 배포 완료 여부를 표시하지 않습니다.

## 피날레의 인과
바깥을 지켜야 안에서 돌아올 수 있으며, 안을 멈춰야 바깥에서 더 싸울 수 있습니다. 첫 가름진이 떠나는 혼의 길까지 막아 실패하고, 담허가 기존 돌단의 몸으로 돌아온 뒤 접힌 석교의 회랑을 통해 네 사람이 육신으로 들어갑니다. 네 사람이 필요한 이유는 힘의 합이 아니라 **중력을 붙들고, 유지점을 맞히고, 움직이는 문턱을 몸으로 지키고, 두 끝의 혼매듭을 이어 두는 일을 같은 국면에서 할 것**입니다. 곽진의 마지막 방어대는 산문 전체가 아니라 출구 하나를 지키고 전멸합니다. 대도사를 이겨도 이미 이쪽에 넘어온 적은 남습니다. 그래서 마지막 승리는 닫는 일이 아니라 갈라놓는 일입니다.

## 소유권과 실제 플레이
- 6-7: 관문 사건은 `outerFallbackReached → returnAnchorHeld → spiritReturnedToOwnBody → bridgeFoldOpened → allFourCrossed`. 박탈된 혼을 되돌렸다고 육신을 한 명 더 만들거나 HP를 자동 회복시키지 않습니다. 새 6-8 입장 치수, 실제 게임상 인적 연속성과 파티·장비·XP 검증. 이전 단독 담허/3인 로컬 증거는 기록에 남기나 새 장으로 산정하지 않습니다.
- 6-8: 1상은 문턱 여러 사선, 2상은 실제 탄도/바닥의 국소 법칙과 안전 턱, 3상은 살아 있는 유지점이 예고된 고정 지점을 실제 공격. 설오·휘겸·소단·담허 각자 적절한 역할이 있고, 단 한 순서의 스킬 빌드만 강요하지 않습니다. 개정판에서는 인간 대도사가 죽습니다. 1HP 생포는 기존 격리 시험만 보존합니다. 시신과 외부 군세를 섞어 혼령 부활로 되돌리지 않습니다. 패배는 폭발이 아니라 진목을 놓치고 그 자리에서 쓰러지는 짧은 장면입니다. 대도사의 죽음이나 유지점 단독으로는 승리하지 않으며 실제 단절/수정 진목과 네 사람의 귀환이 필요합니다. 사람 도복/짧은 진목, 보우 금지.
- 6-9: 박음 지점이 귀환을 증명한 뒤 곽진 부대의 불귀환을 관측. 인트로에서 정산하지 않습니다. 네 사람의 귀환을 상태로 확인한 뒤 시야 안에서 방패선을 봅니다. 정원·구역의 병사와 행동을 실제로 셉니다. 최소 세 높이/틈에서 오는 유입과 거대 앞발을 분리, 가까운 한 그룹을 밀 때 뒤 그룹이 전체를 덮지 않게 경고와 피할 차례를 보장합니다.
- 6-10: 전투 종료, 이름 남김, 망자 인도, 네 사람 실제 도착 및 후일담을 서로 다른 사건/정산 단계로 저장합니다. 이미 육신을 회복했으므로 또 깨어나는 사건 삭제. 목재 잔류 들림은 소리/결 풀림으로 해결 가능; 강제 공격·재보스·무의미한 턴 없음. 기록 완료 후 오래 지난 담허가 **살아 있는 육신으로** 무명사의 남은 흔적을 살피는 짧은 장면. 부활·다음 흑막 암시 없음.
- 적을 배경·실제·구조물형으로 분리. 6막 고유 원혼은 낮은 전열 표정, 임시 1~5막 똑같은 궁수·투사체 무늬 일괄 지양. 서술만 다른 개체를 늘리지 않습니다.
- **SOP:** 장별 정상적인 정측면으로 윤곽/실제 접촉선/시안 분리, 기존 승인 이미지에서 필요한 물리 사용성 확보 → Inkscape 중심 벡터 제작 → 시각/충돌 비교 → 상·하·좌·우 더미와 접합 톤 일치 → 1막 1·2장 실제 벌크 면적 기준 노드/폴리곤 최적화(윤곽 디테일은 남김) → PC/M 줌아웃/전투뷰/충돌 레이 최소 5회 검수. 작은 헤드 비정상 피격, 공중부양, 가짜 답보·단일 직선 맵 기각. 6막 10개 기존 정량 계약의 턴 범위는 참고, 실제 입력/라운드/시간/기예/적 수를 나눠 기록.

## 엔딩의 표현과 참고
- 감정을 문장으로 떠먹이지 않습니다. 휘겸이 “길은 남겼군.”을 먼저 말한 뒤 6-10에서 이름을 놓치지 않는 **작은 플레이어 행동**으로 답합니다. 서쪽 좁은 길에서 잠깐 정지하면 먹이 마르는 소리, 다시 선택권이 돌아오며 마지막 혼이 옆으로 지나갑니다. 포격으로 커진 외부 마지막 전투와 달리, 이 장에서는 다정함을 명시적인 행동으로 만든 상태입니다.
- 컷 1: 산문 재진입, 플레이 입력으로 마지막 매듭을 풀어 인도. 컷 2: 곽진과 마지막 방어대, 산 아래 피해와 구조된 사람(기존 13명 결산과 모순 금지). 메시지는 짧게, 정보는 따로 여정첩. 컷 3: 같은 난간·같은 돌에 닿는 실제 새벽. 징의 잔향, 낮은 대금·아쟁, 잠깐의 바람. 컷 4: 후일 담허가 걸어 스스로 문턱을 넘고, 카메라는 따라가지 않고 빈 길에 잠시 남습니다.
- [Jenova Chen의 GDC Designing Journey](https://gdcvault.com/play/1017700/Designing): 연출 하나의 감탄보다 게임 전체의 감정 곡선을 실제 경험으로 설계하는 접근을 참고. 혼로에서는 난전 다음 걷기와 잠깐 멈춤으로 완화.
- [Outer Wilds 작곡가 Andrew Prahlow의 인터뷰](https://www.gamedeveloper.com/audio/behind-the-hauntingly-beautiful-music-of-i-outer-wilds-i-), [Mobius 공식 제작 노트](https://www.mobiusdigitalgames.com/news/the-music-of-outer-wilds-episode-1): 이전에 떨어져 흘렀던 악기/주제를 마지막 공유 공간에서 모으는 방식만 참고. 합주·모닥불·곡을 옮기지 않으며 기존 혼로 동기, 징·대금·아쟁과 무음의 순서로 표현.
