# 4막 교전 복구 후보

완주·난이도·미술 합격 전이다. 원본 v3 기준과 최신 40장 강화 지시를 구분한다.

- 33·35장의 이름뿐인 중간보스를 실제 예고→발사→재배치→노출 행동에 연결한다.
- 37·38장은 기존 적 슬롯을 교체해 각각 중간보스2개를 둔다. 결박탄 HSH02과 곡사 HWD01을 분리하며, 실제 경고 관측 및 아군 대응 이후에만 발사한다. 이름/표시만으로 고유 패턴을 인정하지 않는다.
- 34장 퇴각점은 현재 동굴 바닥으로 옮기고,39장의 제자리 퇴각점을 기존 동쪽 갑판의 다른 지점으로 옮긴다. 지형은 바꾸지 않는다.
- 36장은 기존 보상 정예 ID를 보존해 외곽으로 옮기고 안마당의 일반 적3개를 제거한다. 외곽2군집·총6명·행동 상한2의 완화전 후보이며 실제 행동수는 별도 측정한다.
- 32–39장의 경계조를 같은 실제 지지면별로 분리하고 인접한 지지면은 제한된 x범위에서만 연결한다.900world 이내·고도차650 이내를 기본으로 반응한다(36장은700). 이는 동시 행동수의 합격 증거가 아니다.
- 승인된 지형·미술·NPC·사건 좌표는 보존한다. 큰 벡터 청크를 재작성하지 않고 공통 빌드의 `shared/act4-encounter-revision.mjs`에서 적 기록만 갱신한다. Game·Workshop·모델 검사가 동일한 결과를 사용해야 한다. 원본 world.json만 읽고 최신 런타임 배치라고 보고하지 않는다.
- 32–39의 지도/교전 revision만6으로 올린다. 구형 진행 전투는 기존 이관 규칙에 따라 해당 장을 재시작하며 성장·장비·이전 완료·4막 증거를 보존한다.31·40 및 Workshop은 이번 revision 변경 대상이 아니다.
