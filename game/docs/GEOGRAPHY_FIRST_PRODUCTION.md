이 문서는 기존 정량 카드의 수직 이동·높이·발판 수 강제 조건보다 우선한다. 기존 실패를 소급 합격시키지 않는다.

## 먼저 통과할 네 가지
1. **장소:** 원래 지리·서사·생활시설을 읽고, 주요 지형마다 무엇인지와 왜 여기 있는지를 설명한다. 원문 근거와 설계 선택을 나란히 기록한다.
2. **구조:** 발판·다리·잔교는 암벽/벽에 붙은 보, 실제 지면의 교각, 양끝의 고정점 등으로 연결된다. 정상 플레이 화면에서도 그 연결이 보인다. 어두운 선 몇 개를 덧대거나 원경을 뒤에 깔았다는 이유만으로 통과하지 않는다.
3. **플레이:** 위 조건 안에서 사선·엄폐·접근·우회·퇴로를 만든다. 지리와 맞지 않는 거대 암주·공중 발판·높이 차를 수치 때문에 추가하지 않는다.
4. **그림:** 승인된 스타일/밀도를 유지하며 공간 전체의 연결을 먼저 본다. 부품 하나의 예쁨은 스테이지 구도·논리의 합격이 아니다.

## 수직 이동 수치의 역할
- 점프/아래점프 횟수, 필수 고도 차, 수직 이동 비율, 발판 수, 맵 높이/종횡비는 **기획·진단 참고값**이다. 이를 채우려고 동선을 늘리거나 발판을 추가하지 않는다.
- 자연스러운 고저차와 의미 있는 위치 선택은 실제 화면·다양한 플레이로 검수한다. 원래 절벽인 장은 수직 전개에 집중할 수 있지만 횟수 할당량은 강제하지 않는다.
- 20R 상한, 장별 전투 분량/난도, 적 구성·기믹·실제 완료, 실측과 오류 보존, 시각 검수는 유지한다.

## 이미지와 벡터의 역할
- **원경은 래스터 이미지**다. 기존 이미지 공급·시차 경로를 유지한다. 벡터로 변환한 뒤 PNG로 포장해 ‘원경 이미지’라고 하지 않는다.
- 실제 플레이 지형, 상호작용 구조물, 적합한 공통 자산/근경은 시안→실제 Inkscape→형태 보존 최적화 경로를 쓴다.
- 중경/후방 구조가 발판을 지탱한다면 카메라 이동 뒤에도 연결이 어긋나지 않아야 한다. 시차가 다른 원경 그림을 실제 부착벽처럼 사용하지 않는다.
- 스타일 기준은 `art/style-reference/act4-user-approved-20261030.png`. 승인 범위는 스타일·품질·밀도이며 배치/충돌/완주 승인이 아니다.
