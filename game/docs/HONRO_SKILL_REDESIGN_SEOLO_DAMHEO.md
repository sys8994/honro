# HONRO 설오·담허 스킬 리디자인 상세기획서

기준: HONRO RC21 계열 메인 런타임의 현재 전투/스킬 구조를 바탕으로 한 개편안

목적은 단순한 수치 조정이 아니다. 기존 Arcfall 시절의 서양 판타지식 스킬 묶음을 걷어내고, **설오는 ‘궤적을 다루는 궁수’, 담허는 ‘법구·기파·진법을 쓰는 도사’**로 플레이 감각 자체를 분리한다.

---

## 0. 공통 설계 원칙

### 0-1. 기본 공격은 스킬트리 밖에 둔다

- 설오: **평사**
- 담허: **기파**
- 기본 공격은 항상 사용 가능하며 스킬트리 선행조건이 아니다.
- 기본 공격에는 SP를 투자하지 않는다. 캐릭터 레벨/공격력 성장만 반영한다.
- 기존처럼 전투 슬롯의 첫 번째 기본기 역할은 유지해도 좋다.

### 0-2. 각 캐릭터는 3개 계통 × 5개 액티브 스킬을 가진다

- 각 계통의 5번째 스킬은 별도 전역 궁극기가 아니라 **해당 계통의 궁극기(이하 ‘계통 비기’)** 다.
- 기존 `A99/M99`처럼 “모든 스킬 습득 후 하나의 궁극기” 방식은 제거한다.
- 계통 비기도 일반 스킬처럼 Lv.1~8 성장 가능하게 한다.
- 단, 높은 기력 소모와 2라운드 전후의 재사용 대기시간을 두어 난사를 막는다.
- 코드에서는 기존 `ultimate:true`와 분리해 `capstone:true` 또는 `branchUltimate:true` 같은 메타데이터를 권장한다. 기존 `ultimate` 로직은 랭크를 1로 고정하고 별도 해금 조건을 적용하므로 그대로 재사용하면 안 된다.

### 0-3. 현재 Lv.1~8 성장 구조는 유지

기존 소스의 일반 액티브 피해 성장 곡선을 최대한 유지한다.

| 스킬 Lv. | 피해 배율 |
|---:|---:|
| 1 | 1.00 |
| 2 | 1.16 |
| 3 | 1.32 |
| 4 | 1.40 |
| 5 | 1.48 |
| 6 | 1.56 |
| 7 | 1.64 |
| 8 | 1.72 |

이 값은 **기본 피해**에 대한 배율이고, 각 스킬의 고유 기믹(거리, 낙차, 속력, 관통 수, 파편 수, 진목 효과 등)은 별도 성장한다.

### 0-4. 밸런스 모델이 스킬 개성을 다시 평준화하지 않게 한다

현재 RC21의 `skillBalanceFactor()`는 런타임 피해에 직접 관여하며 스킬의 raw damage 차이를 크게 보정할 수 있다. 이번 개편에서는 스킬별 의도된 고저차가 중요하므로 다음 중 하나로 바꾼다.

권장안:

- `balanceModel`은 **감사/audit용 점수 계산**에만 사용
- 실제 런타임 피해는 기획 수치가 기준
- 꼭 보정이 필요하면 최종 보정폭을 **0.90~1.10** 정도로 제한

즉, 저격 스킬은 실제로 강하고 지원/설치기는 실제로 낮은 피해를 가져야 한다.

### 0-5. 기력 소모 표기

아래 표의 `기력`은 **플레이어가 실제 HUD에서 체감하는 Lv.1 기준 목표 소모량**이다.

RC21의 `MANA_COST_MULTIPLIER = 1.95`를 그대로 유지한다면 `Skill.cost` authored 값은 대략 `목표 기력 / 1.95`로 설정하면 된다. 기존 랭크별 기력 감소 공식은 유지해도 된다.

### 0-6. 시각 방향

공통적으로 다음을 피한다.

- 과도한 네온
- 서양식 룬 폭발
- 파이어볼/아케인 미사일처럼 보이는 구체
- 화면을 가득 덮는 화려한 입자
- Canvas `filter` 기반 효과

대신:

- 실제 화살, 호리병, 진목 같은 **물성 있는 물체**
- 흰빛·먹빛·청회색 계열의 절제된 기파
- 한지/부적/도자기/목재 같은 재질감
- 짧고 선명한 충격선
- 붓선처럼 얇은 파문과 기문

을 사용한다.

# 1. 설오

## 1-0. 캐릭터 정체성

설오는 단순한 원거리 DPS가 아니라 **“포격 궤적의 질을 공격력으로 바꾸는 궁수”**다.

세 계통은 좋은 사격의 기준이 서로 다르다.

- **절명**: 멀수록 강하다.
- **곡사**: 높이 띄웠다가 떨어뜨릴수록 강하다.
- **강궁**: 빠른 속도로 박을수록 강하다.

이 차이가 플레이어의 조준법 자체를 바꿔야 한다.

# 1-B. 절명 계통

## 계통 기믹: 거리 보정

절명계 스킬은 **발사점과 명중점의 수평 거리**에 따라 피해가 증가한다.

곡선 궤적의 실제 path length를 사용하지 않는다. 그래야 곡사 계통과 중복되지 않는다.

권장식:

`거리보정 = 1 + C_dist × clamp(|hitX - launchX| / 1800, 0, 1)`

- 일반 절명 스킬 `C_dist = 0.40`
- 절명시 `C_dist = 0.60`
- 패시브 `궁세`가 이 계수를 추가 강화

즉 900 거리에서 일반 절명 스킬은 약 +20%, 1800 이상에서는 약 +40%.

### 1-B-1. 급소시

**설명:** 급소를 노려 살을 날린다. 치명타 확률과 피해가 크게 증가한다.

**랭크 성장**

- 치명타 확률: Lv.1 18% → Lv.8 39%
- 치명타 배율: Lv.1 1.70× → Lv.8 2.05×
- 거리 보정 적용

**VFX**

- 화살 자체는 평사와 거의 동일
- 치명타 순간에만 대상 뒤로 아주 짧은 흰색 관통선과 먹빛 잔상
- 화면 흔들림은 미세하게

### 1-B-2. 관통시

**설명:** 적을 꿰뚫고 계속 날아간다. 성장할수록 더 많은 적을 관통한다.

**랭크별 최대 관통 수**

`1 / 1 / 2 / 2 / 3 / 3 / 4 / 5`

- 첫 대상 100%
- 이후 대상마다 이전 피해의 88%
- 얇은 목재 관통은 기존 A02 물리 규칙을 최대한 유지
- 암반은 관통하지 않음

**VFX:** 현행 관통시를 거의 유지. 관통 순간 작은 목재 파편/피격선 정도만 추가.

### 1-B-3. 회기시

**설명:** 적중의 반동으로 숨을 되찾는다. 가한 피해 일부만큼 체력과 기력을 회복한다.

- 기본 피해 40
- 실제 적에게 가한 피해만 회복량 계산에 사용
- 구조물/지형 타격은 회복 불가

**회복률**

- HP: Lv.1 5% → Lv.8 12%
- 기력: Lv.1 3% → Lv.8 7%
- 1회 사격 회복 상한: 최대 HP 15%, 최대 기력 18%

**VFX:** 적중 순간 화살에서 설오 쪽으로 아주 짧고 가는 회백색 선이 한 번 되돌아오며, 설오 주변에 작은 호흡 파동. 흡혈/혈광 표현 금지.

### 1-B-4. 정심

**설명:** 호흡을 가다듬고 한 발을 기다린다. 다음 절명계 사격이 크게 강화된다.

- 이 턴에는 공격하지 않고 행동을 소모
- 기력 소모 0
- 다음 절명계 공격 1회 또는 2턴 안에 사용 시 소모

**Lv.1 → Lv.8 효과**

- 추가 거리 보정 계수: +0.08 → +0.22
- 치명타 확률: +6%p → +20%p
- 방어 무시: +4%p → +15%p

**전략적 목적:** 맞힐 각이 없는 턴을 완전한 손실로 만들지 않고, 다음 좋은 사격을 준비하는 선택지를 제공한다.

**VFX:** 설오가 활을 내리고 한 차례 숨을 고른다. 활시위/손 주변에 아주 약한 흰 기운이 모였다가 사라짐. 별도 폭발 없음.

### 1-B-5. 절명시 ★

**설명:** 먼 거리에서 단 한 번 숨통을 노린다. 장거리 치명타는 약해진 적의 목숨을 끊는다.

- 기본 피해 96
- 기력 62
- 재사용 대기 2라운드
- 속도 약 1.55×
- 거리 계수 `C_dist = 0.60`
- 치명타 확률 Lv.1 25% → Lv.8 39%
- 치명타 배율 Lv.1 2.00× → Lv.8 2.35×

**절명 판정**

다음 조건을 모두 만족하면:

1. 발사-명중 수평거리 1200 이상
2. 치명타 발생
3. 일반/정예 적의 잔여 HP가 일정 비율 이하

즉시 처형.

처형 임계 HP: Lv.1 약 12% → Lv.8 약 22%

보스는 즉사하지 않고 대신 잃은 HP 비율에 따라 최대 +25%의 추가 피해.

**VFX:** 화살이 매우 빠르게 날아가며 길게 빛나지 않는다. 명중 순간 화면 전체가 아니라 목표 주변만 짧게 탈색되듯 번쩍이고, 뒤로 한 줄의 흰 관통선이 남았다가 사라진다.

# 1-C. 곡사 계통

## 계통 기믹: 낙차 보정

권장식:

`drop = max(0, hitY - apexY)`

`낙차보정 = 1 + C_drop × clamp(drop / 900, 0, 1)`

- 일반 곡사 `C_drop = 0.45`
- 칠성추혼 `C_drop = 0.55`
- 자동유도성이 높은 추혼시는 0.35 정도로 약하게 적용 가능

### 급락시

**설명:** 정점에 오른 살이 급격히 떨어진다. 큰 낙차로 맞힐수록 강해진다.

- 정점에 도달하면 중력 배율을 크게 상승
- Lv.1 약 2.8× → Lv.8 약 4.1×
- 지붕/절벽 뒤 적을 노리는 기술

**VFX:** 정점에서 화살이 순간적으로 방향을 세우고, 하강 중 가는 수직 속도선 2~3개. 마법광 없음.

### 전로시

**설명:** 비행 중 한 번 살의 길을 틀 수 있다.

- 발사 후 비행 중 플레이어 입력으로 1회 방향 전환
- 최대 선회각 Lv.1 약 45° → Lv.8 약 80°
- 선회 후 속도 약 92% 유지
- 자동 유도 아님
- 모바일/데스크톱 모두 1회 입력 UX 필요

**VFX:** 꺾이는 지점에 얇은 흰 원호 한 번. 궤적 전체를 빛나게 하지 않는다.

### 추혼시

**설명:** 적의 기척을 좇아 살의 궤도를 완만하게 틀어간다.

- 현재 A13 유도 로직과 LOS 판정 최대한 유지
- 탐지거리/선회각만 랭크에 따라 완만히 상승
- 지형 관통 금지
- “완전 자동 명중”이 아니라 빗나감을 보정하는 수준 유지

**VFX:** 기존을 유지하되 유도 중 화살 끝에 짧은 청회색 꼬리 정도.

### 귀환시

**설명:** 크게 휘어 되돌아오는 살. 같은 적을 왕복으로 꿰면 두 번째 타격이 강해진다.

- 현재 A12의 정점 귀환 컨셉 유지
- 순간 180° 반전 대신 연속적인 곡률을 가진 큰 곡선으로 복귀
- 나갈 때 1회 관통
- 돌아올 때 1회 관통
- 같은 대상을 두 번 맞히면 귀환 타격에 +20% 보정
- outbound 100%, return 기본 70%

**VFX:** 왕복 궤적을 보여주는 얇은 잔상. 부메랑/마법 원반처럼 보이지 않게 화살 형태를 유지.

### 칠성추혼 ★

**설명:** 정점에서 일곱 살로 갈라져 적의 혼을 좇는다. 높이 띄울수록 낙하의 위력이 커진다.

- 정점에서 항상 7개로 분열
- 가능한 한 서로 다른 적을 우선 지정
- 적이 적으면 한 대상에 복수 화살이 몰릴 수 있음
- 같은 대상 최대 4발
- 같은 대상 다중 적중 배율: 100% / 70% / 50% / 35%
- 자탄 기본 피해 26
- 기력 60, 재사용 대기 2라운드

**VFX:** 정점에서 별 모양 폭발 금지. 화살 한 발이 일곱 갈래로 갈라지며 각 자탄이 먹선처럼 얇은 곡선을 그린다. 칠성 배열은 아주 짧게 암시만 한다.

# 1-D. 강궁 계통

## 계통 기믹: 충돌 속력 보정

권장식:

`q = clamp((impactSpeed - 500) / 650, 0, 1)`

`속력보정 = 1 + C_speed × q`

- 일반 강궁 `C_speed = 0.45`
- 철화의 1차 직격만 0.35 정도 적용
- 파생 화살은 별도 속력 보정 없음

## 스킬 표

- 추가 화살 수: `min(5, 패시브 Lv.)`

- 추가 1: 50%
- 추가 2: 33%
- 추가 3: 21.8%
- 추가 4: 14.4%
- 추가 5: 9.5%

모두 맞아도 총 추가 피해 약 +129% 수준이고, 실제 전투에서는 후속타 누락이 잦으므로 손맛을 살리면서 과도한 기대값을 억제한다.

**VFX:** 작은 백색 기핵 또는 납작한 파동. 벽에 닿을 때 반짝임 대신 짧은 원형 파문.

### 삼재파

**설명:** 두 번 스친 자리와 자신의 위치를 잇어 삼재의 기문을 만든다. 그 경계를 따라 기파가 흐른다.

동작:

1. 투사체가 첫 지형 반사점을 기록
2. 두 번째 지형 반사점을 기록
3. 담허의 발사 위치 + 반사점 1 + 반사점 2를 삼각형으로 연결
4. 세 변에 순간적으로 기파가 흐름

- 경계 피해 38
- 삼각형 내부의 적은 낮은 충격 피해 16
- 한 대상은 경계 최대 2회까지만 유효 타격 권장
- 너무 작은 삼각형은 내부 피해 생략
- 랭크가 오를수록 경계 판정 두께 20 → 34 정도 증가

**VFX:** 세 점에 짧은 먹점이 찍힌 뒤 선이 한 붓처럼 연결. 서양식 마법진 문양 금지.

### 동심파

**설명:** 기를 사방으로 밀어내 파면을 만든다. 멀리 퍼질수록 힘은 약해진다.

- 발사 버튼을 누르고 있는 동안 담허 중심 예상 동심원이 커짐
- 놓는 순간 해당 반지름까지 파면이 확장
- **원 내부가 아니라 원주 부근의 적만 피해**
- 지형 무시
- 충전 반지름 약 180~900
- 원주 두께 약 34~50

물리 메타포:

`피해 = 72 × 220 / max(220, r)`

단, 최소 28% 수준에서 clamp.

즉 가까운 반지름에서는 강하고 멀수록 약하다.

**VFX:** 담허 중심에서 회백색 원 하나가 확장. 내부를 채우지 않는다.

### 팔괘파 ★

**설명:** 목표 지점에 팔괘의 기문을 펼친다. 기선 위의 적을 한꺼번에 친다.

조작 권장:

- 조준 각도: 팔괘 중심 방향 + 문양 회전 방향에 반영
- 충전 세기: 중심까지의 거리 결정
- 별도의 복잡한 추가 UI를 최소화

효과:

- 중심 반경 약 70에 피해 62
- 8방향 기선 및 외곽 기문에 닿는 적은 선당 피해 34
- 한 대상 최대 3개의 선 피해만 허용
- 문양 반경 Lv.1 약 220 → Lv.8 약 290
- 기력 66, 재사용 대기 2라운드

**VFX:** 금빛 마법진 대신 먹빛/백색의 팔방 기선이 0.4~0.6초 드러났다 사라짐. 팔괘 문양은 상징적으로 단순화.

## 계통 공통 규칙

- 진목은 바닥에 박힌 뒤 고정
- 소환귀처럼 움직이거나 자동공격하지 않음
- 1~3번은 기본적으로 1회 발동 후 소멸
- 4번 축지진목은 지속 설치
- 5번 오방봉진은 적이 밟으면 대형 진으로 전개

### 파진목

**설명:** 적이 밟으면 진이 깨지며 강한 기파를 일으킨다.

- 진목 반경 약 45 안에 적의 발/몸 중심이 들어오면 발동
- 피해 56, 반경 약 95
- 1회 발동 후 소멸

### 회생진목

**설명:** 아군이 밟으면 체력과 기력을 되찾고 이동력을 회복한다.

랭크별 권장:

- HP: 7% → 14% 최대 HP
- 기력: 8% → 15% 최대 기력
- 이동력: 15% → 36% 최대 이동력

- 1회 발동 후 소멸
- 쓰러진 아군 부활 불가
- 이동력 회복 때문에 담허가 아군의 “보급로”를 설계할 수 있어야 함

### 유인진목

**설명:** 적이 밟으면 주변의 적들까지 홀려 진목 쪽으로 끌어당긴다.

- 트리거 대상 피해 30
- 주변 약 260~365 범위 적을 중심으로 흡인
- 흡인 거리 약 130~235
- 벽 관통 이동은 금지
- 고정 보스는 이동 대신 짧은 방어 약화 또는 피해만 적용 가능

### 축지진목

**설명:** 두 진목 사이의 거리를 접는다. 진목 위의 아군은 다른 진목으로 순간이동할 수 있다.

핵심 규칙:

- 맵에 동시에 최대 2개
- 세 번째 설치 시 가장 오래된 진목 제거
- 아군이 진목 위에서 `E`/인터랙션 버튼 → 다른 진목으로 순간이동
- 같은 유닛은 한 턴에 한 번만 통과 가능
- 진목 자체는 전투 종료 또는 교체 전까지 유지

랭크 보너스 권장:

- Lv.1: 순간이동만
- Lv.2~3: 도착 시 기력 회복 최대 약 8~10%
- Lv.4~5: 도착 시 HP 회복 최대 약 6~8%
- Lv.6~7: 도착 시 이동력 약 16~24% 회복
- Lv.8: 추가로 다음 적 턴 종료까지 받는 피해 약 10% 감소

**VFX:** 캐릭터가 빛기둥으로 사라지는 방식보다, 발밑 문양이 접히고 캐릭터 실루엣이 한 프레임 흐려졌다 다른 진목에서 나타나는 식.

### 오방봉진 ★

**설명:** 적이 진목을 밟으면 오방의 진이 펼쳐진다. 진 안의 적을 가두고 움직임을 봉한다.

발동 시:

- 중앙 진목 + 동서남북 4개 보조 진목 전개
- 반경 약 220의 봉쇄 영역
- 초기 피해 35
- 2라운드 지속
- 내부 적 이동속도 약 -45%
- 이동 예산 약 -35%
- 경계를 넘으려 할 때 22 피해 + 안쪽으로 밀침
- 한 유닛당 경계 피해는 턴당 1회
- 보스는 완전 봉쇄 대신 감속/방어 약화 중심
- 기력 62, 재사용 대기 2라운드

**VFX:** 네 방향에 나무 진목이 솟고, 서로를 잇는 매우 얇은 백색/먹빛 선이 잠시 드러난다. 바닥을 통째로 밝히는 원형 마법진 금지.

|---|---|---|

### 법맥

랭크당 권장:

- 호리병 2차 피해/효력 +3%
- 파문술 선/원주 판정 두께 +2%
- 진목 트리거 반경 +2%, 비피해 효과 강도 +2%

Lv.8에서도 과도하게 커지지 않게 상한 적용.

### 기해

- 최대 기력 랭크당 약 +3%
- 턴 시작 기력 회복 랭크당 +0.5 정도
- Lv.8 기준 최대 기력 약 +24%, 재생 +4 수준 권장

### 천기감응

직접 피해를 올리는 패시브가 아니라 **조작 정보의 질**을 높이는 패시브.

예시 단계:

1. 호리병 2차 범위 표시
2. fuse 종료 예상 위치 표시
3. 반탄파 1차 반사 예상선
4. 2차 반사까지 표시
5. 원호/동심/삼재의 실제 판정 두께 표시
6. 진목 트리거 영역 표시
7. 뇌호 타깃 후보/연폭호 분포 영역 표시
8. 예상 피해 범위를 간단한 low/high 값으로 표시

모든 정보를 한 번에 번쩍이지 말고 조준 시 필요한 것만 얇은 점선으로 제공.

### 회기

**설명:** 헛되이 흩어진 기를 다시 거두어들인다.

- 호리병/파문 계열 공격이 행동 전체에서 적에게 0 피해를 줬을 때 발동
- 기력 환급: Lv.1 18% → Lv.8 46%
- 진법 설치는 “미스”가 아니므로 즉시 환급 대상에서 제외
- 자기/아군 피해만 발생한 경우에도 적 피해가 없다면 환급 가능 여부는 플레이테스트 후 결정. 권장은 환급 가능.

### 입도 ★

설오의 일념과 같은 soft specialization.

- 가장 많은 SP를 투자한 계통을 주법으로 간주
- 주법 고유효과 랭크당 약 +2.5~3%
- 해당 계통 비기 효과 랭크당 +3%
- 다른 트리 하드락은 현 단계에서 하지 않음

# 5. 내부 ID와 적군 스킬 공유에 대한 주의

현재 HONRO 런타임은 플레이어와 적군이 일부 `Axx/Mxx` 스킬 정의를 공유한다. 위 권장 ID를 그대로 재사용하면 기존 적군의 행동이 의도치 않게 바뀔 수 있다.

따라서 구현 시 반드시:

1. 모든 `Axx/Mxx` 참조를 검색
2. 플레이어 개편으로 의미가 크게 바뀌는 ID가 적군 loadout에서도 쓰이면
   - 적군을 다른 적절한 스킬로 이관하거나
   - 기존 동작을 `enemy-only` 스킬 ID로 복제
3. 정심, 전로시, 축지진목처럼 플레이어 입력이 필요한 기술을 적 AI에 무리하게 부여하지 않음

을 지킨다.

# 6. 세이브 마이그레이션 권장

기존 저장 데이터는 스킬 ID별 랭크를 저장하므로 ID의 의미가 바뀌면 포인트가 엉뚱한 새 스킬로 이동한다.

안전한 1회 마이그레이션:

- 설오/담허의 XP, 레벨, 전투 통계는 유지
- 설오/담허의 기존 talent allocation만 초기화
- 기본 공격만 보유 상태로 설정
- 이미 획득한 총 SP는 그대로 미사용 포인트로 환원
- 휘겸/소단 데이터는 변경하지 않음
- loadout은 새 기본공격 + 보유한 새 스킬로 sanitize

# 7. 구현 완료 판정

단순히 데이터 표만 바뀌면 완료가 아니다.

최소 검증 항목:

- 설오 거리/낙차/속력 보정이 서로 독립적으로 계산되는지
- 치명타가 seeded RNG로 재현 가능한지
- 정심 1회 소비/유효기간
- 연속시위 1~5 추가발과 지수 감쇠
- 산개사 + 연속시위 결합 시 기존 손맛 유지
- 귀환시 왕복 동일 대상 재타격
- 칠성추혼 분열/타깃 분산
- 철화 자탄 수/개별 피해/대상별 cap
- 빙호 fuse + bounce + 파편
- 뇌호 범위 내 대상 모두 2차 적중
- 반탄파 천장/벽 다중반사
- 삼재파 삼각형 판정
- 동심파 원 내부가 아니라 원주만 공격
- 축지진목 최대 2개, 3번째 설치 시 오래된 것 제거
- E키 순간이동 및 같은 유닛 턴당 1회 제한
- 회생진목 이동력 회복
- 오방봉진 경계 봉쇄
- 훈련장에서 새 스킬 전부 테스트 가능
- 브라우저 런타임 에러 0
- 기존 맵/이동/렌더링 성능 회귀 없음
