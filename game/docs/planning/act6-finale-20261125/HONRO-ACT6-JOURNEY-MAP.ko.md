# 6막 여정첩: 무명사, 접힌 길

무명사 지도를 장 순서대로 오르는 한 줄로 그리지 않는다. 숲과 산문, 돌단과 석교가 있는 바깥은 지도에서 같은 자리에 남는다. 사찰 내부에서는 거리가 아니라 **어떤 곳이 어느 곳으로 이어지는지**를 기록한다. 안팎을 오가는 구간은 점선, 같은 편에 남는 구간은 실선이다. 한 화폭을 명확한 산문 문턱으로 나눈다. 바깥에는 옅은 새벽 하늘과 연결된 산세, 정방향 석교와 나무를 둔다. 안쪽에는 하늘·산 능선·바깥의 옅은 안개를 사용하지 않는다. 대신 닫힌 목조 법당의 기둥·처마·천장, 틀어진 중력과 닿을 수 없는 내부의 깊이를 암청·보랏빛으로 구분한다. 6-7과 6-9에서 방어선과 석교가 다시 읽히고, 마지막에는 열어 둔 산문으로 돌아온다.

- 기존 여정첩의 막 선택, 현재 길목, 완료한 위치, 드래그·확대·맞춤과 길목 상세를 유지한다. 5막 마지막 장 완료 후 열린다. 배경은 한 장의 전용 지리 일러스트, 점·경로·가림과 MOB/PC 조작은 기존 여정첩 UI와 분리한다.
- 무명사 진행 위치는 기존 장간 체크포인트/완료 영수증을 읽기만 한다. 숨겨진 장의 제목을 노출하지 않으며 현재 길목의 사건 결말은 완료 뒤에만 읽을 수 있다.
- 지난 장을 누르면 장소와 기록을 읽는다. 6막 재전투·개별 보상·엔딩 재생은 새로 부여하지 않는다. 이어하기는 기존 산문 쉼터의 검증된 버튼을 사용한다. 6막 이어하기와 1~5막 저장 키, 체크포인트 작성자, 패킷, 게임판은 바꾸지 않는다.
- 완주 뒤 6막 전체가 드러난다. 연출 개편, 새 엔딩곡, 컷 다시보기는 이번 지도 릴리스에 포함하지 않는다.
