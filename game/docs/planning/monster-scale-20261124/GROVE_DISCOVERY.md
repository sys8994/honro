# 귀림의 첫 밤 — 수목귀 약점 발견 대사안

확인: master d80e64593e40342a34e5ea1e4e13f22ecda770a7. eb3dbeb 이후 원격 비교에서 활성 chapter-44.f4d345861a0107ba.json 및 HONRO_ACT5_CONTENT.fba7315ab47677f7.json 미변경. 실제 이 장 인원은 설오/담허/휘겸/소단, 별도 동맹 정찰 도식. 도식의 기존 첫 대사는 나무/왼쪽 계곡/표식의 거리, 설오는 발자국 관찰이다. 도식이 수목귀 약점을 이미 아는 근거는 없으며 대사 수정 없음.

대상 a5-foe-5, warden/naruWarden, 위 뿌리 능선의 국소 목표. 아래 골/합류/정상 증원은 이 약점 발견을 필요로 하지 않는다. 8.5m 후보의 게임 렌더에서 기존 warden 얼굴 y 약 .081–.456 높이, 눈가 .22. 어두운 뿌리와 목재는 원래 형태를 유지하고, 눈 안쪽의 기존 채움만 약한 옥빛(후보 #b7d4b6)으로 맵 세계 안에서 읽힌다. 전투 전 배우가 정답을 말하거나 조준선에 정답·퍼센트를 표시하지 않는다. 클리어 조건이나 목표 표시를 약점과 같은 색으로 만들지 않는다.

판정은 체급 v2/unknown/정확한 개체 ID/아군 유효 직격 이벤트에만. 피해 전후 관측이 없는 폭발 파편, 연속탄 재전달, 일반 범위타, 상태 피해, 무효타와 다른 몬스터는 제외. 발화는 전투 중 한 줄 비모달 자막, 패턴 경고와 기존 대화를 끊지 않음. 서로 다른 두 유효 몸통 발사(shot ID 중복 제거) 뒤 추론 한 번, 첫 얼굴 직격 확인 한 번. 개체 ID+규칙 키 기준 상태 기록. 두 몸통 직격 전에 얼굴을 맞혔다면 확인 대사만 내고, 이미 확인 후 뒤늦은 몸통 대사는 없음. 설오·담허 중 해당 화자의 직접 발사가 아니어도 같은 자리에서 확인하는 근처 관찰자는 살아 있고 발화 가능한 경우 그 역할 수행. 말할 수 없는 화자뿐이거나 장면이 시야 밖이면 억지 대사를 내지 않고 같은 사실을 다음 유효한 관측으로 남김. 마지막 약점타로 죽더라도 충돌 시점의 스냅샷/좌표를 쓰되 열려 있는 종료 대사나 승리 전환은 가로막지 않음. 이어하기 때 이미 표시한 기록과 미처 전달 못 한 대기 상태 구분, 작업 승인 전 전역 발행/제품 변경 없음.
