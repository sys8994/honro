# 이전 막 체급·약점 후속: 나루와 파도 절벽

기준: `b0f169aa` 정규 신규 전투. 이미 있는 교각귀·귀림 수목귀의 약점, 잠운사의 성장, 나루 서편 두억시니와 포구 장승의 장소별 색, 하늘우물 큰 어둠은 유지한다. 수치나 물량을 맞추려고 전 스테이지의 몸체를 키우지 않는다.

| 막·장 (전체 장) | 변화와 선택 | 이전 → 다음 (normal) |
|---|---|---|
| 1막 3장 (3) 서낭나루 | 물에 오래 잠긴 나루장승을 안전한 기존 접지점에서 한 체 확대하고 푸른 젖은 목재와 갈라진 눈가를 드러낸다. 장부와 철수가 우선이며 장승 처치가 추가 목표가 아니다. 몸통 직격 35%, 얼굴 직격 130%. | 6.5 → 7.5m 렌더 목표, 히트박스 h352/r54 → h406/r59, 초기 체력 848 유지 |
| 4막 4장 (34) 파도에 깎인 절벽 | 이미 큰 턱포격체의 목재를 염분빛으로 바꾸고 부스러진 눈가를 기존 리그의 대비로 보인다. 높은 턱이나 낮은 반대편 포대에서 조준할 가치가 있다. 몸통 20%, 얼굴 100%, 비직격은 얼굴 판정 불가. | h430/r60 유지, 초기 체력 3242 → 1621. 약점이 없는 버전의 표준 6타 예산에서 정밀 3타 안팎을 출발점으로 환산 |

- 장별 밝은 눈가와 피해 표시가 함께 단서를 준다. 동행의 유효한 몸통 직격이 두 번 확인되면, 살아 있고 현장을 볼 수 있는 설오·담허·휘겸이 상태를 추론한다. 얼굴이 먼저 맞았으면 몸통 추론은 건너뛴다. 대사는 비차단이며 기록을 저장해 반복하지 않는다.
- 새 3장/34장 전투에만 전투 체급 리비전 3을 찍는다. 기존 1·2 리비전 저장, 사용자 지도, 다른 이름·출현 파동의 몸과 피해, 서사 목표와 지형은 바꾸지 않는다. 새로운 약점은 몸체/얼굴이 지정 조건에 맞게 놓일 때만 붙인다.
- 3막 관아 마당 두억시니는 곽진·주민 퇴로를 통제하는 개체, 동쪽 달길 두억시니는 관문 출구의 개체이므로 크기를 넣기 위한 대체 자리가 아니다. 30장 나루 서편과 40장 포구의 몸체 보존 근거는 [나루·조수 검토](FERRY_TIDE_VARIANTS.md)에 있다. 둘은 기존 재질 변주만 유지하고 동선을 덮지 않는다.
- 이 변경은 역동성·위압감에 대한 제작자 승인 또는 일반 플레이의 실제 처치 라운드 측정이 아니다. 새 그림·새 패턴·지형·진행 목표는 만들지 않았다.

## 확인

- `node tests/monster-scale-closeout.mjs`: 실제 대상의 접지 적합, 동일 발사 방향의 기준/몸/얼굴 피해(3장 **79/28/103**, 34장 **79/16/79**), 모서리 스침·파생타의 보너스 금지, 두 몸통 직격 직후 추론 → 얼굴 명중 확인, 얼굴 명중이 앞설 때 추론 생략, 이전 리비전 제외와 새 전투 이어하기. 컷마다 양쪽 접지점의 A01 발사와 실제 탄도·지형 도달까지 확인했다.
- `npm --prefix game run typecheck`: 통과. 기존 `tests/act1-review-regressions.mjs`의 652 HP 단언은 변경 전에도 실제 848 HP에서 실패한다. 이 변경은 나루장승의 현재 초기 체력을 유지한다.
- 동일 기존 벡터 리그로 변경 전후 PC 1440×900·모바일 390×844를 로컬 Chromium에서 확인했다. 이 비교 화면은 캐릭터 외형/시각 단서 확인용이며, 해당 장 전체를 플레이한 화면은 아니다.
