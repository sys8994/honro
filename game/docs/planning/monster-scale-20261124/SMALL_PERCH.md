# 끊어진 나무다리의 작은 감시자 (2026-11-24)

하부 전망대에서는 기존 동쪽 암반이 박쥐의 사선을 막습니다. 상부 다리에 실제 발을 딛고 가까이 다가가면 사선이 열립니다. 같은 체급·같은 적 수라도 위로 갈지, 아래의 엄폐를 밟을지 다른 전투 선택이 생기도록 동쪽 기존 산박쥐 foe-7 하나만 바꿉니다.

- 새 정식 1막 6장 전투에만 적용합니다. 체급 h66/r28, 스폰 위치, 공격과 체력, 지형, 운반대·탈출, 다른 날짐승을 바꾸지 않습니다.
- 기존 bridge-east 지지면, 거리와 높이, 실제 가리지 않은 사선이 모두 맞을 때 비로소 일반 전투에 참여합니다. 준비 전에는 임의 순찰·유인으로 튀어나오지 않습니다.
- 직접 시도한 플레이어 공격이 실제 HP를 깎으면 먼저 깨울 수 있습니다. 빗맞거나 자동·지속 피해만으로 경계 상태가 흐트러지지 않습니다. 이미 깨어난 박쥐는 인접 지형을 밟았다고 다시 잠들지 않습니다.
- 아래쪽에서도 아군이 유효한 포물선으로 공격할 수 있습니다. 상부에서 즉시 일반 활이 닿는다는 보장은 없으며, 기존 도약·거리·아래 사선이 다른 선택입니다. 새 텔레포트·일방적 선제 피해·모달 대사는 추가하지 않습니다.
- 잠운사 회랑 까마귀는 현행 이미 지지면을 활용하므로 중복 개입하지 않습니다.
