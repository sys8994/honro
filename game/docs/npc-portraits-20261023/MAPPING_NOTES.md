# 평범한 NPC 최소 8안 매핑

- 연실 전용 1 / 장년 노동자 1 / 청년 노동자 1 / 장년 여성 1 / 노년 남성 1 / 노승 1 / 젊은 승려 1 / 수비병 악귀 1.
- 덕수·석공·길찬은 각각 장년·노년·청년으로 다른 얼굴. 석공/길찬은 재등장에도 같은 초상을 유지.
- 월이·칠복도 현재 활성 구조 경로에 포함. 덕수와 셋이 장년/여성/노년으로 구별.
- 14장 길찬·중층 주민·피난 다리 주민은 청년/여성/장년으로 구별. 마지막 주민 성별은 미확정이며 장년 노동자는 시각 배역 제안. 가족 관계를 임의 추가하지 않음.
- 20장 부자와 이름 없는 주민 2행은 노년/청년/여성/장년으로 구별. 이름 없는 두 주민을 동일인으로 단정하지 않음.
- 16장 노승과 제자는 반드시 다른 얼굴. 19장 유족 남매는 장년/여성으로 구별.
- 공유 얼굴은 다른 장면의 단역 배역 재사용일 뿐 동일 인물 설정이 아님.
- generic 주민은 전역 speaker 매핑 금지, rowId 우선. actorId는 stage와 합쳐 처리. 14장 actor 연결 2건은 런타임 step target 추가 확인 전 제안 상태; row 매핑은 확정 가능.
- 이름 표시는 원래 대본/런타임 그대로. 초상 연결 과정에서 비공개 이름을 미리 표시하지 않음.
- 종지기는 별도 재기획 보류. 익명 존재는 무초상.
- 모든 옷과 얼굴은 일상적이고 평범하게. 화려한 비녀, 후광, 영웅 장식, 장군 갑주, 멋낸 흉터를 배제. 나이/성별이 원문에 없는 곳은 미술 배역 제안이라고 명시.

실제 게임 코드·설정·에셋 수정 없음. 모든 고정 65행과 동적 증언 3이름을 JSON에 매핑.

## 실행 검증

부모 승인 v2의 실제 파일 ID는 worker_mature/woman_mature/man_elder/guard_spirit이며 제안 JSON의 worker_adult/resident_woman/resident_elder/guard_fiend와 명시적으로 대응한다. 제안 JSON은 입력 이력으로 보존하고 runtime config는 game/config/npc-portraits.json에 둔다.

생산 App launch에서7장의 덕수·월이·칠복 마커/배우/동적 증언을 확인했다.14장 현재 revision1의 family-upper target은 resident-1, family-mid target은 resident-3이다. 해당 배우 fallback도 현재 marker target이 일치할 때만 허용한다. 고정65행 rowId는 현재 원문과 전수 대조했으며 표시 이름·본문·관계를 바꾸지 않았다.
