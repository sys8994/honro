# 혼로 NPC 초상화 대상 전수 인벤토리

기준: `narrative-return/narrative-current.proposed.json`. 1–3막 30장. 고정 인물성 NPC 화자 라벨 18개, 대사 65행. 동적 구조 증언에 월이·칠복 2개 이름 추가. 이는 20명의 서로 다른 사람을 뜻하지 않는다. `주민`은 여러 사람이고 `구조한 주민`은 구조 대상 별칭이다.

## 제작 우선순위
- 독립 얼굴 권장 5개: 종지기, 연실, 덕수, 석공, 길찬. 종지기는 대사상 핵심 적대자라 가장 높은 우선순위.
- 승려 보조군 2개: 노승과 제자 승려. 같은 장면에서 식별되어야 한다.
- 주민/노동자 공용 4–5개 기본형: 장년 노동자, 주민 A/B, 필요 시 노년 주민/별도 노동자. 성별·연령은 작품 아트 설정으로 정하되 대본 확정 사실인 척하지 않는다. 이름 있는 단역에도 재사용 가능.
- 병사 악귀 1개: 수비병 악귀. 중요 보스로 승격하지 않는다.
- 익명 목소리: 얼굴 없음 또는 비인물 익명 효과. 정체는 남겨 둔다.
- 합계 제안: 얼굴 12–13개(독립 5 + 승려 2 + 공용 4–5 + 악귀 1). 기존 초상 자산 중복 여부를 확인하기 전의 계획치.
