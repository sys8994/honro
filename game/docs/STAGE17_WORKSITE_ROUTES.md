# 17장 두드리는 벽 · 인양 작업장의 다중 경로

## 실행 범위와 지시

2026-10-09: 11장 최종 기준 bb88d29에서 독립 분기했다. 사용자 승인 후속 구현으로 17장의 지형·배치·장소 미술만 개선한다. 다른 29장, 파티, 이야기의 중요한 사실, 현행 목표 순서와 방어 5라운드는 보존한다. 삭제된 붕괴 고정점은 복원하지 않는다. 사용자 컴퓨터는 사용하지 않는다. 모든 변경은 단위별로 커밋하며 원격 저장이 가능해지면 순서대로 반영한다. 원격·master·Pages의 실제 반영은 별도 검증 없이는 완료라고 보고하지 않는다.

## 구체 공간 계획

11200×8200의 작업 공동. 실제 이동과 교전은 y3100–6210의 동굴 안에 집중한다. 기존 8400×6800보다 넓지만 기능 없는 외곽 확대를 경로 복잡성으로 세지 않는다.

- 높은 길: 서측 비탈 작업대에서 비대칭 상부 암반과 끊긴 인양 작업대로 오른다. 인양틀과 반대편 호위를 향한 긴 교차사선이 있으나 암반 어깨와 박쥐가 한 자리에 머무는 것을 막는다. 동측에는 짧은 막다른 고지 사격점이 있다.
- 가운데 길: 큰 받침돌과 기계 기단, 중앙의 실제 빈 인양구를 가로지르는 목재 보행면, 다시 솟은 인양축 바위로 이어진다. 근접·범위 공격을 위한 짧은 고저 교전면이다.
- 낮은 길: 중앙 암반 아래로 내려가 두 번 꺾인 정비굴을 통과한다. 낮은 천장과 차폐가 장거리 사선을 끊고, 소단의 차폐 너머 지원과 담허 반사 선택을 만든다.
- 서측·중앙·동측에서 위아래를 오갈 수 있다. 모든 동행에게 기본 보행·도약 경로를 두고 직업별 E 잠금이나 강제 파티 분할을 추가하지 않는다. 중앙의 사선 연결로는 세 개의 평행 복도와 구별되는 교차 동선이다.

전투 구역은 입구 공구조, 서측 버팀목, 중앙 인양틀 호위, 인양축 방어, 문 뒤 기록 후위다. 군집 사이 연결은 비우고 전위·정예·고저 지원을 함께 배치한다. 현행 초기24/정예6/유한증원10은 출발 예산이며 검증 전 품질 수치로 주장하지 않는다.

## 목표 연결

작업장 확보 → 안전 버팀목 → 들린 인양틀 제압 → 인양축 복원 → 5라운드 방어 → 남은 적 제압 → 종지기의 기록 조사. 세 경로는 복원축 서측에서 모이며, 기록방 복구문은 천장부터 바닥까지 막아 조기 우회를 허용하지 않는다. 방어에서 축 곁의 동행과 접근로를 끊는 동행의 역할을 자연스럽게 만든다.

## 2차 구조와 최종 제작 범위

첫 사선 중심 블록아웃은 보행 실험용으로만 보존했다. 최종 작업장은 11장의 긴 비탈을 반복하지 않는다. 서측 짧은 왕복 작업대, 중앙 수직 인양갱, 동측 낮은 축 정비굴과 좁은 상승구가 서로 다른 모양을 가진다. 작업발판의 높이차는 실제 기본 도약 약211 이내이며, 넓은 휴식/사격면과 짧은 디딤면의 폭을 달리했다. 상부는 끊긴 맞은편 사격턱이다. 동쪽에서 상층으로 돌아오는 통로와 하부에서 중앙으로 복귀하는 통로도 각각 검증한다.

중앙에는 바위 기단 두 곳에 실제로 내려앉은 큰 인양기, 매달린 인양추, 밧줄·도르래·구동축이 있다. 작은 A자 들린 장치는 큰 기계의 조작부에 연결된다. 서측 도구 작업터와 하부 정비굴에는 서로 다른 작업 흔적·바퀴·밧줄·공구 모임을 국소적으로 배치했다. 실제 천장에 맞춘 버팀목과 낮은 뒤쪽 암반층은 통로의 높이를 설명하며 새 충돌 발판으로 오인할 선반은 추가하지 않는다. 비보행 암반 모서리는 안쪽으로만 둥글게 다듬고 기존 보행선·접지·통과 공간은 보존했다.

## 군집 편성의 검수 후 수정

24명 첫 배치는 전용미술 확대 화면에서 중앙과 하부가 빈약했다. 숫자 유지를 품질 조건으로 삼지 않고 다음 국소 군집을 보강했다.

- 버팀목 작업터: 서로 가까운 두 전위와 정예/근위, 위 작업대의 경계. 작업장을 비우는 첫 목표와 연결한다.
- 중앙 인양기: 인양틀 앞의 공구병 둘, 반대편 정예 감독과 수레, 뒤의 혼령 지원. 큰 기계의 조작부를 감싸므로 가까이 붙는 길과 상부에서 끊는 사선이 다르다.
- 서측 높은 사격턱: 바위 위 경계와 박쥐·혼령. 새 앞쪽 혼령이 예전 후방 사선을 실제로 차단하는 경우도 있어 조준 위치를 바꿔야 한다.
- 낮은 정비굴: 두 수레의 앞 공구병과 높은 도구선반의 후위. 바닥에 모두 한 줄로 놓지 않고 상하층 착탄 선택을 만든다. 반사 천장과 돌기둥을 보존한다.
- 인양축 앞·동쪽 굴·기록방: 혼령 세 체의 범위교전, 낮은 굴의 정예 혼과 수레/근위, 문 뒤 바닥·높은 작업대 후위로 구분한다.

최종 초기 편성은36명, 명시 정예8명과 기존 인양틀 우두머리1개체다. 유한 방어 수레10명, 동시 적 행동3명, 최대 적 예산46명이다. 기존 factory의 11번째 슬롯마다 붙던 숨은 정예 승격은 새 편성에서 제외하고 명시된 정예만 강화한다. 원래 일반 두 개체의 숨은1.25배 HP/0.12 방어만 정상값으로 되돌렸으며 다른 공격·몸 크기·기예·성장 계수는 유지한다. 전체 전투 XP와 장 완료 XP 한도는 그대로이며 더 많은 적에게 배분된다. 과거 진행 중 저장의 값은 바꾸지 않는다.

수레는 서측 인양 바닥과 동측 복구문 안의 실제 지지면에서 번갈아 들어온다. 예고가 표시된 뒤 다음 행동 경계를 지나야 나타난다. 동행이 진입로를 점유하면 원자적으로 대기하며, 저장/재개해도 경고·진입이 중복되지 않는다. 열 명 모두 출현하고 기존 5라운드 방어가 끝나야 다음 목표로 넘어간다.

## 실제 입장 준비 기준

## 최종 검수 결과와 남은 한계

생산 동결862daa4의 경지13·36체 편성은 정상 입력으로63라운드에 완료됐다. 7목표, 방어5/5, 예고수레10/10, 총46적 제압, 동행4명 생존, 재시도·소모품 소비0을 확인했다. 시뮬레이션 시간1018.658초와 조준계산303.755초/물리실행73.146초는 서로 다른 측정값이다. 후반 입력정책이 현형부를 쓰지 않고 소단에게 숨은 혼 처리를 맡겨 나머지 동행이 길게 방어했다. 이63라운드를 적정 페이스나 사람의 필수 시간으로 주장하지 않는다. 기록방 발판에서 봇의 여섯 경로 검색 실패는 물리 장애가 아니라 누락된 그래프 연결이며 해당 발판 실제 기본 도약은 별도 네 동행 모두 통과했다.

검수 통과: 두 HTML 공통 빌드와 TypeScript, standalone Playtest template, Workshop 정규화/왕복과 공간 스키마, 순수 vector 안전성, terrain domain, oneWay, 환경 깊이/30맵 검증 및 인벤토리, 정확한17장 새/구 데이터 경계와 기존11장 모든 보존층, 기존2막 의미·생성·목표와40개 주동선, 동굴 전환 회귀, 전체 migration. 최초 환경 인벤토리 stale과17장 옛 mutation 예외 메시지 차이는 각각 생성문서 갱신과 좁은 테스트 호환으로 해결했다.

`npm run verify`는 빌드/타입/Node 게임 검사 이후 Chromium의 `socket() failed: Operation not permitted`에서 중단됐다. 이 제약을 다른 브라우저 옵션이나 접근 경로로 우회하지 않았다. 실제 `tests/integration.py`, Game/Stage View/iframe Playtest·모바일·브라우저 성능과 Pages 조작은 검증되지 않았다. 이를 전체 verify 통과나 배포 완료로 표시하지 않는다.

두 HTML은9fd34bb의 별도 깨끗한 checkout에서 같은 의존성을 재사용해 재빌드했고 원본과 SHA256이 일치하며 git diff가0이었다. 이후 변경은 검사/문서에 한정된다.
