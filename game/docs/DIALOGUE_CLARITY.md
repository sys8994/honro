## 9→10장 인과

9장의 첫 받이진 설치 뒤 등장 대사에서 받는 대상은 **소단의 붉은 실 망에 붙잡힌 원혼**이다. 양쪽 진 설치는 부분적인 부담 완화이며, 소단이 가운데 줄을 놓아도 안전하다는 증명과 구분한다.

- 소단은 주민을 살리려는 목적은 같다고 직접 말한다.
- 폭포의 줄을 푼 뒤 다른 줄이 당겨졌던 일 때문에, 일행이 자기 줄에 손대는 일을 불신한다.
- 따라오면 바깥 주박으로 막고 다치게 할 수도 있다고 명시한다. 적 진영의 공격과 경고 대사를 같은 보호 목적/불신으로 연결한다.
- 일행은 원혼을 붙든 가운데 줄은 보존하고 자신들을 공격하는 바깥 주박만 걷는다.
- 10장 협력 대화에서 소단이 **의도적으로 놓은 혼이 사람에게 붙지 않고 진에 들어가는 것**을 확인한 뒤 나머지도 놓겠다고 선택한다. 이후 고의로 다치게 한 책임을 인정하는 대사는 유지한다.

## 검사와 증거

`npm run test:dialogue-clarity`는 현재 문장의 고정 delta, production App/model, 화자 목록, 서사 공개 경계, 연출 연결, 9장 퇴장, 새/옛 소단 보호 대사를 검사한다.

- `tests/fixtures/dialogue-clarity-before.json`은 기준 커밋의 별도 runtime을 실행해 채집한 원본이다. 현재 runtime을 기준 디렉터리에서 실행하는 것으로 대체하지 않았다.
- 798개는 raw map 후보·덮어쓰기 이후 대본·runtime dispatch를 함께 모은 **소스 발생 위치 수**다. 고유 문장 수나 실제 플레이에서 발화되는 횟수가 아니다. 잘못된 route ID 문자열쌍은 제외했다.
- 150개의 수집 위치, 143개의 고유 수정 문장을 확인했다. 30장 전부와 30개 쉼터 문맥, 막 종료 쉼터를 읽기 검수했다. 문장 교체가 필요 없었던 1/4장 본문도 검수에 포함한다.
- 모든 비문장 필드와 페이지 수를 기준과 비교하며, 허용 delta 외의 새 문장을 넣으면 거절하는 부정 대조군을 포함한다. 과거 fixture는 바꾸지 않는다. 역사 회귀에 필요한 경우 정확히 일치하는 승인 문장만 원문으로 역투영한다.
- 기존 `story-canon-v01`의 12장 gameplay hash 실패는 기준 소스에서도 동일 hash로 재현된다. 이번 수정 때문에 발생한 11장 문장 비교만 정확한 prose delta로 되돌려 비교한다.
- DOM/Canvas/오디오 대역의 계약 검사, Native 연출 화면 검수, 정상 전투 진행, 브라우저/CSS 가독성, 전체 verify와 master/Pages 배포는 각각 별개 증거다. 이 문서의 읽기 검수는 정상 30장 연속 플레이나 공개 배포 확인을 뜻하지 않는다.
