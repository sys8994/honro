# 몬스터 노드 예산 v2 / 1차 개선 체크포인트

앱 원본: `01e939ad8e4986be1d98aa8321c6202376df9178`. 사용자가 기준으로 선택한 들린 장승(`warden`)은 319노드이며 원형/관절/모션을 변경하지 않는다. 사이즈 보정 비교는 본체의 실제 채색 높이를 128px로 통일한다. 체급, 피해, 배치, 이벤트는 이번 변경 범위가 아니다.

## 예산
- P = 외곽 및 빈 공간의 경계 길이, E = 대비 있는 내부 경계의 가중 길이. 기존 도감과 같은 Lab/알파 가공으로 계산.
- 정수 목표 T = round(1.572 × (P/6 + E/10) × 역할 배수). 1.572는 장승의 319 / (676.4/6 + 901.9/10)이다.
- 적합 [ceil(.8T), floor(1.3T)]. 역할: 일반 1.0, 6-8 독립 괴이 1.3, 한태록 빈 갑주 및 호환 거신 1.5, 빈 상여·종지기 1.65, 혼류의 앞발 1.75, 피날레 보스 대도사 2.2. 동일 자산 재사용은 중복 통계에 넣지 않았다.
- 기존 적 58개 기준 적합 9 / 부족 40 / 과다 9; 보너스로 들어 있는 아군 소환수 8은 적 작업 범위 밖이다. 호환 분기는 목록에 포함했으나, 정상 캠페인의 주 대상보다 후순위다.
- 정규화 높이 128px의 미술 검수 도구다. 실제 게임 프레임 비용, 보스 클로즈업, 장식 승인 여부를 대신하지 않는다. 저노드 판정은 '동일 좌표 중간점 추가' 지시가 아니다. 단순 기하가 의도됐으면 근거를 남긴다. 노드 수는 M/L 및 Q/C 끝점을 세고, 제어점은 별도다.

## 1차 적용 및 한계
- 기존 일반 몬스터 부족 23개: 재질 입체감과 공격 도구의 구조를 보강했다. 궁귀·문지기·별초는 궁시와 갑주를, 저복잡 괴물은 역할을 읽는 굴곡이나 소재를 보강했다. 형상 보강만 했으며 피벗·기존 리그 계층·모션·크기·조준 경로는 고정이다.
- 2막/3막 전용 부족 12개: 빈 상여, 빈 갑주 2종, 석등귀, 인양틀 5개만 구조를 보강했다. 다른 7개는 수레·수차·곡괭이의 반복 구조 또는 이미 동작/층을 갖춘 연출을 검토했고 숫자 상승만 위한 선을 더하지 않았다. 일부는 새 작업 후에도 숫자 하한 미달이다.
- 과다 9개: Act 6 여덟 종과 점복무녀의 미세 색조각과 복잡한 영역을 간소화했다. 목표 값까지 밀어붙였을 때 천, 단청, 금속층이 평면이 되는 경우에는 덜 강한 안을 골랐다. 표는 이전 그림 기준의 동결된 예산과 비교이며 합격 선언이 아니다.
- 호환 분기 5개는 원형을 보존한 상태로 남겼다. 임의로 노드를 보충하지 않았다.
- 후속: 실제 장의 모바일/PC 확대 상태에서 문짝 창살/단청, 상주 앞팔과 겹치는 어깨, 문턱 꼭두의 겹갑, 원혼의 옷과 매듭을 다시 본다. 길이 기준과 차이가 여전히 큰 항목은 똑같이 반복 삭제하지 말고 중간 면/관절 구조를 다시 작도한다.

## 부족 기준 완화: 65~130% (사용자 후속 지시)
