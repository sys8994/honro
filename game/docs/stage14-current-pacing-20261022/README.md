## 최소 개편 후보 — 미적용

1. 상·중층 고정 처치 gate와 바로 뒤 구조의 국소 위협 조건이 겹친다. 고정 제압은 R7/R13, 구조는 R9/R17에 끝났다. 실제 접근을 방해하는 위협만 구조 조건에 흡수하고 별도 고정 처치 gate를 제거하는 후보가 우선이다. 주민 구조·혼 약화/소단 분리·보호 실패 규칙은 보존한다.
2. 세 구조의 직렬 순서는 지나온 장소를 미리 해결하는 선택을 막는다. 병렬 구조 허용 또는 하층 구조와 피난 다리 단계 묶기를 검토할 수 있다. 구조 인원/서사 축소는 부모 결정 사항이며 이번에는 바꾸지 않았다.
3. 보호4라운드와 마지막 지역 정리는 앞선 구조 뒤에 추가된다. 이번엔 직접 재지 못했으므로 삭제 필요를 확정하지 않는다. 마지막 지역 위협을 보호 종료와 함께 판정해 중복 목표 표현을 줄이는 정도가 최소 후보다. 현행은 이미 위층 추적/모든6증원 입장 대기를 요구하지 않는다.
4. 지도 평탄화·전역 능력치 상향 대신 중복 gate부터 줄인다. CF 하강, 좌우 일반 회귀로, 집 마당·다리 지지면, 근접 전위와 원거리 사격점 선택은 보존한다. 자동 정책의 회복 도주를 필수 퀘스트 비용과 섞지 않는다.
