# 몬스터 개편 · 1~50장 변경표

기준은 5막과 서낭나루·돌당골을 포함한 master `2fdf345e9`다. 브라우저에서 현재 캠페인 프로필을 기준으로 새 전투를 생성했다. 초기 적은 적군 유닛에서 퀘스트 표적과 예비 증원을 제외한 수다. 표의 패턴 수는 새 전투에서 지정된 초기 개체 수이며, 실제 사용 횟수와 구분한다. 패턴이 부여된 기존 종은 평소 공격도 유지한다.

신종과 중간보스 원형은 기존 스폰 ID에 걸어 둔다. 좌표, 충돌 크기, 비행 여부, 목표 ID, 초기 총수, 증원 조건 및 행동 상한은 보존한다. 5막은 인계안의 종 배치 범위 밖이며, 검수한 피날레와 하늘우물 편성을 그대로 유지한다.

1~4막에서 집계한 정예 표식은 **165→127기**다. 99기에 거대한·불붙은·저주받은·굶주린·대장 중 한 변이를 지정했다. 중간보스, 장비 보상 대상과 장별로 별도 튜닝된 일부 정예는 본래 역할을 유지했다. 일반화한 정예의 HP와 공격력은 해당 장의 기존 정예 배수를 제거한 값이다.

## 재현과 저장 경계

- 비전투인 2막 9장과 4막의 보호된 장은 전투 규칙 버전을 올리지 않는다. 나머지 1~4막 중 전투가 있는 장의 새 전투에만 버전 1을 기록한다. 이어하기는 저장된 유닛, 패턴, 체력, 목표 상태를 사용한다.
- 1막 9장의 도깨비불 셋은 동일 우물 지지면의 기존 3자리를 사용한다. 4막 3장 물귀신은 갯길 마른 지지면에 두었으며 좌표 기준 최고 수위보다 약 205 위다.
- 열 종의 초기 자리는 엔진 지형에서 사선이 열리고 영웅이 서서 대응할 수 있는 범위가 있는지 확인했다. 점복무녀의 지원군 두 자리, 도깨비불 셋의 합체 사선, 시종 꼭두의 상여 정착지 두 곳 사선도 확인했다. 이 검사는 실제 조우의 완주 시간을 측정하지 않는다.
- 추격체의 현재 이동은 안전한 지지면을 따라가는 짧은 돌진이다. 낭떠러지를 가로지르는 실제 도약은 적용하지 않았다.
- 배치·계약 비교는 `python tests/monster-rework-roster.py <baseline.json> --mode baseline`과 `python tests/monster-rework-roster.py <candidate.json> --compare <baseline.json>`으로 수행한다. 준비된 신규 전투 50개의 유닛 ID·위치·몸 크기·목표·증원·행동 상한을 비교한다. 종별 공격과 실전 완주 결과는 별도 검수 기록을 따른다.
