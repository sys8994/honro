## 위험 지점 확인

- 10장 모두 브라우저 새 전투 진입에 성공했다. 입장 안정화 뒤 초기 전투 적은 접지 또는 의도된 고정/비행 상태였다. 페이지 예외는 관찰되지 않았다. 장별 전체 화면과 주요 군집 진입 화면을 따로 찍어 비교했다.
- 2장: 공중 네 기 모두 현재 지형에서 `HONRO_CORE.flightClear`가 참. 서쪽 적 피격을 설정한 브라우저 체크포인트에서 경고 직후 공중조 자격은 0, 새 대기 행동 직후 4였다. 이미 경고가 나온 교전에서의 반응을 확인한 것이며 일반 플레이 호송 완주 기록은 아니다.
- 19장: [V4 저작 코드](../../../shared/runtime/act23-v4-act3.js#L49)가 적 팀과 이벤트를 명시적으로 제거한다. [작별 및 표식 조건](../../../shared/runtime/act23-v4-act3.js#L81-L94)은 세 혼을 보낸 뒤 이송 흔적을 확인해야 충족된다. [혼 배우](../../../shared/runtime/stage19-farewell.js#L13)는 `side:2`, `honroVisualOnly:true`다. 개시 0기는 누락이 아니다.
- 45장: [기존 브라우저 체크포인트](../../../tests/act5-encounter-browser.py)로 차단 전위 → 상여 접근 → 결속 → 상여 → 후위 순서를 검사했다. 예비 5기 등장 뒤 Continue를 비교했고, 적 19기가 살아 있는 상태로 실제 승리 UI까지 진행했다. 표적 피해와 위치를 놓은 체크포인트여서 일반 플레이의 난이도·처치 라운드 증거는 아니다.

결론: 변경이 필요한 P2 배치 결함을 재현하지 못했다. 현재 로스터·좌표·기술·발동·목표를 보존했다. 10장 전체 일반 플레이, 정상 성장의 처치 라운드, 모바일 가독성, 스케일 후속 패치까지 확인했다고 주장하지 않는다.
