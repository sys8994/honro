# 몬스터 배치 P1-1 — 15장 구현 기록 (2026-11-24)

- 인계: `HONRO-P1-1` 패키지(START-HERE·stage-cards·15-stage-baseline·opening-evidence).
- 기준 master: `e93d606bd`(30장 자연 암면·지도 리비전 반영 이후). 30장은 최신 지형에서 다시 재고 배치했다.
- 공통 원칙:
  - 적 ID·종·기술·보상·목표 연결은 그대로 둔다. 바꾼 것은 위치, 고정 여부, 웨이브 등장 지점뿐이다.
  - 총원과 활성 상한은 그대로다. 46장만 같은 반응이 반복되던 두 기의 종을 바꿨다.
  - 하부 채우기, 전역 섬멸 필수화, 지형·공통 AI·스탯 변경은 하지 않았다.

## 구현 위치

- `shared/runtime/p1-placement.js`(신규): 저작 단계 author `HonroP1Placement`.
  - 새 캠페인 전투에만 적용한다(`initialState.honroP1PlacementRevision=1`). 진행 중인 저장 전투는 저장된 배치를 그대로 쓴다.
  - 지원면 윗선 위로만 옮긴다. 지원면·ID가 없는 프로젝트 변형에서는 그 장을 건너뛴다(`HonroP1Placement.skipped`).
  - 장마다 `design.p1Placement.reason`에 군집별 이유를 기록했다.
- `shared/build.mjs`: 모델 파일 목록과 `projectAuthors` 끝에 `p1-placement`/`HonroP1Placement`를 추가했다.
- `shared/runtime/encounters.js`: 9장 복제(`-cluster`) 위치를 저작값으로 받도록 했다. 이전 1·2·3·4·6·7·10장과 같은 방식이며, `honroP1PlacementRevision===1`인 경우에만 적용한다.
- `shared/data/act5/encounters-late.mjs`: 46장 원본 두 기.
