# 기예 상세와 전장 상태 표시

2026-09-29 · HBUG-046 / HBUG-047

## 기예 시연

`shared/runtime/skill-preview.js`는 공유 Engine·HonroScene·캐릭터/몬스터 에셋으로 작은 평지 전투를 만든다. 기존 허공터의 5600×2300 배치와 별개인 **시연용 전장 구성**이며, 이동·충돌·탄도·피해·진목·소환 판정과 그림은 본게임을 그대로 호출한다. 별도 물리 루프나 Workshop 렌더러는 없다.

- 플레이어에게 제공되는 사용 기예 64개를 시연한다. 상시 기예 20개는 문장과 성장 수치를 제공한다. 미습득 기예의 시연은 경지 1, 습득 기예는 현재 경지를 쓴다.
- 시전자·표적·비행·파문 도형의 범위를 기준으로 카메라를 맞춘다. 시연 카메라는 일반 맵 경계 클램프를 적용하지 않아 사방으로 퍼지는 도형도 중앙에 놓인다. 보통 사격은 낮은 탄도를 먼저 검증하고, 검술은 근접 표적, 반사파는 돌벽, 회신참은 앞뒤 표적, 동심파는 원주상의 표적을 둔다.
- 전로시 선회, 빙호 수동 기폭, 파산격 급강하, 파진연격 후속 검술, 정심 후 사격, 응수세 반격, 축지진목 이동, 호신검막의 투사체 흡수를 실제 API로 실행한다. 회생진목과 수호령은 다친 동행을 둔다. 소환귀의 실제 행동 차례도 진행한다.
- 표적은 효과를 볼 수 있는 충분한 체력을 가지며 시전자 공격력은 고정한다. 시연 피해 숫자는 현재 캠페인 장비·성장 조합의 예상 피해가 아니다.
- 프로필을 복제하고 시연의 save/message/audio 이벤트는 실제 앱에 전달하지 않는다. 시연의 효과 이벤트만 Scene으로 보낸다. 게임의 저장·진행·기력·성장을 쓰지 않는다.
- 보통 7초, 소환·원혼비·백귀야행은 11초마다 전투만 재생성한다. 모달/캔버스/스크롤 위치는 유지한다. 닫을 때 시연 참조를 해제한다.
- `preview-label` 문구는 생성하지 않는다. 캔버스의 접근 가능한 이름은 기예 이름과 ‘시연’이다. 큰 선택 화살표는 시연에서 생략한다.
- 세로 화면은 한 열, 낮은 가로 화면은 설명/시연 두 열과 아래 성장표를 쓴다. 모달 한 곳에서 스크롤하며 하단 장착/강화 버튼까지 도달할 수 있다.

## 설명과 성장 비교

`skillLore.ts`의 서사 문장은 `.skill-desc`에 남긴다. `skillNotes.ts`의 `skillPlayNotes()`는 바로 아래 `.skill-mechanics`에 특수 능력·보너스·주의할 작동 조건을 짧은 플레이어 문장으로 쓴다. 캐릭터 대사로 넣지 않는다. 실제 시간·반격·수동 입력 같은 사용 조건은 필요할 때 설명한다.

`skillGrowthRows()`는 기존 `skillEffectRows()`에서 경지 1~8 중 값이 바뀌는 항목만 골라낸다. 도중에 같은 값을 유지하는 구간은 성장 항목으로 남긴다. 봉쇄진목의 중복된 유지시간은 한 번만 표시한다. 최대 경지는 같은 값 두 개를 나란히 반복하지 않는다. 급소시/절명시/치명 강화의 작은 치명 배율 성장은 소수 둘째 자리까지 표시한다. 계통 위력 가산은 개발용 계수 대신 퍼센트 포인트로 표시한다. 허공터 선택창도 같은 요약과 성장 항목을 쓴다. 기본기/단일 경지 비기는 빈 성장표를 만들지 않는다.

수치 원본 API는 기존 검사·다른 소비자를 위해 유지한다. 플레이어 설명을 작성할 때 판정식을 다른 곳에 복제하지 말고 실제 기예 구현과 함께 확인한다.

## 전장 상태

`HonroCombatStatus.entries(b,u)`가 상태별 아이콘 키·이름·상세·횟수·색을 제공한다. `effects()`는 기존 유닛 정보창을 위한 문자열 호환 API다. `reason()`의 기절/기력/재사용/공중/행동 완료 판정은 유지한다.

- 모든 진영에 같은 그래픽: 기절 별, 결박 사슬, 감속 얼음, 저주 문양, 보호막/수세 테두리. 머리 위에는 최대 세 개의 고정 화면 크기 아이콘과 추가 개수를 표시한다.
- 저주에는 지속 피해·공격/방어 약화, 이간에는 동료 공격 대상 노출을 설명한다. 표식·방어 붕괴·착지 보호·호신검막·축기·정심·후속 검술·합세·주천·이탈보도 상태 목록에 포함한다.
- 하단은 상태 이름 하나와 추가 개수만 보인다. 누르거나 키보드로 열면 모든 상태와 지속시간, 정확한 현재 행동 제한을 읽는다. 일반 설명이 없는 경우 ‘상태’ 버튼에서 확인한다. 적/동맹은 기존 개체 정보창에서도 같은 문장을 읽을 수 있다.
- 현재 턴에 소비된 기절과 다음 행동에 적용될 기절을 구분한다. 만료/치료 후에는 아이콘과 상세를 제거한다. 동행 전환 시 이전 동행의 펼친 상세를 닫는다.
- Canvas 경로를 캐시하고 필터·임시 캔버스를 추가하지 않는다. DOM은 상태 서명이 달라질 때만 갱신한다. 렌더러는 전투 데이터를 변경하지 않는다. 저장 스키마나 상태 효과의 규칙을 바꾸지 않는다.
