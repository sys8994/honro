열 파일 모두 XML 파싱과 브라우저 원본 렌더를 확인했다. 내장 래스터는 0개다. 22·28장은 문서의 700,000B 권장 상한을 넘는다. 21장 런타임 암반 자산은 189,172B다. 이 PC에서는 Inkscape 실행 파일을 찾지 못했다. 다운로드 및 실행 요청은 자동 정책 검토에서 거부됐다.

21·29장 후보는 격리 Chromium에서 데스크톱과 844×390 화면을 확인했다. 21장은 현재 레벨 권장 성장으로 진입한 별도 프로필에서 키보드로 보행·도약·급락시 발사 후 재로드·이어하기가 일치했다. 기존 완주 스크립트는 기준판과 후보 모두 적 18명 기대와 실제 26명이 달라 멈췄다. 후보 2장의 신규 완주·정산은 미확인이다. 두 후보는 공개 빌드에서 비활성이다. 현재 공개 소스와 동일한 빌드에서 21~30장 진입 및 초기 목표 표시를 확인했다.
