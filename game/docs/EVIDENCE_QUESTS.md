문서는 해당 사건의 대화가 전달될 때만 `profile.honroEvidenceDocuments`에 등록한다. 문서 내용/획득 ID로 중복 보관을 막고, 원문을 읽는 일은 목표·보상·퀘스트 함수로 되돌아가지 않는다. 기존 지도/장부/메모 모달을 여정의 기록에서 열며 확대·스크롤·키보드·터치·닫기를 공유한다. 기존 진행 저장의 필수 문서 모달은 그대로 복원한다.

쉼터 수집 목표는 추가하지 않는다. 새 revision의 3막 쉼터는 장소 설명 뒤 같은 장의 필수 배경 서술을 반복하지 않고, 실제 출발 준비 대사는 유지한다. 기존 쉼터 대화는 저장된 revision과 페이지 인덱스로 복원한다. 선택 회고 대화는 남긴다.
