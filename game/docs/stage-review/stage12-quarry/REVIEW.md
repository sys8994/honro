## 진단과 실제 변경

[설계 카드](DESIGN.md) 기준으로 현행 지형·이야기·길표 조사/상하 출구·참가자와 편성을 먼저 확인했다. 오른쪽 옛길 → 상부 채석면 → 뒤쪽 굽이/중앙 길표의 짧은 경로와 서쪽의 긴 순환이 이미 연결돼 있다. 상부 출구는 수비대를 제압하는 교전, 하부는 열린 내리막으로 빠지는 선택이다. 필요한 고유 구조를 보존하고 새 발판·적·기믹을 추가하지 않았다. 전술 동선 개선을 새로 구현했다고 주장하지 않는다.

실제 화면에서 하부 기반의 넓은 단색 면과 전체 폭에 늘어난 공통 명암 도형, 동굴 천장 아래 구분을 보완했다. 하부 경사별로 서로 다른 선반/측면을 저작하고 길표 아래에는 중간 크기의 연결된 층리 면을 넣었다. 천장에는 보행 테두리를 새로 그리지 않으며 하부 음영을 구분했다. 기존 북/서 채석면과 나무·길표·수레·상부 작업굴 입구·이미지 원경은 보존했다. 생성/편집 이미지나 실패 교정 브랜치 구현은 사용하지 않았다.

별도로 author 재실행에서 두 보존 문제가 실제 드러났다. 전체 schema 정규화가 다른 장의 scene 주석을 바꾸려 해 안전 검사에서 중단됐고, 이를 제거하자 최신 두 출구/이야기/장식/수비 역할을 옛 보호·전멸 계약으로 되돌리는 차이가 보였다. 후속 objective/narrative 저작자가 소유한 데이터를 보존하도록 수정했다. 최종 author2회는 30장·Library 전체 동일하며 실제 CLI도 바이트를 쓰지 않았다. campaign/elements/vector-campaign-parts는 기준 master와 diff가 없다. 따라서 구전투 폐기나 map revision 변경도 하지 않는다.
