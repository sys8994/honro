# 10장 거목의 매듭·천 봉헌 장식

기준 master: dca0b847c511c6bdf5cd3e7cb837895f59262168. 부모의 한국 사찰 마당 참고 및 설계 지시에 따른 벡터 렌더 수정이다. 사진/이미지 생성·편집은 하지 않았다.

- 기존 거목의 실루엣·발판·충돌·전투·이야기·성장 데이터는 보존한다. `act1-spatial-art.js`의 기존 Stage10 나무 landmark에만 장식을 그린다.
- 여러 높이의 줄 12개, 불규칙한 길이의 삼베색/회백색 천과 소수의 탁한 적갈색 묶음. 줄기 안쪽의 조밀한 축적과 가지 끝의 성긴 무리로 나눈다. 매듭은 원형 고리/겹친 매듭/굵은 교차 묶음을 섞는다. 일본식 종이 장식이나 축제 색상은 넣지 않는다.
- 장식은 기존 나무와 동일한 뒤쪽 렌더 순서이며, 소단 머리·주박 목표 주위는 비워 둔다. 정적 경로는 나무가 실제 그려질 때 한 번 생성해 재사용한다. 다른 장이나 인트로에서 미리 경로를 생성하지 않는다.
- 집중1: 실제 일반/전체/근접/상부/모바일/가로 화면을 열어 확인. L1 정책에 의해 경로 외곽선으로 만든 줄/매듭이 누락되는 결함을 발견해 불합격.
- 집중2: 줄/매듭을 채워진 벡터 형상으로 수정. 일반·근접·상부 실제 화면에서 연결을 확인. 반복 나비 모양과 일부 떠 보이는 끝을 발견해 변형과 실제 가지 부착을 보완했다.
- 집중3: 최종 형상의 모바일·최대축소·일반·근접 화면을 직접 열어 목표/소단/발판 가독성을 확인했다. 완전 축소에서는 천과 줄/매듭 무리의 큰 실루엣을 읽을 수 있다.

최종 동일 소스 종합 캡처 및 정상 보호전 회귀 결과는 아래 증거 디렉터리에 추가한다. 부모가 실제 화면을 확인하고 통합 순서를 정할 때까지 master 반영/배포는 대기한다. 이번 변경은 장식 보완이며 11장 완성이나 전체 캠페인 검수 합격 선언이 아니다.
