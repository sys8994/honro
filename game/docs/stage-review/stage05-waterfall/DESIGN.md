# 5장 — 폭포 틈의 한 발

기준 master509ed75a. 설오·담허가 물길진/사격턱에서 협력해 폭포 뒤 주박목을 부수고 한 라운드 물길을 안정시킨다. 담허 이탈은 물살 복귀, 담허 사망은 실패. 휘겸은 동행 전투 인물이 아니며 이후 운반대 이야기 연결을 유지한다.

큰 절벽·깊은 연못·낙수와 탄의 상호작용·연못에서 서쪽으로 돌아오는 지형은 기존 전면 개편의 강점이므로 보존한다. 현재 실제 화면에서 이미지 원경이 동굴 안까지 비치는 오류를 확인했다. 이미지 원경이 기존 background()의 동굴 벽을 생략한 것이 원인이다.

이번 변경 범위는 원경 위/물살과 주박목 뒤의 기존 동굴 뒷벽 복원이다. 동굴 아래 개방된 낙수 공간을 어두운 사각형으로 막지 않도록 바닥높이에서 한정한다. 지형·적·기믹·스토리 데이터가 그대로라면 battle revision을 올리거나 구전투를 폐기하지 않는다. 모든 장 데이터의 일치와 현재 저장의 유지, 실제 열린/닫힌 물살과 목표 완료를 검증한다. 정상 플레이에 문제가 있으면 미술 교정과 분리해 보고한다.
