# 5장 폭포 — 기존 개편 보존과 미술 연결 교정

후속 감사에서 아래 author idempotence 실패의 재생성 위험을 수정했다. 기존 검사는 완화 없이 통과했다. 상세 원인/47개 차이/재검증은 [AUTHOR_REPLAY_AUDIT.md](AUTHOR_REPLAY_AUDIT.md)를 참조한다. 아래는 최초 교정 당시 기록이다.

기준509ed75a, 최종 런타임/빌드 b77aa82a. 기존 큰 절벽, 깊은 연못, 서쪽 복귀 경사, 물길진/사격턱, 담허의 유지 기믹과 주박목을 보존했다. 전30장 authored project와 library가 변경 전과 정확히 같다. 적 편성/배치·전투 수치·충돌·물리·이벤트는 변경하지 않았다. 이번 결과는 기존 장의 미술 오류 교정이며 전면 재설계가 아니다.

## 수정과 실제 픽셀 검수

1. `baseline` / `review1`: 이미지 원경 제공자가 기존 Stage5 background()의 동굴 뒷벽을 생략한 것을 확인. 원경 하늘이 주박목 방 안에 비쳤다. 같은 로컬 뒷벽 그리기를 이미지 위에 복원해 실제 화면 비교.
2. `review2`: 열린 폭포와 확대 화면에서 뒷벽이 입구 밖/바닥 아래로 돌출하는 것을 발견. 실제 동굴 입구 윤곽으로 한정했다. 이때 열려 있는 물살 옆에 닫힌 물살의 검은 와이어 윤곽이 남는 것도 발견.
3. `review3`: fluid sheet를 solid terrain readability 윤곽에서 제외. 일반/확대/최소 줌/세로/가로와 개방/복귀를 직접 확인. 실제 물살·body collider는 그대로이며, 가짜 단단한 외곽선만 제거했다.
4. `final` / `final-combat`: 최종소스 b77aa82a에서 별도 종합. 실제 최소 줌0.21176, 모바일390×844/844×390, 열린/복귀한 물살과 주박목 파괴 화면을 직접 열었다. 이미지 끝/빈 공간 및 뒷벽 돌출/닫힌 윤곽 잔상 없음. 대화 종료 후 캡처. Library `libfile_fdb096aac254819189d0c4902530b7a1`.

## 플레이 및 검사

- `tests/stage5-refinement.mjs`: 최종 all30/library 정확 일치, 설오·담허의 물길진↔사격턱↔시작 왕복, 닫힌 낙수의 실제 화살 감속/주박목 무피해, 열린 물살에서 실제 A01 명중. 이동은 적을 분리한 유한 입력, 사격은 준비 위치 fixture이며 정상 전투와 구분.
- `tests/stage5-waterfall-continue.mjs` 통과: 기존 진행 중 지형/내구도/flags를 Continue/import에서 정확 유지하고 retry 시 현행 맵 사용. 미술만 바뀌어 map revision을 올리거나 구전투를 폐기하지 않았다.
- `tests/pre-image-terrain-restoration.mjs`, `tests/stage4-positioning.mjs`, 최종 빌드 통과. 1~3장을 포함한 다른 장의 데이터도 정확히 보존.
- 정상 브라우저: 1~4장 완료 보상만 생산 progression으로 적용한 진입 fixture(연속 캠페인 플레이 아님). 기본 A01/M01, 정상 HP/집중/이동, 실제 AI·미션, 이동/사격/상호작용/방어 입력. 자원·위치·목표 강제 재설정 없음.
- 최종35라운드 승리. 주박목 사격6회, 실제 파괴와 안정화 이후 완료. 설오2/469HP, 담허7/503HP, 적14명 잔존. 물길진 유지가 피격/이탈로 풀려 재상호작용11회. 5장 완료 저장과 다음 쉼터 연결을 결과창에서 확인했다. 낮은 HP이므로 난이도가 충분히 편하다고 주장하지 않는다. lower-beasts 경고는 발생했으나 진입점 점유로 해당 파동의 출현은 이 실행에서 증명하지 못했다.

## 실패 및 제한

초기 진입부에 머무는 정책은8라운드 담허 사망으로 실패. 접근하되 목표를 우선하지 않은 정책은 설오 사망 후70라운드 미완. 원시 상태를 `failed-policies`에 보존했고 통과로 계산하지 않았다. 비종료 상태에서 결과 UI를 부르는 검사 스크립트 문제도 발견해 종료 상태일 때만 outcome()을 호출하도록 수정했다. 실패 정책의 결과 UI는 완료 증거에서 제외했다.

기존 `tests/stage5-lake.mjs`는 첫 단계의 author idempotence assertion에서 실패한다. 현행 프로젝트 전체가 변경 전과 정확히 같음을 별도로 확인했으므로 이번 렌더 수정으로 생긴 데이터 차이가 아니다. 해당 역사 재저작 검사는 수정하지 않았고 관련 이동/탄도는 현재 데이터로 별도 검증했다.

기존 적의 가까운 쌍 배치와 왼쪽 지표의 큰 면은 남아 있다. 이번에는 좋은 고유 지형을 유지하고 명확한 미술 연결 결함을 고쳤다. 모든 기예/난이도, 낙수 하단 전구간 정상 전투, 모든 파동 출현·전30장 완주를 합격 처리하지 않는다. Actions/공개 Pages의 기존 Forbidden/403 제한은 재시도하거나 우회하지 않았으며 master push와 배포 성공/공개 픽셀 확인을 구분한다.
