## 별도 결함·완료 범위

부모의 기계적 진단에서 확인한 배수 접촉 결함을 이 브랜치에서는 수리하지 않았다. 준비된 배수 후 원래 배우 위치 그대로의 읽기 전용 검사에서 `a2-enemy-15` `(6210,4553.207547169811)`/`a2-enemy-17` `(5890,4749.411764705882)` 모두 `validContact:false`다. 원본 battle/배우 exact는 유지한다. 기존 Continue의 좌표 정규화 문제는 부모 보고이며, 이 작업에서 정상 Continue/배수 안전 전이를 통과로 선언하지 않았다. 시각 fixture는 이미 드러난 ledge 상태를 입력하므로 별도 점유/안전 위치 전이 검사를 대신하지 않는다.

별도 기계적 수정 브랜치를 병합하지 않았다. 최종 통합에서는 부모가 최신 배수 점유/안전 전이 코드를 보존하고 이 helper의 시각 필드만 재적용해야 한다. 현재 d55 campaign/manifest 전체로 최신 수정본을 덮는 인계가 아니다. master/Pages는 부모 최종 미술 판단·통합 이후 별도다.

전체30장/전체 verify·무관한 실패 수리·정상 A/B 전투 완주·배수/저장 안정화 검사는 하지 않았다. 실제 수행은 fresh UI/카메라·서로 다른3집중+최종 종합과 명시적 배수 시각 fixture, 변경 관련 불변/재현/정적 재사용에 한정한다. Library 원본 전송은 실패했지만 허용된 d55 UI 대체 기준을 확보했고, 나머지 구현/커밋/푸시는 차단 없이 보존했다.
