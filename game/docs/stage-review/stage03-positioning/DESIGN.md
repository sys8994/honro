# 3장 · 나루의 남은 장부

기준671ec7becd224ca1c197b8356676767c33955337. 기존6500×3100, 나루/화물/지붕/저지대 고유 구조 보존. 잔교와 화물 단차는 설오·담허 기본 이동으로 이미 무피해 접근 가능하므로 새 발판·지형을 추가하지 않는다.

- 이야기/참가: 설오·담허가 홍만의 장부를 회수한다. 휘겸 NPC, 침수된 나루장승과 기존 세 사건을 보존한다. 장부 상호작용 및 기존 철수 안정화 조건 유지.
- 핵심 질문: 잔교 상부에서 아래의 장승을 겨눌까, 하부 물길에서 담허의 기예와 이동을 쓸까? 창고 비탈을 따라갈까, 적재대와 지붕 사선을 선점할까?
- 변경: 같은 상부 보행면의 지붕 두께만34로 축소해 건물 앞 암판처럼 보이는 겹침을 줄인다. 목재 잔교/화물과 지붕 재질을 구분한다. 적 총원/정예/HP/증원 예산을 유지하며 하부 추격·비탈 전위·적재대와 지붕 견제를 서로 다른 위치에 배정한다.
- 보존: 모든 지형/배우/사건/장부 ID, 바닥·지붕 위쪽 좌표, 원경, 카메라, 성장, 스토리. 실패 미술 교정 브랜치 코드는 사용하지 않는다.
- 확인: 3회 실화면 집중+최종 종합, 상하 경로와 실탄, 정상 자원 실제 적 활성 장부 확보/철수, 변경3장 구전투만 재시작, 다른29장/library 동일 및1·2장 회귀.
