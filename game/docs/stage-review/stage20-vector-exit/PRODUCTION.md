# 20장 동굴 출구 지형 미술

범위: 지형 스킨만. 원본9000×5800, 영웅92, floor143점·overhang74점·선반4점×2, 모든 호송/쉼터/출구 동선과 배우·스토리·장비·카메라·원경 보존. 보조선반·호송물·움직이는 기계는 추적 자산에서 제외.

공정: 원본 및 authored 실효 지형 대조 → 정확한 폴리곤 가이드 → 프롬프트 사전 저장 → 이미지 생성 → 원래 배우 배율 검토 → 명시적 고정 팔레트 → 실제 Inkscape → 내부 컴포넌트 추출 → 접지/극점 보호 최적화 → 동일 canonicalSolid/contactInset 합성1×/2× → 정상/모바일/외곽/호송구간 화면 비교. 생성 이미지와 SVG를 충돌 도형 대신 사용하지 않음.

실패와 재발방지:
- 평면색 요청에도 생성PNG에는 미세 명암이 남았다. 팔레트 경계가 주색 가운데를 지나면 미세 노이즈가 벡터 수천 노드로 증폭된다. 첫 동쪽 추적691357B 및 엔진240000문자 제한 거부를 보존했다. 제한 상향 금지; 원본 주색 분포를 확인하고 이미지 재평면화 후4색으로 다시 추적했다.
- 팔레트 정리는 미술적 손실 변환이다. 원본/실패 추적 보존, 이후 확정RAW와 최종SVG의 오차만 별도로 검증한다. 이미지 대비 무손실이라고 하지 않는다.
- 지역 자산 외곽에 닿는 원본 컴포넌트를 통째 제외하여 사각 재질 접합을 피한다. 하부·양끝은 전체 지질 원본 스킨이 연속 지지한다. 새 좌표로 바위나 가림막을 그리지 않는다.
- 보호대 폭이나 합격 임계값을 늘려 통과시키지 않는다. 최적화기의 원본보존 영역72소스px는 비교검사 보호대 변경이 아닌 최적화 제한 강화다.

네이티브 렌더 검수는 브라우저·플레이·게임성 통과를 뜻하지 않는다. 해당 검수와 배포는 통합 담당자가 별도로 수행한다.

최종 미술 정리: 팔레트 변경만으로 남은 잡티를 해결하지 못해 비의미적 내부 광물톤 마스크에만 반경3소스px opening/closing 후 실제 Inkscape 재추적. 최초 외곽 마스크는 무변경, canonical 경계±12소스px는 원본 마스크 유지. 픽셀면적/연결성분 제거·추가수를 각 레이어에 기록. 눈코입·표식·장치·배우·지지대가 없는 순수 광물톤 소스에만 적용. 원본RAW와 정리RAW는 별도 보존한다. 이 단계의 손실을 이후 최적화 오차로 숨기지 않으며 정상배율 전후 화면을 별도 비교한다.
- 입력 마스크 정리는 가장자리를 몇 픽셀 안쪽으로 이동시킬 수 있다. 기존2px 경계접촉 제외만 사용하면 원래 이미지 끝에 붙던 컴포넌트가 내부 도형으로 오인되어 사각 접합을 만든다. 생성소스 경계16px 이내 컴포넌트를 제외하고 연속 전체지질 underpaint로 연결한다. 정리 전후 동일 규칙 적용.
- 전후 증거를 만들 때 작업 디렉토리의 변경 중 RAW를 복사하지 않는다. 불변 pre-clean trace에서 별도 입력 디렉토리를 재구성하고 같은 import/clip 루프로 렌더한다.
