## 실제 변경

기존 주요 암반은 세 종류의 독립 돌 몸체가 여러 줄로 복제되고 사이에 녹색 바탕이 드러났다. 기존 암면의 밝은 면·절리·층리 요소는 유지하면서, 주요 9개 지질 덩어리에서는 개별 돌 외곽/클립을 제거하고 연결된 암반 바탕 위에 지형별 노출면을 저작했다. 주요 깊은 절리는 한 덩어리당 하나로 제한하며, 발밑 근처는 중간 크기의 면으로 읽히게 깊이를 제한했다. 입구/북쪽 경계 밖도 같은 지형 안에서 이어진다. 작은 기존 바위·목재 가지 미술은 보존한다. 공통 암면 요소를 사용하는 보완이며 모든 면을 새로 그린 전면 재설계라고 주장하지 않는다.

별도로 공개 author가 이후 밀도 보강에서 보존한 `wave-hold-knots`(6730,6736)를 과거 기본값으로 덮어쓰던 재생성 위험을 수정했다. 현행 밀도 revision이 소유한 마커를 보존하며, 의미상 동일한 데이터는 원래 파일 형식/바이트도 다시 쓰지 않는다. 30장과 모든 Library 자산을 포함한 두 번의 author 동일성 검사가 통과했다.

## 미술 검수

초기 추상 면/붙인 노출면 초안은 넓은 단순 면·패치 느낌 때문에 내부 불합격으로 폐기했다. 최종 후보는 기존 벡터 암면의 장점을 보존하는 방향으로 좁혔다.

1. 전체 형태/연속성/지지: 서쪽·중앙·하부 overview를 직접 열었다. 개별 돌 몸체의 붙인 경계와 녹색 빈 띠를 제거했고 실제 아치/통로/뿌리 지지를 보존했다.
2. 디테일/가독성/깊이: 입구·중앙 근접·주민 터·수관 연결부 실제 화면을 열었다. 보행 경계·캐릭터·목표와 비충돌 원경을 구분하고 기존 큰 나무 형태를 보존했다.
3. 카메라/모바일/상태: 서/동 경계 최대 축소, 세로 주민 터/중앙, 가로 뿌리 연결부를 확인했다. 별도로 실제 정상 진행 저장의 매듭 전/보호 후/하강/승리 상태를 브라우저 Continue로 열어 확인했다.

별도 최종 종합은 최종 소스 커밋에서 다시 촬영한다. 공통 암면 구성요소의 반복 인상이 완전히 없거나 모든 장 미술이 합격했다고 주장하지 않는다. 부모가 최종 화면의 미술 적합성을 판단한다.

- R33 정체: 가까이 도달해도 동쪽 매듭 좌표로 계속 모이던 검사 정책이 사격/접근을 방해했다. 실제 상호작용 수비대 우선과 도달 거리 조건을 고치자 R34 해체, R38 보호 완료로 이어졌다.
- 하강 정체: 검사 그래프가 겹친 one-way 뿌리 아래 anchor를 같은 x의 걷기만으로 도달할 수 있다고 가정했다. 실제 하강 입력 대신 뿌리 끝을 걸어 내려와 서쪽으로 돌아가는 정상 입력을 사용했고 R48에 전원 하부 지면 도달. 기존 main/root-return 입력 경로 검사도 네 클래스 모두 통과했다. 이것을 맵 충돌 결함으로 단정하지 않았다.

실제 승리 저장을 production App에 Continue해 보상·성장·장착·중복 보상 방지·export·12장 진입을 검증했다. 첫 검사 기대값은 정상 완료 보너스 XP를 누락해 실패했으므로, production completion의 정상 지급을 포함해 기대값을 바로잡고 보상 예산/중복 지급 방지까지 확인했다. 테스트만 완화해 게임 결함을 숨긴 것이 아니다. 실제 브라우저에서도 저장 5개의 좌표/HP/자원 불변, 승리 결과·쉼터·12장 버튼 진입을 통과했다. 59라운드 전체는 네이티브 입력 진행이며 전체 브라우저 재생이라고 주장하지 않는다.
