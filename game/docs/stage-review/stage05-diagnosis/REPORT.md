1. **먼저 배치/각성을 5장 단위로 명시한다.** 초기20/행동4를 바로 깎기 전에 복제 후 최종 지지면·군집·입구를 저작한다. 물길진 위 한 전망대의 멧돼지/궁수 중첩과 전원 초반 각성, 군집 이름과 실제 방어 위치의 불일치를 우선 조정 후보로 삼는다. 연못 너머 접근 불가능한 곳에 적을 밀어 넣어 여백으로 포장하지 않는다.
2. **초기 선택 지형 하나에 실제 차폐/우회 대가를 만든다.** 현재 전망대의 반사/원거리 사선은 보존 후보이나, 기본 지상 적이 그대로 고지 공격을 할 수 있다. 같은 수의 적을 두고 바닥/고지 선택의 피격·표적·퇴로가 달라지는 짧은 비교가 먼저다. 원래 waterfall 저작의 암반 어깨가 lake 경로에서 사라지는 소유권부터 정리할 필요가 있다.
3. **진 유지 위치의 선택을 별도 검토한다.** E 반복 문제는 아니다. 의식 담당이 하부 좁은 위치에 묶여 기예/위치를 바꾸는 폭이 작은 문제다. 기존 “담허가 진을 벗어나면 물살 복귀”와 목표/서사는 보존하며, 진 안의 엄폐/반사면이나 선택 가능한 사선이 실제 달라지는 최소안을 검토한다.
4. **증원 문구와 capacity 대기를 일치시키는 후보.** 현재 한 라운드 예고 후에도6자리 부족이면 무기한 대기할 수 있다. 수량·cap·승리조건을 바꾸기 전에, 예고/입장 상태를 정확히 전달할지 검토한다. 그 뒤에도 체감이 과밀하면 초기 인원 감축/유한 분산안을 별도로 비교한다. 이 진단은 특정 새 인원수를 승인하지 않는다.
