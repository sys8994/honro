## 변경과 픽셀 검수

- x0/4300에서 끝나던 면과 정확한 수평·수직 색 띠를 제거했다. 카메라 외곽까지 이어지는 비대칭 큰 암층, 깊은 절리, 서로 다른 방향의 중간 돌출 암반으로 뒤 절벽을 구성했다. 작은 균열이나 같은 돌 복제로 채우지 않았다.
- 회색 상판/블록의 별도 칠을 제거하고 실제 암턱과 뒤 암면에 같은 월드 암층 경로를 사용했다. 실제 암턱의 밝은 보행 테두리와 암면 밖으로 노출된 충돌 옆면은 유지한다. 뒤 암면 안쪽에서 블록 전체를 둘러싸던 검은 외곽선만 잇도록 바꿨다. 예외는 새2장 바위턱7개뿐이며 다른 장의 윤곽선은 보존한다.
- 도로 뒤 긴 단색 띠를 낮은 암반 밑동·불규칙한 돌 무리·성긴 풀·접촉 음영으로 바꿨다. 배우보다 먼저 그려 상여/적 실루엣을 가리지 않는다. 시각 장식에 보행용 밝은 테두리를 그리지 않아 실제 도로/발판과 구별한다.

집중1회(`review1`)는 전체 연결과 도로 접점을 직접 확인했고, 남은 공통 검은 블록 테두리를 찾았다. 집중2회(`review2`)는 근접 암턱/모바일의 재질과 실제 접촉선을 보고 안쪽 윤곽선을 교정했다. 집중3회(`review3`)는 고지 근접/동쪽/모바일 최대축소에서 긴 지그재그가 기계적으로 반복되지 않도록 암층을 서로 다른 덩어리로 나눠 확인했다. 모두 실제 production browser 캡처이며 중간 상태라는 metadata를 유지한다.

최종 소스에서 별도8화면(`final`)을 촬영하고 전체/도로 양 끝/고지/둥지/모바일 좌우/가로 구도를 모두 직접 열었다. 새 도입 대사에서 고지 설오와 왼쪽 상여가 같이 보이는 구도와 실제 R3 저장 재개 화면도 직접 열었다. 부모의 미술 통과는 아직 없으며 횟수만으로 합격 처리하지 않는다.
