# 5막 저승이 닿은 산 · 목표 동선과 교전 설계

기준판은 master `25094081a`다. 작업 지시는 5막 인계 ZIP의 `plan/honro_act5_plan.md` v1.0 및 현행 장별 사건을 보존하면서 실제 목표 동선에 개입하는 교전을 보강하는 것이다. 원안의 20R 초과 상단과 현행 설계의 21R 상단은 이번 실측 목표에서 20R로 조정한다. 20R은 설계 상한이다. 연출상 시험 진 유지에 있는 기존 적 턴 한 번 외에 라운드 대기를 추가하지 않는다. 사용자 실측은 각 장 1회다. 이전 문서의 Chromium 자동 입력 1회 수치와 독립적으로 다룬다. ## 설계 카드

전 장은 설오·담허·휘겸·소단 네 동행 기준이다. 이동·사선에 쓰이는 실제 지형과 원경은 유지한다. 기존 입구·장 순서·상호작용 ID·대사·일지·승패 플래그·보상은 이어 사용한다. 출구는 현재와 같이 생존 동행 2명(9장 1명, 마지막 생존자 1명 예외)이 도달하면 완료한다. 표의 수직·복합은 기존 실제 동선 분류다. 동선 변경 없이 분류 수를 채우지 않는다.

6·7장의 원안은 진법 발견·실패가 중심이다. 발판 좁은 곳의 정예 수를 기준에 맞추려고 늘리지 않는다. 이번 장별 중간보스 수에서는 화면에 예고와 응답 방식이 있는 대상을 센다. 일반 정예, 장무율 주 보스, 기믹 대상은 별도로 기록한다.

## 구현과 측정 정의

- 이전 전투는 저장된 `honroMap.act5.encounterVersion`과 배우·HP·위치·목표를 사용한다. 신규 진입·명시적 재시도에 새 편성을 적용한다. 배치 개편으로 캠페인 맵 revision을 올리지 않는다.
- 적 턴 행동 상한, 초기 생존 전투원, 유한 예비대, 살아 있던 전투원 최대치, 실제 행동한 서로 다른 적을 각각 기록한다. 기믹 파괴물·동행·보호 대상·잠든 예비대는 초기 전투원에 포함하지 않는다.
- 실효 교전은 주경로에서 그 적에게 피해·제압을 가했거나, 피해를 받거나, 실제 피할 수 있는 공격을 보고 위치·행동·기예를 바꾼 경우를 개체 ID로 중복 제거한다. 처치와 직접 목표 처치, 교전은 독립 집계다. 빗나간 표적 없는 탄·제자리 대기·도달 못 한 접근은 행동 기록에 남겨도 실효 교전에서 제외한다.
- R은 결과가 보여 주는 아군+적 주기 번호다. 적 피해·실패와 재시도, 보조 정책 1회와 사람 직접 입력 표본을 별도로 기록한다. 유저 제공의 직접 플레이 라운드/처치 순서는 `8/7, 5/7, 11/11, 6/8, 6/7, 미제공, 3/5, 7/7, 11/16, 미제공`이다.
- 참고 기준은 적 6~8 실제 행동, 중간보스 8~9개 장·12~15체, 수직형 최소 5장·복합형 최소 4장이다. 현재 원안의 장소별 역할과 실제 정량 검수에서 벗어나는 장은 결과에 이유와 함께 기록한다. [배치 기준](ENCOUNTER_PLACEMENT.md) · [교전 검수](ENCOUNTER_ACCEPTANCE.md) · [제작 SOP](STAGE_PRODUCTION_SOP.md)

## 확정 편성과 Chromium 실측

아군과 NPC를 제외한 실제 전투원이다. 합법 성장 기준인 각 장 진입 XP·훈련 12점·습득 기예를 적용한 격리 프로필에서 새로 진입해 정산까지 진행했다. 조준·이동 정책이 Chromium의 실제 엔진 입력·충돌·AI·미션·정산을 실행했다. 전투원 좌표나 피해를 준비하지 않은 연속 실행이다. 별도의 키보드·버튼 집중 검수와 사용자 직접 실측은 이 표에 합치지 않았다. 실효 열은 양측 HP·보호막에 실제 영향이 확인된 적의 고유 ID 수다. 피해가 없는 방어·우회 선택까지 포함하면 늘어날 수 있다. 행동 열의 중앙값·최대는 발사, 화면에 표시된 패턴 실행, 실제 접근이 관측된 적 페이즈 표본을 기준으로 한다.

군북·군패·상여 결박은 파괴 기믹이며 처치 열에서 제외한다. 장무율은 중간보스 합계에서 제외한 주요 보스다. 중간보스는 **8장에서 10기**로, v3 참고안 12~15기보다 적다. 진법 시험이 중심인 6·7장에는 추가하지 않았다. 일반 적에게 실제 피해를 낸 동행 행동 수는 대표 초반 표본의 중앙값이 2~4회였다. 작은 범위 피해와 저항을 포함한 값이며 1~2회 기준을 모든 종·기예에서 실측으로 달성했다고 볼 수 없다.

2·3·4·5·8·9·10장의 기본 표본은 초안 하한 미달이고 6장은 초안 상한보다 2R 길다. 기본 표본 열 장은 모두 20R 안에 들어왔다. 8장에서 근거리 선택 적을 추가 제압한 표본은 22R/14처치/23교전으로 20R 설계 상한을 넘었다. 4장의 빠른 쪽도 실제 피해 교환이 20기 이상이고, 10장은 동일 편성에서 회복·돌파 선택이 생존 인원을 늘렸다. 1·3장은 교전 초안 상단을 각각 1·2기 넘었다. 플레이어 직접 표본과 동일 조건으로 재측정하지 않았으므로 개선폭의 차이는 정책 효과를 함께 포함한다.

### 증원과 경로에서 본 것

- 1장은 천막 뒤와 옹벽 입구가 각각 1·10R에 경고와 입장했고, 각 입구 첫 행동을 같은 R에 확인했다. 도식은 옹벽 굽이까지 살아서 대피했다. 2장은 군북 경고 3R, 진입 4R, 행동 4~6R이며 세 호송 대상이 대피했다. 군북이 꺼지면 증원이 생략되는 조건을 유지했다.
- 3장은 갑주 넷이 10R에 들어와 10~12R에 행동했다. 장무율의 사격 예고와 대응, 군패→비살상 제압→소단 분리를 확인했다. 해당 표본에서 곽진은 HP 9로 생존해 경계가 빠듯했다. 4장은 아래 골과 위 뿌리 모두 오른쪽 합류턱을 지나 승리했다. 아래에서 올라타는 위 뿌리 발판은 초기 위치부터 실제 D·Ctrl 입력으로 별도 확인했다.
- 5장 상여 증원 다섯은 6R에 출현했고 생존 적이 8R부터 행동했다. 살아 있는 도식을 직접 겨누던 적의 선택을 제한해 하산 장면을 보존했다. 6장은 담허가 첫 석단에서 떨어져 서쪽 낮은 석단에 착지한 뒤, 두 표식 사이를 직접 걷고 다른 목적지 이름의 밧줄로 복귀했다.
- 7장 역류 두 입구는 11R 다섯 기, 생존자의 실효 행동은 11~14R이었다. 8장은 제한 진 이후 8R 두 입구 다섯 기, 행동 8~13R과 수면흉 예고·도구 회수를 관측했다. 빠르게 진행한 준비 정산에서는 선택 증원 일부가 점유 대기 상태로 남았다. 9장은 10R 다섯 기, 첫 행동 11~13R이었다.
- 10장은 석교 전투 전에 계단 사격조의 조기 개입을 늦췄다. 참조 공격 입력을 12%→11.1%로 조정했다. 기본 표본은 두 곳이 예고하되 비어 있던 동쪽 편대 두 기만 5R 들어와 6~7R 행동했다. 회생진목과 회풍참을 섞은 표본은 다른 입구를 비워 네 기 모두 5~6R 입장·행동을 확인했고 네 동행이 모두 생존했다. 두 표본은 산문 정산 라운드·완료 플래그를 브라우저 새로고침에서 복원했다.
- 10장 구판은 회풍참 뒤 석교 y=1976에서 산문 아래 y=1339로 복귀했다. 수정판은 y=1976 발판으로 돌아왔다. 9장의 원래 상층 복귀는 확인한 사격 각도에서 재현되지 않았다. 새 코드에서 하층 회풍참 추락 후 같은 징검길 y=4880 복귀와 선행 조건 없는 계단 입력 차단은 확인했다. 구판 버전 4의 6장 전투는 기존 세션·배치·HP·좌표·목표 그대로 이어졌다.
