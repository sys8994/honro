## 승인된 목표와 보존 범위

사용자는 현재 복잡도 개선을 인정한 뒤 “이번 스테이지를 완성도높게 마무리하고, 그 다음 후보 스테이지를 골라서 개선하자”, “몬스터 배치 원칙 다시한번 상기하고 그거 반영해서 개선해”라고 요청했다. 그래픽이 무엇인지 알아보기 어렵고 몬스터가 등간격·저밀도로 보인다는 피드백을 이번 완료 기준에 포함한다.

- [캠페인 적 배치 기준](ENCOUNTER_PLACEMENT.md)을 따른다. 전체 적 숫자나 통과한 검사 수를 공간·전투 품질의 대리 지표로 삼지 않는다.
- 11장 안에서 나무/뿌리/암반의 읽힘, 아군 진입, 적 역할군집, 보호 대상/동맹의 위치, 예고와 전투 진입을 개선한다.
- 기존 일곱 목표와 정보 공개 순서, 주민 보호, 살아 있는 혼을40% 이하로 약화한 뒤 소단 E, 반경680/4턴/잔향6, 잔적 전원 제압 및 북쪽 흔적의12장 연결을 보존한다.
- 다른29장·기존 공통 스킬/몸체/물리/스키마를 바꾸지 않는다. 전체 지형 확장이나 다음 후보 장 재작업은 이번 마감 범위가 아니다.
- 기존 진행 저장은 저장 당시 지형·미술·편성·이벤트·진행을 유지한다. 새로운 렌더 또는 이벤트 동작은 새 진입용 명시 revision으로 구분한다.
- `master` 및 기존 Pages와 진행 브랜치를 구분한다. 원격 저장·검사 통과·배포·실제 공개 검수는 각각의 상태로 보고한다.

## 검수 방법

1. 수치·군집명에 앞서 근접 장면에서 각 적이 무엇을 지키는지와 단일/범위 공격·다른 층의 대응이 실제로 가능한지 확인한다. 군집별 실제 좌표, body 접지·겹침, 사격 연결과 빈 연결 구간을 기록한다.
2. 경지10은 정상1–10장 기준20,571XP를 사용한다. 정식 수련/장비 설정 뒤 실제 선택·이동·기본 도약·사격·방어·E·대화·tick만 허용한다. 화면에 없는 아이템, 적 삭제, 강제 피해·목표 완료, 이후 HP/기력/이동력/XP/좌표 재주입은 금지한다.
3. 전체 완주에는 초기 위치·주변 적·진행을 잘라 놓은 대표 구간을 사용하지 않는다. 실패 시 입력 정책의 미숙함과 실제 막힘/불가능한 사선/과한 집중 피해를 구분하고 최초 문제가 생긴 턴·위치·적·상태를 남긴다.
4. 기존32경로·세 전술구간·M09 선택 지름길·국소 방어/구출 검사는 독립 회귀로 유지한다. 이 검사들이 새 전체 완주나 사람의 난이도 승인을 대신하지 않는다.
5. 브라우저 실행은 이 환경에서 Chromium socket EPERM으로 실패한 상태다. Native 그림·엔진 정상입력 결과와 브라우저 직접조작/모바일/성능을 혼동하지 않으며, 접근 제약을 우회하지 않는다.
