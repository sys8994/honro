# 30장 남겨진 길: 나루 방어 뒤 달라진 퇴로로 전원 집결

## 현재 전장의 선택

낮은 길은 새로 정착한 선체와 동쪽 착지 널판으로 돌아가며 F 궁수의 수평 사선을 상대한다. 높은 길은 D의 반사석을 발판으로 C 동쪽 어깨에 복귀한 뒤 E 능선을 지나며 후위 편대와 교전한다. 두 선택 모두 같은 G의 높은 옛길에 모인다. 배가 아직 기다리거나 정착을 취소해도 원래 높은 길은 열린다.

이 차이는 단순 지도상의 두 선이 아니다. `pressureVersion:2`의 보수적 rank1 정상 입력에서 낮은26/6은 F 기존 편대4발/129피해와 새 궁수2발/70피해, 높은26/6은 E 후위3행동/2발/71피해와 F 기존1발/71피해를 각각 상대했다. 높은 길에서는 낮은 F증원 궁수를 우회했다. 두 경로 모두 수비 완료 뒤 마지막 생존 동료 집결까지3라운드였다. 모든 군집을 강제 전투시키거나 잔적을 찾는 목표를 추가하지 않았다.

## 원래 임무와 저장 계약

세 목표와 서사/직업/후일담은 보존한다.

1. transport-map: 실제 상호작용 반경260, 같은 층 적220 이내에서 불가.
2. ferry-hold: 원래 산개3 증원을 포함해 유효한 적팀 종료3회. 동료 수비반경540, 적 contest230. 기존 진행은 contest 사이에 지워지지 않는다. 항상 연속된 세 전체라운드라는 뜻은 아니다.
3. old-road: 살아 있는 일반 동료 전원이 radius440, 발높이 차150 이내에 집결. 거리식 `hypot(dx,.75dy)`. 죽은 동료/소환/현혹 개체는 집결 인원에 더하지 않는다. 적 전멸·퇴로 점유 해제·배 정착 완료가 새 승리조건이 아니다.

새 NPC·강제2+2·4막공개·추가 직업 E·특수 기예 필수문은 없다. 과거30 진행 저장은 자체 지형과 편대를 계속 사용한다. 새 배 상태는 battle snapshot의 ferry revision으로, 후속 후위 필터는 저장된 spec의 pressureVersion2로만 적용한다. 이전 ferry spec이 없는/1인 저장은 원래 적 후보 의미를 그대로 유지한다.

## 배와 외곽둔덕의 안전한 변화

수비 진행1에 예고 → 실제 일반 동료에게 새 행동기회 제공/완료 → 진행2 이상과 안전 행동경계 및 점유 없음 →0.8초 시각정착 → 두 terrain snapshot의 broken 상태를 원자적으로 한 번 교환한다. 영웅·적·소환·진목·투사체·장·지연 영역을 실제 좁은 선체 쓸림polygon과 사라지는 둔덕/최종 선체에서 검사한다. 움직이는 배가 몸을 밀어내거나 배우를 순간이동시키지 않는다.

대사/modal/발사/검토/근접후속 등은 지연, 새 점유는 대기로 복귀, 승리는 미완료 변화를 취소한다. 저장/Continue를 반복해도 정착1회와 미생성 증원 의미를 유지한다. 공개 shortening 함수는 안전한 정착 애니메이션만 줄이며 대화 Skip으로 기다리는 배를 강제로 열지 않는다.
