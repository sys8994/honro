## Observable baseline differences

The SOUL aim preview correction affects existing battles, including non-Act-4: when a friendly actor blocks O01, the prediction now identifies that actor. In this master-based isolated fixture the actor lost 40.2 HP; the unblocked target lost 126 HP. Those are fixture values, not difficulty or full-play evidence. The live collision and damage policy were not altered.

The tidal-water geometry also excludes points where no finite floor exists, even without a selected floor ID. Previously such an unsupported sample could add `Infinity` to the visual polygon. This is a deliberate finite-geometry correction rather than strict preservation of that invalid default output; the legacy floor selection itself remains. Other native options have fallback fixtures, but general outside-world culling uses real bounds and can change rendering for artwork whose bounds metadata is inaccurate. These differences require integration review rather than a blanket no-change claim.
