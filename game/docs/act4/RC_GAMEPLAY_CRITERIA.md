# 4막 RC 게임성 검수 기준 연결

이 문서는 설계 기준의 출처와 남은 실측을 연결한다. 아래의 수치는 설계 목표이며 실측 완료나 자동 합격이 아니다. 사용자 표기는 4막 1~10장, 내부 ID는 31~40이다.

원문은 고정 commit `c8ff67fa6dd5103555523b6627ae9e113e43541a`의 [40장 설계 v3](https://github.com/sys8994/honro/blob/c8ff67fa6dd5103555523b6627ae9e113e43541a/game/docs/quality/40-stage-criteria-v3.md), [v2 기초 데이터](https://github.com/sys8994/honro/blob/c8ff67fa6dd5103555523b6627ae9e113e43541a/game/docs/quality/40-stage-criteria-v2.json), [v3 patch](https://github.com/sys8994/honro/blob/c8ff67fa6dd5103555523b6627ae9e113e43541a/game/docs/quality/40-stage-criteria-v3.patch.json), [31·34·39 frozen design](https://github.com/sys8994/honro/blob/c8ff67fa6dd5103555523b6627ae9e113e43541a/tools/act4-pilot/frozen-design-v3.json)이다. frozen design은 원문 v3 SHA-256 `e2183e74492a4cb61338f8a691a51f23e7af2205fb9148ae6f6b2c138311aa54`와 지리 우선 후속 분류를 기록한다. 기존 파일을 새 threshold로 대체하지 않는다.

| 기준 | 적용 및 현재 상태 |
| --- | --- |
| 원래 승리 조건·보호 대상·사건·저장 | 각 장 실제 UI에서 자연 진행, 목표와 보상 once, 저장과 복원을 확인한다. 개별 fixture 성공을 전체 완주로 확대하지 않는다. |
| 분량 | 전체 20턴 상한은 강제 패배 타이머가 아닌 설계·검증 예산이다. 한 번 20턴 안에 완료한 사실만으로 게임성 전체가 합격하지 않는다. 장별 목표와 반복 실측도 비교한다. |
| 난도·전투 | 일반 정책 성공률, 실제 행동한 적, 유효 피해와 막간 상승, 필수 경로 실제 교전·중간보스 행동/예고/대응을 확인한다. 처치 수와 교전 수는 다르며 0킬만으로 실패를 단정하지 않는다. |
| 공간·전략 | 지리와 서사에 맞는 고저차 및 실제 위치·사선·엄폐·우회·선택지를 검수한다. 후속 지리 우선 개정에 따라 점프·아래점프 횟수, 고도 수치, 발판 할당량은 참고다. 진행 불가나 충돌·실제 전술 결함은 여전히 필수로 다룬다. |
| 화면 | 실제 크기·모바일·줌·좌우 끝의 미술, 보호 요소, 끊김과 가독성은 별도 실측한다. 정적 캡처만으로 게임 완주를 주장하지 않는다. |

33·34·38·39는 빠른 통과 기록만으로 실효 위협과 대안 경로가 증명되지 않아 추가 실측이 필요하다. 36의 v3 원문은 필수 교전 4–8, 중간보스 0, 총 클리어 7–10턴을 제시한다. 별도 보고된 전투 2–4R 목표와 현재 후보 9체·전투 10R 사이의 차이는 근거와 측정 정의를 추가 확인한다. 교전과 배치 적 수를 같게 취급하지 않으며, 차이를 맞추려고 적을 임의 삭제하지 않는다.

RC 31·32의 확인된 결과와 원본 증거는 `tools/act4-rc/PLAY-RESULTS.md`에 있다. 다른 장의 최신 통합 runtime 정상 완주, 충분한 반복·초견성·전술·위협·모바일 실기기 검수와 관련 저장 회귀는 별도 gate다. 상세 원본 및 후속 개정과 실제 실행 입력/소스 hash를 비교하고 미완료를 보존한다.
