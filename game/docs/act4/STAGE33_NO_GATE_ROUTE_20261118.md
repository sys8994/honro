# 33장 축지진목 없는 출구 도달 검증

기준: 공개 master 1e043b09d4ce107e1d2dcf70fe2274dff7098476. 테스트 전용 branch audit/stage33-no-gate-20261118 최종 테스트 commit 817d2da752d633435f2598ccebc317830192b381. CI 44317103387 성공.

## 확인

최신 production Engine 및 원래 스테이지의 지형·캐릭터 초기 위치를 사용하여 네 캐릭터 각각 출구 (6705,1507.5) 15px 이내, 높이30px 이내에 일반 걷기·점프만으로 접지 도달했다. 축지진목을 포함한 스킬 호출, 좌표 이동 주입, 지형 변경은 없다. 각 캐릭터 HP 변화0.

경로: 낮은 갯길을 동쪽까지 걷기 → 동쪽 아래 계단 오르기 → 발판에서 왼쪽 위 계단으로 점프 → 계단을 다시 오른쪽으로 오르기 → 왼쪽 연결 발판으로 점프 → 중간 높이 보행면 → 왼쪽 위 경사로 → 상부 출구로 오른쪽 이동.

자동 입력 경로는 각24회 점프, 이동예산보충6~7회다. 최적 경로/최소 점프 수나 정상 클리어 턴 수가 아니다. 단순 오른쪽 걷기/반복 점프는 낮은 길 끝에 도착하고 출구와 약1500 높이차가 남아 실패했다. 경로의 좌우 전환을 알아보기 어렵다는 UX 검토가 필요하다.

## 검증 한계

이것은 각 캐릭터별 독립적인 실제 충돌·이동 API 검증이다. 이동 예산을 인위적으로 보충했고 적 턴과 조수 진행을 멈췄으며 초기 저수위만 사용했다. 실제 전투·적 공격·고수위 시간표·일행 동시 집결·출구 상호작용·보상·저장·실제 브라우저 입력의 정상 완주는 미검증이다. 따라서 '축지진목 없이 이동 가능한 경로 존재'는 확인했지만 '정상 게임플레이 클리어 검수 완료'라고 보고하면 안 된다.

처음 두 입력 시도 실패는 테스트 입력의 문제(뒤로 건너뛰기 전 점프 누락, 중간발판보다 높은 정상 착지 불인정)였으며 게임 지형을 변경해 통과시키지 않았다.
