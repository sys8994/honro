## 실제 수정과 사진

모든 사진은 로컬 Chromium의 실제 App/Engine/Scene에서 캡처했다. source/카메라/줌/해상도/배우 좌표는 각 `captures.json`에 남긴다. `_local/reports/act4-preview/` 아래에 보관한다.

1. `art-loop1`: 파란 하부 단색을 장별 재질로 분리하고 대나무 잎/분지 집터를 작성했다. 직접 본 결과, 연속된 세 층이 지층을 케이크처럼 만들고 보행로 지지 기둥이 위로 돌출됐다.
2. `art-loop2`: 하부 층을 비대칭 퇴적·토양 면으로 끊고 물골/첫 둑을 실제 geometry에 추가했다. 대숲에 잎 있는 굵은 차폐를 연결하고 폐촌에 빈 기단을 넣었다. 플레이 줌/모바일에서 기둥의 상단과 문이 문틀을 벗어나는 위치를 확인했다.
3. `art-loop3`: 지지 기둥 높이를 실제 지면–보행면 사이에 맞추고 문을 실제 열린 문틀로 옮겼다. 낮은 돌계단을 collision에 맞추고 지붕의 큰 빈 부분을 만들었다. 떠 있는 하부 색 사각형의 대비를 낮추고 지표에서 이어지는 면으로 수정했다.
4. `art-final`: source를 고정한 뒤 별도 종합 캡처. 전체 줌/플레이 줌/모바일 세로 9뷰에서 캐릭터를 합법 지지면에 둔 pose fixture로 접지·가독성을 확인했다. `art-baseline`은 `fe1e184a`의 원래 map factory를 같은 현행 공통 런타임/카메라/줌/해상도로 읽은 비교다. 두 묶음 모두 original profile 보존, 전체 지형 domain, grounded=true, render 전후 battle JSON 동일, pageerror0이다.

이 검수는 첫 세 장 미술 수정 묶음의 로컬 결과다. 정상 전투 완주, 4막 전체 미술 확정, 공개판 검증이나 정식 출시를 의미하지 않는다. 부모에게 실제 비교 PNG를 전달하며 이후 7개 장소의 작업을 이어간다.

## 필요한 범위의 실행 확인

- native terrain: 세 schema/domain, 26 초기 유닛의 300tick 접지/HP 안정, 세 주동선 연결. 이동량을 보충한 지형 fixture다.
- 35 분기: 아래 통로 실제 신체의 최소 머리 위 여유 56.3 world units, 기본 점프를 쓴 상부 차폐 통과. 각각 별도 제어 포즈에서 원본 Engine을 실행했다.
- native ballistic: 31 둑 뒤 A01 실제 하강 명중, 35 굵은 대 실제 차단과 옆 빈터 명중. hit/HP 결과를 주입하지 않았다.
- actual App/Story event fixture: 배 이동/도착 갑판/접지 집결과 미리보기 스냅샷, 문 종료 화면 관측/정적/재개, 사망한 미표시 행의 retired 분리, 실제 차폐와 우회 명중 뒤 비정지 bark 및 중복 없는 영수증.
- 최신 휴식터 regression: 원래 SVG, 동행 불투명/부재/사망 분리, split v1/v2 roster, 선택 대화·여정첩·Continue·모바일, rest 중 battle build 없음 통과.
- 관련 visual hierarchy, typecheck, Game/Workshop build 통과. 전체30장 자동완주는 실행하지 않았다.

남은 범위는 정상 교전/실제 이벤트 플레이, 32/33/34/37/38/39/40, 완성된 장별 성장/승패/Continue 정책과 전체 69행의 조건 연결이다. 물골은 얕은 기존 water-pool만 사용한다. 위험 물의 회수/점유 교착은 별도 미검증 의존성으로 정식 출시를 막으며, 이전 폭포 후보의 변경은 포함하지 않는다. 일반 진행은 기존 1–30을 유지한다.
