## 실제 수정과 사진

모든 사진은 로컬 Chromium의 실제 App/Engine/Scene에서 캡처했다. source/카메라/줌/해상도/배우 좌표는 각 `captures.json`에 남긴다. `_local/reports/act4-preview/` 아래에 보관한다.

1. `art-loop1`: 파란 하부 단색을 장별 재질로 분리하고 대나무 잎/분지 집터를 작성했다. 직접 본 결과, 연속된 세 층이 지층을 케이크처럼 만들고 보행로 지지 기둥이 위로 돌출됐다.
2. `art-loop2`: 하부 층을 비대칭 퇴적·토양 면으로 끊고 물골/첫 둑을 실제 geometry에 추가했다. 대숲에 잎 있는 굵은 차폐를 연결하고 폐촌에 빈 기단을 넣었다. 플레이 줌/모바일에서 기둥의 상단과 문이 문틀을 벗어나는 위치를 확인했다.
3. `art-loop3`: 지지 기둥 높이를 실제 지면–보행면 사이에 맞추고 문을 실제 열린 문틀로 옮겼다. 낮은 돌계단을 collision에 맞추고 지붕의 큰 빈 부분을 만들었다. 떠 있는 하부 색 사각형의 대비를 낮추고 지표에서 이어지는 면으로 수정했다.
4. `art-final`: source를 고정한 뒤 별도 종합 캡처. 전체 줌/플레이 줌/모바일 세로 9뷰에서 캐릭터를 합법 지지면에 둔 pose fixture로 접지·가독성을 확인했다. `art-baseline`은 `fe1e184a`의 원래 map factory를 같은 현행 공통 런타임/카메라/줌/해상도로 읽은 비교다. 두 묶음 모두 original profile 보존, 전체 지형 domain, grounded=true, render 전후 battle JSON 동일, pageerror0이다.

이 검수는 첫 세 장 미술 수정 묶음의 로컬 결과다. 정상 전투 완주, 4막 전체 미술 확정, 공개판 검증이나 정식 출시를 의미하지 않는다. 부모에게 실제 비교 PNG를 전달하며 이후 7개 장소의 작업을 이어간다.

## 필요한 범위의 실행 확인

- native terrain: 세 schema/domain, 26 초기 유닛의 300tick 접지/HP 안정, 세 주동선 연결. 이동량을 보충한 지형 fixture다.
- 35 분기: 아래 통로 실제 신체의 최소 머리 위 여유 56.3 world units, 기본 점프를 쓴 상부 차폐 통과. 각각 별도 제어 포즈에서 원본 Engine을 실행했다.
- native ballistic: 31 둑 뒤 A01 실제 하강 명중, 35 굵은 대 실제 차단과 옆 빈터 명중. hit/HP 결과를 주입하지 않았다.
- actual App/Story event fixture: 배 이동/도착 갑판/접지 집결과 미리보기 스냅샷, 문 종료 화면 관측/정적/재개, 사망한 미표시 행의 retired 분리, 실제 차폐와 우회 명중 뒤 비정지 bark 및 중복 없는 영수증.
- 최신 휴식터 regression: 원래 SVG, 동행 불투명/부재/사망 분리, split v1/v2 roster, 선택 대화·여정첩·Continue·모바일, rest 중 battle build 없음 통과.
- 관련 visual hierarchy, typecheck, Game/Workshop build 통과. 전체30장 자동완주는 실행하지 않았다.

남은 범위는 정상 교전/실제 이벤트 플레이, 32/33/34/37/38/39/40, 완성된 장별 성장/승패/Continue 정책과 전체 69행의 조건 연결이다. 물골은 얕은 기존 water-pool만 사용한다. 위험 물의 회수/점유 교착은 별도 미검증 의존성으로 정식 출시를 막으며, 이전 폭포 후보의 변경은 포함하지 않는다. 일반 진행은 기존 1–30을 유지한다.

## 부모 v1 불합격 뒤 수정

Library 비교본 v1은 부모와 독립 미술 검수에서 세 장 모두 불합격이다. 위 세 차례 로컬 검수는 최종 미술 승인으로 간주하지 않는다. 지적은 하구 분기 부재, ㄱ자 발판, 떠 있는 지붕, 시작 배치 사진의 혼동이었다.

- 31: L1 수면이 L2 모래톱을 덮던 순서를 수정했다. 굽은 퇴적 혀와 비대칭 갈대섬을 수면 앞에 두고 낮은 물골을 실제 지표에 넣었다. 깊은 검은 띠는 표층 침식 면으로 낮췄다. 시작 배는 원경 크기에서 선착장 접근 크기로 이어진다. 입장 카메라는 실제 배·선착장·첫 적을 차례로 렌더한 뒤 검수 문구를 연다.
- 35: 상판/기둥 두 구조를 제거하고 바닥에 이어진 흙 선반과 깨진 돌계단으로 바꿨다. 기존 ‘아래 통로 최소 56.3’ 검사는 제거된 옛 구조의 역사 기록이며 현재 기준이 아니다. 현재 두 구간은 도랑–흙 계단/낮은 담 접근의 실제 이동과 기본 점프로 검사한다. 뿌리는 지표의 밑동에서 낮게 갈라진다. 배경 대는 낮은 대비로 분리했다.
- 36: 주 건물은 왼쪽 지붕을 기둥에 붙이고 오른쪽 붕괴면은 바닥에 걸쳤다. 나머지는 문틀만/탄 골조/빈 기단으로 나눴다. 무너진 담은 보행면 뒤 잔해로 낮추고 충돌 엄폐를 제거했다. 외곽 정예는 실제 warden HP/공격 증가로 적용했다.
- 초기 검수에서 적 `archer`가 플레이어 직업 데이터를 쓰던 편성 오류를 고쳐 `possessedArcher/possessedGuard`를 사용한다. 초기 아군은 원래 좌표 그대로이며 첫 적과 최소 수평 간격은 770/840/600이다. 기존 미술 사진은 조준 위치를 강제한 pose fixture다. 실제 초기 배치는 별도 `initial-and-cover/*-initial-*.png`로 구분한다.

새 사진은 `art-correction-F`의 같은 카메라 9뷰와 `initial-and-cover`의 실제 초기 desktop/mobile 6뷰다. 별도 차폐 증거는 신체 겹침 없는 합법 접지 위치 x3040/x3350에서 5도·0.2 A01을 실제 발사한 blocked/open aim+impact 사진이다. 31 하강 명중은 실제 적 크기에 맞춰 45도·0.5로 측정했다. hit/피해 결과는 주입하지 않았다. native terrain, ballistic, 초기 300tick/차폐 검사를 통과했다. 부모의 다음 미술 판정은 대기하며 일반 캠페인은 닫혀 있다.

## Library v4 판정 뒤 좁은 보완

부모의 독립 픽셀 검수에서 35 지지된 계단/경사로, 36 지붕 접점/폐허 변주, 정상 시작 적 간격은 통과했다. 이 형태를 보존하고 다음 두 P1 및 작은 접점만 수정했다.

- 31 모래톱은 분기와 갈대 단서를 유지하면서 높이와 띠 폭을 낮췄다. 같은 L2 수면 평면에 얕게 놓고 끝부분의 물색/침수 경계로 기존의 매달린 S 띠 인상을 줄였다. 충돌 지형/물 정책/배 사건은 바꾸지 않았다.
- 31/35/36 모바일 시작에만 진행 방향을 포함하는 짧은 구도를 둔다. 정상 네 인물과 31의 다음 둑/물길, 35의 계단·돌담, 36의 첫 적·폐촌 문틀이 한 화면에 들어온다. 실제 이동/선택 이후에는 기존 추적을 쓰며, 사용자가 수동 줌/팬을 조절하면 시작 구도 강제를 종료해 그 선택을 보존한다. 전역 카메라/다른 막은 수정하지 않는다. 시작 상태의 전용 저장/재개도 같은 구도를 보존한다.
- 35 큰 돌담은 기존 충돌과 방향을 유지하고 지면에 붙은 작은 부서진 돌로 하단 접촉을 보강했다. 36의 기울어진 목재 끝은 작은 파손면과 발치 조각만 추가했다. 빈 마당은 유지한다.

`act4-first3-art-followup.py`는 배우를 재배치하지 않은 정상 초기 3장의 실제 모바일 화면을 촬영한다. 300tick 이후 원래 좌표/HP, 접지, 24px 이상 인물 크기, 다음 지형/위협 단서의 화면 포함, 저장/재개, 수동 줌 보존, 실제 이동 후 native follow 복귀를 확인했다. `act4-terrain-preview.mjs` 연결 지형/35 분기와 `act4-preview-ballistics.mjs` 실제 곡사·대나무 차폐/우회도 통과했다. 루트 빌드의 엔트리는 기존 `game.bb473a1851feb03e.html`로 동일하다.

제출은 같은 Library ID `libfile_cbc7d05a8a388191abd5356345c9e5ff`의 버전 5다. 31 시작 동일 카메라 전후/확대와 31·35·36 원래 시작 모바일 전후에만 집중했다. `_local/reports/act4-preview/art-followup/results.json`에 카메라/배우/단서/소스 해시를 보존했다. 부모의 최종 미술 판정과 정식 캠페인 개방/공개 검증은 별도이며, 이 후보에서 31–40을 일반 진행에 열지 않았다.
