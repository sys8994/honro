# 4막 지형 미술 인계 통합

기준 소스와 공개 빌드는 e57736aa25bdf5b55c06ff2748e0b7f24c7217a2다. 4막 1~10장은 내부 31~40장이다. 첨부의 장별 좌표 등록과 조립 SVG를 사용했다. 현행 월드의 충돌, 유닛, 목표, 이벤트, 수면, 카메라, 보상과 맵 revision을 기준으로 삼았다.

| 4막 | 적용한 미술 | 현행 플레이·검수 초점 |
|---|---|---|
| 1장 | 하구 흙둑과 승선 접근로 목재를 기존 암반과 계단에 연결 | 접안, 계단 접근, 갑판 접지, 전원 승선 |
| 2장 | 흙마당과 집 세 채, 문틀과 별도 움직이는 문짝 | 하층 12개 지형, 등불 비행 상한 520, 문턱과 재회, 안전 7명 |
| 3장 | 갯길 접촉면을 기존 암반과 조수 그림에 연결 | 예고, 고조, 저조 복귀와 상부 우회 |
| 4장 | 절벽 접촉면을 기존 굴 천장과 좌우 지질에 연결 | 오버행, 점프, 사선과 동굴 연결 목격 |
| 5장 | 대숲, 뿌리 흙비탈, 옛 돌담, 나무 통로와 별도 원경 | 세 빈터와 측면 경로, 차폐·사선 |
| 6장 | 폐촌, 목조 지지대, 집터와 별도 원경, 쓰러지는 문짝 | 마당 통행, 문 밀기와 전원 집결 |
| 7장 | 다져진 운송길, 석축, 난간, 도르래와 갈대 | 짐길 경사와 기존 구조 신호 관측 |
| 8장 | 해식굴 접촉선을 현행 굴과 구조용 받침 위에 연결 | 굴 천장과 바닥, 탐침·담허 연결과 우회 |
| 9장 | 해변 접촉선을 기존 폐선, 그물, 동적 조수 위에 연결 | 포격 예고, 그물 해제, 주민 네 명 이동과 고지 집결 |
| 10장 | 같은 부두 기둥 네 곳에 목조 가새 벡터를 재사용 | 현행 42적 최종전, 조수, 배와 고지 귀환 |

조립 SVG는 제작 참조다. 실제 레이어는 현재 SVG importer로 다시 생성한다. 원경 두 장은 별도 WebP로 빌드한다. 미술 레이어는 충돌과 상호작용을 추가하지 않는다. 예전 미술 ID와 내용은 각 장의 지연 로딩 묶음에 남아 진행 중인 전투가 그대로 해석된다. 새 전투부터 인계 자산을 사용한다.

```sh
python tools/act4-vector-production/import-handoff.py /path/to/HONRO_ACT4_HANDOFF shared/data/act4/handoff-art
npm run build
```

## 적용 검증

- 공식 author 적용 후 소스와 발행용 장 JSON 모두에서 미술 필드를 빼고 기준과 동등함을 확인했다. 2장 지형 12개와 등불의 배치·비행 범위, 10장 42적과 조수·승리 설정을 포함한다.
- 새 벡터 23개는 기존 런타임 제한과 장별 BODY 참조 검사를 통과했다. 40장 기둥은 비균등 월드 등록과 원래 네 배치를 합성하고 하나의 내부 심벌을 네 번 사용한다.
- 2장 비행 범위·하층 이동·문짝의 이전 방식과 새 방식, 5장 차폐, 6장 문, 7장 신호 접근, 8장 동굴 사건, 9장 구조 경로, 이동 갑판, 정산 조건, 저장 자산 서명의 집중 엔진 검사를 실행했다.
- 브라우저 완주·정산과 공개 검수는 장별로 실제 실행한 기록에 따라 판단한다. 새 장 진입, 이전 저장 이어하기, 현재 저장 이어하기는 서로 다른 확인이다.
