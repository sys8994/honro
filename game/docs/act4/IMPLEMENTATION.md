# 4막 지형 미리보기 · 진행 기록

2026-10-27 첫 구현 단위. 승인 시안 원본 4개를 실제 픽셀로 확인했으며 Git blob SHA는 `README.md` 인계값과 일치한다. 부모의 최신 계획 및 검수 완료 대사 JSON이 입력이다.

`tools/act4/preview.html`은 기존 Game/App/Engine/Scene과 map v6 compiler를 사용하는 별도 검수 진입점이다. 31·35·36은 일반 캠페인에 등록하지 않는다. 기존 30장 전투 예산을 **명시적인 fixture**로 빌려 작성한 지형을 검수한다. 4막의 성장·보상·완료 정책이 구현됐다는 뜻이 아니다. customMap의 원래 프로필 보호와 persist 차단을 사용한다.

- 31: 낮은 하구 둑, 두 비대칭 교전 주머니, 중간 여백, 둘째 둑 차폐, 배경 수로·선착장·배.
- 35: 바다가 없는 대숲, 폭/높이가 다른 세 빈터, 아래 통로와 유한 상부 지지면, 충돌하는 굵은 대와 비충돌 가는 대를 분리.
- 36: 낮은 분지의 넓은 빈 마당, 외곽 적 2체, 기존 한국식 집/작업 처마 자산. 수집 퀘스트 없음.

공통 source의 변경은 별도 검수 플래그를 가진 customMap의 기존 이미지 원경 선택뿐이다. 기존 달 없는 구름 자산을 새벽색으로 사용하며 1–30의 팔레트/이미지/정상 실행은 유지한다. source factory는 일반 번들에 등록하지 않는다. 새벽 지면 gradient 역시 미리보기 스크립트를 명시적으로 읽은 경우에만 사용한다.

실제 Chromium 카메라 fixture는 `_local/reports/act4-preview/`에 둔다. 첫 화면에서 굵은 갈대와 녹흑색 지면을 발견했고, 이후 줄기/이삭과 회청색 지면으로 교정했다. 다음 검수에서는 수관의 일렬 덩어리와 인접 지하 polygon의 세로 경계를 발견해 잎 방향/높이를 분산하고 공통 월드 높이의 gradient로 수정했다. 세 번째 검수에서는 대숲 아래 통로, 근경/원경 대나무 층, 폐촌 한옥 자산과 모바일 가독성을 확인한다. **이는 첫 지형 검수본이며 최종 미술 승인/정상 플레이 통과를 선언하지 않는다.**

현재 native 집중 검사는 schema/domain, 초기 접지 안정, 세 장의 아래 길 이동 연결을 확인한다. 연결 검사는 방해 몸을 제거하고 이동량을 보충하므로 정상 전투 완주와 구분한다. Chromium 검수는 실제 App customMap의 원래 프로필 보존, 전체 지형 domain, page error를 확인한다.

## 두 번째 구현 단위 · 물리 사건과 대사 영수증

`preview-events.js`는 검수 HTML에서만 명시적으로 읽는다. 검수 완료 JSON의 15개 인물 행/4개 목표 UI만 사용하며 일반 캠페인 catalogue 676행을 확장하거나 고치지 않는다. 장별 대사는 living speaker, 실제 장소와 사건을 확인하고, 실제 DOM에 표시한 ID와 폐기한 ID를 분리한다. 종결 cursor는 목격 증거가 아니다. 스냅샷은 이 미리보기의 명시적인 `snapshot/restore` API이며 **정식 App Continue 통과로 부르지 않는다.**

- 31: 물길 위협 제거 후 배가 실제 이동한다. 선착장/배는 별도 형상이며 도착 때만 실제 갑판 지지면이 생긴다. 전원(현재 살아 있는 동행)의 갑판 x/y·접지를 확인한 상호작용만 `boarded`를 만든다. 적만 조기 제거하거나 선착장 근처 공중에 모여도 완료되지 않는다. 곡사 안내는 둘째 둑의 실제 A01 하강 명중을 관측한 경우에만 발화한다.
- 35: 굵은 대 군락의 실제 projectile impact와 옆 빈터의 실제 target hurt를 별도 증거로 확인한다. 이후 해당 살아 있는 표적에 대해 방금 차폐된 위치에서만 짧은 안내를 표시한다. 기존 `banter` 상태 표시를 재사용하며 전투/dialogue lock을 걸지 않는다. 검수 입력에서는 x3060 직사 차단, x3350 직사 명중을 실제 탄으로 확인했다.
- 36: 살아 있는 휘겸을 문 가까이 선택한 상호작용만 문을 민다. 별도 동적 문을 회전시키며 종료 화면의 실제 그리기, 기존 `break` 효과음 요청, 그 뒤 2초 정적을 확인한 뒤 승인 문 대사를 연다. 문 화면을 그리지 않은 상태의 시간 경과/스냅샷 재개는 대사를 만들지 않는다. 이후 문 대사 두 행을 실제 표시한 영수증과 충분한 정적/출구 접근이 있어야 이탈 문답을 연다. 동행 사망으로 미표시된 행을 기록에 넣지 않는다.

`tests/act4-preview-ballistics.mjs`는 고정 포즈에서 원본 실탄의 31 둑 곡사 명중(30도/65%), 35 굵은 대 차단과 옆 빈터 명중(0도/20%)을 확인한다. HP나 collision hit를 주입하지 않는다. `tools/testing/act4-preview-events.py`는 실제 App/Story/Engine과 제어한 포즈/피해/시계를 사용하는 집중 fixture다. 배 이동/갑판 집결/스냅샷, 미표시 문 화면의 대사 보류/재개, 사망한 두 번째 행의 retired 분리, 실탄 차폐/우회 증거와 비정지 bark/중복 없는 표시 영수증을 검사한다. 이는 정상 플레이 완주/공개 검증이 아니다.

남은 계약: 미술 최종 완성, 정상 이동/전투/승선 플레이, 이동·점프·최대 사거리 정량표, 35 상부 진입과 실전 리듬, 완전한 조용한 사건 연출/음향 검수, 전투 밸런스, 최종 미술 종합 검수. recover/lethal 물 규칙은 독립 미검증 의존성이며 정식 출시 차단이다. 31 끝의 물은 미리보기의 배 접근 공간이며 낙수 회수 정책은 아직 제공하지 않는다. 32/33/34/37/38/39/40은 아직 구현하지 않았다. 이전 폭포 후보/승인 대기 변경은 가져오지 않았다. master/Pages는 기존 3막 배포를 유지한다.
