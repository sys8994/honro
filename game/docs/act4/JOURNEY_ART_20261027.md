# 4막 풍경형 여정첩 지도

기존 1막과 3막 지도 원본의 높은 시점, 한국식 건물·암반·숲의 묘사 밀도와 그림 지도의 화풍을 참조해 공식 이미지 생성 도구로 새 원본을 만들었다. 2막 원본도 실제 픽셀을 확인해 막별 실루엣 차이를 대조했다.

- 원본: `concepts/HONRO_Act4_Journey_PaintedDawn.png` (1586×992).
- 게임 자산: `shared/assets/journey-maps/v1/act4.webp` (원본 크기, WebP 품질 93).
- 이미지 안에는 글자·숫자·노드·경로 그래프를 넣지 않았다. 31–40 노드와 진행 경로는 기존 여정첩 DOM/SVG 오버레이를 사용한다.
- 포구·하구 갈대·갯벌·높은 해안 절벽·내륙 대숲과 폐촌·곶의 운송길·해식굴·난파 해안·귀환 선착장에 맞춰 지도 위 앵커만 배치했다. 장 순서와 개방 조건은 바꾸지 않는다.
- 이 변경은 여정첩 그림·앵커·진행선만 다룬다. 31장을 포함한 전투 지형·몬스터·기믹·저장·대사·장비는 변경하지 않는다.

실제 브라우저에서 데스크톱/모바일 기본 보기와 전체 보기, 열 노드 포인터 선택, 키보드 확대·맞춤, 현재 장의 정상 진입을 확인한다. 네 막 이미지의 실제 디코딩과 요청 실패 뒤 재시도도 확인한다. 전체 지도 검수를 위한 선행 완료/성장 상태는 fixture이며 전투 완주 검사가 아니다.

미술 원본과 실제 장착 화면을 조정자에게 전달해 독립 미술 확인을 받는다. 과거 도식의 파일 형식 수정 통과를 새 미술 승인으로 간주하지 않는다.
