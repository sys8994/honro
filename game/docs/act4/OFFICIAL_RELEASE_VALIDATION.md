# 4막 정식 연결 검증

미술은 31/35/36 v5 실제 PNG에 대한 부모의 독립 픽셀 검수를 통과했다. 35의 지지된 길, 36 폐허 접점, 정상 시작 적 간격은 v4 승인 결과를 유지한다. 검수 이미지: Library `libfile_cbc7d05a8a388191abd5356345c9e5ff` 버전 5.

정식 연결은 승인된 열 장 지형과 69행(대사 54 + 목표/결산 15)을 공유 런타임으로 옮긴다. 미리보기 전용 저장과 결과 화면은 정식 번들에 포함하지 않는다. 일반 캠페인의 성장·장착·전투 저장, 결과 정산과 여정첩을 재사용한다. 40장 뒤 미구현 막으로 진행하지 않는다.

검증 범위는 원본 App/Scene/Engine을 사용하는 집중 fixture와 실제 전투 구간 검사다. 좌표 배치·선행 완료 조건·적 처치 제어를 쓰는 검사는 열 장 정상 전투 완주 증거가 아니다. 전체 30장 자동 순회는 수행하지 않는다.

- `act4-official-smoke.py`: 일반 앱의 31–40 진입, 전투 수치, 같은 revision Continue, 40 뒤 안전 휴식과 여정첩.
- `act4-official-contracts.py`: 실제 관측 영수증, 32 재회, 38 고정 연결, 39 네 주민 이동, 40 승하선과 결산의 일반 저장 연결.
- `act4-equipment-release.mjs`: 기존 획득 API의 8개 정의/6개 사건, 조건·출처·회차, 선택 독점, 저장 실패 후 재개와 once. 물리 사건 생성은 별도 브라우저 검사.
- 기존 지형/투사체/예외/실제 조수 압박 구간 검사 결과는 각 집중 검사 범위에서 유지한다.

폭포 별도 패치는 포함하지 않는다. 기존 1–3막, 휴식터 원본 SVG, 실제 roster 불투명 표시, 24장 선택 대화, 52개 장비 시스템은 보존한다.

정식 연결 후 추가 저장 검사:
- 31–40 각 장에서 같은 revision Continue와 실제 페이지 새로고침 후 재개, HP/기력/좌표 보존을 확인했다.
- 저장된 장 자료의 비동기 준비가 끝나기 전에 App 원형에 접근하던 4막 어댑터를 기존 `HONRO_APP_READY` 경계 뒤에 연결한다.
- 열린 검수 대사의 실제 cursor/관측 영수증은 복원하고, 종료 직후 저장한 대사는 다시 열지 않는다. 주민 입장 HP 적용은 최초 입장에 한정한다.
- Chromium 24장 현장 선택대화·실제 화자 사망 처리·저장·모바일·원본 불투명 SVG 휴식터 검사를 통과했다. 장비 App 7개 및 16/17/18/20 집중 검사를 통과했다.
- `rest-idle.mjs` 35행의 옛 fixture 전체 상태 비교와 `rest-journey.mjs` 6행의 옛 도착 대사 비교는 기준 master `ced733a66d49f69c5f93791c5ffad64d270fd3a4`에서도 같은 위치에서 실패했다. 기존 실패를 통과로 세지 않는다. 원본 휴식 아트 연결 검사와 실제 Chromium 24장 휴식 회귀는 별도로 통과했다.

추가 실제 실행 범위:
- 정식 33장 초기 배치에서 실제 이동·낙하·점프·발사·대기와 원래 적 AI를 사용해 5라운드 고수위 전 네 동행 피난을 확인했다. 적의 실제 발사와 HP 피해가 발생했다. 시작 뒤 좌표·HP·자원·라운드·이동 예산을 주입하지 않았다. 선행 장 완료와 입장 성장은 fixture이며 이 구간을 장 전체 클리어로 세지 않는다.
- 정식 39장의 점유된 회수둑에서 현재 행동 종료 뒤 실제 동행 이동으로 공간을 열어 같은 쪽 낮은 둑 복귀와 1회 피해/기력 보존을 확인했다. 지상 적 침수 제약과 명시적 유령/수생 예외를 구별했다.
- 정식 39장 실제 예고→원래 적 발사→탄도 충돌/HP 피해, 보스 사망 후 다음 예고 취소, 살아 있는 보스를 남긴 네 주민의 실제 보행·접지·안전 고지 도착/동행 탈출을 확인했다. 구조 검사에서 턴과 선행 전투 조건은 제어한 fixture다.
- 35장 호리병 전달자는 실제 네 주인공 동행으로 제한한다. 소환 표지가 없는 섭혼된 적만 근처에 있어도 인계가 시작되지 않는 검사와 실제 동행 인계/저장/once를 통과했다.

공개 활성 후보:
- `game/config/story-release.json`의 `act4`를 켜고 환경변수 없이 생성한 기본 Game/Workshop/Playtest 빌드와 타입 검사를 통과했다.
- 마지막 31–40 실제 페이지 재로드/Continue와 40 뒤 종료 gate 검사, 기존 장비 획득 API 집중 검사도 통과했다.
- 38 담허 실제 사망 뒤 일반 이동·점프로 비상 통로를 건너는 검사에서 연결 능력을 허위 생성하지 않았다. 위치/이동 예산을 제어한 지형 fixture이며 정상 전투 완주 증거는 아니다.
- 69행 원고 세 JSON의 Git blob SHA는 승인된 문서 브랜치 `91485a6667c63d2e1ad455860884f14aff1b8f22`와 동일하다. 기존 676행 검수 원고와 폭포/공통 지형 원본을 변경하지 않았다.

여정첩 이미지 형식 후속 수정:
- 4막 SVG 원본을 빌드가 `.webp` 확장자로 발행하여 HTTP 200 뒤에도 Chromium 디코딩이 실패했다. 실패 파일은 `web/graphics/journey-map-act4.17afbdd8897b1210.webp`였다.
- 원본 확장자로 발행하도록 한 줄을 수정했다. 새 파일은 같은 SVG 바이트의 `web/graphics/journey-map-act4.17afbdd8897b1210.svg`이며 실제 `image/svg+xml` 응답과 브라우저 표시를 확인했다. 1–3막 WebP URL/바이트는 그대로다.
- 네 지도 실제 디코딩과 강제 1회 요청 실패 후 장소 버튼 유지/기존 재시도를 검증했다. 기준 master `ced733a6`의 1막은 같은 `journey-map-act1.31fefd98a807ce78.webp`를 HTTP 200으로 받아 1536px로 정상 디코딩했다. 부모가 본 공개 1막 실패는 로컬 기준/후보에서 재현되지 않아 원인을 확정하지 않는다.
