## 확정 저작·저장 범위

독립 감사와 교차 확인한 `shared/data/open-structures.json`의 74항목만 바꿨다. 3막 배치 asset68개(21:10,22:11,23:4,24:4,25:13,26:4,27:13,28:3,29:3,30:3)와28장 얇은 목조 경사지붕2개, 5장 폭포 돌출 암반과7장 나무 돌출부2개 및26장 흙덮개·29장 수문 지붕2개다. terrain 좌표·asset collision 다각형·벡터·배치·적·임무는 그대로다.

1–20장 기존 열린 발판 외에 5장 폭포 돌출 암반과7장 나무 돌출부도 one-way로 바꿨다. Native Scene 픽셀에서 아래/옆이 열린 독립 구조임을 확인했으며, 두께나 이름으로 고체 예외를 삼지 않았다. 1–6장 지반의 화강암20개와 실제 동굴 천장·지반 지지부는 별도로 유지한다. 3막의 연속 상부 실체와 아래까지 찬 기반, 수직 벽·기둥13개도 유지한다. 독립 지붕과 다르게 실제 막힌 실체이며 이름의 roof/gallery만으로 일괄 전환하지 않았다.

실행 중인 정식 Continue 저장은 현재 전체 형상·설계·앵커·출처가 일치할 때만 플래그를 보정한다. 위치·HP·자원·목표·투사체와 기존 지형 좌표를 유지한다. 다른 역사 형상이나 미확인 출처는 새 진입/재시도에서 새 규칙을 받는다. Workshop 자동저장도 미편집 정본 stage와 asset이 정확히 일치할 때만 갱신한다. 공유 에셋을 참조하는 stage 하나라도 편집됐으면 그 에셋은 건드리지 않는다. 임의 import/normalize는 무손실 보존한다.
