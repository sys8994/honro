# 40장 연속 일반 입력 비교: 중간 근거

## 범위
공개 기준선 배치와 후보 배치를 같은 공식 runtime에서 비교했다. 원래 스폰과 42체를 유지하고 권장 진입 25레벨의 동일한 합성 훈련 프로필을 사용했다. 사용자 저장은 열거나 수정하지 않았다. 이후 move/jump/drop/fire/wait/select와 실제 턴 진행만 사용했다. coast와 pilot 공식 래퍼 및 실제 Canvas 예고를 적용했다.

이것은 app:false Engine 입력 검사이며 정상 App의 대화·주민·배 호송 완료 검사가 아니다. 적 삭제, HP·이동량 보충, 순간이동, 턴 강제 지정, 호송 상태 강제 완성은 하지 않았다. 결과는 특정 입력 정책과 프로필의 관측이며 보편적 난이도 판정이 아니다.
