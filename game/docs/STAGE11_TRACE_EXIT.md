# 11장 북쪽 흔적 조사로 마무리

2026-10-11 정상 진행 검수에서 두 매듭·4턴 보호·주민 구조를 끝낸 54턴 저장에도 멀리 흩어진 적 37명의 전맵 소탕이 남았다. 사용자가 추가 개편을 승인하여, 마지막 `clear-road` 필수 소탕만 제거하고 북쪽 `trace`의 실제 접근·조사와 다음 장 연결 대사는 유지한다. 남은 적과의 전투는 선택이며 지형·배치·전투 수치·파동 예산은 바꾸지 않는다.

## 현재 계약

- 순서: 서쪽 매듭 → 서쪽 반응 교전 → 동쪽 매듭 → 4턴 보호와 6혼령 진입 → 주민 구조 → 북쪽 흔적 조사.
- `shared/runtime/stage11-trace-exit.js`가 공통 모델 번들의 마지막 저작층이다. 원본 `campaign.json`과 과거 지도/검수 기록은 그대로 두며, Game·Stage View·Playtest의 공통 저작·컴파일 경로에 같은 6단계 계획을 제공한다.
- 새 전투와 재시도는 `honroStage11TraceExitRevision: 1`을 갖는다. 이 revision에서만 옛 전맵 소탕/대기 증원 완료 override를 해제한다. 서쪽 반응 교전, 보호의 4턴/6명 진입 조건, 구조 및 흔적 조사 주변의 기존 안전 조건은 유지한다.
- 구조한 주민은 계속 보호 대상이다. 사망 실패가 조사 완료/승리보다 우선한다.
- 아직 대기 중인 선택 반응 파동을 삭제하지 않는다. 조사 전에는 기존 안전·행동 경계에 따라 진입하며, 승리/패배 뒤에는 기존 queue/flush의 종료 방어가 출현을 막는다. 이 파동을 모두 출현·처치하는 것은 최종 조사 외의 숨은 승리 조건이 아니다.
- 첫 클리어의 기존 성장 상한 보상과 12장 해금은 그대로다. 선택 전투를 건너뛰면 해당 처치/피해 통계와 전투 중 경험치를 얻는 시점은 달라지지만, 첫 클리어 XP 상한을 낮추거나 별도 보상을 만들지 않는다.

## 진행 저장 이관

명시적 campaign 출처·campaign 모드이며 11장 교전 revision 2/Act2 revision 2 이상인 진행 저장 중, 순서와 ID가 기존 7단계 계획과 정확히 같은 경우에만 이관한다. 저장된 `honroAct2Steps`와 있으면 narrative snapshot의 계획에서 `clear-road`만 제거하고 새 revision을 붙인다.

HP/XP, 배우·지형·사건·파동, marker, 완료 flag/checkpoint, 대기/현재 대화와 읽은 기록은 보존한다. 이미 끝난 전투, 이전 ravine revision 1, custom/Workshop/출처 없는 저장, 다른 장, 인식하지 못하는 계획 및 미래 revision은 수정하지 않는다. 이전에 승인된 비행 적 끼임 복구 등 기존 Continue 동작은 독립적으로 계속 적용되며 새 이관의 변경분과 구분하여 검사한다.

## 확인과 한계

`NODE_OPTIONS=--max-old-space-size=512 node tests/stage11-trace-exit.mjs`:

- 정상 54턴 export 전체의 이관 차이를 정확히 비교하고 멱등성·pinned narrative·제외 경계를 확인한다.
- 실제 App Continue/내보내기/재개/재시도의 계획·상태 보존을 확인한다.
- 4턴 및 6혼령 진입의 각 미충족 상태는 여전히 보호 미완료다.
- 기존 흔적 marker로 한 배우만 배치한 명시적 공간 fixture에서 생산 상호작용 E/결과 처리를 호출한다. 적 37명이 살아 있는 채 승리하고, 기존 발견 대사가 결과 대화에 합쳐지며, 동행 네 명의 첫 클리어 XP는 기존 상한 23502, 12장은 해금된다. 인접 위협의 조사 차단과 구조 주민 사망 실패도 확인한다.
- 이 검사는 정상 이동 완주·브라우저 입력/시인성의 증거가 아니다. 생성 HTML 재빌드, 전체 verify 및 실제 Pages/Game/Workshop 검수는 통합 배포 담당 범위다.

기존 `stage11-ravine-draft-resume`의 초기/부분 저장 보존은 통과했다. `stage11-ravine-completion-history`는 변경하지 않은 원본 지도와 역사 helper를 읽다가 기존 encounter-density 전체 hash 기대값에서 막힌다(actual `f9103f71…`, expected `4e6862fc…`). 역사 fixture를 현재 개편에 맞춰 완화하지 않았다.

`stage11-ravine-semantics`의 현재 목표 기대값은 승인된 소탕 한 항목만 제외하도록 분리했고, 나머지 목표·능력치·성장·구저장 보존은 통과했다. 더 오래된 `stage11-ravine-encounters`는 첫 roster 검사에서 현재 53명 대 과거 기대 45명으로 막혀 이후 항목은 실행되지 않았다. 이 패치가 원본 적 편성이나 그 역사 기대치를 바꾸지는 않는다.
