# 혼로 첫 화면 · 안개 속 첫나루

## 2026-10-13 개편

사용자 승인으로 기존 거대 나무 SVG, 기본 글꼴 타이틀, H 낙관을 대체한다. 이전 A안의 붉은 낙관·SVG 전제는 폐기했다. 첫인상은 먹빛 산맥, 물안개, 작은 나루와 등불이다. 캐릭터·후반 장소·서사 정체를 노출하지 않는다.

### 미술 구조

- PC: 왼쪽 어두운 물의 여백에 독립 로고와 메뉴, 오른쪽 아래 온전한 작은 열린 배·나루·등불. 산맥은 낮은 대비로 뒤에 물러난다.
- 모바일: PC 그림을 잘라 쓰지 않는다. 세로로 따로 제작한 산맥의 빈 중심과 하단 나루를 사용한다. 상단 로고, 중앙 실제 HTML 메뉴, 하단 풍경이 겹치지 않게 나눈다. 가늘고 긴 화면의 추가 트리밍은 오른쪽 기준으로 등불·배를 보존한다.
- 로고: 사용자 확인 표기 `魂路`(혼의 길)를 큰 상아빛 붓글씨로 두고, 바로 아래 기존 `혼로` PNG를 한 번만 작게 배치한다. 한글 너비는 한자의 28%, 이미지 높이는 약 30.76%다. 작은 화면에서도 읽는 순서가 한자 → 한글이 되며 이전 `HONRO` 세 번째 줄은 제거한다. H·낙관·붉은 인장 없음. `魂`의 云/鬼, `路`의 足/各과 한글 획을 원본과 실제 축소 크기에서 확인한다.
- 색: 청회색 먹빛, 낮은 채도의 물안개, 따뜻한 상아빛 글씨와 단 하나의 작은 등불. 과장된 중국식 봉우리, 일본식 건축·장식을 추가하지 않는다.

### 구현 계약

`shared/assets/environment/title/`에 가로/세로 WebP와 JPEG fallback, 로고 PNG를 둔다. `game/build.mjs`에서 picture source와 로고를 내장하므로 외부 이미지 요청과 새 로딩 화면이 없다. 배경 실패 시 먹빛 gradient, 각 로고 실패 시 읽을 수 있는 HTML `魂路` / `혼로`를 같은 고정 비율 영역에 남긴다. 제목의 접근성 이름은 한 번만 `혼로`로 읽고 장식 이미지·시각적 보조 표기는 aria-hidden으로 중복 낭독하지 않는다. 배경과 로고는 장식/접근성 제목을 분리하며 메뉴는 원래 버튼과 data-action을 사용한다.

기존 신규 여정/진행 여정/저장 전투/중단 대화/분할 원정의 분기, 설정·기록·Workshop Map, 음악 wake·저장 계약을 그대로 보존한다. 시작 지연과 입력 차단을 만들지 않는다. 의도적 화면 애니메이션은 제거했고 reduced-motion에도 정적이다. 기존 방향키 메뉴 탐색과 focus-visible을 유지한다.

### 검수 기준

- 1440×900, 400×800, 333×740, 333×592, 844×390, 667×333에서 한글 판독·상단 설정·최대 2개 메뉴·footer 여백·나루/등불 가림을 확인한다.
- 로고 alpha의 밝은 프린지·회색 양각감, 반복 산세, 큰 나무 잘림, 메뉴가 그림에 구워졌는지 확인한다.
- 이미지 실패·모든 저장 분기·반복 진입·설정 및 기록 열고 닫기·키보드·음악을 별도로 검수한다.
- Native Canvas 합성은 미술 배치 진단일 뿐 실제 CSS/브라우저 검증이 아니다. 실제 공개 Pages 검수가 완료되기 전 최종 합격으로 표시하지 않는다.

### 현재 검수 기록

첫 가로/세로 원화와 로고를 구현자 및 독립 검수자가 직접 열람했다. 세로 배의 덮개를 제거해 열린 배로 통일했고 이미지 도구로 로고 프린지를 완화했다. 실제 alpha의 어두운 배경 Native 합성에서 H·낙관·유령 테두리 없음과 글자 판독을 확인했다. 로컬 Chromium은 환경 소켓 권한으로 실행되지 않아 실제 공개 Pages 검수는 별도 대기 중이다. 자동/Native 결과와 최종 브라우저 결과를 구분한다.

### 한자 중심 계층 · 2026-10-13

- 확정 표기: `魂路`. 제목 한자 확인 질문에 사용자가 동의한 뒤 제작했다. 원본 로고는 `hanja-wordmark.png`(1859×846, RGBA)이며 배경 그림과 기존 한글 원본은 변경하지 않았다. 전체 타이틀 이미지 파일 합은 1,590,019바이트다. 모두 Game HTML에 내장하며 별도 네트워크 요청·글꼴 다운로드가 없다.
- 한글은 한자 아래 3–7px 간격, 이미지 높이 약 31%. 가로/세로·낮은 화면의 로고 폭은 이전 수치를 유지한다. 배경, tagline, 메뉴 위치·동작·저장 분기는 변경하지 않는다.
- Native 검수: 1440×900, 400×800, 333×740, 333×592, 844×390, 667×333의 원본 그림+실제 표시크기 로고 합성. 구현자와 독립 검수자가 한자 구조·한글 비율·배경 조화를 직접 확인했다. 원본의 미세 alpha 입자는 390/263/170px 표시에서 화면을 더럽히는 밝은 덩어리로 보이지 않았다. 붓끝을 인위적으로 지우지 않았다. `tools/testing/capture-title-hanja-native.mjs`는 미술 스케일 진단용이며 브라우저 CSS/기기 화면을 재현했다고 주장하지 않는다.
- 계약 검사: 두 글자 표기·두 계층·RGBA/크기·31% 높이·5개 저장 분기·반복 진입·독립 이미지 실패 fallback·접근성. 실제 브라우저 검사는 같은 6개 viewport에서 비율·비겹침·실패 전후 높이·키보드·설정/기록 복귀를 확인하도록 확장했다. 로컬 Chromium은 페이지 실행 전 socket 권한 실패가 확인되어, 최종 공개 Pages 검수는 별도 담당이 수행해야 한다.
