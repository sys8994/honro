# 혼로 첫 화면 · 안개 속 첫나루

## 2026-10-13 개편

사용자 승인으로 기존 거대 나무 SVG, 기본 글꼴 타이틀, H 낙관을 대체한다. 이전 A안의 붉은 낙관·SVG 전제는 폐기했다. 첫인상은 먹빛 산맥, 물안개, 작은 나루와 등불이다. 캐릭터·후반 장소·서사 정체를 노출하지 않는다.

### 미술 구조

- PC: 왼쪽 어두운 물의 여백에 독립 로고와 메뉴, 오른쪽 아래 온전한 작은 열린 배·나루·등불. 산맥은 낮은 대비로 뒤에 물러난다.
- 모바일: PC 그림을 잘라 쓰지 않는다. 세로로 따로 제작한 산맥의 빈 중심과 하단 나루를 사용한다. 상단 로고, 중앙 실제 HTML 메뉴, 하단 풍경이 겹치지 않게 나눈다. 가늘고 긴 화면의 추가 트리밍은 오른쪽 기준으로 등불·배를 보존한다.
- 로고: 정확한 `혼로` 두 글자의 독립 붓글씨 PNG, 실제 투명 alpha. H·낙관·붉은 인장 없음. 작은 `HONRO`는 별도 HTML 활자다. 혼의 ㅎ/ㅗ/ㄴ, 로의 ㄹ/ㅗ 획을 원본과 실제 축소 크기에서 확인한다.
- 색: 청회색 먹빛, 낮은 채도의 물안개, 따뜻한 상아빛 글씨와 단 하나의 작은 등불. 과장된 중국식 봉우리, 일본식 건축·장식을 추가하지 않는다.

### 구현 계약

`shared/assets/environment/title/`에 가로/세로 WebP와 JPEG fallback, 로고 PNG를 둔다. `game/build.mjs`에서 picture source와 로고를 내장하므로 외부 이미지 요청과 새 로딩 화면이 없다. 배경 실패 시 먹빛 gradient, 로고 실패 시 읽을 수 있는 HTML `혼로`를 남긴다. 배경과 로고는 장식/접근성 제목을 분리하며 메뉴는 원래 버튼과 data-action을 사용한다.

기존 신규 여정/진행 여정/저장 전투/중단 대화/분할 원정의 분기, 설정·기록·Workshop Map, 음악 wake·저장 계약을 그대로 보존한다. 시작 지연과 입력 차단을 만들지 않는다. 의도적 화면 애니메이션은 제거했고 reduced-motion에도 정적이다. 기존 방향키 메뉴 탐색과 focus-visible을 유지한다.

### 검수 기준

- 1440×900, 400×800, 333×740, 333×592, 844×390, 667×333에서 한글 판독·상단 설정·최대 2개 메뉴·footer 여백·나루/등불 가림을 확인한다.
- 로고 alpha의 밝은 프린지·회색 양각감, 반복 산세, 큰 나무 잘림, 메뉴가 그림에 구워졌는지 확인한다.
- 이미지 실패·모든 저장 분기·반복 진입·설정 및 기록 열고 닫기·키보드·음악을 별도로 검수한다.
- Native Canvas 합성은 미술 배치 진단일 뿐 실제 CSS/브라우저 검증이 아니다. 실제 공개 Pages 검수가 완료되기 전 최종 합격으로 표시하지 않는다.

### 현재 검수 기록

첫 가로/세로 원화와 로고를 구현자 및 독립 검수자가 직접 열람했다. 세로 배의 덮개를 제거해 열린 배로 통일했고 이미지 도구로 로고 프린지를 완화했다. 실제 alpha의 어두운 배경 Native 합성에서 H·낙관·유령 테두리 없음과 글자 판독을 확인했다. 로컬 Chromium은 환경 소켓 권한으로 실행되지 않아 실제 공개 Pages 검수는 별도 대기 중이다. 자동/Native 결과와 최종 브라우저 결과를 구분한다.
