# HONRO 첫 화면 기획

상태: A안 구현(2026-10-08). 아래 제안의 핵심 구도를 게임 타이틀에 반영했다.

## 추천: 달빛 아래, 여정의 첫 나루

첫 화면을 포스터의 일부가 아니라 하나의 풍경으로 만든다. 먹빛 산맥, 잔잔한 물, 길가의 작은 등불이 먼저 보이고, 그 위에 독립된 `혼로` 로고와 짧은 메뉴가 놓인다. 전투 화면과 같은 한국화 진경산수·수묵담채의 형태를 쓰되, 전투 지형을 그대로 복사하지 않는다. 고요하지만 누군가 지나간 흔적이 있는 장소가 게임의 여정과 악귀의 기척을 함께 예고한다.

가로 화면의 왼쪽 36%는 로고와 메뉴를 위한 어두운 여백이다. 오른쪽에는 낮은 나루와 굽은 소나무, 그 뒤로 먼 산맥을 배치한다. 작은 등불은 우하단, 달은 우상단에 두어 시선이 메뉴에서 풍경으로 흐르도록 한다. 인물은 넣더라도 아주 작은 뒷모습 하나만 사용하며, 등장 인물·3막 사건·보스를 선공개하지 않는다. 글자가 그려진 이미지는 사용하지 않는다.

```text
┌───────────────────────────────────────────────┐
│                                               │
│    혼로                              작은 달  │
│    HONRO                 흐린 먼 산맥         │
│                                               │
│    이어서 걷기                     굽은 소나무 │
│    새 여정                                    │
│    설정                물안개 / 물빛           │
│                            낮은 나루 · 등불   │
└───────────────────────────────────────────────┘
```

로고는 배경과 분리된 편집 가능한 SVG로 제작한다. 붓획의 무게와 여백을 중심으로 `혼로` 두 글자를 구성하고, 붉은 낙관은 하나만 둔다. 영문은 한글의 약 15% 크기로 조용히 받친다. 기존 로고가 확정되어 있다면 그 형태를 유지하고 독립 에셋으로 정리한다. 메뉴는 장식 문양보다 명확한 글자와 선택 표시를 우선한다.

## 비교안

| 안 | 장면 | 장점 | 판단 |
|---|---|---|---|
| A · 첫 나루 | 산수·물안개·등불·낮은 나루 | 여정과 고요한 불안을 함께 전달하고 모바일 여백 확보가 쉽다 | 추천 |
| B · 닫힌 성문 | 훼손된 문루, 한쪽에서 비치는 달빛 | 악귀·폐성의 분위기가 즉시 읽힌다 | 3막 장소와 의미가 너무 가까워 전체 게임의 첫인상을 좁힐 수 있다 |
| C · 네 사람의 길 | 작은 네 동행이 산길을 걷는 뒷모습 | 동행의 이야기가 먼저 읽힌다 | 인물·복식·애니메이션 제작량이 크고 첫 만남을 미리 보여준다 |

## 공식 레퍼런스에서 가져올 원칙

- [Hollow Knight의 환경 개발 비교 — Team Cherry](https://www.teamcherry.com.au/blog/hollow-knight-then-and-now): 제작사가 공개한 같은 장소의 전후 비교는 색과 깊이, 전경·배경 풍경을 보강하는 접근을 보여준다. HONRO에서는 전경 한 덩어리, 안개로 떨어진 원경, 메뉴 여백으로 적용한다. 이 자료는 실제 타이틀 메뉴 배치의 근거가 아니다.
- [Hades II 공식 게임·미디어 페이지 — Supergiant Games](https://www.supergiantgames.com/games/hades-ii/): 공식 페이지가 로고와 월페이퍼 등 미디어를 제공한다. 여기서 얻는 제작 원칙은 로고와 일러스트를 별개 자산으로 관리하는 것이다. 로고가 박힌 포스터를 크롭하는 현재 문제를 해결하는 데 적용한다. 메뉴 구도를 그대로 모방한다는 뜻은 아니다.
- [Ghost of Tsushima 콘셉트 아트 과정 — Sucker Punch / PlayStation](https://blog.ko.playstation.com/2020/10/30/20201030-got/): 제작진은 중요한 자연 요소를 강조하고 덜 중요한 요소를 낮추며, 시각 정체성을 로고·UI·컷신에 연결했다고 설명한다. HONRO에서도 같은 조형 원칙을 첫 화면과 게임 배경에 연결한다. 한국 산수·소나무·나루의 형태를 사용하고 일본식 복식이나 건축 문양을 가져오지 않는다.

위 적용안은 공식 자료를 바탕으로 한 HONRO용 디자인 제안이다. 각 게임의 실제 최신 타이틀 화면을 직접 검수한 결과로 표현하지 않는다.

## 움직임과 소리

입장 시 0.5초 정도 밝아지며 로고와 메뉴를 함께 보여준다. 연출이 끝나기를 기다리지 않고 즉시 메뉴를 조작할 수 있다. 원경은 거의 고정하고 물안개와 등불만 천천히 움직인다. 레이어 간 이동은 화면 기준 약 1–3px로 제한하고, 커서에 따라 화면 전체가 기울거나 큰 시차가 생기지 않도록 한다. 8–12초 이상의 느린 안개 흐름과 등불의 작은 밝기 변화면 충분하다.

음악은 기존 첫 곡과 실제 재생 정책을 유지한다. 바람·물 소리는 선택적으로 아주 낮게 섞고, 사용자 첫 입력 전에 강제로 소리를 재생하지 않는다. 설정의 모션 감소에서는 정지 장면을 사용한다.

## 메뉴와 작은 화면

저장이 있을 때 `이어서 걷기`를 가장 먼저 보여주고 기본 선택한다. 저장이 없으면 `새 여정`을 기본 선택한다. 기존 설정·여정 진입 기능은 보존한다. 개발용 Workshop 진입은 일반 플레이 메뉴의 주인공처럼 강조하지 않는다. 선택한 항목은 짧은 붓 밑줄과 작은 낙관색 표시로 구분한다. 키보드 ↑↓/Enter, 포인터, 터치로 동일하게 조작하고 포커스를 분명히 표시한다. 버튼의 터치 높이는 최소 44px로 한다.

세로 화면은 별도 구도 값을 사용한다. 상단 20–35%에 로고, 하단 60–82%에 메뉴를 놓고, 나루·등불은 중앙 오른쪽에 남긴다. 단순 중앙 크롭으로 로고나 주제를 잘라내지 않는다. 390×844와 844×390의 브라우저 주소창·safe area를 고려하고, 메뉴 뒤에는 국소적으로 어두운 면을 두어 작은 화면에서도 읽히게 한다. 가로 화면 1440×900도 함께 검수한다.

## 이후 제작 순서와 완료 기준

1. A안의 가로·세로 정지 구도와 독립 로고를 제작해 두 화면에서 비교한다.
2. 순수 SVG의 하늘·산맥·물안개·나루/소나무 레이어와 메뉴 여백을 확정한다.
3. 기존 타이틀 진입·저장·설정 흐름에 연결한다.
4. 느린 모션과 모션 감소를 적용하고, 첫 입력 지연·음악 중복·메뉴 포커스·저장 없는 상태를 검사한다.
5. 실제 Game과 Workshop 내 Game 진입, 세 가지 화면 비율에서 로고·등불·메뉴가 잘리지 않고 읽히는지 확인한다.

구현 소스는 `shared/assets/environment/title-first-ferry.svg`, `title-wordmark.svg`, `game/src/title.css`와 `game/build.mjs`다. 원경과 로고를 별도 순수 SVG로 내장했고, 저장·설정·여정 재개 버튼을 유지했다. 가로 1440×900, 세로 390×844, 낮은 가로 844×390의 실제 브라우저 화면은 `_local/reports/title-refresh/`에서 확인한다. 여정첩과 다른 화면으로 넘어갈 때 음악을 새로 자동 재생하지 않는다.
