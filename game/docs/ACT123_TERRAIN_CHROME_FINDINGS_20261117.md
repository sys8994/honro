# 앞선 후보 Chrome 직접 대조 결과

기준선 7d238d20663c3ceffe430eb0304e01516ae625cf, 후보 eb2557080a4ae57ba75f75077d1cd374053638b7. CI 44155946749의 4개 작업은 성공했다. 8장 × 2화면 × 원본/후보 = 32 PNG를 비교 시트에서 직접 관찰했다. 이 CI 성공은 이미지 로딩, 고정 초기 상태, 전체 battle 불변, 물리/카메라 일치와 실제 변화 유무를 뜻하며 미술 합격이 아니다.

## 배포 차단

- **3장: 시각 회귀, 배포 제외.** desktop-br에서 보행선 위 지형 본문이 수직으로 크게 늘어나고, portrait-bl에서는 원래 낮은 아치 위로 거대한 가짜 아치/기둥이 나타난다. 원래 path 문자열과 physics 보존만으로 합성 transform/clip 변형을 검출하지 못했다. 하단 사각 빈틈 해소는 이 회귀를 상쇄하지 않는다. source registration/collage 및 runtime 변환 원인을 확인해야 한다.
- **7장: 시각 품질 보류.** 외부 사각 공백은 사라졌으나 하부 긴 수직 반복 면과 오른쪽 수평 경계가 남는다. 원래 보행 실루엣은 이 표본에서 유지되지만 확대 접합과 동일 합성법의 영향 확인 전 장 전체 합격으로 세지 않는다.
- **32장: 별도 기존 미완, 이 결합 코드에 포함되지 않음.** 최적화 alias만 적용하면 상대 m subpath의 선택 마스크가 이동할 수 있어 단순 적용 금지. Native float/Chrome 차이는 별도 진단 중이며 잔선 해결과 구별한다.

## 제한 범위에서 확인된 개선

- 12장 portrait-bl/br: 화면 하단의 별도 밝은 다각면 띠가 제거되고 본문 하부가 이어진다. 상부 플레이 구조는 표본상 유지.
- 15장 portrait-bl/tl: 양 끝의 직사각 반복 암면 띠 제거. 원래 상부 암맥 끝의 미해결 미술 의도 항목은 그대로 남긴다.
- 21장 desktop/portrait-bl: 암반층 왼쪽 수직 끝과 하단 면 경계가 완화된다. 실제 상부 길/건물 유지. 자연스러움 최종 취향 판정과 모든 팬 위치 검수는 별도.
- 22장 desktop/portrait-bl: 두 기초면의 사각 하단/측면 경계를 완화한다. 모든 구조 실루엣 유지. 새 미술 디자인 승인을 의미하지 않는다.
- 28장 portrait-bl/br: 화면 하단 y667~695의 배경 노출 띠 해소. 변경 11,310픽셀/화면, 이 영역 밖 동일.
- 30장 desktop-br/portrait-bl: 원거리 수로의 하단 절단과 암면 끝 경계를 완화한다. 원래 상부 채널/길은 유지. 큰 비보행 면 확장인 만큼 고배율 팬/메모리 정량 검증은 별도.

16대조 모두 physics/camera 일치. 변경 픽셀 수는 효과 범위이지 품질 점수/합격 기준이 아니다. 기존 저장 roundtrip과 source identity 관련 회귀도 해당 CI에서 실행했다. 사용자 저장·기존 전투·일반 공개 UI를 조작하지 않았다. 실기기, 공개 입력, 전체 상태 행렬, 프레임 시간/실제 메모리, 게임플레이 정량은 미검수다. master/Pages 미반영.
