## 구현

- `story-content.js` v6에 주막·1~10 진입/결말·현장 사건·장부·구조 증언·협력 전환을 모았다. 스테이지 종료 창에는 대본 전체 대신 확인한 사실과 다음 목적을 요약한다.
- 짧은 관찰·전술 대사는 전투를 멈추지 않는 현장 자막으로 전달한다. 나무꾼·장부·주민 증언은 주변 적을 정리한 뒤 대화한다. 진입/결말과 소단 협력 전환은 입력을 취소하고 전투·카메라를 정지한다.
- 장부는 과거 승객과 최근 들림 기록을 분리한 두 쪽의 문서로 표시한다. 페이지와 대화 위치를 기존 전투 저장에 함께 보관한다. 장부 확보/구조/받이진 상태는 기존 상호작용에서 먼저 반영하므로 건너뛰기가 진행 조건을 누락시키지 않는다.
- 목표를 달성하는 순간 장부 대사가 큐에 남아 있어도 결말 앞에 보여준다. 턴 경계보다 먼저 출구에 닿은 경우에도 이미 예약된, 전투 행동 없는 중요 증언을 먼저 회수한다. 완료 후 적 증원을 실행하지 않는다.
- 기록은 대화 중의 **대화 기록**, 일시정지의 **대화와 장부 기록**, 제목/여정도의 **기록**에서 읽는다. 이미 접한 장면의 전체 대사를 저장하므로 넘긴 부분도 다시 읽을 수 있다. 기록 열람은 상호작용·보상·합류를 재실행하지 않는다.
- `profile.honroNarrative`에 최대 120개 장면을 중복 없이 보관한다. 기존 저장 스키마·XP·배분·완료 플래그는 변경하지 않는다. Workshop/custom 기록은 해당 전투 상태에만 두며 수련은 캠페인 기록을 만들지 않는다. 메타데이터가 없는 구형 대화도 그대로 이어 읽는다.
- 소단은 적 진영에서도 실제 살아 있는 보스가 발화자로 잡힌다. 두 받이진과 기존 체력 조건을 충족하면 외부 증원 4기의 생성 성공을 확인한 뒤 동맹으로 전환한다. 생성이 막히면 다음 경계에서 재시도하며 중복 생성/부분 협력 전환을 막는다. 합류·비살상 판정·전투 난이도 수치는 유지한다.

설오는 필요한 정보를 곧바로 묻고 판단의 책임을 인정한다. 담허는 현재 관찰로 설명하고 모르는 것은 범위를 정해 답한다. 휘겸은 보호 대상·위치·역할을 말하며 가문 사정으로 대답을 회피하지 않는다. 소단은 다시 사람에게 붙을 위험을 구체적으로 반박하고, 실제 분담이 작동한 뒤 협력한다. 주민 세 명은 각각 가해 충동·아이 보호·소단의 한계를 증언한다.

“지워진 이름을 되찾았다/동행의 이름을 기억했다” 알림을 일반 발견·호송 표현으로 바꾸었다. 물리적으로 내려갈 수 있는데 길이 없다고 하던 설명, 구조 대상의 바깥 매듭을 공격하라는 모호한 안내, 전투 종료 뒤 다시 전투 전 설득을 하던 결말을 정리했다. 후반 지명·조직·왕실 책임·담허 과거·휘겸 가문 진실은 공개하지 않는다.
