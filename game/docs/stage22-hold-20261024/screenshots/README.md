부모 요청에 따른 선별7장이다. 자동 로그/나머지는 `_local`에 유지한다. 최종 후보32d92f6b91fc55562056258e155585864fec5b19, build game.a0095a2a051df30e.js. 기준 master78818166의 build game.43758b5ea28cc2fd.js와 비교했다. 실제 로컬 Chromium390×844 touch의 정상 App.frame/원래 Scene.render를 계속 실행했다. 초기11턴 checkpoint/실제 기록 수령/앞선 구역 정리/접근 위치/카메라만 준비했으며 이후 실제 키보드 이동·동행 선택·방어·읽기·autosave Continue를 썼다. 원본 사용자 세이브·실기기·공개 배포 증거가 아니다.
