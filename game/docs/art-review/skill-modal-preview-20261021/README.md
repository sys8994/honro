## 모달과 시연 변경

모달은 하나의 연속된 테두리·배경·clipping 안에 비스크롤 헤더와 별도 overflow 본문을 둔다. 제목·X·SP 바·장착/회수/강화가 헤더에 있고 본문이 뒤로 들어가지 않는다. 원래 4계열 목록과 SP 바는 보존했다. 증감/장착 뒤 본문 위치와 시연도 보존한다.

각 스킬의 코드상 효과·조건·입력 정책을 [84개 계약](../../SKILL_PREVIEW_SCENARIOS.md)에 매핑했다. 지상 표적은 실제 floor/platform을, 공중 표적은 실제 bat 종류를 쓴다. 모든 발사·명중·회복·소환·패시브는 실엔진에서 발생하며 실제 프로필과 분리된 복제 시연이다.

- 전로시는 실제 추가 입력으로 한 번만 꺾고 전후 실제 궤적과 명중을 보인다. 목재 관통/파괴, 비행 산개, 귀환, 최고점 분열, 밀기·끌기, 공전 검기 등은 해당 조건을 둔다.
- 도형 4종의 원래 캡처는 생성 직후 투명도 0 시점을 잡았다. 도형을 바꾸지 않고 실제 가시 프레임에 촬영했다. 번개·후속 폭발·짧은 추적탄도 해당 시점만 추가 촬영했다.
- 실제 자원·준비/소비·방호·약화·동행 자동조준 가능 여부·포획 피해 전달·분담·소멸 회수량을 관찰줄에 표시한다. 패시브는 동일한 미습득 실엔진과 비교한다.
- 잔부는 실제로 생성되어도 게임 런타임 renderer에 그리는 코드가 없었다. 실제 `occultTraps`의 좌표·남은 턴을 표시하고 발동/만료 후 사라지게 했다. 1280/360px에서 부적 픽셀 153/72와 실제 밟기·주박을 별도로 확인했다.
- 지박부의 저HP 시연은 부적 폭발 도중 생긴 아군 지박령까지 맞는 기존 엔진 동작을 드러냈다. 전투 규칙은 바꾸지 않고 부적 적용→실제 후속탄 처치 순서의 중립 내성 표적을 쓴다. 만혼귀결은 선행 반향령을 제거하고 선택 기예만으로 흩어짐→귀결을 보인다.

## 보존 범위와 한계

스킬 밸런스·효과·투자·성장·저장·인트로/BGM·캠페인 지형·이미지는 변경하지 않았다. 시연의 초기 HP·위치·자원과 입력 정책은 해당 효과를 실제로 발동시키도록 정한다. 각 스킬의 주요 작용을 확인한 것이며 모든 부가 조건·캐릭터 조합·캠페인 지형·확률 분포까지 검증한 것은 아니다. 작은 발사체·소환령과 밀집 피해 숫자에는 판독 한계가 있어 스킬별 기록에 명시했다.

실제 휴대폰 하드웨어가 아닌 Chromium viewport/터치 및 safe-area 에뮬레이션이다. 기존 23장 성장 저장 fixture 실패는 이전 master에서도 재현된 별도 이슈이며 해당 테스트/판정을 변경하거나 완화하지 않았다. master 통합 소스의 로컬 실행 검증을 마쳤다. 공개 Pages 접근 여부와 배포 실행 결과는 로컬 검증과 구분하여 최종 인계한다.
