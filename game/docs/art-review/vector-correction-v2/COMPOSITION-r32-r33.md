# r32/r33 구성 실험 — 채택하지 않음

r31에서 원본→네이티브 경로의 중간 형태 보존 가능성을 확인한 뒤, 배율과 접지 구성을 바꾼 실제 두 후보다. 두 후보 모두 normal/실제 최소 줌을 직접 열어 FAIL로 기록했다. 미달 후보를 완료로 종료하지 않으며 master/Pages는 보류한다.

r32: 여러 암면을 담은 임의 구간을 1.8–2.2world/sourcepx로 배치했다. 그러나 마스크가 실제 바위 외곽을 따르지 않아 암반 창문이 됐고, 넓은 흙 덮개는 또 단순한 띠가 됐다. 폐기.

r33: 원본 픽셀 위에서 개별 암석 외곽을 잡아 배치했다. 모양의 사각 끝은 줄었으나 독립된 돌을 흙 위에 배열한 인상이 강하다. 실제 배치 scale은 2.45–4.5world/sourcepx로, 일부 얼굴은 여전히 과대하다. 파일 상단의 이전 r32 배율 주석은 r33의 실제값을 설명하지 못한다. 수치나 외곽 개선을 장면 합격으로 보지 않는다. 폐기.

형태와 접촉틈을 버려 용량을 줄이는 대신, 원본색 네이티브 영역을 원본좌표128px 크기의 공간 묶음(3,700개)으로 분리해 bounds를 추가했다. 각 색의 연결 성분과 hole은 함께 유지했다. SVG/JSON은 같은 순수 경로이며 매프레임 파싱하지 않는다. 그러나 이 기술 변경 자체를 미술 통과로 세지 않는다.

곡선 실험도 별도로 했다. 모든 작은 모서리에 Q를 넣은 후보는 SVG14.82MB/gzip4.89MB, cubic 적합 후보는10.74MB/gzip4.01MB였다. 실제 소스 확대 비교에서 이득이 작고 용량/기하 비용이 커 런타임에 채택하지 않았다. 현재 기하는 M/L이다. 이로써 경로 방식 자체를 실패로 판단하지 않는다.

다음은 2000world 폭의 실제 게임 카메라 구간 네 장(각 입력1440×2160, 실제 H≈75화면px)에서 각각 장소의 전체 사면을 저작하는 작업이다. 같은 원본을 반복 타일링하지 않는다. 각 구간에 올바른 사람 배율로 큰/중간 형태를 함께 설계하고, 실제 부모가 요구한 상면/가림과 구간 사이의 연결을 닫는다. 이미지 생성 결과는 미승인 저작 참조이며 실행시 래스터로 사용하지 않는다. 작은 파일 목표로 돌아가지 않는다.
