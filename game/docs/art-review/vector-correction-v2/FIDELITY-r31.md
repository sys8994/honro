# 같은 원본 네이티브 경로의 충실도 대조 — 진행 중

부모가 본 r30은 FAIL이다. 이를 원본 참조→네이티브 경로 방식 전체의 실패로 일반화한 판단은 정정한다. 같은 원본에서 팔레트·영역병합·경계 오차를 바꾸면 중간 암면과 접촉 틈이 상당 부분 복원된다. r31은 가능성 검증이며 장면 완성이 아니다.

## 통제한 배율

원본은 1536px가 아닌 실제 **1672×941px**다. r30과 r31 모두 x=-900, y=740, 폭6000world, 1원본픽셀=3.588516746world로 투영했다. 실제 성인 H=103.5world는 원본28.842px에 해당한다. 정상 줌.65에서는 원본1px가 화면2.3325px, 모바일 줌.4에서는1.4354px다. 원본의 작은 경계 손실이 정상 화면에서 확대되는 조건이다. 원본 자체의 큰 암반과 반복되는 경사 배치 문제도 변환 오차와 구분한다.

r30: 작업1000px, 고정8색(+바탕1색), 작은 영역100작업px≈279.56원본px 병합, 경계오차2.6작업px≈4.3472원본px(정상 화면 약10.14px), 경계노드10,713.

r31: 원본1672px, 원본에서 추출48색, 작은 영역12원본px 병합, 경계오차0.55원본px(정상 화면1.283px), 최소 루프 면적4원본px, 경계노드460,909. 파일 크기나 노드 수를 맞추기 위한 추가 축소는 하지 않았다.

## 실제 픽셀 손실

동일1672×941 격자에 경로를 네이티브 Canvas2D로 렌더하고 원본 RGB와 비교했다. 숫자는 미술 합격 기준이 아니다. `loss.json`과 재현 스크립트가 비교 폴더에 있다.

| 단계 | 평균 RGB 절대오차 | PSNR dB | 큰 형태 오차(σ3) |
| --- | ---: | ---: | ---: |
| r30 네이티브 | 13.580 | 22.099 | 8.876 |
| 48색 팔레트만 | 3.806 | 32.526 | 1.974 |
| 작은 영역 병합 후 | 6.216 | 26.431 | 2.935 |
| r31 실제 경로 | 6.233 | 26.585 | 3.261 |

r31은 r30보다 평균오차54.1%, 큰형태오차63.3% 감소했다. 영역 병합이 손실을 다시 키우는 지점도 확인된다. 큰 면만 남기기 위해 더 병합하지 않는다. 원본·r30·r31의 같은 정상 카메라 영역을 `evidence/ferry-fidelity-r31-comparison/normal-source-crop-comparison.png`에 배치했다.

`*-comparison-ready/source-diagnostic-*.png`는 원본을 동일 게임 지형 클립과 카메라에 넣은 **비교 전용 래스터 진단**이다. 배포 후보가 아니며 실제 게임 소스에는 이 오버라이드가 없다. 원경 등 비검토 레이어의 준비 시점 차이는 전체 장면 판정에 사용하지 않는다. 후보 실제 화면과 immutable receipt는 `ferry-fidelity-r31/`, `ferry-fidelity-r31-mobile/`이며 정상/게임 최소줌/모바일 모두 직접 열었다. 모든 오류0, pure true, 촬영 전후 소스 동일이다.

## 용량과 기존 캐시

r31 SVG raw3,810,084 / gzip1,068,225bytes, 실행JSON raw3,807,131 / gzip1,065,671bytes. 기존 원경952,722bytes와 비교하면 gzip은 비슷한 수준이나 경로 초기 그리기 비용은 별도다. 한 번 준비한 Path2D를 재사용하며 매프레임 재해석, 실시간 필터, 근경 래스터 내장은 없다.

동일 Chromium 한 번의 측정(성능 보장 수치 아님): 정상 첫 렌더1425.6ms/3번째1.1ms, 최소줌537.8ms/5.1ms, 모바일728.0ms/0.9ms. 기존 타일RGBA는 정상12타일12,780,288bytes, 최소줌20타일21,300,480bytes, 모바일6타일6,390,144bytes였다. 전체 색 compound가 모든 타일에 다시 그려지는 초기 비용이 커 공간별 가시성 묶음으로 바꾸는 중이다. 이 수치에 브라우저 경로 메모리·번들 문자열·기타 레이어 비용은 포함되지 않는다.

## 판정 및 다음 실제 수정

암면·접촉 틈의 보존 가능성은 확인했다. 현재 r31은 경계 계단, 보행선에서 잘린 큰 암면, 양끝 사각 경계, 원본의 줄무늬 배치가 남아 **장면 미술 FAIL**이다. 같은 전체그림을 과대한 조각으로 맵 전체에 투영하는 것은 해결이 아니다. 다음은 적정 H 배율의 구간 경로를 배치하고 수작업 경계·가림·토사 구조로 하나의 나루 전경을 설계하는 작업이다. master/Pages 및 최종 승인 보류.
