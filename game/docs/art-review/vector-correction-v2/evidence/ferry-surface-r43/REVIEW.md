# 실제 화면 검토 — FAIL / 미승인

composition: **FAIL** — 한 근경 공간 안의 상면 명암을 낮추고 국소 박리면을 더했다. 뒤쪽 지표가 인물과 연결되지만 전체 몸체의 과대한 면은 아직 교정 전이어서 FAIL이다.

hierarchy: **FAIL** — 발밑의 면 위계는 개선됐으나 신규 몸체가 r25 원본보다 훨씬 큰 단순 다각형이어서 최종 위계가 성립하지 않는다.

grounding: **FAIL** — 기존 collision과 독립된 근경 외곽을 사용한다. actual normal/wide에서 인물은 지표 내부에 서고 뒤쪽 땅은 collision clip에 잘리지 않는다.

materials: **FAIL** — 상면의 강한 삼각 대비를 낮추고 일부 노출된 층을 더했다. 전경 전체의 저작 면은 다음 핵심 수정 대상이다.

readability: **FAIL** — actual normal/minimum-wide 확인, 오류0·pure true·전후 sourceHash 동일. 이 중간 버전의 모바일은 별도 촬영하지 않았다.
