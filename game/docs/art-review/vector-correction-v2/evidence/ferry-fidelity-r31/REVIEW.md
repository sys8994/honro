composition: **FAIL** — 동일 원본·투영·실제 인물 배율에서 48색 네이티브 경로를 비교했다. 전경 암반 덩어리는 돌아왔지만 전체 구도는 원본의 줄무늬 암반 배치를 그대로 따르며 양 끝 사각 경계가 노출되어 FAIL이다.
