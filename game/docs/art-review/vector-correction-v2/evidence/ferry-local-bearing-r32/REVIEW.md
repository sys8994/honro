# 실제 normal/wide — FAIL

composition: **FAIL** — 구간별 배율로 줄였으나 마스크가 실제 개별 암반 외곽을 따르지 않아 여러 암반을 담은 잘린 창문처럼 보인다. 실제 normal/wide 둘 다 명확히 FAIL이다.

hierarchy: **FAIL** — 중간 재질은 유지됐으나 넓은 단순 흙 덩어리와 복잡한 창문의 대비만 커졌다. 큰 형태부터 전체 위계를 설계하지 못했다.

grounding: **FAIL** — 흙이 암반 발을 묻는 대신 직사각형/임의 폴리곤 조각 사이를 덮는다. 전경이 한 몸으로 연결되지 않았다.

materials: **FAIL** — 원본48색 재질은 보존하나 단순한 흙의 면과 지나치게 다르다. 작은 배율 조정만으로 통합할 수 없다.

readability: **FAIL** — 실제 두 화면에서 창문/스티커 경계와 넓은 빈 흙을 확인했다. 모바일 확대를 추가해 합격 근거로 삼지 않고 이 구조를 폐기했다.

원본 receipt와 sourceState는 manifest에 연결했다. 오류0, pure true, 촬영 전후 source hash 동일. 최종/모바일 완료 근거로 세지 않는다.
