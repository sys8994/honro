원본1944×809 투명 근경 전체를 uniform2.2배로 사용했다. quietFar는 별도 공유 레이어이며 늘이기/잘라 붙이기/옛clip texture는 없다. 왼쪽 낮은 잔교/실제 물→중앙 길→오른쪽 높은 마당과 사람 크기의 온전한 한옥·문턱/상자/one-way 지붕을 원화에서 저작했다. 집 벽/기둥/뒤 절벽으로 앞 길을 막지 않는다. 기존 물/날씨/처마 서사 실을 유지한다.

기능/예산: ledger 문간 상호작용, 휘겸의 원래 숨김→등장, 소굴2개, 나루장승과 기존 사건 ID/대사/보상 유지. 초기12일반+장승1과 ID별 HP/공격/기예/XP/행동cap/증원 수 불변이다. 원본·clone·실제 관련 스폰을 새 좌표로 재배치하며 clone 쌍은 반복하지 않는다.3장 revision만1→2다.1·2장과4장이후/11장WIP 저작 소스를 바꾸지 않았다.

확인: 주요길 기본 이동/도약1회, 상자→지붕 도약2회와 지붕 보행/하강→ledger 획득, 초기 접지/flightClear/관련spawn, 물1개와 old3장 restart를 국소 확인했다. 이 이동/장부 검사는 적 없는 geometry fixture이며 전투 흐름 증거가 아니다.

실제 Chromium App에서는 원래 입장 연출 뒤 휘겸이 등장하고, 초기13적을 유지한 채 두 영웅이 일반 대기했다. 원래 동행/적 AI의 첫 적턴에서 박쥐가HBT01, 산개가 이동 후HBR01, 장승이 얕은 바위에서 잔교로 접근 후HWD01을 실제 발사했다. 종료 시13적 전원 생존/설오HP425/담허HP454/휘겸 유지, 강제 각성/순서/배치/피해나 적 제거는 없다. 전체 전투 완주·모든 역할군/기예 검증은 아니다.

실제3뷰 pageerror0, sourcefilter2/farcanvas1이며 같은 원화 두 source를 공유한다. 초기3뷰 뒤 material 분류와 미사용 forestChoice metadata만 정리하여 최종 build를 갱신했고 그림·vertices·배우·구도는 동일하다. 통과한 기능 검사를 반복하지 않았다. 공용library 자산 사용처가 바뀌어4/7/9의 생성 asset index도 재배분되지만 해당 장 저작/미술/지형 소스는 미수정이다.

정확한 카메라/해시·동작/스폰/저장 검사 범위는 manifest.json에 있다. 전체verify/무관 장·기예/별도 검수자는 실행하지 않았다. 부모 실제 화면 확인 전 master/Pages 미반영이다.

이미 일반 도약으로 도달한 우측 지붕 착지 지점의 별도 기본 사격 probe에서도, 원래13적/온전한 지형을 유지한 채 A01로 아랫길 적에게 실제87피해를 확인했다. 이 사격 probe는 영웅 시작 위치만 해당 착지점으로 초기화했으며 전체 정상 전투 완료 증거가 아니다. 코드/그림/기존3뷰 변경 없이 결과만 manifest에 추가했다.
