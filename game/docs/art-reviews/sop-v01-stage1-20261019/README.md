분리된 회색 다각형을 없애고 원화 앞쪽 바위 두 개의 큰 색면/윤곽을 작은 캐시로 추출했다. 여섯 돌턱은 해당 윤곽과 같은 one-way 접촉면을 사용하며 몸체가 아래 기존 암반/뿌리로 이어진다. 소나무 첫 진입은 원래 보이는 바위 경사를 사용해 보조 한 개를 제거했다. 그림/캐릭터를 새로 흐리게 하거나 디테일을 추가하지 않았다.

월드6000×2698.3957와 줌 범위는 그대로다. camera artBounds.bottom만 원화가 가로로 이어지는 source780으로 두어 하단 투명 영역이 빈 띠로 보이지 않게 했다. 더미지형/새 지하색/경계 합성은 추가하지 않았다. 같은 카메라 요청 중 y중심만 전경 coverage에 따라 clamp된다. 바뀐 소나무 진입의 정상 점프만 통과, build/실제 전체·근접 각1뷰 pageerror0. 주 경로·적·목표·전체 방어전은 반복하지 않았다. 정확한 좌표/범위/이미지바이트는 manifest.correction에 있다.

주 경로 이동·일반 점프로 오른쪽 높은 출구 도달/arrival 준비, 고목 가지 접근, 상부 선택 사격대 접근을 적 없는 지형 fixture에서 확인했다. 초기 적8개/ID별 능력/행동 cap2를 보존하며 지상 접지/비행 여유를 확인했다. 확장된 지형을 옛 playProjection5400폭으로 잘라내던 상속값을 제거했고1장 revision3만 적용했다. 전체 방어전/기예/verify는 실행하지 않았다.

최초 기능 확인 초안은 추가 돌턱의 단순 다각형 표현이 부모 검수에서 거절되어 위 보정본으로 대체됐다. 현 상태를 먼저 원격 저장해 전체 구도/재채색 및 지형을 볼 수 있게 한다.2~5장 runtime은 아직 변경하지 않았다. 원본PNG와 lossless1MB미만WebP, 정확한 카메라/실제 확인 범위는 manifest.json에 있다. master/Pages 미반영.
