# SOP v0.1 · 3장 나루와 창고

[실제 전체 화면](stage3-01-ferry-warehouse.webp). 원본 PNG와1MB 미만 lossless WebP를 보존한다.

승인1983×793 재채색을 uniform7000/1983배,7000×2799.294world로 적용했다. 낮은 진입 나루→긴 기슭→중간 흙길/계단→창고 문턱을 연결하며 기존 흙길·지붕을 one-way로 쓴다. 세 개의 필요한 보조 바위는 같은 원화의 큰 바위 윤곽/몸체를 추출해 기슭·석축·창고 옆의 지지부에 붙이고 접촉면을 공유한다. 앞쪽 장식 나루로 새 앞뒤 전투 차선을 만들지 않는다.

장부 ID/문간 상호작용, 휘겸 등장, 나루장승/초기13적·ID별 능력·종·군집·cap/기존 이벤트·물·대사·보상은 유지한다. 이벤트와 원본/clone은 새 지면/공중으로 옮기며 같은 두 마리 쌍을 반복하지 않는다. 서사 실은 새 창고 상인방/문 위 목재에 부착한다.3장 revision3만 적용한다.

최소 확인: 나루 진입부터 문 앞까지 정상 이동/점프와 실제 장부 획득, 도달한 창고 마당에서 분기한 지형 fixture의 정상 지붕 점프·보행과 출구 접촉 통과. 상호작용 fixture의 marker 인자 오타만 바로잡고 이미 통과한 주 경로는 반복하지 않았다. 초기13 능력/접지·flightClear, build/실제 입장 후 휘겸 표시/전체1뷰 pageerror0. 전체 전투/무관 기예/전체verify와1·2장 검사는 하지 않았다. 정확한 카메라와 실제 범위는 manifest.json. master/Pages는 미반영.
