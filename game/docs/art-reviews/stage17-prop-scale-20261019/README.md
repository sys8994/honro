시각 전용7개 소품에만 기존 authored scale×.55를 적용한다. art.props 원래 배율은 그대로이며 최종 placeOn에 표시 배율을 넘긴다. 재실행해도 누적 축소되지 않고 바닥 support의 x/y와 원본 벡터 모양/디테일을 보존한다.3개 등불의 조명 x/y도 최종 표시 배율로 계산한다. 호이스트/구조물·발판/충돌·거대 묵종·캐릭터·지도/사거리·퀘스트/ID와 전투revision은 바꾸지 않는다.

설오 H103.5world를 기준으로 서측 작업대 상판 기준선139×.561=77.979world(.753H), 긴 곡괭이272×.561=152.592world(1.474H), 입구 목재 지지대277×.572=158.444world(1.531H)다. 이 값은 해당 기준선/지지대의 높이이며 전체 그림 bounds를 사람 키로 오인하지 않는다.

실제 Chromium Game 화면1장,3000×2000/줌.6이다. 멀리 떨어진 입구 목재(1120,4300), 서측 작업대(2030,4413), 하부 기름등(4350,6093)을 같은 정상 배율에서 함께 보기 위한 큰 viewport다. 왼쪽 설오는 기존 입구 바닥의(1350,4324)에 둔 비율 검수 fixture이며 접지를 확인했다. 정상 캠페인 완주/이동 검증을 주장하지 않는다. 큰 구조물과 적은 원래 크기 그대로 보인다.

미술 author2회 재실행의 stage 결과 동일, 실제 변화는7개 scale+6개 light 좌표뿐이다. 다른29장·원본 library 자산/순서·지형/유닛/퀘스트/revision은 동일하다. 필요한 build1회 후 외부 chapter17 표시 배율/앵커와 runtime 값7개 일치, 콘솔0을 확인했다. 생성된 chapter17-assets를 포함한 다른59개 chapter/asset payload는 기존과 같은 해시이며,1장과 쉼터 변경도 보존됐다. 전체verify/기예/전투전수/모바일/성능 검사·추가 검수자는 실행하지 않았다. 공개 화면 확인은 부모 담당이다.
