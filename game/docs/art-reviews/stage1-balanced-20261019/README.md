# 승인 balanced 산림 · 1장 실제 화면

[정상 배율](stage1-normal.webp) · [전체 구도](stage1-overview.webp) · [모바일 최소 줌](stage1-mobile-minimum.webp)

승인 PNG를 원본 그대로 보존하고 보이는 픽셀 차이0의 lossless WebP로 배포한다.1774×887을 uniform6000/1774배,6000×3000world로 사용한다. 근경 추가 brightness/filter 없음; 독립 quietFar .68·물/날씨·로딩 그룹화·전술 줌/팬·캐릭터 원본 유지. 그림의 실제 흙길/뿌리/돌/상부 둑에 접촉을 맞췄으며 새 그림·타일 반복·떠 있는 회색 발판/지형 texture clip은 없다. 외곽은 비충돌이며 깊은 면의 감쇠는 최하단 보행면 아래에서 시작한다.

확인은 build1회, 기존8적/cap2·ID별 능력·이벤트 의미 및 초기 지상/공중 접촉, 적을 생략한 native geometry fixture의 주 경로/높은 출구·낮은 뿌리·고목 돌출 가지·중간 바위·상부 사격대다. 선택 경로는 주 경로의 실제 도달 지점에서 분기했다. 기존1장 전투만 revision2→3으로 재시작하고 성장/SP·장착/완료를 보존하는 정책1사례도 확인했다. 전체 전투·다른 장·기예/전체verify는 실행하지 않았다.

실제 Chromium1440×960 정상(.6)/전체(.24),390×844 실제 pinch 최소(.05735294) 화면이다. 콘솔 오류0, 이미지 요청은 quietFar/stage1BalancedNear 두 개뿐이며 정적3프레임 동안 이미지/캐시/필터 수와 전투 데이터가 안정적이다. 캐시 필터1회는 원경에만 적용되며 새 근경은 정적 승인 톤이다. Library 저장은 네트워크 오류로 실패하여 이 파일들을 전달본으로 보존한다. 상세 수치·국소 확인 범위는 manifest.json에 있다. 공개 Pages 상태는 최종 작업 보고에서 구분한다.
