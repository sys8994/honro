## 증거 수준과 손실
이 문서는 2026-11-17 조사 당시 이 스레드에 남은 도구 출력/이미지 관측/보고를 복원한 것입니다. 현재 환경에서 재실행하거나 원격 현재 상태를 검증한 결과가 아닙니다.
- 원본 REPORT.md, final-roster.json, 도식 3장, 추가 Scene PNG는 환경 재생성으로 소실되었습니다. 이 작업자는 그것들을 원격/Library에 보존한 적 없습니다. 아래 예전 파일명은 증거의 출처 기록일 뿐 현재 접근 가능한 첨부가 아닙니다.
- 조사 당시 game/tests/helpers.mjs runtime({legacyMaps:false,productionStory:true}) + battlefield()로 HonroWorld.build → sanitizeStageBattle → Engine 이후 side=1 초기 roster를 1~30장 모두 추출했습니다. 지형 polygon/marker와 대조한 도식 3장도 직접 보았습니다.
- A: 최종 초기 roster/지형/목표 데이터와 도식 확인. B: 실제 production Scene 렌더 픽셀 확인. C: 실플레이·증원후 위치/공격 검증. 전 장 A 수행, 아래에 명시한 장만 B 수행, 이 작업자는 C 미수행입니다.
- Native Canvas production Scene은 Chrome 실제 게임 플레이와 다릅니다. 29장 Chrome CI 원본도 보았으나 전체 행렬은 화면 가장자리였으므로 보스 근접 판정은 Native 신규 렌더에 근거합니다.
- 아래 side1 수에는 목표 타격물/영혼 actor가 섞여 있습니다. 몬스터 수라고 부르면 안 됩니다.
- 13/29 수정 제안 이후 이 작업자가 게임 파일을 수정하거나 branch/commit/push한 사실은 없습니다. 이후 타 작업자의 변경 여부는 이 문서로 판정할 수 없습니다.

## 추가 해석 주의
1막 clone은 shared/runtime/encounters.js의 structuredClone(u)로 원본 group/role을 상속합니다. s.encounters.unitIds에 clone ID가 없다는 사실만으로 활성화 기능버그를 주장하지 않았습니다.
13장 최종배치출처는 shared/data/act2/stage13-compact-package.json의 stage.units. 29장 기존경비는 shared/data/campaign.json, 추가보스/방패는 shared/runtime/act23-v4-stage29.js. 이는 당시 코드 읽기 결과이며 현재 원격 최신 파일은 재검증 필요합니다.

복원자는 원본 캡처 재생성·수정·현재 브랜치/CI 검증을 수행하지 않았습니다. 후속 담당자는 이 문서를 과거 조사 기록으로만 사용하고, 수정후 sanitize 최종 위치·지지면·몸체·필수 퀘스트 계약을 새로 검증해야 합니다.
