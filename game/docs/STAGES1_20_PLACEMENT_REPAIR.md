# 1~20장 배치 결함의 국소 교정

기준은 `1fb64610`이다. SOP의 설계 카드 → 지형·동선 → 아군/NPC → 적 → 이벤트·대사 순서로 기존 계약을 확인했다. 공통 벡터 연결과 기존 배치의 품질은 구분한다. 이번 수정은 확인된 공중 몸체 충돌과 역할 없는 긴 공중 순회선을 교정하며, 지형·건축·공통 런타임·생성 번들은 수정하지 않는다. 기존 사건, 필수 경로, 목표, 아군/NPC, 초기 적 수·능력·정예·행동 상한·증원은 보존한다.

## 11장 첫 수정 단위

- 전투 의도: 서측 매듭 → 중앙 의식 → 주민 구조 → 동고지와 흔적 길. 최근 개편의 경계조·보호 여백·유한 증원을 유지한다.
- 주민 입구의 까마귀 `rv11-refuge-two-levels-0`는 `rv-root-arch` 윗면과 몸체 여유가 겹쳤다. 같은 x에서 y를 30 줄여 입구 엄호 역할을 유지한다.
- 동고지 박쥐 `rv11-east-stone-overwatch-7`와 정예 까마귀 `rv11-east-stone-overwatch-9`는 위쪽 `rv-east-windswept-bough`의 아랫면에 걸렸다. y를 각각 20, 130 늘려 같은 상단 사격대와 가지 사이의 열린 공중에 둔다. 가장 가까운 지면으로 내리거나 다른 군집으로 보내지 않는다.
- 53명(붙은 혼 포함), 행동 상한 4, 군집·정예·스탯·목표·지형·주민 여백 불변. 자연 물리 2초에서 좌표·HP가 안정적이며 전체 초기 공중 적의 `flightClear`가 참이다.
- 같은 지지면에 아군을 한 번 배치한 국소 교전에서 주민 입구 까마귀와 동고지 박쥐의 실제 AI 사격·탄도로 각각 26·30 피해를 확인했다. 정예 까마귀의 유효 사격 선택도 확인했으나 그 발사는 피해 0이었다. 정상 입장부터 도달한 플레이 증거와 구분한다.
- 실제 Scene Native Canvas의 같은 카메라 전후 캡처: `_local/reports/stages1-20/stage11-{refuge,east}-{before,after}.png`. 실제 브라우저·정상 연속 완주·난이도 승인을 뜻하지 않는다.

## 통합 방법

`tools/map-forge/stages1-20-clearance-patch.mjs`의 `applyChapterClearancePatch(project, stageId)`는 지정된 장의 명시된 배우 좌표와 기존 encounter-site 좌표만 바꾸는 재실행 가능한 함수다. 다른 담당의 최신 `campaign.json`에 필요한 장 ID만 적용한다. 파일 전체를 오래된 사본으로 교체하지 않는다. 11장 원본 저작 함수의 lift도 같은 값으로 고쳐 재생성 시 되돌아가지 않는다.

이번 변경에는 지형 교체가 없으므로 공통 map revision은 올리지 않는다. 저장된 진행 중 전투를 재배치하거나 재시작하지 않으며 새 진입·재시도에서만 새 초기 좌표를 사용한다. 이후 통합에서 실제 지형이 바뀌는 장은 부모 담당이 해당 장 revision만 올리고 기존 성장·장착·진척 보존 경계를 적용한다.

다섯 장의 초기 공중 적 모두 `flightClear`를 통과했고, 수정한 여섯 체는 2초 자연 물리에서 좌표·HP가 변하지 않았다. 실제 지지면에 한 번 배치한 동행을 향한 AI 선택과 실제 탄도로 13장 48, 15장 41, 16장 46, 17장 30, 18장 낮은 박쥐 27 피해를 확인했다. 18장 위쪽 박쥐는 다른 동행을 향한 사격을 선택했으며 지정 관측 동행의 피해는 0이었다. 모든 적에게 피해를 강제하거나 전 장 완주를 주장하지 않는다.

재생성 원본은 `stage9-13-tactical.mjs`, `forest-cavern-topology.mjs`, `stage16-temple.mjs`, `stage17-worksite.mjs`, `stage18-bell.mjs`에 같은 좌표/상대 높이를 반영했다. 18장과 19장을 함께 재저작하지 않았고 19장의 활성 데이터는 동일하다. 각 장의 전후 화면은 `_local/reports/stages1-20/stage{13,15,16,17,18}-*-{before,after}.png`다.

## 유지한 장과 검증 범위

1장의 기초 학습과 이전 짝 배치 교정, 2장의 높은 왼쪽 능선 엄호, 4장의 피란문 방어, 5장의 물길 의식과 직접 닿지 않는 폭포 뒤 주박, 6장 호송, 7장 주민 구조, 8장 상여, 9~10장 소단 연결은 유지한다. 12장의 최근 채석터 편성과 14장의 수직 주민 구조, 19장의 종 내부와 20장의 생존자 호송도 유지한다. 실제 변경이 없는 장의 이동·전투 전수 검사는 실행하지 않았다.

원본 JSON을 `1fb64610`과 구조적으로 비교하여 아홉 체의 x/y·존재하던 spawn 좌표와 해당 encounter-site x/y 이외의 모든 장 필드가 동일함을 확인했다. 공통 library도 동일하다. 필수 경로·지형·증원·이벤트·대사·정예·능력/보상은 바뀌지 않는다. 새로운 지형 리비전이나 저장 이관이 필요한 변경은 없다.
