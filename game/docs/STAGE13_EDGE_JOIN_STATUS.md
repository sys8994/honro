## 상부 roof는 자르기가 아닌 원래 물리 윤곽
수목 자산은 없고 상부 핵심은 traced-roof-v2다. 화면상 높은 질량의 윗면이 보이지만 원본 canonicalSolid 꼭짓점(8075.8,−1900)을 compact X .225*x+3355,Y−1900으로 바꾸면(5172.055,−3800)이며 실제 cave-roof 물리점과 정확히 같다. 이후(5200,−3791.748),(7605,−3600),(10200,−3700)으로 이어지는 원래 윤곽이다. 등록bbox가 자른 것으로 오인해 위쪽을 임의로 채우지 않았다.

최종roof alpha는 등록범위 안이다. 이 검사는10 world-unit/pixel 표본이므로 미세픽셀 전수 보증이나 모든 최대줌 판정이 아니다. 원본과 배치는 변경하지 않았다.
