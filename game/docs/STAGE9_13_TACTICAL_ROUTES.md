# 9·13장 선택 경로 제작 계약

## 범위

`tools/map-forge/stage9-13-tactical.mjs`의 `applyStage9And13Tactical`가 최종 장소/퀘스트 후처리 뒤에 적용된다. Game·Workshop·Playtest는 같은 캠페인과 충돌체를 사용한다. 별도 렌더러나 새 이동 능력은 없다. 9장의3600×3500과13장의8200×6600, 기존 NPC 지면과 목표·사건·적 총원/수치/자원은 유지한다. 기존 고정 비행 사수의 높이만 새 실고체 위로 옮긴다.

## 9 바람 없는 마당

- 서쪽은 낮은 무너진 회랑의 실제 암석 상판과 아래의 주민/받이진 접근길이다.
- 동쪽은 높고 짧은 석축 어깨와 양끝의 뿌리/목재 접근경사다. 서쪽과 높이·오르내림·사선이 다르다.
- 받이진 사이 바닥 귀환은 새 강제 순서나 직업기예 없이 계속 보행한다. 소단/NPC와 대피/받이진 사건은 변경하지 않는다.

## 13 숨은 석문

- 입구 돌출 어깨는 짧은 평참 뒤 비대칭으로 내려가는 두꺼운 암괴다. 아래쪽 석공 접근을 차폐하면서 위쪽 곡사 자리를 준다.
- 문 안의 옆굴은 평평한 작업 참과 꺾이는 동쪽 귀환, 두꺼운 천장 아래 짧은 통과구다.
- 바닥과 석문을 뚫지 않는다. 위쪽 길도 문 서쪽/동쪽에 각각 닫힌다. 구조→석문→출구 목표,12장 분기별 입장과14장 연결은 그대로다.12 A입장의 기존 전정 사격발판은 의도적으로 보존한다.
- 새로운 평범한 길은 모두 기본 이동·기본점프로 접근한다. 추가 보상/기예·진목/축지는 요구하지 않는다. 경사 양끝의 낮은160높이 진입을 사용하면 아래길을 걷거나 위길로 뛰어들 수 있다.

## 미술/충돌

실고체는 외곽선과 실제 두께가 있고 기본탄을 차단한다. 접근 목재는 기존 one-way 규칙이다. 뒤쪽 모암은 실제 바닥에 접지된 낮은 대비의 무윤곽 vector이며 충돌·가짜 발판 테두리가 없다. `stage9:tactical-recessed-support`와`stage13:tactical-recessed-support`만 추가된다. 기존 승인 원경은 변형하지 않는다.

## 검증과 현재 한계

- `tests/stage9-13-tactical-traversal.mjs`:8개 저작경로×양방향×4체형64조건. 실제 Engine 걷기/기본점프를 사용하고 목표에 포즈를 보정하지 않는다. 시작위치1회 초기화, 적 제거와 이동예산 갱신은 고립 물리검사를 위한 것이므로 정상전투 완주라고 부르지 않는다.
- `tests/stage9-13-tactical-contracts.mjs`:저작 멱등, 범위밖28맵/기존 목표·사건·지면·자원 보존, 새/옛9·13 지형의 실제 App export/import/Continue 왕복. DOM/저장소는 격리된 테스트 더블이다. 실제 사용자의16장 저장이나 원본fixture는 바꾸지 않는다.
- `tools/environment/capture-stage9-13-tactical.mjs`:동일 카메라5개 production Scene Native PNG. `before --project=<기존캠페인>`으로 전후 비교한다. Native는 브라우저 입력/정상전투 증거가 아니다.
- 독립검수에서 첫 초안의9서회랑 경사 접점에1프레임 invalid contact가 관측되었다. 영구 복귀불가는 아니었으나 경사와 실고체 상면의 접점을 정확히 맞추는 후속교정을 했다.
- 정상 자원 전투, 실제 반사/관통의 전술효과, 새 Pages와브라우저 Game/Workshop은 별도 독립 검수 및 통합 배포 단계다. 모든검수 완료 전에는 최종 디자인 합격으로 보고하지 않는다.
