# 2장 이미지 우선 협곡 저작

2026-10-19. 1장 검수 브랜치와 별도 worktree/브랜치에서 제작한다. 원본 벡터 지형·실루엣·좌표·맵 스크린샷·충돌 마스크를 이미지 생성에 입력하지 않았다. 승인 원본의 회화/깊이 감각과 1장 신규 원화의 재질만 참고하고, 연속 하부 흙길·양쪽 독립 절벽·상부 교전·동쪽 상여 출구라는 기능으로 독립 장소를 먼저 생성했다. 두 번째 원화 편집에서 자연스러운 낮은 바위 어깨를 보완한 뒤 실제 그림 안에서 접촉선을 읽었다. 원화에는 인물·상여·적·UI가 없다. 최종 원화 원본 PNG는 Library `libfile_6ff075fc607481918eabe0eff59a24f2` v1로 보존하고 배포용은 `shared/assets/environment/stage2-image-first/place.webp`다.

`tools/map-forge/stage2-image-first.mjs`가 1536×1024 원화를 균등 2.4배로 놓고 길 내부의 접촉점을 저작한다. 하부 흙길은 작은 기복만 있는 연속 solid이며 점프 없이 통과한다. 뒤쪽 독립 절벽의 상부/어깨는 one-way 접촉 면이다. 절벽 몸체 그림을 하부 행렬 앞의 충돌 벽이나 천장으로 만들지 않는다. 실제로 밟는 면만 원화의 넓은 상면 안에 놓아, 행렬은 앞쪽 길을 계속 지나고 설오는 뒤쪽 높은 길에 설 수 있다. 양쪽 바위 어깨는 기본 점프로 연결된다. 구형 장식·바위 에셋 충돌·그림과 맞지 않는 나무 가지 계단은 이 장에서 제거하고 새 원화의 바위 어깨로 교체했다. 앞쪽 고유 암반/흙/물은 그림 아래까지 이어지며 토양 단면이나 반복 재질이 아니다.

설오/상여/동행/NPC/적 원본과 비위치 능력·HP·XP, 초기 6체+추가 편성 6체, 행동 상한 3을 유지한다. 원본 및 런타임 추가 편성은 왼쪽 절벽 접근 2체, 중간 행렬 길목 2체, 오른쪽 둥지 4체, 출구 방어 4체로 나누며 빈 연결 구간을 둔다. 추가 편성은 `stage2-image-first-roster.js`에서 새 전투에만 배치한다. 저장 전투 위치는 재배치하지 않는다. 공중 추가 개체는 기존 `flightClear`로 몸 전체 여유를 확인한다.

`procession-seen`, `road-pressure`, `sniper-seen`, `right-cliff`, `last-flight`의 ID/대사/행동 의미/연쇄 조건과 유한 증원 수를 유지한다. 위치 기반 progress와 road-pressure의 진입점만 새 장소에 맞춘다. 상여의 기존 도착 계약 `honroEscortGoalX=3340`과 `honroStage2AirborneRevision=1`을 유지한다. 원화 생성 후 선택한 단일 배율에서 이 도착점은 그림의 동쪽 흙길 안에 위치한다. `stage2-airborne.js` 원본은 수정하지 않아 경고→새 대응 기회→방출, 안전 경계의 유한 진입, 기존 공중 이동/공격을 그대로 사용한다.

전용 `stage2-image-first-art.js`만 이 장의 opt-in에 응답하며 1장 렌더러나 공용 암석 함수를 수정하지 않는다. 장소 원화는 지형 마스크·타일 재질·띠 변형 없이 한 균등 변환으로 그린다. 최초/정상 요청은 이 장 원화 1개이며 다른 장소 원화를 디코딩하지 않는다. 공유 월드 캐시를 사용하고 매 프레임 재질 필터/새 RAF/나무 모션을 추가하지 않는다. 기존 날씨·전도성 얕은 물 두 곳과 기존 수면/접촉 파문 구현은 보존한다. 수면은 새 길의 작은 젖은 구간으로 옮기고 불투명 카드가 그림을 덮지 않도록 이 장에서만 얇게 합성한다. 충돌 디버그는 기존 실제 외곽선이며 기본 꺼짐이다.

현재 한계: 원경을 포함한 단일 장소 그림이므로 공유 원경과 독립 깊이 시차는 아직 적용하지 않았다. 그림의 실재 범위 안에서 카메라를 제한해 가로/세로/줌아웃에 그림 끝을 노출하지 않는다.
