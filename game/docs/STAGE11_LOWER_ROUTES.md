# 11장 하부 암대와 추락 복귀

11장의 하부는 필수 주민 암대, 선택 서측 회귀로, 추락받이로 구별한다. 추락받이는 별도 탐색/전투 장소가 아니지만, 실제 도달한 동행이 갇히지 않도록 기존 회귀 뿌리로 돌아갈 수 있어야 한다.

| 지형 ID | 실제 상면 범위 | 역할 |
|---|---|---|
| `rv-ritual-buttress` | x5400–9500, y6710–7600 | 중간 의식 암대 |
| `rv-root-east-descent` | (9500,7600)→(11000,8630) | 주민 접근 동측 내리막 |
| `rv-lower-refuge-rock` | x6800–11300, y8600–8850 | 주민 x9700, 구조 관련 적/혼이 있는 필수 하부 암대 |
| `rv-lower-west-shelf` | x4000–6800, y8740–8900 | 의식 암대 아래 선택 서측 회귀로 |

| `act2-floor` | 서측 (2300,8000)→(4000,10000), 중앙 y10500 등 | 낙하 피해가 적용되는 추락받이. 밝은 rim은 최초 진입 x0–1500에만 표시 |

주민 접근은 의식 암대→동쪽 뿌리 끝→북측 흔적 능선 x11200 부근→주민 암대로 되돌아오는 선이다. 서쪽 긴 암대를 왕복할 필요가 없다. 현행 목표 overlay는 주민 구조 후 북쪽 흔적 조사로 끝나며 x10350의 옛 `clear-road` 표식을 잔당 전역 정리 의무로 설명하지 않는다.

서측 암대는 주민 구역에서 물러나 의식 암대로 돌아가는 선택 경로다. 구조 후 북쪽 출구로 가는 지름길이나 보상 길이 아니다. 실제 주민 구역의 기본파는 기존 적에게85피해를 줬지만, 서측 중앙의 실제 pose에서 가까운6적에 대한 기본파 유효 사선은 확인하지 못했다. 공격 명당이나 필수 탐색 길로 과장하지 않는다.

이전90d77eed에서는 서측 암대 밖으로 떨어지면 HP53을 잃은 뒤 바닥 서쪽 (2486,8219)에서 암괴 밑면에 머리가 막혔다. 바닥 경사1.176은 허용1.35 이내지만 높이92인 몸에 통로가92.384px뿐이다. 그 자리 점프 상승0.953px, 열린 곳의 기본 점프 상승213.615px였다. 동쪽도 (3994,9992)의1092px 벽에 막혔고 이동력이 남아 있었다. rim 제거만으로 끝낼 수 없는 softlock이었다.

현행은 같은 뿌리의 기부를 바닥까지 내린다. 바닥에서 x3490으로 접근해 기본 점프로 x3540 뿌리에 올라 x4000까지 이동하고, 기존 암대 접점 x4030에서 다시 기본 점프로 x4080의 상부 뿌리에 접속한다. 의식 암대로 복귀하면 기존 주동선에 다시 합류한다. `fall-bed-recovery` route는 이 두 실제 점프를 명시한다. 새 적/이벤트/워프/자원 보정은 없다.

실제 실패한 두 저장을 이어 사용한 국소 회귀 검사에서 서측 R59→62, 동측 R61→64에 복귀했다. 각각 기본 점프2회·일반 이동력 갱신 대기3회이며, 기존 낙하 피해 후 HP692/기력245와 적37명을 유지했다. fixture 난이도는 원래 저장의 `explorer`다. 생산 Game의 Ctrl/방향키로 두 접점도 독립 확인했다. 전체59턴이나 전 캠페인을 다시 실행한 증거가 아니다.

이 국소 검사의 **테스트 전용 지형 재적용**은 새 원본에서 컴파일한 뿌리 record만 충돌/월드 뷰에 적용하며, 모든 인물의 좌표·HP·기력·이동력·적·임무는 그대로 둔다. 게임의 일반 Continue에 이 어댑터를 넣지 않는다. 배포에는 기존 장별 map revision 정책을 사용한다: 11장 revision1/geometry7로 옛 전투만 같은 장에서 새로 시작하며 성장·SP 배분·장착·완료/보상 장부는 보존한다. 같은 revision 및 Workshop은 보존한다. 무손실 낙하 워프나 전투 중 강제 좌표 이동이 아니다.
