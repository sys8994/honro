# 11장 하부 암대와 추락받이

11장의 하부는 필수 주민 암대, 선택 서측 회귀로, 추락받이로 구별한다. 적이나 보상이 없는 모든 바닥을 탐색 경로로 안내하지 않는다.

| 지형 ID | 실제 상면 범위 | 역할 |
|---|---|---|
| `rv-ritual-buttress` | x5400–9500, y6710–7600 | 중간 의식 암대 |
| `rv-root-east-descent` | (9500,7600)→(11000,8630) | 필수 주민 접근을 위한 동측 내리막 |
| `rv-lower-refuge-rock` | x6800–11300, y8600–8850 | 주민 x9700, 구조 관련 적과 혼이 있는 하부 암대 |
| `rv-lower-west-shelf` | x4000–6800, y8740–8900 | 의식 암대 아래 선택 서측 회귀로 |
| `rv-root-west-return` | (4000,8900)→(5400,7080) | 서측 회귀 뿌리. x4030 부근에서 기본 점프로 접속 |
| `act2-floor` | (2300,8000)→(4000,10000)→(6000,10500) 등 | 낮은 추락받이. 서쪽 최초 진입 x0–1500 이외는 주동선이 아님 |

주민 접근은 의식 암대→동쪽 뿌리 끝→북측 흔적 능선 x11200 부근→주민 암대로 되돌아오는 선이다. 주민 암대에 도달하려고 서쪽 긴 암대를 왕복할 필요가 없다. 현행 목표 overlay는 주민 구조 후 북쪽 흔적 조사로 끝나며, x10350의 옛 `clear-road` 표식을 전역 잔당 정리 의무로 설명하지 않는다.

서측 암대는 주민 구역에서 떨어져 재정비하거나 의식 암대로 돌아가는 선택 경로다. 구조 후 북쪽 출구로 가는 지름길이나 별도 보상 길이 아니다. 실제 정상 저장에서 담허의 주민 암대→서측 암대→뿌리→의식 암대 복귀에 기본 점프 1회, 이동력 갱신 대기 5회가 들었다. 길 자체의 공격 사선 이득은 확인하지 못했다. 긴 무교전 구간이므로 선택 회귀라는 표기를 유지한다.

2026-10-21 국소 검수에서 서측 암대 밖 (3956,9948)로 떨어진 담허는 `act2-floor`에 착지하며 53 피해를 받았다. 서쪽으로 올라가면 (2486,8219)에서 서측 어깨 암괴 아래에 막혔고 기본 점프 13번째 시도 제한에서 중단했다. **이 바닥의 정상 복귀는 통과하지 않았다.** 추락받이의 지형을 안전한 회귀로로 안내하지 않는다. 모든 방향의 탈출 불가를 증명한 검사는 아니며 복구 발판이나 낙하 복귀 규칙을 새로 만들지 않았다.

표현은 기존 물리와 별개다. `stage11-landscape-art.js`는 실제 두 회귀 접점에만 짧은 표식을 그리고, 깊은 `act2-floor`의 밝은 보행 rim을 끈다. 공통 `terrain-readability.js`도 같은 판정으로 밝은 상면만 제외하며 어두운 고체 외곽선은 남긴다. 최초 진입 바닥, 실제 암대와 뿌리의 보행 rim, 다른 장과 opt-in 없는 구형 전투는 유지한다. 지형/유닛/목표/성장/SP/보상/저장 revision은 바꾸지 않는다.

실제 엔진 입력은 정상 저장의 생산 Continue 이후 `move/jump/select/wait/tick`으로 수행했다. 적 삭제·좌표 강제·자원 무제한 없이 담허의 필수 진입(41→44라운드, 적42 유지)과 선택 복귀(54→59라운드, 적37 유지)를 서로 다른 정상 체크포인트에서 확인했다. 새 캠페인 전체 완주나 모든 동행/빌드의 검증은 아니다. 3회 집중 검수와 최종 원본 PNG·trace는 `_local/reports/stage11-lower-review/`, 상세 일회성 보고서는 `_local/archive/stage11-lower-route-review.md`에 보존한다.
