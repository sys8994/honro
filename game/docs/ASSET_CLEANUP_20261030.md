# 전체 자산 정리 — 2026-10-30

## 범위와 결과

이번 정리는 실행 그래픽·초상화·오디오·폰트, 편집기 자산, 제작 원본, 검사 입력, 과거 검수 출력, 생성된 웹 파일을 구분하여 진행했다. 파일명 검색에 나오지 않는다는 이유만으로 삭제하지 않았다.

- 정리 전 검증 작업본의 추적 파일: 16,240개, 약 2.257GB.
- 정리 후 추적 파일: 약 1.139GB. 이는 최신 파일 집합이며 Git 과거 이력을 삭제하거나 줄였다는 뜻이 아니다.
- 현재 게임 빌드 그래프: 116,819,329 → 65,150,170바이트, 약 44.2% 감소.
- 현재 데이터 JSON: 약 77.99 → 29.20MB. 전체 그래프가 최초 접속 시 모두 내려받는 데이터는 아니다.
- 독립 캐릭터 도감: 48,124,460 → 6,207,963바이트. 72항목을 보존했다.
- Pages에서는 제작용 `art/`와 검사 전용 `tests/`, `game/tests/`를 추가 제외한다. 파일은 Git에 보존한다. 실제 웹 사용 파일과 공개 도감·데모는 제외하지 않는다.

## 실제로 줄인 것

1. 기존 JSON pool 형식으로 반복 벡터 문자열을 재사용한다. 복원된 1,090개 자산과 40개 스테이지는 원래 데이터와 같다. 별도의 거대 전체 라이브러리 사본 대신 공통·장별 묶음과 편집기 전용 자산을 원래 순서로 조합한다. 현재 그래프에는 임시 분할 `.bin`이 없다.
2. 같은 바이트의 그래픽 별칭은 빌드 중 한 URL을 재사용한다. JS 모듈의 실행 횟수나 객체의 독립성은 합치지 않는다.
3. SVG 77개에 중복 내장된 참조 PNG를 이미 존재하는 동일 PNG의 상대 링크로 바꿨다. 벡터 XML의 다른 바이트는 유지했다. 이 소스는 SVG와 참조 PNG를 함께 복사해야 한다. 과거 증거가 파일 해시를 고정한 원본과 일치하지 않는 이미지는 보존했다.
4. 필요한 과거 검사 fixture와 제작 snapshot은 gzip으로 저장하고 기존 도구가 복원하도록 했다. 원본 바이트의 해시·내용과 검증 조건을 유지한다.
5. 과거 브라우저 캡처와 실행 추적 중 현재 검사 입력이 아닌 자료를 정리했다. 이미 공개된 원본과 동일한 자료는 고정된 과거 GitHub commit 링크 및 복구 목록을 남겼다. 별도 보관이 필요한 과거 제작 검수본은 무결성 확인 후 보관했다.
6. 도감 생성기의 문자열 치환 오류를 고쳐 중복 삽입을 제거하고, 도감 렌더러가 읽지 않는 배경·맵 데이터를 제외했다. 실제 게임의 데이터나 렌더러는 삭제하지 않았다.

## 보존한 것

- 현재 초상화, BGM/SFX와 폰트 subset, 필요한 SVG·리그·애니메이션·제작 시안.
- 편집기에서 사용 가능한 재사용 자산. 현재 스테이지에 배치되지 않았다는 이유로 없애지 않았다.
- 현재 승인 게이트의 이미지와 프로브, 저장·호환성 검사에 쓰이는 프로필 및 기준 데이터.
- 기존 공개 버전의 캐시 호환 파일. 기존 7일 보존 정책에 따른 자연 만료는 최적화 효과와 별도로 계산한다.
- 실제 공개 기능과 개발용 템플릿·재현 코드. 기존 forge 템플릿 3개의 URL 존재를 기능 정상 동작으로 간주하지 않는다.
