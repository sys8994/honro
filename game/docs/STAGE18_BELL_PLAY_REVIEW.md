휘겸은 S09를 정상 사용했지만 navigator의 적 목적지 평가가 여전히 기사용 `dy≤300`, 강한 근접 접근거리60 선호였다. C rear는 y2816.54, 아래 사격 바닥은 y3170으로 높이차353.46이다. 후보 R57–62/R65의 **7개 경로없음 사건** 가운데 무회복 방어는4회, 비교 R44–54의 **11개 사건** 가운데 R45–54 무회복 방어는10회다. 따라서 “7/10”을 같은 종류의 건수로 비교하면 안 된다.

실제 비교판 R55 production Continue의 동일 휘겸 위치 `(9035.73,3470)`에서 읽기 전용 route 진단을 했다. C rear를 적 목적지로 삼으면 null이지만 C 바닥 `(5200,3170)`을 보행 목적지로 삼으면 238개 graph link가 존재하며 전투 JSON은 완전히 불변이었다. 이는 그래프 목적지 필터의 한계를 지지한다. 해당 진단 자체를 실제238구간 이동 성공으로 세지는 않는다. 실제 지형 단절이나 S09 필수성을 뜻하지 않으며, 다른 동료가 실제 C에 도착한 trace와 별도로 해석한다. 최종 비교 후 정책을 고쳐 수치를 다시 만들지 않았다.

## 보상과 19장 정상 입장

두 판 모두 각 동행 XP가 **46235 + 전투1927 = 48162**, 실제 최초 완료 보상2890을 더해 **51052**가 됐다. 일반 `result-continue` 버튼으로 19장 소개에 도착했고 레벨14·동일 랭크/슬롯/수련을 유지했다. 실제 입장 회복은 설오1344/332, 담허1483/547, 휘겸2999/372, 소단1782/606으로 각각 HP/기력 최댓값이며 소모품 수량은 그대로다. 주민은 HP1900, 접지·보호 상태이고 소단 의식3/3/4 및 각 유한파동3/3/4 계약을 확인했다.

18장의 하강 완료 collision/world와19장 지형의 공간 좌표만 절대오차1e-8을 허용했다. 실제 최대오차는2.7284841053187847e-12다. ID·순서·재질·플래그·점 개수·그 밖의 숫자는 exact이며 64 collision/64 world 조각이 맞았다. 실제 보상을 받은 같은 프로필로 원래19장을 따로 compile해23개 actor 계약과 성장/아이템 동치를 검사했다. 19장에 이전18장의 전투 상태/투사체/말뚝/소환물/종지기를 복사하지 않았다. 19장 전체 전투/의식 완료 주장은 하지 않는다.

## 별도의 이전 정책 증거

- 기본기만 사용하는 정상입력 연속 trajectory는 최종 지도에서 R104 production 저장을 입력 정책 수정 후 이어 R134 승리했다. A01/M01/O01 무료, S00 정상8기력, 4인 생존·아이템0. R134 시작의 실제 저장에서 마지막 O01→승리→일반19입장을 다시 검증했다. 이 결과는 선택 기예를 발사하지 않아도 가능한 기본 대안의 안전성 근거이며 최종 대표 페이스 비교와 합치지 않는다.
- 그 기본기 run의 마지막1체는 R124–134의43동행행동/21이동/16무회복방어였고 실제 이동직선합47,293.46px였다. move21행 exact 중복0이며 B 정리 후 세 동료가 G 목표로 돌아가는 동안 소단이 D로 향한 실제 봇 왕복이다. 최종 대표 쌍의 짧아진 꼬리를 이 이전 run의 성공률/인과 개선율로 해석하지 않는다.
- 이전 대표 정책의 baseline R62 승리와 candidate R16 경고 Continue 실패도 보존했다. 후자는 live collision 자세와 저장 복구의32px 위치 차이를 strict assertion이 잡았으며058 생산 수정 후 위 fresh 두 판의 전체 상태 exact로 재검증했다. 이전 실패를 최종 승리로 덮지 않았다.
- 별도 정상입장 역할 선택 proof의 R22 진 활성/살아있는 B 후위 공통저장에서 M11 반사, 같은 aim M01 차폐, 기본점프+옆이동 M01 대안을 검증했다. 지도는 같지만 해당 proof는058 전 runtime이므로 여기의 fresh 기술사용 수에 합산하지 않는다. 위치준비 전술 fixture도 별도 범위다.
