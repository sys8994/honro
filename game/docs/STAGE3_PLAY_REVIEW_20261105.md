- A/B: 빈 프로필의 공식 검수 모드에서 3장 진입. 경지1, 활성 기본 기예 A01/M01, 기본 패시브 유지. 전술 난이도. A는 기본 속도1.5, B는 설정에서 적 속도4.
- C: 기존 `tests/fixtures/act1-art/stage03-entry.json`의 profile을 변경 없이 공식 가져오기. 1·2장 완료 보상 준비 자료이며 연속 캠페인 실플레이 증거가 아니다. 일반 모드, 설오 경지2·담허 경지3, 기본 기예, 전술 난이도·속도1.5.
- D: C 승리 후 공식 여정첩으로 재방문. UI에서 소유 장비와 SP만 사용했다. 설오 급소시3·솔바람 화살통·숨돌림 옥돌, 담허 화호3·빙호2·해진 장명부·풀매듭 호리병. 첫 3장 완료 보상도 포함하므로 최초 진입 자원만의 교전 검증은 아니다. 일반 모드·전술 난이도·속도1.5.

## 전술 관측과 한계

기예 투자, 다리 위 사선, 빙호의 실제 둔화, 교전 후 이동·방어·불씨 회복이 유효했다. 회피7턴과 교전9턴의 비용 차이는 관측했으나 재미의 최종 판정을 대신하지 않는다. B의 긴 전투에는 벽에 너무 가까운 점프 시작, 방향 전환, 설오 이탈보를 다음 차례로 오인한 제어기 지연이 포함된다. D의 화호1발도 예측과 실제 착탄 차이로 빗나갔다. 이를 제품 결함으로 세지 않았다.

산개는 휘겸과 교전하며 지연시키는 역할을 보였다. **플레이어에게 직접 압박을 가하거나 상하 경로 선택을 바꾸게 하는 역할은 충분히 확인하지 못했다.** 확정된 3장 제품 결함이 없어 밸런스·지형·공통 코드는 변경하지 않았다.

미검증: 1장부터 이어진 새 일반 캠페인, 최초 진입 자원만의 장승 처치 승리, 모든 기예·장비·난이도, 실물 모바일, 전체 캠페인 회귀, 새 Pages 배포. 과거 Native R6/R20대 기록은 이번 완주 근거로 사용하지 않았다. 디버그 기록의 일반 가져오기는 제품 검증에 거절되어 제외했고 검증을 우회하지 않았다.

## 검사와 별도 5장 실패

`node tests/stage3-positioning.mjs` PASS. 격리된 경로/투사체 검사이며 위 UI 완주와 별개다.

`node tests/ground-contact-save.mjs`는 3장 구간 전에 5장 archer fixture의 line40 `assert(q.e.jump(q.u))`에서 실패했다. line38의 `(1467,2851)`은 [옛 저장 접지 버그 기록](BUG_LOG.md)의 2026-10-06 평지 좌표다. 현행 [5장 지형 저작](../../tools/map-forge/stage5-dynamic.mjs)은 승인 lower-bank에 y+1000을 적용하며 해당 x의 지면은2789.142857이다. 옛 준비 좌표는 약62px 매몰되어 grounded/validTerrainContactPose=false, 이동도1640·점프 비용75인 상태에서도 정상 점프 가드가 거절한다.

[5장 기존 검수](STAGE5_DYNAMIC_20261026.md)와 현재 소스를 대조하고, 임시 격리 진단에서 네 체형을 **현재 지면으로 준비**한 뒤 보행→점프→착지→App 내보내기/가져오기/Continue→발사를 확인했다. 네 체형 모두 통과했다. 이 진단은 상태 준비와 DOM 대역을 사용하므로 정상 캠페인 완주가 아니다. 이번 assert 실패는 낡은 테스트 준비 좌표에 기인하며 현재 위치의 점프·저장 결함은 재현되지 않았다. 5장 전체 지형/전투 무결성을 뜻하지 않는다. 기존 테스트·가드·5장 제품은 수정하지 않았고 별도 담당자가 현행 지형에 맞는 검사 의도를 검토해야 한다.

후속 테스트 교정: 위 진단 뒤 별도 요청으로 `ground-contact-save.mjs`의 5장 시작 높이만 현행 `valley-floor`에서 계산하고 옛 벽 접근을 현행 통나무 앞 보행으로 바꿨다. 실제 보행 거리·점프 상승·통나무 착지를 단언하며 기존 위치 범위·저장 왕복/반복 불러오기·복원 후 발사는 유지한다. 전체82조건 통과. 임시로 생산 Engine의 5장 점프를 거절시키자 `Stage5 supported actor must jump`에서 실패했다. 결함 주입은 원래 바이트로 복원했으며 제품·가드 변경은 남기지 않는다. 3장 실제 입력 결과와 준비/미검증 범위는 그대로다.
