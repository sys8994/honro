# 14·22장 수직 지형 개편

## 범위와 보존

기준 소스 `6e1727377b0d5765120dde567d044d965d59bb36`에서 14장 암벽 마을의 하강·구출·피난 다리 합류, 22장 관아 석축과 세 기록각의 상승·교차 엄호를 순차 제작한다. 다른 28장, 기존 순차 목표·파티·성장 예산과 진행 중 전투 snapshot은 보존한다. 새 진입에만 별도 수직 revision을 적용한다.

기획 기준은 2026-10-10 독립 검토된 「수직 스테이지 설계안」 SHA256 `51b68ee95db344beba07f94baa256fa0cd1debc1dac13690ce097bebe0a55d7b`다. 크기 14장 7600×10400, 22장 4800×6600과 초기 43/32체는 검증할 제안이다. 면적·총원·테스트 수를 품질 승인으로 삼지 않는다.

## 순서와 상태

1. 14장 회색모형: 실제 고체 단면, 기본 이동/점프/안전 낙하, 삼분기와 기본 복귀. 진행 중.
2. 14장 역할 군집·정예·기존 유한 12증원: 미착수.
3. 14장 한국적 미술·Native 실제 렌더·정상자원 입력·새/옛 App 저장: 미착수.
4. 14장 독립검수 결과를 반영한 22장 회색모형·교전·미술·저장·정상입력: 미착수.
5. 전체 회귀, 증거 manifest, 독립검수, master/Pages 후보: 미착수.

## 필수 지리 검수

- 점프 실효중력1000, 실제 상승 약214를 사용한다. 필수 상승120~160과 모든 체형의 머리/착지 여유를 확인한다.
- 14장 C→F의 걷다 내려서는 경로, C↔D/E↔F의 복귀, E 미방문 시 고립 적, 구출 비살상, G 원형 방어와 H 보호대상을 각각 검증한다.
- 22장 기본 연결과 잠금, 같은 층 상호작용·2적턴 방어, 각 반응 파동의 실효성을 확인한다. 기획의 첫145도약 격리 성공은 전체 연결의 성공이 아니다.
- 전역 이동/중력/AI를 바꿔 지리 결함을 덮지 않는다. 무기능 군집은 배치·연결부터 고친다.
- 순수 빈 이동과 전투 중 선점/엄호/회귀 이동을 구분한다. 필수 경로에는 특정 기예를 요구하지 않는다.

## 검증 한계와 공개 조건

기준판의 `village-cavern floor-main` 전체검사 실패와 Chromium socket EPERM이 알려져 있다. 현재 환경의 실제 상태를 재확인하고 Native App/Canvas 결과와 브라우저/Pages 직접 검수를 분리한다. 회색모형은 완성작으로 공개하지 않는다. 변경 단위는 작업 브랜치에 보존하고 알려진 신규 결함 없는 검수 후보만 master/Pages에 통합한다.
