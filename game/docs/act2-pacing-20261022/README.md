## 저장·생성·통합 경계

새 `act2-pacing.js` author를 공통 번들의 마지막에 적용하고 원본 campaign에도 같은 멱등 overlay를 저장한다. 11장 전용 재생성기에도 마지막 overlay를 적용한다. 살아 있는 옛 전투는 알려진 ID 순서/캠페인/미종료만 upgrade하며 기존 지형·배우·보상/XP·done/checkpoints를 재생성하지 않는다. 옛 전투의 흔적 좌표는 그대로여서 먼 능선에 이미 간 동행을 되돌리지 않는다. 새 진입/재시도만 짧은 흔적 위치와 편성을 쓴다. 지형 polygon 변경이 없어 map revision으로 진행 전투를 폐기하지 않는다.

공용 변경 충돌 위험: `shared/build.mjs`의 modelFiles/projectAuthors 마지막 항목, `shared/runtime/act2.js` satisfied의 선택적 전용 hook 한 곳, 생성된 HTML/web manifest. 부모의 다른 공통 작업과 통합 시 단일 목록에 `act2-pacing`/`HonroAct2Pacing`를 남기고 최종 소스로 재빌드한다. 공통 렌더/물리 루프는 바꾸지 않았다.
