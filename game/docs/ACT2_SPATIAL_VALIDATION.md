# 2막 공간 개편 회귀 계약

2026-10-05. 대상은 새로 시작하는 11–20장 공간 개편이다. 이 문서는 자동 검사의 범위와 한계를 설명한다. 실제 전투 완주, 브라우저 화면 검수, 성능 검사는 각각 별도 결과로 판단한다.

## 보존 기준

`tests/fixtures/act2-spatial-contracts.json`은 개편 전에 고정한 원본이다. 출처 커밋도 파일에 기록한다. 좌표·카메라·지형만 비교에서 제외하며 다음은 그대로 비교한다.

- 목표 ID와 순서, 필수 직업, 방어·경합 반경, 방어 턴 수
- 도입·사건·마무리 대사, 구조·비살상·호송 의미
- 기존 유한 증원 종류·수량·정예 간격·동시 행동 수
- 직업·기예·몬스터 원형·밸런스 설정 전체
- 장별 초기 유닛의 HP·공격·이동·기예·경험치 예산·교전 집단
- 1막 열 장의 정규 맵

`act2-spatial-legacy-save.json`은 구형 revision-2 지형, 피해, 소모품, 목표·방어 진행이 들어 있는 저장 fixture다. 현재 엔진으로 읽고 다시 붙일 때 이를 새 공간으로 덮어쓰지 않는지, 재실행해도 변하지 않는지 검사한다. 새 기준에 맞추기 위해 이 두 파일을 재생성해서는 안 된다.

## 단계별 검사

1. `node tests/act2-spatial-contracts.mjs`
   - 13개 보존 검사. 목표·대사·밸런스와 기존 저장을 고정한다.
2. `node tests/act2-spatial.mjs`
   - 승인된 장별 topology·방 ID·목표 연결, 실제 폴리곤의 표면 참조, 필수 보행 지지면과 네 인물의 몸통 여유를 검사한다.
   - 파괴 목표 여섯 곳은 선언된 사격 위치에서 실제 투사체를 발사하여 표적 HP 감소를 확인한다. 공명 억제와 버팀목은 해당 검사에서 명시한 전제 상태다.
   - 13장 자연광 진입과 낮은 회랑의 실제 충돌 천장, 낮은 사선·높은 사선 차이, 15장 수문과 수갱의 높이 차이, 20장 실제 지붕 끝을 검사한다.
   - 18/19장 구조 폴리곤·천장·통로·묵종 위치/크기를 정확히 비교한다.
   - 20장 NPC 자체를 옮기지 않고 기존 호송 tick으로 걷기, 쉼터 대기, 재출발, 도착을 검사한다. 기존 x=4400 증원 조건과 한 번만 생성되는 성질도 확인한다.
3. `node tests/act2-spatial-progression.mjs`
   - 모든 장의 목표를 순서대로, 네 인물이 각각 실제 보행으로 접근한다.
   - 문과 장애물을 처음부터 열지 않는다. 해당 목표에 도달한 다음 기존 상호작용/파괴 hook으로만 지형 상태를 바꾼다.
   - 14장 하층 가족 전에 다리 문이 필수 내리막을 막던 오류를 방지한다. 그 잘못된 배치를 테스트 안에 다시 넣으면 실제로 통과하지 못하는 mutation guard도 있다.
   - 전투·방어 시간·도달/호송 완료는 명시적인 상태 fixture다. 이 검사는 일반 전투 완주가 아니다.
4. `node tests/act2-traversal.mjs`
   - 열린 경로 상태에서 열 장 × 네 인물의 전체 필수 경로 40개를 확인한다. 실제 보행/접촉 판정을 쓰며 점프, 순간이동, 강제 복구를 쓰지 않는다.
   - 이것만으로 닫힌 문의 진행 순서를 증명할 수 없으므로 3번을 반드시 함께 실행한다.
5. 기존 `act2.mjs`, `act2-revision.mjs`, `act2-terrain.mjs`
   - 목표 순서·저장·보상·구조·종지기·방어·증원·지역 등불·정예·지형·물 검사를 유지한다.
   - 모든 동굴에 같은 upper/middle 선반과 두 번의 회전을 요구하던 항목은 실제 장별 공간 계약으로 교체했다. 노드 수나 장식 수를 늘리는 할당량도 제거했다.

## 브라우저 검사

`act2-spatial-browser.py`는 Game, Stage View, 실제 Playtest의 지형·목표·묵종 위치를 비교하고 장별 방을 데스크톱·세로·가로 모바일 화면으로 촬영한다. 기존 브라우저 검사도 폐기된 switchback 좌표 대신 새 방 위치를 따른다.

이번 작업 환경에서는 로컬 HTML/localhost 브라우저 접근이 정책상 차단되어 이 브라우저 검사와 화면/성능 검수를 실행하지 않았다. Python 구문 검사는 통과했다. 브라우저 미실행을 화면 통과로 해석하지 않는다. 정상 접근이 가능한 지원 환경에서 빌드 후 실행해야 한다.

## 정상 전투 봇

`act2-playthrough.mjs`는 기존 이동·발사·아이템·대기·상호작용 API를 사용한다. 새로운 목표 위치는 `design.space.sites`를 따른다. 저장 체크포인트에는 지형·경로·목표·유닛 배치·물의 해시를 포함한다. 이전 지형에서 이긴 체크포인트를 새 지형의 통과 근거로 재사용할 수 없다.

상태 fixture·격리된 물리 통과와 일반 전투 완주는 다르다. 행동 한도 안에 이기지 못하거나 아직 실행 중이면 미완료로 기록한다. 기존 장별 전투 완주 결과를 이번 개편의 완주 결과로 옮겨 쓰지 않는다.

자동 결과는 `_local/reports/act2-spatial/`에 저장되며 부분 장 검사는 파일명에 장 번호를 붙여 전체 검사 결과를 덮어쓰지 않는다.
