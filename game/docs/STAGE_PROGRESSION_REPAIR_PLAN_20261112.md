# 장별 진행 개선 순서 · 2026-11-12

기준은 `d3ff2a0fa`. [40장 라운드 비교](stage-round-review-20261111/README.md), [최신 작업 SOP](HONRO_NEW_VERSION_SOP.md), [버그 기록](BUG_LOG.md)과 40장 상호작용 조사 결과를 대조했다. 이 순서는 진행 불능과 실행 불일치를 우선하며, 기존 수정이 있는 장은 최신판에서 먼저 재현한다. 2막 1·2장은 현재 공개판의 정상 신규 12R·정산 기록을 재사용한다.

| 순서 | 대상 | 먼저 확인할 현상과 수정 범위 |
|---:|---|---|
| 1 | 2막 3장 (13) | 소단 분리 대사와 실제 발동, 담허·석공의 위치 조건, 자동 호송 중 남은 조건, 문 안쪽 빗장과 전원 통과 안내. 대사·지형·저장을 보존한다. |
| 2 | 2막 7·8장 (17·18) | 방어·철수·하강·안전 도달·유헌 제압에 뜨는 E부터 제거한다. 버팀목·고정구의 지역 위협과 작업 중 조건, UI 조회가 시작하는 18장 대사를 따로 재현한다. 18장 오류 9는 별도 사례로 유지한다. |
| 3 | 3막 1·9·10장 (21·29·30) | 수레·보스·차폐·편대 표식의 작동하지 않는 E, 29장 수문 선행, 30장 호송 4/4 뒤 증언·지도 조건과 결과를 확인한다. 수레 파괴·실물 증언·기존 대사를 보존한다. |
| 4 | 4막 10·6·9·2장 (40·36·39·32) | 마지막 생존자의 수중 복귀와 턴 정지의 기존 패치를 우선 재검증한다. 이후 현재 조건과 막힌 이유를 표시한다. 문 대사·집결, 주민 4명 안전, 재회·보고, 같은 여정 기록은 유지한다. |
| 5 | 2막 4·5·6·9·10장 (14·15·16·19·20) | 14장 분리 선행 대사 회귀, 15장 자동 출구와 수문·홈 조건, 16장 증언 자동 발동, 19장 가족 사건과 마지막 담당자, 20장 호송·바깥 확인. 19장 비전투 분량과 가족 대사를 보존한다. |
| 6 | 3막 2·3·4·5·6·7·8장 (22–28), 4막 1·3·4·5·7·8장 (31·33·34·35·37·38) | 현재 행동을 막는 실제 조건만 설명한다. 전용 E와 공통 축지, 자동 증언·분할·조사·신호를 구별한다. 4막은 인원·접지·장면·안전 조건을 기준으로 대표 장부터 공통 표시를 확인한다. |
| 7 | 1막 5·6·9장 (5·6·9), 2막 10장 (20), 3막 5장 (25), 4막 2·7·8·9장 (32·37·38·39) | 진행 정상화 뒤 남은 분량만 검토한다. 5·6장은 지나치게 긴 필수 교전, 9장은 기존 2R 승리의 재발 여부, 20·25·32장은 교전 후 이동, 37–39장은 경로와 전투 압력을 확인한다. 기존 조정은 대조 후 재사용한다. |

1막 1·2장은 작은 회귀만 확인한다. 3장 장승 수치와 이미 수정된 1막 NPC 피해·매듭 판정은 현행에서 재발한 경우만 다시 변경한다. 관찰된 4막 1·5·10장 오류 9와 4막 4장 턴 정지는 빌드·저장 상태·브라우저 환경을 나눠 재현하며, 확정된 게임 결함이 나오면 분량 작업보다 먼저 처리한다.

장별 변경 구간을 실제 브라우저 입력으로 짧게 확인하고 통과한 빌드에서 요청된 신규 완주·정산·저장을 한 번 실행한다. 같은 구간에서 다시 막히면 기존 실행을 보존하고 해당 구간만 재현한다. 동일 원인의 표식·안내 변경은 한 번에 검수할 수 있다. 근거 없는 체력·턴·승리조건 변경과 정상 작동 장의 일괄 수정은 피한다. 다른 담당자가 수정 중인 장은 최신 원격과 진행 상태를 확인한 뒤 파일과 배포 시점을 조율한다.
