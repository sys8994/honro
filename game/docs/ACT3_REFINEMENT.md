# 3막 풍경·악귀·증원과 공통 전투 안내

## 제작 원본

`tools/map-forge/act3-refinement.mjs`는 21–30장의 접지된 곡선 소나무, 돌과 갈대, 석등·작업장 소품, 둑과 암반의 큰 명암면을 저작한다. 24–30장 일부 빈 구간에는 실제 바닥과 일치하는 작은 둔덕·패임을 더한다. 단일 지형의 확장 범위는 유지하고 새 dummy/skirt나 독립 충돌 발판을 만들지 않는다. 다층 건물·다리·작업 지점은 기존 높이를 우선하며, 생성 후 `settle`과 편성 생성기로 유닛·마커의 접지를 다시 확인한다. 기본 바닥을 `design.act3.refinement.baseFloor`에 보관해 재실행 때 굴곡이 누적되지 않는다.

소나무 원본은 `tools/environment/act3-pine-art.mjs`, 원경은 `shared/assets/environment/act3-far.svg`다. 기존의 큰 단색 L4 능선을 작은 산맥·구름·안개의 공통 SKY로 대체했다. 실내 23장은 하늘을 가리고 25장의 동굴은 기존 천장 마스크를 유지한다. 공통 렌더러의 작은 수평/수직 시차와 낮은 채도·밝기, 장별 밤톤을 사용한다. 게임·Stage View·Playtest가 같은 에셋과 번들을 읽는다.

## 유한 증원

`tools/map-forge/act3-reinforcements.mjs`가 목표 완료와 장소별 진입로를 연결한다. 기존 초기 편성 190명/40정예는 유지하고, 기존 목표 방어 파동과 별도로 29개 편대/67명의 유한 진입을 추가한다. 25·26장은 두 동행의 전투에 맞춰 한 편대를 두 명으로 제한한다. 마지막 일부 편대의 첫 문지기는 정예다.

조건 달성 때 먼저 경고를 표시하고 안전한 행동 종료 경계에서 한 편대만 배치한다. 실제 진입 지점에는 원과 `증원` 표시를 잠깐 보여준다. 공통 동시 인원 상한, 실제 접지·점유 검사, 원자적 배치 재시도, 난이도 배수 1회 적용을 유지한다. 경계 토큰·대기 목록·완료 플래그를 저장하므로 같은 경계의 이중 flush나 재개로 다시 투입하지 않는다. 성장 예산에는 추가 정예의 가중치를 포함하고 기존 장별 XP 상한은 유지한다.

## 한국 악귀 벡터

`tools/monster-forge/act3-species.mjs`에서 문지기 악귀·성벽 궁귀·수문장 악귀·별초 궁귀·장부귀·주조귀를 만든다. 수비대의 겹여민 군복·전립·붉은 끈, 창백한 얼굴과 녹빛 눈을 사용한다. 장부귀는 종이를 두른 두건·긴 옷과 날리는 장부, 주조귀는 작업용 머리띠·종틀·망치로 직업과 실루엣을 구별한다. 정예는 붉은 갑옷 면·어깨 장구·전립 장식·긴 무기와 화면 표식으로 읽힌다.

일반 적과 정예의 HP 바 색은 같다. 정예의 표시 배율 1.12는 미술에만 적용하며 물리 h/r·충돌·행동 수치를 바꾸지 않는다. 새 두 악귀는 기존 전투 역할과 기예를 사용한다. 보스·아군·소환귀는 기존 벡터에 위임한다.

기존 11종의 원본 대비 2.85–3.15배 앵커 계약은 유지한다. 새 6종은 가짜 원본 비교 대신 에셋당 최대 350앵커/90경로/16색의 `act3-authored` 예산을 명시한다. SVG·리그·5개 동작은 같은 원본에서 생성한다. `test:act3:refinement`는 새 SVG/Canvas 일치·접지된 대기 발·양방향 동작과 128/96/64px 증거를 검사한다. 기존 비교는 `test:monsters`에서 별도로 유지한다.

## 공통 UX

상단 목표는 현재 한 가지 행동만 짧게 안내한다. 클릭하면 완료된 목표와 현재 목표를 체크리스트로 보여주며 미래 단계는 숨긴다. 27장의 병렬 목표는 현재 동행이 수행할 수 있는 행동을 우선한다. 실제 목표·실패·종료 판정과 저장 상태는 유지한다.

피해 숫자는 대상별·공격별로 합산한다. 같은 공격의 30/30/30 피해는 30/60/90으로 갱신하고 다음 공격은 새 숫자로 시작한다. 검정 사각 상자는 제거하고 숫자와 얇은 어두운 윤곽으로 읽힌다. 화면용 합산 상태는 전투 저장에 포함하지 않는다. HUD에는 3px 경험치 막대를 표시한다. 살아 있는 동행의 전투 레벨업은 효과와 함께 HP·기력·이동력을 채우며, 이미 사용한 행동은 되돌리거나 쓰러진 동행을 부활시키지 않는다.

디버그에서는 분할 원정 중에도 쉼터와 모닥불을 열어 기예·능력치를 설정할 수 있다. 일반 원정의 쉼터 제한과 일반 저장 격리는 유지한다. 설정을 끄면 기존 일반 상태로 돌아간다.

## 검증과 범위

집중 검사는 `npm run test:act3:refinement`, 지도 재생성은 `test:act3:art`, 필수 이동은 `test:act3:locations`, 편성/사격은 `test:act3:encounters`로 수행한다. `tests/integration.py`는 세 막 30장 전체의 Game/Stage View 월드 렌더와 공통 엔진을 대조한다. 호스트별 목표 HUD는 월드 화소 비교와 분리해 실제 UI 테스트에서 확인한다.

명시적 QA 상태로 진행·피해·레벨업을 재현하는 검사는 정상 캠페인 완주·사람의 난이도 평가를 뜻하지 않는다. 기존 진행 중 전투의 지형·적 편성·임무·자원을 재생성하지 않는다. 새 제작은 새 입장/재시도부터 적용된다. 첫 화면은 [별도 기획](TITLE_SCREEN_DESIGN.md)만 작성한다.
