아래쪽의 2~17라운드와 성능 표는 **이전 revision 1의 역사 기록**이다. 두 배 이상 넓은 맵, 증원·거점 제압·정예를 넣은 현행 revision 2의 근거는 이 절의 표와 새 검사 결과다. 상태 fixture 10장, 선반 끝에서 완전히 착지한 뒤 돌아오는 14장 경로를 포함한 물리 이동 10장, 게임/Workshop 실제 화면 17묶음, 동적 UI 라벨을 제외한 두 화면 월드 화소 비교 67조건이 통과했다. 최신 화면은 `_local/reports/act2-revision/iteration-14/`에 있다.

2026-10-03 재점검에서 기존 `play-11.json`·`play-12.json`의 51/57라운드 승리는 봇이 `Engine.wait()` 대신 체력을 직접 더한 결과임을 확인해 폐기했다. 두 프로세스가 같은 13장 체크포인트를 덮어쓴 구간도 폐기했다. 검증기는 실제 `wait()`·`item('heal')`·이동·발사·상호작용 API만 사용하고 전투 중 배우·적·목표 상태를 직접 바꾸지 않는다. 시작 프로필에는 해당 장 입장 경지의 정상 XP·자동 수련과 소단의 습득 가능한 현형부를 적용한다.

## 검사 중 찾아 수정한 문제

1. 동굴마을 상층의 끝이 하층을 막아 돌아갈 수 없었다. 우측 하강 구간을 분리해 아래를 걸어서 되돌아갈 수 있게 했다.
2. 암반 선반과 바닥의 겹친 끝에서 양쪽 표면이 매몰 판정을 받아 동행이 추락했다. 두 윤곽의 상부 경계를 한 고체로 합쳤다. 목표물도 실제 표면 위로 재배치하고 급한 경사 구간을 늘렸다.
3. 일반 장식 렌더러가 새 목표 마커를 건물로 그렸다. Act 2 마커를 별도 처리하고 현재 목표 위치만 링으로 표시한다.
4. 수문을 내리면 얕은 쪽 물 표면이 바닥보다 내려갈 수 있었다. 초기 수심과 바닥을 조정해 120 하강 뒤에도 물 도형이 뒤집히지 않도록 했다.
5. 공통 물 번개 검사에서 기술 ID가 없는 환경 탄의 피격 연출이 `skill.branch`를 읽다 실패했다. 기술 정의가 있을 때만 해당 연출을 호출한다. 기존 잠긴 수면 아래의 다른 층까지 감전시키지 않는 검사가 통과했다.
6. 과거 충전 검사에 제거된 O16 최저 속도 62% 기대값이 남아 있었다. 기존 HBUG-070의 현재 ‘충전량 그대로’ 동작에 맞추고 기술·시간별 실패 진단을 추가했다.
7. 단독 환경 도구는 콘텐츠 전체를 읽지 않는다. 스키마의 캠페인 장 수 검증이 콘텐츠 객체 없이도 20장을 처리하도록 했다.
8. 신규 적/공격의 감응도는 정상 적용됐지만 공통 존재상 분류표의 명시적 등록이 빠져 있었다. H2 공격 8종과 적 10종을 기존 적용 수치와 동일하게 등록했다.
9. 과거 검사의 ‘모든 장이 1막 대사 형식’, ‘모든 적은 기존 벡터 11종’, ‘1장 폭 4,200’ 가정을 갱신했다. 2막 사건 대사도 5줄 이하로 검사하고, 기존 11종의 미술 계약과 새 10종의 실제 공통 렌더/상태 불변 검사를 각각 유지한다. 출구 검사는 현재 맵에 의도적으로 오래된 콘텐츠 폭을 주어 같은 회귀를 재현한다.
10. 모바일 화면에서 화면 밖 목표 접두사가 깨진 글자로 보이던 것을 ‘화면 밖 ·’로 수정했다. 화면 캡처의 대사 카메라 전환도 정리하고 실제 최소 전술 줌을 수치로 확인했다.

## 한계와 후속 평가 기준

- 인간이 이야기와 공간을 처음 보며 10개 장을 연속으로 플레이한 사용성 평가는 아니다. 특히 2-7과 2-8의 반복 공격 부담, 2-9의 천도 중 전투 압박은 초회 플레이로 평가해야 한다.
- 모바일은 Chromium의 390×844, 844×390 화면과 클릭/키보드 이벤트 검사다. 실제 휴대전화의 터치 지연·발열·배터리를 측정하지 않았다.
- 연출은 현형, 등불, 종의 잔울림, 구조물 상태 변경이다. 새 음성·음악, 무너지는 암반의 강체 물리, 승강기의 연속 이동 애니메이션은 없다.
- 동굴 전투는 공통 충돌·물리·카메라를 사용하며, 새 몬스터는 공통 AI와 기존 공격 동작을 조합한다. 독립된 Workshop 전용 게임 루프는 없다.
- 마지막 3막 표시는 목적지 안내이며 플레이 가능한 3막 맵은 포함하지 않는다.
