# 검수 이미지 중복 정리 · 2026-10-24

동일한 Git blob·바이트 수가 확인된 중복 캡처 569개(104,288,287B)를 제거하고 각각의 동일 원본 한 벌을 유지한다. 게임 실행 에셋·미술 레퍼런스 원본·fixtures·발행 보존 그래프는 대상이 아니다. 동적 재생 갤러리 및 실행 코드/JSON 소비가 불명확한 355개 후보는 제외한다.

[경로 대응표](index.json)의 `deletedCopies`에 삭제 경로, 현재 `canonical` 경로와 원본 Git blob을 기록했다. 옛 파일은 [고정 원본 트리](https://github.com/sys8994/honro/tree/5154db899d3c9f62012c87b4f943cd44f2c3e676)에서 같은 경로로 찾을 수 있다. Markdown/HTML의 실제 이미지 링크는 동일한 현재 원본으로 연결한다. 캡션·검수 시점·결과는 바꾸지 않는다.

`historicalRecords`의 과거 JSON 경로·시간·hash는 당시 캡처의 사실이므로 그대로 보존한다. 지금 같은 파일이 다시 생성되었거나 검사가 재실행된 것으로 해석하지 않는다. 삭제된 이름이나 디렉터리 패턴은 위 경로 대응표 또는 고정 역사 트리로 조회한다.

이 작업은 현재 체크아웃의 중복 파일을 줄이는 문서 정리다. Git 과거 객체를 삭제하거나 게임의 초기 로딩·프레임 성능을 개선하는 변경은 아니다.
