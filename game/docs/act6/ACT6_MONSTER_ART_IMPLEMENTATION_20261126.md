# 6막 신규 몬스터 벡터 복원과 체급 개편
2026-11-26. 개발 브랜치 검증 중. 6막 지형, 대사 또는 이벤트와 승패 조건의 내용은 바꾸지 않았다.

## 실제 경로
- 새 벡터 8종과 피벗·동작의 편집 원본은 `tools/actor-forge/art-act6/`. 이미지나 clipPath를 번들에 넣지 않는다. `node tools/actor-forge/build.mjs`로 기존 배우 출력과 게임 런타임을 갱신한다. 지형 최적화처럼 세밀한 금실·단청·붉은 매듭을 전부 없애지 않고, 미세 잡음을 선별한다.
- 대도사와 3괴이는 58장, 두 원혼·문턱 꼭두·앞발은 59장 소유자가 연결한다. 맺힌 원혼과 넘쳐온 원혼은 59장 처음과 증원에서 별개 리그다.
- 예고를 아트 임의 타이머로 만들지 않는다. 58장 대도사의 실제 예고, 상주의 낙하 표시, 59장 앞발의 실제 휩쓸기 표시에서 예비 동작을 받고, 발동 시 실제 공격 모션으로 넘긴다.
- 58장 서명된 장 진입 자료를 바꾸지 않는다. 대도사는 실제 등장할 때 h/r 310/83, HP 11,800, 방어 .18을 적용한다. 기존 체력 전환 7,600·4,600과 이벤트 표식을 유지한다. 상주·천수귀·문짝 h/r의 목표는 203/48, 265/89, 298/98이며 실제 지형 접촉 또는 공중 공간을 먼저 검사한다.
- 59장 선봉·증원 목표 h/r은 넘쳐온 원혼 155/45, 맺힌 원혼 123/36, 문턱 꼭두 222/60, 앞발 360/116. 첫 등장 판정과 분리, 범위가 못 들어가는 위치에만 제한적으로 보정한다. 공격과 HP는 종별로 달리 올리며 14체 활동 상한은 유지한다.

## 중간 검수
- 거칠게 추적한 8종의 정지 벡터와 8종 각각 대기/예고/공격/피격 브라우저 비교를 완료했다. 64/140/270 px, 양 방향 포함 96개 화면 기준은 실제 게임과 같은 배우 Canvas 경로에서 그렸지만 독립 샘플이지 실제 장 플레이는 아니다.
- 단순 실시간 전체 추적에서는 59장 14체 렌더링 96px에 p95 30.1ms였으므로 불합격 처리했다. 그림에서 실루엣을 보존하고 안쪽 곡선만 정리한 뒤, 같은 종류의 벡터 대기 포즈를 공유하는 24MiB 상한 캐시를 적용했다. 행동·피격·이동·고배율은 기존 Path2D로 직접 그린다.
- 로컬 분리 벤치마크(14체, 그중 1체 행동) 96px p95 3.4ms. 128px는 16.5ms로 전체 실제 장의 저사양 기기 품질을 보장하지 않는다. 초기 캐시·템플릿과 실제 장의 카메라·지형·이벤트 포함 별도 확인을 거친다.
- 코드 확인: `node tests/act6-monster-art-bind.mjs`, `node tests/act6-final-defense-dialogue.mjs`. 전체 장 상태 테스트와 Pages까지 동일하다고 보고하지 않는다. 사용자 직접 플레이 밸런스는 별도다.
