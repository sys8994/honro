# 53→54 본편 파손 난간

[53-B·54-A 선택 도면](../proof-slice/route-plan.svg) · [이전 검수판](../proof-slice/README.md) · [54→55 원본 저장 차단 수정](../relay-fix/README.md)

53장은 산문 뒤 회랑, 서고, 파손 법당, 상부 파손 난간을 연결한다. 기본 오름길과 다시 합류하는 윗마루·들보 길이 있다. 상부 진목 앞까지 실제로 이동하고, 원래 진목 사용과 실제 M09 포격을 마친 뒤 B 건너편 벽에 올라간다. x=3240의 동일 면을 밟고 y=455를 넘어야 정상 54 진입과 기록이 시작된다. 유효 폭은 224 world이다.

54장 수신은 같은 B 지형과 가까운 판을 쓰고, live에서는 동일 담허 객체를 첫 발점에 이어 놓는다. 독립 브라우저에서 새 기록을 열면 같은 발점으로 원본 담허와 승인 적 한 명을 복원한다. 수문지기 또한 실제 +X 가속으로 붙고 그 면을 따라 걸어서 실제 LA01을 쏜다. 담허는 같은 면에서 도약·재접지하고 실제 M01로 교전한다. 승인된 적이 죽고 투사체와 현장 효과가 끝난 뒤에만 관측 회랑을 연다. 회랑의 두 갈래는 각기 정상축 아래길에 돌아온다. 끝의 관측턱을 직접 밟은 뒤 기존 N→L→C→L와 M09를 수행한다.

53의 이전 두 진목과 새 M09는 53의 고정 지지면에 남는다. 새 M09의 증거만 저장에 들어간다. 다른 투사체·물·장판·상승류·소환·지원 위험은 원래 방에서 정상 종료할 때까지 기다린다. 54의 기존 차트 검사에도 이 조건이 남아 있다. 54의 원본 담허 검사는 개인 객체·출처·소유권과 성장 한도 0을 유지하며, 별도 등록한 수문지기만 활성 한도 1의 전투에 들어간다. 내부 소단 기예를 실연해서 운반 정책을 확인하는 검수는 후속이다.

## 재현

기존 53장 이어가기 기록을 별도의 테스트 브라우저에 읽힌 다음, 일반 빌드의 `HONRO.html` 휴식과 실제 입력만 사용한다. `HONRO_ACT6_B_SLICE`는 사용하지 않는다.

```sh
npm run build
evidence=game/docs/act6/mumyeongsa-p00-p10/baseline
python "$evidence/native_b.py" --build "$PWD" --out /tmp/native-b-60 --hz 60 --mobile
python "$evidence/native_b.py" --build "$PWD" --out /tmp/native-b-120 --hz 120 --forks
python "$evidence/relay_live_chain.py" --build "$PWD" --out /tmp/native-b-relay
python "$evidence/cold_resume.py" --build "$PWD" --out /tmp/native-b-old
```

처음 회랑을 거친 표본의 N 진입은 아직 공중에 있을 때 눌러 거부됐다. 접지한 뒤 입력하도록 검수 동작을 고쳤다. 다른 초기 표본의 M09는 법선 (0.968,−0.252)인 옆면에 충돌해 바닥에 진목이 놓였지만, 장의 윗면 증거로 채택되지 않았다. 완료 위치에 들어선 뒤 더 왼쪽을 기다리던 검수 입력도 고쳤다. 재시도에서도 같은 지지면을 실제 방사체로 맞히도록 검사한다.

## 남은 단위

- 53·54의 미술 검수는 승인 시안과 실제 화면을 여러 배율로 겹쳐 보고, 외곽 네 방향·모서리의 더미 반복과 접촉선 오차를 표본화한다. 54의 B 종료 후 관측 회랑과 기존 C 차트는 기존 정상축으로 복귀하는 경로다. 독립적인 역중력 처마 착지와 C의 56 수신은 별도 검수한다.
- C는 56의 첫 받침·정상축 복귀까지만 붙인다. [56 장 어댑터](../../../../../shared/runtime/stage56-adapter.mjs)의 현행 foe 4와 입장 cap 4에서 출발해, 승인 지형을 보호한 채 활성·예비 편성과 첫 가름진 역류를 실제 입력으로 확인한다.
- [57→58 수신](../../../../../shared/runtime/stage58-normal-entry.inc.js)에서 실제 원본 네 사람, 지지면, 좌표·방향, 손상·장비 및 기존 곽진 소유권을 보존하며 새 기록을 읽는다. 58-B 법당은 상하 교전, 대도사 국면, 실제 벽·천장 접촉, 귀환 마루를 분리해 검수한다. 소단의 외부·내부 지원도 실제 기예와 접촉으로 확인한다.
- [58 귀환](../../../../../shared/runtime/stage58-normal-entry.inc.js)과 [59 외부 전선](../../../../../shared/runtime/stage59-owner.mjs)은 네 사람의 수동 산문 통과, 전후 일대일 수신, 소단과 휘겸의 외부 동선, 적 시작·누적·최대 활성·실제 공격과 양측 웨이브를 채운다. 승인된 6-10 엔딩과 다른 작업자의 기존 변경을 보호한다.
