# 58→59 R 공유 산문

58에서 대도사·유지점과 수정 진목 의식이 완료되면 네 원본의 서쪽 이동을 기록한다. 일반 아래 방향 중력에서 기존 돌 바닥을 밟고 `x=3260`을 직접 넘은 기록이 한 명씩 필요하다. 이동 순서를 넘기는 버튼은 통과 증거를 만들지 않는다. 59 수신실은 같은 산문 벡터와 58의 동일 바닥 굴곡에서 같은 발점을 받는다. 네 명이 짧은 석단을 실제로 걸어 나오면 기존 마당의 배우 위치·지형과 전투를 다시 연결한다.

| 실행 | 관측 |
|---|---|
| 이전 58→59 저장 | 이전 앱의 실제 전투 완료본이 일반 쉼터에서 열린다. 기존 59 마당에 접지하고 읽기 전후 저장 바이트 동일. |
| R 수신 계약 | 이전 58 완료 기록에 시험용 R 접촉 좌표를 만들어 입력했다. 59 일반 쉼터에서 네 원본의 ID·체력·기력과 짐을 그대로 받아 `m59-return-gate-stone`에 접지했다. 네 명이 실제 입력으로 서쪽 끝까지 걸은 뒤 일반 59 지형과 위협이 복원된다. [수신 화면](screens/contract-receiving.webp) · [마당 화면](screens/contract-courtyard.webp) |
| 오염된 접촉 | 시험용 기록의 설오 한 발점을 1 world px 위로 바꾸고 해시를 다시 계산했다. 59 이어가기를 거부하고 쉼터와 저장 바이트를 유지했다. |
| 58 실전 및 네 명의 R 통과 | 7라운드에 대도사와 유지점이 모두 쓰러졌다. 담허가 수정 진목을 놓고 네 명이 일반 아래 방향 중력에서 돌 바닥을 밟아 서쪽 선을 넘었다. 8라운드 승리와 다음 장 해제까지 확인했다. [실전 승리 화면](screens/live-58-r-won.webp) · [위치·플래그](live-58-r-won.json) |
| 실제 새 59 저장 | 실전 기록기는 마지막 담허가 승리하면서 입력이 끝난 뒤에도 계속 걸으려다 다음 장 클릭을 놓쳤다. 승리 프레임에서 이동을 해제하도록 바꿨으며 라이브 59와 새 저장 검수를 재실행 중이다. |

첫 실전 실행은 낮은 통로에서 보스에게 닿는 포격이 부족해 14라운드에 소단이 쓰러졌다. 다음 실행에서 전열을 동쪽으로 나누고 예고를 피한 뒤 승리했다.
