## 축과 카메라 모션

시스템의 `prefers-reduced-motion: reduce`를 적용한 Chromium에서 60·120Hz 양쪽의 B에서 실제 +X 방향 접지와 원래 사격을 관측했다. 두 주사율 모두 실제 M01 폭발 뒤 수문지기는 접선으로 67.83 world px, 폭발 범위에 있었던 담허는 179.63 world px까지 밀리고 각각 벽으로 다시 접지했다. 적의 LA01도 실제 접촉해 피해를 줬다. 120Hz 판은 이후 M09·C·55 새 저장까지 통과했다. 60Hz 판은 B와 정상축 복귀 이후 M09 사선 계산에서 멈췄다. 별도 기본 모션 두 판의 55 라이브·새 저장은 검수됐다. [감소 모션 입력·피격·재접지](b-reduced.json) · [60Hz 화면](b-reduced-60.webp) · [120Hz 화면](b-reduced-120.webp) · [기본 모션 두 주사율](../native-b/observed.json)

카메라의 시스템 설정은 등장 카메라의 패닝을 420ms에서 1ms로 바꾸고, 이야기 프레임의 목표 위치를 즉시 적용한다. 이는 렌더 코드의 설정이다. 물리 축은 같은 B와 C의 실제 몸·발점 계산에서 나온다. [등장 카메라](../../../../../shared/runtime/reinforcement-camera.js) · [이야기 카메라](../../../../../shared/runtime/story-framing.js)

58의 기존 빌드에서 실제 조작으로 벽·천장에 붙인 뒤 엔진 진단을 실행했다. 기본 포격과 같은 방향의 충격을 넣었을 때 두 축 모두 접촉면에서 4 world px 이상 떨어지지 못했다. 이 항목의 진단은 직접 충격 입력이다. 실제 전투의 포탄 충돌은 별도의 60·120Hz 명중 자료에서 확인했다. [60Hz 수정 전](gallery-before-60.json) · [120Hz 수정 전](gallery-before-120.json) · [실제 천장 포격](../hall-d/gallery-combat.json)
