Chromium PC 1440×900, DPR 1에서 전후 카메라 월드 사각형·배율을 고정했다. 일반 여정첩 검수 진입으로 53·54·58을 각각 열었다. 54 B는 앞서 실제 플레이로 얻은 서명 체크포인트를 썼다. L과 C의 화면은 진단용 위치 설정 뒤 기존 차트 버튼을 눌러 전환하고 발이 닿은 상태에서 캡처했다. 전후 여섯 상태에서 엔진 플레이·월드 지형 배열, 발점, 중력, 플레이·시각 경계 값이 모두 일치했다. 검수용 충돌 윤곽은 계속 활성화할 수 있다. [카메라·지형·이미지 해시](conditions.json)
