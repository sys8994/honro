# 54→55→56 찢어진 처마 C

54의 M09가 서명된 윗면에 실제 닿고 기존 출구에 접지하면 짧은 C 처마실이 열린다. 담허는 떨어진 위치에서 위 방향 가속 (0,−320)을 받아 천장 y=900에 발을 붙인다. 법선은 (0,+1)이며 대향 난간 y=1136까지 236 world이다. x=720을 걷고 나서 x=736의 실제 접촉을 기록한다. 기존 L 차트의 충돌점·진목·반경과 세 차트 밟기는 함께 유지한다.

55에는 원래 세 외부 배우만 전투에 들어간다. 담허의 x=736, y=900과 C 접촉은 보호된 담허 기록으로 남아 빈 종터 완료 뒤 56장에 넘어간다. 같은 처마의 live 진입 및 새 저장 재로드에서 담허를 같은 발점과 법선으로 받았다. 오른쪽으로 이동해 x=928에 닿으면 중심을 유지하며 아래 방향 가속으로 전환한다. y=1136에 착지하는 순간 승인된 `A-upper-veranda`가 열린다. 본체의 11개 벡터 지형·낭떠러지·승인 미술과 원래 적 위치를 처음 상태에서 이어 사용한다.

| 검수 | 결과 |
|---|---|
| 54 M09 및 C | 기존 54장 기록에서 실제 N→L→C→L을 수행하고 M09를 발사했다. C의 받은 법선과 중력, x=736 접촉, 장 저장을 확인했다. 본편 53 출발의 120 Hz B→C→55 별도 검수도 통과했다. |
| 빈 종터 및 두 저장 | 실제 HLN01 타격으로 결속이 풀리고, 소단이 접지해 결속을 수리한 뒤 공격으로 빈종각귀를 해소했다. 새 55·56 기록을 독립 브라우저에서 각각 읽었고 일반 저장과 시점 기록 바이트가 맞았다. 바꾼 M09 표면·기예와 C 접촉 법선은 거부됐다. |
| 56 진입과 되돌림 | live 및 cold 모두 x=736, y=900에서 시작해 x=928, y=1136의 승인 난간으로 내려갔다. 수신실 동안 본체 적은 대기했고, 난간에서 x=1936,3456,5872의 세 적을 원래 위치에 확인했다. |
| 첫 가름진 역류 | 실제 도보·도약과 목표 입력으로 두 진목, 작동, 다른 발점에서 역류 확인까지 수행했다. 엔진 힘 표본은 +145에서 −145로 바뀌었고 예약 적 `draft-pressure-3`가 나왔다. |
| 기존 기록 | 54·55·56의 기존 포맷을 그대로 열었다. 잘못된 이전 M09 기록은 거부됐다. C가 없는 이전 55→56 기록은 기존 난간에서 시작한다. |

첫 반복에서 56 수신실이 본체 적에게도 임시 지형을 적용하고, 담허가 일반 방향으로 그려지는 문제를 발견했다. 본체의 배우를 수신실 밖에 보관하고 실제 산책 렌더에 천장 자세를 적용했다. 또 시험 입력이 난간 착지 뒤까지 눌린 경우 x=934.7을 읽어 틀린 실패를 냈다. 아래 중력 복귀 때 키를 놓고 원래 난간 접지를 기다리도록 검수 입력을 고쳤다.
