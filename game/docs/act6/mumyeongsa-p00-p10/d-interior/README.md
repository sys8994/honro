# 56 안쪽 돌길과 D의 두 접근

56의 기존 첫·둘째 진목, 가름진 역류와 대피, 임시 통로 개방, 동쪽 돌길을 실제 완료하면 원래 출구 부근에서 D 돌문턱을 연다. 원래 출구에 닿는 순간은 이동 중이며 57로 가는 버튼이 뜨지 않는다. 담허가 원래 E 발판 끝을 걸어 새 석단에 올라가고, 공용 문턱 안에서 실제로 발이 닿은 뒤 57을 연다. 바깥 57은 원래 받침·석교·결속·곽진·육신 회수 순서로 진행한다.

| 가지 | 월드와 공용 단면의 대응 |
|---|---|
| 56 E 끝과 실장한 D | 원래 `E-joined-ordinary-floor`의 끝 (6536,3232)에서 D의 공용 첫 발점 (2600,3470.857142857)으로 이어진다. 공용 점에 (3936,−238.857142857)을 더한 발면을 사용한다. 기존 끝을 지나야 걷는 받침 하나를 추가했다. |
| 57의 바깥 석교 | 공용 점에 (+3200,−758)을 더한 원본 네 사람 수신 슬라이스와 문틀을 그대로 쓴다. 합체 뒤의 기존 물리 경로를 걷는다. |
| 58의 낮은 법당 | 공용 점을 같은 축척으로 읽고 원래 바닥과 비교한다. 56 발점 증거와 57 원본 네 사람의 점이 모두 공용 단면에 속한다. |

세 갈래의 공용 단면은 선언한 408 world px 통과 구간과 같은 목조 문틀 벡터를 쓴다. 실제 D 접촉 방향은 아래 (0,+320), 발면 법선 (0,−1)이다. 58 +X 벽과 −Y 처마는 입장 뒤 별도 실제 구역에 남는다. 56 본체와 바깥 낭떠러지 패킷은 기준과 동일한 blob `49ee966549dd788c157d76dfe0008147df595183`이다.

56 실제 기록은 원래 E에서 접근한 발점, 새 면에 처음 붙은 위치, 공용 좌표와 실제 출발 발점을 각각 적는다. 장의 마감과 새 57 경계가 그 발점을 확인한다. 57은 외부 원본 네 명과 곽진의 별도 영수증을 그대로 요구하고, 56 증거가 있었던 판에서는 새 58 기록에 함께 싣는다. 이전 56 기록에는 원래 E 면의 출구 지점만 허용한다. 이전 58 기록은 네 원본과 기존 곽진 증거를 검증하며 존재하지 않았던 실내 증거를 만들어 내지 않는다.
