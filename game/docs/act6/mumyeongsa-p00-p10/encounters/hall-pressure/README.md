# 58 대도사와 R 실전 압박

일반 쉼터에서 호환 58 저장을 열고 대도사 표식에 맞춰 이동, 공격, 방어를 선택했다. 시드는 19388이다. 4명으로 시작해 공격 가능한 16명이 등장했다. 이 중 대도사는 기둥·문턱 입력 뒤 등장했고, 유지점과 시각 전용 인물은 집계에서 제외했다. 12라운드 동안 실제 입력 48회를 썼고, 13라운드에 쓰러진 대도사와 유지점을 확인한 뒤 같은 원본 네 명을 R까지 걸었다. 새 59 저장을 별도 컨텍스트에서 열었을 때 발점, 상태, 저장 바이트가 같았다. 종료 때 일반 적 여섯 명이 살아 있었다.

| 기준 | 첫 실측 |
|---|---:|
| 시작 / 누적 공격 가능 적 | 4 / 16 |
| 한 라운드에 행동한 적 최대 | 6 |
| 실제 발사 / 직접 충돌 | 29 / 24 |
| 대도사와 부하가 체력 또는 실드에 피해를 준 기록 | 69 |
| 최대 활성 수 / 계획 상한 | **12 / 9, 실패** |

빙의 그릇과 먹빛 잔향, 기괴한 몸을 장 소유자가 추가하면서 기존 지역 편성 갱신을 기다리는 동안 활성 수가 넘었다. 국면 변화·등장·기괴한 몸 추가 시 같은 편성 함수로 현재 발점과 지역을 즉시 재평가하도록 수정했다. 새 버전에서 최대 9명과 기존 실제 교전·종료를 다시 측정해야 한다. 이 판의 33.4 ms는 다른 브라우저와 함께 실행한 데스크톱 호스트 값이다. 모바일 단독 성능 판정에는 쓰지 않는다.
