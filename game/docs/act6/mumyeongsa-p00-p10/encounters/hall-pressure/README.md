# 58 대도사와 R 실전 압박

일반 쉼터에서 호환 58 저장을 열고 대도사 표식에 맞춰 이동, 공격, 방어를 선택했다. 시드는 19388이다. 4명으로 시작해 공격 가능한 16명이 등장했다. 이 중 대도사는 기둥·문턱 입력 뒤 등장했고, 유지점과 시각 전용 인물은 집계에서 제외했다. 12라운드 동안 실제 입력 48회를 썼고, 13라운드에 쓰러진 대도사와 유지점을 확인한 뒤 같은 원본 네 명을 R까지 걸었다. 새 59 저장을 별도 컨텍스트에서 열었을 때 발점, 상태, 저장 바이트가 같았다. 종료 때 일반 적 여섯 명이 살아 있었다.

| 기준 | 첫 실측 |
|---|---:|
| 시작 / 누적 공격 가능 적 | 4 / 16 |
| 한 라운드에 행동한 적 최대 | 6 |
| 실제 발사 / 직접 충돌 | 29 / 24 |
| 대도사와 부하가 체력 또는 실드에 피해를 준 기록 | 69 |
| 최대 활성 수 / 계획 상한 | **12 / 9, 실패** |

빙의 그릇과 먹빛 잔향, 기괴한 몸을 장 소유자가 추가하면서 기존 지역 편성 갱신을 기다리는 동안 활성 수가 넘었다. 국면 변화·등장·기괴한 몸 추가 시 같은 편성 함수로 현재 발점과 지역을 즉시 재평가하도록 수정했다. 새 버전에서 최대 9명과 기존 실제 교전·종료를 다시 측정해야 한다. 이 판의 33.4 ms는 다른 브라우저와 함께 실행한 데스크톱 호스트 값이다. 모바일 단독 성능 판정에는 쓰지 않는다.

활성 갱신을 고친 판에서는 시작 4명, 누적 16명, 최대 활성 9명, 라운드별 행동자 최대 6명, 실제 발사 18회와 체력·실드 피해 기록 34건을 확인했다. 네 원본이 R을 직접 건너 59에 라이브 및 새 컨텍스트로 들어갔다. 대도사·유지점을 쓰러뜨린 뒤 8라운드에 돌아왔으므로 11라운드 하한은 여전히 미달이다. [활성 상한 수정 후 실제 지상 판](activation-capped-ground.json) · [R 출발](activation-capped-ground.webp)

같은 시드의 상층 경로는 58의 벽 `(+320,0)`과 천장 `(0,−320)`에 실제 접지해 M01로 `a6-58-opening-2`에게 피해를 준 뒤, 보통축에 착지하고 후반 대도사 국면과 유지점, 네 몸의 R을 완료했다. 시작 4명, 누적 18명, 최대 활성 9명, 라운드당 순서 최대 6명, 실제 적 발사 28회, 체력·실드 피해 33건이었다. 마지막 전투와 R은 10라운드로 11라운드 하한보다 짧다. 후속 지상 판은 2국면에 동쪽 마루 `(4335,3080)`와 중층 `(3975,3073.526)`에서 실재하는 분대가 합류했다. 5라운드 소단이 바닥 `(4459.190,3203.573)`을 밟고 장부 먹선을 끊어 후반 충전에 대응했다. 시작 4명, 누적 16명, 최대 활성·행동 순서 9·6, 실제 적 발사 16회와 체력·실드 피해 28건을 기록했다. 마지막 전투는 8라운드에 끝났고 3국면 새 지원대는 이 지상 판에서 들어오지 않았다. 이후 네 배우의 R 라이브와 59 독립 재로드를 확인했다. 기록의 50ms는 다른 판들이 함께 실행된 호스트 수치다.
