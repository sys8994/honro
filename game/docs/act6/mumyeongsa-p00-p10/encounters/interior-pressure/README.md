# 53·54 세 구역을 직접 싸운 첫 판

54는 실제 53 출발의 B 경계에서 시작했다. B의 네 명, 54-N의 네 명과 회랑 세 구역에서 새로 다섯 명이 들어와 **누적 13명**을 확인했다. 최대 공격 큐는 4명이다. 들보와 관측턱에서 13라운드까지 실제 교전했지만 담허가 쓰러져 M09나 C로 갈 수 없었다. 이 판은 누적과 총 피해의 실측이며 승리 경계를 통과하지 못했다. [54 피해·발점 원자료](54-first.json) · [실패 화면](54-first.webp)

53은 다섯 명으로 시작해 세 방에 도착해 실제 공격했다. 누적 일곱 명이었고, 8라운드에 윗난간에서 진목 쌍을 사용하려 했으나 기한 내 착지하지 못했다. 같은 위치에서 발점과 기존 `gateResolution`의 전체 거부 이유를 따로 기록하도록 재현기를 보강했다. [53 타격·이동기록](53-first.json) · [실패 화면](53-first.webp)

python game/docs/act6/mumyeongsa-p00-p10/baseline/hall_encounters.py --build "$PWD" --out /tmp/honro-54-pressure --stage 54 --b-proof game/docs/act6/mumyeongsa-p00-p10/visual-atlas/capture-input-b.json

53 재현에서 여덟 번째 라운드에 실제 발점이 맞았지만 두 진목이 모두 사라진 것을 확인했다. 플레이어 설치물을 처리하는 기존 유효기간 부여가 장 소유의 고정 통로에도 적용되었다. 고정 통로의 정확히 두 진목을 구분했다. 53 방 세 곳의 접지 거리 범위도 조정해 후방 적이 멀어지면 살아 있는 몸을 유지한 채 다음 방에 자리가 생기도록 했다. 변경 후 같은 일반 앱에서 시작 5명, 누적 12명, 활성 최대 6과 라운드 공격 큐 최대 4를 확인했다. 목진목 11·12를 원래 발점에서 사용한 뒤 실제 M09와 공용 B를 밟아 54 새 저장을 읽었다. 이 판은 빠른 경로로, 장기 대치 후 재통과와 8라운드 하한은 추가 검수 중이다. [TTL 실패](53-expired-gates.json) · [12명 실전과 새 54](53-retained-route.json)

54 하단·윗마루 비교는 같은 승인 B 저장에서 시작했다. 앞의 두 접근 지점은 각기 4·5라운드, 끝 관측턱은 10라운드였다. B의 실제 피해는 두 판에서 체력 33과 실드 27로 같았다. 하단 판은 회랑에서 체력 피해 1,317.1을 받은 뒤 쓰러졌다. 두 윗마루로 도약해 회생진목을 쓴 판은 더 오래 교전해 회랑 피해 2,193.0을 기록했으며, 진목 회복을 거쳐 15라운드 차트와 새 55 저장까지 체력 1,408.3으로 도달했다. 이 판의 누적은 12명이다. 하단 판에서 나온 누적 13명과 같은 실행의 완주로 묶지 않는다. 상대의 실제 넉백과 좁은 회랑의 발점은 다음 단일 실측에서 함께 기록한다.

회랑 내부에서 실제 투사체가 만든 담허 소유 M07·M10만 장 소유자가 등록한다. `N→L`의 기존 발점·단차·출구 확인을 모두 통과할 때만 그 자리의 설치를 종료한다. 다른 장과 차트의 투사체·지원 효과 거부는 유지한다. 위 판은 회생진목 23번을 `N→L`에 남겼고, 실제 M09가 `x=2308.381236`, `y=2924`, 반경 6으로 맞아 동일 `mid-contact` y=2930의 윗면으로 확인됐다. 실제 C 천장 뒤 55 새 저장을 별도 앱 문맥에서 다시 열었다. B의 체력 피해 33과 실드 피해 27은 두 비교판과 같았다. 회랑 체력 피해 1,857을 주고받는 동안 실제 넉백 두 건은 B(3540×3000), 17건은 N 회랑(3200×3000)이었다. 회생진목과 두 윗마루를 써 담허 체력 1351.3으로 새 55를 다시 열었다. ### 회생진목과 부활 없이 마친 54

세 짐승의 호위 범위를 첫 마루 끝 x979와 둘째 관측 구간 x1148의 접지 위치로 넘겼다. 뛰거나 떠밀리는 동안은 마지막 실제 접지 구역을 쓴다. 원래 배우는 그대로 현지에 있고 돌턱으로 되돌아가면 다시 대응할 수 있다. 세 짐승 중 같은 라운드 순서에 동시에 들어온 최대는 1명이었다. 4·5·6~7라운드에 서로 다른 하운드가 각각 실제로 행동했다. 기존 HBM01 효과, 피해 수치와 체력은 그대로다.

같은 일반 B 저장을 열고 담허의 [M01, M10, M07] 장착을 보존했다. 이 판은 M10이 장착돼 있으나 **한 번도 쓰지 않았고 부활이 없었다**. 라운드 11에 시작 4명, 누적 14명, 활성 최대 6명, 공격 순서 최대 4명으로 55에 들어갔다. B에서 체력 33·실드 27, 보통축 회랑에서 체력 985를 잃었다. 기존 패배판에서 세 하운드에게 받은 1,162.1이 이번에는 100+97+200=397이었다. 나머지 회랑 적은 588을 가했다. 실제 넉백은 B 2건·N 17건이었다. 담허는 체력 322.2를 남겼다.

세 차트, 실제 M09 `x=2310.789370`, `y=2924`, 반경 6과 `mid-contact` y2930의 동일 면, C 천장 `(736,900)` 접지를 거쳤다. 따로 연 새 55는 같은 저장 바이트와 기예 배열을 유지했다. [전체 실제 행동](54-no-mending.json) · [M09](54-no-mending-legacy54-m09.webp) · [C](54-no-mending-eave-send-ceiling.webp) · [55 라이브](54-no-mending-legacy54-live55.webp)

## 53 서고와 법당 사이의 실제 교전 범위

두 대조 RNG 값 31717·46183에서 담허가 법당을 지나며 사망했다. 31717에서는 서고 끝의 수의귀 `archive-balcony-3`가 체력 480, 옛 상주와 법당 안 두 수의귀가 709.4를 깎았다. 서고 적과 법당 적이 같은 라운드에 서로 다른 높이에서 공격했다. 역할은 원래 발판에 남기고, 실제로 접지한 배우가 서고를 지나 법당의 두 돌턱을 건너면 그 방의 역할이 교전하도록 범위를 정했다. 똑같은 HBM01과 배우 체력을 쓴다. [31717 이전 손실](53-before-handoff-31717.json) · [46183 이전 손실](53-before-handoff-46183.json)

### 같은 대조 RNG의 일반 저장 완주
