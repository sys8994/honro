# 55 빈종각귀의 실제 사선과 복구

51부터 일반 쉼터로 이어간 한 탭이 처음으로 막힌 곳은 55였다. 원래 `(2112,1523.077)` 돌턱에 있던 빈종각귀가 등불귀 비행 AI의 재배치로 `(2440,785.75)`까지 날아가 체력 60에서 살아 있었다. `fixed`를 사용하던 다른 종과 비행 적은 기존 분류를 쓴다. 이 장의 빈종각귀만 고정 지상 사수로 둔다.

고정 뒤에도 종을 개시하면 HLN02만 택했다. HLN01을 고른 대조에서는 방아쇠가 한 번도 작동하지 않았다. 현행 솔버가 `(2660,1600대)`의 소단을 향해 계산한 발사 경로를 원문 그대로 조사했다. 먼저 닿은 세 점은 `x=2236`의 새 증원 몸통이었다. 기존 도착·수리·실패 조건을 유지하고, 그 증원 일부를 서쪽과 낮은 암반, 소단 뒤편의 독립 발판으로 재배치했다. 휘겸이 받침에 닿은 뒤 수리 전까지 빈종각귀는 실제 HLN01 방사를 시도한다. 수리한 뒤에는 본래 두 기예로 돌아온다.

복구 판의 빈종각귀는 시작부터 사망까지 `(2112,1523.077)` `arrival-core-terrace`에 접지했다. 1라운드 HLN01이 `(2660,1641.211)`에서 좌정한 소단을 직접 쳐 체력을 2144.1에서 2105.1로 낮췄다. 2라운드 휘겸 행동을 소비해 접지한 소단이 결속을 수리했고, 실제 설오 사격이 480→371→38→0으로 낮췄다. 5라운드 휘겸이 정렬하고 새 56이 라이브 및 새 컨텍스트에서 열렸다. 이 판은 복구 및 진입의 증거다. 55 누적·라운드 목표 및 다른 결속 경로의 현재 판은 별도다.
