# 무명사 게이트 검수표

감독은 P00(`aa40fb1`), P20(`56d7b946`의 물리·실제 경계 검수), P40(`c01cb3ca`의 독립 검수표와 실제 인계 증거)을 통과로 판정했다. 배점 합계는 **40%**다. P40의 장착·기력 격리 표본과 모든 조합의 미실측 범위는 아래에 기록했다. 나머지 게이트의 판정은 진행 중이다.
