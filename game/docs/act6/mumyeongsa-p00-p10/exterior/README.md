# P30 외부 접촉선 검수

51은 일반 쉼터에서 들어갔고 52·55·57·59·60은 격리된 컨텍스트에서 기존 정상 기록으로 열었다. PC와 390×844 터치에서 같은 배율과 카메라 위치로 원본과 충돌선을 각각 캡처했다. 장마다 시작 지점에서 실제 이동하고 수평 5개 위치를 촬영했다. 아래 면 수는 솔버가 같은 지형으로 판정한 걸을 만한 구간이며 개별 경로 완주의 수가 아니다. [실측 JSON](observed.json) · [PC 장별 오버레이](screens/pc-six-chapters.webp)

55 중앙 `x=3400`은 석단에서 두 은행 사이로 내려가는 빈 공간이다. 실제 발판처럼 보였던 뒤쪽 돌띠와 암면 4개의 명도·색을 낮췄다. 형상과 돌단·가까운 발판은 원래대로 그린다. PC의 같은 화면 좌표 `(640,200)`은 RGB `(118,107,101)→(73,74,81)`, 기존 발판 쪽 비교점 `(160,322)`는 `(110,101,95)`로 동일하다. 아래 화면은 이전·이후·이후 접촉선 순이다. [PC](screens/bell-gap-pc.webp) · [터치](screens/bell-gap-touch.webp)

59 서쪽 높은 단에서 이전에 관측한 약 4 px는 띠 내부의 밝기 대비였으며 접촉선 편차 계산에는 실제 원본 윗변을 대응했다. `westTraversal7-0`과 `finale-cutout-west-terrace`는 양 끝 `(1493.92265,1519.11602)`과 `(1644.75138,1677.12707)`부터 같은 선이다. 기존 기록에서 PC와 터치로 이 단 위를 실제 이동했다. [PC](screens/west-high-pc.webp) · [터치](screens/west-high-touch.webp)

57의 접힘과 수신 돌은 런타임에서 원본 4명이 밟고 58에 진입했다. 60은 1440·390에서 두 혼 인도, 3라운드, 확인된 완료 영수증, 저장 바이트 보존, 자연스러운 타이틀 귀환을 확인했다. 51·52·55·57의 개별 좁은 계단·벽·점프·양쪽 끝을 모두 실제 입력으로 밟은 결과와 장식 전체의 정량 편차는 미검수다. [57 경계](../sodan-thread/reunion.json) · [60 PC](screens/ending-1440.webp) · [60 모바일](screens/ending-390.webp)

## 여섯 장 접촉선 대조

두 화면 크기에서 일반 앱 솔버가 같은 지형으로 확인한 모든 보행 가능 윗변을 20·50·80% 지점에서 조사했다. 각 표본을 대응하는 원본 자산의 실제 인스턴스 좌표로 투영해 가까운 같은 기울기의 모서리를 비교했다. 55의 단일 미술과 57의 암반은 자산 하나가 여러 받침으로 이어지므로 원본 근접 모서리와 대조했다. 57의 가드레일·수리받침·담허 돌단 15점은 별도 미술이 없고 충돌 지형을 엔진이 직접 그려 실제 화면과 충돌선을 별도로 확인했다.
