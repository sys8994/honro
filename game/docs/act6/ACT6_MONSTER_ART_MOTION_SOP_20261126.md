# 6막 신규 몬스터 8종: 모션 검수와 제작 SOP

**판정: 이미지 시안 → Inkscape 분리·벡터화 → 파트별 리깅은 조건부 후보 제작법이다.** 현재 8개 모두 공격·피격은 서로 다른 실제 포즈로 그려진다. 실제로 전진하는 두 원혼의 이동을 보완했고, 현재 전용 이동 포즈는 6개다. 따라서 “시안이 예쁘거나 파트가 나뉘었으니 자연스럽게 움직인다”로 판정하지 않는다. 사람과 닮지 않은 몸에 모두 같은 걸음이나 점프를 그리는 것도 하지 않는다.

## 실제 런타임 검수

`python tests/monster-detail-seven-browser.py --finale --out _local/reports/act6-motion-review`는 실제 `Scene.unitBody`, `HonroActorVisual.state/pose`, Canvas Path2D와 상용 리그를 사용한다. 같은 시간에서 해당 동작만 켜고 껐을 때 관절 변형이 있는지 비교해 단순한 대기 흔들림을 이동 모션으로 잘못 세지 않는다. 96px에서 대기·이동 요청·공격·피격·반전, 128px에서 확대를 확인했다. [기존 장 연결 검사](../../../tests/act6-monster-art-bind.mjs)도 통과했다. 독립 렌더 검수는 실전 조작이나 저사양 성능 측정과 구분한다.

| 6막 리그 | 공격/피격 | 전용 이동 포즈 | 전용 점프·낙하 |
|---|---|---|---|
| 대도사 | 있음 | 없음, 8장 페이즈는 떠오름과 위치 바꿔치기 | 없음 |
| 거꾸로 매달린 상주 | 있음 | 있음, 8장 고정·낙하 예고에 전용 공격 포즈를 사용 | 없음 |
| 천수귀 | 있음 | 있음 | 없음 |
| 입 벌린 문짝 | 있음 | 있음, 8장 본체는 고정 | 없음 |
| 넘쳐온 원혼 | 있음 | 저공 전진, 몸통이 먼저 기울고 휘장이 반 박자 늦게 따라옴 | 없음 |
| 맺힌 원혼 | 있음 | 몸이 낮게 밀린 뒤 매듭이 반대로 튕겨 되돌아옴 | 없음 |

대도사·거꾸로 매달린 상주·혼류의 앞발의 예고 바인딩과 발동 우선순위는 8/9장 엔진 신호를 입력으로 확인한다. 이동 트랙이 있다는 사실과 엔진이 실제 그 동작을 호출한다는 사실은 다르다. 전용 점프·낙하 포즈가 없다고 고정/부유형이 실패하는 것도 아니다. 59장의 실제 전진 신호를 받는 두 원혼에는 전용 움직임만 추가했다. 피벗, 벡터 경로, 대기·공격·피격 키, 조준, 이동 속도와 전투 규칙은 이전과 동일하다. 고정·위치 바꿔치기 역할인 대도사와 앞발에 보행을 억지로 넣지 않았다. 미술 취향 최종 승인과는 분리한다.

## 다음 제작부터 적용

1. 먼저 스테이지 실제 소유자와 연출표에서 고정·활보·부유·급강하·위치 바꿔치기를 구분하고, 몸통과 별도로 움직여야 할 부분을 정한다. 공통 행동명에 끼워 맞추지 않는다.
2. 승인된 시안은 몸통, 중첩되는 관절 끝, 손에 든 물건, 천과 매듭을 레이어로 분리한다. 정지 그림을 통째 추적해 한 장으로 흔들지 않는다. 팔이나 천을 최대 각도로 움직였을 때 빈 관절이 노출되지 않도록 가려져 있던 여유 면을 포함해 작도한다.
3. Inkscape에서 실루엣, 주요 명암, 전투 식별 단서(약점·손·창살·부적 등)를 먼저 벡터화한다. 경로 최적화 전에 게임 피벗을 표시하고 움직일 그룹을 고정한다. 실제 게임 배율에서는 중요한 면을 남기고, 클로즈업 전용의 안쪽 미세 무늬만 더 높은 LOD에 둔다.
4. 게임의 동일 상태에 연결한다. 대기·공격 예고→발동→회복·피격은 필수로 맞춘다. 스테이지가 실제로 이동시키는 종은 이동 방식에 맞춰 몸 무게와 뒤따르는 부속을 배치한다. 실제 점프·낙하를 쓰는 종만 그 포즈를 별도 검증한다. 조준·충돌·유닛 위치는 연출 변경 때문에 손대지 않는다.
5. 같은 일반 전투 배율과 근접 배율에서 좌우 반전, 관절 겹침, 지면이나 천장 기준, 타격 전후 형태 보존을 본다. 독립 리그와 실제 장의 등장·경고·이동·발동 중 어느 경로를 확인했는지 구분한다. 기존 8종의 모션이 이미지 시안과 입체 구조는 충족하더라도, 이동과 자연스러움은 해당 종을 실제 전투와 나란히 본 뒤 최종 채택한다.
