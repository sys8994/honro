### 공간 전환

과거 실제 플레이에서 작성해 저장소에 보존된 B/C/D/R의 서명 저장을 **현재 버전** 일반 쉼터에서 열어, 390×844 모바일 조이스틱으로 이동했다. B는 벽을 따라 걷고 다시 같은 벽에 착지했다. C는 위쪽 중력 벡터로 발을 붙이고, 통로를 건너 정상 중력, (928,1136) 난간에 닿았다. D는 네 원본이 같은 수신 마루에 섰고, 담허가 그 마루를 걸었다. R은 네 원본을 하나씩 터치로 골라 산문 건너편 같은 마당까지 옮겼다. 모두 공개 기체의 저장 계약을 통과했고, 각 검수 전후 주 저장 바이트가 동일했다. [수신 및 터치 결과](seams.webp)

54의 L, C, C→L도 현재 애플리케이션 버튼으로 도달해 렌더와 접지를 확인했다. 여기는 전투 재완주 대신 검수용으로 유효한 지형의 발점을 설정한 후 실제 전환 버튼을 눌렀으므로, B/C/D/R의 독립 이동 검증과 구분한다. [세 전환](charts.webp)
