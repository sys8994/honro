## 단계 1: 공간·시안 계약
역사적 한국 산사 목구조(기둥·창호·공포·기와·들보·석단·단청 잔흔)가 경로/전투에 쓰여야 한다. 6-8은 동굴에 소품만 얹는 것이 아니라 바닥·회랑·벽·천장이 본체인 비틀린 법당. 6-3/4/8은 각 새 시안 2안과 선택 근거, 공용 축척의 영웅 오버레이(실제 h/r, 문/계단을 비교), 원경·접지용 지형·전경 마스크 분리, 허용 엣지와 연결구 명시, 정측면. 노드 예산은 빈 맵 면적이 아닌 실제 벌크 기준으로 1막 1·2장 측정부터. 실루엣 선명, 얇은 명암 밴드/블러 추적 금지. 접합·연속성 먼저, 노드 최적화는 뒤. 아래/위/좌/우·네 모서리를 실제 확대·전체뷰로 검수. 의도적 낭떠러지는 붕괴 지형과 물리 귀결까지 명시한 설계 예외, 그 밖에 화면 끝에서 잘린 벽·지붕·기둥·미봉합 바닥 0. 6-6 본체·낭떠러지와 예외를 유지하고 경계용 입출구만 국소 조정.
- 실제 연결: A(6-3 산문 뒤 회랑) → B(6-3 출구/6-4 입구, 같은 기둥·파손 난간·문폭/발판) → C(6-4 출구/6-6 입구, 가로로 열리는 찢어진 처마의 끝) → D(6-6 깊은 길/6-8 진입부가 맞닿는 법당 문턱). 6-5와 6-7은 바깥으로 시점이 바뀌는 장이지 내부가 물리적으로 단절되는 장이 아님. 6-7의 네 명 재진입 경로는 D에 닿는 기존 외부 석교/문턱 분기로 동일 랜드마크를 교차시킨다. 6-8 퇴장→6-9 바깥 도착도 같은 산문 그래픽 앵커.
- `edgeId, from, to, landmarkId, approach, sharedColliders, clearWidth, activeGravity, nextSpawn, allowedHazard`로 경계 선언. 같은 축척 비교, 양편의 문폭/충돌은 허용 4 world px 이내, 나타나는 방향/인물의 발 위치/중력 일치, 입구 통로 100% 통과 가능. 종료 버튼/텔레포트만으로 문턱을 대체하지 말고 실제 이동으로 접촉 후 장 전환하고, 다음 장 첫 프레임의 출발선을 직전 끝점과 대응. 관계가 불분명하면 antechamber를 겹쳐 렌더, 새 장에 갑자기 막다른 벽 금지. 6-3·4는 실제 이동 가능한 경로 길이가 각각 기존 대비 1.8배 이상, 주요 방 4개 이상, 상하 분기 2개 이상, 재합류 1개 이상 확보를 작업 가설로 삼는다. 공간 부피를 늘리기만 하고 직선/빈방으로 채우면 실패. 6-8은 진입/상하 교전 선택/법당 중심/귀환을 구분. 각 장의 상하좌우 연결·교전 경로를 실제로 긁어보는 전체뷰와 국소 캡처 첨부.
