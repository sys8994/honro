# 6막 피날레 플레이 검수 기준 개정
2026-11-25 / 곽진 방패선과 네 인물 합류 확정안 기준

기존 기획서의 “클리어 턴”은 개인 행동인지 아군/적 교대 라운드인지 정의되어 있지 않습니다. 이번 검수에서는 그 목표를 임의 환산하지 않습니다. 스톡 유저 화면이 기록하는 엔진 라운드, 실제 아군 행동, 그 중 발사/방어/대기/현장 조작, 이동 입력, 적 턴과 증원 횟수, 시뮬레이션 초, 실제 플레이 초(컷신 제외)를 별도로 수집합니다. 초기 정량 목표를 충족했다고 주장하기보다 어떤 선택이 빠졌는지를 먼저 봅니다. 늘어난 대기·숫자 채우기·전면 섬멸을 난이도로 인정하지 않습니다.

## 표준과 별도 판정

- 격리된 실제 Chromium PC·모바일 전장 목표, 엔딩 컷, 임시 종료 기록은 통과한 기반입니다. 별도 선택 시드, 독립 사람 조작, 자유 카메라, 모바일 플레이 해상도와 기존 성장 파티의 정상 세이브·이어하기를 이 기반에 합산하지 않습니다.
- 6-3/4의 실제 2라운드와 6-9의 3라운드는 탐구/압력 관점에서 보강 대상입니다. 6-9 최초 후보는 새 공격 대응이 실재하더라도 결과가 고작 대기 1회 감소·동일 3라운드이며 후속 피해가 늘어난 안은 기각했습니다. 상부/하부마다 다른 목표를 넣더라도 장 원본과 비례, 대기 강제가 아닌 대응 선택이 먼저입니다.
- 그라데이션·밝은 윤곽과 구분될 조형, 광활한 원경과 실제 접촉/근경 따로, 더미 사방 연속성(의도된 공동은 그대로), 노드 최적화 순서와 1막 1·2장 벌크 기반 레퍼런스는 장별 승인 절차입니다. 지도 줌아웃, 접합 네 면, 실제 충돌 겹침, 표준 PC/M, 중간 페이즈를 분리해 보고합니다.
