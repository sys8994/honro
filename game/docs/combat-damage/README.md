# 전투 피해 편차 정책 (2026-10-23)

평균 공격 배율은 1.0이다. 기예 ID별 `damageVariance.ts`의 명시적 표가 유일한 편차 원본이다. 형·기·혼, 치명타, 거리/낙차/속력, 방어, 감쇠와 기존 성장 배율을 보존한다. HP 피해 계산 전 원 피해에 행동 계수를 한 번 곱하며, 확정 처형(A99)은 이 공격 피해로 기존 처형 조건을 판정한 뒤 기존 마무리 규칙을 유지한다.

## 분류 근거

- 정밀 활/관통/회기/선회·급소·절명과 절제된 단일 검격·검기·응수/사생, 직선 혼창은 ±5%.
- 산탄/연타/튕김/추적·곡사/철화, 이동 검격/공전, 정돈된 기파/파문/진목, 일반 혼령탄/부적/소환령은 ±10%.
- 호리병 폭발/연쇄 폭발/천뢰, 급강하 충격/파열 검압, 불안정한 통과·귀환·분열·귀결 혼행과 지박은 ±15%.
- 회복·지원·고정 비율 자원·명시적 자기희생 비용·강제 HP·환경 피해에는 편차를 붙이지 않는다. 피해로 산출하는 회기/먹귀 전달/밀침 충돌/살흔은 이미 결정된 실제 피해를 이용하므로 계수를 다시 곱하지 않는다.
- 적 전용/역사적 NPC 기예(`enemyOnly`, L 사본과 H 몬스터 기예 포함)는 보수적 ±10%. 짐승의 근접 행동과 아군 NPC 경비/척후의 직접 검격도 행동당 ±10%. 아군 도사/무당의 실제 기예는 해당 ID 규칙을 따른다.

## 행동·저장 계약

새 행동을 승인한 `Engine.fire`에서만 버퍼를 소비한다. 같은 산탄/광역 대상, 연속 시위, 분열/반사/후속 폭발, 함정/진목, 저주/지박, 소환 공격은 최초 행동 계수를 보존한다. 응수세의 지연 반격과 S13의 착지 뒤 검술도 처음 계수를 저장해 쓴다. 반향령은 소환 시 별도 편차를 겹치지 않고 따라 쏜 혼행의 계수를 받는다. 섭혼은 해당 부적의 계수를 제어 기간의 직접 공격에 전한다.

`damageSequence={version:1,seed,index}`는 기존 crit/proc `rng`와 독립이다. 전투 생성/로드 시 별도 고정 seed(기존 battle seed와 고정 salt의 hash)로 현재 청크 1024개를 미리 만든다. 균등 표본과 그 반대값을 함께 넣고 청크 전체를 섞어 청크별 평균을 정확히 1.0으로 유지한다. 버퍼는 런타임 WeakMap에만 있고 저장하지 않는다. 1024개를 소비하면 절대 청크 번호와 seed로 다음 청크를 한 번 생성하므로 같은 배열을 순환하지 않는다. 고정 seed이므로 같은 장의 새 시작과 같은 입력은 재현 가능하다. 저장은 3개 스칼라와 살아 있는 효과의 계수뿐이며 청크 수에 따라 커지지 않는다. `Math.random`은 추가하지 않았다.

예상 궤적은 읽기/복제 전투에서 계산하고 live index를 소비하지 않는다. 기예 시연은 별도 practice 전투를 사용한다. Continue/내보내기/가져오기/재실행은 저장된 index와 계수를 그대로 쓴다. 기존 체크포인트 재시도는 원래 전투 스냅샷과 함께 이 상태도 복구한다.

구 저장의 진행 중 투사체/연속 시위/검격/반격/설치물/저주/소환에는 계수를 추정하거나 다시 뽑지 않는다. 없는 계수는 해당 효과의 수명 동안 1.0이다. 시드 상태만 index 0으로 추가하며 다음 새 행동이 첫 안전 경계다. 기존 행동·자원·보상은 재작성하지 않는다. 분할 원정으로 가져가는 curse/earth 상태에도 결정된 계수를 보존한다. 현 스키마는 version/seed/index와 유효 계수 범위를 검증한다.

기예 상세의 수치는 평균이며 `피해 기준` 행에 행동당 ±범위를 표시한다. 환경·일반 지형 파괴/연쇄 장치의 강제 파괴값은 편차 대상이 아니다. 전투 유닛으로 등록된 공격 가능 목표는 일반 공격 계산을 따른다.

## 아군·동맹 오사격 30%

현재 동맹은 side0, `honroAlly`, `honroCivilian`, `objective` 및 그 소유 소환/섭혼 유닛이다. 소유권은 owner를 따라 재귀적으로 판정한다. 먹귀는 공격을 받아 전달하는 적성 껍질이므로 기존 예외(side1)를 유지한다. 중립 side2 전체를 동맹으로 간주하지 않는다.

새 공격은 `attackSide`에 발사 당시 진영을 저장하고 모든 후속/설치/지속 경로로 전한다. 발사자의 죽음·제거·섭혼/해제가 지연 공격의 진영을 바꾸지 않는다. 구 공격의 `attackSide` 부재만 기존 actor/owner 우선, 없는 발사자는 saved side/보고서 provenance 순으로 호환한다. 미상 출처를 아군으로 추정하지 않는다.

허용된 우발적 아군 공격은 치명·형기혼·방어·감쇠·상한을 적용한 **기존 정수 최종값 ×0.3**이다. 이후 같은 값으로 보호막을 소모하고 HP를 차감한다. 최소1도0.3으로 남으며 추가 반올림으로1이 되지 않는다. 실제 HP 차이에서 생기는 밀침 후속 피해에는 이미 감산된 표시를 전해 이중 적용을 막고, 반올림도 감산 전 척도로 한 번만 한다. 피해 보고서/보호막 집계는 실제 HP/보호막 변화이고 소수 첫째 자리까지 표시해0.3을0으로 숨기지 않는다.

기존 자동 공격 보호(아군 소환/반향/연속 시위/파편/자동 분열의 아군·중립 HP/상태/지형 면제)는 유지한다. 이 경로의 실제 오사격은 여전히0이다. 직접 조준한 근원탄, 허용된 반사/광역·진목/지속 효과와 발사자가 사라진 지연 폭발은 허용 여부 판정 뒤 30%를 적용한다. 장치의 후속 통 폭발에는 진영만 전하며 피해 편차를 새로 부여하지 않는다. 적→아군, 아군→적, 중립, 회복, 명시적 S02 체력 비용, 환경/스크립트 HP, 분혼의 실제 피해 분배, 먹귀의 실제 HP 전달은 별도 추가 감산 대상이 아니다. AI 예상 피해는 평균 공격과 같은30% 관계를 사용하며 난수 버퍼를 소비하지 않는다.
