# 1막 영체 피해 반응 조정

## 범위와 이유 (2026-10-13)

수비창의 형·기·혼은 합계 100%인 비율이 아니라 각 속성으로 **받는 피해의 감응도**다. 기본 평사의 공격 구성은 형96%/기4%이므로 기존 등불의 형18%/기110% 감응에서는 21.68%만 통했다. 1막에는 소단이 아직 합류하지 않아 물질 위주 설오·휘겸에게 과한 벌점이었다.

현행 8장은 초기 적37체 중 떠도는 혼4·등불5(그중 정예 등불1)를 포함한다. `EXISTENCE_PROFILES.md`의 과거 8장 영체0·일반적20은 당시 편성 기록이며 현재 수치가 아니다. 7장 수의귀2, 9·10장 떠도는 혼 각2도 이번 대상이다. 1–6장 최초 편성에는 대상 종족이 없으며 육체형 짐승·장승·상두꾼·빈 상여·적대 소단은 변경하지 않는다. 관련 종족이 1막 증원으로 생성돼도 같은 반응을 받는다.

| 1막 일반/정예 종족 | 형 이전→현재 | 기 | 혼 | 평사 전달 이전→현재 | 기파 전달 이전→현재 |
|---|---:|---:|---:|---:|---:|
| 떠도는 혼 | .20→.65 | 1.05 | 1.32 | 23.40%→66.60% | 98.20%→101.80% |
| 매듭진 수의귀 | .24→.72 | 1.05 | 1.28 | 27.24%→73.32% | 98.52%→102.36% |

화살에는 여전히 약27–33% 저항하고, 기와 혼이 더 잘 통한다. 수의와 등불의 물질 매개를 맨혼보다 조금 더 맞히기 쉽게 한다. 기·혼 감응을 내리지 않고 형 감응만 높여 담허의 기존 역할을 유지한다. 기본 기파의 증가폭은 3.60–4.16%p, 혼령탄은 변화 없다. 휘겸의 평참은 같은96/4 구성으로 설오와 같은 완화를 받는다. HP·갑옷·공격력·기예·AI·지형·개체/증원 수·퀘스트는 변경하지 않는다.

## 단일 적용 경로와 저장

`HonroAct1Roster.applyDefense`만 수치를 소유한다. 공통 Map compiler의 최종 생성, World 적 생성기(증원), StageRules의 캠페인 Continue 경계에서 같은 함수를 호출한다. Game/Stage View/Playtest는 같은 compiler와 피해 계산을 사용한다. 캠페인1–10장만 적용하며2·3막 및 연습장/사용자 custom 맵은 제외한다.

대상은 `side===1`, `ghost/shade/lantern` 기본 종족이며 보스·중간보스·최종보스·소환령과 명시된 `existenceDefense`는 제외한다. 처음 적용한 개체에 `existenceDefense`와 `honroAct1DefenseRevision:1`을 기록한다. 과거 저장에 필드가 없으면 Continue 시 기본값만 채우므로 진행 중 전투에도 반영된다. 현재 HP/최대HP·좌표·속도·행동·갑옷·상태·existenceShift·현형·목표·진행을 초기화하지 않는다. 이미 적용한 저장은 재적용하지 않고 사용자/디버그의 개별 방어 재정의도 덮어쓰지 않는다. 저장 스키마 증가는 없다.

## 검증과 한계

`npm run test:act1-defense`는 다음을 확인한다.

- 30장 전후 전체 유닛에서 새 방어 필드 이외 차이 없음, 초기/유한 증원 정의 불변
- 일반/정예 생성기, 보스 제외, 명시 재정의 및 상태 가감 보존
-2·3막·연습장·custom 맵 불변, Game/Workshop 동일 compiler 결과
- 실제 App Continue와 내보내기/가져오기3회에서 기존7–10장 피해 반응 적용,11/18/22장 불변, HP·좌표·속도·행동·상태 보존
- 정상 진입 레벨·랭크1·치명 없음에서 실제 `effective`/`hurt`/갑옷/정수 반올림을 사용한 모든 초기 적 단일 명중 비교

집중 검사 통과 시의 설오 기본 평사 반복 명중 수는1–6장14/24/41/42/78/80으로 불변,7장108→90,8장373→258,9장134→112,10장202→170이다. 체력 가중 감응도는7장.8892→.9380,8장.7762→.8609,9장.8886→.9262,10장.9123→.9459다. 기존 `existence-damage`와 `existence-variety`도 통과했다.

상세 표는 `_local/reports/act1-defense/workload.json`에 생성한다. 체력 가중 감응도와 반복 명중 수 합계는 적 체력의 상대적인 처리 부담 지표이며, 이동·사선·자원·적 행동을 포함한 실제 TTK/전투 완주가 아니다. 브라우저/정상 연속 플레이/Pages 검수와 전역 verify 결과는 통합 시 별도로 기록한다.

추가 검사: 기존 `tests/act1-existence-roster.mjs`는 `Spirit quota stage 8`에서 실패한다. 과거 일반 영체≤12.5% 가정과 현재8장 일반36체 중 영체9체(25%) 편성이 맞지 않는다. 이번30장 전후 검사에서 종족/개체 수가 불변임을 확인했으므로 이 작업의 감응도 변경으로 발생한 편성 차이는 아니다. 해당 역사 편성 테스트나 현재 배치를 이번 범위에서 바꾸지 않았다.
