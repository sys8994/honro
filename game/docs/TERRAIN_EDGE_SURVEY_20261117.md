## 기준선과 기존 후보의 구별

공개 코드 기준선은 e89242ee와 코드/에셋이 같은 master **7d238d20**이다. GitHub compare 결과 두 커밋 간 변경은 검수/SOP 문서2개뿐이다. 독립 검수 소스는 e89242ee와 전체 tree 동등 확인을 재사용했다. 혼재한 수정 후보의 조건부 분기와 각 장 관련 경로의 변경 여부를 따로 확인했다.

**2~10·12·14·15장의 기존 수정 후보는 별도 브랜치에 보존된 상태이며, 이 조사에서 master/Pages에 반영하지 않았다.** 후보에서 결함이 사라진 렌더를 공개판의 해결 결과로 바꾸어 쓰지 않는다. 공개 기준선에 이미 포함된 과거41장 등의 작업은 이 미배포 후보들과 별개다. 11·13·16장의 브랜치는 검사/기록용이며 해당 장의 미술 수정이 아니다.

21~50장은 이번 조사에서 새 수정 후보를 만들지 않았다. 17~20장 및1장 보충 조사도 코드·미술을 바꾸지 않았다.

## 방법과 한계

독립 Native Canvas에서 production project/compiler/Engine/renderer를 사용했다. 기본 화면비는 desktop1331×763, portrait390×696, landscape844×390, DPR1. 최대 줌아웃과 허용 극단 팬을 중심으로 보고 작은/의심 접점만 추가 확인했다. 1장은27뷰 보충,21~50장은 장별27뷰를 기본으로 했다. 앞선1~20장의 더 많은 접점·A/B 자료도 재사용했다. 각 보고서의 실제 범위를 따른다.

정적 렌더의 물리/상태 불변 확인은 실제 조작·파괴·수위·호송·퀘스트·저장 복원의 확인이 아니다. JPEG 증거는 시각 판정용이지 무손실1px/AA 계측 자료가 아니다. 공개 브라우저/실기기 입력, 연속 팬/줌 중 캐시 변화, 모든 작은 접점 및 동적 상태는 미확인 범위로 남는다.
