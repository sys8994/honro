# 지하 집하장 1차 제작 계약

25장은 설오·담허가 단절된 첫 석대를 축지진목으로 횡단한다. 27장은 같은 두 동행이 상부 석대→하부 하역대→봉인 창고의 세 단절부를 순서대로 건넌다. 두 인물의 직접 M09 사용을 확인하는 런타임과 연계 중이다. 일반 점프 길을 따로 놓지 않는다.

배경은 저문골에서 수거한 물품의 은폐 집하장이다. 무명사의 대종 주조소를 옮기는 설정이 아니다. 물품 묶음에는 숟가락·놋그릇·농기구·이름표가 같은 가족 번호로 묶이며 지상 희생자 명단과 대조한다. 최종 목적, 저편의 정체, 현묵의 현재 운명은 확정하지 않는다.

- 소스: `tools/map-forge/act3-hidden-waterworks.mjs`
- 임시 프로젝트 생성: `node tools/map-forge/act3-hidden-waterworks.mjs`
- 실제 공통 렌더러 캡처: `node --expose-gc tools/environment/capture-hidden-waterworks.mjs --project _local/reports/hidden-waterworks/project.json --stages 25,27 --out _local/reports/hidden-waterworks/review-v2`
- 현재 단계는 대표 지형·미술 초안이다. 활성 campaign은 아직 변경하지 않았다. 런타임 횡단·미션·브라우저 입력·일반 캠페인 완주는 별도 검증 대상이다.

## 인터페이스

`stage.design.act3.crossings[]`는 `id/from/fromZone/to/landing/checkpoint/markerId`를 담는다. fromZone과 landing은 `{left,right,y}`, 지점은 `{x,y}`다. landing은 석대 전체이며 출발 구간의 저장 지점은 안전면에 둔다. map compiler의 `honroMap.act3`로 전달한다. 25/27의 party는 archer/mage, 동시 행동 상한은2다. 각 목표는 단계별 한 줄이다.

## 2차 연결과 물리 예산

- 23장은 천장·지하 홍예 후벽을 제거하고 지상 하역장으로 읽히게 했다. 기존 호송길·운반인·층별 경비는 보존한다.
- 24장의 출발 연출 v2는 설오·담허 지하, 휘겸·소단 지상이다. 진행 중 v1 출발 연출은 별도 유지한다.
- 25: 같은 높이의 700 간격, 출발1960→도착2940.
- 26: 묘역 기록실과 지상 공방을 한 동선으로 합쳤다. 선조 기록과 주민 구조·주조량 대조를 유지하고 반복 기록함 방어는 없앴다.
- 27: 첫 상승200/간격700, 다음 하강400/간격950, 마지막 상승200/간격700. 원래 더 넓은 안은 기본 M09가 닿지 않아 폐기했다. 출발 구간 폭은270이며 최단 설치 실패도 재시도 대상이다.
- 28: 불길을 제어한 뒤 네 동행이 합류한다. 가족 번호 대조, 가문 청원과 탄압, 폐쇄 승인, 대도사 현장 학살, 특정 고위 관리의 사후 은폐 책임을 구별해 보존했다. 29·30장은 변경하지 않았다.

`node tests/hidden-waterworks-maps.mjs`는 영향 없는1~22·29~30의 정확한 보존, 재생성 멱등성, canonical 왕복, 실제 신체 접지, 목표 marker와26·28 열린 문 이후의 일반 이동을 검사한다. 이는 브라우저 입력·일반 완주나 난이도 검증을 대신하지 않는다. 대표 캡처 v4는 실제 공통 Scene이며 인공 구조의 규모와 기능을 나누는 방향으로 수정했다. 최종 미술 승인·런타임 연계 검수는 계속된다.

## 최종 재료 패스와 선택형 물 반사

봉인문은 임시 X 표식을 없애고 엇갈린 목판, 쇠경첩, 금줄, 작은 봉인지, 문턱 그림자로 바꿨다. 살림도구·천짐·항아리의 세 물품 실루엣을 쓴다. 석대 몸체를 가리던 불투명 물높이 면은 시각 검수에서 폐기했고 얇은 흔적만 남겼다.

`materials[].reflections`는 기존 공통 수면 패스 안에서만 쓰는 선택 입력이다. 수면의 기존 클립 안에 최대4개의 재사용 실루엣을 그리고 아래로 투명해진다. 지형·충돌·사격 면은 만들지 않으며 Scene.time과 reduced-motion 처리를 공유한다. 25·27의 물에만 저작했다. `node tests/water-reflection-opt-in.mjs`는 기존 물의0/1.2/31초 픽셀 완전동일, 수면밖 불변, 데이터 활성 범위를 검사한다. 이 검사가 미술 승인을 대신하지 않으므로 review-v7 실제 캡처도 확인한다.

## 통합 검수 수정

26/28의 실제 조립에서 원래 `addLocationDetail/refineStage` 장식 호출을 누락한 것은 제작 결함이었다. 원본의 그을린 문틀·공방 도구·실제 경사 어깨·풍경 묶음을 복원했다. 28에는 중앙 뜰의 낮은 보관채·돌담·서류함·소나무·탄 들보를 더했다. 26 수면은 경사 제방과 만나는 정확한 교점까지 채워 노출된 수직 물 가장자리를 없앴다.

이와 별도로 캡처 도구가 모든 canvas를1×1로 줄이는 과정에서 공용 원경 캐시까지 파괴해 다음 화면의 하늘이 단색으로 보이는 증거 결함이 있었다. 새 전용 캡처는 원경 decode를 확인하고 개별 Scene 캐시와 주 출력 canvas만 정리한다. 공용 원경/안개 캐시는 기존 bounded cache에 남겨 같은 프로세스에서 재사용하고 프로세스 종료로 회수한다. 이 결함을 실제 게임의 원경 누락으로 기록하지 않는다.

편성 생성기에는 새 명시적 plan version2를 추가했다. 초기/정예는25장7/2,26장10/3,27장8/3,28장11/3. 새25~28에는 방어 증원을 복사하지 않는다. 실제 몸 겹침과 시작 공간 검수에서28의 겹친 두 적을 분리하고 양쪽 동행의 출발 여백을 확보했다. 10장×5난이도 편성/정예/기본탄도·장별XP예산·저장된보상불중복 검사를 통과했다.

새26/28은 `hold` 또는 반복 고정구 공격 단계를 포함하지 않는다. 26은 조사문서→주민 구조→작업기록 대조,28은 양쪽 불길 제어→합류→청원서/승인문/은폐기록이다. 지하 튜토리얼의 버튼·수련 설명은 기예 도구카드와 도움말에 두고 대사는 돌면과 앞의 석대를 짚는 짧은 말로 다듬었다.
