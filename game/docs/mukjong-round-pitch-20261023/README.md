# 18장 묵종의 라운드 고조

기준 `cf9c1628231606320d568439f4e4399581833111`. 12장 지정 대사의 승인 B/rate1, HP 조건 제거, 묵종 v08·카드 UX·초상화를 보존한다. 원본 MP3와 전투/퀘스트/대사/턴 수는 변경하지 않았다. master/Pages는 부모 담당이다.

18장의 첫 조작 가능 프레임부터 잔울림을 시작한다. 개인 차례가 아닌 `b.round` 경계를 세고, 억제되지 않은 라운드2개마다 한 번 재생하며 반음1개씩 올린다. `rate=2^(min(5,floor(activeRounds/2))/12)`, 첫음은0반음/rate1, 최대5반음/rate1.334839854다. 상한 뒤에도2라운드 간격을 지키고 더 높아지지 않는다. 실제 종지기 의식도 같은 단계/버퍼를 쓴다. 같은 라운드는 먼저 처리한 잔울림/의식 한 번만 재생해 이중 타종을 막는다.

억제진 유지 미완료, 종지기 연결 중단(`keeperRitual.suppressed`), 하강 중에는 재생과 상승을 멈춘다. 억제 시작/종료 상태와 마지막 라운드·누적 활성 라운드를 저장하며, 풀릴 때 지난 라운드를 가산하지 않는다. `act2.silenced`는R1부터 끝까지 남는 구형 파동 차단 플래그이므로 장 전체를 영구 무음으로 만들지 않고 실제 유지 상태를 확인한다. 종지기 제압/사망/부재·목표 완료·전투 종료 후에는 멈춘다. 착지·회고·조건부 발언에 새 타종은 없다.

새 전투는0으로 초기화하고, Continue는 단계·간격·기준·억제·재생 슬롯/serial을 유지한다. 고조 도입 전 구 저장은 과거 발동을 추정하지 않으며 현재 라운드의 잔울림을 재생한 것으로 취급하고 이후부터 진행한다. 반복 UI·같은 serial·음소거 해제에 밀린 재생은 없다. 기존 단일 AudioBuffer/제한 재시도/비동기 준비를 유지한다. 새 rAF·타이머는 없고 기존 App.frame의 대사 갱신 뒤에서만 잔울림을 판단한다. mount의 음악 갱신에서 첫 소리를 소비하던 초기 초안 경계는 제거했다.

## 발동 경로와 현실적 길이

현재 초반 잔울림 예고·증원은 억제 응답/hold-silence에 묶여 있어 새 강타를 붙이지 않았다. bell-first는revision2에서 실행되지 않고, HP60% 보복은Short 경로에서 제외된다. 착지도 타종이 아니다. 따라서 부모가 승인한 최소 음향 연출인 주기적 잔울림을 채택했다.

기존 정상 입력1표본(keeper-ritual41a435f1)은R10 완료, 종지기R9~10에 실제 의식1회였다. 의식만 쓰면 고조가 들리지 않는다. 같은 표본의 기록된 목표/억제 상태를 재생하면 **R1 기본음, R1~3 억제 정지, R5 +1, R7 +2, R9 +3**으로 이어진다. 의식도 이 단계에 합류한다. 억제 시간을 강제로 더해R9 +4를 만들거나 전투를 늘리지 않았다. 이것은 사람 평균/새 정상 완주 측정이 아니다.
