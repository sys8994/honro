# 혼로 오프닝과 1~5막 스틸컷

## 의도와 보존 범위

신규 여정의 화면은 혼을 보내는 일상에서 실종자 수색과 연목 고갯길로 좁혀 간다. 오프닝은 5컷이다. 1~5막은 기존 가로·세로 스틸컷 한 장씩을 남기고 앞뒤에 새 컷 두 장을 더한 총 세 장으로 닫는다. 6막 최종 엔딩의 서술 자막, 어두운 여백, 장시간 미세 움직임, 페이드와 입력 흐름을 참고한다. 6막의 엔딩 내용·저장·임시 음악은 작업 범위가 아니다.

각 막의 1컷은 **그 막의 사건 회수**, 2컷은 **그 다음 길로 이어지는 사이 이야기**, 3컷은 **다음 막의 예고**다. 모든 자막은 짧고 차분한 3인칭 과거형으로 쓴다.

| 구간 | 컷 순서 |
|---|---|
| 오프닝 | 밤새 켜진 나루 등불 → 북쪽 산골 빈 마당 → 홍만을 찾는 나루의 단서 → 주막의 경고 → 설오가 들어선 황혼의 고개 |
| 1막 | 고목의 붉은 매듭(기존) → 동쪽 외문의 붉은 발자국 → 북쪽으로 이어지는 산길 |
| 2막 | 동굴 안 대종(기존) → 버드나무가 자란 나루 → 강 건너 읍성 |
| 3막 | 강변의 기록(기존) → 버려진 운송 나루 → 무너진 길을 돌아가는 장례길 |
| 4막 | 배가 닿은 포구(기존) → 도식이 짚은 능선 → 산을 가리키는 진목 표식 |
| 5막 | 끊어진 산줄기 아래 협곡 → 돌아보면 사라진 능선 → 닫힌 무명사 산문(기존) |

대사 원본은 `shared/campaign-stills/content.json`. 오프닝은 뒤에서 밝혀지는 홍만의 행방과 실종자의 수, 전투 사건을 미리 들추지 않는다. 2·3막 증언은 기존 앱이 현재 저장에서 확인한 문장만 사용하고, 추가 서술은 실제 경치와 여정 위주로 쓴다. 일부러 지금 확인하지 않은 단서를 소급해 주지 않는다.

## 신규 그림 제작 입력

6막의 포구 스틸 `shared/act6-ending-replan/stills/ending_still_04_land.webp`는 화풍만 참조했다. 빛바랜 채색과 먹빛 가장자리, 자연스러운 재질과 깊이, 조선풍 한국의 목조건물과 옷차림, 절제된 표정과 몸짓을 기준으로 삼았다. 포구의 인물이나 구도를 다른 컷에 복제하지 않는다. 하단 자막 영역은 명암 대비가 낮고 핵심 피사체가 없는 쪽으로 구도를 잡으며, 실제 글씨는 그림에 굽지 않는다. 한 장을 자르기만 하는 대신 가로 16:9와 세로 9:16을 각각 별도 구도로 생성하고 WebP로 준비한다.

장면별 프롬프트의 핵심: 오프닝 등불은 사람 없는 낮은 물가, 빈 산골은 재난·사망 묘사 없이 남겨진 생활 물건, 홍만 단서는 사람 없이 나룻배의 밧줄, 주막은 따뜻한 처마와 차가운 길, 마지막 고개는 뒷모습 설오와 활만 남긴다. 1막 외문에는 붉은 진흙 자국만, 북쪽 길에는 작은 방울과 느슨한 붉은 실을 둔다. 2막 출구는 늙은 버드나무, 읍성은 읽히지 않는 봉인 인상과 먼 성벽, 3막은 새 사건을 그리지 않고 닳은 나루와 멀리 이어진 우회로, 4막은 포구 건너 접힌 능선과 닳은 나무 표식, 5막은 길이 사라지는 빈 자주빛 안개가 주인공이다.

## 연결과 검수

`shared/campaign-stills/build.mjs`에서 컷 개수와 순서, 가로·세로 그림의 크기를 검사한다. `shared/runtime/campaign-stills.js`는 6막이 쓰는 재생기와 CSS를 공용으로 사용한다. 장별 승리·보상·이어가기·다음 막 진입은 기존 소유자가 처리한다. 여정첩 다시보기와 디버그 미리보기는 진행 저장을 쓰지 않는다. 신규 오프닝은 기존 첫 주막 장면과 중복 홍만 나레이션만 대신한다. 1막 1장 실제 대사와 튜토리얼, 이전에 시작된 저장은 기존 경로를 유지한다.

검수 진입점은 `node --test tests/campaign-stills.mjs`와 빌드 후 `python tests/campaign-stills-browser.py`다. 테스트 입력은 구간 진입과 완료·미리보기의 저장 계약을 확인하는 독립 저장이며, 캠페인 전투 수동 완주나 플레이 난이도 검수와 구분한다.

통합 빌드에서 실제 Chromium으로 신규 여정과 회전, 1~5막 15컷의 표시와 디코딩, 디버그 복귀, 정상 완료의 진행 위치 복원, 여정첩 다시보기의 비저장 동작을 확인했다. 기존 6막의 별도 미리보기도 그대로 열린다. 신규 30개 그림의 전체 전송량은 가로 약 3.5 MB, 세로 약 3.3 MB이며 각 장면을 열기 전에는 해당 시퀀스 그림을 요청하지 않는다.
