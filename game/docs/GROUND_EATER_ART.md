# 먹귀 접지·포획 시각 표현

기존 귀면과 넓은 먹빛 수의를 유지하고, 수의 아래 짧은 두 발을 추가한다. 전신 idle 확대로 발이 들리는 동작은 사용하지 않는다. 입 안쪽의 비대칭 균열과 치아가 `eaterSwallow`의 0.9초 동안 세로로 열리고 닫히며, 얼굴과 수의는 반대 방향으로 압축된다.

- 엔진의 h/r 성장에만 비례한다. 그래픽에서 추가 성장 배율을 곱하지 않는다. 현재 엔진의 5단계 상한(1.7배)과 일치한다.
- 포획 수가 있을 때 입 안 혼빛은 최대 3개로 제한한다. 포획 직후 최대 6개의 시각 잔상이 원래 위치에서 입으로 수축하며 들어간다. 잔상에는 HP·상태표시가 없고 엔진 상태를 바꾸지 않는다. 포획된 유닛과 HP·상태표시는 `eaterCapturedBy`가 있는 동안 렌더하지 않는다.
- 상시 투사체 유인 원은 제거한다. 삼키는 동안 짧은 안쪽 흐름만 그린다. 범위 안내가 아니므로 실제 포획반경을 나타내지 않는다.
- `fx/eaterRelease`는 0.7초의 벌어지는 먹빛 고리와 방사 흐름을 표시한다. HP0·시간 만료 모두 같은 엔진 이벤트를 사용한다.
- 기존 hit clip을 보존하여 충격 때 얼굴·몸이 기울어진다. 이동·넉백 좌표는 엔진이 담당한다.

검사: `node tests/ground-eater-native-art.mjs`. 실제 production Scene/Native Canvas에서 빈 먹귀, 1/10 포획, 삼키기 전후, 좌우, 충격, 390px 세로화면·0.4배 줌, 방출 9개 프레임과 렌더 순수성을 확인한다. 결과는 `_local/reports/ground-eater-native/`에 쓴다. 재구성 상태 시각 검사이며 실제 엔진 포획 수명주기나 브라우저 조작 검수를 대신하지 않는다.
