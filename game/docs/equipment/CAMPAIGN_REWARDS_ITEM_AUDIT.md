# 혼로 장비 52종 획득·효과 대조

기준은 최신 작업 시작 시점 master `ca4b4464c`다. 원본 기획표의 예약 상태와 공개 빌드의 실제 경로를 따로 확인했다. 아래의 장 번호는 막에서 보이는 장 번호 기준이다. 43·48장은 각각 5막 3·8장이다.

## 기준판 확인

- 데이터는 장비 52종, 보상 사건 36개, 회차 단위 1택 선택 12개를 정의한다. 효과 ID 26개 가운데 25개가 고유 동작을 사용하고, 1개는 현재 수치 보정만 적용한다. 효과 ID가 없는 26개는 기초 스탯 옵션이 정상 적용되며 그중 전용 16개는 특정 기예의 피해나 비용도 보정한다. 고유 동작의 일반 획득과 실제 전투 구현 여부는 별도다.
- 1~4막 39종은 공식 획득에 연결되어 있다. 4막은 일반 클리어와 별개로 동일 회차·공식 배틀·해당 사건의 승선/도달/전달/정예/구조 근거를 확인한다. 2막 2장의 원혼 파동과 5장의 수문도 선택 행동 근거를 요구한다. 조건 미충족과 선택하지 않은 대안은 정상적인 제외다.
- 5막 3종은 공개 빌드의 실제 장과 데이터 사건이 존재했으나, 기존 `publicEvent`의 허용 범위와 `collect`의 취득 사건에 빠져 있었다. 기준판 소스를 Node VM에서 실행해 4·5막 공개 플래그, 기존 클리어와 완료 배틀을 모두 주어도 43·48장 사건이 원장에 생기지 않는 것을 확인했다. 6막 10종은 5개 예약 사건이며 현재 미획득 상태가 의도되어 있다.
- 첫 고유 장비의 기존 장은 소단 2막 9장, 설오 3막 2장, 휘겸 3막 4장, 공용 3막 6장, 담허 3막 9장이다. 개인 고유 16개는 모두 특정 기예와 묶인다. 특히 반향령·반탄파·급락시를 찍지 않았을 때 장비 자체의 경로가 열려도 고유 동작은 발동하지 않는다.
- 기본 스탯, 기예 수치 보정, 사건 원장과 고유 동작을 실제 코드에서 대조했다. 6개 개인 T2 옵션에 가벼운 고유 동작을 입혔다. 기존 아이템 ID·소유·장착·선택 원장을 사용한다. 같은 선택에서 남은 대안은 다시 지급하지 않는다. 3막 문서고·가문 문장·현묵 잔영이 등장할 때 주던 T3 보상은 원래 장에 둔다. 고개깃 활장식의 감속은 고저차와 한 번의 직접 사격을 요구하며 보스·목표물을 제외한다.

5막 3장의 무구 백의는 첫 공식 클리어에서 고정 지급한다. 5막 8장은 같은 조건에서 담허 전용의 미결정 2택1을 등록한다. 기존 공식 클리어 자료도 같은 사건을 한 번만 정산한다. 이미 선택된 항목은 그대로 이어간다. 43·48장 뒤 기존 휴식터를 거쳐 선택·장착할 수 있다. 다른 5막 직행, 기존 진행 중 전투와 장착 상태는 보존한다. 정상 경로에 연결된 장비는 **39→42종**, 한 회차 최대 소유 수는 **29→31개**다.
