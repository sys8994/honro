## 상세 검토

### U01 · 급락 뒤 낮은 튀김 · 추천

고개깃 활장식 / 급락시

- 효과: 급락시가 지형에 닿으면 낮은 수평 화살로 한 번만 튀긴다.
- 플레이 선택: 고지 낙하 사격으로 엄폐 뒤의 낮은 적을 노린다.
- 대가·상한: 튕김 피해는 원본의35% 이내, 낙차 보너스 재계산 없음. 적당1회, 목재 관통 추가 없음.
- 필요 구현: engine.ts 지형 명중 분기 + projectile 1회 플래그
- 검수 위험: 반사 무한루프·상부 천장·같은 적 재적중·재개 시 플래그 보존

### U02 · 막힌 관통의 끝 · 후보

송곳눈 활장식 / 관통시

- 효과: 관통 횟수를 모두 쓴 직후 남은 화살을 작은 원형 압력으로 바꾼다.
- 플레이 선택: 먼 적을 직접 겨누기보다 앞줄을 관통해 끝점을 고른다.
- 대가·상한: 추가탄 없음. 마지막 직격과 끝 압력의 합을 원래 한 번 피해 이내로 분할. 보스 중복 금지.
- 필요 구현: engine.ts pierce 잔량 종료 + 기존 radial hit 판정 재사용
- 검수 위험: 마지막 적과 주변 적의 이중 피해·사망 후 재발동·벽 너머 피해

### U03 · 마른 숨의 회수 · 추천

잔숨 화살통 / 회기시

- 효과: 시전 직전 기력이25% 이하면 회기시의 HP 회수분을 포기하고 기력 회수로 돌린다.
- 플레이 선택: 부상 중에도 다음 기예를 이어 갈지, 체력 회수를 남길지 자원 상태로 갈린다.
- 대가·상한: 기존 기력18%/사격 상한 유지. 실제 적 피해만 원천, 과회복·사망자 제외.
- 필요 구현: skillMechanics.ts recordRedesignDamage의 A06 회수 + cast 시점 상태 고정
- 검수 위험: 다단 관통 합산·동일 사격 상한·회복 기여도 자기 회수 처리

### U04 · 벽에 걸린 격퇴 · 후보

멎은줄 화살통 / 격퇴시

- 효과: 격퇴된 첫 적이 가까운 벽에 막히면 추가 연쇄 충돌을 포기하고 짧은 감속을 건다.
- 플레이 선택: 적 뒤의 벽을 사격 자원으로 삼아 길목을 묶는다.
- 대가·상한: 감속1턴, 같은 사격1회. 보스에는 감속 면역 정책 유지. 추가 HP 피해 없음.
- 필요 구현: engine.ts shove/terrain 접촉 + slowed 상태
- 검수 위험: 벽·발판 구분·이미 감속된 적·밀침 정산 귀속

### U05 · 늦게 여는 화호 · 추천

절수 호리병 / 화호

- 효과: 화호가 첫 지형 접촉에 한 번 튄 뒤 재입력으로 열린다.
- 플레이 선택: 직선 착탄 대신 낮은 턱 뒤에서 불꽃을 펼친다.
- 대가·상한: 기존 파편 수/적당 상한 유지, 최대 수명 연장 없음. 첫 적 직격은 즉시 폭발.
- 필요 구현: skillMechanics.ts redesignImpact/gourdBurst + 기존 M02 재입력/fuse 흐름
- 검수 위험: 입력 지연·시간 초과 폭발·재접속 중 fuse·파편 중복

### U06 · 돌려 펴는 원호 · 추천

원륜 지팡이장식 / 원호파

- 효과: 지형에 부딪힌 원호파의 부채꼴을 진행 방향 반대쪽으로 펼친다.
- 플레이 선택: 벽을 맞춰 뒤쫓는 적을 쓸어 담는 사선을 만든다.
- 대가·상한: 지형 접촉일 때만. 기존 반경/각도/총 타격 수 유지, 적 직격은 원래 방향.
- 필요 구현: skillMechanics.ts redesignImpact/skillGeometry + mageGeometry.ts 원호 치수
- 검수 위험: 방향 벡터·지형 밖 생성·같은 적 교차 중복·시연 일치

### U07 · 홀로 돌아오는 파문 · 후보

장정 지팡이매듭 / 반탄파

- 효과: 반탄파의 분열을 없애고 한 발의 반사 한도를 늘린다.
- 플레이 선택: 넓게 퍼뜨리는 대신 좁은 통로의 한 사선을 끝까지 이용한다.
- 대가·상한: 총 수명/이동거리 유지, 반사마다 기존 감쇠 유지. 반사2회 추가가 검토 시작점.
- 필요 구현: skillMechanics.ts redesignImpact의 waveBounce 세대/분열 분기
- 검수 위험: 분열 자탄 예외·벽 끼임·영구 반사·저장된 세대 호환

### U08 · 서리만 남기는 병 · 추천

맑은숨 호리병 / 빙호

- 효과: 빙호를 재입력으로 열면 파편을 포기하고 작은 서리 띠를 남긴다.
- 플레이 선택: 맑은숨 호리병을 진목 회복 보정에서 호리병의 봉인 개방·길목 제어로 옮긴다.
- 대가·상한: 직접 파편 피해 없음, 띠1개·1턴·적당 감속1회. 기존 감속 상한 유지.
- 필요 구현: skillMechanics.ts detonateIceGourd/gourdBurst + fields 감속 영역
- 검수 위험: 회생진목 M10과 완전 분리·비행 중 저장·감속 중첩·필드 소유자

### U09 · 한 점의 천뢰 · 후보

좁은벼락 호리병 / 천뢰호

- 효과: 범위 내 각 적에게 나누던 낙뢰를 조준점 가까운 한 적에게만 모은다.
- 플레이 선택: 무리 청소를 버리고 특정 위협을 끊는다.
- 대가·상한: 최대2번, 합산 예산은 현행2대상분 이내. 다른 적 피해0, 상부 차폐 유지.
- 필요 구현: skillMechanics.ts gourdBurst/gourdSky + lightningGeometry.ts 차폐
- 검수 위험: 동률 대상 안정성·보스 다중 hit 상한·상부 지형·재로드 재선정 금지

### U10 · 낮게 흐르는 검기 · 추천

먼칼 검집끈 / 월영참

- 효과: 월영참 본체가 첫 바닥 접촉에 소멸하지 않고 짧게 지면을 따라간다.
- 플레이 선택: 낮은 위치에서 전방을 훑되 공중 적 대응을 포기한다.
- 대가·상한: 원래 수명 안에서만, 큰 턱에서 종료. 현재 S09 단일 본체의 적당 hit 제한 유지. 레거시 twinCrescent는 대상에서 제외.
- 필요 구현: warriorMechanics.ts stepWarrior/bladeMoon 접지 투영 + locomotion.ts 지면 질의
- 검수 위험: 고정 쌍월 본체 예외·벼랑·자탄/섭혼 전파 금지·벽 통과

### U11 · 거리를 남긴 도약참 · 후보

가벼운 칼끈 / 도약참

- 효과: 도약참의 타격 후 남은 이동력을 지불해 짧게 뒤로 착지한다.
- 플레이 선택: 적 안쪽에 머무는 대신 다음 사격선을 비운다.
- 대가·상한: 기력·HP 무료 회복 없음. 이동력 부족이면 원래 착지. 벽/벼랑 안전 경로만 허용.
- 필요 구현: engine.ts warriorLeap 착지 + 기존 moveLeft/grounded
- 검수 위험: 착지 중복·이동 부채·저장 후 공중 상태·호송 지형 우회

### U12 · 기력으로 잇는 사생 · 후보

침골 손목감개 / 사생참

- 효과: 사생참의 HP 지출 일부를 기력으로 대신 치른다.
- 플레이 선택: 체력의 위험을 남겨 두면서 기예 연속 사용과 생존 사이를 고른다.
- 대가·상한: 필수 HP 지출 절반은 남김. 기력 부족 시 원래 규칙, HP1 미만 불가. 위력은 실제 지출 HP만 기준.
- 필요 구현: engine.ts lifeSlash 비용 확정 + manaCost 지불 영수증
- 검수 위험: 무료 피해 전환·동시 자원 부족·과거 snapshot·비용 기여도

### U13 · 물러서는 응수 · 추천

검세 손목감개 / 응수세

- 효과: 응수의 첫 반격은 피해를 절반 남기고, 적을 짧게 밀며 휘겸이 한 몸길이 안에서 뒤로 물러선다. 추가 이동력은 쓰지 않는다.
- 플레이 선택: 받아내고 근접 마무리할지, 다음 동행 사선을 열지 고른다.
- 대가·상한: S08의 기존 행동·기력 비용은 유지. 특수 응수는 턴당1회, 해당 반격 피해50% 포기. 지상 안전 경로가 없으면 밀침·후퇴 전환 없이 원래 반격. 보스 밀침 면역 유지.
- 필요 구현: warriorMechanics.ts stepMelee의 martialGuard.counter/strike + engine.ts 피격 귀속 + walkTerrain 안전 경로
- 검수 위험: 안전 경로 검사 뒤 반격/이동을 한 번에 확정. 보스에게도 자기 후퇴는 유효한지 확인. 다단 피격 중복·상호 반격·낙사·기본 방호 소실 금지.

**선택 매력 재검토**

- 판단: 대가를 하나 덜어내는 수정안은 추천 유지. 현행 게임에는 적용하지 않음.
