## 상세

### U01 · 적용

급락시가 바닥에서 낮게 한 번 튕깁니다.

- 대상: 급락시
- 선택: 고지 낙하 사격으로 엄폐 뒤의 낮은 적을 노린다.
- 대가/상한: 튕김 위력65% · 남은 사거리 안 최대600 · 재적중 없음
- 구현: skillMechanics.redesignImpact / trajectoryMultiplier · equipmentCombat 여행 거리 표지
- 위험: 반사 무한루프·상부 천장·같은 적 재적중·재개 시 플래그 보존
- 판단: 사용자가 확정한 장점·작은 대가·명확한 단발 상한을 적용.

- 위험: 마지막 적과 주변 적의 이중 피해·사망 후 재발동·벽 너머 피해

- 대가/상한: 시전 기력40% 이하 · 한 사격 기력25% 상한
- 구현: skillMechanics.recordRedesignDamage · shotDamage 회수 상한
- 위험: 다단 관통 합산·동일 사격 상한·회복 기여도 자기 회수 처리
- 판단: 사용자가 확정한 장점·작은 대가·명확한 단발 상한을 적용.

### U05 · 이번 미채택

화호가 첫 지형 접촉에 한 번 튄 뒤 재입력으로 열린다.

- 대상: 화호
- 선택: 직선 착탄 대신 낮은 턱 뒤에서 불꽃을 펼친다.
- 대가/상한: 기존 파편 수/적당 상한 유지, 최대 수명 연장 없음. 첫 적 직격은 즉시 폭발.
- 구현: skillMechanics.ts redesignImpact/gourdBurst + 기존 M02 재입력/fuse 흐름
- 위험: 입력 지연·시간 초과 폭발·재접속 중 fuse·파편 중복
- 판단: 동일 슬롯 경합·소품 개념·구현 위험을 고려해 이번 채택에서 제외. 기존 후보를 숨기거나 적용 완료로 표시하지 않는다.

### U12 · 적용

사생참의 체력 비용 절반을 기력으로 대신 냅니다.

- 대상: 사생참
- 선택: 체력의 위험을 남겨 두면서 기예 연속 사용과 생존 사이를 고른다.

- 구현: startWarriorCast 사생참 비용 분리 · 원래 lifeCost 위력 유지
- 위험: 무료 피해 전환·동시 자원 부족·과거 snapshot·비용 기여도
- 판단: 실제 장착·만피·1경지 기준 대납 계수0.5는25~40레벨에서 총 기력77~78%를 써 과도했다. 대체HP의25%를 기력으로 내도록 조정하여 총 소모45~47%로 낮췄다. 실제 현재HP가 낮으면 비용도 줄고 기력이 모자라면 원래HP 비용으로 돌아간다.

- 구현: tickWarrior 응수세 · gearGroundPath / gearMove
- 위험: 안전 경로 검사 뒤 반격/이동을 한 번에 확정. 보스에게도 자기 후퇴는 유효한지 확인. 다단 피격 중복·상호 반격·낙사·기본 방호 소실 금지.
- 판단: 사용자가 확정한 장점·작은 대가·명확한 단발 상한을 적용.

- 장점이 실제 전술 선택을 바꾸도록 수정하여 적용.
- 공격 희생과 추가 이동력 비용을 제거했다. 원래 반격100%·방호와 안전한 위치 변경을 함께 얻으며 주기당1회로 제한한다.

- 판단: 동일 슬롯 경합·소품 개념·구현 위험을 고려해 이번 채택에서 제외. 기존 후보를 숨기거나 적용 완료로 표시하지 않는다.
