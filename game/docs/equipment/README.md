# 혼로 장비 52개 최종 설계

현재 실행 효과와 설정은 [장비52 검토](equipment_review_20261028.html), 실제 채택/제외는 [고유능력 행 목록](unique_candidates_20261028.html)을 따른다. 아래 v03 문서는 최초 설계·획득 인계 원본이며 이후 전술 효과와 저티어 옵션 대체를 반영한 현행 수치표가 아니다.

기존 56개 카탈로그의 개정안이다. 전용 32개와 공용 20개이며, 기본 지급 4개도 포함한다. 전용 1슬롯 + 공용 1슬롯을 쓰고 주무기는 바꾸지 않는다.

## 획득과 구현 범위

고정 24개와 선택 사건 12개로 한 회차 최대 36/52개를 얻는다. 미선택 16개는 같은 회차에 다시 지급하지 않는다. 선택 전 모든 대안을 비교하며, 미결정 선택과 확정 기록을 저장한다.

공개 1–3막에 연결할 정의는 31개(회차 최대 23개)다. 4막 잠금 8개를 더하면 1–4막 39개(최대 29개)이며, 5–6막 13개는 비활성 예약이다. 31·35·36장 미리보기를 정식 4막 공개로 취급하지 않는다.

이 묶음은 최종 설계와 구현 인계다. 런타임 장비 기능·보상 사건·아이콘이 구현됐다는 보고가 아니다. 실제 브라우저 렌더링은 검증하지 않았고, 구조·문법·필터 로직과 20,736개 선택 조합을 확인했다. 문서만 게시하므로 게임 빌드·배포 변경은 포함하지 않는다.

현재 코드·저장·검증·발행 상태는 [구현 기록](implementation_status.md)을 따른다. 위 데이터/설계 검증 문서는 설계 확정 당시의 기록이다.
