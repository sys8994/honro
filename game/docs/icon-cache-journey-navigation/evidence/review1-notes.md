# 집중 픽셀 검수 1 — 구조/지리 (2026-10-22)

실제 Chromium JPG `review1-fixed-390x844`, 세 막 overview, `review1-zoom9-390x844`를 직접 열었다. 상단 52px/하단 64px, 번호 옆 라벨, 세 막 원본 구도와 전반 진행선 구조를 확인했다. 1막 물길은 다리/관문을 경유하며 아랫마당→윗마당은 계단 쪽을 따른다. 2막 입구/지하 사찰/한 종/별도 출구, 3막 지상26과 지하25·27의 순서 연결을 점검했다.

발견/후속: 완료 경로 점선 대비가 그림 위에서 너무 낮아 다음 검수 전 명도를 보강한다. 18→19가 한 종을 지나가는 표현과 19→20의 복귀는 몸체를 가로지르지 않고 오른쪽 상부 통로로 돌아가는 제어점으로 교정한다. 현재 위치의 추가 문구는 핀/라벨 혼잡을 줄이기 위해 제거하고 aria-current를 유지한다. 키보드/핀치 테스트 도중 임의 pointer ID로 setPointerCapture를 호출한 초기 검사 실패는 검사 입력 오류였으며, Chromium CDP 실제 touch 이벤트로 교체해 통과했다. 해당 오류를 게임 결함으로 분류하지 않는다.
