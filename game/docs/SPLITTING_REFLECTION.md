# 반탄파의 반사·분열 계약

2026-10-13 개정. 과거 2~7회 단일탄 반사·반사마다 +8% 증폭·전체 반사 예상선 명세를 새 발사에 한해 대체한다.

- 최초 탄은 모든 SP에서 하나다.
- SP1~8의 반사 분열 순서: `[1]`, `[2]`, `[2,1]`, `[2,2]`, `[2,2,1]`, `[2,2,2]`, `[2,2,2]`, `[2,2,3]`.
- 최대 동시 파동: 1, 2, 2, 4, 4, 8, 8, 12. 부모를 한 후손으로 재사용하므로 한 발사의 전체 고유 ID 수도 이 상한 이내다. 각 분열은 세대를 정확히 하나 소비한다. x1도 한 번 반사한다.
- 지형에만 반사/분열한다. 본체 명중은 피해 후 해당 탄을 제거한다. 마지막 세대의 다음 지형 접촉은 분열·추가 피해 없이 소멸한다. 최초 발사의 age를 모든 후손이 공유하므로 기존 12초 수명과 월드 경계 제거가 유지된다.
- 정반사 속도의 84%를 보존하는 기존 반동에 대해 2개는 ±9°, 3개는 -9°/0°/+9°다. 스치는 입사는 표면 바깥 방향 각도의 70% 이내로 대칭 폭을 좁혀 후손이 즉시 같은 면 안으로 진행하지 않게 한다.
- 반사마다 각 후손 피해는 부모의 82%다. 세대별 100/82/67.24/55.1368%. 원래 46 기본 피해, 경지별 기존 피해·기력 성장 공식은 유지한다. SP7은 SP6과 탄수·각도가 같고 기존 피해 성장 및 소비 감소로 가치가 증가한다.
- 예상선은 복제 전투에서 실제 `stepProjectile`을 재생한다. 첫 반사와 그때 나온 모든 후손의 다음 충돌까지만 보인다. 다음 반사/분열은 그리지 않는다. 원본 전투, RNG, HP, 지형은 바뀌지 않는다.
- 최초 조준탄은 기존 직접 조준 공격 규칙을 유지한다. 반사 후손은 자동 파생 공격으로 분류하여 기존 중앙 아군·중립 보호 규칙을 적용한다. owner/shot/기여도 원천은 보존한다.
- 새 발사만 `reflectionVersion:1`을 저장한다. 필드가 없는 진행 중 옛 탄은 기존 반사 횟수와 증폭으로 끝나므로 Continue에서 갑자기 분열하지 않는다. 저장 형식의 전체 revision을 올려 기예나 진행을 초기화하지 않는다.

## 검증

- `npm run test:splitting-reflection`: 전 SP 표, 세대별 피해, 출사각 대칭/접선 입사, 본체 소멸, 최초 피해, 자동 아군 보호, 한발 전체 lineage 상한, 30/60/120 FPS, 실제 충돌과 예상선 끝점, 저장 검증 및 실제 App Continue·3회 export/import.
- `node tests/skill-redesign.mjs`, `node tests/projectile-platforms.mjs`: 기존 기예와 one-way 발판 회귀.
- `npm run capture:splitting-reflection`: 실제 Production Scene/Native Canvas의 SP1/8 예상선 및 세대별 탄. `_local/reports/splitting-reflection/art/`에 저장하며 브라우저 검증을 대신하지 않는다.
- 수학적 총 탄 피해는 실전 기대 피해가 아니다. 후반 세대는 앞 세대가 적에게 먼저 명중하지 않고 다음 지형까지 살아남아야 하며, 분산·감속된 후손이 적을 맞혀야 한다. 독립 수치 검수는 이 조건을 민감도 시나리오로 구분한다.

전체 verify와 공개 Pages의 최종 검수는 병렬 기능 통합 트리에서 별도로 수행한다.
