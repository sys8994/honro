# 앞선 지형 후보의 실제 Chrome 제한 대조

기준 공개 소스7d238d20과 지형 결합 코드80fc236d(후속 문서dc56b1b5)를 비교한다. 2~10·12·14·15 및21·22·28·29·30 후보는 이미 결합 기준에 포함되어 있다. 기존 후보 보존은 최종 합격과 다르며, 특히 Native 증거를 Chrome 증거로 바꾸어 부르지 않는다.

범위는 렌더 합성/등록 변경 영향이 큰3/7,12/15,21/22,28/30의 두 접합/극단 화면씩이다. 원본/master와 후보를 별도 임시 worktree에서 같은 독립 fixture로 컴파일한다. 잠금 dependency 파일이 정확히 같을 때만 설치 패키지를 공유한다. synthetic 초기 상태·고정 seed/시계이며 localStorage/sessionStorage/indexedDB 접근을 실패로 처리한다. 사용자의 공개 전투·브라우저 세션은 접근하지 않는다.

각 화면은 이미지 로딩과4프레임 정착을 확인하고 전체 전투 JSON 불변·physics·카메라 일치 및 실제후보효과를 검사한다. 최종 판단은 PNG 직접 관찰로 한다. 15장 상단 원본 암맥 끝의 미해결 항목은 수정한 것으로 세지 않는다. 동적 이벤트, 최대줌 전체위치, 공개 UI 입력, 실기기 또는 게임플레이 정량 합격은 이검사에 포함하지 않는다.

장별 미검수와 기존 Native 근거는 ACT1/ACT2_EDGE_JOIN_CANDIDATE_INDEX_20261117.md 및 STAGE*_EDGE_JOIN_STATUS.md에 남아 있다. 1/11/13/16~20/24/25/27 등 기존 무수정 장을 새로운 변경완료로 계산하지 않는다. 기존 관련 소스identity와실제저장roundtrip/inline규칙 회귀도 한 작업에서 재실행한다. 기존 table가정실패를 숨기거나 저장codec을바꾸지 않는다.

이번 브랜치는 테스트/기록만 추가하며 생산 코드·미술·사용자 저장·master/Pages는 변경하지 않는다. CI 결과와 직접 시각 검수는 후속으로 기록한다.
