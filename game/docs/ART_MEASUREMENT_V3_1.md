# 미술 측정 v3.1 · 직선 비율의 측정 범위 수정

2026-10-30. 20% 목표 / 30% 상한은 변경하지 않는다. 기존 v3 결과는 삭제하거나 새 정의의 결과로 바꿔 적지 않는다.

## 필수 정량 판정
- 단위: 스테이지 전체에서 고유한 자연 보행선의 길이 가중 직선 비율. 같은 선을 여러 카메라에서 중복 집계하지 않는다.
- 척도: 참조 줌 0.7 CSS/world에 고정한 동일 물리 구간. 1 CSS px 재표본, RDP 3 CSS px, chord 오차2 CSS px, 방향편차10°, 연속길이80 CSS px 정의를 참조 좌표로 환산해 사용한다.
- 분모: 대상 고유 자연 윤곽의 전체 실제 길이. 화면 잘림·배경 크기·불도달 구간 추가로 바꾸지 않는다. 재질별 사전 등록된 목재/인공물 예외 외에 자연 평면을 통째 제외하지 않는다.
- 보행 상면, 동굴 천장, 지형 몸체의 자연 외곽은 별도 집계한다. 서로 평균내어 한 부위의 단순함을 숨기지 않는다.
- 목표는20% 미만, 필수 상한은30% 미만. 같은 원본으로 재현 가능해야 한다.

## 참고 경고와 필수 시각 판정
- 개별 카메라 crop과 최소/정상/최대줌의 비율은 참고 경고다. 전체 판정의 분모로 사용하지 않는다.
- 국소 화면의 어색한 직선·큰 미완성 여백·반복 형상·사선 가림은 별도 **필수 시각 검수**에서 탈락시킬 수 있다. 전체 평균 통과가 면책 사유가 아니다.
- 확대 시 형태 손상, 접지 오차, 틈, 작은 중요 부분 보존 검사는 기존처럼 모든 지정 줌에서 필수다.
- 특정80px 창에만 맞춘 잔물결·미세 지터·동일 facet 반복은 금지한다. 독립된 시각 검수 후 정량 결과를 본다.

## 수정 근거와 이전 결과
- 동일 단일 암반의 두 전술 평면은 전체top654.64 reference CSS에서27.65%, mobile crop417.99에서43.36%였다. 형상은 같은데 crop 분모가 달라진 결과다.
- 고정 물리창으로 환산하면 같은 윤곽의 비율이 줌 변화에 대해 수치오차 수준으로 불변이다. 원 CSS 창을 그대로 확대 화면에 적용하면 같은 큰 곡선을 더 짧게 관찰해 직선으로 판정한다.
- 새 전체 판정에서도 기존31 v1은95.36%, 큰곡률 v3은88.51%, 단일facet만바꾼 v3은85.52%로 모두 실패했다. 이번 수정으로 기존 후보를 통과시킨 것이 아니다.
- 반복 물결 v2는 일부 수치 개선과 물리 연결 통과에도 시각 기각했다. 기각 상태를 유지한다.
