# 혼로 지형 제작·최적화·검수 SOP

2026-11-20 KST. 현재 적용: 기존 1~5막. 6막 무명사 시안은 보류. 이 문서는 제작과 지형 검수 지침이며, 특정 장이 이미 개선됐다는 보고서가 아니다.

## 1. 돌아갈 방식과 기준

**승인 기획과 지형 가이드 → 새 정측면 이미지 시안 → 원경 분리 → Inkscape 의미 부품별 벡터화/정리 → 정밀 최적화 → 운영과 동일한 렌더로 수정·재검수.** 맵에디터에서 처음부터 작도하도록 의무화한 실험 방식은 폐기한다. 맵에디터는 실제 배치, 좌표, 레이어, 게임 렌더 연결 확인에 사용할 수 있지만 저작 방식의 합격 조건이 아니다. 이미 좋은 시안/벡터가 있다면 폐기하거나 새로 만들지 말고 지적된 자산·구역만 고친다. 새 시안이 필요한 경우에도 지형 벡터와 원경을 동일 이미지 전체 추적으로 만들지 않는다.

**미술 기준은 1막 1·2장의 실제 화면이다.** 1막 1장은 등간격으로 울렁거리는 선이 아닌, 둔덕·골·경사가 자연스럽게 이어지는 실루엣과 크기가 다른 암면, 1막 2장은 뿌리 있는 큰 절벽과 굽은 돌출부, 층위와 깊이의 기준이다. 그림이나 지형을 복사하지 않는다. 과거 승인 시안은 시점·프롬프트 보조 사례일 뿐 이 두 장의 품질 기준을 대체하지 않는다. 기준 장은 별도 승인 없이 변경하지 않는다.

## 2. 장에 들어가기 전

1. 장 ID/배포 버전/현재 실제 렌더 자산과 연결 순서를 고정한다. 단일 SVG만 보지 않는다. base, color, alpha, clip, 외곽 부분, 실제 벡터 캐시, 원경, 공유 자산과 적용 장을 분리해 목록화한다.
2. 당시 지적의 원문과 최신 상태를 분리한다. 재현이 안 되면 재현 구간·버전·카메라를 적는다. 이미 고친 것을 다시 원복하지 않는다. 버그 위치가 불명확하면 상하좌우 전체부터 확인한다.
3. 플레이/카메라 경계, 충돌 지면의 좌표와 지면·벽·통로·의도된 빈 공간, 꼭 지킬 장 ID와 객체를 기록한다. 미술 수정 중에는 물리·배치·이벤트를 같이 고치지 않는다. 지형과 발 위치 정합은 표시 검수에 포함하고, 실제 이동 능력/승리/적은 별도 트랙으로 유지한다.
4. 전체(최소 줌), 보통 보행 배율, 실제 허용 상단/하단/왼쪽/오른쪽 pan, 네 모서리, 대표 화면과 모바일을 확보한다. 원본·후보·합격본을 각각 기록한다. 버전, 렌더러, DPR, 카메라·월드 위치·줌, 클록/날씨, 해상도, UI/디버그 모드를 고정해 같은 조건으로 전후 렌더한다.

## 3. 시안과 Inkscape 저작

### 신규·국소 시안용 표준 프롬프트

아래를 원래 기획과 현재 동일 배율의 실제 이미지를 함께 넣어 사용한다. `[ ]`는 필수 가변 항목이다.

> 혼로 2D 횡스크롤용 [장 ID / 지명]의 [대상 구역 / 전체 범위]를 완전한 정측면으로 그리세요. 조감/사선/등각, 보행면 너비가 위에서 보이는 투시는 금지합니다. [상·중·하 암체/발판/접합/랜드마크]를 [기존 지리·서사 이유]에 맞게 배치하세요. [유지할 보행면과 빈 공간]을 가리지 말고 [자연스러운 곡선 및 서로 다른 크기의 암면]으로 큰 덩어리와 중간 규모 디테일을 나누세요. 1막 1·2장의 그림을 복제하지 말고 실루엣의 곡률·큰 면/중간 면/작은 디테일 위계·층위·접합 원칙만 따르세요. 장르와 [시간대·재질·주색]을 유지하세요. 원경은 분리하고, 지형 이미지에는 원경 안개나 블러를 구워 넣지 마세요. 윤곽을 선명하게, 사진처럼 잘게 쪼개지지 않게, 단색 평면·등간격 발판·같은 바위 반복을 피하세요. 필요한 [상·하·좌·우 연장]까지 지질·재질·명암면이 이어져야 합니다. 이유 없는 아래 천장이나 떠 있는 층은 넣지 마세요. 게임상 또는 지질·서사상 필요할 때만 쓰고, 붙을 지형과 공간 관계를 보여주세요. [보호할 줄기·수관·보행면·좁은 틈·문지방]을 끝까지 유지하세요. 캐릭터·UI·텍스트·화살표 없이 [원경용 이미지 / 단색 진단 배경의 지형용 이미지]를 분리해 만드세요.

상하층은 화면 장식 개수가 아니다. 서로 다른 높이의 지형이 어디에 붙거나 독립하는지 읽혀야 한다. 층위라고 가장자리의 여러 색 띠를 남기지 않는다. 이유 없는 천장·허공 띠는 기본 제외. 필요할 때 지리, 물리 또는 서사 사유와 실제 관계를 설계 카드에 한 줄로 남긴다.

Inkscape에서 암반 몸통/BODY, 표면/SURFACE, 절벽 옆, 상하 더미, 재사용 오브젝트, 보호 마스크를 의미별로 분리한다. 깨끗한 알파 실루엣과 내부 색층을 별도로 만든다. 흐릿한 시안 가장자리의 반투명 픽셀을 양자화 경로로 쌓지 않는다. 먼저 배경과 실루엣을 분리하고, 가장자리의 내부·외부 색을 고정한 뒤 내부 재질만 적절한 색 수로 추적한다. 레이어의 변환·클립은 좌표 기준을 밝히고 필요하면 명시적으로 보존한다. 파일·레이어 이름, 시안/추적 설정과 원본 해시를 보존한다.

## 4. 공격적으로 최적화하되 형태를 지키는 방법

1. **실제 표시본과 원본을 둘 다 잰다.** 도형 트리 개수를 노드 수로 적지 않는다. 명령·제어점·subpath·실제 path와 미술 면 수를 따로 적되 비교는 같은 정의로 한다. 원본/컴파일 파일/gzip bytes, cold 첫 화면, warm 렌더 p50/p95, 캐시 여부를 각각 보고한다. 용량만 준 것을 렌더 개선이라고 쓰지 않는다.
2. **두 예산을 나눈다.** 보행 상단·접합·외곽 알파·수관·기둥·구멍은 오류 허용치를 가장 낮게 잡고 어떤 좌표를 잠갔는지 명시한다. 큰 내부 색면·의미 없는 작고 반복되는 부스러기는 더 강하게 줄인다. 하나의 epsilon을 전 맵에 적용하지 않는다. SVG 단위를 월드·스크린 단위로 환산하고 기존 엔진 한도/보호 오차를 약화하지 않는다.
3. 저장소 `tools/terrain-node-optimizer`의 SVG 또는 Package 경로를 쓰고, nested transform/clip 보호로 건너뛰는 경우에는 실패로 기록한다. 같은 제약을 확인하는 진단 어댑터를 사용하되 (a) 중복·정밀도, (b) 합치기 전 보존할 보호 영역, (c) 내부 면의 경로 단순화, (d) 불필요한 경계 추적 층 제거, (e) 전체 런타임 렌더 순으로 다룬다. clip·mask·socket·physics·원래 깊이 층을 암묵적으로 바꾸지 않는다.
4. 의미 있는 암면을 단색 면으로 덮어 감량하지 않는다. 한 줄 실루엣의 일반 안티앨리어싱과 안쪽/바깥쪽에 따라붙은 넓은 여러 색 띠를 구별한다. 투명·단색 배경과 게임 배경에서 1×/2×, 필요 시 4×로 보고, 경계 법선에서 알파 전이와 색 층을 확인한다. 줌이나 캐시 설정을 바꿔 숨기는 것은 반려. 의도된 암층은 경계와 무관한 내부 파단면을 유지한다.
5. A/B/보수/공격 후보를 검증하고 감량이 작은 경우 다음 원인으로 옮긴다. 렌더 수치와 눈으로 본 양쪽 검사에 통과한 후보만 올린다. 경로당 노드는 줄어도 파일이나 실제 면/렌더가 늘어난다면 최적화 합격으로 표시하지 않는다. 화면에 보이는 지지/틈을 닫거나 형태가 바뀌면 원본을 보존하고 후보를 반려한다.

초기 우선순위: 5막 6장(지도명 하늘우물 입구)의 추가 운영 자산 8개 17,203,572B, 5막 2장의 SURFACE 이전 최적화 회피, 5막 전체의 다중 엣지, 5막 1·2·4장과 4막 2·3·4·5장 접합, 4막 8장 및 귀림, 1막 3장 변경 이력과 현재 재현. 1막 1·2장은 변경하지 않는 참조. 이 목록은 오래된 원문을 기반으로 한 조사 우선순위이며 최신 문제 확정이 아니다.

### 모든 장에 적용할 1막 1·2장 정량 기준
- 최신 운영의 1막 1·2장 지형 벡터를 각각 공통 정의로 센다. 닫힌 한 경로 안에 면이 여러 개면 별개 subpath를 센다. 눈으로 보이는 폴리곤과 내부 구멍/겹친 색면을 구분한다. 경로 끝점·곡선 제어점·clip path와 렌더 인스턴스 중 어떤 비용을 집계했는지 표에 적는다. JSON 트리의 nodeCount 표기를 믿지 않는다.
- 면적 분모는 고정된 월드 좌표에서 해당 장의 실제 지형 벡터 알파 면적 합집합이다. 줌이나 투명 여백으로 늘리지 않고, 원경/UI/캐릭터 및 별도 소품을 빼고, 동일 픽셀 밀도와 알파 문턱으로 재현한다. 중첩 지형은 면적에서 한 번만 세되, 렌더에서 실제 그리는 중복 면과 노드는 비용으로 별도 집계한다. 보호 clip 포함 여부를 전 장에 같게 한다.
- 100만 월드 제곱 단위당 노드·닫힌 폴리곤·정규화 bytes와 총용량, 전송 압축 bytes, 실제 p50/p95를 표시한다. 1막 1·2장의 두 실측값을 기준 구간으로 두고, 장별 편차/기준 대비 배수를 전 1~5막 표로 공개한다. 수치가 없는 상황에 임의로 목표를 정하지 않는다. 총용량이 커도 실제 지형 면적이 넓어서인지, 중첩 추적이 과도해서인지는 두 수치를 함께 보고 판단한다. 비슷한 수준으로 수렴시키되 형태·가독성 손실로 숫자를 맞추지 않는다.
- 현재 운영 중인 무거운 장부터 기준 밀도까지 적극적으로 줄인다. 내부 색면은 더 큰 절대 오차 허용량 후보를 시도하고, 경계·지면·clip은 고정한다. 작은 일괄 감량만 반복하지 말고 중복 색면 제거·겹띠 제거·실제 안 보이는 추적 면을 구분해 재구성한다. 너무 단순한 장에 숫자만 맞추려고 무의미한 노드를 추가하지 않는다. 안전한 예외는 근거/리스크와 해당 원본 화면을 보고한다.

## 5. 검수 최소 5회

매 회차마다 아래 표를 전부 실행한다. 첫 회는 원본/경계 고정, 이후 회차는 **다른 실제 수정 또는 다른 원인 처리**가 있어야 한다. 다른 단계를 이름만 바꿔 세거나, 조사 준비/스크립트 작성/파일 내보내기/CI 재실행만으로 회차를 올리지 않는다. 각 회차는 모든 기준을 확인하고 새로 드러난 실패를 기록한다. 5회 달성 자체는 완료 조건이 아니다.

| 검사 | 매 회차의 기록 |
|---|---|
| 노드·용량·성능 | 실제 paths/commands/노드/면, 원본과 컴파일 bytes+gzip, 동일 기기·카메라에서 cold/warm p50/p95. 아직 못 잰 항목은 미검증 |
| 윤곽 | 정상 AA와 추적 블러/겹띠 분리; mask 안팎, 원경 합성, 1×/2× 확대 전후 |
| 외곽과 접합 | 상·하·좌·우와 4모서리, 최소 줌/정상/모바일. 더미는 실제 지층-암면-색이 연결, 원경·카메라·단색벽으로 숨기지 않음 |
| 미술·구성 일관성 | 1막 1·2장과 비슷한 보행 배율로 대조. 정측면, 주요 실루엣·높이 다양성, 큰 암체와 중간 명암면, 나무 끝까지 온전, 이유 없는 천장·복제 구역 없음 |
| 시각 지면 | 진짜 보행 가능해 보이는 선과 물리 접촉을 대조. 공중부양·발 파묻힘·가짜 사다리·통로를 표시. 지형 미술-only라면 물리·배치 등은 해시 보존 |
| 근거 | 장/빌드/자산 hash, 수정 가설·무엇을 바꿈, 같은 카메라 전후 스샷, 각 항목 합격/실패/미검증, 다음 변경 |

검수 기록 양식: `[지형 n/최소5] [장과 자산] [변경] [전체/국소 스샷] [전후 수치] [기준별 판정] [다음]`. 화면으로 판단할 수 없는 부분은 ‘미검증’. 반려된 가설도 원본 대비 차이가 실제 확인된 경우에만 그 근거와 함께 기록한다. 최종은 목표에 포함된 전 장을 대상으로 미해결·보류를 나열한다. 한 장의 개선이나 CI 성공만으로 전 장을 합격 처리하지 않는다.

## 6. 별도 플레이·전투 트랙과 배포

지형 회차에 전투·호위·클리어 테스트를 포함하지 않는다. 플레이 및 몬스터는 별도 원문/검수표: 전원 섬멸 조건 금지, 목적지·장소에 묶인 다양한 목표, 의미 있는 군집 또는 드문 개체와 악역/중간보스의 이유, 실제 접근성과 정량 밸런스, 보상. 문제 이름만 바꾸거나 조건을 숨기지 않는다. 6막 신규 시안/구현은 보류.

변경은 검증된 단위별 격리 브랜치에 남긴다. 기준 통과와 원본 보존이 확인된 것만 승인 범위에 따라 master 및 기존 Pages로 보내고, 배포 SHA·브라우저 실제 이미지·캐시와 환경을 재확인한다. 상충하는 이전 맵에디터 의무/QA 목표를 이 문서에 근거로 우선 적용하지 않는다. 의심스러운 적용은 최종 사용자 지시와 현재 활성 소스를 확인한다.
