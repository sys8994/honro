# 25·27 수직 집하장 V3

25는 수직 수문 정비축, 27은 수몰 집하장과 맞은편 봉인 통로다. 저문골 가족 물품·무명사로 보낸 흔적을 유지하며 새 괴물의 정체나 목적을 추가하지 않는다.

## 공간과 이동

- 25: 입구 → 상승한 동쪽 정비실 → 낮은 천장을 지나 오른쪽 열린 점검창에서 왼쪽 위로 발사 → 중앙 점검창 → 서쪽으로 되돌아가는 경사 석회랑 → 전망실 → 위쪽 물받이 → 깊은 틈 너머 검문실 → 왼쪽 상층 봉인회랑. 필수 공간이동 연결은 5개다.
- 27: 입구에서 걸어서 상부 하역창 → 깊은 낭떠러지 건너 낮은 수몰 하역대 → 위쪽 맞은편 봉인통로 → 왼쪽 회수창 → 걸어서 배수 회랑 → 왼쪽 위 대조대 → 걸어서 명세실. 필수 공간이동 연결은 4개다.
- 사격창 선택은 실제 고체 지붕·벽으로 만든다. 조준을 가로막는 곳에서 성공한 플레이를 숨은 순서 플래그로 되돌리는 방식이 아니다. 현재 V3 런타임은 안전한 실제 도착과 두 동행 집결을 기록하며 정상적인 지름길을 허용한다.
- 첫 착지 진목을 유지한 채 한 동행이 기다리고 담허가 사격창으로 갔다가 돌아오는 선택도 가능하다. 매번 발밑 진목을 재설치할 필요는 없다. 진목 최대 2개·오래된 것 교체·6턴 지속 등 기본 M09 규칙은 변경하지 않았다.
- `design.act3.crossings`는 공간이동 그래프의 연결이다. `walkingComponents`는 그 사이의 실제 연결된 걷기 구간이며, `requiredRoute`를 x순으로 정렬하거나 서로 다른 층을 한 지면으로 간주해서는 안 된다. `optionalRoutes.points`는 `{x,y}` 객체다.

## 기본 물리 예산

실제 공유 엔진의 rank 1 M09와 preview를 사용한다. 무풍 최대 수평 도달은 상승 0/250/400/500/600/700일 때 약 1274/1038/855/707/515/170이다. 필수 상승은 450으로 설계했고 초고도 상승과 큰 수평 거리를 한 발에 결합하지 않는다.

두 동행의 기본 점프 최고 상승은 약 214이다. 정상 최고 이동속도 450의 같은 높이 점프는 약 589이며, 낙하 중 이동거리는 더 늘어난다. 같은 높이 700, 하강 600의 간격 1000은 실제 점프로 건너지 못하는 것을 검사한다. 최종 끊어진 목재 끝을 포함한 실지형도 별도로 검사한다.

실제 턴의 바람 목록은 `[0,12,-8,6]`이다. -8/0/12에서 총 27개의 지도 연결·바람 조합을 검사하며 좌향과 우향을 모두 포함한다. 각 조합은 여러 각도·파워가 유효하고, 실제 발사 착탄과 preview 오차, 설오·담허의 각각 E 도착을 확인한다.

## 구조와 미술

경사 석회랑의 닳은 연속 상면은 실제 걸을 수 있는 충돌면이다. 디딤석 단면과 154 높이의 조적 지지부, 양쪽 돌면, 젖은 수위선, 깊은 수면과 선택형 반사를 사용한다. 서쪽 전망실·상층 검문실·맞은편 봉인통로·명세실에는 실제 벽과 천장을 둔다. 마지막 봉인문과 가족 살림 꾸러미의 기존 최종 미술을 재사용했다.

새 에셋은 `a3-waterworks-v3:` 이름 공간이다. 공개 B의 기존 Library 404개는 순서와 내용을 그대로 보존하고 새 에셋만 덧붙인다. V1/V2 저장 지도·기존 진목·기존 에셋을 V3 지형으로 섞지 않는다. 다른 28장의 canonical stage는 변경하지 않는다.

## 재현 검사와 범위

- `tests/vertical-waterworks-physics.mjs`: 실제 canonical 충돌·기본 rank1 샷·preview·2인 E, 극단 바람, 최대 기본 점프·하강, 두 인물의 걷기 연결. 각 연결의 시작 자세를 격리한 fixture다.
- `tests/vertical-waterworks-structure.mjs`: 5/4 연결, 실제 방·걷는 구간·별도 에셋, 낮은 천장에서 막히는 사격.
- `tests/vertical-waterworks-continuous.mjs`: 적만 제외하고 처음부터 끝까지 실제 걷기·턴·기력·기본 진목 교체·E. 시작 이후 위치나 자원을 리셋하지 않는다. 기본 재설치와 대표 대기·복귀 전략을 모두 검사한다.
- `tests/hidden-waterworks-maps.mjs`: 생성 멱등, canonical 왕복, 접지, 목표, 다른 장 보존과 26/28 기존 보행.
- `tools/environment/capture-hidden-waterworks.mjs`: 공통 Scene의 전체/기본/횡단/세로/문서방 렌더. 화면별 source hash와 실제 camera를 manifest에 기록한다.

적 없는 연속 fixture에서 25는 12라운드·9발, 27은 14라운드·7발로 최종 문서방에 두 동행이 도착했다. 25 두 번째 연결에서 설오 대기·담허 복귀 전략을 쓰면 11라운드·8발이다. 이 수치는 실제 조준 고민, 대화, UI 입력, 적 전투를 포함한 클리어시간이나 난이도 검증이 아니다. 브라우저 정상 입력과 배포 검수는 별도 통합 단계에서 수행한다.
