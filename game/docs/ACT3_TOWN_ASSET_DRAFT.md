# 3막 읍성 공통 미술 재료 · 비활성 시안

## 범위와 상태

스토리 기획 v0.1의 18–20쪽에 공통으로 등장하는 성문, 관아, 관창의 재료 3종이다. 맵 후보 선택 전에도 비교할 수 있는 **미술 시안**이며 맵 구조, 동선, 이야기, 단서, 기믹 또는 전투 수치를 확정하지 않는다. 특정 사적을 복제한 고증 모델이 아니라 기존 HONRO 수묵담채 팔레트와 side-view 조형을 잇는 창작 건축이다.

원본은 `workshop/drafts/act3-town-assets/`의 SVG와 `manifest.json`에 있다. 현재 Game/Workshop 자산 목록·캠페인·`shared/build.mjs`에 등록하지 않는다. 새 SVG 이름을 읽는 파일 glob이나 자동 등록도 없다. 기본 캠페인은 기존 20장이고 두 HTML은 기준 커밋 그대로다.

## 세 재료의 구분

- **읍성 성문:** 큰 화강암 면, 홍예의 빈 구멍, 3칸 목조 문루, 넓고 낮은 팔작지붕. 불규칙 석재 몇 면으로 무게를 내고 균일 벽돌·미세 균열을 반복하지 않는다.
- **관아 담장·문간:** 따뜻한 회벽과 낮은 석재 기단, 긴 기와담, 높게 올린 문간. 성문보다 낮고 수평적인 실루엣이다. 빈 현판은 특정 관청·가문·기록을 뜻하지 않는다.
- **관창 하역 외벽:** 긴 낮은 기와지붕, 벽 하부 널판, 닫힌 판문과 높은 환기창, 열린 하역칸, 서로 떨어진 석재 받침. 창고와 하역 장소를 구분하되 짐·지도·장부·왕실 문장은 넣지 않는다.

기와를 얹은 관아 담장과 수평 단을 이루는 한국 담장의 형태적 배경은 [국사편찬위원회 우리역사넷의 전통 공간 해설](https://contents.history.go.kr/front/km/print.do?levelId=km_039_0030_0030_0080&whereStr=)을 참고했다. 원본 사진·그림은 복사하거나 내장하지 않았다.

## 좌표와 이후 배치 조건

모든 SVG는 발 기준 `(0,0)`, 위쪽 음수 Y다. `reference`는 현재 공통 환경 계약을 따른다. 원본 SVG 좌표와 world unit이 1:1이 되도록 높이/60을 사용했다. 이는 배치 확정이 아니라 비교를 위한 크기 제안이다. `candidateLayer`는 땅에 붙는 구조물의 기본인 L1-back이며, 미래에 장소를 설명하는 중경으로 쓸 때는 기존 support/group/depth 규칙을 사용한다. 새 패럴랙스 계수나 별도 renderer를 만들지 않는다.

`manifest.json`의 `groundContacts`는 실제 그림이 Y=0에 닿는 점, `clearRegions`는 실제로 알파가 0인 안전 여백, `roof.bounds`는 해당 처마 그룹이 그려지는 전체 bounds다. 검사는 native raster에서 실제 paint bounds를 측정하여 선언 범위 안에 드는지 확인한다.

- 성문 아치의 검사용 안전 여백: X −120…120, Y −185…−8. 문 아래 지형에 자동으로 구멍이 생기지 않는다.
- 관아 문간의 안전 여백: X −68…68, Y −260…−8. 양쪽 기둥과 담장 아래만 접지하며 가운데 문턱은 비워 둔다.
- 관창 하역칸의 안전 여백: X 242…390, Y −300…−163. 데크 위의 공간이다. 데크 표면 Y=−152, 지면 Y=0. 받침 사이 공간은 X 140…320, Y −84…−9에서 투명하다.

**SVG 그림은 지형 충돌이 아니다.** 문루/처마/벽/데크를 탄도 차단이나 이동 발판으로 쓰려면 맵 선택 후 별도의 실제 지형 polygon으로 설계해야 한다. 특히 문간을 막는 하나의 사각형 collision, 데크의 허공 접지, 그림만 있는 통행/발판으로 오인하는 배치를 금한다. 이 시안은 충돌·경로·상호작용을 전혀 만들지 않는다.

## 재현 검사

```sh
node tests/act3-town-assets.mjs
node tools/environment/preview-act3-town-assets.mjs
```

검사는 XML, 기존 `compileSVG`와 `HonroVectorArt.validate`, 재사용 Path2D, SVG 안전 어휘, 파일 크기/경로 수, 실제 paint/처마 bounds, 접지 13점, 투명 여백 4곳, 390px 카드 내 0.24배 축소를 확인한다. 현재 활성 데이터·번들 원본·두 HTML이 기준 `53fd108`과 동일한지 함께 검사한다.

컨택트 시트와 수치는 `_local/reports/act3-town-assets/`에 생성한다. 기존 공통 Canvas 벡터 renderer로 만든 재료 시안이며 실제 Game/Workshop 장면, DOM·입력, 포격각, 이동 가능성, 최종 미술 승인 또는 성능 검증을 대신하지 않는다. 두 HTML에 런타임 변화가 없어 이 draft 단위에서는 새 빌드 산출물을 저장하지 않는다. 활성화 시에는 최신 기준으로 재검수하고 전체 빌드·검사·실제 Pages 검증을 별도로 수행해야 한다.
