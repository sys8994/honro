# 몬스터 체급 2차 적용과 검증 (2026-11-24)

대상은 정식 캠페인의 좁은 단위입니다. [50장 기준과 설계](planning/monster-scale-20261124/PHASE2_DESIGN_AND_BASELINE.md)에 전체 조사를, [귀림 발견](planning/monster-scale-20261124/GROVE_DISCOVERY.md)에 대사 설계를 기록했습니다. h는 월드 피격 높이, r은 반폭입니다. 기존 리그를 사용하며 h와 실제 모습의 높이는 같지 않을 수 있습니다.

| 장과 개체 | 기존 → 새 전투 | 이유 및 보존 |
|---|---|---|
| 1막 6장 교각귀 | h352/r54 → h460/r64 | 젖은 교각 목재의 더 큰 몸. 전투 전 휘겸이 얼굴 균열을 언급. 얼굴 직격 100%, 몸통 20%. 기존 지형·운반 목표 보존. |
| 2막 6장 하층 어둑시니 | h152→239→291에서 h152→280→490으로 | 침수 하층의 성장 대비. 조건·축소·HP·r43 유지. 기존 비충돌 큰 어둠 실루엣은 별도. |
| 3막 10장 서편 두억시니 | 체급·위치·체력 동일 | 나루 석분으로 바랜 회갈색. 기존 다락과 사수 사선에 거체를 끼우지 않음. |
| 4막 10장 포구 장승 | 체급·위치·체력 동일 | 조수에 바랜 청회색 목재. 승선 계단과 저·만조 전환 보존. |
| 5막 4장 거목 수목귀 | h298/r49 → h460/r64 | 윗뿌리 한 기만 체급·이끼빛 껍질·옥빛 눈. 내려가는 길의 출현과 통과 조건은 그대로. |

귀림은 서로 다른 실제 플레이어의 직접 몸통 공격 두 번이 감쇄돼 HP를 깎은 뒤 한 번만 추론합니다. 투사체 파편·자동·중복 접촉을 셈에 넣지 않습니다. 실피해가 들어간 첫 얼굴 적중을 한 번 확인합니다. 첫 적중이 이미 얼굴이면 늦은 추론을 건너뜁니다. 살아서 볼 수 있는 설오 또는 담허가 기존 비차단 자막으로 말합니다. 기존 저장은 지난 체급·규칙으로 계속됩니다.

## 검증과 한계
- 50장 초기 전투 실측(기준 공개판 eb3dbeb2): 전투 적 1,143개. 피격 높이 0.9배 초과~1.65배 미만이 820개(72%), 5배 이상은 큰 어둠 1개였습니다. 후발 증원과 전 장 완주 실측은 아닙니다.
- 교각귀: 정상 성장 파티의 집중 공격에서 3라운드 처치. 실제 얼굴 직격, 담허 원호파, 얼굴/몸통의 피해와 PC·모바일 진입 대사·기존/신규 Continue 검증. 근거: Actions 45311659491.
- 잠운사: 두 통제 피격·세 무피격 전환의 실제 엔진 결과 h152→280→490→490→280→152. 기존 HP, 목표/위치·복선·PC/모바일 기존 Continue 보존. 근거: Actions 45312857116.
- 귀림: 윗뿌리 교전 지점에서 시작한 정상 성장 파티 검수에서 3라운드 처치. 양쪽의 작성된 경로 조건과 단계, PC/모바일 몸통/얼굴 타격 뒤 대사, 기존 Continue 검증. 스테이지 전체 완주나 난이도 전체의 증명은 아님. 근거: Actions 45315841107.
- 나루·포구는 그림 배색만 바뀝니다. 새 그림, 지형 변경, 일반 적 일괄 확대/일괄 약화는 하지 않았습니다. 작은 적의 위협은 기존 이동·엄폐·군집을 보존해 비교했으며, 신규 소형 전투 기믹의 전면 확대는 별도 실험입니다.
