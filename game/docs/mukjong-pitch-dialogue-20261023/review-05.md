# 5차 검수: 전체 대본 최종 대조
17장: 산 사람의 혼으로 종을 누르는 범행을 이미 안다. 새 대사는 이를 다시 설명하지 않고 눈앞의 조임과 끊기는 목소리에 반응한다.
18장 초반: 종지기 위협→소단의 이름을 끊지 말라는 항의→담허의 기존 사격 지시 유지. 피치 설명은 아직 변화가 없으므로 초반 대사에 붙이지 않는다.
첫 상승: 소단은 들린 변화를 말하고, 담허는 원인 1문장과 역할 1문장만 말한다. 목소리가 끊기는 것은 지금까지의 봉음 행위와 일치한다.
후반: 실제 의식과 결박 강화가 있을 때만 종지기의 명령과 소단의 반발. 휘겸과 설오의 기존 제압 대사를 대체하지 않는다.
해방: '이번엔 끝까지'는 과거에도 이름이 들렸던 사실과 맞고, 가족의 호명을 요청하는 다음 문장에 이어진다. 감상·성장 요약·주제 선언 없음.
19장: 아직 천도되지 않았으며 가족이 이름을 불러 혼을 나눠 받는 과정 그대로 유지.
최종 수정: 없다. 최종 5개 신규 행, 기존 2개 행 교체, 2개 조건부 대화 묶음과 기존 outro 삽입. 전투/퀘스트/실패 조건 변화 없음. 이는 부모의 텍스트·연속성 검수 5회이며, 인게임 동작 검사는 아직 별도 필요하다.
