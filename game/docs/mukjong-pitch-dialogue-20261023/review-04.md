# 4차 검수: 발동 순서·분기·읽기 흐름
발견: 첫 상승 두 행과 후반 두 행을 매 번 발동시키면 전투가 대사로 끊긴다. 음원 로드 전 대사를 먼저 보여주면 체험→반응 순서가 무너진다. 후반 조건 충족 뒤 캐릭터가 이미 제압된 경우 위협 대사가 남을 수 있다.
조건: 첫 상승 대화는 18장 첫 실제 재생된 상승음(1반음 이상) 뒤 한 번, 안전한 기존 대화 경계에서 일반 다음 버튼으로 읽는다. 로드 실패/음소거 시 새 설명창을 소리 대신 억지 출력하지 않는다. 후반은 첫 상승 대화를 마친 뒤 실제 종지기 의식 성공, 3반음 이상일 때 한 번. 같은 사건에서 두 대화가 겹치면 첫 대화만 하고 후반은 다음 적합한 의식으로 넘긴다. 늦게 조건이 맞더라도 제압·종료 후에는 재생하지 않는다. 조건 미충족이면 후반 대사는 생략한다. 저장/뒤로/재렌더로 반복 금지. 대사 자동 넘김 금지.
제압 후 한 행은 기존 봉음판 낙하 서술 다음, 가족을 불러 달라는 기존 소단 말 바로 앞. 첫 상승/후반 대화를 못 봐도 문맥 성립.
정합 교체 2건: '내가 손을 놓으면 저 종이 다시 운다. 그때도 내게 풀라 하겠느냐?'→'내가 손을 놓으면 저 안의 것들이 쏟아진다. 너희가 다 받아낼 수 있느냐?'는 종지기의 위협/자기 정당화로 유지. '종의 울림이 낮아졌다.'→'종의 울림이 잦아들었다.'는 현재 피치가 내려가지 않고 정지·감쇠하는 계약과 일치.
