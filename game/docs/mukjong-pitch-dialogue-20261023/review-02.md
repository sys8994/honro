# 2차 검수: 인물의 목적과 행동
소단은 소리에 민감한 구출 당사자로 끊기는 이름을 걱정한다. 담허는 설명을 길게 하지 않고 조임의 원인과 필요한 역할을 짚는다. 종지기는 혼을 잃으면 결박이 풀릴 것을 두려워해 입을 막는다. 설오·휘겸에게 같은 감상을 반복시키지 않는다.
발견: 담허의 '계속 짚어 주게'는 대상과 행동이 모호하다. 설명을 피하려다 피치와 조임의 인과도 흐려졌다.
수정: 담허 '줄을 죌수록 종이 저렇게 우는 게야. 소단, 들리는 이름을 기억해 두게.'
후반 초안 유지: 종지기 '아직도 제 이름을 부르느냐. 더 조여야겠구나.' / 소단 '그만해요! 이름도 못 부르게 할 셈이에요?'
제압 후: '이제 들려요. 아까 끊겼던 이름들이…….'를 '이름이 들려요. 이번엔 끝까지…….'로 수정해 이전에도 일부 들었음을 보존한다.
