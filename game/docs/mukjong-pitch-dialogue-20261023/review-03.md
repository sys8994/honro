# 3차 검수: 말투·명료성·불필요한 문학성
읽은 문장: '종소리가 아까보다 높아졌어요. 부르던 이름도 자꾸 끊겨요!' / '줄을 죌수록 종이 저렇게 우는 게야. 소단, 들리는 이름을 기억해 두게.'
검토: '음정·피치·반음·공명 주파수' 대신 평범한 '소리가 높아졌다' 사용. 고어 명사나 억지 시어 불필요. 담허의 기억 요청은 명언이 아니라 구조할 혼을 놓치지 않으려는 행동이지만, 이름 외우기가 새로운 게임 과제로 오해될 여지가 있다.
수정: 담허 마지막 문장을 '소단, 안의 목소리를 계속 들어 주게.'로 바꾼다. 역할은 명료하고 새 수집 과제를 만들지 않는다.
후반 종지기 '더 조여야겠구나'는 혼잣말처럼 차분하다. 현재 상대의 저항에 직접 반응하도록 '아직도 제 이름을 부르느냐. 그 입까지 묶어 주마.'로 변경. 소단 반박은 유지.
