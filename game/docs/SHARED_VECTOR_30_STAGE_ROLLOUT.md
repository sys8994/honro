# 1~3막 30장 공통 벡터 렌더 연결

[제작 SOP v1.0](STAGE_PRODUCTION_SOP.md)의 재료·렌더 변경 범위다. **30장 렌더 연결을 완료했으며 전체 스테이지 재설계나 미술 합격을 뜻하지 않는다.** 기존 맵 크기, 충돌 다각형, one-way, 유닛/적 편성, 진행·실패 조건, 이벤트·대사, 저장 ID/리비전은 유지했다. 진행 중 전투를 다시 시작시키는 데이터 변경은 없다.

단계 0의 [30장 설계 카드](../../review/shared-vector-campaign/stage-cards.json)는 기존 목표·앞뒤 장·현재 참가 인물·크기/종횡비·수직성·ID·초기 적 예산을 기록한다. 새 전투 질문이나 승패 규칙을 만들지 않고 각 장의 기존 목표/컨트롤러를 기준으로 보존했다. 단계 1/3/4/5/6은 기존 계획 보존이며 단계 2와 7의 공통 렌더 연결만 변경했다.

## 구현과 보존 범위

- registry/compositions가 유일한 경로 원본이다. `tools/environment/vector-kit-runtime.mjs`가 같은 모듈을 일반 runtime으로 변환하고 정식 `shared/build.mjs`에 넣는다. Game·Workshop·Playtest가 같은 목록을 사용한다. 장별 경로 사본은 없다.
- `campaign.mjs`의 30개 명시적 설정이 팔레트·기본 재질·사용 부품·유지할 특수 요소를 구별한다. 동굴/도시/수로/화재/기록 공간에 소나무를 일괄 배치하지 않는다. 원래 일반 소나무/풀의 일부는 공유 부품 참조로 바꾸고, 복잡한 고유 건축·주술목·동굴 구조·랜드마크는 기존 벡터를 유지한다. 한옥 전체를 신규 공통화했다고 기록하지 않는다.
- 임의 다각형·천장·오버행·개별 one-way를 그대로 채색하고 실제 노출 가장자리에 옅은 경계를 둔다. 강한 충돌 윤곽 토글과 기존 인물/카메라 보정, 2장 사격턱 카메라는 유지한다.
- 1~4장은 이전 이미지 제작기가 `terrainBounds == playBounds`와 유한한 그림 몸체를 남긴 특례다. 명시한 기반 지형에만 기존 `HonroTerrainDomain.author/extend`의 외곽 규칙으로 **표시용 battle view**를 만든다. 기존 b.terrain·충돌·저장에는 쓰지 않고 동일한 domain tile 캐시로 그린다. 하단 fade·별도 스커트 없이 하나의 몸체로 이어진다. 나머지 26장은 기존 canonical domain을 그대로 사용한다.
- 이미지와 함께 삭제된 1~4장의 근경에는 공통 고목/소나무, 나루 쉼칸, 피란문 기둥의 제한된 대체 표현을 넣었다. 3장 창고/4장 성문 전체 그림은 아직 공통화되지 않은 임시 뼈대이며 실제 지붕/계단 one-way와 퀘스트 대상은 유지한다. 이 대체 표현은 완성된 장소 미술이 아니다.
- 기존 1~4 near 그림을 다시 얹지 않는다. 1~10 location 및 18/21/27 painted 질감 패스는 새 캠페인 패스에서 비활성화한다. 1~4 원경은 quietFar만 독립 요청하고 5~10은 기존 원경 이미지를 사용한다. 이후 장은 기존 원경을 유지한다. 지형 출력은 어떤 이미지 디코드도 기다리지 않는다.
- 묵종 외피/내부 특수 돌과 30장 정착 배·붕괴 가림막은 기존 이벤트 미술에 위임한다. 폭포는 기존 벡터 흐름·표적 표시를 유지한다. 새 물 모션·새 사건·새 적/대사는 만들지 않았다.
- Path2D·배치는 sceneVersion/에셋 버전별로 캐시한다. 화면 밖 부품은 생략하고 기존 bounded world tile 캐시를 사용한다. 매 프레임 랜덤·필터·이미지 픽셀 스캔이나 전체 지도 거대 캔버스를 추가하지 않았다. 각 장은 기존 loader가 필요할 때 불러온다.

## 실제 확인

- 정식 빌드 성공. 최초 새 환경에서 TypeScript 부재로 시작하지 못해 기존 의존성을 복구했다. 이후 특수 이벤트 표현과 첫 네 장 외곽 결함을 보완하며 정식 생성물을 다시 만들었다(성공 4회). 전체 verify/스킬/별도 검수자는 실행하지 않았다.
- 30장 활성/누락 참조/런타임 오류 스모크 1회. 30/30 공통 provider 활성, 누락 에셋 0, page/HTTP 오류 0. 모든 렌더 전후 collision/units/events 동일. 외곽 수정 후에는 영향받은 1~4장만 재확인했다.
- 1장 실제 App 입장·키보드 이동 181.9 world. 선택 one-way의 실제 Engine.tick 접지 오차 0 world. 파괴 후 연결된 공유 가지/수관 3개 제거 확인.
- 5·18·27·30장은 원래 production battle에서 짧은 실제 Engine.move/tick를 실행했다. 폭포/타겟 활성, 묵종 suspended 외피, 27장 masonry-vault 충돌, 30장 moored 상태·old-road 출구를 확인했다. 캡처는 해당 장소를 보기 위한 검사 카메라다. 폭포 퍼즐 해결·묵종 하강·나루 정착/최종 집결·각 장 완료를 재플레이한 증거는 아니다.
- 현재 미술은 단순한 기반 연결이다. 넓은 사면, 일부 한옥/고유 구조, 기존 지형 발판과 공유 수목의 시각 접합은 추가 제작이 필요하다. 세부 미술 보강 대기 없이 30장 연결을 먼저 배포한다.
