# 자동 공격의 아군 보호

## 경계

직접 조준한 원탄·유도 원탄·반사 원탄과 직접 설치한 진목/장판/지연폭탄의 기존 피격 규칙은 보존한다. 원탄의 아군 피해를 일괄 제거하지 않는다.

다음 공격은 자동 공격이다.

- 소환령과 섭혼 대상의 자유 행동: 배회령 근접, 등불귀 추적탄, 돌격귀 밀치기, 먹귀 반격, 지박령 지속 공격
- 반향령 복제탄, 패시브 연사, 분열/비/추적/궁극기 자탄, 파편, 연속 소폭발, 추가 번개, 수렴 원혼, 구 기예의 추가 폭발
- 휘겸 연참의 모든 베기, 회신의 두 번째 베기, 응수세 반격, 당긴 뒤 추가 베기
- 회전검의 개별 궤도 검: 중심 투사체의 직접 조준/지형 충돌과 별개로 자동 공격 출처를 부여한다
- 위 자동 공격에서 파생된 장판·지연 효과·밀치기 연쇄·주박 지속 피해

공격 소유자와 경험치 기여 소유자는 변경하지 않는다. `autonomous`는 피해량/속성과 별개인 출처 표지다. 기존 저장의 child/secondary/followup/echoSource 및 소환·섭혼 소유 관계도 자동 출처로 읽는다. 연참/반격/회전검은 실행 때 같은 표지를 생성하므로 진행 중 구 저장에서도 보호한다. 구 쌍월참의 직접 조준 crescent 원탄은 child를 피해 상한 목적으로 사용했으므로 자동 자탄으로 분류하지 않는다. 반향/후속 복제 여부는 여전히 자동 출처로 읽는다. 직접 설치된 구 장판/주박에는 자동 출처 기록이 없으므로 기존 직접 효과 규칙을 유지한다.

## 공통 판정

`Engine.attackAllows`가 현재 소환/섭혼 소유자, honroAlly, objective의 동맹 관계를 읽는다. 자동 공격은 같은 동맹과 중립 NPC/자신을 피격 대상으로 삼지 않는다. 의도적 유도 대상 선정과 실제 투사체 충돌, 광역 피해, 상태 변화, 밀치기에는 동일한 관계를 사용한다. 아군을 맞고 사라지는 대신 통과하므로 뒤의 적을 계속 공격한다. 직격 진입점에서도 방어하여 개별 피격 효과가 새는 것을 막는다.

자동 공격은 지형 충돌/반사/가림을 유지하되 지형 HP를 깎지 않는다. 받침 파괴에 따른 낙하, 통 폭발, 연결된 낙하물/수문 피해를 아군에게 우회 적용하지 않기 위해서다. 이는 자동 공격이 지형 목표를 파괴하지 못한다는 의도적인 제한이며 직접 조준한 원탄/검술의 지형 공격은 유지한다.

## 검증과 한계

`npm run test:autonomous-friendly-fire`는 실제 엔진의 20개 출처×진영 비행, 전후/겹친 아군, 자신/동맹/NPC, 상태·밀치기·지형 연쇄, 지상/공중 연참과 첫 적 처치 후 연계, JSON 저장 재개, 회전검, 소환수 전체 차례 종료, 반사 유지, 적 HP/XP 기여 수치 동일성을 확인한다. `test:ally-targeting`에 연결한다. 이전 `projectile-friendly-fire`의 자동 공격 기대값만 새 계약으로 갱신한다.

독립 코드 검토, 통합 전체 verify, Game/Workshop의 실제 화면과 최종 Pages 검수는 별도 기록한다. 격리 테스트는 캠페인 전체 완주나 사용자의 정상 저장 검증을 대신하지 않는다. 정상 저장은 수정하지 않는다.
