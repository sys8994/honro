# 자동 공격의 아군 보호

## 경계

직접 조준한 원탄·유도 원탄·반사 원탄과 직접 설치한 진목/장판/지연폭탄의 기존 피격 규칙은 보존한다. 원탄의 아군 피해를 일괄 제거하지 않는다.

다음 공격은 자동 공격이다.

- 소환령과 섭혼 대상의 자유 행동: 배회령 근접, 등불귀 추적탄, 돌격귀 밀치기, 먹귀 반격, 지박령 지속 공격
- 반향령 복제탄, 패시브 연사, 분열/비/추적/궁극기 자탄, 파편, 연속 소폭발, 추가 번개, 수렴 원혼, 구 기예의 추가 폭발
- 휘겸 연참의 모든 베기, 회신의 두 번째 베기, 응수세 반격, 당긴 뒤 추가 베기
- 회전검의 개별 궤도 검: 중심 투사체의 직접 조준/지형 충돌과 별개로 자동 공격 출처를 부여한다
- 위 자동 공격에서 파생된 장판·지연 효과·밀치기 연쇄·주박 지속 피해

공격 소유자와 경험치 기여 소유자는 변경하지 않는다. `autonomous`는 피해량/속성과 별개인 출처 표지다. 기존 저장의 child/secondary/followup/echoSource 및 소환·섭혼 소유 관계도 자동 출처로 읽는다. 연참/반격/회전검은 실행 때 같은 표지를 생성하므로 진행 중 구 저장에서도 보호한다. 구 쌍월참의 직접 조준 crescent 원탄은 child를 피해 상한 목적으로 사용했으므로 자동 자탄으로 분류하지 않는다. 반향/후속 복제 여부는 여전히 자동 출처로 읽는다. 직접 설치된 구 장판/주박에는 자동 출처 기록이 없으므로 기존 직접 효과 규칙을 유지한다.

## 공통 판정

`Engine.attackAllows`가 현재 소환/섭혼 소유자, honroAlly, objective의 동맹 관계를 읽는다. 플레이어 진영의 자동 공격만 같은 동맹과 중립 NPC/자신을 피격 대상으로 삼지 않는다. 적의 자동 공격/소환은 이 새 보호 규칙을 적용하지 않으며 기존 민간인·objective·지형 피해 규칙을 유지한다. 부모가 없는 구 저장은 저장된 side를 쓰고, side도 알 수 없으면 기존 피해를 보존한다. 의도적 유도 대상 선정과 실제 투사체 충돌, 광역 피해, 상태 변화, 밀치기에는 동일한 관계를 사용한다. 아군을 맞고 사라지는 대신 통과하므로 뒤의 적을 계속 공격한다. 직격 진입점에서도 방어하여 개별 피격 효과가 새는 것을 막는다.

플레이어 진영의 자동 공격은 지형 충돌/반사/가림을 유지하되 지형 HP를 깎지 않는다. 받침 파괴에 따른 낙하, 통 폭발, 연결된 낙하물/수문 피해를 아군에게 우회 적용하지 않기 위해서다. 이는 자동 공격이 지형 목표를 파괴하지 못한다는 의도적인 제한이며 직접 조준한 원탄/검술의 지형 공격은 유지한다.

## 독립 검토에 따른 경계 보정

부모 검수에서 자동 공격의 보호를 적 진영까지 넓히면 적 자동 자탄/소환의 민간인·objective·지형 위협이 사라진다는 문제를 지적했다. `protectedAutomaticAttack`을 별도로 두어 현재 소유/동맹 기준 플레이어 진영에서만 보호하도록 수정했다. 적의 직접/자동 공격을 중립·동맹·objective·적/플레이어 대상으로 각각 HP·밀치기·지형 HP까지 수치 대조했다. 부모 없는 저장의 side 0/1/2/미상과 적 소유 소환의 stale side:0도 확인했다.

직접 조준의 예외 경계는 두 가지다. 구 쌍월참의 두 crescent 원탄은 직접 공격이며 child 피해상한 플래그만으로 자동 공격으로 바꾸지 않는다. S12 중심탄은 기존 직접 조준·지형 충돌을 따르고, 별도 난수 궤도의 개별 회전 검에만 자동 출처를 전달한다.

단일 재실행 명령: `npm run test:autonomous-friendly-fire`. 이는 엔진 회귀와 `tests/autonomous-friendly-fire-save.mjs`의 실제 App export/import/Continue 6개(소환/연참/회전검 × 새/구 출처)를 함께 실행한다. App 검사는 DOM·저장소 대역을 사용하며 브라우저 검수로 표현하지 않는다. 저장 재개 후 적 피해와 보호대상 HP를 실제 공격 종료까지 확인한다.

### A03 자동 재조준 경계

연환시의 처음 직접 조준한 구간은 기존 아군 충돌을 유지한다. 첫 명중 뒤 다음 적으로 자동 재조준하는 순간부터 `autonomous:true`를 남긴다. 새 표지가 없는 이전 저장의 `mode:chainArrow`와 `chain>0`도 같은 출처로 읽는다. 적 소유 체인은 민간인·지형 피해를 그대로 유지한다. 실제 비행에서 첫 적–아군–다음 적 배치, 현재/구형 JSON Continue, 최초 조준 구간, 후속 장판·상태·밀치기·지형을 추가 회귀로 확인한다. 이 보완은 독립 검수자가 발견 후 직접 구현했으므로 다른 검수자의 별도 검토를 필요로 한다.
