# 2차 B: 동굴 전환 구간의 최소 보강

## 장소별 결정

- 11: 소나무 산길과 북쪽으로 높아지는 실제 지반을 유지한다. 주민 은행과 북쪽 암벽의 접지된 뒤쪽 바위 덩어리, 실제 바닥 안쪽의 넓은 절리면을 보강한다. 기존 능선 선택 발판과 목표 접점은 그대로다.
- 12: 채석장의 긴 상승과 동굴 입구를 유지한다. 입구의 실제 고체 암벽 내부에 큰 면과 중간 크기 층리를 추가한다. 낙석핀·사격 위치·복구 지반을 옮기지 않는다.
- 13: 열린 붕괴터에서 낮은 문으로 내려가는 실루엣을 유지한다. 문 뒤 낮은 갱도의 목제 작업 발판은 아래 필수 길과 같은 x 영역에 있으며 기본 점프로 오르고 반대편 바닥으로 돌아온다.
- 17: 중앙 인양 장비가 놓인 큰 작업장은 유지한다. 후반 기록 작업 통로의 실제 고체 천장만 낮춰 좁은 통로로 연결한다. 해당 목제 작업대에서는 바로 아래/오른쪽 기존 무리를 사격할 수 있다.
- 18·19: 종과 종을 받치는 양쪽 기존 암반·바닥·천장은 동일하다. 공통 왼쪽 사슬 작업대와 오른쪽 종지기 작업대를 더한다. 18의 제압 군집과 19의 기존 의식 혼 군집은 바꾸지 않는다. 같은 자리가 전자는 제압 접근, 후자는 천도 장소 사이 사격/이동 선택으로 쓰인다. 19장에 새 이야기나 확정되지 않은 인물을 추가하지 않는다.
- 20: 낮은 출구에서 열린 하늘로 나오는 구도와 호송길이 이미 목적을 충족하므로 원본 전체를 유지한다.

## 물리와 보존 범위

새 발판은 지지대가 있는 목재 one-way다. 고체 암봉이나 고체 천장처럼 양방향으로 탄을 막는 것으로 표현하지 않는다. 17장 천장은 실제 solid다. 미술 면은 실제 지형 안에 clip되며 별도 가짜 발판·충돌면이 없다.

필수 바닥·문·파괴 표적·주동선·목표·의식 반경·NPC·적 좌표 및 군집·파동·최소턴은 모두 보존한다. 신규 선택 발판에 적을 강제로 옮기지 않는다. 모든 추가 선택 경로는 점프 수련 없이 사용할 수 있다. 필수 이동에 새 기예 구매가 필요하지 않다.

원본은 `tools/map-forge/cavern-transition-layers.mjs`다. `design.cavernTransitions`가 표시된 맵만 빌드 시 후처리를 재적용한다. 기존 저장 전투 지형을 교체하는 실시간 마이그레이션은 추가하지 않았다. 장18·19의 비파괴 지형이 정확히 같음을 검사한다.

## 확인한 범위와 한계

- `node tests/cavern-transition-layers.mjs`: 원본 목표/배치/스토리/물리 조건 보존, 다른 장과20장 불변, 생성기 재적용 멱등성, 직렬화/재가져오기. 실제 공통 엔진으로 네 체형의 필수 보행28조건(기존 문/낙석 제거 뒤), 신규 선택 왕복24조건을 확인한다. 선택 점프는 기본 점프이며 체력 손실이 없다.
- `node tests/cavern-transition-shots.mjs`: 일곱 장의 기존/신규 선택 사격 자리14곳에서 기존 적을 대상으로 기본 활의 실제 발사·비행·충돌·피해를 확인한다. 테스트는 현재 적 편성을 바꾸지 않는다.
- `node tests/cavern-transition-required-shots.mjs`: 현행 유일한 필수 파괴 사격인18장 위쪽 사슬에 원래 서 있는 위치에서 기본 활 실탄이 명중하여105.24피해를 준다. 이전 개정에서 퇴역한 낙석핀을 현행 필수 목표로 되살리지 않는다.
- `node tests/cavern-transition-regeneration.mjs`: 원래2막 recipe부터 미술·장소 후처리·finalize를 거친 일곱 장이 canonical JSON과 정확히 같다.
- `node tests/act2-spatial-contracts.mjs`: 2막의 기존 목표 순서·의식/제압 분류·반경·스크립트·파동·적 능력·군집과 진행 저장 보존 계약13건을 통과했다.
- Native Canvas의 공통 Game/Workshop renderer로 전체/기본/모바일 구도를 캡처하고 직접 확인한다. 이미지 decode 완료를 기다리고 정적 캐시 canvas를 임의로 축소하지 않는다.

이 기록은 브라우저 HUD 정상 전투 완주, 연속 캠페인의 자원 난도, 모든 난도, 성능 또는 GitHub Pages 배포 검수를 대신하지 않는다. 필수 경로 검사는 제거 가능한 기존 장치를 열린 상태로 만든 격리 물리 검사다. 사격 검사는 선택 위치에 초기 배치한 단일 사수의 실탄 검사다. 테스트에 화면에 없는 아이템 명령을 사용하지 않는다.
