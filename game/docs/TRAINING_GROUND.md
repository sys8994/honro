# 허공터: 산기슭의 옛 수련터

범위는 자유 수련 월드와 공통 입력·메뉴·글꼴이다. 캠페인 지형, 이야기,
기예 수치, 진행 저장은 바꾸지 않는다. 원본은 `shared/runtime/world.js`의
`trainingWorld`이며 Game과 Playtest가 같은 번들을 사용한다.

## 지형과 표적

6000×2300 공간에 다섯 장소를 잇는다. 바닥은 외곽까지 이어지는 하나의
polygon이며, 별도 그림을 밟는 경로로 사용하지 않는다.

- 서쪽 마당: 시작점에서 500 이상 비운다. 사람 사수와 산개를 떨어뜨려
  평사·거리 조절·근접 접근을 비교한다.
- 무너진 단: 낮은 단→높은 단은 실제 one-way 목재다. 밑으로 통과하고
  위에서 착지하며 Alt/아래 버튼으로 내려간다. 뒷받침 목재는 공통
  `act1-spatial-art.js`의 접지된 열린 지지대이며 추가 충돌면은 아니다.
  단 위 사수·수의귀와 아래 멧돼지를 다른 각도에서 겨눈다.
- 바위 그늘: 암반 지붕은 동쪽 산체에 붙는다. 낮은 진입로의 바위 엄폐,
  천장과 안쪽 벽은 실제 고체다. 반사·투과 기예를 비교할 수 있다.
  아래 길은 막다른 사격 자리, 위 지붕은 서쪽 징검단으로 오르는 통과로다.
- 얕은 물굽이: 실제 경사진 바닥과 맞닿은 물 30 깊이, 양쪽 마른 둑을
  남긴다. 물속 혼령·산개와 마른 둑의 사슴으로 속성·설치 위치를 비교한다.
- 동쪽 빈터: 산개·상두꾼·수의귀·사수의 작은 혼합 군집, 방어력 .28의
  내구성 있는 정예 장승, 서로 다른 높이의 박쥐·까마귀·등불귀를 둔다.
  범위 공격, 공중 사격과 단일 정예 공격을 한 장소에서 바꿔 본다.

적은 초기 18체(공중 3, 정예 1), 실제 적 행동 상한 2다. 종류의 고유
기예·형/기/혼 방어 특성, 일반 발사·반사·물·발판 규칙을 그대로 쓴다.
표적 자동 재생성은 없고 명시적 다시 수련이 전장을 초기화한다.
동행/기예 변경은 현재 지형·적 HP·탄·소환물을 유지한다. 아군이 쓰러지지
않는 기존 연습 규칙과 일반 저장 격리를 보존한다.

공통 야외 벡터 재질·접지된 소나무/폐회랑·암면과 기존 1장 이미지 원경을
재사용한다. 허공터에 캠페인 기본 장식을 비율 배치하지 않는다.

## 공통 조작과 표시

Alt는 데스크톱에서 단독 누름을 떼었을 때 기존 `App.drop()`을 호출한다.
키를 떼기 전에 다른 키가 오면 취소해 Alt+Tab/브라우저 조합을 보존한다.
반복·AltGr·수정키·입력 필드·편집 영역·대화·모달·blur에서는 발동하지 않는다.
Ctrl 도약, 방향키 조준, F 방어, 전체화면 Escape 우선순위는 유지한다.

`tooltips.js`가 data-tooltip/data-shortcut과 중앙 행동 설명을 위임 처리한다.
동적 버튼은 별도 등록하지 않는다. 한 개의 비상호작용 tooltip을 현재
전체화면 루트에 두고 aria-describedby의 기존 연결을 보존한다. 내용은
textContent로만 넣으며 title 속성은 사용하지 않는다. 키보드 포커스와
마우스에서만 나타나고 모달 교체·DOM 제거·blur에서 정리한다.

일시정지는 먹색·변색된 황동·상아색과 각진 새김 프레임을 쓴다. 기예
아이콘을 교체하지 않고, 메뉴에만 길/부적/회귀/모닥불/화면 SVG 표식을 둔다.
기록 삭제는 별도 경고색 확인 동작으로 구분한다.

Noto Serif KR 가변 outline을 자체 호스팅한다. 모든 한글 음절·자모와 원본
문자 범위를 보존하고 자주 쓰는 한글은 공통 subset으로 묶는다. 제목·본문·
숫자 토큰을 구분하며 실제 weight를 쓴다. 출처·OFL·재생성 도구와 문자
목록은 `shared/assets/fonts/noto-serif-kr/`에 있다. font preload는 없다.

검증은 `tests/training-layout.mjs`의 네 체형 연속 이동/실탄과
`tests/training-ui-browser.py`의 실제 입력·저장 격리·tooltip·메뉴·글꼴을
사용한다. 연속 이동 검사는 여러 턴 분량 이동도를 명시적으로 부여한
지형 진단이며 정상 전투 완주 증거가 아니다. Linux Chromium 100%/125%
본문 화소를 확인하되 125%는 CSS zoom이며 Windows rasterization은 미확인이다.
