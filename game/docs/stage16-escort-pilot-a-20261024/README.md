기준/롤백: `008b3a121565a08c0ef667b3461374ba9dd6a637`. 이 브랜치의 시범 변경 커밋을 revert하며 옛 코드를 실행 폴백으로 남기지 않는다. 신규 진입에만 `honroTempleEscortRevision:1`을 저작한다. 기존 전투 스냅샷·지형 revision·프로필 스키마는 변경하지 않는다. 롤백 후 추가 상태는 사용하지 않는 메타데이터이며 기존 구조/문/기록 완료 ID를 유지한다.

확정 흐름: 구조 → 같은 쉼터의 증언/열쇠 → 두 승려의 실제 보행 → 법당 툇마루 → 문 열기 → 방 안 기록함 접근 → 기존 기록 대화. 증언의 승인된 휘겸 한 줄과 guide만 추가하며 기존 rowId/대사는 보존한다. 목적지는 기존 법당 `(5650,4250)`, 기록함은 같은 법당 안 `(6200,4250)`으로 옮긴다. 기존 쉼터의 우측 출구와 참배길을 사용한다. 적 수/처치/고정 턴/안전 반경은 조건이 아니다. NPC 기존 속도/이동 자원, 몸과 지형 충돌, 막힌 목적지의 근처 합법적 자리 선택을 사용한다.

새 단계는 기존 evidence/afterEvidence 형식이므로 롤백한 런타임도 신규 세이브의 추가 목표를 처리할 수 있다. 검사/실제 입력 전략 및 화면 근거는 완료 후 기록한다. 6–12턴/최대15턴은 목표이며 강제 타이머가 아니다. master/Pages는 부모가 검토·반영한다.

## 경로 교정

몸을 피해 도약하다 기존 서회랑에 올라간 경우 서회랑 계단/누마루를 따라 실제 이동해 법당 측면 발판 끝에서 내려온다. 하단 출구의 부동소수점 좌표에 멈추지 않도록 보행 도착 허용 오차를 사용한다. 일반길/서회랑/출구 경계 3개 물리 fixture가 실제 이동으로 모두 도착했다. 라운드 직접 진행을 사용하는 이 검사는 통상 전투 완료 턴 증거와 구분한다.
