### 보완 후 최종 전열 결과와 한계

최종 `4d53f8ce` 런타임에서 이전과 같은 전열 우선 입력기로 **22턴 승리**했다. 구조/증언 12턴 → 두 승려 도착 19턴 → 문 20턴 → 기록 22턴이다. 13레벨/27SP 입장 준비 후 배우 위치·HP·기력·이동량·목표를 조작하지 않았으며, 사망 0/소비품 0이다. 방어 입력은 전체 23회(구조 전14, 피신 중8, 기록 단계1)였으며 강제 대기 목표는 없다. 피신 중 실제 적 몸/교전으로 기다린 구간이 있었고, 17턴 노승은 `(5285,4170)`의 적 몸 위에 접촉한 상태였다가 진로가 열린 후 19턴에 실제 툇마루에 도착했다. 노승 HP1578/1900, 제자 HP902/950으로 생존했다. 서회랑 x3440의 이전 영구 정체는 재발하지 않았다.

검사 입력기에서 휘겸의 기존 측면 회랑 경로 계산이 20턴에 한 번 막혔지만 다른 동행으로 실제 문/기록 입력을 이어 22턴에 완료했다. 이것을 NPC/게임 소프트락으로 처리하거나 범위 밖 전역 경로를 수정하지 않았다. 이벤트 데이터는 그대로여서 늦은 진행에서 기존 구조/기록 반응과 hold-hall-0 증원이 발동했고, 새 웨이브는 저작하지 않았다.
