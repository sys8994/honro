# 혼로 미술 검수 v3

**필수는 승인 조건, 참고는 원인 분석과 조정용이다.** 기본은 풍부하고 일관된 화면이며 노드·폴리곤·장식 수로 품질을 판정하지 않는다. 아래 수치는 설계 목표이고 실측 전이다.

| 대상 | 필수 | 참고 |
|---|---|---|
| 자연 지형 | 긴 직선 기본 **20% 미만**, 절대 **30% 미만**. 직선에도 경사·단차·고저 변화. 상면·천장·하부 각각 확인 | 다중스케일 굴곡·곡률·길이비. 톱니로 수치만 높였는지 진단 |
| 화면 구성·스타일 | 불필요한 공백을 큰 지형·게임 요소·근경·장식으로 구성. 일관된 윤곽·명암·색감의 실제 이미지 승인 | 형태 anchor·영역 커버리지·공백 면적/폭·명암면·색 분포 비교 |
| 시안 재현 | 주요 형태와 눈·입·접점·출입구 등 의미 보존, 주요 윤곽 최대 오차 **2 CSS px 이하** | 큰 형상 IoU 0.98, 색·에지 차이. 질감의 픽셀 복제는 요구하지 않음 |
| 최적화 보존 | 불변 raw 대비 외곽 **1.5px 이하**, 보호 부위 **0.5px 이하**, 중요한 요소 소실 **0개** | RGB MAE·IoU·SSIM. 전체 평균이 좋아도 의미 손실은 탈락 |
| 부품 연결 | 접합 틈·콜라이더 접촉 오차 **0.5px 이하**, 보이는 틈·겹침·색 단절 **0건** | 동일 재질 이음의 OKLab L 차 0.03, 속성·법선·카메라 소수점 위치 진단 |
| 런타임 | 현행 엔진 안전한도 tree **512**, depth **24**, path d **60,000자** 이내. 실제 화면·조작 정상 | PC 16.7ms/모바일33.3ms p95 목표, 파싱·첫 렌더·warm 프레임·메모리·bytes |

참고값 하나가 범위를 벗어났다는 이유만으로 자동 반려하지 않는다. 다만 실제 가독성·진행·의미 보존·프레임 정지 같은 결함을 참고 항목이라며 통과시킬 수 없다. 특정 장의 핵심인 참고 지표는 제작 전에 해당 장 필수로 지정할 수 있다.

## 수치 과적합 방지

1. **단계별 화면:** 시안 실루엣·명암·컬러 → Inkscape → 최적화 → 실제 게임을 찍어 확인한다.
2. **숫자 숨긴 비교:** 숫자를 보지 않고 기준판과 후보의 자연스러움·풍부한 구성·스타일을 독립 평가한다.
3. **다른 시점:** 튜닝에 쓰지 않은 카메라·줌·화면 크기로 다시 본다.
4. **검수도 시험:** 톱니 윤곽, 잔장식 살포, 과밀 하부로 평평한 천장 숨기기, 제외 마스크 늘리기 등이 실제로 탈락하는지 확인한다.

꼭 필요한 시야·조준·동선만 사전에 범위를 지정한다. 미완성 공백을 나중에 의미 있는 여백으로 면책하지 않는다. 같은 품질의 합격 후보 중 비용이 낮은 안을 채택하고, 최적화 때문에 형태·인상이 무너지면 탈락시킨다.

**PASS:** 적용 필수 전부 통과 + 실제 크기 이미지 승인. **FAIL:** 필수 미달·의미 파손. **미완료:** 필수 미측정·근거 없음. 참고 경고를 해결하려 디테일·노드 수를 무작정 늘리지 않는다.
