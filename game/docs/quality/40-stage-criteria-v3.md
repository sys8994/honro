설계 목표 · 실제 플레이 통과 전. 필수 기준은 다른 수치로 상쇄하지 않는다.

## 전체 곡선

HTML에서 필수/참고 지표와 막을 선택해 40장 목표 범위를 비교한다. 모든 장 목표 상한 20턴은 강제 패배 타이머가 아닌 설계·검증 예산이다. 선은 구간 중심, 음영은 목표 범위다. 실측값과 합산 난이도 점수는 없다.
