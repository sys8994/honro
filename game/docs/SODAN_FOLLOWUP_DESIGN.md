# 소단 후속 수정: 궤적·소환령·허공터·BGM

2026-10-01. 기준 작업은 `cdbe82f` 이후이며 게임과 Stage View/Playtest는 같은 번들을 사용한다.

## 원인과 적용 규칙

- 만혼귀결의 대표탄은 3.2초 뒤 예측점으로 순간이동했다. 저속으로 멀리 쏘면 화면 속 혼령은 중간에서 사라지고 피해는 먼 곳에서 시작했다. 기본 발사·예측·실제 비행이 `Engine.velocity()`와 `advanceProjectile()`을 공유하며, 만혼귀결의 속도 계수는 0.93→1.55다. 충돌 또는 2.25초 공중 귀결 중 먼저 일어난 위치에서 귀결한다. 이전 저장의 비행탄에 시한 필드가 없어도 현재 보이는 자리에서 귀결한다.
- 초혼의 공중 시전 시점은 등불귀 외에 없어 예측선이 전장 밖까지 이어졌다. 공중 시전 초혼은 충돌 또는 1.45초에 발동하고 예측과 실제가 같은 시한을 사용한다. 이후 HBUG-061에서 배회령은 예외로 지형 충돌에서만 발동하고, 궤적은 네 동행 공통 점선으로 통일했다.
- 현행 플레이어·적/NPC 투사체 기술 118종은 공통 초기 속도 경로를 사용한다. 동맹의 기본 발사도 같은 `Engine.velocity()`를 사용하며, 보조탄·유도탄·돌격·파동은 의도된 별도 이동 규칙이다. 활성 코드에서 `velocity`/`stepProjectile`을 덮어쓰는 패치는 발견되지 않았다. 광범위한 발사 속도 변경 대신 확정된 불일치만 고쳤다.
- 허공터는 설정 적용 때 `launch()`로 월드를 재생성했고 첫 떠도는 혼 근처 x=1840–2000에 숨은 상승 기류가 있었다. 기류를 없애고 조작 영웅만 바꾸도록 했다. 적·소환령·진목·비행탄·카메라·음악 세션은 유지된다. 명시적 리셋만 월드를 재생성한다.
- 먹귀 흡인 반경은 `200 + 경지×15` 월드 단위이며 같은 수치로 얇은 점선을 그린다. BGM 5번은 10장의 우두머리가 깨어난 경우에만 쓰고, 월드맵에서 새 전투를 시작하면 선택된 전투곡을 처음부터 연주한다. 같은 저장 전투를 재개하면 이어 듣는다.

## 소환령 시각 설계와 반복

기존 배회령(수의), 등불귀(행등), 돌격귀(목탈), 호혼령(장승), 문지기귀(창호)에 먹귀(귀면와의 벌어진 입), 반향령(쌍으로 접힌 종이 인형), 지박령(부적과 뿌리가 얽힌 제의 기둥)을 더했다. 새 세 종은 벡터 카탈로그에 없어서 기본 영체 그림으로 떨어졌으며, 이제 각각 독립 리그와 대기·이동·공격·피격·낙하 동작을 갖는다.

도상 참고: [국립민속박물관 《신들이 사는 마을》](https://www.nfm.go.kr/user/planexhibition/home/20/selectPlanExhibitionLView.do?planExhibitionIdx=991), [국립민속박물관 무속·부적 자료](https://efw.nfm.go.kr/service/book/theme/133/11), [국립중앙박물관 귀면와](https://www.museum.go.kr/MUSEUM/contents/M0502000000.do?relicId=149517&schM=view&searchId=search). 외곽·재료의 착상만 참고했으며 소장품 이미지를 복제하지 않았다.

1차 256/128/96/64px 검수에서 먹귀의 둥근 눈과 어깨가 귀여운 가면처럼 보였다. 2차에서 비대칭의 깊은 눈구멍, 기와 균열, 찢어진 소매·발톱을 더했고, 실제 허공터 화면을 보고 실루엣 높이를 120으로 키웠다. 반향령의 좌우 종이 날개와 지박령의 뿌리는 64px에서도 기존 다섯 종과 구분된다. 크기별 그림·동작 시트는 `_local/reports/actor-forge/`, 전투 화면은 `_local/reports/game-eater-training.png`와 `_local/reports/playtest-eater-training.png`에 둔다.
