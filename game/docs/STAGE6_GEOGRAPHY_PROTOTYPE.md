# 6장 지형 회색 상자 — 실험, 배포 불가

기준 런타임은 6장 추격 브랜치, 대상은 기존 구조·교각귀·운반대·출구를 보존하는 비대칭 지리다. 현재 지형 원본은 `tools/map-forge/stage6-positioning.mjs`와 Stage6 BODY 자산이며, 예전 이미지 지형 문서는 현재 원본이 아니다.

스켈레톤: [기존 지형과 비대칭 후보 비교](stage-review/stage06-bridge/geography-prototype/skeleton.png).

## 동선과 검증 가설

- 시작 고지 y 약1830에서 서쪽 긴 사면과 얕은 암반 어깨를 내려가 구조 저지대 y 약3300을 지나, 동쪽 경사로 출구 y 약2500으로 이어진다. 서·중·동 파손 교판은 기존 높이와 서로 다른 길이/틈을 유지한다. 서교판은 공중 적과 교각귀를 노리는 선택 엄호 위치, 하부는 목표 접근과 운반대 보호다.
- 실제 충돌 회색 상자 노드: (0,1770), (550,1870), (1250,2050), (1700,2220), (1950,2240), (2350,2550), (3000,3170), (3500,3300), (4100,3270), (4700,3090), (5350,2800), (6600,2450). 단일 연속 지면의 후보이며 확정 원본이 아니다.
- 세 영웅의 하부 전구간과 서교판 왕복 후 구조점까지의 격리 Engine 경로에서 전 프레임 지지 고도차 1429–1469, 피해 0이었다. 하부 순수 이동은 약 4.5–5.1 행동 예산이다. 서교판에서 즉시 낙하하면 9–13 피해가 관측되어, 서쪽 사면으로 돌아내려오는 무피해 대안을 검토했다. 검사는 적·실제 파티 경쟁·연속 캠페인을 포함하지 않는다.
- 준비한 지지 포즈와 실제 projectile에서는 서교판→까마귀 128, 서교판→교각귀 92, 하부→교각귀 92 피해가 가능했다. 비대칭 후보에서 상부·하부 교각귀 피해는 같았으므로 상부 우월성을 주장하지 않는다. 이는 준비 포즈 한 구성의 가능성이지 인간 재미의 확정이 아니다.
- 준비한 선두 위치를 따라 기존 Mission이 운반대를 x4100→6440까지 이동시키며 새 하부 지면에 맞췄다. 준비된 목표 상태에서 교각귀 생존 중 종료 불가 및 제거 후 완료 가능을 확인했다. 정상 상호작용/출구 증거는 아니다.
- 기존 수면 y2980은 변경 바닥에 부정합이다. 평평한 저지대 x3385–4100, 수면3270·최대 깊이30의 후보를 적용한 격리 이동에서는 세 배우 모두 통과했으나 실제 렌더·전기·호송 전투는 미검증이다.
- 준비한 시작 지형/배우 + 이후 실제 App 입력의 한 seed에서 기존 행동 슬롯 수를 늘리지 않고 추격 1체가 R4 운반대에 42 피해, 휘겸이 대응했다. 이는 동적 지형 주입 fixture이고 완성된 소스의 정상 연속 플레이가 아니다. 실제 전프레임 지지 고도 확인과 다수 정책·seed가 남았다.

## 저장·미술·남은 조건

지형 배포 후보가 생기면 6장 전용 campaign map revision을 3에서 4로 올려 구 6장 진행 중 전투만 재시작하고 성장·장착·SP·클리어와 Workshop/타 장을 보존한다. 변경 전 저장·같은 revision 재개를 실제 경계에서 확인한다.

현행 BODY 후보는 지형 원본 hash를 검증하므로 기존 그림을 억지로 늘리거나 검증을 우회할 수 없다. 확정 스켈레톤을 바탕으로 비대칭 암반과 불균등 파손 교각을 재저작하고, 실제 교판 상면·지면 접촉과 렌더를 Inkscape 원본부터 검증한다. 참고 이미지의 대칭 그릇형 지형·동일한 교각 배치는 채택하지 않는다.

적 실제 배치·동선, 사격/엄폐, 추격 경고·대응, 물과 낙하, 구조/출구, 저장, 데스크톱/모바일 시각, 최종 통합 소스의 실제 App 플레이와 원문 v3 cohort/holdout은 모두 미완료다. 이 문서나 스케치만으로 지형·재미·배포 합격을 선언하지 않는다.
