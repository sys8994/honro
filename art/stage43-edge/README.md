### Trace option correction (2026-11-16)

The earlier `HONRO_TRACE_SMOOTH` experiment accidentally changed **stack**, not smoothing: the old action was `8,true,${SMOOTH},false,4,${CORNERS},0.2`. Official Inkscape 1.4 order is `scans,smooth,stack,remove_background,speckles,smooth_corners,optimize` (`src/actions/actions-object.cpp`). Earlier v1/v2 comparisons must not be cited as a pre-smoothing-off experiment. The helper now independently controls smoothing and stacking, defaults to `16,false,true,false,4,0,0`, and the stage43 angular study uses 8 scans. Optimize tolerance 0 is not a disable switch; Inkscape still enables curve optimization internally. `tests/stage43-trace-settings.py` prevents recurrence. This tooling fix is not art approval or release approval.
