# 초상화 변형 32조합 · 2026-10-24

기존 미제작 목록의 주인공20종과 주민12종, 총32개 identity/expression 조합을 제작했다. 승인된 주인공 원본과 현행 NPC 게임톤 원본에서 각각 독립 생성했으며 변형본을 다음 변형의 참조로 누적 사용하지 않았다. 새 이미지 세션 격리를 확인했다고 주장하지 않는다.

각 결과의 얼굴·나이·의상·화풍·감정/동작·손·머리/갓 여백을 직접 확인했다. 휘겸 concern 첫 출력은 갓 상단 여백 부족으로 제외하고 원본에서 다시 생성한 v2만 포함했다. 전32개1024×1536 RGBA와 실제 투명 픽셀 존재를 검사했다. 반복 마이크로텍스쳐를 억제하는 표준 프롬프트를 사용했다.

[manifest](manifest.json)에 identity/expression,원본PNG hash/bytes,참조 경로를 기록하고 prompts/에 각 요청문을 보존했다. 이미지 바이트를 후처리로 다시 그리거나 인코딩하지 않았다.

현재는 이미지 제작·검수 결과다. game/config의 ready registry,런타임WebP,얼굴크롭은 아직 연결하지 않았으며 게임에 적용됐다고 표시하지 않는다. 연결 시 같은 기존 expression ID에 등록하고 승인base를 덮어쓰지 않으며, 실제 모바일 대사창/허공터/모닥불과 갓·손 크롭 및 캐시 확인을 별도 수행한다. 모든32장을 인트로에 선로드하지 않는다.
