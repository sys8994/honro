# 사용자 제공 외형 레퍼런스 기반 초상화

2026-10-22. 사용자가 새로 첨부한 260915_설오/담허/휘겸/소단 설정 시트를 얼굴·분위기·표정 참고로 사용했다. 복장은 현재 게임의 설오 올리브/아이보리, 담허 갈색/아이보리, 휘겸 먹색/암적색과 검은 갓, 소단 아이보리/보라·붉은 매듭으로 정리했다.

사진 질감과 조밀한 의복 장식을 줄인 2D 게임 초상화 후보다. 1024×1536 RGBA 원본이며 얼굴·옷·머리의 실제 픽셀과 알파 채널을 확인했다. 별도 배경 합성·게임 UI 연결·표정 확장은 하지 않았다. 사용자 미승인 시안이며 master/실제 게임에는 적용하지 않는다. 이전 graphic-game-v1과 다른, 사용자가 제공한 최신 레퍼런스에 따른 후보군이다.

이미지는 직접 이미지 생성으로 제작했다. 원본 설정 시트는 입력 자료이며 이 폴더에는 복제하지 않았다. prompts.json은 이 후보들의 재현용 제작 지시다.
