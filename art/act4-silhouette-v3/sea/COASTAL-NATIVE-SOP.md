# Coastal native-vector production checklist

1. **Audit physical role before painting.** Inventory every authored terrain and instantiated collision. Resolve visual ownership by actual element, sourceAssetId or explicit collisionSource, not names alone. Check full-stage overview for uncovered engine primitives. Do not paint invisible triggers/water/recovery volumes as solids.
2. **Budget pixels for play.** A92-world actor should occupy at least25–40sourcepixels. Separate gameplay-focus source regions from camera-visible far/deep opaque continuation. A19k-world panorama at2kpx is not a usable gameplay-outline source. Keep each stage's actual macro route; split sources with planned joins rather than stretch one generic stone strip.
3. **Generate by role.** Playable material gets medium-scale authored silhouettes and a readable narrow contact edge. Interior strata are broad and sparse. Rear scenic objects have fewer/closer color planes; foreground reeds are darker/desaturated but preserve blade outlines and actor apertures. Characters/HUD are not dimmed by a global filter. Dawn is soft bluegray, not black night.
4. **Trace in the actual native tool.** Save embedded reference and actual Inkscape SVG. Verify Colors mode, scan count, Smooth/Stack/remove background, speckle/corner/optimization settings in current UI. Wait for document/UI state changes before further input. A mistaken trace is discarded, never relabelled. Record actual saved path count and source SHA.
5. **Optimize with protected structure.** Keep outer gameplay silhouette, semantic small details and compound-hole winding. Remove only explicitly budgeted tiny interior components; merge adjacent noisy gradient-quantized color planes when their interior detail hurts hierarchy. Quantize serialized controls with a stated geometric error bound rather than bypass engine path limits. Use structured parse/serialize, never regex surgery on implicit SVG commands.
6. **Fit truthfully.** Correct macro-anchor drift while retaining authored interval contours; use the same sampled top for bank collision. Architectural planks/stone use actual slope/flat panels, not many tiny warps that read as cloth. Bound top error in world units. A one-way visual underside is not a substitute for its real walking top. Material, HP and indestructible flags are explicit; authored HP may compile to a sentinel and must be reported distinctly.
7. **Engineer solid coverage separately.** Native art must be opaque over actual camera-visible solid, verified source-only with no engine base hiding gaps. Deep opaque continuation draws BEHIND native artwork. Normalize only artificial export-edge closures; regression must prove protected interior controls and collision outline unchanged. Sparse ~1px residual AA is documented, not used to conceal missing masses.
8. **Occlude approach ends correctly.** Ground-entering wood/wall ends render before the opaque BODY (or receive a mask derived from the exact soil contour). Do not change walk geometry merely to bury a visible hanging blade. Never use unrelated revision flags to suppress paint.
9. **Inspect actual whole frames.** Normal, mobile-size, full-stage and actual actors standing/contact/boarding all matter. Fixed initial overview with airborne entry actors is not contact proof; a native canvas fixture is not a browser/FPS or linked-campaign proof. Inspect source concept beside actual output, not source-only art approval.
10. **Freeze and prove.** Bind image, source, complete compiled colliders, input tape and runtime hashes. If paint-only changes, prove full physical equality; do not inherit art approval or rebrand old images. Fresh gameplay/boarding/camera contracts must pass changed geometry with legal ordinary inputs, preserving old failures separately. Deliver scoped stage/ownedAssets plus hash-guarded shared references; one integrator writes main world/runtime and publisher alone pushes/deploys.
