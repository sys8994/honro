# 전체 시안 v2 · 구조 비교 중

구조 입력 `structural-guide-v3.png`와 기존 style-board를 image_gen에 실제 첨부했다. 서로 다른 중앙 나무 길·돌목·최하단 복귀로와 왼쪽 상여 앵커가 v1보다 분리되어 읽힌다. 이 이미지는 미술 구상이며 최종 배포 에셋·사용자 승인·충돌 정합 통과가 아니다.

남은 문제: 사격 바위가 직각 계단 기둥처럼 읽히고, 상부 나무 길도 단순 각진 보처럼 보인다. 실제 접촉선과 발판 끝은 유지하며 비보행 측면·하부를 침식된 바위/뿌리로 편집해야 한다. 보행 주변 일부 큰 암면은 배우 크기로 다시 비교한다. 전체 그림을 그대로 추적하지 않고 아래 지질·나무 지지/가지·사격바위·상여를 의미별로 분리 제작한다.

이 시안을 이유로 검증한 collision 좌표를 바꾸지 않는다. 레이어 제작 전에 구조 앵커와 실제 보행 카메라의 저비용 합성으로 차이를 재확인한다.
