# 전체 시안 v1 — 구조 불일치로 반려

전체 장 후보 B의 실제 proxy guide·style-board·높은 절벽 참고를 built-in image_gen에 전달했다. 출력은 `overview-v1-rejected.png`. 최종 장면/벡터화 입력으로 채택하지 않는다.

직접 확인한 문제:

- 중앙의 별도 상부 측면선과 아래 돌목을 하나의 큰 아치로 합쳤다. 두 통과 높이와 낮은 복귀 경로의 선택을 보존하지 못했다.
- 상여틀을 가이드보다 오른쪽으로 옮겼고 원래 상여 proxy가 별도 작은 바위로 남았다. 서술과 실제 차폐의 좌표 일치가 깨진다.
- 사격바위4단이 자연단차로 다듬어지는 과정에서 계단 수/상단 접촉선이 변했다. 실제 점프 검증의 지형과 같지 않다.
- 원경/공간·뿌리 지지는 읽히지만, 장 전체를 이대로 벡터화하면 검증한 게임 구조를 바꿔야 한다. SOP대로 시안 단계에서 수정하며 충돌을 그림에 맞춰 몰래 바꾸지 않는다.
- 큰 아래 암면은 깊은 지반에 둘 수 있으나 접지 주변 일부는 배우보다 커 보인다. 보행 배율에서 별도 비교가 필요하다.

다음: 두 층 접촉선·상여 앵커·사격바위 단차를 더 분명한 구조 가이드와 부분별 편집으로 고정하고 재생성한다. 이 실패를 보존한다. 단색/가짜 지형으로 결함을 덮거나 자동 검수 통과로 표시하지 않는다.
