# Natural stage-39 tide bark after host isolation

Source commit `7fcbe131` gives Act 4's subtitle its own node. Previously `P.observe` rendered and recorded an Act 4 bark in `#banter`, but `HonroStoryBarks.tick` later hid that same node when its separate reviewed-story queue was empty. The previous game receipt therefore did not establish that the bark survived a frame to be painted. A prior failed natural capture is retained at `../tide-natural-capture-attempt/`.

These are actual headless Chromium runs continued from the same game-generated round-one checkpoint in `../entry-v2-upper-proof/`, with normal keyboard/mouse inputs; no q.bark, seen, timer, proof or receipt was injected. The game naturally observed the water and upper path and displayed `설오 물이 올라옵니다. 높은 쪽으로 가세요!`. Desktop 1440×900 DPR1, portrait 390×844 DPR3, and landscape 844×390 DPR2 recorded actual painted-screen PNGs and per-animation-frame visibility intervals of 3.333, 3.467 and 3.367 seconds respectively. Text is 15 CSS px; bounding boxes do not intersect the minimap, reward button, battle header or bottom HUD. The portrait placement is below the reward button and the speaker name does not wrap. A subsequent real right movement moved the actor 51.6, 40.4 and 37.6 world units respectively. These are measured browser runs, not physical-device tests, full mission completions, or proof that every Act 4 bark has been visually reviewed.

`result.json`-style files and compressed full action/observation logs preserve the state. `tools/qa-stage39/check-tide-bark.py` checks duration, size, HUD non-overlap and following input; `fullplay-20.py` records the read-only visibility measurements. The pre-existing common `#banter` is still owned by the reviewed-story implementation; the new node is scoped to Act 4 and hides when its bark ends. `tests/act4-stage35-blocked-shot.mjs` also verifies the old common node can be hidden without hiding the Act 4 node, along with the existing 35 draw, once and restore guards. A first diagnostic callback deadlocked by attempting a nested Playwright screenshot; it was interrupted and the screenshot was moved to the main loop, so it is not counted as a game failure.
