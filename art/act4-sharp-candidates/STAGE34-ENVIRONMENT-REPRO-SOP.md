# 34장 환경 접합 — 재발 방지 규칙

1. **실제 Chrome과 레이어 분리로 원인을 좁힌다.** BODY/신규 환경/원경을 각각 숨긴 증거를 남긴다. Native 합격·engine 접지 true만으로 미술/발밑을 합격 처리하지 않는다.
2. **좌표와 보호 대상을 구분한다.** source/world/screen 단위, 원래 배율과 등록 변환을 기록한다. 보행 높이·실루엣·발·목재·배우·충돌·서사를 보호하며, 임시 y1400 같은 숫자 때문에 새 절단을 만들지 않는다.
3. **기존 잘못된 색절단은 보호 대상이 아니다.** 실제 발/길을 그대로 두고 비플레이의 자연면 전체가 이어지게 교정한다. 단색 띠·사각 패치·끝점을 위로 옮기는 cap·sprite offset으로 숨기지 않는다.
4. **참조 기반 미술 수정 → 실제 Inkscape → 검수 순서를 지킨다.** 원시안·원본·raw trace를 보존한다. 그라데이션/중간색 띠가 늘면 색 수를 무조건 늘리지 말고 큰 평면색으로 정리한다.
5. **투명 RGB와 alpha는 별개다.** 숨은 RGB는 nearest-opaque로 확장하고 alpha는 독립 추적한다. 흰 path 일괄 삭제나 nearest 고해상도 복제로 pixel stair를 해결했다고 하지 않는다.
6. **색 component를 자연면으로 오인하지 않는다.** crop으로 닫힌 경로·compound·색별 구멍은 독립 자연면이 아닐 수 있다. 전체 면의 바깥 경계와 내부 색 union을 함께 본다.
7. **외부 mask를 바꿔도 내부 clip을 보존한다.** alpha만 아니라 전체 색상 노출도 확인한다. 새 경계 양쪽 색과 모든 끝점을 실제 합성에서 검수한다.
8. **Boolean 결과는 단독 투명 렌더로 검증한다.** 아래 불투명 층이 큰 hole을 가릴 수 있다. visible-color는 모든 상위 색층을 차감한다. `12−13`이 `12−13−14−15`와 같다고 가정하지 않는다.
9. **source→raw / raw→final / 의도적 미술 교정을 분리한다.** AA peak 위치를 직접 보고 기하 손실과 구분한다. 수치를 맞추려고 의미 있는 형태를 침식하거나 원래 없는 구슬 색섬을 영구 보존하지 않는다.
10. **한 crop 합격으로 끝내지 않는다.** 실제 최소/일반/최대 배율과 전체 가로·세로 pan, 양측 연결, 기존 성공 영역을 재검수한다. 이번에는 46뷰+25뷰를 사용했다.
11. **모든 긴 선을 결함으로 보지 않는다.** 원색면의 자연 절리/옆면 음영인지, 길을 자르는 T접합/클립 끝인지 근거로 구분한다. 원래 facet apex 때문에 새 시안을 무한히 만들지 않는다.
12. **최적화는 경로·byte·비용으로 측정한다.** 경로 문자열 분할은 노드 감소가 아니다. 비관여 subpath 제거 시 원문·holes·opacity·clip을 보존하고 변화 히트맵을 검수한다.
13. **무의미한 bit 차이 때문에 불필요한 경로를 남기지 않는다.** 1afe는 565개 subpath를 제거했고 71뷰 차이는 7픽셀/max1, 보호·alpha 변화0이었다. 의미 손실 없는 AA 차이는 명시적으로 검토한다. 단, 다른 렌더러의 동일성으로 확대하지 않는다.
14. **지원 포맷 전체를 파싱한다.** `d`뿐 아니라 `dParts`, 필요시 use/symbol도 처리하고 path/segment 총량을 독립 inventory와 대조한다. dParts 누락으로 나온 숨은 경로0개 결론은 철회했고 실제22개/75segments로 정정했다.
15. **명령 성공은 exit0만으로 판단하지 않는다.** 실제 산출물·hash·path 수·로그를 확인한다. 미실행/불확실 결과와 실패는 보존하고 근거 없이 같은 작업을 반복하지 않는다.
16. **전달과 승인을 분리한다.** exact candidate SHA, 기반/런타임 hash, 압축 왕복 검증, 보호/미검증 범위를 manifest에 기록한다. Native cold/warm은 실제 Chrome 성능·전투·미션 합격이 아니다.

원본/기각안/대형 PNG는 로컬에 보존한다. 최소 원격 패키지에는 선택된 소스·실제 추적·실행 가능한 최종 조립 상태·명령·hash·이 규칙만 보존한다.
