수직 수문과 목재 문짝/철제 가이드, 정비실의 후면 벽체와 하중을 받는 아치, 권양 드럼과 멈춤목 보관대를 추가했다. 서쪽 전망대의 낮은 석대는 양쪽 기본 보행으로 올라갔다 돌아올 수 있는 사격면이다. 기존 다섯 진목 연결·관찰창·필수 현장 조사·7적·파티·목표·구역·낙하 복구 로직은 보존한다. 단순 발판 수/맵 크기 증가는 하지 않는다.

Native PNG는 실제 공통 게임 렌더러의 출력이며 브라우저 캡처와 구분한다. 브라우저/정상 자원 전투 검사는 별도 상태다. 새로운 일반 진행 저장을 만드는 코드는 변경하지 않았으며 기존 저장 지형을 교체하지 않는다.
