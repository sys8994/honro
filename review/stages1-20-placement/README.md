# 3장 나루 배치 전후

같은 카메라(x=2150, y=950, scale=.3), 같은 참가 동행과 지형에서 비교한 Chromium 실제 renderer 화면이다. 기존 생성 번들에 같은 profile로 만든 전후 Native battle을 전달했다. 정상 연속 도달·완주나 배포 후 입력 검증을 뜻하지 않는다.

- `stage3-ferry-before.png`: 잔교부터 창고 앞까지 이어진 공중 줄.
- `stage3-ferry-after.png`: 서쪽 정찰은 유지하고 clone 두 체를 잔교 끝의 낮은 견제·높은 측면 엄호로 모았다.
- 초기 적 13명·행동 상한 3, 지상/지붕 수비·장부·휘겸 합류·지형·능력·증원은 유지한다.

좌표·교전 확인·7개 장 전체의 변경 범위는 [배치 교정 기록](../../game/docs/STAGES1_20_PLACEMENT_REPAIR.md)을 참고한다.
