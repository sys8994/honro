# 휴식터 공통 벡터 통합 캡처

2026-10-20, 로딩 개선 master `2014aa4c57c4a4deb579863fdea87cfb7c08f2d1`에 휴식터 소스 `c3f1bd35de6f209f5f51722e41defcab27b85f6c`만 통합한 빌드다. Library 첨부는 업로드 도구 연결의 네트워크 오류로 생성 전에 실패하여, 부모가 승인한 저장소 캡처 대안을 사용했다.
