## 검사와 한계

- `contracts.json`: 다른29장 정확히 동일, 반복 저작 동일, 목표/편성/파동 계약 유지, 자연 초기 접지, 4체형×두 경로 왕복 통과. 왕복은 적 없는 열린 문 경계의 **유한 이동 예산 지형 격리 검사**다. 초기 분기에서 아래 길을 가려도 위 경사로로 끌려가던 결함을 발견해, 위쪽 진입을 짧은 기본 점프로 분리한 뒤 재검사했다.
- `resume.json`: 생산 App export/Continue로 옛 맵·새 맵의 전체 전투 스냅샷이 정확히 보존된다. DOM/저장소 대역을 사용했다.
- `goals.json`: 완료된 봉인·출구 도착을 명시 주입한 계약 검사. 기록 자동 확보, 두 출구 각각 한 사람으로 완료, 다른 동행은 멀리 있고 적은 살아 있는 상태를 확인했다. 정상 완주 증거와 구분한다.
- `shots.json`: 다섯 군집 각각 지지된 근접 시험 위치에서 기본탄 예측과 실제 피해 일치. 위치·대상 격리 fixture다.
- `browser.json`: Game/모바일/Workshop 총9장 캡처, JS 오류0. 전체 브라우저 정상 완주·터치 이동 숙련 검사는 하지 않았다.
- `normal/stage-29.json`: **숨겨진 아이템 호출 없는 정상 자원 Native App 입력 봇**. 경지별 합법 시작 예산·자동 스킬 배분의 선언된 입장 fixture. HP·위치·목표·적AI·승패를 바꾸지 않고 이동/점프/기예/방어/대화 입력만 사용했다. R13·55행동에 B출구로 승리, 세 유한 증원 모두 생성. 승리 직전 생존HP: 설오437/935, 담허448/998, 휘겸1550/1598, 소단554/1144. 소단이 점검교에 남아 있고 휘겸이 출구 범위에 들어가 완료했다. 결과 화면의 회복 전 상태는 `combatEnd`에 따로 기록했다. 이전 아이템을 쓴 진단은 정상 완주 증거에서 제외했다.
- 환경 검증30맵 오류0. 두 HTML 빌드 완료. 전체 캠페인 verify·성능·공개 Pages 검사는 이 미승인 장별 작업에서 반복하지 않았다. 기존 전체 기준선 실패를 이번 통과로 바꾸지 않았다.
- 각 군집/파동의 첫 실효 행동과 플레이어 반응을 전부 묶는 encounter 승인 manifest는 아직 완성하지 않았다. 파동 생성만으로 모든 파동의 전술 효과를 합격 처리하지 않는다.
