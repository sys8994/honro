## 구현

renderer의 `GEOLOGICAL_PLACEMENTS`에는 지지 지형 ID와 장소 의미가 있는 구성점만 정의한다. Y는 기존 terrain의 `topAt`에서 구한다. `GEOLOGY_GROUPS`는 공통 부재의 재사용 가능한 조합이다. 개별 장의 충돌/지형 데이터를 복사하지 않는다.

- **3장:** `ferry-ground`의 x=560 잔교 아래 젖은 퇴적층, x=2260 비탈 아래 흙 둔덕, x=3190 우측 배수 침식의 비대칭 3군집. 큰 층의 방향·비율과 돌의 형태·매몰 깊이가 다르며 아래에 독립된 장식을 두지 않는다.
- **18장:** `act2-floor`의 x=430 디딤면 아래 기반 어깨, x=1130 낮은 암반층의 매몰석, x=1960 비탈의 깨진 암석 포획체. 모두 지표에서 약 1~4H 안쪽에 중간 구조를 구성한다. 깊은 몸체는 기존의 넓은 명암으로 이어진다. 이 구간의 자동 장식은 대체하고, x>3000의 기존 구성은 유지한다.
- 모든 새 군집의 instance opacity는 **1**이다. 기반층/돌의 몸체도 불투명하다. 몇 개 큰 명암만 몸체 위에 얹으며 서로 다른 돌의 몸체가 비쳐 보이지 않는다. 개별 돌의 저작 bounds×scale 높이는 대략 0.75~1.95H이며 매몰된 하단을 제외한 노출 크기는 이보다 작다. 캐릭터·카메라는 변경하지 않았다.
- 큰 기반층 → 접촉 틈 → 서로 다른 돌 → **같은 기반층의 앞면** 순서로 그린다. 앞면은 동일한 bounds/gradient/transform을 써서 돌 하단을 가린다. 개별 돌 아래의 반복 선반/받침은 사용하지 않는다.
- 중간 지질 구조는 `structure` LOD로 광역에서도 유지한다. 기존 작은 장식의 `middle` LOD는 유지한다. `prepare`/Path2D/타일 캐시와 노드 bounds culling을 재사용하고, 명시 조합을 우선한 전체 72 부재 한도를 적용한다.
- 미세결·노이즈·반복 타일·래스터·새 필터·새 엔진은 추가하지 않았다. 새 부재는 각각 1~5개의 큰 저작 Path와 기존 재질/팔레트로 만든다.

## 필요한 확인만 수행

[실제 기록](clustered-checks.json): 위 두 카메라만 확인했다. page error 0, terrain/units/markers/events/objectives 직렬화 동일, prepare 1회, 반복 렌더의 타일 생성 증가 0. 3장은 3개 큰 부재+13개 중간 부재, 18장은 전체 맵 5개 큰 부재+35개 중간 부재(그중 정상 화면에 보이는 곳이 명시 군집)이며 전체 예산 72 이하다. 타일 메모리는 각각 21,300,480B / 15,975,360B로 이전 동일 카메라와 같다.

실제 두 PNG를 보고 접지·부분 가림·인물 대비 크기와 불투명 면을 확인했다. 새 전체 검사·전 장 순회·별도 검수자는 실행하지 않았다. 이전 `after-*`, `refined-*`는 각 revision의 기록이며 현재 revision의 다른 장 검증을 뜻하지 않는다.
