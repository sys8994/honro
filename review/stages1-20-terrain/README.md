# 현행 지형 보존 화면

기준: `de286f94`. 이번 후속 대조에서 추가 지형 변경을 확정하지 않아 전후 비교를 꾸미지 않고 현행 화면만 보존한다.

- [6장 교량 위·아래](https://raw.githubusercontent.com/sys8994/honro/569e11123b2e077ef1f37aeaf92f44d131df73e5/review/stages1-20-terrain/stage6-bridge-levels-preserved.png): 아래 연속 호송로와 위 상판·파손 틈의 높이 차이. 실제 기본 이동으로 서쪽 잔해에서 가운데 상판까지 연결했다.
- [20장 쉼터](https://raw.githubusercontent.com/sys8994/honro/569e11123b2e077ef1f37aeaf92f44d131df73e5/review/stages1-20-terrain/stage20-rest-overwatch-preserved.png): 오른쪽으로 이어지는 호송 길과 별도 높은 사격턱. 두 선택 사격턱 접근·지면 복귀를 실제 기본 이동으로 확인했다.

두 화면은 기존 생성 번들의 실제 Chromium production Scene에 관찰 카메라를 적용했다. 초기 배우·지형을 그대로 사용하며 정상 연속 도달·전투 완료를 주장하지 않는다. 상세 판단과 검수 한계는 [지형·동선 대조](../../game/docs/STAGES1_20_TERRAIN_REVIEW.md)에 있다.
