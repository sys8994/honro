## Mechanism

Same original25 compound paths, order, fillRule, apron, original grass/roads and shared material. The existing base rendering and1716+transition are unchanged. Only eligible partial-grass internal pixels within1420..1716 can haveRGB corrected. Original alpha bytes are never assigned. Original1x opaque-grass mask, road mask and fullBODY/field/target opacity gate stay intact; high-resolution road or unresolved-alpha samples are additionally skipped. Original opaque protected palette pixels are conservatively skipped even if finite precision in a cropped mask yields partial coverage. This palette guard was added after a Native synthetic-field test exposed two such pixels at scale0.6; the original failed draft remains locally recorded, not treated as acceptable tolerance.

For eligible pixels, render native colors and semantic labels at2x/4x on stripes whose row count is derived from the pixel and total logical-memory caps. Shared field texels are enlarged by exact integer nearest-neighbor drawImage with smoothing disabled, so no new texture-filter assumption. The source vectors are rasterized at the actual camera/cache transform and subpixelphase. Use explicit integer-grid premultiplied RGBA sums and equal box weights; no drawImage high-quality downsampling. Source-over AA at the higher sample resolution remains an approximation, not exact original256 binary point sampling or analytic area coverage.

The first native Canvas supersample scratch is reused for colors and labels. Every resize and readback dimension is asserted. Each high-resolution scratch is capped at1,048,576 pixels; stripe height adapts to width and factor. The low ROI is also capped at1,048,576 pixels. Scratch plus live color/label/old/mask/field readback payload is accounted and capped at24MiB. Stats explicitly exclude JS/native/GPU allocator overhead and possible delayed GC. Scene benchmark clear reduces buffers to1x1. No scanline/spatial compiler is used in the new helper.

## Validation and interpretation

The Node and in-browser premultiplied box-mean unit case includes fully transparent colored texels and half-alpha color. Exact expected alpha/weightedRGB is asserted, plus uniform2x/4x Node cases. The actualScene fixture uses DOM-attached correct bitmap/CSS canvases. Cold10, warm60 and pan60 are retained; debug spatial verification is disabled for timed paths. These are decoded/prepared isolatedScene measurements, not cold app startup, real phoneFPS, UI Continue or complete campaign play.

Local Native synthetic-field2x and4x checks across five scales: original alpha0differences, above1420 differences0, opaquegrass224,134pixels changed0. This is not realScene evidence. Full color+semantic supersampling was materially more expensive than the mask-only feasibility test (roughly0.71s for2x /1.00s for4x accumulated over five differently scaled800x500views in one Native run); do not cite mask-only timings as production cost. Chrome measurements must decide whether the architecture is viable. Reject rather than tune endlessly if real cost or visible residual edges are unacceptable.
